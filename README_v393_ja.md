# SERA v393 — ビットタラン攻撃関節の座標ずれ・頭部埋まり回避の修正

- 攻撃中の足首・関節位置が時間とともにずれる不具合を修正しました。IKが足先のワールド座標を一時補正しても、次のアニメーション再生フレームで各関節の親基準ローカル位置をBlockbench原本のバインド値に復元します。関節の相対位置と骨の長さが攻撃を重ねても変化しない構造です。**Head関節だけは従来どおり独立追尾の位置制御を維持**します。
- v392で追加した頭部の上下回転（Pitch）にも、従来Yawと同じ**実メッシュ間の最大10cm侵入深度制約**を追加しました。回転途中で脚に侵入する直前に補間を制限し、脚から遠ざかる回転は許可します。
- 既に膝が頭へ入り込んだ場合は、頭部と脚のメッシュ同士の干渉深度を測定し、悪化させない上方向の補正を選びます。倒れている間も頭部が脚に埋まり込んだ場合は補正を試みます。
- 元のBlockbenchのモデル、関節Pivot、アニメーション、攻撃時間、胴体45°追尾、踏みつけ先端短辺の接地方針は変えていません。
- 12種類×2周の攻撃で関節ローカル座標が元の値へ復元されること、頭部のPitchで脚へ侵入しないことを検証する専用Godotランタイムテストを追加しました。
- Android実機の描画確認は別途必要です。
