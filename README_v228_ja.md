# SERA v228 — SLIDE靴底の全面接地と腰の沈み込み

## 変更点
重量脚部B/Dの通常移動SLIDEに限り、v227の両足IKを改良しました。

- **靴底を水平化**：両足の足首を回転して靴底を床と平行にします。B・Dの靴底は元データで平面形状のため、踵からつま先まで接地する向きになります。
- **実際の靴底頂点で高さ調整**：水平化してから左右の靴底最低点を計測し、腿→膝下の二骨IKで足首を床に合わせます。靴メッシュだけを床へ移動する方法は使いません。
- **腰を少し落とす**：SLIDE中は表示用の腰高を常時7cm下げ、必要なときは合計最大30cmまで下げます。膝が伸びきらない余裕を作ります。

## 変更しないもの
元のBoost_*モーション、Blockbench原本、移動速度、当たり判定、HP/EN、足音、背面スラスター、通常BOOST、STEP、攻撃、ジャンプ、ガード、被弾、LOWER BODY A/CとNEXUS展示は変更しません。

## 検証上の注意
元靴の底面が平らという前提はB/Dのモデルデータで確認しています。新規装備の足底が傾いた形状の場合は別途校正が必要です。GitHub Actionsの静的・形状検査は実機描画の確認ではありません。Android実機では特に旋回時の足首、膝方向、SLIDE入出の姿勢を確認してください。
