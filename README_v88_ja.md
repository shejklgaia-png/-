# セラ v88 — バックステップ距離4m

- 基準版：v87 (`sera_portrait_godot_melee_v87_backstep_boost_step.zip`)。
- 画面下フリックの**バックステップ**移動予定距離を **2.0m → 4.0m**に変更。
- 速度は従来どおり、対象表面との距離に応じた **8～10m/s**。移動時間は **約0.40～0.50秒**（途中の衝突や入力による中断がなければ）。左右ステップの最大0.40秒制限は維持。
- 移動方向はロックオン敵から遠ざかる方向。衝突判定・Backstepポーズ・残像・カメラ制御はv87を継承。
- HUDの待機時表記を `SIDE <=0.4s / BACK 4.0m` に変更。
- ブースト＝ロングドラッグ時の加速移動、ステップ＝フリック高速回避。v87から変更なし。
- 格闘3段ダメージ12/12/26、左右ステップ、接敵・被弾・敵AI、既存アセットを維持。
