# SERA v191 — 標準骨格「足C」追加

## 機能
- GitHubの `models/storage/足C.bbmodel` を元に、左右の靴（片側2メッシュ）を標準骨格 `Foot_L` / `Foot_R` に合わせて取り込みました。
- 元モデルでは左右のフォルダが「右足」「右足2」と記載されています。実際のX座標がそれぞれ +14.1 と -14.1 なので、右足・左足として正規化しています。
- スケール調整で、標準Aの片足寸法4×4×8（BB単位）に対し、Cは **幅4.64（+16%）×高さ4.56（+14%）×前後8.961（+12%）** です。
- 統合先は `models/SERA_BOOSTER_allテスト.bbmodel` の `Waist3`。左右の `Thigh_L3 → LowerLeg_L3 → Foot_L3`（右も同様）を追加しました。腰・腿・膝下は標準Aのメッシュを別UUIDで複製し、足先だけ提供されたC靴へ交換しています。
- 新しい下半身はNEXUSのCUSTOMIZATION → **LOWER BODY = C** で選択できます。既存のA/B、鳥足Dおよび独立した頭Cは保持されています。
- モーションはA標準骨格に追従し、足C独自のアニメーションは不要です。v190の足裏高さ補正・接地足音も利用します。ボディのステータスは現在Aと同じ暫定値を継承します。
- 元の `足C.bbmodel`、標準Aの既存メッシュ・既存23モーション、B/鳥足D、頭Cの姿勢を変更していません。

## インポートの境界
- 今回追加したのは **靴底4メッシュのみ**。元ファイルの腰・腿・膝などにある他の8メッシュは取り込んでいません。
- 元素材の面/UV、頂点の形状は維持し、X/Zを0.29倍、Yを0.57倍に調整しました。元のテクスチャが埋め込まれていない場合は既存のSERAパレット表示になります。
- 脚の接地補正は静止モデルを基準とした高さ調整です。歩行IKと段差への足合わせは含まれません。

## 確認手順
1. GitSyncで `main` を同期し、Godotの `SERA v191` を開きます。
2. NEXUS → CUSTOMIZATIONでLOWER BODYをCに切り替えます。足のサイズ・接合・色と左右、A/B/Dへの切替を確認してください。
3. HEADをCにして頭Cと足Cを同時選択できることを確認します。
4. TRAININGで走行・停止・ブースト・ステップと足音・接地高さを確認してください。

**検証状況**: GitHub CIで構造とデータの静的検査を実施。Android実機描画と音声の確認は未実施です。
