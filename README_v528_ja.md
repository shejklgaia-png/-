# SERA v528 — 共通LABO 3D研究室・クレート行動・角丸UI

## 実装
- LABO・素材変換（精製/分解）・倉庫は、**同じ3D研究室**を画面上端から30%の領域に常時表示します。共通の `SubViewportContainer` + `SubViewport` は初めて施設を開いたときにだけ生成します。施設のタブ切替では再生成しません。
- 研究室は静止画像ではなく、Godot標準の3Dメッシュで構成します。若干の煽り視点の固定カメラ、設備・床・壁・照明、稼働する3Dプリンター（ヘッド往復・印刷中パーツの高さ変動）、端末を設置します。
- **クレート**は小型キャタピラ、横長の発光バイザー、三本指のC字マニピュレータを備えたローポリ3Dモデル。経路探索AIや物理演算なしで、プリンター確認→端末へ移動→端末操作・情報確認→プリンターへ戻る、の実動作ループで移動・向き・頭・アーム姿勢が変化します。絵文字顔、会話、飲食の描写はありません。
- 全選択UIは同一 `StyleBoxFlat` ベースの**角丸ブルーグレー**。共通Themeが「装備製作/素材変換/倉庫」タブ、LABO選択肢、倉庫内カテゴリ、素材変換操作、戻るボタンを統一し、装備・素材カードも四隅を欠く旧枠から角丸へ切り替えています。
- 以前のAndroid Godotエディターで動作確認済みの**標準Button/HBox/VBox、WebPアトラスのソース直接復号フォールバック、アイコン後付け、保存・素材・試作製作**は維持しています。カードは100pxの高さとし、3列、7/12件の一覧を表示します。

## 省電力・軽量化
- 3Dシーンは初回のみ遅延生成し、タブで共通再利用します。別施設や拠点に戻ると `SubViewport.UPDATE_DISABLED` と `hero_stage.set_process(false)` で描画・行動を止めます。小さなSubViewportとGodot標準の不透明ローポリメッシュを使用します。
- キャタピラ歩行・造形機は少数の位置補間で動かし、NavigationAgent/物理ボディ/3Dテクスチャの追加はありません。描画性能はAndroid実機で最終評価してください。
