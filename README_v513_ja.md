# SERA v513 — マット調アイコン19種類と試作装備のLABO製作・倉庫・カスタマイズ

## アイコン・資源施設
- ユーザーが選んだマット調のアイコン画像を **WebP RGBAアトラス（288×360px、72×72px×4列×5行）** として収録。
- スクラップ／合金／電子部品／有機素材の各低・中・高＝12素材、試作装備7種に**19種すべて固有アイコン**を割り当て。素材・装備のIDとの対応を`scripts/sera_item_icons.gd`に固定。
- 倉庫では12素材のアイコン・名前・所持数、製作した装備のアイコン・名前・個体IDを確認できる。
- 精製・分解装置の素材選択画面には各系統の低/中/高アイコン、変換画面には「入力アイコン×必要数 → 出力アイコン×出来高」を表示。

| H01 | スカウトバイザー | 頭 |

LABOで「試作装備の製作」を開き、実アイコン付きの一覧から選択して製作。**本段階は素材消費なし**（未確定レシピを仮決めしない）。製作は登録済みの有効なセーブスロットでのみ行い、倉庫に製作物を追加する。製作された装備はNEXUSのカスタマイズ画面で装着・選択し、現在装着中の個体アイコンを表示可能。

## 命名と重複防止
- 設計IDと表示名を分離。IDは不変、品名は後から変更可能。
- 個体IDは`設計ID-通算連番`（最低4桁、上限以上なら桁数拡張）。例：同じ試作頭部を3つ製作すると`H01-0001`、`H01-0002`、`H01-0003`。各セーブスロット内の採番履歴を保持し、重複したUIDを拒否。
- セーブデータは既存スキーマv2に`crafted_items`、`craft_serials`、`equipped_crafted`を追加。旧セーブには空欄を自動補完し、素材・以前の装備選択には影響させない。製作/装着処理は保存成功後のみメモリを確定。
- この7アイコンは**新3Dモデルではない**。装備中は対応する既存の機体モデルセットAを暫定使用し、NEXUS表示と戦闘用装備スロットを一致させる。新3Dモデル製作は別工程。

## CIと保護対象
- v510以降のmain、AGENTS、CIマニフェスト、既存の素材変換・装備切り替え・セーブ・NEXUSのテストを確認。素材アイコンと試作品のランタイム/静的テストを**実装前に作成しCI登録**済み。
- `tools/v511_matte_icons_self_check.py`と`tools/v511_matte_icons_runtime_check.gd`は、19アイコン実画像、全材料/装備の登録、倉庫と変換の画像、製作採番、ロード後のUID維持、誤スロット装着拒否などを検証。
- 旧機体モデル原本、バトル、予測シールドv512の新しい描画・テスト、資源変換比率/固定素材、基地配置・戻る操作を変更しない。全CIはmainマージ後に実行する。
