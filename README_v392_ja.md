# SERA v392 — ビットタランの見下ろし・胴体斜め45°・踏みつけの着地

- 頭部は従来の水平固定・プレイヤーへの上下スライド追従をやめ、首のYaw（左右）→Pitch（上下）の順で先端短辺をプレイヤーへ向けます。回転は世界上方向基準で組み立て、余計なRoll（横倒し）を生じさせません。ダウン時の予告動作と脚への接触回避用の上下移動は維持しています。
- 攻撃中の胴体は、攻撃腕に対して左右45°斜めとなるようプレイヤーへの照準から45°オフセットして旋回します。向きは予備動作中に更新し、振り抜き中は固定します。敵のルートと支持脚の接地位置は動かしません。
- 踏みつけの予備動作中は、元のBlockbenchの股関節・膝・足首の姿勢をそのまま再生します。0.25秒の振り下ろし中だけ、足先の短い接地面を地面に水平になるよう補間します。着地後は短辺の向きを維持し、足先実メッシュの最低点で接地高さを調整します。
- 攻撃時間・硬直・既存キー・脚破壊・ダウン・衝突判定の方針は維持します。新しい専用Godotテストで頭部のロール・攻撃12通り・踏みつけ接地を検査します。Android実機での表示確認は別途必要です。
