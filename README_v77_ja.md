# SERA v77 — 時間差で残る3重残像

## 表示仕様
- ステップと円外ブーストでのみ、新しい残像を約0.055秒間隔で生成します。
- 発生時点の全身モーションの姿勢とワールド座標を静止状態で記録するため、残像は本体に追従しません。
- 1枚は0.22秒間表示し、時間経過で不透明度が二次曲線に沿って0まで減少します。
- 最大3枚。同じ発生枠を再利用するため、長時間ブーストでも残像の数は増えません。
- 発生時の不透明度はステップ0.34、ブースト0.28。停止後にも既存残像は自然消滅します。
- 背景・敵・弾丸・HUDには残像／ブラーを適用しません。

## 描画負荷
- 24パーツそれぞれに3インスタンスの `MultiMeshInstance3D` を1つずつ生成します（追加描画バッチは24、単純な72ノード／ドローにはしません）。
- 元のメッシュを共有し、残像の発生時だけ全パーツのワールド変換を一括記録します。
- 描画範囲（AABB）は発生位置に追従して更新し、フィールドの中心から遠くへ移動しても残像が消えないようにしています。
- 画面全体のポストプロセスやViewport／CPUでのメッシュ再構築はありません。
- Android実機でのFPS・重なり具合は未検証です。
