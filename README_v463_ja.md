# SERA v463 — ビットタラン背部独立レールガン

## 追加した攻撃
- 背部の既存2本のレール状メッシュを、Bodyに取り付けた独立した旋回（Yaw）・仰角（Pitch）Pivotで操作します。脚4本・頭・歩行・原本攻撃のキーフレームには変更を加えません。
- **レーザー発射開始は10.0秒周期**、発射後**2.0秒間**の太い青白いレーザーを照射します。照射中もプレイヤーを滑らかに追尾します。
- 発射終了後は照準を**0.4秒間保持**し、続く0.8秒で基本角度へ滑らかに復帰します。その後、チャージ開始とともにプレイヤー追尾を再開します。
- 発射前には銃口の青白い球状発光が0.2秒で縮小・消滅し、その**0.2秒後**にレーザーが出ます。
- 左右の側面箱それぞれに短い発光バーを3本配置し、チャージ経過に応じて順番に点灯します。
- レーザーの衝突は発光軸とセラの位置を使って計測し、0.5秒以上の間隔で既存のガード・シールド・HP・KO処理へ入力します。

## 実装／検証
- 新規 `scripts/bittaran_railgun.gd` はモデル外の専用制御で、`models/bosses/Bittaran.bbmodel` と自動生成データは変更しません。
- `scripts/bittaran_battle.gd` から砲台をBodyの子へ接続し、物理フレームで独立更新します。
- 新規 `tools/bittaran_railgun_runtime_check.gd` をGodot CIマニフェストに登録し、周期、光球、照射、充填表示、砲台姿勢、既存14ボーン保持を検証します。
- Android実機では照準の機体干渉、側面バーの視認性、半透明の描画・レーザーの厚み、ガード時の当たり判定を別途確認してください。
