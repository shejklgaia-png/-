# SERA v440 — 攻撃脚を固定床Y=0に接地、関節接続を維持

## 概要
前バージョンでは、歩行・旋回の4脚と、攻撃時の非攻撃3脚にIKが適用されていましたが、**攻撃脚そのものの床接触は原本アニメーション任せ**でした。今回は攻撃脚にも関節IKで床接触を加えました。

床は無限に広い完全な平面で、**高さY=0の固定値**です。地形サンプリング、レイキャスト、物理形状の動的生成は不要です。

## 軽量化した接地処理
ビットタランの各脚は上肢・下肢・足先の**3つの直方体メッシュ**で構成されています。各メッシュの回転を含む最下点は、8頂点を走査せず、直方体の中心・半径から正確に計算できます。

`lowest_y = (global_transform * box_center).y - (abs(basis.x.y)*half.x + abs(basis.y.y)*half.y + abs(basis.z.y)*half.z)`

- 起動時に、各脚の3つのメッシュ参照とAABB中心・半サイズを1回だけキャッシュ。
- 攻撃中は1フレームにつき**3直方体の最下点評価＋攻撃脚2ボーンIKを最大1回**だけ実行。
- 旧案の毎フレーム24頂点走査とIKの複数回反復は廃止。Godotの本番ビルドではIK後の再計測も省略し、開発ビルドだけ接触残差を記録。
- 足先の原本回転方向は維持し、**上肢・下肢の関節回転のみ**で足先／すねの高さを補正。補正後の足裏は物理的に届く範囲で床と接触します。
- 同時に従来の**非攻撃脚3本のワールド固定接地IK**を維持。攻撃開始・終了の姿勢補間、往路／復路の再生時間とスローはv439から変更していません。
- 胴体の高さ、モデルルートの位置、脚の関節ローカル位置／骨長、全18メッシュのローカル位置・回転・スケールは変えません。メッシュ単体を床へスナップさせません。

## 到達可能性に関する制約
固定長の2ボーン関節から**物理的に届かない床上の目標**がある場合、関節を伸長・切断・メッシュ独立平行移動することはできません。その場合は到達限界で停止し、足先が床から離れる／一部が床を貫通する残差が残る可能性があります。これは関節整合性を優先した制限であり、全ての姿勢で接地保証をするものではありません。
