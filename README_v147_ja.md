# SERA v147 — CUSTOMIZEの拡大・縮小を2倍速に変更（2026-11-08）

セラの展示位置からCUSTOMIZE拡大位置への移動・拡大と、戻る操作時の展示台への縮小・格納を、どちらも**0.28秒から0.14秒**に短縮しました。直線移動、表示サイズの制御、回転と背景グリッドの仕様は変更しません。

カメラは従来どおり0.18秒で同時に移動します。モデルが0.14秒で先に目標画面座標へ到達した後も、カメラの0.18秒が完了するまで相対位置を維持し、カメラ完了時に最終モデル位置を確定します。これにより到着時の瞬間移動を避けます。

シアンの放射グラデーション・サイバー青グリッドは拡大時に両方の移動が終了してから表示し、戻る操作では即時消去します。3区画メニュー・NEXUS_pose・他の設備・戦闘・音声は変更しません。

Godotで表示するプロジェクト名は命名規則に従い`SERA v147`です。

静的検査：`tools/v147_customize_double_speed_self_check.py`。GodotエディターとAndroid実機での映像・実際のアニメーション速度は未検証です。
