# SERA v428 — なぎ払いの低姿勢・足先モデルの水平化

## 低姿勢
- 左右のなぎ払い時だけ胴体降下限度を従来の1.10mから1.70mまで拡張します。下限は常にBodyメッシュの実際の床面クリアランス（20mm）で制限し、床下には埋めません。
- 攻撃中に足先が床に到達した後も、胴体の低い姿勢を維持し、攻撃後の「脚を先に戻す→胴体を上げる」復帰順序は変更しません。
- 踏みつけ・弾きの胴体降下限度1.10mは据え置きです。

## 足先モデルの水平化
- Blockbenchのモデルで足先の長軸は左右それぞれのボーンローカル回転とは異なる場合があるため、実メッシュの中心方向ベクトルをワールド空間で計測します。
- なぎ払いのキーフレーム0への導入（0〜0.32秒）を維持し、0.32〜0.70秒に足先の長軸を床と平行になる方向へクォータニオン補間します。足先の向きは自然に連続遷移します。
- 水平補正後のモデルの最下点を用いて接地・床貫通回避を解き直し、脛は必要な場合だけ床を回避します。攻撃終了後は水平化を解除し、基本姿勢へ戻ります。
- 各フレームの原本キー姿勢から方向を再計算するため、繰り返すたびに足先の角度が蓄積することはありません。

- v428で左右なぎ払いの床と水平な足先長軸、低い胴体、接地精度、反復時のズレを検証します。
