# SERA v381 — ビットタラン・四脚攻撃（2026-11-15）

## 新しい行動

ビットタランの**前左・前右・後左・後右**の各脚が、以下の3種類から攻撃します。敵が生存し、立っていて、攻撃対象が近く、該当脚が未破壊の場合に発動します。

| 攻撃 | 予備動作 | 打撃 | 復帰 |
|---|---|---|---|
| 踏みつけ（STOMP） | 1.00秒かけて攻撃脚を1.05m持ち上げる | 0.20秒で着地。**接地と同時**に、その脚の現在の脛のX/Z投影幅の**1.5倍**まで衝撃波を発生 | 0.48秒で自然に戻る |
| 外向き蹴り（KICK） | 1.00秒かけて胴体を屈め、**足裏の接地点を移動させず**膝を内側にたたむ | 0.19秒で外側へ1.65mの目標位置に蹴り出す | 0.45秒で徐々に元へ |
| 横薙ぎ（SWEEP） | 0.72秒かけて攻撃脚側へ胴体を傾け、肩の高さを下げ、脚を地面方向へ伸ばす | 0.35秒で低い脚を横に鞭状スイング | 0.65秒で体幹・脚・接地点を滑らかに戻す |

攻撃タイプは巡回し、脚はプレイヤーとの距離に基づいて選択します。攻撃中は歩行・旋回を一時停止し、すべてのモーションは**既存の四脚IKと実モデル**を使用します。元のBlockbenchファイルと既存のWait/Idle/Turn/Approachキーフレームは変更していません。

## ダメージ・演出

- 踏みつけは着地1フレームで、足本体と脛投影幅1.5倍の衝撃波を同時判定します。リングは約0.30秒で消え、発動位置に残ります。
- 蹴りと横薙ぎは実モデルの各メッシュの当たり判定を使用し、空間の空洞部分を大きな箱として攻撃判定にしません。
- 1回の攻撃で与えるダメージは最大1ヒット。ダメージ処理は既存の防御・SH・HP・ノックバック・KOを再利用します。
- 脚の破壊、転倒、起き上がり、死亡、再出現時は通常攻撃を停止または初期化します。既存の10cm頭・脚干渉制御やダウン手順を変えません。
