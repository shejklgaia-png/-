# SERA v544 — ビットタラン歩行の足音を抑える

## 2026年11月22日の更新

- ビットタランの**歩行時の足音**「ロボットの足音1」の出力レベルを **-5.0dB → -13.0dB** に変更しました。1音あたり8dB減で、線形振幅は従来のおよそ40%です。
- 歩行時に左右の足が接地して音声が重なるケースを考慮して、足音の音声同時再生上限を4→**2**に変更しました。接地に同期する再生タイミング、脚の動作、歩き時の土埃とカメラ振動は維持します。
- 攻撃予備動作「巨大ロボットが腕を動かす3」の音量**+4.0dB**、BGM **-8.0dB**、崩落・被弾SE、踏みつけ・弾き・なぎ払いの着弾音は変更していません。3回被弾で次の踏みつけ確定の仕様も維持します。
- 既存の音声形式・イベントタイミング検査（静的・Godot実シーン）へ、足音-13.0dB・2音制限、攻撃SE+4.0dB、BGM-8.0dBの期待値を実装前に追加しました。既存CIを削除・スキップしていません。
