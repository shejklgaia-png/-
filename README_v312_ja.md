# SERA v312 — 全方向の回避を7m・15m/sへ統一、回避方向へ低く傾く

## 通常ステップ（フリック回避）の仕様
- 前・後・左右・斜めを問わず、**移動距離7m**。画面フリックの方向へ直線移動する既存の衝突判定は維持。
- **標準速度15m/s**。装備補正が1.0倍なら、回避所要時間は`7÷15=約0.467秒`。既存の装備速度・時間補正とEN消費は継続適用。
- **低姿勢リーン**：既存4方向モーションのサンプリングとv311の「ロック中ターゲット方向＝セラの前方」を維持し、そのうえでWaistに回避方向への**22°の傾き**と**14cmの引下げ**を加えます。リーンの軸はセラのローカル進行方向を使用。前後左右・斜めで滑らかに変化します。
- ポーズ補正はステップ開始時に既存の0.12秒クロスフェードで増し、ステップ終了後は0.16秒で解除。衝突判定用`CharacterBody3D`は傾けたり床下に沈めたりしません。
- Blockbench原本（9.2.2の`Step_R`含む）、他のアニメーション、カタナ、ロック部位、カメラ、通常格闘は変更なし。

## 回避と攻撃の区別
- **左右蹴り派生**は従来の合計3m・基準10m/s・元の2倍モーション再生時間、コンボ当たり判定/オービット軌道を維持。新たな回避リーンは掛けません。
- **サマーソルト（Kick_b）**の既存5m後方飛翔も通常ステップの7m変更には含めません。

## 検証
- 既存の静的/Godot実行テストを新しい通常回避の距離・速度・姿勢処理に合わせて回帰検査。
- 新規テスト：全8方向での距離・速度・予定/実移動、低姿勢の角度/14cmオフセット、終了時復帰と蹴り派生からの分離。
- Android実機のタッチ操作感や描画は未検証です。
