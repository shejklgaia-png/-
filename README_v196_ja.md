# SERA v196 — NEXUSposeの両腕を下半身に応じて持ち上げる

## 動作
NEXUSの展示用SERAだけで、現在装着されている下半身と左右の腕の干渉を検査し、必要な側だけ肩・上腕の角度を最小限変更します。

- NEXUSposeの元の姿勢を記憶し、下半身と腕の装備を切り替えるたびに**必ず元姿勢へ戻してから再判定**します。
- 干渉がない場合：元のNEXUSposeから1度も変更しません。
- 干渉がある場合：肩は0.3°ずつ（最大8°）、上腕は1.5°ずつ（最大90°）、左右それぞれ外側・上方へ回転させます。最初に空間が空いた角度を採用します。
- 判定は表示中の実メッシュを用い、装備A/B/C/Dを問わず適用。非表示の装備メッシュは判定しません。
- SYSTEMの保存データを読み込んだときにも同じ再判定を行います。カスタマイズのシルエット・選択表示は更新します。

## 制限
- 判定は3Dメッシュを包む軸平行境界箱（AABB）です。複雑な形状では実際には重ならなくても回避姿勢になる可能性があります。最大角度でも重なりが残る場合は警告を出します。
- 元のNEXUSposeファイル、戦闘・訓練モーション、モデル形状、接地・カメラ、保存形式は変更していません。
- Android Godot実機での表示・角度・干渉は未検証です。

## 確認
1. `main`を同期し、Godotで**SERA v196**を開きます。
2. NEXUS → CUSTOMIZEで下半身AとDを切り替え、Dなど干渉がある時だけ両腕が上がるか確認します。
3. 下半身Aへ戻し、元のNEXUSposeの角度に戻るか確認します。
4. 腕装備Bや鳥脚C、SYSTEMの別セーブ読み込みでも確認します。
