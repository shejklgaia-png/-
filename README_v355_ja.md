# SERA v355 — ビットタラン戦のカメラ・操作・破壊・復活

- カメラのレンダリング補間とビットタランの14関節の物理補間を統一し、60Hz IKの表示チラつきを抑えます。最終IKに基づくロック選定は維持します。
- プレイヤーがボスの画面奥側に回り込んだとき、格闘フリックの前後基準だけ画面上下に固定します。0.65mで切り替え、手前0.25mで解除するヒステリシスを使います。格闘フリック入力中の基準は固定します。
- RUN/BOOSTおよび360度STEPの画面相対移動、ロック線と当たり判定は変更しません。
- 破壊された脚・頭の装甲は焼損色と橙色の発光を復活まで維持します。ヒット時フラッシュとは独立します。
- 敵死亡時は3D金属片が拡散して本体が焼損暗転します。透明な複製モデルは重ねません。
- 死亡3秒後、進行中のコンボが終了した時点で本体500HPと頭・全4脚の独立ゲージを同時に全回復します。本体が復活するまでは部位HPを回復しません。
- 1〜3本目の脚破壊時は頭が下がるダウンが2.5秒、4本目の脚破壊時は6秒です。ダウン中のみ頭・BODYをロック可能にします。

前版: [SERA v354](docs/history/release_notes/README_v354_ja.md)。

Android実機での最終的なカメラ描画・操作感は別途確認が必要です。
