# SERA v478 — レーザー連続ヒット・接地投影の追尾加速・ビットタラン高速化

## レーザーの発射と追尾
- **0〜10秒：充填**。砲台は基本姿勢のまま完全に静止し、プレイヤーを追いません。
- **10〜12秒：青い球体によるチャージ**。球体の出現と同時に1度だけ高速追尾を開始。追尾の入り0.7秒は滑らかに加速し、青い球体が縮小し終わるまで速度上限なしでプレイヤーを狙います。
- **12〜14秒：レーザー照射**。発射直後の基本追尾速度は旧値の**0.7倍**。レーザー軌道を地面へ投影した位置とプレイヤー足元の水平距離が**0.5mを超えた場合**、プレイヤーの実際の移動速度を測定し、速度に追いつくよう滑らかに旋回を加速します。0.5m以内に戻ると基本追尾速度まで滑らかに減速します。
- **14〜14.7秒：砲台の基本姿勢復帰**。0.7秒で姿勢を戻し、次の充填中は静止します。レーザー2秒・球体2秒は変更していません。

## ダメージ判定
- **1回のレーザー照射で命中できる最大回数に制限はありません。** レーザーに実際に触れている間、または照射中に再接触した際、**0.20秒間隔**で繰り返し命中できます。FPSによる異常な連続判定を防ぐため、時間基準で管理します。
- 通常のHP／ガード／シールドとノックバックを使用します。既存のDamageknockモーションは再被弾で先頭から再起動しません。射線外にいる間はダメージを受けません。
- プレイヤーがKOしてもレーザーは本来の2秒間照射し、エフェクトと基本姿勢復帰を維持します。

## ビットタラン本体の移動
- 歩行速度 **0.936 → 1.872 m/s（2倍）**、加速度 **0.78 → 1.56 m/s²（2倍）**。
- その場旋回 **34 → 68°/秒**、移動中旋回 **22 → 44°/秒**、停止時の向き微調整 **18 → 36°/秒**。
- 既存の原本足運び・脚接地IK、攻撃原本、砲台モデル、エフェクト、攻撃範囲は変更しません。

## 検査
- `tools/bittaran_railgun_runtime_check.gd` にて、従来の充填静止・青球体の高速追尾、レーザーの0.7倍追尾と0.5mの境界、移動速度連動の追尾加速、複数回実ヒット、連打抑制の時間間隔、ノックバックとガード、移動・旋回速度を検査します。
- Android実機での視覚・プレイフィールは別途確認が必要です。
