# SERA v329 — 投影セラ正面フリックと20%画面余白

- v328は見た目のセラ正面を取得しても実際のバッシュ／左右蹴り／サマーソルトでは固定スクリーンUP基準でした。v329はタッチ開始時にカメラへ投影したセラの正面を「前」、その右／左／後ろを90度の各セクターとして判定します。
- フリック中はこの投影軸を固定して、カメラの移動や攻撃中の回転で入力方向が入れ替わらないようにします。ガードからのバッシュも同じ軸を使用。通常STEPは従来通り画面360度方向へ移動し、コンボ受付時間・EN・モーションは変更しません。
- カメラ：セラの左右0.38mの胴体端を画面の20〜80%内に保護します。解析的フィットは22%の安全域で計算して2%の緩衝帯を設け、既存の平滑なズーム半径制御を維持。画面端Yawの反復探索は再導入しません。ターゲット中心構図を維持。
- Androidでの指入力・画角・見た目は未検証です。
