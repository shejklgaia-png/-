# SERA v238 — メカフレーム式の頭・四脚ターゲット

## 見た目
- 既存の2mキューブをメイン胴体として維持。頭部を上面から浮かせるのではなく、**前面（+Z）の外周に差し込むメカフレーム**へ移動。
- 頭：ネックマウント、センサーケース、左右レール、上下クロスメンバー、前面バイザー、破壊時の露出フレーム。
- 左右の前脚・後脚：**側面接続基部から外側へ張り出す構造**。股関節ジョイント、側方アウトリガー、縦フレーム、膝、ピストン、外装プレート、踵、地面に届く足先。
- 左右を対称配置し、前後は胴体側面の前後4か所へ固定。頭部・脚は、敵が左右へ動いても親ターゲットと同じ座標系で追従。

## 配置と部位判定
- コア：中心座標 (0,0,0)、2mのキューブ。既存の物理移動衝突はここだけ。
- HEAD：ローカル中心 (0,0.52,1.28)、外接範囲1.48×0.82×0.96m。前面へ張り出し、ロックは顔正面へ。
- 脚：X=±1.23、Y=-0.67、Z=±0.78m。各部位AABBは1.38×1.88×1.02mで、根元と外部フレームから足先まで内包。左右の脚のフレームは鏡映し。
- 静止ターゲット基準高さ1.53mで脚の足底はY=0m。既存上下ボブ（±0.07m）はそのままなので、動作中の足先は上下に移動します。
- 照準オフセットもメカフレーム外面寄りへ調整し、部位AABBを使う格闘ヒット・ターゲット自動変更に反映。

## 従来仕様の維持
- **頭部・四脚の個別耐久値、防御・破壊防御、前脚消失・後脚残留・頭部変形、破壊時の怯み、脚2本破壊での長ダウン、頭部破壊での敵攻撃制限**はv237と同じ。
- セラの操作・武器・モーション・装備、EN、中央胴体の物理コライダー、カメラ追従中心に変更はありません。
- 素材は不透明なBoxMeshのみ。Blockbench原本・装備インポーターへの変更はありません。
