# SERA v231 — BOOST中のカメラ微振動修正

## 参考動画からの確認
10.58秒の録画（1096×2560、約113fps）では、高速BOOST時の画面描画とキャラクター移動の更新間隔に差があります。機体の移動は固定の物理フレームで実行される一方、カメラは各描画フレームで最新の物理座標を使用していました。これにより、とくに近距離・斜め後方BOOSTで同じ座標と更新座標を交互に描画するカクつきが発生し得ます。

## 実装内容
- トレーニング画面内のみ`SceneTree.physics_interpolation`を有効にする。退室時は元設定に戻し、拠点・メニューには影響させない
- Playerと動くVirtualTarget、それぞれの床影をGodotの補間対象にする
- Camera3Dと各関節のアニメーションは独自の毎フレーム更新を維持（二重補間を防止）
- カメラの旋回、距離、画面内保護とHUDターゲットマーカーに補間済みPlayer/Targetの同一サンプルを使用
- ターゲットの上下モーションを物理更新に合わせ、リスタート時のテレポート補間をリセット

## 維持する仕様
v230の近距離BOOST角度処理・安全ズーム、v229のSLIDE/BOOST姿勢補間、脚IK、モーション原本、入力・移動・衝突・HP/EN・スラスター・足音は変更しません。
