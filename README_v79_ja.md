# セラ v79 格闘ブーストキャンセル時のカメラ追従修正

## 修正
- 格闘モーションの BOOST、DASH、STRIKE 各状態をカメラの移動中として扱います。格闘の予備動作中や攻撃中に待機時のリセンタリングへ入る問題を防ぎます。
- 格闘動作中、および外周円を越えたブースト移動中は、カメラの方位・ズーム追従レートを一時的に強化します。
- 格闘からドラッグブーストへのキャンセル時も、この高速追従モードが連続します。
- 通常走行・ステップのカメラ設定値は維持します。
- プレイヤー・敵・戦闘・被弾・残像など既存機能は変更しません。

## チェック
- Godotの実行環境はこの作業環境にないため、描画と実機での追従は未検証です。
- Androidで「遠距離から格闘接近→外周ブーストでキャンセル」および「格闘中の横ブースト」を確認してください。
