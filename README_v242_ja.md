# SERA v242 — ロック切替ボタン

## 配置
- トレーニング戦闘画面の左右端に `◀ LOCK` と `LOCK ▶` のボタンを配置しました。
- 中心高さは画面下端から40%（画面上端から60%）。スマートフォンの画面比率に追従するアンカー固定です。ボタンは各108×68px、左右端から18pxです。
- 下部のRUN/BOOST操作ガイドや上部のHP/EN/戻るボタンに重ならない位置です。

## 操作
- `◀ LOCK`：現在のロック位置から**画面に映る左側**で一番近い未破壊部位を選択。
- `LOCK ▶`：現在のロック位置から**画面に映る右側**で一番近い未破壊部位を選択。
- ロックしていない場合は画面中央を基準にします。敵の向き・部位名ではなく、カメラ投影した画面X座標で決めるため、視点が回り込んでも左右操作は直感に一致します。
- 遮蔽・画面外・破壊済みの部位は候補外です。押した方向に別部位がない場合は変更しません（端からの循環なし）。
- 手動選択は移動中・待機中も維持します。コンボやバッシュの途中では部位固定のため切替しません。選択部位が破壊された場合やターゲットが再出現したときは自動ロックに戻ります。

## 入力と従来仕様
- 専用タッチIDでボタンの押下・ドラッグ・離しを独立処理。ボタンを操作した指では攻撃・フリック・移動を発生させず、別指での移動を妨げません。
- 既存の自動ロック、ターゲットマーカー、近接追尾/部位破壊、カメラ/EN/操作ロジックはそのままです。
