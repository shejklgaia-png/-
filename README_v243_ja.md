# SERA v243 — 右下1/4の操作枠とAUTO/MANUALロック

## コントローラー
- 戦闘画面の**右下4分の1**（横50〜100%・縦50〜100%）に、半透明の操作エリアと細い青緑の外枠を追加しました。
- **枠内で最初にタッチした場合のみ**、RUN/BOOST、フリックステップ、格闘タップ、ホールドガードの操作が始まります。最初に枠外へ触れた指からはこれらの操作を開始しません。
- 一度枠内に触れれば、**ドラッグや指を離す位置は枠外でも自由**です。始点の固定と、既存の移動/BOOST/格闘/ガードの判定は変更しません。
- コントローラーの描画も起点から円が広がる既存のデザインを維持し、枠を超えてもドラッグ操作の円は継続します。

## ロック切替ボタン
- 操作枠の**左上**：`◀ LOCK`
- 操作枠の**中央上**：`AUTO`／`MANUAL`（タップで切替）
- 操作枠の**右上**：`LOCK ▶`

### AUTOモード（初期状態）
自機の正面にある狙える部位を従来どおり自動選択します。左右ボタンは使用できず、暗い状態で表示します。

### MANUALモード
切替直前のロック対象を維持します。左右ボタンを押すと**画面上の左右**で隣接する生存・表示中・非遮蔽の部位に切り替えます。破壊時やターゲット再出現時もMANUALモードを保持し、自動で別部位へ移りません。

## タッチ判定
- 切替ボタンへのタッチは格闘/ステップ/移動の開始として解釈しません。
- 指で操作枠内に触れた後のドラッグは枠の外へ出ても続きます。
- 既存のボタンと操作用指は別に追跡し、マルチタッチでの干渉を抑えています。
