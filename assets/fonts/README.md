# Bundled SIL OFL fonts for SERA

These fonts are redistributed under their individual SIL Open Font License 1.1 texts in this folder.

- Noto Sans JP variable (100–900), complete Japanese font.
- Rajdhani Bold for technical navigation.
- IBM Plex Mono Medium for equipment IDs.

Source: https://github.com/google/fonts/ (ofl/notosansjp, ofl/rajdhani, ofl/ibmplexmono).
Generated using tools/vendor_sera_fonts.py with Git blob SHA checks; the font glyph sets are not truncated.
WOFF2 files load directly as Godot 4.7 FontFile assets.
