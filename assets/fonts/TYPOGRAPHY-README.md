# SERA LAB typography (v548)

Bundled complete fonts from the Google Fonts upstream repository, redistributed under their respective SIL Open Font License v1.1 notices in this folder. Android does not fetch fonts from a CDN.

M PLUS 2: prominent Japanese headlines and equipment names.
IBM Plex Sans JP: Japanese controls, panels and body text.
M PLUS 1 Code: Japanese technical information and status lines.
Rajdhani Bold + IBM Plex Mono: technical English labels (unchanged).
Noto Sans JP remains available for compatibility if needed.

Sources: https://github.com/google/fonts/tree/main/ofl/mplus2, /mplus1code, /ibmplexsansjp. Source Git SHA is verified by tools/vendor_sera_typography.py.
