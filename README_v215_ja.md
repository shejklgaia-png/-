# SERA v215 — 鳥足Cの接地とモーションのガタつき修正

## 対象
カスタマイズ画面の `LOWER BODY=C`（逆関節の鳥足）専用です。A・B・Dの標準骨格のモーションと接地処理は維持します。

## 接地の修正
- 従来のRUN中は、足音が鳴る瞬間だけ鳥足の足メッシュを床へ動かし、次のフレームで元に戻していました。足首と足が1フレームだけ跳ねる原因になるため、**Cの足メッシュ瞬間移動だけを無効化**しました。
- 鳥足Cでは、歩行・待機中に左右の実際の足裏メッシュ頂点から床との高さを計測し、キャラクターの**表示用リグのみ**を0.10秒の時定数で滑らかに上下補正します。支持脚が切り替わっても急なY位置変更が起きにくい方式です。
- 足音は従来どおり、左右の足裏の浮上・接地判定から発生します。
- キャラクター本体の当たり判定・速度・Player座標は変更せず、ジャンプ中・NEXUS展示中はこの補正を行いません。

## モーションのガタつき
- 鳥足の旧Blockbenchデータでは、STEP・BOOSTの一部の関節にキーフレームがなく、未指定の関節が生のバインド姿勢へ切り替わる場合がありました。**欠けている関節だけ**、元の鳥足の待機ポーズで補完します。
- 前ステップ `Frontstep` の鳥足専用キーも未制作のため、当面は鳥足の待機関節姿勢を使用します。上半身の `Frontstep` は引き続き再生します。
- `Wait_motion`（3.6秒ループ）の左足首には0秒と約0.217秒に異なる回転キーがあり、ループの終端に戻る際に角度が跳ぶ問題がありました。ループ最後の0.2秒だけ開始姿勢へ滑らかに戻します。
- 作者の元ファイル・オリジナルのボーンPivot・RUN/BOOSTのキーフレーム値は編集していません。

## 検査
`tools/v215_bird_gait_grounding_self_check.py` にて標準Cの6ボーン、補完対象、接地補正、ループつなぎ、他の脚部との独立性を静的・数値チェックします。Android実機の見え方は未確認です。
