# SERA v304 — 各部位のカメラ／AUTOロック専用当たり判定を115%へ拡大

## 実装
- 頭部、左前脚、右前脚、左後脚、右後脚、BODYの**6対象に独立した不可視の`Area3D`＋`CollisionShape3D`＋`BoxShape3D`**を用意しました。
- 基準となる各部位の箱型エンベロープに対し、**幅・高さ・奥行きそれぞれ115%**のロック専用サイズへ拡大しています。各部位の回転・移動を追従します。
- HEADは従来の上方1.0m、前方0.85mのロック補助領域を包含した状態でさらに115%に拡大し、頭部ロックが難しくならないようにしています。
- 物理の`collision_layer`/`collision_mask`をどちらも0、`monitoring`/`monitorable`をfalseにしてあります。**専用領域はロック判定用のみ**で、キャラクターの衝突、攻撃の命中、ダメージ、部位破壊範囲には影響しません。

## ロック線との関係
- v303からの**セラ→敵中心を結ぶ左右0.5m間隔の2本線**は変わらず、同じ部位の拡大した専用ボックスに2本とも交差するときだけAUTO候補になります。
- BODY、頭、各脚は2本の最初の交点までの距離を比較して選択します。0.22秒の安定化時間・コンボ中の固定・破壊後のロック再取得は維持します。
- `LINES ON/OFF`は引き続き判定線のみを表示します。**拡大ボックスは透明・非表示**です。
- 以前の実メッシュ1本線検査APIは、古い形状テストとの互換性のため残します。ゲームのAUTOは専用ボックスを使用します。

## テスト
- v304静的検査＋Godot 4.7.2実行回帰を追加。6つの専用ボックスの115%寸法、親モデルの回転追従、衝突レイヤー無効、実メッシュ境界外のロック可否、攻撃／物理当たり判定の不変、BODY／HEADの選択、部位破壊を検証します。
- v303の片側1本の線だけが交差する状況も、新しいカメラ用ボックスで検査します。Android実機未確認。
