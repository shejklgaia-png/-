# SERA v193 — 下半身D追加・FEET削除

## 今回の修正
- 新しい標準骨格の脚パーツ（`models/storage/足C.bbmodel`）は、足先だけでなく、**腰・腿・膝下・足を含めた下半身セット**として扱います。
- NEXUS → CUSTOMIZATIONの **FEET** 行を完全に削除しました。
- **LOWER BODY** は4種類から選べます。
  - **A MID**：元の標準脚
  - **B HEAVY**：既存のBセット
  - **C BIRD**：従来Dだった逆関節脚。既存の鳥足専用6ボーンとキーフレームを維持
  - **D NEW**：今回追加した標準骨格の新しい下半身。標準Aの関節構造に合わせて、元の足Cファイルから腰2・腿4・膝下2・足4の全12メッシュを取り込み、一回り大きい形状に調整
- 追加した下半身Dは、元ファイルの12メッシュすべてをA骨格の関節ピボットへ対応付けています。元データの面・UVと左右構造を維持し、腰・腿・膝下は標準Aに対して全方向約10％大きい領域へ収まるよう変換、足先は幅116％・高さ114％・前後112％です。元ファイルは変更していません。
- 独立したHEAD Cはそのまま選択できます。鳥足、頭C、標準Aのモーションを削除・再生成していません。
- 訓練中の靴底高さ補正、足音、背丈に応じた衝突カプセル補正は、選んだLOWER BODYに対応します。
- カスタマイズ展示用セラの根元座標は接地高さ補正しません。画面内の位置・サイズは従来のカメラフィットのみで管理します。

## セーブデータ
- プロフィールをv2形式に更新しました。旧v191/v192保存の鳥足Dは新Cへ、旧下半身C／FEET Cは新Dへ**一度だけ**変換します。新形式の保存済みC/Dは再読み込みしても勝手に入れ替わりません。
- 旧グローバルcfgも初回読み込み時に同じ変換を行い、新しいcfg書き込みではスキーマ番号2を記録します。
- FEET設定は保存対象から外しました。他の装備設定・実績・進捗・プレイ時間は変更していません。

## 確認方法
1. GitSyncで `main` を同期し、Godotの `SERA v193` を開きます。
2. CUSTOMIZATION画面のFEET行がなく、LOWER BODYにA/B/C/Dが表示されることを確認します。
3. Cでは鳥足、Dでは新しい標準骨格の下半身が表示されることを確認します。
4. HEAD Cを組み合わせ、セラの位置やカメラの表示が崩れないことを確認します。
5. TRAININGでC・Dの走行、足音・接地と保存済み装備の復元を確認します。

**検証範囲**：GitHub Actionsのモデル構造・静的コード検査。Godot Android/Xperia 1 Vの実際の表示・操作はまだ検査していません。
