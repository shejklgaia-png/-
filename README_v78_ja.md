# セラ v78 — ブースト残像の消滅時間を短縮

## v77からの変更
- **ステップ**：残像の寿命0.22秒、不透明度34%、発生間隔0.055秒、二次曲線での透明度減衰を維持。
- **ブースト**：残像の寿命を0.22秒から**0.14秒**に短縮。不透明度28%と発生間隔0.055秒は維持。
- ブーストの消滅までの時間が短くなるため、同じ二次減衰でも透明度が速く低下します。
- 残像ごとに発生時の種別に基づく寿命を保存し、ブーストからステップ（または逆）へ切り替えても、既に発生済みの残像の寿命は変わりません。
- 最大残像数3、過去の全身ポーズと位置の固定、`MultiMesh` による軽量描画、背景ブラーなしは維持。
