# セラ v53 — v51俯瞰角度へ復帰・最低ステップ2.0m

## 変更点

- カメラの俯瞰角度をv51と同じ値に復帰（`CAMERA_ELEVATION_RATIO`: 0.11 → 0.1325）。
- 画面内の上下構図はv52を継続：注視点をターゲット中心より0.90m下に設定、画面下25%の操作用領域を保護。
- v52の近接ズーム限界7.8m、遠距離16m、全体フレームフィットも維持。
- ステップの予定移動距離下限を1.5m → 2.0mへ変更。
- 速度は2.0m以内で6m/s、2.0m超で10m/s。最大ステップ時間0.40秒、予定移動距離上限4.0m、基本円弧角度35°を維持。

## ステップ計算例（予定距離・衝突なし）

| ターゲット中心との水平距離 | 速度 | ステップ予定距離 | 所要時間 |
|---|---:|---:|---:|
| 1.0m | 6m/s | 2.0m | 約0.333秒 |
| 2.0m | 6m/s | 2.0m | 約0.333秒 |
| 3.0m | 10m/s | 2.0m | 0.20秒 |
| 5.0m | 10m/s | 約3.05m | 約0.305秒 |
| 8.0m | 10m/s | 4.0m | 0.40秒 |

近接時は必要に応じて回り込み角度を拡大します。ターゲット中心とほぼ重なる場合は、過度な回転を避けて接線方向の直線移動に切り替えます。**物理的な衝突がある場合、実際の移動距離は2.0mに達しないことがあります。**

## 維持事項

- 通常の左右ドラッグ、左右フリック、タップ攻撃、ステップモーション
- ターゲットとプレイヤーの当たり判定、および自動接近時の貫通防止
- v52の操作用空白領域とカメラ構図、近距離の引き加減
- 既存の3Dモデル、エフェクト、シーン、UI、アニメーション

## テスト

`python tools/v53_camera_step_self_check.py` を実行すると、変更値・既存関数の保全・円弧ステップ速度および移動時間とカメラ投影を検査します。これは静的/数値検証であり、Godot本体やAndroid実機での動作確認ではありません。
