# SERA v195 — LOWER BODY Dの外観・比率修正

## 原因
前回v193〜v194では、更新された「脚C」のモデル（ゲーム内はD）の各部位を、標準Aの腰・腿・膝下・足先の寸法枠に**別々の倍率で圧縮**していました。このため、Blockbenchで作った太い脚、大きな足先、長い靴の形状比率がゲーム内に反映されていませんでした。

## 今回の修正
- `models/storage/SERA_LEGS_C_AUTHOR_NORMALIZED.bbmodel` の12メッシュを、元のローカル頂点・面・UVに従い、**すべて一律36％で縮小**。パーツ別の独立した幅/高さ/奥行の縮小を廃止。
- 元の足裏Y=0.2を、ゲーム内Y=0へ合わせています。上端は約17.3 Blockbench単位で標準セラの腰付近へ接続。前後の位置関係は統一倍率で保持。
- 下半身全幅（両足を含む）は旧データの8.64から15.91 Blockbench単位、足の前後長は約8.96から約11.12へ拡大。脚・足の全体比率は原本と一致。
- `SERA_LOWER_BODY_D_STANDARD_READY.bbmodel`、`models/SERA_BOOSTER_allテスト.bbmodel` と両方のエクスポート用埋込を更新。
- Blockbenchの元ファイルはテクスチャを含まないため、Dのメッシュの色番号をGodot側で明示的に描画。腰と腿・膝下はローズ系、靴は淡いブルー系としました。
- 装備の選択は従来どおり **LOWER BODY D NEW**。標準A骨格の共有モーションに接続し、他のA/B/C装備、HEAD C、セーブデータ、タッチ操作、戦闘は変更しません。

## 重要
- モデルのシルエットを優先して全体を同一倍率で変換しています。元ファイルの関節Pivotは標準Aの骨格位置と完全には一致しないため、実機で膝・足首の屈曲や地面との接触を確認する必要があります。
- GitHubでの静的検査が成功してもAndroidのGodotによる描画・モーションの確認とは別です。
- Godotのプロジェクト名は `SERA v195`。同期後にCUSTOMIZEからDを選び、旧v194と足の幅・前後長・部位カラーを比較してください。
