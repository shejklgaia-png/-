# SERA v159 — BOOSTモーションの切り替え猶予

BOOSTからRUNに戻った後、**0.30秒間はBOOSTモーションを維持**します。これはアニメーションだけの猶予で、BOOST速度や入力判定を延長するものではありません。

- **BOOST中の方向転換**：指がBOOST解除範囲やRUNのデッドゾーンを一瞬通過しても、BOOSTモーションを維持します。0.30秒以内に別方向のBOOSTへ戻れば、間にRUNやWAITのモーションを挟まずBOOST姿勢の方向を更新します。
- **BOOST解除後もRUNで移動**：0.30秒間はBOOST姿勢のまま動き、猶予終了後にRUNモーションへ移行します。
- **停止を挟む短時間の方向変更**：同じタッチ操作中は中心の18px以内でも短時間BOOST姿勢を維持します。実際の移動速度は0のままです。
- **中断時**：指を離す／攻撃／ステップ／ガード／被弾／ジャンプ／着地の場合は猶予を解除し、それぞれのモーションへ移ります。

BOOSTの開始210px・解除184.8px未満・確定0.10秒、速度補間0.15秒、固定112px RUN円と360°入力、HUD表示、残像などは変更していません。

静的検査と独立したタイマー計算で確認しています。Godot/Android実機での動作は未検証です。
