# SERA v197 — NEXUSposeの腕が水平まで持ち上がる問題を修正

## 原因
v196では傾いた腕の大きな軸平行境界箱を用いていたため、空白も下半身との重なりとして検出される場合がありました。上腕の最大追加角度も90度と大きすぎました。

## 修正
- メッシュの向きに合わせたOBB（15軸の分離判定）を使用。AABBは軽量な一次判定のみ。
- 元のNEXUSposeから上腕最大24度、肩最大3.2度に制限。
- 左右独立で少しずつ上げ、非接触となる最小角度で止めます。完全に避けられない場合は干渉を減らせる最小の角度にし、改善できなければ元姿勢に戻します。
- 下半身/腕の装備切替時とセーブ読込時に再計算。NEXUSの展示のみ。戦闘アニメーションとモデルは変更しません。

GodotでSERA v197を開き、LOWER BODY Dで腕が以前のように水平にならず、下半身と接触しない高さで止まるかご確認ください。
