# SERA v263 — 接敵時の操作方向とセラのSTEP移動を一致させる

## 原因
- 前版ではSTEPの左右方向がカメラ座標、前後方向が敵を向くセラ本体の正面基準でした。接敵時にセラとカメラの相対角度が変わると二つの軸が斜交・反転し、斜め入力が打ち消されるなどして、入力と実際の移動方向がずれる問題がありました。
- STEP中にもカメラ方位が追従回転するため、固定されたワールド進行の見た目が画面上で旋回する問題もありました。

## 修正
- STEPの世界移動方向は`_screen_drag_to_ground(direction)`のみで求め、RUN/BOOSTと同じカメラ画面軸で全360°を解釈します。
- 移動方向はステップ開始時に固定。実モーションはそのワールド移動方向をセラ本体の正面から見た相対方向へ変換し、既存のFrontstep/Backstep/Step_L/Step_Rを連続ブレンドします。ステップ途中でセラが敵の方へ回転しても、モーションの方向は0.08秒スムージングで追従します。
- STEP中のカメラyawを保持して画面入力と経路の関係を安定化。ズームと画面内フレームフィットは維持、終了後は既存のカメラ追従に戻します。
- スラスターの後退成分は画面フリックYではなく、固定されたワールド進行に対する機体の背面方向から求めます。

## 維持
- 360°ステップ入力、前3m・後4m・左右2～4mの距離係数、EN消費・速度・連続衝突処理、v259コンボ受付中のロック固定、v261斜め後退ノズル、RUN/BOOST・Bashの入力ルール。
- **敵の体に当たった場合は衝突判定と壁面スライドの影響を受ける**ため、実際の移動距離・方向が障害物に制約される点は従来どおりです。

静的・数値テストで全角度/セラ・カメラの相対方向/カメラ回転・モーション補間を確認します。Godot/Android実機では未検証です。
