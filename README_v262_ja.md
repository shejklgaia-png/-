# SERA v262 — 360°連続STEPとモーション補間

## 入力
- STEPは画面でフリックした方向を**1度刻みや45°区画に丸めず、360°の連続方向**で受け付けます。真上=前、真下=後、左右は各サイドに対応。斜め30°/45°/60°も角度そのまま進行へ渡します。
- Guard/3段後のBashは従来通り**セラ正面基準の前方90°区画**を使用。STEPの新仕様の影響を受けません。

## モーションと移動
- 既存4クリップ `Frontstep`、`Backstep`、`Step_L`、`Step_R` の姿勢をフリック角度に応じて補間。四方向そのものではそれぞれの原本モーションを維持し、斜め方向は滑らかに合成します。
- ブレンド係数に三次イージングを追加してカード方向を横切るときの切替を滑らかにします。アニメーション開始/終了の既存0.12/0.16秒遷移も維持。
- 進行は画面横方向とセラ前後方向の加重合成を続行。前3m・後4mの純方向は維持し、純横への方向が近い部分だけ、距離の前後係数を滑らかに繋ぎます。
- 横2〜4m、速度の接敵時調整、EN15、連続衝突判定、STEP時のスラスター噴射と右下補正・加速演出も維持します。

## 検証
