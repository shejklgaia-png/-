# SERA v318 — ステップとカメラ追従

## STEP
- 通常の全方向フリックSTEPは **合計4m**、基準速度 **15m/s**（装備倍率は従来どおり）。開始瞬間に進行方向へ **0.3m** の衝突スイープを行い、その距離と経過時間は4m全体に含めます。残り3.7mを元の入力方向へ移動します。遮蔽物に当たれば実移動距離は短くなります。
- ワープ直前のセラの残像とスラスターは元位置に0.05秒間残します。方向とアニメーションの選択は従来どおり。
- 左右フリック蹴りの3m/10m/sと、後方サマーソルトの5mは変更しません。

## カメラ
- STEP開始0.07秒で水平追従を減衰し、方向固定に滑らかに移行します。終了後は **0.06秒保持 + 0.24秒で加速復帰 = 合計0.30秒**。実体のカメラYawを補間し、ステップ終了時に目標角へ瞬間移動しません。カメラの平行移動追従と画面端保護、ズームは維持します。
- 通常RUN/BOOSTでは、ターゲットの左右へ移動できるよう水平Yawに **±22°の余白** を設けます。その余白を越えた方向転換は旧来と同じ10/s感度で追従します。停止時は徐々に中央構図へ戻します。
- 格闘中は予備動作・追尾・通常3段（カタナ2段）・Bash・左右蹴り・後方蹴り・ループ追撃受付期間をひとつのカメラ状態として扱います。フォーカス追従15→27/s、Yaw追従10→20/sを **0.65秒** で増加し、終了後 **0.18秒** で通常に復帰します。コンボ区切りで追従状態を初期化しません。
- カメラの上下角、近距離ZOOM、衝突・表示エフェクト、ロック先、攻撃時間、ENは変更しません。

Android実機での画面内移動・近接連打中の手応えは、デバイス表示で最終確認が必要です。
