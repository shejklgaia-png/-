# SERA v113 — RUN中の頭部の過剰な回転揺れを抑制（2026-11-07）

## 症状と修正
- 走行時に頭が揺れすぎる問題を対象とします。元の前進RUNでは、Waistを除くTorso・Chest・Neck・Headの合成向きが4位相平均から最大約29.8°変動します。単純にHeadのキーフレームを弱めると、胴体の振りに対する頭の補償まで失われます。
- RUN専用の描画処理で、前後2つのモーションを現行の重みで合成し、0/0.25/0.5/0.75秒の4位相から頭部の平均向きを算出。現在の姿勢と平均姿勢の間をQuaternionで補間し、周期的な回転の振れ幅を**元の35%（65%抑制）**へ変更します。
- 上半身4関節に配分した既存の敵へのターゲット追従ヨー補正を平均側にも含めるため、RUN中の視線追従は維持します。腰の旋回追従と最大15°のバンクはそのままです。
- 頭部のローカル回転だけを補正します。頭の上下移動、腰のルート運動、胴体・腕・脚、全Blockbenchキーとモデルデータのバイト列、非RUNのモーションには変更を加えません。
