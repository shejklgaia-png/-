# SERA v281 — サマーソルトキックの弧状跳躍

**変更箇所**：`scripts/main.gd` の `Kick_b` 後方飛行制御。

- 従来の「後方へ一定速度の直線移動 + 独立したsin関数による上下移動」を、XZ座標と高度を**同じ3次ベジェ曲線**から求める方法に変更しました。
- 制御点：始点（0m, 0m）→（0m, 2m）→（4m, 2m）→終点（4m, 0m）。実際の最高高度は1.5mです。後方への方向は従来どおり敵から離れる方向です。
- 離地直後は上方向の変位を主体にし、頂点近くで後方移動速度が最大になり、着地直前には後方移動が減速します。これによりジャンプ軌跡の接線が開始・終了点でほぼ垂直になります。
- 移動は前後のベジェ曲線上の座標差分だけを衝突判定付きで適用します。フレームレート依存の加算誤差や壁抜けを増やさない設計です。
- 後方4m・最高高度1.5m・飛行0.8秒・着地0.2秒、全身360度回転、`Kick_b` 原本キーフレーム、最後の姿勢の描画完了待ち、蹴り当たり判定を維持します。

`v281_somersault_arc_self_check.py`（静的確認）と `v281_somersault_arc_runtime_check.gd`（Godot実行テスト）を追加しました。Android実機での見た目の確認は別途必要です。
