# SERA v137 — 固定回転とサイバー青グリッド（2026-11-08）

CUSTOMIZEの拡大表示で、セラだけが初期表示位置を中心に回転するよう変更しました。初期の拡大率・位置を固定し、回転中に倍率や中心が変化しません。

背面の放射グラデーションとグリッドは、プレビュー開始時に胸・胴・腰ボーンを基準に位置を決め、回転しても**追従しません**。背景は黒ではなく暗いサイバー青です。青系のグリッド線は背景の放射状不透明度に従って外縁へ溶け込み、線の端をアンチエイリアスで処理しています。

1マスの大きさはプレビュー開始時のHead_Meshの投影幅の約半分とします。幅の取得に失敗したときは1280px画面で約38px相当の設定を使用します。

回転ジェスチャーは、拡大中の画面内で**左のメニューパネルと右下の戻るボタン以外**なら上下左右のどこからでも開始できます。ドラッグ途中で除外領域に入った際は回転を一時停止し、出たときに差分が跳ねないよう追跡座標を更新します。

既存の5設備、NEXUS_pose、カメラの0.18秒遷移、訓練画面、Blockbench素材・戦闘処理は維持。固定回転の結果、剣が横に伸びる角度で画面外へ一時的にはみ出ることがあります。

静的検査は `tools/v137_customize_fixed_grid_self_check.py`。GodotエディターとXperia実機での描画・入力確認は未実施です。
