# SERA v240 — ターゲットの側面腕フレームと四脚を大型化

## デザイン
- 2.0×2.0×3.4mの前後に長い本体は変更せず、左右の側面に取り付けた**腕のようなアウトリガーと四脚を大型化**しました。
- 上部：大きな肩装甲・太い接続腕・側面外装を追加／拡大。
- 下部：上脚支柱、膝関節、下脚支柱、ピストン、前腕ガード、突出アーム先端、幅広の足先を拡大。
- 全パーツは立方体・直方体の**不透明BoxMesh**。左右Xおよび前後Zを鏡映し、左右差や前後向きの違和感を抑制。

## 寸法とロック
- 側面部位（4本）：外接判定 **幅2.24m × 高2.00m × 前後1.36m**（旧1.38×2.00×1.02m）。
- 足底は従来どおり標準高さで地面Y=0に位置。先行指示の**本体と同じ高さ2m**を維持。
- ロック点は外部腕・装甲側へ移動。前脚Z+0.52m／後脚Z-0.52mに配置し、前後どちらからでも腕先端を照準できます。
- カメラの対象横半幅を旧1.85mから**2.35m**に拡大して外装を画面内に収めます。

## 維持
- 低い頭部、前後に長い本体、本体物理判定、部位破壊・耐久値・怯み／ダウン・頭部破壊の射撃制限、セラのモーションと操作は維持。
- **腕状フレームは四脚の内部モデル**です。独立した第6・第7破壊部位の追加ではありません。

## 検査
- v238・v239の静的回帰検査を寸法変更に合わせ、新規v240のモデル構造・足裏・腕先端照準・AABB・カメラ幅検査をCIで実行。
- Godotエンジン／Xperia実機での3D描画・照準切替・斬撃の実動作は未検証です。
