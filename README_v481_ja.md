# SERA v481 — ビットタランのレーザー威力60％・なぎ払い判定を停止0.5秒前で終了

## レーザー
- ビットタランの背部レーザーだけ、従来の**60%の威力**へ変更します。従来の1ヒットあたり基準HPダメージ18→**10.8**、ガード／シールド消費23→**13.8**。実際のHP減少には既存のプレイヤー防御率を、ガード消費には装備補正を引き続き適用します。
- 通常のトレーニング弾、他のボス攻撃、なぎ払い、踏みつけ、弾きの威力は変更しません。
- 既存のレーザー照射2秒、0.20秒間隔での再ヒット・最大ヒット回数無制限、射線から1.5m超での加速、球体縮小開始時刻の減速、原本の音声・視覚FX・ノックバックはすべて維持します。

## なぎ払いの当たり判定
- **横薙ぎ動作の停止フレームの0.5秒前で、接触ダメージ判定を終了します。**
- 原本Blockbenchの横薙ぎ停止／折り返しに対応する関節キーは、前脚が元のクリップ時刻**1.50秒**、後脚が**0.875秒**です。前脚の終了判定は**1.00秒**、後脚は**0.375秒**に変更します。前後左右の4本すべてに同一ルールを適用します。
- 判定開始（前脚0.75秒、後脚0.25秒）、足先・下肢メッシュの実接触条件、1攻撃1ヒット、攻撃の軌道や再生速度、モーション原本、エフェクトは変更しません。
- 終了時刻を超えた後は、まだ足がプレイヤーや地面に接していても追加ヒットしません。アニメーションはそのまま最後まで再生します。

## 検査
- `tools/bittaran_railgun_runtime_check.gd`：実戦のHPダメージとガード消費が従来の60%、通常弾は従来威力100%、レーザー多段ヒット・反動は変更なし。
- `tools/bittaran_keyframe_hit_sector_runtime_check.gd`：前脚・後脚の元のBlockbench停止キーが存在すること、そこから正確に0.5秒早い終了フレームと、実メッシュ接触中の命中抑止を検査します。
- Android実機での視覚的な当たり判定の印象やゲームバランスは別途確認が必要です。
