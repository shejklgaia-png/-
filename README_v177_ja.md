# SERA v177 — A中量 / B重量の性能テスト実装

## 対象
- 既存A・B装備を交換可能なまま、各部位の性能値を実戦に接続しました。
- **A＝中量標準型**（機敏・低消費）、**B＝重量型**（高耐久・高攻撃・低機動・EN消費大）。同じセットで揃える必要はなく、パーツ混合可。
- HEAD/TORSO/ARMS/LOWER BODY/BOOSTER/RIGHT WEAPON/LEFT WEAPONをCUSTOMIZEからA/B選択。**BOOSTERはモデル分離前のため性能のみ切替**（見た目は共通）。
- 旧セーブはBOOSTERの指定がなくてもAに補完。更新後も7枠を保存。

- HPは5部位合算（A一式800、B一式1040）、防御は5部位の**単純平均**（A16%、B29.4%）。
- BOOST最終速度＝ブースター基礎速度×脚補正（A一式6.09375m/s、B一式5.289m/s）。
- ガードへの遷移速度は左武器の基準時間を両腕倍率で補正。ガード小/中/大は現行ガードリアクションの再生速度で試験し、別モーションはまだありません。
- ノックバック距離・時間は脚から別々に補正。ステップの基本軌道を維持し、速度・再生時間を補正。
- B右武器はENを使う武器として試験。EN不足時は発動不可。EN不要武器ならEN0でもその場で格闘可能です。

## EN / SH / ブレイク / ダウン（試験値）
- EN最大100、自動回復24/秒。BOOST20EN/秒、STEP15EN/回、近接接近16EN/秒、B右武器は各段で4/4/8EN。Bブースターは移動消費×1.40。回復待機0.25秒。
- EN不足ではBOOST、STEP、自動接近、EN消費武器を使用できません。通常RUN、EN不要のその場攻撃、通常ガードは可能。0から16回復するまでBOOSTは再起動しません。
- SH最大100、自動回復16/秒、待機0.45秒。ガード被弾で23（弾）/35（範囲）を左武器・腕補正で軽減。SHが0になった被弾で即ガードブレイク（大怯み1.25秒）。
- ブレイク中に脚の必要ヒット回数（A3/B5）に達すると無敵ダウン1.45秒、4m後退。復帰時EN/SHを満タンに戻す。HPは回復しません。
- TRAININGでは被弾にHPダメージ（弾18/範囲26×防御率軽減）を仮導入。**HP0時のゲームオーバー処理は未実装**です。

## 訓練用の部位破壊・弱怯み試験
- 既存の赤い訓練キューブ全体を**1つのCORE部位**として仮扱い（耐久75）、本体HP100と独立して同時減算。
- CORE破壊時は敵の新規攻撃を1.0秒停止（大怯み試験）。全体弱怯み蓄積50で0.55秒停止。0.36秒以内の次ヒットで延長（A右武器＋0.18秒、B＋0.07秒、最大1.5秒）。
- HUDにSERA HP/DEF/EN/SH、CORE耐久、怯み蓄積とBREAK/STUN表示。
- **本物のボスの外周部位、部位防御、部位素材、チャージ突進、部位個別のアニメーションはまだ未実装**です。既存Aアニメを利用しBは攻撃数値だけを変えます。

## 端末での確認
CUSTOMIZEでA一式→TRAINING、移動/フリック/格闘/ガード/敵攻撃を確認。NEXUSへ戻りB一式に切り替えて同じ動作を比較してください。敵デバッグのFIRE/AUTOでSH枯渇、ガードブレイク、追加被弾によるダウンを確認できます。旧A/Bモデルや効果音、ステージ、カメラ、メニュー遷移のデータは変更していません。

GitHubの静的整合性を検査していますが、**Godot構文実行・Androidでの動作確認は未実施**です。これは暫定パラメータであり最終的なゲームバランスではありません。
