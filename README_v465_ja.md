# SERA v465 — 充填完了まで静止する低速追尾レールガン

## 発射前の挙動
- **充填未完了**（10秒周期の発射直後2秒＋保持0.4秒＋復帰0.8秒の後、3.2～9.6秒）は、砲台が**基本姿勢のYaw=0°・Pitch=0°**で静止します。敵の姿勢・ルートYawが変わってもローカル基本角度を維持します。
- 砲台左右の側面箱の3段階バーは従来通り充填時間を示し、3本すべて点灯する **9.6秒時点で充填完了**です。
- 充填完了と同時にプレイヤー追尾開始。青白い銃口球状光の縮小0.2秒と、続く0.2秒の暗転後にレーザーを発射します。発射開始は10秒周期、レーザー持続は2秒です。

## 回避可能な照準
- 水平旋回（Yaw）の最大速度 **24°/秒**、上下仰角（Pitch）の最大速度 **18°/秒**に制限します。旧仕様120°/秒・100°/秒から低減しています。
- 基準ブースト約6.09m/秒で8m周回する場合、プレイヤーの方向は約43.6°/秒で変化するため、**ブーストで横方向へ移動すれば追尾が追いつきません**。照射中も同じ追尾速度です。
- 従来通り、照射終了後0.4秒間は最後の射角を保持してから0.8秒かけて滑らかに基本姿勢へ戻し、以降は次の充填完了まで静止します。
- 胴体のPitch・Roll非継承、独立Yaw/Pitch、既存のモデル原本・脚モーション・攻撃処理・カメラの全身フレーミングを維持します。

## 検証
- `tools/bittaran_railgun_runtime_check.gd` が未充填時の基本角度固定、充填完了後の追尾開始、8m・ブースト速度での追尾遅れ、Yaw/Pitchの速度上限、10秒発射周期と既存の視覚演出を検査します。
- `tools/bittaran_full_frame_level_gun_runtime_check.gd` も充填完了からの追尾へ合わせ、傾いたBodyに対する水平維持を再検証します。
