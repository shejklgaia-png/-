# SERA v333 — ロック対象基準のフリックと常駐コンボガイド

- フリック判定と4つの色区画の前方を、セラの位置から**現在ロックしている部位の照準点**へ向かうXZ直線に統一しました。カメラへ投影した方向が前（赤・Bash）、右／左（黄・Kick_r/Kick_l）、後方（青灰・Kick_b）です。セラの頭・腰モーション回転には左右されません。BODYロックなら敵本体中心、部位ロックならその部位の既存照準点を使います。
- タッチ開始時にロック方向を確定し、フリックの途中では保持します。指を離しているコンボ中は実際のロック方向にガイドが滑らかに追従し、ロックUI/カメラ/物理移動は変更しません。
- **コンボ中はコントローラーを常時表示**：攻撃クリップ、バッシュ／左右蹴り／サマーソルト、着地中の連携、0.65秒リンク受付中も直前の操作位置に残します。新しい指が触れた時と攻撃タップ成立時は短く明るくなります。通常移動のタッチ終了後は従来通り消えます。
- **アイコンは実際の受付状態に連動**：次の通常攻撃タップやバッシュ後の連撃を受け付ける時は中心に小さな剣、最終段中・直後にフリック派生を受け付ける時は、前に拳/衝突・左右にブーツ・後ろにバク転矢印を表示します。使用できない時のアイコンは消し、ガイドの色だけ控えめに残します。モデル/モーション/既存攻撃時間・消費EN・STEP方向には手を加えません。
- Android実機の表示サイズ・輝度・コンボ入力感は最終確認が必要です。
