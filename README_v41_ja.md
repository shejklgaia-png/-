# セラ v41 — ロックオン円の2回転・収縮・拡大アニメーション

v40を基準にした表示変更です。攻撃・移動・モデル・剣エフェクト等は変更していません。

## 近接可能距離に入ったとき

- ターゲット表面から0.75m以内で、外周の**4本の弧だけ**が時計回りに720°（2回転）します。
- 同じ0.30秒の間に半径が **62px → 42px** に縮み、終了後は小さい円で停止します。
- 近接可能と判定した瞬間に赤（外周線幅5.0px）に切り替わります。回転中も5.0px固定です。

## 近接距離から離れたとき

- 距離が0.75mを超えると、外周4本の弧が反時計回りに720°（2回転）します。
- 同じ0.30秒の間に半径が **42px → 62px** に広がり、終了後は通常円に戻ります。
- 近接不可と判定した瞬間にシアン（外周線幅2.0px）に切り替わります。回転中も2.0px固定です。

## 共通事項

- 円の中心は画面中央に固定。中央の十字は回転・移動・拡大縮小しません（色は距離状態に合わせて切り替え）。
- 近接距離の判定は`main.gd`の既存の`_distance_to_cube_surface`と`MELEE_SURFACE_REACH=0.75`をそのまま使用します。
- 0.30秒の途中で距離が切り替わった場合、**現在の角度と半径を引き継ぎ**、逆方向に新たな2回転を始めます。位置が突然飛びません。
- 0.30秒間だけ毎フレームUIを更新し、終了時に更新を停止します。
- 敵HP0時の攻撃、HP回復、剣エフェクト、キャラクター、カメラ、陰影、床はv40から変更していません。

## 調整値

`scripts/touch_overlay.gd`冒頭の定数で調整できます。

- `LOCK_SPIN_DURATION = 0.30` 回転時間（秒）
- `LOCK_SPIN_TURNS = 2.0` 回転数
- `LOCK_RADIUS_NORMAL = 62.0` 通常半径
- `LOCK_RADIUS_MELEE = 42.0` 近接時半径
- `LOCK_RING_WIDTH_NORMAL = 2.0` 通常線幅
- `LOCK_RING_WIDTH_MELEE = 5.0` 近接時線幅
