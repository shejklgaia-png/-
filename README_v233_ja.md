# SERA v233 — カメラ最接近位置の調整

## 変更
最接近時のカメラ半径を **7.8mから8.8m** に引きました（約13%後方）。

このため、ターゲットに近づいたときの機体や周囲の見える範囲が少し広がります。

## 変更しない項目
- 遠距離での標準カメラ半径16.0m
- ターゲットとの距離に応じた滑らかなズーム補間
- 通常移動/BOOST/STEPのカメラ追従速度・旋回挙動
- v232の左右画面端BOOST時の安全フレーミング
- 移動速度、攻撃、装備、モーション、スラスター

必要な場合は既存のフレーム保護処理により8.8mより後方へカメラが引かれます。

## 検証
GitHub Actionsでカメラ半径・ズーム補間・既存の保護処理の静的回帰検査を行います。Android端末上の構図確認は未実施です。
