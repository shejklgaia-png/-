# SERA v162 — BOOSTモーション0.50秒保持＋RUNへ0.20秒クロスフェード

ブースト判定を解除しても、セラのBOOSTモーションを**0.50秒間そのまま維持**し、その後**0.20秒かけてRUNモーションへ滑らかに移行**します。0.50＋0.20＝**合計0.70秒**でRUN姿勢への復帰が完了します（BOOSTを再開しない場合）。

| 動作 | v161 | v162 |
|---|---:|---:|
| BOOST解除後の姿勢保持 | 0.30秒 | **0.50秒** |
| BOOST→RUNの補間 | 0.08秒 | **0.20秒** |
| BOOSTへ入る補間 | 0.08秒 | 変更なし |
| BOOST→WAIT（停止）の補間 | 0.08秒 | 変更なし |
| 実移動速度の減速 | 0.15秒 | 変更なし |

- 0.50秒以内に再びBOOSTへ入る場合、RUN姿勢を挟まずBOOSTモーションを継続します。
- 0.20秒のRUN補間が始まってからBOOSTを再開した場合は、その時点の姿勢からBOOSTへ切り替えます。
- 指離し、ガード・攻撃・回避・被弾・ジャンプ・着地では保持を解除し、通常の動作を優先します。
- 停止状態のまま保持が切れた場合は従来どおりWAITへ戻り、RUNへの0.20秒補間は適用されません。

BOOST開始184.8px／解除159.6px、RUN円112px、360°入力、速度と外周装飾は変更していません。

静的コード検査・独立の時間遷移計算済み。GodotエンジンおよびAndroid実機での動作は未検証です。
