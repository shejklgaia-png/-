# SERA v235 — 前方ステップの移動距離を1.5倍

## 変更内容
- **前方STEP**：2.0m → **3.0m（1.5倍）**。上フリックで発動する`Frontstep`の移動量を変更。
- **斜め前方STEP**：前方の移動成分だけ3.0mを基準にするため、方向に応じて移動量が連続的に変化します。ステップ全体の予定距離上限4.0mは従来どおりです。
- **左右STEP・後方STEP**：変更なし。後方は4.0m、左右は従来の公転軌道です。
- **移動速度**：従来の8〜10m/sを維持。前方に3.0m動く場合の時間は0.300〜0.375秒です。
- **アニメーション・衝突・カメラ・EN**：変更なし。ターゲットや壁に当たると移動距離は3.0mより短くなります。
