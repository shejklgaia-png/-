# SERA v208 — 背面スラスターの可動角度

背面左右スラスターのエフェクト方向を、Blockbenchで制作されたノズルのローカル後方（+Z）を基準として次のように制限します。

| 方向 | 旧v207 | v208 |
|---|---:|---:|
| 左 | 38° | **80°** |
| 右 | 38° | **80°** |
| 下 | 24° | **90°** |
| 上 | 24° | **1°** |

- Godotでローカル+Z方向を噴射する場合、X正回転は下を向きます。上方向を-1°、下方向を+90°として非対称にクランプします。
- ノズルのPivot・位置・モデルや元のブースト／STEP／攻撃追尾の表示条件は変更しません。
- v207の逆移動時の不自然な左右振れの回避を継続。左右80°まで到達できるよう、後方投影の微小オフセットを0.25から0.02へ調節します。
- 回転追従の時定数0.075秒は維持。実機画面での回転方向・可動範囲の目視確認は未実施です。

検証: `tools/v208_thruster_angle_limits_self_check.py` と既存v206/v207を含む静的チェック。
