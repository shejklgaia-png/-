# SERA v525 — シールドの無隙間八角形とガラス破片の表現更新

## 修正内容
- 予測シールドの六層八角形の間の空白を解消し、内外の境界を正確に接続しました。中心も塗りつぶしたままです。
- 通常の防御八角形、破壊時の亀裂、ガラス片の描画サイズ・飛散距離を従来の30%に縮小しました（70%小型化）。
- 破壊時の14枚のガラス片を単色のシアンブルーに統一。位置・角度・速度・大きさ・形状を出現時に個別の乱数で確定し、外側へ減速しながら消えるようにしました。
- SP100・軽減率・回復・各部位の当たり判定、短い破壊音、3D深度とヒット火花の前後関係は変えていません。
- 六層×八角形、横1.15倍、展開・保持・消失が0.20秒ずつという時間配分は維持しました。

## 検査
- 本体変更前に旧v510/v516テスト期待値を更新し、新規v525静的・Godot実描画テストを登録しました。
- 新規チェックは隙間のない境界一致、サイズ30%、破片の単色頂点色・減速・消失を確認します。
- CI通過とは別に、Android実機での発色・見た目・表示遅延をご確認ください。
