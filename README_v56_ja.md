# セラ v56 — 少し俯瞰にしたカメラ

## 変更内容

- 俯瞰角度（水平面からのカメラの見下ろし角）を約7.55°から約11.86°へ、約4.31°増やしました。
- `CAMERA_ELEVATION_RATIO` を `0.1325` → `0.21` に変更し、カメラの高度を上げて同じ注視点を見ます。
- カメラの注視点 `CAMERA_FOCUS_DROP=1.35m`、接近時最小距離 `7.8m`、遠距離基準 `16m` は変更していません。
- v55のコンパクトな上部HUD、画面下25％の操作領域、ターゲット追従マーカー、画面内への自動ズーム調整を維持しています。
- ゲームプレイ、ステップ（最低2.0m、最大4.0m、近距離6m/s・その他10m/s、最大0.4秒）、衝突判定、攻撃、ドラッグは変更していません。

## 検証

`python tools/v56_camera_pitch_self_check.py` で設定値・v55からの差分・数値投影による可視範囲をチェックできます。GodotエンジンおよびAndroid実機での描画・操作確認は未実施です。
