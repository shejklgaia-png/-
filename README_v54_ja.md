# セラ v54 — マーカーをターゲットの画面座標へ追従

## 変更内容

- 画面中央固定だったロックオンマーカー（4つの円弧と中央の十字線）を、`Camera3D.unproject_position(target.global_position)` に基づくスクリーン座標に移動。
- 毎フレーム、カメラ追従・ズーム・フレーム補正が終わった後に再投影。ターゲットが上下に揺れる／将来 X・Z 方向に動く場合も、中心のワールド座標に追従。
- ターゲットがカメラ背後または画面外にあるときは誤表示を避けるためマーカーだけを非表示。
- 近接時の赤色・太線化、4つの円弧の回転アニメーション、ドラッグガイドの描画・タッチ透過は維持。
- ヒットストップ中でもターゲットの3D位置が更新されていればマーカー位置は更新。

## 変更しない仕様

- v53の俯瞰角度、画面下25％の操作スペース、近接時のカメラ距離7.8m。
- 最低ステップ2.0m、最大4.0m、近接6m/s・通常10m/s、最大0.4秒。
- ドラッグ移動、攻撃、衝突判定、3Dモデル、エフェクト、既存アニメーション。
