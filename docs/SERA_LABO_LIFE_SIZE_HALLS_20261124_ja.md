# LABO・精製・倉庫 実寸施設

BASEの施設モデルは地図上のアイコンであり、専用画面には直接流用しない。共通の材質・生成単位メッシュのみ再利用し、各機械は独自寸法・構造で組み直す。クレートは等倍。床は約33×27m、LABO造形機約10×8m、炉は煙突頂部約10.7m、倉庫棚約9.4m。造形機は柱・走行ガントリー・昇降ヘッド・材料塔・排出コンベヤ・4種の造形品。炉は耐熱炉口・火炎・双煙突・側面投入・冷却ライン。分解は反転二軸刃・投入排出ライン。倉庫は左右4層棚・中央昇降機・貨物搬送。クレート操作で約10秒の作業サイクルを開始。UI・在庫・BASE・精製ロジックは変更しない。新アングルと配置保存キー INDUSTRIAL_V3。設備、端末、床、背景設備、棚、貨物、独立可動部の配置ルートを公開。可動演出は配置ルートの子で行うため保存座標を上書きしない。内部パネル・ボルトなどは設備の一部として同時移動。実機未検証。
