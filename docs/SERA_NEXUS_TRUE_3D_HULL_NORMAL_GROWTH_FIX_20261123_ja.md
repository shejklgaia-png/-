# NEXUS全身枠線：PR #814の欠落・黒い内部面を修正（2026-11-23）

## Android実機の観察
PR #814でステンシルなしの平滑化反転ハルを採用したが、正面・側面・背面の実機画像で頭部・腕・脚・武器の黒い外周がほぼ見えず、特に首〜胴体の内側には黒い面が現れた。通常描画の不透明装甲は存在する。

## 根本方針
前回はクリップ空間のXYだけを3px移動し、**Z座標と実際の3Dメッシュ形状を変えなかった**。この方法では膨張した奥行き面が生成されず、元装甲の深度テストでほぼ全域が隠れる可能性がある。

今回の描画は本来の**頂点法線方向への3D膨張**に戻す。GPU標準深度テスト、元メッシュの深度マスク、平滑化法線ベイク、NEXUS元装備の子としての追従は維持する。

## 変更内容
- `shaders/sera_nexus_depth_hull_blockbench.gdshader`: `POSITION` でのクリップXYずらしを**削除**し、`VERTEX += normalize(NORMAL) * local_growth` に変更。膨張した実メッシュの3D座標および深度がレンダラーで正しく計算される。
- `PROJECTION_MATRIX[1][1]` と `VIEWPORT_SIZE.y` から画面1px相当の視空間長を求める。透視投影はカメラ距離を掛け、平行投影は一定とする（`PROJECTION_MATRIX[3][3]`で判定）。モデルの親スケールは `MODELVIEW_MATRIX` で考慮。元の画面幅3pxを目標とし、3D厚みは距離と投影の違いに応じて変わる。
- 閉じたBlockbench装甲は既存どおり`cull_back`、`depth_draw_never`、GPU深度テストONの透明パス。元装甲の`CULL_FRONT`とは逆の面を描く。
- `shaders/sera_nexus_depth_hull_open.gdshader`: 従来の`cull_disabled`は全メッシュ表面に黒い面が重なる可能性があるため**`cull_back`に変更**。開放・両面メッシュにも同じ3D法線膨張を適用し、さらに視空間で元の不透明面より奥へ数ピクセル相当押し込む。これは両面起因の内部黒塗りを抑えるための専用例外処理。
- `scripts/sera_nexus_depth_hull_outline.gd`: 輪郭パイプライン識別子・補助ノード名・コメントを更新。平滑化ベイカーと装備交換の管理は変更しない。

## 維持する制約
- NEXUS全身プレビューの通常黒`#0B1118`・目標3px。診断1/9は青緑。
- 追加SubViewport、カメラ、ステンシル、画像マスク、CPU輪郭抽出を使用しない。
- 既存キャラクターの頂点・マテリアル・UV・法線を直接変更しない。輪郭は元メッシュに追従する別メッシュのみ。
- 戦闘・単体プレビュー・BASE施設・敵・クレートは変更しない。

## 留保
- これは設計上、**正確な全身2Dシルエットの保証ではない**。分割装備間の接合部、開放面、特殊な凹形状では線が欠けたり余計に出たりする可能性がある。
- 画面3pxは投影換算の目標であり、頂点法線の傾きや形状により実画素幅は異なる。
- 開放メッシュは視空間奥へずらすため、他の装甲で隠される線が増えることがある。
- **今回もAndroid実機での画面・FPSは未確認**。回転中の追従、頭部と長い武器の輪郭、首周辺の黒塗りを重点的に観察する。

ユーザー指定により、CIテスト項目の確認・修正・適用およびCI/動作テストは実施しない。
