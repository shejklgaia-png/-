# NEXUSの余白解消・部品整理（2026-11-23）

## 症状
ご提供の実機画像は、天井上が明るい空背景で大きく抜けており、前景床も暗い空白となっている。左右コンソールは画面端で大きく切れている一方、壁の反復梁・換気スリットや階段の細かい部品は密集する。原因は繰り返しメッシュの過剰投入だけでなく、上方向の閉じた背景とカメラ手前まで続く床の欠如、端末の大きな占有率にある。

## 修正
- 既存8モジュールから装飾・警告マーク・細かいスリット類を削減。構造輪郭と個別選択対象は保存。
- 暗いリアボールト背面壁を遠方に追加して上方向の空を遮り、屋根の近接コファーと冷色灯を間欠配置。
- 床の基礎色を黒から青灰に変更し、前景パネルを正面カメラより手前のZ=36.5mまで延長。長い近景には繰り返し照明を増やさず、間欠導線と排水溝のみ。
- 環境の背景色を暗いブルーグレーへ。ただしプレビュー背景色 `NEXUS_PREVIEW_BACKDROP_COLOR` は変更しない。
- SYSTEMとTRAINING端末の形状はそれぞれ独立したまま、配置を中央側・奥へ移動し、0.85/0.82倍へ縮小して画面外への切れを緩和。選択用シルエットにも同じ倍率を適用。
- NEXUSカメラの注視点を少し下げて、上空の空き領域を圧縮。環境描画・カメラのみ調整し、SERA展示用リグの姿勢・メニュー・プレビュー・出撃機能や既存輪郭シェーダーは不変。

## 運用制限
ユーザーのCIテスト禁止方針に従い、CI項目、テストファイルは確認・変更せず、Godot／Android／Python等のテストも起動していない。構図・表示重なり・性能は実機未確認。
