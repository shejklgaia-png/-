# BASE 床ライティング改善（2026-11-24）

## スクリーンショット基準
- 縦画面BASEの各施設は明るく発光しているが、広い金属床は一様な明るさに見える。
- 暗いチャコール系金属パネル、既存の6色・6 MultiMesh、床の目地・黄色の導線、NEXUSシャッターと精製機の強い照明は保護する。
- 施設やコード・小物の位置、俯瞰カメラ、HUD、操作、可視ID枠線は変更しない。

## 実装
- `sera_base_deck_lighting.gdshader`：既存の8段階シェーディング・テクスチャ・頂点色を床専用に維持し、WORLD座標に固定した3つの広域の明暗波を弱く重ねる。描画バッチ増加なし。ズーム・カメラ移動で模様が流れない。
- `sera_base_floor_lighting.gd`：NEXUSと7施設の位置・寸法と設備の正面方向から、柔らかい接地影8枚＋床への淡い色反射8枚を2つのMultiMeshで生成。床面直上Y=-0.019mに置き、設備・ケーブル・凸部の奥で描画する。
- `sera_base_floor_patch.gdshader`：楕円グラデーションのフェード。固定位置の透明面のみ。輪郭用ID収集から除外するメタデータを持つ。
- スポットライト、サーチライト、炉床の発光・煙は既存VFXを利用。新しい動的ライト、シャドウマップ、全画面ポスト処理、Viewport、毎フレームCPU更新を追加しない。

## 制約と確認状況
- ユーザーの指定によりCI項目の確認・変更、CI／Godot／Android／その他のテストを行っていない。
- 実機スクリーンショットでの明暗差、光の重ね合わせ、FPSは未確認。
