# NEXUS全身シルエット：消失復旧と同一Viewport 2D外周（2026-11-23）

## 事故状況

PR #811で導入した「全身メッシュの8方向投影＋共通ステンシル17のNOT-EQUAL判定」について、Android実機スクリーンショットで**通常NEXUS全身の黒い枠線が完全に消失**した。写真からは、8方向のMultiMeshが描画されていないのか、マスク・ステンシル比較・透明パス順が問題なのかを確定できない。Godot 4.7公式でもステンシルは実験的機能であり、透明パスでの制約が明記されている。

過去の実機では、エッジ抽出方式に戻しても頭部外周が欠落し手前の凸角が目立った。そこで**GPUシェーダーの面向き、ステンシル、クリップ座標移動のいずれにも依存しないバックエンド**へ切り替える。

## 新しい通常表示

- 追加コード：`scripts/sera_nexus_canvas_silhouette.gd`（Control）。
- 同一ViewportのNEXUS HUD CanvasLayer内に描画。**追加カメラ、SubViewport、GPU→CPU画素読み出し、ステンシル、GPU深度参照をすべて使用しない**。
- Godot公式 `Camera3D.unproject_position()` を使い、現在のNEXUSカメラで表示中の装備メッシュごとの **3D AABBの8頂点**を2Dスクリーン座標へ投影する。上下左右＋斜めの方向に実際のジオメトリをずらすのではなく、画面に映る**近似投影領域**を各パーツごとに作る。
- `Geometry2D.convex_hull()` でメッシュごとの投影輪郭を取得する。複数の投影領域が重なる場合、`Geometry2D.merge_polygons()` で領域結合し、**結合結果の境界だけ** `draw_polyline()` で黒3px描画する。ポリゴン内部を塗らない。
- ControlをHUDの最初の子へ配置し、**他のHUDメニューの背後、3Dレンダリングの前面**に描画する。カメラ・キャラクターと同じプロセスフレームの `_draw()` で最新座標を取得し、1フレーム前の画像を使わない。
- 装備の候補一覧を0.35秒ごとに更新し、装備交換・表示切替へ対応。FXや旧生成輪郭を除外する。
- グラフィック設定「キャラクター枠線」のON/OFFに従う。NEXUS全身カスタマイズ表示以外には適用しない。
- 診断0は黒3pxの2D投影外周、診断1・9は青緑色の2D外周。旧GPUエッジ／ステンシルの診断は従来通り残すが、PR #811の通常8方向シルエットのコントローラは**生成しない**。
- HUD診断欄は2D投影対象・結合外周数・ステンシル不使用を表示する。

## 品質・正確性の制約

- **3Dメッシュの正確な画素シルエットではない**。あえて各メッシュの境界箱を投影するため、斜めの装甲、曲面、武器先端、凹形状には誇張や角張りが生じる。ユーザーが「品質は問わない」と指定したことを踏まえ、描画の成立と同一フレーム追従を最優先した。
- 装甲の投影領域が離れている場合、複数の境界線になる。隙間がある場合は本来の全身形状より大きく見えることがある。重なった内部線はポリゴン結合によって抑制されるが、全身の実メッシュの厳密な和集合ではない。
- 2Dポリゴン結合はカメラが動くフレームごとにCPUで行う。GPU描画の増加は限定的だが、AndroidでのCPU負荷は未測定。FPSや回転中の体感追従は実機で確認するまで保証しない。
- 描画は元の3Dキャラクターと同じフレームで最新のカメラ座標を参照する構成だが、NEXUSのUIや入力更新順序による見かけのずれは実機確認が必要。
- もし結合ポリゴンの向きにより外周が全件除外される場合は、**表示ゼロを避けるフォールバック**として取得できたポリゴンの境界を表示する。

## 影響範囲

- 修正：`scripts/command_nexus.gd`（新Control接続・旧本番8方向無効化・表示切替と統計）、`scripts/sera_nexus_canvas_silhouette.gd`（新規）。
- NEXUSの全身だけに適用。単体パーツプレビュー、戦闘、BASE、敵、クレート、共通3D材質は一切変更しない。
- PR #811の8方向シェーダー／スクリプトはリポジトリに残すが、通常のNEXUSではノードを生成せず使用しない。19診断ボタンは残す。

## 実機確認していただきたいこと

1. 通常NEXUSカスタマイズ表示で**黒3px程度の外周が見えるか**。
2. 正面と側面、回転中で、黒い線が本体と同じフレームに追従しているか。
3. 装備交換した後に新装備の外周が描画されるか。
4. FPS・引っかかりが許容範囲か。特に装備交換時や高速回転時。

ユーザー指定により、**CIテスト項目の確認・修正・適用、およびCI／動作テストは実行しない**。

- Godot 4.7 `Camera3D.unproject_position`
- Godot 4.7 `Geometry2D.convex_hull`、`Geometry2D.merge_polygons`
- Godot 4.7 `CanvasItem.draw_polyline`
- Godot 4.7 `spatial_shader` ステンシルの実験的機能に関する注記
