# IRIS（H02）材質調整：セーブ／ロード（2026-11-22）

## 対象
- NEXUS → カスタマイズ → HEAD D「アイリス」単体プレビューをダブルタップして全画面化 → 「材質調整」。
- 保存データは端末共通。ゲーム本編の3つのセーブスロットとは独立し、既存のFPS・操作設定と同じ `user://sera_settings.cfg` にセクションを追加。
- **シェーダー適用先は従来どおり NEXUS内H02単体プレビュー限定**。戦闘・BASE・LABOや他の装備の描画を変更しない。
- モデル・オリジナルメッシュ・テクスチャ・可視メッシュID輪郭は変更しない。追加の3Dパスは無し。

## 操作
1. 材質を調整すると「最後の設定」へ即保存。次回起動時に自動復元。
2. 「セーブ／ロード」から5枠を表示。各行は名前（最大24文字）、保存、読込。
3. 「全材質をコピー」は互換フォーマット `SERA_IRIS_MATERIAL_SHADING_V1` のJSONをクリップボードへコピー。
4. 「貼付け復元」は同じ形式のJSONを検証して適用。「標準に戻す」は初期値を適用して最後の設定へ保存。5枠は上書きしない。
5. 全画面から戻ると編集パネルは閉じ、既存の端末Back／プレビュー操作を維持。

## 保存形式
- `[iris_material] last` にJSON文字列。
- `[iris_material_slot_1]` ～ `[iris_material_slot_5]` に `name` と `data` JSON文字列。
- フォーマットはモデル `H02/アイリス`、材質キー `armor` / `dark_mechanism` / `lens` / `emission`、各 `steps`、`threshold`、`lens_lit`。
- 入力の型・段階（OFFまたは2～8）・しきい値（0～1）・発光段階OFFを検証。無効なJSONは適用せず、現在の表示を維持する。
- 標準の装甲8段/0.65、暗色機構2段/0.70、レンズ3段/0.10、発光OFF/0.00、点灯OFF。従前の端末保存値や5枠プリセットは保持する。

## 検証チェック
- 新規起動（ファイル無し）、FPS設定との共存、5枠への保存、別枠へ保存、名前の変更、再起動後の自動復元。
- コピー→貼付け、範囲外・不正な書式の拒否、空スロット読み込み、標準設定への復帰。
- NEXUSアイリス以外への非適用、青白い材質選択フラッシュ、2～8段切替、全画面Back、タッチドラッグとの競合防止。
- 実機Godot/AndroidでのUIサイズ・仮想キーボード・再起動耐久試験は別途確認が必要。
