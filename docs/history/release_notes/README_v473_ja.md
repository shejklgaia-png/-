# SERA v473 — レールガンの全チャージ〜照射終了を連続低速追尾・命中しても停止しない仕様へ

## 原因
- v472までは**チャージ途中は照準を固定**し、球体表示で高速追尾を開始し、さらに青球体終了時とレーザー発射時に**現在のプレイヤー位置へ瞬間的に照準合わせ**していました。発射中の角速度だけ遅くしても、この二重の瞬間補正で回避が困難でした。
- ビーム被弾時の通常ダメージリアクションがSERAのBOOST/STEPを妨げていました。また、プレイヤーKO直後にはレーザー制御全体がリセットされ、照射途中で止まっていました。
- 砲台の角速度上限をボス本体に相対的にかけると、ボス本体が向きを変えた分が実質的な無料旋回になり、プレイヤーのBOOSTより早く狙い直す場合がありました。
- 角速度を固定の15.12°/秒にするだけでは遠距離ではBOOSTの見かけの角速度がそれ以下になることもありました。

## 追尾・照射仕様
- 10秒周期で**3.2秒からチャージ開始と同時に追尾**し、**7.5〜9.5秒の青い球体表示・9.5〜10.0秒の発射準備・10.0秒のレーザー開始から12.0秒の照射終了まで、追尾を一度も止めず**に続けます。
- チャージ開始直後の2秒間だけ滑らかに速度が立ち上がり、その後は同じ追尾方式を継続します。**球体の点灯、最後の1秒収縮、0.5秒の発射準備、レーザー開始で追尾速度が切り替わったり瞬間捕捉したりしません。**
- 水平Yawの基本最大角速度は**15.12°/秒**、上下Pitchは**11.34°/秒**。さらに、現在のプレイヤー装備のBOOST速度と実距離を利用し、**BOOSTで得られる見かけの角速度の35%以下**に制限します。つまり遠距離ほど砲台の追尾角速度も低下します。
- ボス本体が向きを変えた場合も、ワールド空間で保持した砲台角度を基準として**ボスの旋回分を含めて速度制限**します。追尾用の指数フィルタはチャージから照射まで6Hzで共通です。
- チャージ演出とレーザーの白芯・青い外縁、電撃・流動プラズマの描画、射程45m・半径・照射時間2秒・10秒周期は変更しません。

## 被弾しても止まらない
- **レーザーによるダメージはHP/シールドに反映しますが、通常の被弾ノックバック・モーション中断・移動停止は発生させません。** SERAは命中後もBOOST/STEP移動を継続できます（KOは既存の仕様どおり行動不能）。
- 他の弾・踏みつけ・弾き・なぎ払い・通常攻撃のダメージリアクションは変更しません。
- **レーザーそのものも命中時やSERAのKOでは停止せず、2秒照射が終わるまで表示・追尾を継続します。** ボスが倒れた場合の停止とバトルリセットは従来どおりです。
- 実際のBOOST入力確定0.10秒・速度立ち上がり0.20秒を考慮し、**レーザー発射後0.65秒からダメージ判定を有効化**します（v472では0.40秒）。開始から当たり判定を出すわけではありません。以後は射線上にいる場合だけ、従来の0.5秒間隔でダメージが入ります。

## 検査
- `tools/bittaran_railgun_runtime_check.gd`を更新し、チャージ・球体・発射前0.5秒・レーザーの全期間で追尾を保持し、瞬間捕捉や速度リセットが起きないことを実際のGodotで検証します。
- ボス本体70°回転後もワールド照準が角速度上限を超えないことを検査します。
- **8mおよび30m**で、RUNからBOOSTへ移行する実際の0.1秒入力確定・0.2秒加速を模擬した移動軌道において、レーザー終了まで被弾しないことを検証します。
- 実際にダメージが発生してもレーザーの表示が途切れず、プレイヤーのHPは減るがBOOST状態と行動状態が変化しないこと、プレイヤーKO中もレーザーが続くことを検証します。
- ビットタラン原本、14ボーン、18メッシュ、脚IK、頭追尾、カメラの既存実装・全件CI検査を維持します。Android実機のプレイフィールとエフェクトの視認性は別途確認が必要です。
