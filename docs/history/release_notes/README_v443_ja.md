# SERA v443 — 振り上げを削除して胴体復帰後に脚をゆっくり戻す／なぎ払い往路3秒

## 変更概要

**攻撃後の脚を踏みつけの振りかぶり姿勢まで持ち上げる処理を完全に削除**しました。代わりに、6種類すべての攻撃で以下の順序に固定します。

1. **攻撃終了**：原本の攻撃クリップが最後まで進む（弾き・踏みつけの1.50秒硬直は維持）。
2. **胴体を基本姿勢へ戻す**：なぎ払い1.40秒、弾き・踏みつけ0.62秒。攻撃脚の原本終了姿勢はこの間維持し、平面Y=0への接地IKと支持脚3本の接地IKは継続。
3. **脚をゆっくり基本姿勢へ戻す**：胴体が戻りきった後、攻撃脚の上肢・下肢・足先の3関節を**1.20秒**かけて、直前のIK補正済みの姿勢からWaitの基本姿勢へ直接smoothstep補間。途中で踏みつけの振りかぶりポーズは経由しません。床への引き寄せは解除し、必要時のめり込み防止のみ残します。

上記の補間は関節のローカル回転と正規の関節位置のみに作用し、メッシュを単体移動・切り離し・伸長させません。Blockbench原本ファイルも書き換えません。

## なぎ払い往路は開始から3.00秒

左右の「なぎ払い」に共通適用します。

| 攻撃開始からの経過時間 | 動作 | 原本アニメーション時刻 |
|---|---|---|
| 0.00〜1.00秒 | Wait→なぎ払い原本0秒の開始姿勢へ補間 | 0.00秒のまま |
| 1.00〜3.00秒 | **なぎ払い往路全体を均一な速度で再生** | 0.00〜0.50秒（0.25倍速で一定） |
| **3.00秒** | **往路終了・折り返し** | **0.50秒** |
| 3.00〜4.00秒 | 復路、通常速度 | 0.50〜1.50秒（1.00倍速） |
| 4.00〜5.40秒 | 胴体を基本姿勢へ復帰 | 原本終了姿勢→Wait |
| 5.40〜6.60秒 | 攻撃脚の3関節をゆっくり基本姿勢へ復帰 | 原本終了姿勢→Wait |

**往路の途中だけを減速する特殊スロー区間は復活させません。** 往路の0.50秒分の原本を全体にわたって均一に2.00秒へ伸ばし、折り返しまでの全体（開始姿勢補間1.00秒＋往路2.00秒）が3.00秒になるようにしています。

## 6種類の攻撃の総時間（攻撃開始から）

| 攻撃 | 原本再生・硬直終了 | 胴体復帰完了 | 脚の復帰完了 |
|---|---:|---:|---:|
| なぎ払い 左右 | 4.00秒 | 5.40秒 | **6.60秒** |
| 弾き 左右 | 2.82秒 | 3.44秒 | **4.64秒** |
| 踏みつけ 左右 | 3.57秒 | 4.19秒 | **5.39秒** |

## 実装と検査
- `scripts/bittaran_attacks.gd`：なぎ払いの再生時刻を「往路全体2.00秒→復路1.00秒」とする区分線形の時計へ変更。復帰は`recovery_stage = body / leg`の2段階のみ。
- `scripts/bittaran_rig.gd`：踏みつけの高振りかぶり姿勢の再生・参照関数を廃止。胴体復帰後、直前のIK補正済み姿勢から攻撃脚3関節を1.20秒で直接基本姿勢へ戻します。
- `scripts/bittaran_foot_ik.gd`：胴体復帰中は接地維持、脚の復帰中は強制接地なし、床めり込み防止あり。
- `tools/v436_bittaran_attack_timing_runtime_check.gd`：全6攻撃について、復帰順序の`body -> leg`、原本再生時刻、往路終了3.00秒、全時間、段階間の姿勢補間を検査するよう更新。
