# SERA v291 — カメラ基準のロック改善・両手武器の反対側装備制限・カタナ鞘の回転修正

## ロックができない問題：原因と仕様変更
v289の部位自動選択は「セラ→敵中心」の向きに加え、敵本体の箱と他の脚の箱による線分遮蔽を**候補の除外条件**としていました。大型敵では特に正面・横移動中のほとんどの部位が遮られ、すべての候補が除外されてロックIDが空になる場合がありました。距離自体には明示的な選択距離上限はありませんでしたが、前方の投影や遮蔽判定によってロックできなくなっていました。

v291では**カメラ画面の中央に映る位置に最も近い健全部位をAUTOロック**する方式に変更しました。
- 各部位のワールド照準位置を`Camera3D.unproject_position`でスクリーン座標に変換。画面中心からの正規化距離が最小の部位を優先します。
- **距離は微弱な同点処理のみ**（100mでも最大0.03点）。部位が本体や他の部位の後ろに投影されたことを理由に候補から除外しません。画面端の候補も必要に応じて選択でき、ロック不能へ陥りません。ただし、カメラ背後のものと破壊済み部位は新規選択から除外します。
- 現在選択している部位が最良候補と近ければ0.065のヒステリシスで選択を維持し、横走り中にロック先が頻繁に変わるのを抑えます。
- **連続攻撃中／派生受付中の破壊部位ロック保持**はv289どおり。コンボ終了時に初めて新しい健全部位を選び直します。
- **MANUAL**の左右切替も、敵の本体や別の脚による遮蔽除外を撤回。右端・左端からもう一度押すと反対端へ循環し、何も選べずボタンが無反応にならないようにします。
- 画面外へロック部位が移動してもマーカーを隠さず、42pxの内側へクランプした**橙色の画面端マーカー**を表示します。実際のロックID・命中位置は変えません。
- 移動・格闘の発動可能距離（従来の距離計算）やカメラ追従は変更していません。

## 右カタナ装備時のLEFT WEAPON
- `weapon_r=K`（KATANA）は**両手武器**として、`weapon_l`のメッシュ（既存盾など）を非表示にします。元の左装備セットの選択・保存値は保持するため、カタナを外すと元通り表示されます。
- NEXUSのLEFT WEAPON行は**グレーアウト**し、装備名 **KATANA** を表示。左右の切替操作はできません。
- 両手武器判定を`TWO_HANDED_WEAPON_LABELS`へ集約しました。将来、**左手側に両手武器**が登録された場合はまったく同じロジックでRIGHT WEAPONを無効化し、選択元・表示・保存を左右反転させます。

## 左前腕の鞘モデル表示
- Blockbench原本の`Katana_l3`直下の1メッシュに**Y軸+90°のメッシュローカル回転**が設定されています。
- 旧インポーターの`_add_entry`は`Bird_`メッシュしかelement.rotationを読み込んでおらず、この鞘の回転が無視されていました。`Katana_`階層のメッシュも**原本のローカル回転を適用**するよう修正しました。
- カタナ装備時に左手武器の既存モデルも非表示にするため、鞘と盾が重なることも防ぎます。元の階層・ピボット・テクスチャ・原本Blockbenchデータは変更しません。
- v290の鞘5メッシュ／抜き身2メッシュの透明度切替、2段コンボ・フリック派生は維持します。
