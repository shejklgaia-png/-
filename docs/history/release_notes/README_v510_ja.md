# SERA v510 — 敵の予測シールド：接触防御光・亀裂・破壊SE

## 仕様
- ボス体力バーの青色オーバーレイ案は**撤回**。HPの視認性を維持し、敵本体の防御成功箇所にのみ短時間の半透明エフェクトを発生。
- 命中した部位の衝突位置で、縁が透明な放射状の頂点グラデーションを表示（既存の火花と装甲の間の深度付きレイヤー）。
- 残存シールド100〜60%で青、59〜30%で黄、29%以下で赤。
- SPが0へ落ちる命中で、青白い稲妻の亀裂が中心から左右へ伸び、青白い光が放射状に拡散する。独立した電撃+破裂SEを再生（実行時にPCM生成、音源ファイル不要）。
- 最初の対象はトレーニングのテストターゲット、ビットタラン。両者の戦闘シーンで同じ共通コンポーネントを使用。

## 戦闘上の数値（初期検証値）
- シールド最大100SP、最大近接軽減25%、最大遠距離軽減95%。
- 近接シールド削り：8 + 基礎威力×0.16SP。遠距離削り：2 + 基礎威力×0.05SP。
- 軽減率は現在のSP比率に比例。ヒット時の**減衰前SP**でHPダメージを計算してから、SPを消費。
- 最後の命中から4秒で回復開始、20SP/秒で回復。シールドが尽きても本体ダメージは止まらない。敵の部位破壊ゲージは従来の計算を維持。
- 遠距離攻撃の共通計算を先行実装。左手ハンドガン等の武装そのものは未実装であり、今回新規の射撃入力や武器は追加しない。
- プレイヤー側のガードシールドSHとは独立。
