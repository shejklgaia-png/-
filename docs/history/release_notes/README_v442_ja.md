# SERA v442 — 攻撃終了→胴体復帰→脚の振り上げ→足の位置を戻す

## 復帰フロー（全6攻撃共通）
**原本攻撃の終了（弾き・踏みつけは従来の1.50秒硬直後）→ 胴体と支持脚を基本姿勢へ → 攻撃脚を振り上げる → 攻撃脚を基本位置へ戻す**、と順番を固定しました。

1. **胴体復帰**：`Body`を原本攻撃終了ポーズから`Wait`へsmoothstep補間。なぎ払いは1.40秒、弾き・踏みつけは0.62秒。**この間は攻撃脚3関節の原本終了姿勢を維持**し、床Y=0への攻撃脚接地IKは継続。支持脚3本の接地IKも継続。
2. **脚の振り上げ**：胴体の復帰完了後、攻撃脚の`FrontLeg`・`FrontLowerLeg`・`FrontFoot`を、同じ側のBlockbench原本`踏みつけ_L`または`踏みつけ_R`の**時刻1.00秒の振りかぶり姿勢**まで0.34秒で滑らかに補間。直前の床IK補正済み関節姿勢を保存して開始することで、接地状態からの瞬間的な姿勢飛びを減らします。胴体は`Wait`を維持。
3. **足の位置を戻す**：攻撃脚の3関節を0.46秒で`Wait`姿勢へ着地させます。胴体は`Wait`から動かしません。復帰後の歩行IK移行時に追加のジャンプ軌道は入れません。

単一メッシュの平行移動、関節ピボットの移動、骨の伸縮はありません。足先がY=0を突き抜ける場合のみ、v440の軽量な2ボーン接地IKで補正します。脚を持ち上げるフェーズでは床への引き寄せを行いません。

### 攻撃開始からのタイムライン

| 攻撃 | 攻撃クリップ＋従来の硬直終了 | 胴体の基本姿勢への復帰完了 | 振り上げ完了 | 足位置の復帰完了 |
|---|---:|---:|---:|---:|
| なぎ払い 左右 | 2.50秒 | 3.90秒 | 4.24秒 | **4.70秒** |
| 弾き 左右 | 2.82秒 | 3.44秒 | 3.78秒 | **4.24秒** |
| 踏みつけ 左右 | 3.57秒 | 4.19秒 | 4.53秒 | **4.99秒** |

なぎ払いは、**基本姿勢→攻撃開始姿勢1.00秒＋原本モーション1.50秒（1.00倍速、途中スローなし）**を維持します。攻撃中の原本キーフレームと3本の支持脚IKは変更しません。

## 変更したコード
- `scripts/bittaran_attacks.gd`：`source_body_return_seconds()`を追加。すべての攻撃に`recovery_stage = body / lift / plant`を定義し、各段階の実再生時間を直列に合算。
- `scripts/bittaran_rig.gd`：攻撃脚の原本終了姿勢を維持したまま先にBodyをWaitへ戻し、完了後にのみ踏みつけの高振りかぶり姿勢を挟むよう再配置。脚の振り上げ開始時は直前のIK補正済み関節姿勢から補間。
- `scripts/bittaran_foot_ik.gd`：Body復帰中の攻撃脚は床へ接地し続ける一方、脚の振り上げ・足戻し中は床への引き寄せを解除（めり込み防止は有効）。
- `tools/v436_bittaran_attack_timing_runtime_check.gd`：全6攻撃について、Body復帰完了前に脚が上がらないこと、踏みつけ原本の高振りかぶり姿勢を通ること、最後にWaitへ戻ることを検査。
