# セラ v30 — 立体レンズ状の斬撃（C案）

## 変更した内容
- **v29で確定した位置・角度・攻撃モーション・0.55m前方配置は完全に維持**。元の `Swordeffect` の **子ノード**として立体エフェクトを追加します。
- 既存の白い斬撃と細い補助弧を元に、**8フレーム分の凸レンズ状3Dメッシュ**を同じUV座標から事前生成しています。輪郭は厚み0、内部の高さは最大0.064m（局所座標）です。両側対称の凸形状を作り、`cull_front` で奥側の面を半透明描画します。
- 元の平面テクスチャは**透明度0.35**で残し、立体形状と別々に描画します。UV・フレーム番号・移動・回転・スケールはすべて共有します。
- 元の画像に描かれた四角い粒子は除去・整理しました。断続的な補助弧2本は元の主弧の形状を追って再構成し、補助弧にも専用の小さな凸形状を設けました。
- 白い粒子はUV上の軌跡点からランダム生成し、個別の速度・寿命・大きさで漂わせます。影響は**斬撃周囲だけ**であり、敵に命中したときの既存ヒットエフェクトは維持しています。
- 白／赤切替（PCキーボードの `C`）は引き続き使用できます。通常の起動時は白です。

## 操作
1. このフォルダの `project.godot` を Godot 4.7.2 Androidエディターで読み込んでください。
2. 起動して短くタップすると敵へ接近し、剣攻撃と連動して斬撃を描画します。
3. ドラッグ移動・ターゲット固定カメラ・当たり判定はv29と同じです。

## 調整する場合
`scripts/sword_trail.gd` に以下の設定があります。
- `flat_layer_opacity = 0.35` ：元の平面残光の濃さ。低いほど透明です。
- `volume_opacity = 0.75` ：裏側の立体レンズの濃さ。
- `particle_rate = 27` ：毎秒の粒子発生数。最大32個に制限。
- 立体の最大高さは `assets/slash_C_volume_geometry.json` に焼き込み済みです。再生成には同梱の生成仕様に従って変更してください。

## 位置・角度の整合性
- Blockbenchの原板：X/Z軸 ±8単位、`UNIT=0.065`、UVは0〜16。
- v30の3Dメッシュ：UV `(u,v)` を `(u-0.5, v-0.5) × 1.04m` としてX/Zへ戻しています。
- 元のUV4隅とのローカル座標誤差は数値計算上**0m**。新しいノードの相対TransformはIdentityで、モーションや前方0.55m移動を再適用しません。
- 厚みを持つ部分は視点に応じて**正常な立体視差**が生じます。完全に画面上の同じピクセルに重なることは物理的に保証できません。

## 検証状況
- `python tools/v30_validate.py` の静的チェック35項目が合格。元のリグ・攻撃・カメラ・ヒット処理などをSHA256で照合しています。
- GPUレンダラーによる透明面の順序、実際のアニメーション中の裏面カリング、フレーム落ち等は**Godot/Android実機で未検証**です。環境にGodotバイナリがなく、起動テストは実行していません。
- 収録した `assets/v30_clean_slash_2d_preview.gif` は**テクスチャの2Dプレビュー**であり、Godotでの立体描画を録画したものではありません。

## 主要な追加ファイル
- `scripts/sword_trail.gd` ：v30エフェクト一式
- `shaders/slash_C_volume.gdshader` ：裏面のみの立体レンズ
- `shaders/slash_C_particle.gdshader` ：個別の光る粒子
- `assets/slash_C_volume_geometry.json` ：8フレームの立体メッシュ形状（UV基準）
- `assets/slash_C_white_clean_4x2.png` ：粒子を整理した白色8コマ
- `assets/slash_C_red_clean_4x2.png` ：赤色8コマ
- `tools/v30_validate.py` / `tools/v30_static_report.json` ：静的検証

元のv29は別フォルダとして保存しておいてください。
