# SERA v409

## 概要
実機フィードバック「攻撃の誘導で胴体が回転しすぎて変なねじれになる／後脚より後ろへ前脚で攻撃してくる／後脚で狙う時に異様にねじれる」への対応です。攻撃時の誘導（胴体の回転追尾と、攻撃脚の肩の照準）を、「攻撃する脚の付け根の角をプレイヤーへ向け、その角度には違和感のない上限を設ける」方式に変えました。

## 何が起きていたか
- 胴体の回転追尾は全ての脚で共通の「胸を攻撃脚の斜め前方45°へ向ける」計算で、上限は±140°でした。後脚で背後のプレイヤーを狙うと要求されるヨーは約135°になり、踏みつけでは胴体ボーンが最大約127°ねじれていました（計測）。しかし後脚の付け根の角はもともと後方約146°を向いているので、その角をプレイヤーへ向けるなら約34°の回転で済みます。ユーザーの指摘どおり、斜め前方を向ける計算そのものが後脚のねじれの原因でした。
- 肩の照準の上限も弾き130°／なぎ払い100°と大きく、胴体の回転と重なって、前脚の足が後脚の付け根のライン（ボスローカル z ≈ −1.24）より後ろ（最小 −2.30）まで回り込んでいました。

## 修正
- 胴体ヨー（`scripts/bittaran_battle.gd`）: 目標角を「プレイヤー方向 − 攻撃脚の付け根の角」に変更。角は実測値で前脚 +34.4°/−33.8°、後脚 +145.8°/−146.0°。上限は ±140° → ±60°。回転速度（100°/秒）は不変です。
- 肩照準（`scripts/bittaran_rig.gd`）: 上限を弾き 130° → 85°、なぎ払い 100° → 75° に。ゲームが実際に選ぶ配置での必要量（実測: なぎ払いは前脚で最大約53°、弾きは後脚・背後で最大約71°）は上限内に収まります。

## 計測結果
- 胴体ヨーの最大値: 全脚・全技・全方位で 60° 以下（従来は踏みつけで最大125°）。
- 胴体ボーンのねじれ（ヨー成分）: 踏みつけ最大 127° → 62°。後脚の弾き（背後のプレイヤー）63° → 30°。後脚のなぎ払い（真横のプレイヤー）は照準が 87.7° → 34.4° に下がり、命中も改善しました（足とプレイヤーの最小距離 1.29m → 0.78m）。
- 前脚の弾きを背後へ強制発動した場合の足の回り込み: ローカル z −2.30 → −1.67。
- ゲームが選ぶ自然配置（前脚は前方、後脚は後方）では、全脚・全技とも従来どおりプレイヤーへ届きます。

## チェック
- 新規 `tools/v409_bittaran_guidance_limits_runtime_check.gd`: 上限（胴体60°／照準85°・75°）が全脚・全技・全方位で守られること、自然配置で付け根の角がプレイヤーを向くこと、前脚の回り込みが z ≥ −1.85 に収まること、自然配置で足がプレイヤーへ届くことを検査。v408 ツリーでは FAIL、本版で PASS。
- 既存チェックの変更（意図と理由は各ファイル冒頭と DEVELOPMENT.md に明記）: v392（胸の期待値を「45°固定」から角方式へ変更。HEAD と踏みつけの主張は不変）、v403（後脚の横オフセット配置を攻撃脚自身の側へ変更。主張・閾値は不変）。
- 関連チェック（v383/v385/v386/v389/v391/v396/v397/v399〜v408）はすべて PASS。ローカル全件スイートも PASS（PR の CI でも確認）。

## 既知の制限
- 体の反対側の脚で無理に狙う配置（通常の技選択では選ばれません）では、照準上限のため着弾方向がずれる場合があります（弾きで最大約23°）。脚や胴体を不自然に回してまで当てるより、外す方を選んだ結果です。

## 既知の未適用事項
