# SERA v540 — ビットタランのダウン土埃・縦揺れ・4種SE連携

## 2026年11月22日の更新

- **後足ダウン**の土埃を、作者の後足ダウンモーション原本時刻 **0.75秒**で1回だけ発生するよう変更しました。前脚ダウンの土埃は従来の原本時刻 **1.75秒**を維持します。
- 土埃発生の同じフレームで、前後どちらも**大きな縦方向のカメラ振動**と「巨大ロボットが倒れる」SEを再生します。縦方向の専用インパルスを減衰させ、既存の攻撃カメラ振動に加算する際の横揺れは増やしません。
- 「ロボットの足音1」を歩行中の実際の接地イベントに、「巨大ロボットが腕を動かす3」を攻撃モーション開始（構え段階を除く）に、「ロボットを強く殴る3」を脚部破壊によるダウンのけぞり開始に割り当てます。
- 4本ともユーザー提供音源をOgg Vorbisに変換して**ゲーム内埋込**としました。AndroidのGit同期直後にもGodotの非同期音源インポート完了を待たず読み込めます。
- 土埃・崩落SE・縦揺れは同じイベントから発火し、同じダウンでの再発火は防止します。既に倒れ始めた際の追加脚部破壊で、のけぞりSEが重複することも防止します。
- **前後どちらのダウンでも、原本1.75秒の姿勢に到達するまでダウン時間の計時を始めない**既存仕様を維持します。通常の2.5秒／全脚破壊6秒、脚部の踏み替え、起き上がり時間、既存戦闘バランスは変更しません。
- 事前に影響テストの期待値を更新し、4種の音源形式・音源読み込み・イベント回数・着地同期・前後のFXタイミング・ダウン計時・縦揺れを検査するテストをCIに登録しました。
