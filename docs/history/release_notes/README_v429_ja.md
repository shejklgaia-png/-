# SERA v429 — ビットタラン脚の持ち上げ復帰・なぎ払い下肢の水平化

## 攻撃終了後、脚を持ち上げて戻す
- 左右前脚のなぎ払い・踏みつけ・弾きの終了後、0.42秒の脚復帰中に足先を高さ0.65mの滑らかな弧で持ち上げ、基本姿勢の接地点へ戻します。
- 中央で足先の角度を変える際、左右それぞれの「踏みつけ_L/R」振りかぶり0.75秒の足首キーフレームとWaitの相対クォータニオンを参照します。手動の左右鏡像角度は設定しません。
- 足先の攻撃専用接地を解除してから持ち上げるため、地面に貼り付いたまま横滑りして戻る動作を防ぎます。脚の0.42秒復帰が終わった後に0.62秒で胴体を戻す順序は維持します。

## なぎ払いの下肢と足先の水平化
- v428の足先モデル長軸の水平化を維持します。
- 下肢も、実メッシュの最長軸を計測してなぎ払い中の長軸を水平化します。メッシュのみの後処理で、膝・足首Pivot、下肢ボーン、接地IKは変更しません。
- 補正した下肢メッシュのローカル回転は毎フレームのIK開始前と攻撃終了時に原本の回転へ戻します。次のモーションの累積ねじれを防ぎます。

## 検証
- 左右各3種類を2回ずつ（計12攻撃）、踏みつけ型の持ち上げ復帰、下肢・足先モデルの水平、攻撃終了後の原本回転復元とキャッシュクリアを実Godotで確認します。
- 従来のv425〜v428接地・胴体復帰・床回避テストも残します。Android実機での最終的な見た目は未確認です。
