# SERA v225 — スラスター描画順・深度テストの修正

## 発見された原因
斬撃の表示中、セラ本体には`sera_foreground.gdshader`による追加描画があり、`depth_test_disabled`＋透明物の描画優先度126が指定されていた。一方、スラスター噴射・帯状軌跡の優先度は初期値0だった。そのため、噴射がセラの前面にあっても後から本体の描画で覆われ、断続的に消えるように見えた。

## 対応
- 噴射の外側10角筒・内側10角筒、帯状軌跡の各`ShaderMaterial.render_priority`を127に設定。斬撃中の本体オーバーレイ（126）より後に描画する。
- 両スラスターシェーダーの深度テストは**有効のまま**で、装甲の奥や地面の裏から透けて見えるようにはしない。
- v224の格闘中可動域（左右±20°、下35°）を補間後の実際のサーボ姿勢にも適用する。
- v222の胴体干渉防止がv224の角度制限を上書きする場合、まずBlockbench元ノズル方向へ復帰する。特殊なモデルで元方向も危険な場合のみ従来の外向き投影を適用する。

## 維持するもの
Blockbench元モデル・1〜3段目モーション、通常BOOST/STEPの可動範囲、格闘追尾と連続噴射、加速フレア（15倍・0.05秒）、10角筒、0.34秒帯状軌跡、ガード/武器/カメラ/入力等。

## 検証
`tools/v225_thruster_draw_order_self_check.py` が描画優先順位・通常深度テストの維持・格闘ノズルの実際の角度制限と安全フォールバックを検査する。GitHub Actionsで回帰テスト。Godot/Androidの実機表示は未検証。
