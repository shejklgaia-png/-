# SERA v396 — ビットタランの四脚なぎ払い姿勢と接地補正

- 左前脚のBlockbench原本「なぎ払い」は6つの関節キーフレームを持ちます。他の3脚はこの元モーションの空間反転で再現します。従来は**各脚で異なる待機姿勢を基準に回転差分を反転**していたため、とくに右前脚・後脚の足首位置が持ち上がり、角度も変わる問題がありました。
- **なぎ払いに限り**、左前脚の肩・膝・足先のキーフレーム姿勢そのものを左右（X軸）・前後（Z軸）に反転し、4脚が同じ相対軌道と足先の向きを持つ方式へ変更しました。同時に、原本の胴体傾斜（ロール／ピッチ）も対象脚に合わせて反転します。
- 攻撃開始時の足先接地高は、反転後の胴体姿勢で計算します。打撃中に床との接触補正が必要でも、**なぎ払いの肩・膝・足先の回転キーはIKで再計算しません**。従来の足先末端位置だけの最小限の床補正を利用します。
- なぎ払いの往路・復路の速度、振りかぶり、攻撃距離、硬直なしの1.40秒復帰、プレイヤー追尾、既存のダウン・起き上がり・頭部20cm干渉回避は変更しません。ほかの踏みつけ・弾きの再ターゲット方法も変更しません。
- 新規の`tools/v396_bittaran_sweep_mirror_floor_runtime_check.gd`では**4脚×9時刻**の足首位置と足先角度の対称性、さらに4脚すべての実戦シーンで関節キー維持と床貫通防止を確認します。全CI・ビットタラン専用CIに登録しました。実際のGodotテスト成功とAndroid実機の見た目は別途検証が必要です。
