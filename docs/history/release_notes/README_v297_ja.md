# SERA v297 — 低い頭部のロック判定を上へ1m拡張

## 変更内容
- AUTOロックのカメラ→敵本体中心の有限線分判定はそのまま維持します。
- 頭部`head`のみ、既存の頭部外接箱の**上端からさらに1.0m**の範囲に、表示されないロック専用AABBを1つ追加します（幅・奥行きは既存の頭部外接箱と同一）。
- 頭部の実メッシュに当たらない高めの視線も、この追加AABBを通過すればHEADを選択します。上方に離れすぎて交差しないときは通常どおりBODYを選択します。
- 頭部の追加AABBを含め、同じカメラ→本体中心の線分で交差距離を比較します。脚は従来どおり可視メッシュへの交差だけを判定します。

## 不変更
- Blockbenchモデル、メッシュの位置・高さ・表示、歩行用物理衝突、通常攻撃/バッシュ/派生攻撃の追尾と命中AABB、ロックマーカー位置、セラとカメラの移動。
- AUTO切替の安定化、破壊部位除外、コンボ中のロック固定、MANUAL左右切替。HEADへのロック時も攻撃対象座標は元のままです。
- ロック用の追加計算は頭部に対するAABB線分交差1回のみで、物理オブジェクトやレイキャストは追加しません。

## 検証
- `tools/v297_head_lock_vertical_cap_self_check.py`、`tools/v297_head_lock_vertical_cap_runtime_check.gd` を追加。可視メッシュに当たらない高い視線、上端からの逸脱、回転、破壊、脚の不変、攻撃AABBと狙点の不変、AUTO再取得を検査します。
- 旧v296検査の「空洞は脚ロックしない」条件は頭部パッドと独立に確認します。
- Android Xperia 1 Vでの描画・操作確認は未実施です。
