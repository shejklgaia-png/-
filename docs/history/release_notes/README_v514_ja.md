# SERA v514 — LABO試作装備・素材アイコンと倉庫/カスタマイズ導線

- 基本素材12種類、試作装備7種類の**固有アイコン**を引き続き共通マットアトラスから表示し、変換時は投入/生成のランク・個数・所持数を並記。
- LABOの「Shell開発」から実際に試作装備の製作画面へ進めるよう変更。カタログでは各装備の所有個数を確認可能。
- 無料試作で発行した個体は倉庫へ保存し、NEXUSカスタマイズの該当スロットから選択可能。独自3Dメッシュがないため既存Aモデルを仮表示。
- 製作ID `H01-0001` 形式を厳格に検証し、表示名を「装備名＋完全なUID」に統一。連番はセーブごと・設計図ごとに単調増加し、同名衝突と重複登録を禁止。
- CIを本体変更前に拡充：全19アイコンの異なるアトラス領域、製作ID形式、異なる設計図の連番、保存再読込、選択と失敗時の保護。従来の素材変換/戦闘仕様は保持。
- 実機では縦画面の変換欄、所持件数、倉庫/カスタマイズ表示を確認してください。ヘッドレスCIは描画の肉眼確認を代替しません。
