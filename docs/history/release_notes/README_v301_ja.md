# SERA v301 — AUTOロック線分の始点をカメラからセラへ変更

## 変更
- AUTOロックの交差判定を**カメラ座標→敵本体中心**から**セラの物理ルート座標→敵本体中心**へ変更しました。毎フレームの実際の`player.global_position`を始点とします。
- BODY・HEAD・前後左右の脚は、従来と同じメッシュ（HEADのみ既存の不可視補助AABBを含む）と線分の交点を使い、**セラから最も近い交点**を同じ優先度で比較します。強制HEAD優先やBODY優先はなし。
- セラが動いて線分が変わればロック判定が変わりますが、**カメラが回転・移動するだけではAUTOの部位選択が変わりません**。
- 従来の0.22秒のロック切替確認（現在の部位が線分から外れた／破損した場合は即再取得）と攻撃中・コンボ受付中の部位固定は維持します。
- MANUALの画面左右切替とHUD表示位置には引き続きカメラ投影を使います。カメラ挙動・射撃・格闘・コンボ・移動・モデル・物理衝突・部位破壊計算は変更しません。
- 古いカメラ始点のメッシュ判定APIは履歴の形状回帰テスト用として互換維持しますが、**ゲームのAUTO取得処理からは呼び出しません**。

## 検証
- `v301`静的検査／Godot 4.7.2実行検査を追加。セラ正面・背面による切替、カメラだけの移動による不変性、BODYとの交点距離比較、0.22秒の切替、HEAD破壊と既存MANUAL/コンボの保持を対象にします。
- `v293〜v299`の履歴ジオメトリ・統合テストは、同じ線分の始点にセラを置いて検証するよう更新。
- Android実機のタッチ操作・表示は未検証。
