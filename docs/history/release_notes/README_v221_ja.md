# SERA v221 — 通常格闘中のスラスター噴射が見えなくなる症状の修正

## 動画で確認できた症状

ユーザーから提供されたSERA v220の実機動画では、3段目の振り抜き中に画面上で**STRIKE 3/3、EN 100%**と表示されているにもかかわらず、背面の青い噴射がほぼ見えないフレームがありました。

v220で通常格闘の準備・追尾・振り抜きの全状態を噴射対象に追加しましたが、それだけでは**実際の画面上で連続して見える**ことまで保証できませんでした。

## 今回の修正

- 通常攻撃の追尾が止まっている間は、微小な衝突補正・ヒットストップによる移動量から噴射方向を推定しません。代わりにセラの**安定した背面方向**へノズルを向けます。
- 通常格闘中に限り、既存の10角形の**通常スラスターの長さを最大1.65倍**へ拡張し、腕や装甲の陰から噴射が見えやすいようにします。
- 通常格闘中は通常噴射の透明度に対する強度を最大1.65倍、発光を最大1.3倍に補助します。0.06秒の滑らかな追従で急な形状切替を防ぎます。
- 通常格闘以外や噴射OFFのときは元の長さ・明るさへ戻ります。

## 変更しないもの

**15倍に拡散する加速バースト（0.05秒拡散・0.18秒復帰）**は別の制御です。移動を伴うステップ・追尾開始時だけ発動し、通常格闘のその場での振り抜きでは再発動しません。

攻撃モーション・追尾・当たり判定・EN消費・ブースト・ステップ・バッシュの噴射条件、金属ノズルとBlockbenchモデル、左右のノズル可動域、重量脚部SLIDEは変更していません。通常格闘が終了・キャンセル・被弾で停止した場合は、通常噴射も停止します。

## 検証

`tools/v221_melee_jet_visibility_self_check.py`で通常攻撃全状態、安定方向、経路、補助表示の時間応答、復帰処理、従来の15倍バーストとの分離を確認します。GitHub Actionsの静的・数値検査は実機の見た目を保証しないため、実際の噴射の連続性は引き続きAndroid上での確認が必要です。
