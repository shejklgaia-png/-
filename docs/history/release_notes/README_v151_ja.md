# SERA v151 — セラ本体の方向転換を滑らかに（2026-11-09）

v150では入力方向と実際の移動ベクトルを即時更新していましたが、**RUNの姿勢がベクトルの直線補間を使っていたため、180°転換で姿勢方向が急反転する**可能性がありました。また、RUN/後退切り替え判定が姿勢の向きより先行していました。

## 主な変更
- RUN・BOOSTのモーション方向を、角度ベースの最短回転で滑らかに変更。180°の方向転換でも表示ベクトルが消失しません。
- ±180°近くでの方向入力の細かな揺れに対して回転方向を保持し、3°未満の姿勢の微振動を抑えます。**操作入力のデッドゾーンは追加しません。**
- RUN 0.055秒・BOOST 0.045秒の方向追従、前進/後退クリップ混合は0.085秒。腰の向きは前進/後退の混合率から連続補間し、後退へ切り替わる瞬間の180°スナップを防止します。
- コントローラ表示の方向追従0.052秒はそのまま。RUN/BOOSTモーションをその応答に近づけます。

## 変更しない動作
- 実際の移動方向は指のスワイプを受けて即座に更新し、RUN 4.0625m/s／BOOST 6.09375m/sで移動します。
- 140pxの進行方向ロングドラッグBOOST、約50°の方向転換による解除、タップ攻撃・長押しガード・フリック回避・NEXUSメニュー。
- モデルデータ・アニメーションの元キーフレーム、ターゲット向きへの視線追従、左右利き設定、RUN/BOOSTの四方向モーションは維持します。

静的・数値検証は`tools/v151_turn_smoothing_self_check.py`。GodotとXperia実機での動作確認は未実施です。
