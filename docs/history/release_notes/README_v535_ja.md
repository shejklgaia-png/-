# SERA v535 — ビットタラン10分戦闘バランス

## 2026年11月22日の更新
- 全身A装備・通常3段コンボによる部位破壊主体の攻略で、順調な攻撃成功ペースなら**約10分**の討伐を狙います。
- ビットタランHPを2550、前脚の耐久値を左右720、後脚を左右620、頭部を150に変更。
- 共通HPダメージは脚0.75倍、ダウン中の頭部2.50倍、胴体1.00倍。部位破壊量は別に管理します。
- 4本の脚を各1回破壊すると、起き上がった後も胴体を常時ロック・攻撃できます。壊れた脚を再破壊して追加ダウンは発生しません。
- A装備の総HPを320、B装備を416に変更（全部位HP配分を2倍）。防御率、EN・SH、攻撃力・重量・モーション速度は維持。
- ボス固有の踏みつけ30、弾き22、なぎ払い28、腹部砲5.04、レールガン8.1／接触。トレーニング敵は変更しません。
- **Godot 4.7.2の実シーン検証**で、平均8秒に1回のコンボ成功・4脚12コンボずつ・頭部合計5コンボ・胴体26コンボのシナリオは約**601.7秒**と算出しました。実機操作での平均討伐時間は未測定です。
- ダウンモーション、AI・当たり判定、原本Blockbench、カメラ・セーブ形式は変更しません。
