# SERA v296 — カメラと本体中心を結ぶ線分による部位ロック

## 通常時の自動ロック（AUTO）
- カメラのワールド座標から敵本体の中心（`target.global_position`）までの**有限線分**を使用します。無限の視線やカメラ方位10分割、画面中央に近い部位の推測ではありません。
- 頭・四脚の実際に表示される各 `BoxMesh` について、メッシュのローカル座標に線分を変換し、`AABB.intersects_segment` で交差判定を行います。部位全体を包む大きなAABB内の空洞は無視します。
- 交差した未破壊部位のうち、カメラから最初に交差するものを優先します。交差する部位がない場合は**BODY（本体）**をロックします。破壊済み部位は候補外です。
- 現在選択中の部位が線分から外れたら即座に切り替えます（BODYへの復帰も即時）。BODYから部位への取得も即時です。**複数の部位が同時に線分に交差し、現ロック部位も交差し続けている場合のみ**、従来の0.22秒切り替え確定を維持します。

## 変更しない仕様
- 格闘接近・各段・バッシュ・派生蹴り／追加入力受付中のロック固定、破壊直後のコンボ内ロック保持および攻撃追尾・当たり判定。
- MANUALの左右切り替えと任意部位への手動固定（AUTOの線分制限は手動指定には適用しません）。
- 本体中心を基準とするカメラ追従とセラ本体の正面向き、画面上のロックマーカー、敵HP、破壊・モーション・入力。
- v293の円周角度選択ヘルパーは履歴テスト互換のため残しますが、**AUTOからは呼びません**。

## 確認
- `tools/v296_camera_center_mesh_lock_self_check.py` および `tools/v296_camera_center_mesh_lock_runtime_check.gd` を追加。実メッシュへの線分交差、空洞・本体フォールバック、移動・回転・破壊およびロック取得を検査します。
- v292/v293の過去検査は旧仕様の期待部分だけ更新し、歴史的な円周ヘルパー自体の検査は維持しています。
