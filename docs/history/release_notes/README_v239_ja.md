# SERA v239 — 前後に長い本体、同じ高さの四脚、低位置頭部

## デザインと寸法
- **本体**：赤い直方体のサイズを **横2.0m × 縦2.0m × 前後3.4m** に変更。横方向には広げず、前後（ローカルZ）だけを1.7倍に伸ばします。
- **四脚**：左右側面の前後位置をZ=±1.27mへ変更。脚それぞれの縦の外接寸法を**本体と同じ2.0m**へ揃えました。接続基部、関節、支柱、ピストン、装甲、足先はいずれも不透明な**直方体または立方体のBoxMesh**で形成し、側面メカフレーム構造を維持します。標準のターゲット中心高さ1.53mでは足先はY=0mです。
- **頭**：前面外周へ付いたセンサーユニットは中心を高さ**約1.09m**へ下げました。高さ約0.68～1.50mの部位当たり判定と、約1.06mのロック点により、通常の近接攻撃が狙える位置へ移しました。頭部の実表示もロック・判定の高さと一致しています。
- ターゲットの上下ボブは現行のままなので、足先が地面からわずかに上下する動作は残ります。

## 判定・カメラ
- 本体の**表示／物理コライダー／剣ヒット判定／距離計算**を同じ2.0×2.0×3.4mに統一しました。長い胴体の手前側で立ち止まるように、移動ターゲットの侵入防止も同寸法へ変更しています。
- 画面内収まり判定には拡張された外側フレームも含めます。カメラ追従の基準位置は従来どおり胴体中心です。
- 頭と四脚のHP・防御率・破壊演出・自動ロックの選択方式は変更しません。ガード／移動／攻撃モーションも維持しています。
