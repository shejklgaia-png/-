# SERA v471 — レールガンの発射前・照射中追尾速度をともに0.7倍

## 変更内容
SERA v470の追尾速度を基準として、発射前と照射中の独立Yaw/Pitch角速度上限をそれぞれ**0.7倍**に変更します。

| フェーズ | v470 | v471（0.7倍） |
|---|---:|---:|
| 発射前の水平Yaw | 720°/秒 | **504°/秒** |
| 発射前の上下Pitch | 576°/秒 | **403.2°/秒** |
| 照射中の水平Yaw | 21.6°/秒 | **15.12°/秒** |
| 照射中の上下Pitch | 16.2°/秒 | **11.34°/秒** |

発射前の制御は従来どおり2秒間のsmoothstepイーズインと24Hz指数平滑化の速度上限です。青い球体が消えた後の0.5秒間は高速捕捉を継続し、発射開始フレームの現在位置への最終照準合わせは保持します。発射後は6Hz指数平滑化と新しい角速度上限でブーストを振り切れる仕様です。

## 維持する仕様
- 10秒発射周期、2秒間の青い球体、最後1秒の収縮、完全捕捉後の0.5秒発射待機、レーザー2秒、終了後0.4秒保持＋0.8秒で復帰。
- 球体外縁の青いフレネル明滅・12本の稲妻、流れるプラズマレーザーと18本の電撃、深度遮蔽、照射当たり判定・45m射程。
- ビットタラン原本18メッシュ・14ボーン、脚攻撃、IK、全身カメラと独立Yaw/Pitchの砲台機構。

## 検証
`tools/bittaran_railgun_runtime_check.gd`で4方向すべての新しい追尾速度上限（v470比70%）、ブーストの追尾振り切り、発射初弾の完全捕捉、既存演出・レールガンFXの回帰を検査します。Android実機での視覚・プレイフィール確認は別途必要です。
