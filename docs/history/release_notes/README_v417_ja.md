# SERA v417 — ビットタラン後足「弾き」の脚軸回転を修正

## 修正対象
- 左後脚・右後脚の「弾き」で、脚の太もも／脛が長軸を中心に回転してしまう問題です。
- v416で導入した後足の地面を這う軌道、後足の股関節ワールド位置を保持する処理、通常の後傾25°から同角度の前傾へ移る胴体姿勢、胴体高さ固定、原本の足先方向は維持します。

## 原因と変更
v416の床接地調整は、原本の軌道を適用した後に、足裏の高さ・脚の届く範囲・脛メッシュの床貫通を調整するため、同一フレームで同じ脚のIKを複数回呼びます。従来の`_align`は、**直前の補正済み関節回転**へさらに最短回転を掛けていました。屈曲方向の変化に加え、これが太もも／脛の**軸回転（ロール）**を引き継ぐ原因となります。

v417では、後足の弾きに限り、胴体の前傾補正および攻撃脚の照準を適用した直後、IK処理前の原本の肩・膝・足先位置、太ももと脛の世界回転を**そのフレーム固有の基準**として保存します。

IKの各解決では、元の骨軸から新しい骨軸へ向ける**最小のスイング回転**を原本の世界回転に適用して姿勢を作り直します。前回のIK結果に回転を加算しません。このため、接地を解き直しても原本の脚の軸向きが不用意にねじれません。骨の長さ、スケール、足先の世界回転は変更しません。

対象は後足（左・右）の弾きのみです。前足の既存の弾き・他の攻撃・歩行・転倒など、一般のIK処理は引き続き従来の方法を使用します。攻撃の終了・中断時には、一時的な原本基準と軸調整フラグも初期化します。

## 検証
- 新規`tools/v417_bittaran_rear_kick_axial_roll_runtime_check.gd`を全件CIに登録しました。左右後足×2方向×各4連続攻撃（合計16回）を実際のGodot戦闘シーンで動かします。
- 弾きの地面を這う区間（原本クリップ0.32〜0.62秒）において、各フレームの太もも・脛の実回転と、**原本世界回転を新しい骨軸方向へ最小スイングした理論回転**との差が0.35°以下であることを検査します。
- 同時に、後足の足先メッシュが床付近20cm以内を通るフレームが80%以上であることを確認します。
- v416の左右後足×各8回接地・右前脚×8回足先回転回帰、v415の原本姿勢保持、v414の胴体姿勢・高さ固定、および既存の全Godot回帰検査を継続します。
- Godot headlessの全件CIとビットタラン専用CIは成功しています。Android実機での見た目はまだ確認できていません。
