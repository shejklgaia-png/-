# SERA v157 — 固定式デジタルスティック

指が触れた地点に**8方向のデジタルパッド**を表示します。同じタッチの間、パッドの中心・矢印・中央のボタンは**指に追従しません**。指の位置で選択した方向の矢印だけが点灯します。

## 操作
- **移動：** 指を中心から34px以上動かすと8方向（上下左右・斜め4方向）へ一定のRUN速度で移動します。対角線も同じ速度です。
- **停止：** 指を中心の22px以内へ戻すと停止します。34pxと22pxの差で小さな指ブレによるON/OFFの連続切替を防ぎます。
- **方向変更：** 45°刻みの8方向から即時に選択します。方向境界に6°のヒステリシスを設けます。反対側へ移動するときも特別な高速反転は行わず、固定パッドの中心を跨いで切り替えます。
- **ブースト：** 開始時の中心から半径125%（210px）以上を0.10秒維持、110%未満で解除。既存の移動速度とBOOSTの加減速0.15秒は維持します。外周のBOOSTガイドも指に追従せず固定表示です。
- **攻撃・ガード・回避：** タップで攻撃、静止ホールドでガード、規定のリリースフリックで回避する操作は従来どおりです。

GodotエディターとAndroid実機での操作感・表示確認は未実施です。
