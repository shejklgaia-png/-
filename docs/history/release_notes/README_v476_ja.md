# SERA v476 — ビットタランのレーザー追撃を廃止（1照射につき1ヒット）

## レーザーの被弾仕様
- **1回のレーザー照射（2秒）につき、プレイヤーへのダメージは最大1回です。**
- 初回命中は従来どおり、実際のビームとプレイヤーの位置関係・幅・射程から判定します。**初回命中していない場合はブーストで回避可能**です。
- **最初に命中したときだけ**HPダメージ／通常の物理ノックバック（基準1.2m・0.24秒、装備倍率適用）／Damageknockリアクションが発生します。
- レーザーが引き続きプレイヤーの身体と重なっていても、ノックバックで射線外に移動したあと再びレーザーに接触しても、**同じ照射中の追撃・追加ダメージは一切ありません**。
- **ノックバックと操作不能は通常のDamageknock終了条件に戻します。** 直前のv475で追加した「照射終了までずっと被弾姿勢を維持する」機能も撤去しました。
- レーザーは命中の有無に関係なく**2秒間照射し続けます**。次の発射では命中記録をリセットし、また初回の実際の接触によって最大1回だけ命中します。
- ガード中も1回の照射につき1回だけシールドへの接触判定を適用します。シールドが残っていれば通常のガード処理を優先し、他の攻撃には影響しません。

## v474で確定した時間軸は維持
- 0〜10秒は充填中で追尾なし。10〜12秒に青い球体とともにプレイヤー追尾開始。12〜14秒は即レーザー照射＋継続追尾、14〜14.7秒で0.7秒の基本姿勢復帰。
- 追尾の入り0.7秒、RUNでは振り切れずBOOSTなら回避できる追尾速度、球体の青縁／電撃／レーザーの流動プラズマ、原本モデル／14ボーン／IKとカメラは不変。
- **発射前の待機や発射後の無判定時間はありません。** 最初にレーザーが接触した瞬間から1回命中できます。

## 実装・テスト
- `scripts/bittaran_railgun.gd`で従来の連続ダメージタイマー・照射中ラッチを削除し、`beam_hit_registered`の1ショット1回フラグのみを保持。照射終了・リセット・次のチャージで消去します。
- `scripts/bittaran_battle.gd`で照射全体にわたる被弾姿勢の強制保持と追撃を削除。初回命中では通常のガード／HP／物理ノックバック処理を維持します。
- `scripts/main.gd`のレーザー専用被弾保持フラグを撤去。通常のノックバック回復条件・別の攻撃の仕様を復元します。
- `tools/bittaran_railgun_runtime_check.gd`で1ショットの初回命中・遠方退避後の追加被弾なし・再接触しても追加被弾なし・次のショットで初回接触を再許可・通常ノックバック／ガード・BOOST回避をGodot上で確認します。
- Android実機でのノックバックの見え方は別途確認します。
