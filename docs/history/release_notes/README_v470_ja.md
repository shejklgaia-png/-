# SERA v470 — 電撃をまとう青縁のチャージ球体と流動プラズマレーザー

## 銃口の球体チャージ（2秒）
- 既存の青白い球体の外側に、**フレネル効果で輪郭だけが濃い青になる透過球**を重ねます。外縁は時間・UV変動で断続的に明滅し、球体中央は白〜青白のままです。
- 球の表面に**枝分かれする稲妻（12本の不規則な電撃）**を発生させます。時間ごとに軌道が変わり、途切れたり走ったりする様子を再現します。
- 既存の膨張0.2秒、表示2秒、最後の収縮1秒と、同時に始まる2秒間の追尾イーズインを維持します。青縁と電撃も球の拡縮に同期し、砲口からずれません。

## レーザー照射中（2秒）
- 従来の白い芯＋青い外周ビームを維持しつつ、追加の**流動プラズマ層**を配置しました。UVスクロール風の縞と不規則な発光、細かな幅の脈動により、静止した直線ではなく連続的なエネルギー照射を表現します。
- ビームの周囲に**18本の短い枝分かれ電撃**が走り、周期的に位置・方向が変化します。ボスの照準が旋回しても砲口座標に追従します。
- スマートフォンでも負荷を抑えるため、電撃形状の更新は**約20Hz**。ゲームの乱数と分離した決定的な計算と1メッシュ単位の動的更新を使います。モデル・攻撃判定・レーザー45m射程に変更はありません。
- 球体とビームはともに**深度テストON**、描画順は既存の共通定数`DEPTH_TESTED_EMISSIVE`を使用し、装甲・床・セラを不適切に透過しません。

## 照準速度
| 状態 | 変更前 | 変更後 |
|---|---|---|
| 発射前・完全捕捉待機の水平Yaw | 900°/秒 | **720°/秒（0.8倍）** |
| 発射前・完全捕捉待機の上下Pitch | 720°/秒 | **576°/秒（0.8倍）** |
| 照射中の水平Yaw | 24°/秒 | **21.6°/秒（0.9倍）** |
| 照射中の上下Pitch | 18°/秒 | **16.2°/秒（0.9倍）** |

※ 追尾の2秒間立ち上がり曲線と発射時点の完全捕捉は保持。発射後のブースト回避も従来どおり可能です。

## 保持される戦闘挙動
- 10秒発射周期、2秒レーザー、2秒球体、最後の1秒間収縮、**完全捕捉後0.5秒待機**、終了後0.4秒保持＋0.8秒復帰。
- 正本ビットタランの18メッシュ・14ボーン構造、脚攻撃、頭追尾、胴体の傾斜を継承しない2軸砲台、全身を写すカメラ、HP/ガード・ヒット判定。

## 実装・検証
- `scripts/bittaran_railgun_fx.gd`（追加エフェクトの制御）、`shaders/bittaran_railgun_rim.gdshader`（青縁・明滅）、`shaders/bittaran_railgun_flow.gdshader`（レーザーの流動）を新設しました。
- `tools/bittaran_railgun_runtime_check.gd`で新規ノード／Shader／電撃ジオメトリ／表示切り替えとリセット／追尾速度を確認します。実機の光り方・視認性はAndroidで別途確認が必要です。
