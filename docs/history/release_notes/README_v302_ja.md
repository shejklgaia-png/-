# SERA v302 — 四脚のロック狙点を中央へ・命中エフェクトを部位別に分離

## 四脚のロック位置
- 左前・右前・左後・右後の4脚について、従来の外側・爪先寄りにずらしていた`aim`を、**各脚全体の2m高メカフレーム中央（pivot）**へ変更しました。
- ロックマーカー、手動部位切替の狙点、格闘追尾、左右蹴りのロック部位回転中心は、共通の`get_part_aim_world`/`get_part_local_aim`を通じて新しい位置を使用します。
- **AUTOの交差線分（セラ→敵本体中心）、実メッシュのロック優先度、衝突形状、攻撃当たり判定、頭部狙点、部位HPは変更しません。**

## 命中時の部位エフェクト
- v301では各部位の専用マテリアルの点滅に加えて、**すべての命中でBODYの`hit_flash_remaining`も再起動**していました。また、BODYを揺らす`target_mesh`は全四脚とHEADの親で、BODYの揺れが全部位へ伝播していました。
- v302では**BODYにロック中の命中でBODYマテリアルだけ**、**HEAD・脚への命中では該当部位のマテリアルと部位pivotだけ**を0.145秒発光・反応させます。別部位のマテリアルやタイマーに新たな発火を伝播させません。
- BODYの親ノードの位置・回転を常時ゼロに固定し、他の部位が一緒に揺れないように変更しました。BODY自体は従来の暗赤色の色変化を維持（BODY全体の揺れのみ停止）。HEADと脚の局所揺れは維持します。
- 破壊済みの部位を連続コンボでロック保持しているときも、ダメージ計算上BODY扱いに切り替わることだけを理由にBODYを点滅させないよう、**ロック中の部位ID**を演出判定に使用します。
- 剣・Bash・左右蹴り・サマーソルトの攻撃命中経路は維持します。スパークの描画深度と縮尺を敵本体中心ではなく、**実際の部位着弾座標**に合わせ、他部位の面にずれて表示されにくくしました。

## 検証
- 新規`v302`静的・Godot実行回帰に、全四脚の中央狙点、左右・本体回転追従、5部位それぞれの単独発光、BODY単独発光、破壊済みコンボ、スパークの部位着弾とエフェクト復帰を追加。
- v238の過去のモデル寸法・センター・HP契約は維持し、狙点の旧オフセットだけを更新。Android実機の視覚印象は未検証です。
