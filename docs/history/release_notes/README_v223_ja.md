# SERA v223 — 背面スラスターに帯状の残光軌跡を追加

## 仕様
左右の噴射口が移動・方向転換した際、通過位置を結んだ青い帯がワールド空間に残ります。帯の中央に細い白青色の発光ラインを重ねます。古い部分ほど細く透明になり、約0.34秒で消えます。噴射停止後の残光も同じ寿命で消去します。

- 既存の正10角形の噴射筒を**置き換えずに重ねる**方式です。粒子、追加テクスチャ、物理判定は使いません。
- 表示位置はノズルの最新の物理回転（格闘中の身体めり込み防止補正も適用後）から採取します。過去の点はワールド座標に固定し、胸や噴射口が回転しても一緒には動きません。
- 平面的な帯はカメラ方向へ向けて再生成するため、急旋回や斜め移動でも消えにくくなります。大きな瞬間移動や噴射の再開では線をつながずに区切ります。
- 0.026秒間隔または移動距離3.5cmで新しい位置を記録。最大32点、0.34秒分だけ保持し、Android向けに描画量を抑えます。

## 維持
正10角形噴射、0.05秒で最大15倍に拡散・0.18秒で復帰する加速バースト、格闘中の通常噴射継続、左右ノズル可動・身体干渉保護、移動・EN・攻撃・装備・原本モデルは変更しません。重量脚部SLIDEは新たな噴射対象にしません。

## 検証
専用静的テスト tools/v223_thruster_ribbon_trail_self_check.py を追加し、ワールド座標履歴、再開時の分断、残光の時間減衰、従来の噴射機構との独立性を確認します。Android実機での幅・重なり・透明描画の見え方は未確認です。
