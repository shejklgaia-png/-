# SERA v384 — 踏みつけを頭上追尾・垂直足先へ戻す（2026-11-15）

## 踏みつけ（STOMP）

- **振りかぶり1.00秒**：プレイヤーの頭上を目標に、足を上昇させながら追尾します。狙点はプレイヤーの衝突カプセル上端を基準にし、頭よりさらに35cm高い位置を目指します。途中でプレイヤーが移動すれば振りかぶり中の狙点も滑らかに追従します。
- **足先の向き**：踏みつけに限り、足先メッシュが**垂直下向き**になるように保ちます。前版のすべての攻撃に共通する水平化補間は踏みつけには適用せず、持ち上げ・振り下ろしの間は足先を水平に倒しません。
- **振り下ろし0.20秒**：振り下ろし開始時点で狙点を固定し、そこから地面へ一気に踏み込みます。足本体と現在の脛のXZ範囲の1.5倍まで衝撃波で判定し、1攻撃最大1ヒットです。到達限界を超える狙点については二骨IKの実到達距離に従い、衝撃点は実際の足裏の位置を使用します。
- **復帰0.48秒**：足を引き戻して元の接地位置へ戻します。弾き・なぎ払いの挙動は今回変更していません。

**攻撃中**はこれまでどおり通常の旋回・接近を止め、胴体のみプレイヤー方向へ旋回、頭部は独立追尾し、残り3脚はワールド接地位置を維持します。部位破壊後も攻撃可能です。
