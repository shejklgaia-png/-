# SERA v453 — ビットタランの距離別攻撃選択

## 近距離は踏みつけ、中距離は弾きを優先

| 攻撃 | ボス本体からプレイヤーへの水平距離 | 方角 |
|---|---|---|
| 踏みつけ | **0〜3.00m** | 全方向（最寄りの実脚） |
| 弾き | **3.75〜5.15m** | 正面±38°（前脚のみ） |
| なぎ払い | 2.70〜7.10m | 正面・側面・背面寄り（従来通り） |

踏みつけが距離3.00m以内で最優先されます。弾きは一定距離を取った正面でのみ発動し、近距離での誤選択を防止します。3.00〜3.75mの移行帯では、従来のなぎ払いが条件に合う場合に使用されます。正面以外では引き続きなぎ払いを使い、真後ろの死角では旋回します。

近距離から開始した場合、攻撃前に必要な**3歩**はプレイヤーの周囲を回るように移動し、踏みつけの距離を維持します。弾きを一度使ったあとは同じ技を連続せず、歩行して別種の攻撃が可能な距離に移ります。

**攻撃モーション原本・実メッシュ当たり判定・足の接地・粉塵・アニメ再生時間は変更していません。** 既存のv452なぎ払い初回ストローク判定、踏みつけ着地1回判定、脚の復帰仕様も維持しています。

Godotの距離・角度の境界値、および実戦シーンでの近距離／中距離の3歩後の攻撃選択を新規テストで検証します。Android実機の操作感・見た目・FPSは未確認です。
