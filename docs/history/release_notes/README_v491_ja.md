# SERA v491 — 俯瞰拠点のグリッド金属床を画面全体に拡大

## 修正内容
- v490では床の**暗い下地のみ**を256m角に拡大していました。今回は視認できる**色付きのグリッド状金属プレートそのもの**を拡張しました。
- 従来の5×7＝35枚から**85×85＝7,225枚相当（約255m四方）**のグリッドに変更。プレート1枚の幅2.94m、3m間隔、6種類の金属色、プレート間0.06mの細い継ぎ目を維持。
- パネル1枚につき1ノードを作らず、6色ごとに`MultiMeshInstance3D`で一括描画。Android縦画面の負荷増加を抑える設計です。
- 下地の連続床はそのまま維持し、グリッドの継ぎ目だけ下地の金属が見えるようにします。
- SERAの移動境界、CRATE巡回、NEXUS建物タップと内部メニュー、戦闘・セーブ・カメラ位置は変更しません。

## 検査
- 実装前に`tools/base_exploration_self_check.py`と`tools/base_exploration_runtime_check.gd`を更新。6色のバッチ、総数7,225、グリッドの実座標、俯瞰カメラの追従範囲9地点×四隅がグリッド内に含まれるか検証します。
- v490の下地床表示検査、NEXUS↔拠点遷移、モデル・戦闘テストを維持。マージ後に共通CI全件を実行します。
- Android実機ではプレートの連続表示・描画負荷・継ぎ目をご確認ください。
