# SERA v466 — 球体チャージ中の高速捕捉と発射後の低速追尾

## 充填完了から発射まで（発射周期の9.6～10.0秒）
- 側面の3本の充填バーが満点灯するまでは、砲台は基本姿勢で静止します。
- 満充填の**9.6秒時点で銃口の青白い球体チャージが始まるのと同時に、プレイヤーへ高速かつ滑らかに旋回**します。
- 発射前の最大旋回速度は**水平900°/秒、上下720°/秒**。専用24Hzの指数イージングを通し、移動中のプレイヤーを短い事前照準期間で捕捉します。基準ブースト約6.1m/秒を大幅に上回る照準能力です。
- 従来通り、球体は0.2秒で縮小・消滅し、続く0.2秒間はレーザーを発射しません。この**暗転中も高速追尾を継続**します。
- **レーザー発射開始のフレームで、プレイヤーの実際の現在位置にYaw/Pitchを正確に合わせます。** 初弾は充填中に補足した過去の位置ではなく、発射時点の位置を指します。

## レーザー発射から終了まで（0.0～2.0秒）
- **レーザー発射後は水平24°/秒、上下18°/秒の低速追尾へ切替**。ブーストの横方向移動が照準に勝り、照射中の回避ができます。
- 10秒発射間隔、2秒照射、発射後0.4秒保持＋0.8秒で基本姿勢へ復帰、充填中静止を維持します。
- 砲台はBodyの前傾・横傾きを受けず、独立Yaw/Pitchの2軸のみで作動します。ビットタラン全身を映すカメラ、既存の脚攻撃・頭追尾・14ボーン原本は変更しません。

## 検査
- `tools/bittaran_railgun_runtime_check.gd` が、球体表示と高速旋回の同時開始、プリファイア速度上限、横ブースト中の発射時完全捕捉、発射後1秒間の低速角速度・ブーストに対する追尾遅れ、Pitch上限、光球の縮小・暗転・10秒周期を検証します。
- 全身撮影・Roll禁止の `tools/bittaran_full_frame_level_gun_runtime_check.gd` を維持します。
