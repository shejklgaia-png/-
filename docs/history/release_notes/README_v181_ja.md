# SERA v181 — バッシュの0.6秒追尾とブースター別近接ブースト

## ブースター追加ステータス
| ブースター | 近接ブースト速度 | 近接ブースト時間 |
|---|---:|---:|
| A（中量） | 11.5 m/s（旧速度と同値） | 1.0秒 |
| B（重量） | 9.5 m/s（Aより低速） | 1.2秒 |

- `scripts/sera_part_stats.gd` のブースターに `melee_boost_speed` / `melee_boost_duration` を追加。v180までの `approach_speed` は後継ステータスへ置換。
- 通常格闘のタップ後に従来の `meleeboost` 準備モーション（最終キー姿勢まで）を表示し、その後の**実際の追尾移動区間**にブースターの速度・時間を適用します。
- 敵ターゲットの現位置を毎フレーム参照し、攻撃可能距離に到達した時だけ既存の `melee1` へ接続します。時間切れ・EN不足で接敵できなければ移動を終了し、空中から敵に当たるようなダメージは発生させません。
- 接敵時の停止点は既存のターゲット矩形表面との距離・16回二分探索を使用します。敵が動いても攻撃可能距離を超えて突き抜けません。
- 接近中のEN消費は旧仕様（16EN/秒×ブースター消費補正）、装備の残りの性能は変更しません。

## バッシュ変更
- ガード状態から前方フリック、または3段格闘からの前方フリックによるバッシュ派生で、**バッシュモーションに入る前に0.6秒間の敵追尾**を行います。
- 追尾中は既存 `meleeboost` モーションを使用。追尾位置は毎フレーム更新され、0.6秒後に既存の `Bash` モーションを発動します。敵が近ければ停止して追尾時間終了を待ち、離れれば追います。
- 追尾移動には同じブースターの近接ブースト速度を使用。ただしバッシュ用追尾時間はA/B共通で**固定0.6秒**とし、通常格闘用の近接ブースト時間1.0/1.2秒は適用しません。
- 追尾移動のみENを消費し、EN不足なら移動せず残り時間を経過させます。バッシュ本体はEN不要なので発動可能です。
- 敵が0.6秒で射程外に逃れた場合でもバッシュ動作は実行しますが、従来どおり命中判定は実際の距離で行うため空振りになります。
- バッシュ中と追尾中のタップを次の3段格闘1段目として1回だけ先行受付します。従来のコンボ派生・ガード・エフェクトを維持します。

## HUDと確認手順
- 通常格闘の追尾移動時、HUDに現在の近接ブースト速度と経過/最大移動時間を表示します。バッシュ追尾時は `BASH HOMING  経過/0.60s` を表示します。
- CUSTOMIZEでA/Bブースターを切り替え、TRAININGで移動ターゲット `MOVE: ON` にして通常格闘の追尾を比較してください。A=11.5m/s・1秒、B=9.5m/s・1.2秒。
- ガード状態から前フリック、3段コンボから前フリックを行い、追尾0.6秒後にバッシュが発動することを確認してください。追尾中に敵が動いた場合も、目標位置が更新されます。
- ENが足りない場合や近接ブースト時間切れの場合、過剰追尾/射程外命中が発生しないことを確認してください。
