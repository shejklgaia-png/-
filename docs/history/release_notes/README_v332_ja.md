# SERA v332 — セラの実際の正面とフリック区画の整合

- v331の表示不一致の原因：タッチ開始時／表示更新時のカメラ投影に、敵のロックに合わせて回転する衝突ルート（CharacterBody3D）を使っていた。一方、RUN/BOOST/STEP/格闘時はセラのHead・Chest・Waistに個別のアニメーション回転が加わるため、画面に見える正面方向と一致しない場合がある。
- v332では実モデルの**頭部ピボット**のワールド向き（-Z）を平面上へ投影して「前」を算出。激しく傾いて水平向きが消えた場合は胸→腰へフォールバックし、モデルの準備ができない場合のみ従来の衝突ルート基準へ戻す。
- **入力と表示を同じ計算に統一**：バッシュ／左右蹴り／サマーソルトの候補判定に使うタッチ開始時の向きと、赤・黄・青灰のガイドを同じ関数から取得。指を動かしている最中、コンボ判定に使う軸はフリック開始時に凍結したまま表示も固定。通常RUN/BOOSTのガイドだけは実表示向きに応じ滑らかに追従。
- ガイドの色・4つの90°角度区画・装備・物理・カメラ・着地0.2秒演出は変更しない。既存の全CIに加え、実リグの見た目の向きとプロジェクションを比較するGodot検査を追加。
- Android実機の最終的な見え方と操作感は別途確認が必要。
