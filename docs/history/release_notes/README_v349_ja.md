# SERA v349 — ビットタランの頭・胴体はダウン中だけロック可能

## ロック可能部位

| 部位 | 通常時 | 脚破壊ダウン中 |
|---|---|---|
| 左前・右前・左後・右後の4脛 | 可能 | 可能 |
| 頭 | 不可 | 可能 |
| 胴体 | 不可 | 可能 |

- **ダウン判定：** ビットタラン専用IKの `break_reaction_active()`。脚の部位耐久値がゼロになり機体が滑走/前傾している実際の約1.15秒間だけ弱点ロックを解放します。単なるよろけ・立ち止まり・汎用部位破壊フリーズでは頭・胴体を解放しません。
- **自動ロック：** 通常時の候補は四脛のみ。既存の2本のロック線が脛に交差しなければ、正面線との距離が最も近い脛へ自動補完します。既存の空文字列のBODYフォールバックを通常時に許可しません。
- **手動ロック：** 通常時は四脛のみを巡回。ダウン中はHEADに加え、`body` という選択用IDでBODYも巡回できます。`body` への攻撃は既存のBODY（空ID）と同じ共通HPダメージとして処理します。
- **起き上がり：** ダウン解除と同じ物理更新で、HEAD/BODYをロック中なら四脛のいずれかへ切り替えます。コンボ入力中も通常時の弱点ロックは保持しません。
- **リセット：** 再出撃/KO後は通常時の4脛のみを選択可能な状態に戻ります。

## 既存機能

- モデル2倍、低重心IK、視野角100°・低速接近AI、脚破壊による1.05m滑走・頭部1.35mへの下降、頭/胴体/脚の独立したヒットエフェクトは維持します。
- 共通訓練室の`scripts/main.gd`、`scripts/target_parts.gd`、`scripts/sera_lock_management.gd`は変更せず、ビットタラン専用の`scripts/bittaran_parts.gd`および`scripts/bittaran_battle.gd`のみで制御します。
