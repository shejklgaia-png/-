# SERA v326 — カメラ安定化・刀ソードエフェクト角度修正

- 通常移動中も透視投影の解析的な画面収容半径を使用。ピクセル単位の境界判定でズームが拡大・縮小を繰り返すのを防止し、プレイヤーとボスが画面に収まる安全領域を優先します。
- 刀2段目の剣閃に付加されていたY軸180°の回転を廃止。Blockbenchの`Swordeffect`へ記録された各モーション固有の位置・回転・スケールに正確に追従させます。
- カメラYawの感度・近接追尾・STEPの0.3秒復帰、刀のモデル原本・モーションのキーフレームは変更しません。
- 旧v323剣閃検査を改訂し、カメラ収容と両段の剣閃姿勢に関する静的・Godotテストを追加。Android実機の映像・操作は引き続き要確認です。
