# SERA v37 — ダメージ表示・足元の影・床グリッド調整

v36の戦闘・移動・カメラ・剣エフェクトを保持した表示調整版です。

## 変更点

1. **ダメージ数値のマイナス記号を除去**。初期ラベルおよび攻撃命中時表示の両方を `20`（正の数値）に変更。HPの減少計算そのものは変更していません。
2. **プレイヤーの足元マーカーを縦横50%に縮小**。円の半径は1.38m→0.69m、直径は2.76m→1.38m。ターゲットの円の直径は2.76mを維持しています。
3. **双方の丸い影をダークグレー `#202329` に変更**。同じ非照明マテリアルを共有し、色を一致させています。
4. **床グリッドを濃く**。ライン色を `#111821` に変更、ライン幅を0.016m→0.032mに拡大しました。マスの4m間隔と床の形・位置は変更していません。

## 変更していないもの

- v35/v36で採用した白い剣軌跡、立体メッシュ、UV、粒子および前方0.55mの表示位置
- `melee1`、移動、カメラ、攻撃判定、ダメージ量20、HP、ヒットストップ
- プレイヤーおよびターゲットのリアルタイム影無効化
- ターゲットの足元マーカーの大きさ・位置

## 確認手順

1. 画面タップで攻撃し、命中時の数値が「20」と表示されること。
2. プレイヤーの円の直径がターゲットの約半分であること。
3. 両円が同じダークグレーであり、ターゲットの円は縮んでいないこと。
4. 床のマス目が従来より濃く太く見えること。
5. カメラ移動や斬撃演出がv36から変わっていないこと。

**Godot本体での起動テストは実施できた場合に限り報告します。**
