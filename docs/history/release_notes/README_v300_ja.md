# SERA v300 — 固定距離STEP、ロック部位中心の2段蹴りと直線ブースト

## ステップ移動
- 画面上方向（前）：**3m**、左右：**3m**、下方向（後）：**5m**。敵までの距離、BODY/部位ロック状態による距離の増減を廃止。
- 方向入力は全360°を維持。左・右・前の間は常に3m、左右から後ろへは角度の`smoothstep`で3→5mを滑らかに補間。斜め後ろ45°は4m。
- 方向は入力時のカメラ向きで固定し、全方位とも**基本10m/s**（装備補正を除く）。後方5mは基本0.5秒、前・左右3mは0.3秒。従来の敵距離に応じた前後減速も通常STEPでは使用しません。
- 衝突時は既存の`move_and_collide`で遮られ、実移動距離が計画距離より短くなる場合があります。これは移動距離補正ではありません。

## 左右蹴り
- `Kick_l` / `Kick_r` は、2段目の予備動作が終わるまで従来の初段追尾を維持し、**蹴りブーストの計画軌道長を左右とも3m**に固定。
- 予備動作が完了した瞬間に、選択中のロック部位（HEAD/BODY/四脚）の実際の狙点を水平方向に投影して回転中心とします。ロック部位が動けば、2段目の接触時刻までは回転中心を追従。
- 元の`Kick_l/r`の2段目ヒット時刻 **0.58333（モーション進行率）** までロック部位を軸に円弧移動します。接触した時点の接線を固定し、残りの距離は**回転せず直線ブースト**で移動します。途中で敵が動いても直進方向は変更しません。
- 円弧の距離＋接触後の直線距離＝合計3m。接近しすぎて回転半径がほぼ0になる場合は円弧を縮め、その距離を直線へ割り当てます。最大回転120°、安全な衝突処理は維持。
- 既存2倍モーション時間、2段接触キーフレーム、ダメージ／破壊部位のロック、格闘・Bashコンボを維持。

## サマーソルトキック
- `Kick_b` の**命中後の後方飛距離を4m→5m**へ変更。
- 滞空0.8秒、最高高度1.5m、着地0.2秒、既存ベジェ曲線と命中判定タイミング、原本モーションは変更しません。
