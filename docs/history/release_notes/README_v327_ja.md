# SERA v327 — 敵の脚に乗らない衝突・自然落下・サマーソルト接地

- 敵の脚や胴体に押し上げられないよう、敵の物理コライダーを縦バウンドから独立させ、通常の衝突移動がY高度を勝手に変えないようにします。
- ステップ・格闘・ジャンプ・サマーソルト・着地のアクション中は独自の高度制御を優先します。アクション終了後も空中に残っている場合は、元のジャンプ重力に従って視覚床のY=0まで自然落下させます。敵の上に着地することはありません。
- サマーソルトは原本`Kick_b`の全キーフレームを描画してから着地モーションへ入り、0.055秒の滑らかなクロスフェードと0.20秒の着地再生を維持。着地中は装備中の足裏が床上に来るよう表示用リグを補正します。
- モデル・モーションの原本とキーフレーム、4mステップ、5mの後方サマーソルト、攻撃衝突、HP/ENの仕様は維持します。Androidの映像での最終確認は別途必要です。
