# SERA v504 — 俯瞰拠点の施設を画面全体に分散配置

## 変更内容
- 中央付近に密集していた7施設を、Android縦画面の**上段／中段／下段かつ左右**に広く配置。LABOは左上、NEXUSは右上、精製炉・保管庫・回収機は左側、リサイクラー・発電機は右側、建設端末は下部中央。
- 施設の3D形状、表示名、機能、独立したタップメニューは保持。NEXUSの出撃・アセンブル・データ・設定・トレーニングの機能は増減・重複なし。
- カメラの俯瞰視点と全画面グリッド床を維持。狭い中央通路を確保し、クレートの巡回経路と施設が接触しない配置に調整。
- 外側へ移動した設備の名前は画面内に収まるよう位置を補正。タップ判定は3D施設の位置を基準に投影する方式を維持。
- 未確定の資源獲得量・消費・製作時間などの仮実装は行わない。セラ/移動スティックの一時非表示も維持。

## 事前CI確認と先行テスト
- 現行mainのv503、`AGENTS.md`、`tools/sera_ci_manifest.txt`、`tools/base_facilities_runtime_check.gd`、`tools/base_exploration_runtime_check.gd`と登録済みモデルポリシーワークフローを確認。
- 3D配置の変更前に`tools/base_facilities_runtime_check.gd`へ画面X方向約52%以上・Y方向約40%以上の分散、各施設がタップ可能な画面範囲内に存在すること、施設基礎が重ならないこと、施設名がクリップされないことを追加。
- NEXUSを移動するため、古い座標を固定した`tools/base_exploration_runtime_check.gd`の入口衝突チェックを**現存するNEXUS建物の入口のワールド座標**に変更。既存の床、非表示SERA、CRATE、自律巡回、NEXUS往復テストは維持。
- 変更対象は拠点の位置、ラベル補正と関連テストのみ。ボス/装備/モデル原本への変更なし。全CIをmainマージ後に検証し、実機で表示・タップしやすさを別途確認。
