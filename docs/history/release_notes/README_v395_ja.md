# SERA v395 — ビットタランの脚優先干渉回避・頭部20cm許容

- **頭部と脚の干渉回避は脚優先**とします。頭部は基本的にセラへの独立追尾を継続し、干渉した支持脚の膝を外側かつ下方向へ倒して逃がします。足先のワールド接地点、脚の骨長、胴体ルート位置、既存の歩行タイミングは維持します。
- 頭部と脚の実メッシュの許容貫入深度を **10cmから20cm** に変更しました。膝は13cmを目安に先行して折り、20cmへ近づくまでは頭部の旋回・上下追尾を極力妨げません。頭部旋回は14cmから徐々に減速し、20cmでは深く入り込む方向への回転を停止します。離れる方向の回転は許可します。
- 膝の倒し補正を最大0.70（従来0.45）へ拡大し、倒し始めを速くしました。フレーム単位の過補正を避けるため、回避目標は従来どおり間欠再評価とヒステリシスで安定化します。
- 攻撃中も**支持脚に限り**頭部干渉回避を実施します。攻撃中の脚そのものはBlockbenchの元モーション優先とし、脚を倒す処理で攻撃姿勢を上書きしません。物理ダウン中の支持姿勢、攻撃中ダウン移行と部位破壊タイマーは従来のままです。
- 軽い見た目の重なりを理由に頭部を上へ逃がす補正を廃止しました。**20cmを超える実メッシュの深い侵入時のみ**最終的な安全処理を残します。頭部の腕復帰範囲の機械的な旋回制限は維持します。
- 旧10cm規定の既存Godot回帰テストを現行20cm仕様に修正し、攻撃中の支持脚回避・攻撃脚の姿勢保持・接地点保持・頭部不変を確認する `v395_bittaran_leg_first_head_clearance_runtime_check.gd` を追加しました。全CIへの登録は済んでいますが、Godot headlessの実行結果とAndroid端末での見た目は未確認です。
