# SERA v122 — 前景コンソールの角度調整（2026-11-08）

## 変更内容

v121の拠点の手前2台（TRAINING / SYSTEM）の向きだけを変更しました。Godotの`scripts/command_nexus.gd`で共通Blockbenchモジュール `kiosk` を配置する際のY軸角度を、左右対称の **+18° / -18°** に変更しています。従来の +10.3° / -10.3° より斜め向きです。

- 左手前：`Vector3(-1.70, 0, -0.65)`、Y軸 +18°
- 右手前：`Vector3(1.70, 0, -0.65)`、Y軸 -18°

位置・スケール、カメラ、看板の高さ、照明、Blockbenchモジュール原本と埋め込みデータ、設備の非操作仕様は変更していません。起動時2択と訓練ステージの操作/戦闘も維持しています。

## 検証

`tools/v122_nexus_console_angle_self_check.py` を追加。2台の角度、既存カメラ値、レイアウト、非インタラクティブな仕様を静的に検査します。旧`v121`の回帰テストは後継バージョン名でも使用できるように修正しました。**Godot実行およびAndroid実機での角度の見た目は未検証**です。
