# SERA v314 — 通常フリックステップ全方向5m（通常BOOSTの5m制限を撤回）

## 訂正対象
v313で「通常BOOSTを5mで打ち切る」と実装した解釈は意図と異なりました。通常BOOSTの距離積算・上限・解除後再武装を削除し、v312の継続ドラッグ型BOOSTへ復帰します。

## 通常STEP
- 前後左右・斜めを含む360°のフリック回避距離は**一律5m**（v312/v313の7mから変更）。ターゲット距離で増減しません。
- 標準速度は**15m/s**を維持。装備補正1.0時の所要時間は**約0.333秒**（5÷15）。装備の速度・時間補正とEN消費もそのままです。
- フリック方向への衝突安全な直線移動、ロック先を前方とする4方向/斜めポーズ補間、Step_R原本、22°の回避リーンと14cmの腰下げ、0.12秒の入り/0.16秒の戻りを維持。
- 待機HUDを「STEP ALL 5.0m」に修正。

## 対象外
- 通常のRUN/BOOSTドラッグは距離固定ではなく、従来どおり継続する操作へ復帰します。
- コンボ左右蹴りは3m・10m/sと2倍モーション時間、サマーソルトKick_bは5m後方飛翔を維持します。

## 検証
既存v235/v236/v300/v309/v310/v311/v312距離回帰とv313 BOOST回帰を現行仕様へ修正し、v314静的/Godot実行テストをCIへ追加。Xperia 1 V実機では未検証です。
