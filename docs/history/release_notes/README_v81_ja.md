# セラ v81｜至近距離ステップ・カメラのスコープエラー修正

## 原因
v80では `_physics_process()` 内のローカル変数として宣言した `close_step_camera_this_frame` を、別関数 `_process()` で参照していました。GDScriptのローカル変数は別の関数から参照できないため、v80の1338行付近で識別子未宣言エラーが発生しました。

## 変更
- `close_step_camera_this_frame` をスクリプトのメンバー変数として宣言。
- `_physics_process()` は既存のステップ開始時スナップショットをそのメンバー変数に代入。
- `_process()` の至近距離カメラ回転制限は同じ値を参照（ロジック・閾値は変更なし）。
- ブーストと格闘の追従設定はv78準拠を維持。

## 維持
- 至近距離（敵キューブ表面から1m以内）左右ステップ中のカメラ回転上限±18°、画面端の方位強制補正回避。
- 通常移動・ブースト・格闘・ステップ速度、残像、敵AI、被弾・ノックバック、その他のUI等はv80と同一。

## 検証
- ソースコードのスコープ検査、変更差分、ZIP整合性を確認。
- Godot 4.7.2/Android実機でのゲームプレイ・描画検証は環境の都合により未実施（別途検証できた場合のみ記載）。
