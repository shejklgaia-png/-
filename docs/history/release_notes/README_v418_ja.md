# SERA v418 — 弾きの距離依存を廃止・後足の接地から胴体後角の高さを逆算

## 変更1：弾きはプレイヤーまでの距離で縮めない

- 全4脚の弾きで、プレイヤーに近いほど脚を短く伸ばしていたv404/v406の`kick_reach_factor`計算と、足先IKの距離クランプを削除しました。
- Blockbench原本の弾き軌道を再生し、方向のみ既存の照準処理で調整します。近距離のプレイヤーを脚が通り越しても、モーションは距離で変化しません。ヒット判定は従来どおりです。
- **物理的な骨長を超える接地位置**は、v416の床近傍の解決によって必要な範囲だけ到達可能な位置へ調整します。これはプレイヤー距離ではなく、床と脚の幾何学的制約です。
- 旧v404の「近距離でプレイヤーを大きく通り越さない」回帰テストは、新仕様の「近距離でも原本の長い伸長を保つ」に変更しました。

## 変更2：後足攻撃で、脚の接地から胴体後方の付け根の角の高さを求める

対象：左右後足の**弾き・なぎ払い・踏みつけ**すべて。

1. 攻撃フレームの足先メッシュ、または踏みつけの短い先端面の床接地位置を推定します。弾きは原本の反転された足先軌道、なぎ払いは現在の原本足先姿勢、踏みつけは攻撃目標と垂直に立てた足先を使用します。
2. 股関節→膝→足先の**現在の実骨長**、接地時の足先の位置・回転、股関節から接地点までの水平距離を使って、接地可能な最大の股関節の高さを三角関数で逆算します。
3. その高さを超えている場合に限り、**胴体前側の左右脚の付け根の平均高さを固定したまま**、BodyのローカルX軸回転を調整します。これにより胴体の後方の左右角が実際に上下し、そこに接続されている後足の付け根も連動します。
4. 検索は両方向の回転を試して、後方の角を下げる方向を選択します。姿勢の限界値、胴体メッシュの床貫通、股関節の沈み込み量を制限します。通常姿勢への復帰時には時間補間で補正をゼロにします。
5. 胴体の**ルート位置の高さは維持**し、前脚側の付け根を上下させません。支持脚は既存のIKで同じ床の接地位置へ再配置します。v417の後足の弾きの軸回転を防ぐため、攻撃脚の肩の原本ワールド回転はBodyの追加回転後に戻します。

これまでv414では、後足攻撃中の胴体の基礎姿勢は基本姿勢の25°後傾から同角度の前傾へ移り、*完全に同じ角度のまま*保持していました。v418では、**その基礎姿勢に床接地から算出された追加ピッチを重ねます**。前後の脚の付け根の位置を変えるための変更であり、胴体全体を上下させる処理ではありません。旧v414のチェックは、追加ピッチを差し引いた基礎姿勢とルート高さを引き続き検証します。
