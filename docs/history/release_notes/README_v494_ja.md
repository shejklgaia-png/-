# SERA v494 — レールガンの追尾をもう少し密着させる

## 変更点（照射中のみ）
- レーザー照射中、射線とプレイヤーの水平距離0〜**1.5m**で追尾速度を滑らかに補間します。v493の0〜2.5mから短縮し、少しのずれでも早めに加速します。
- 射線上の最小追尾角速度を、RUNとBOOSTの間に設定した最大追尾速度の**0.70倍→0.85倍**へ引き上げました。
- レーザー照射中の照準角度の指数補間を**10/s→14/s**へ調整し、追尾の微小な遅れを軽減しました。青球体の追尾開始・縮小中は従来の時間補間のままです。
- 1.5m以遠の最大追尾角速度は**v493から変更しません**。装備に応じたRUNとBOOSTの間（標準装備：RUN 4.0625m/s、追尾相当5.3828125m/s、BOOST 6.09375m/s）で固定し、通常移動には追いつき、横BOOSTなら振り切れる関係を維持します。
- 過度に速いプレイヤーの移動・ワープ・ノックバックなどで速度上限を突破しない仕様も維持します。

## 変更しない仕様
- 0〜10秒の充填中は追尾せず、10〜10.7秒の青球体追尾開始、10.7〜11秒の高速照準、11〜12秒の青球体縮小中の0.7倍追尾、12〜14秒のレーザー照射、14〜14.7秒の基本姿勢への復帰は据え置きます。
- 発射時の威力60%、接触0.2秒間隔の再ヒット、ノックバック、モデル、関節、足の攻撃、音声、レーザーエフェクト、ビットタラン本体との世界Yaw分離、接続軸の同期は変更しません。

- 実装前に既存レールガン実Godotテストを先行更新。0/0.375/0.75/1.125/1.5mのsmoothstep係数、1.5m以遠の最大速度制限、発射時0.85倍・青球体縮小中0.7倍、照射中14/sの反応、実シーンで通常移動時の射線誤差0.8m未満・BOOSTの離脱を検証します。新規CIの登録は不要です。
