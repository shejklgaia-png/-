# SERA v532 — ビットタランの胴体着地・起き上がり調整

## 今回の変更
- ビットタランの脚破壊後、実際に胴体が落下して地面へ接触した瞬間だけ、胴体の実ワールドAABBより横方向に広い（幅・奥行140%）範囲で土埃を発生させます。
- 踏みつけの灰色6層（土壌・粉塵・砂・微細粒子・岩片・砂利）を利用し、独立した一度きりの粒子発生器で元の攻撃エフェクトと衝突しません。大きな接地音とカメラ衝撃を追加しました。
- 既存の通常ダウン2.5秒／全脚ダウン6.0秒、起き上がり1.0秒／1.3秒は保持します。復帰姿勢は5次の滑らかなC2補間で急加速・急停止を抑えます。
- すでに倒れている状態で別の脚を破壊しても、土埃が二重に出ることはありません。専用 Godot 回帰テストを追加しました。
