# SERA v214 — 方向転換中のBOOSTスラスター噴射継続

## 変更内容
BOOST中に指を別方向へ動かすとき、実際のBOOST入力が一時的に外れても、**見た目のBOOSTモーションが継続する限り左右のスラスターノズルも噴射し続けます**。

| 状態 | 背面スラスター |
|---|---|
| 実際にBOOST中 | 噴射 |
| 方向転換でスティックが一瞬中央に戻る | BOOST姿勢を表示中なら噴射継続 |
| BOOST姿勢の維持時間（最大0.50秒） | 噴射継続 |
| BOOST→RUNへの姿勢移行（0.20秒） | BOOST姿勢が混ざっている間は噴射継続 |
| 通常RUN / 待機 / 指を離した後 | 停止 |
| 重量脚部の通常SLIDE（待機50%＋BOOST50%） | 噴射しない |
| STEP / 攻撃追尾 | 従来どおりの専用噴射条件 |

**速度やEN消費は従来のBOOST判定のまま**です。姿勢維持時間中の噴射は視覚演出であり、BOOST加速やEN消費を追加しません。

## スラスターの方向
方向転換で一瞬ニュートラルになった場合、最後に入力していた噴射方向を保持します。次に操作方向が決まったフレームから新しい方向へ追従します。

後方移動時の真下への補正、左移動時の画面下〜右の扇形、下向き初期方向、Blockbenchの3DノズルPivot回転はそのままです。

重量脚部では、本当にBOOSTした後の0.50秒の姿勢維持を通常SLIDEの50%ブレンドより優先します。維持が終わると通常の重量脚部SLIDEへ戻ります。通常SLIDE中の背面噴射はありません。
