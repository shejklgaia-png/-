# SERA v112 — 左へのドラッグを前方RUN優先にする利き手モード（2026-11-07）

## 変更
- 右利き（初期値）では、左方向（ターゲット基準）のドラッグがやや後方へ傾いても前方走行モーションを維持します。左側前方RUN判定を従来より20°拡張。
- 左利きに設定すると拡張する側が逆になり、右方向のドラッグで同じ補正がかかります。
- ゲーム画面上部のボタン `HAND: RIGHT`（右利き）／`HAND: LEFT`（左利き）を押すたびに切替。設定は `user://sera_settings.cfg` に保存して次回起動にも引き継ぎます。

## 前後モード判定（敵方向を0°、左右真横を90°）
| 利き手 | 左側のRUN中心境界 | 右側のRUN中心境界 |
|---|---:|---:|
| 右利き（既定） | 120° | 100° |
| 左利き | 100° | 120° |

- 既存の±5°ヒステリシスは維持。拡張側では前進→後退125°超、後退→前進115°未満。非拡張側では105°超／95°未満のまま。
- 初めて走り出す時は中心境界で判定し、走行中はヒステリシスを適用します。設定切替時は現在のドラッグ方向を再判定し、既存のモーションブレンドとルート回転制限で滑らかに姿勢を更新します。

## 維持と検証
- **実移動方向は補正しません**。斜め後ろへのドラッグは実際の進行方向としてそのまま使用し、前方RUNか後ずさりかの見た目のみ選択を変えます。
- v111の前進・後退2モード、0.18秒ブレンド、腰の進行方向追従、腹部から頭部へのターゲット追従、最大15°の旋回傾斜、ステップ/ブースト/ガード/格闘/ジャンプ、カメラ・BGM・SE・モデルファイルは維持。
- `tools/v112_handed_run_mode_self_check.py` に左右利き手の鏡像判定、初回判定、ヒステリシス、設定切替の関数配線とHUD/設定保存を確認する検査を用意。旧v111検査の定数アサーションを新仕様へ更新。
- **Godot実行・Android実機タップ・利き手の保存復元の実行確認は未実施**。実機で左110～125°のドラッグ、利き手切替、ゲーム再起動後の保存、ボタンから誤操作が発生しないか確認してください。
