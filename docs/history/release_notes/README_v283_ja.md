# SERA v283 — 3段目の振り切り後0.1秒キャンセル

## 変更内容
- 3連打の3段目（`Melee3`）の振り切りキーは従来どおり **15/24秒＝0.625秒** です。
- **0.1秒後の0.725秒**を、予約されたフリック派生の専用キャンセルポイントに設定しました。
- 予約済みの **左右蹴り（Kick_l／Kick_r）・後方サマーソルト（Kick_b）・前方バッシュ（Bash）** は、原則このポイントから発動します。キャンセルポイントを過ぎてから予約された場合は、次の更新で発動します。
- フリックが予約されていない場合は、従来どおり **Melee3の全長約0.83333秒** が終わってから待機状態に戻ります。
- **通常攻撃1段目の発動可能時間は変更していません**。Melee1／Melee2のキャンセルタイミング（7/24秒）・通常攻撃の受付条件・コンボループ条件は従来どおりです。
- 3段目の追尾中（STRIKE_TRACK）でもバッシュ予約を受け付け、通常ステップへ誤変換されないようにしています。
- 刀（Katana）は現行の0.5秒モーションが短いため従来のクリップ終端基準を維持し、原本Melee3への追加0.1秒のみを適用します。
