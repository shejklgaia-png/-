# SERA v183 — 追尾解除後も予備動作を最後まで再生

## 修正内容
- v182では `release_attack_windup()` が追尾終了時に `clip_time` を振りかぶり最終キー時刻へジャンプさせていたため、ターゲットが早く射程へ入ると予備動作の途中が省略されていました。
- **v183ではジャンプを削除。** 追尾が終了すると往復ループだけを止め、現在表示中の `clip_time` をそのまま維持して、同じBlockbenchモーションの残る振りかぶり→振り抜き→命中キーを自然に再生します。
- 対象はバッシュ（`Bash`）、通常格闘2段目（`Melee2`）、3段目（`Melee3`）。近距離で入力し即追尾解除した場合も、0秒から予備動作を通過して攻撃が出ます。往復ループから解除する場合も、現在の姿勢から順方向に再生を再開します。
- 変更箇所は `scripts/sera_rig.gd` の `release_attack_windup()` のみ。ブースターの追尾速度・時間、`BASH_TRACK` / `STRIKE_TRACK` の追尾終了タイミング、EN消費、攻撃中の命中まで追尾、命中判定、ヒットストップ、コンボ入力とアニメーション原本は変更しません。

## 変更しない追尾上限
| 対象 | 従来通り |
|---|---:|
| 通常格闘初段 Aブースター | 0.4秒 |
| 通常格闘初段 Bブースター | 0.6秒 |
| バッシュ | 0.2秒 |
| 格闘2・3段目 | 各0.2秒 |

## 確認手順
1. GitSyncでmainを同期し、Godotの `SERA v183` を起動します。
2. 動いている敵に近接してバッシュを出し、**最初から振りかぶり→攻撃まで表示**されることを確認します。
3. 追尾を必要とする少し遠い位置でバッシュを出し、追尾中の往復ループから不自然なポーズ飛びなく振り抜きへ移ることを確認します。
4. 3段格闘の2・3段目も同じように予備動作が省略されないことを確認します。
5. 追尾時間上限と敵に命中するまでの追尾はv182と同じか確認します。
