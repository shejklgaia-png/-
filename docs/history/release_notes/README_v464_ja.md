# SERA v464 — ビットタラン全身フレーミングと砲台水平制約

## 戦闘カメラ
- ビットタランの**18個すべての正本メッシュ**（胴体、頭、4脚と足先、背部2本のレール）および砲台側面箱の現在のワールド座標から外接範囲を求め、全身が画面に収まる最小カメラ半径を逐次算出します。
- 正面・側面・背面・斜めからの視点をカバーし、上下はボスHP表示とタッチ操作領域を避ける安全領域を維持します。既存のセラ追従、ロック、移動方向、被写体透過、ZOOMの安定化処理は維持します。
- レーザーが遠くまで伸びた際に不必要な引きカメラになることを避けるため、45mのレーザー本体は全身フィットの対象に含めません。

## 背部砲台の2軸制御
- 胴体の前傾／後傾（Pitch）・左右傾き（Roll）を照準へ継承しないよう、砲台の向きをワールド水平面基準で毎フレーム再構成します。
- 砲台の向きは **水平旋回（Yaw）と専用Pitch軸での上下角のみ**。横転（Roll）しない構造とし、Bodyボーンの位置変化のみ引き継ぎます。
- 既存の10秒周期、2秒照射、0.2秒球状発光、照射終了後0.4秒停止、0.8秒復帰、3段階チャージバーは保持します。

## 検査
- 新規 `tools/bittaran_full_frame_level_gun_runtime_check.gd` が実Godot上で複数方向の全身フレーミングと、前後・左右へ傾けたBody上での砲台のワールド水平姿勢を検査します。
- `tools/bittaran_railgun_runtime_check.gd` の旋回検査は親ボーンの傾きを相殺したローカルEuler値ではなく、独立したYaw状態を直接検証します。
- Blockbench原本・14ボーン骨格・脚IK・足元攻撃・頭追尾は変更しません。
