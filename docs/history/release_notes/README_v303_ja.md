# SERA v303 — ロック判定を左右2本の平行線へ変更・可視化ボタンを追加

## AUTOロックの幾何
- セラの物理ルート座標から敵本体中心へ引く線分を基準に、**水平面で左右それぞれ0.25m（間隔0.50m）の平行線分2本**を使います。ターゲットやセラが移動・回転すると随時再計算します。カメラ向きは使用しません。
- 部位選択候補は、**2本とも同一部位の実BoxMeshに交差**したHEAD・四脚（HEADだけ既存のロック補助領域を含む）とBODYだけです。**片方だけに交差した部位は候補から除外**します。
- BODYと各部位は引き続き同列の交点比較で、**各線の最初の交点までの距離のうち、遠いほう**をスコアとし、最小の部位を選びます。BODYは空文字のロックIDとして従来どおり扱います。
- 境界から外れた際も即切替はせず、次候補が**0.22秒継続**した場合だけ切り替えます。部位破壊時の再選択は即時、コンボ継続中のロック保持は維持します。これにより薄い隙間・一時的な交差の出入りによるフラつきを防ぎます。

## 可視化ON/OFF
- 戦闘画面の**AUTO/MANUALボタンの直下**に`LINES OFF`／`LINES ON`ボタンを追加しました。デフォルトは**OFF（完全非表示）**です。
- ONでは、判定と同じ2本の線分を水色の細い3Dラインとして表示します。ラインはモデルの手前を無条件に透過しない深度テスト付きで、当たり判定・攻撃・ロック自体には影響しません。
- AndroidタッチとPCマウスのどちらでも切替可能です。ボタンに触れてもRUN/BOOST/STEP/ATTACK操作には移行しません。AUTO/MANUAL・左右切替の既存ボタン配置は変更しません。

## 維持した仕様
- セラ→ターゲット中心を基準にしたAUTO、HEAD/四脚/BODYのロック順、手動左右切替、0.22秒の切替確認、既存部位の破壊/保持、格闘・Kick・サマーソルトの命中判定、カメラとHUDロックマーカー。
- 旧1本レイのAPIは履歴回帰用として残し、AUTOの取得元にのみ2本方式を適用します。

## 検証
- `v303`静的・Godot 4.7.2実行テストを登録。2線の平行/距離、1本しか交差しない部位の除外、0.22秒の切替、カメラ非依存、HUD切替ボタンとラインの一致を検証します。
- Android実機でのライン描画やタッチ操作は未検証です。
