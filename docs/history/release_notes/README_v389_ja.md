# SERA v389 — ビットタランの胴体埋まり防止と、攻撃中ダウン時の脚姿勢リセット

## 胴体が床に埋まらないようにする
弾き／なぎ払いの0.70秒の低い予備姿勢や、脚破壊後のダウンによって、胴体が床面より下へ入ることがありました。原因は脚の接地IKのみが実装され、BODYメッシュの地面接触が確認されていなかったことです。

毎フレーム、**BODY本体メッシュのAABB全8頂点を実際のワールド座標へ変換**して最下点を求め、床面から2cmの余裕を確保します。必要なフレームだけモデルの胴体高さを補正し、脚のIKをその後に解決します。HEADや各脚のメッシュはこの判定へ含めず、BODY自身が地面へ潜る場合だけ動作します。

## 攻撃中に脚を破壊された場合
踏みつけ／弾き／なぎ払いの途中でダウンが発生したら、以下を行います。

1. 攻撃モーションと当たり判定を即時キャンセル
2. **脚の実接地位置を先に記録**し、足の瞬間ワープを防ぐ
3. すべての脚関節（肩・膝・足）とBODYの回転を、Blockbench `Wait` の基本姿勢に戻す
4. 物理ダウンモーションおよび既存の接地IKへ移行

頭部はモーションによる上書きを受けず、ダウン中だけ従来どおり中立方向へ戻ります。致死攻撃でも残った攻撃モーションは停止します。

## テスト
`tools/v389_bittaran_body_floor_down_interrupt_runtime_check.gd`は、4脚×3種類の攻撃に対して、実モーション中／攻撃中断後のBODYの床面貫通防止、全13関節の基本姿勢へのリセット、HEADの独立制御、攻撃中の再発動防止をGodot 4.7.2の実シーンで確認します。既存のPython／Godot全テストも継続します。

Android実機での最終映像確認は別項目です。
