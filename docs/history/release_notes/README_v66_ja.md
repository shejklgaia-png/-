# SERA v66：敵AI（低頻度の単発射撃）

## 変更点
- v65を基準に、固定キューブの敵へ独立した射撃AIを追加しました。
- ゲーム開始約2.2秒後に初回の攻撃予兆が始まります。予兆は0.65秒です。
- 敵は予兆後に橙色の弾丸を1発発射します。弾速は7.5m/sです。
- 発射後の待機時間は毎回4.5〜6.5秒のランダム値です（次の予兆0.65秒を加えると、発射間隔は約5.15〜7.15秒）。
- 予兆の開始時点でプレイヤー位置を狙い、その後は追尾しません。ステップで避けられます。
- 弾丸は実体のあるArea3D判定に加え、1フレームの移動区間にレイ判定を行い、すり抜けを抑制します。
- プレイヤーに命中した弾は消滅し、画面全体に0.22秒の薄い橙赤色のヒット表示を出します。
- 敵HPが0の間は**新たな発射を停止**します。既に発射済みの弾はそのまま飛びます。
- プレイヤーHP、シールド、被弾硬直、ガード、ガード崩れ、ノックバックは**未実装**です。今回の命中処理でダメージ値は変更しません。

## 調整可能なパラメータ
`scripts/enemy_shooter.gd` のエクスポート値：
- `first_shot_delay = 2.2` 秒：初回予兆まで
- `fire_interval_min = 4.5` 秒、`fire_interval_max = 6.5` 秒：発射後の待機時間
- `warning_duration = 0.65` 秒：射撃前の予兆
- `projectile_speed = 7.5` m/s：弾速

## 変更ファイル
- `scripts/main.gd`：AI起動、ターゲットHPに応じた発射停止、被弾表示への橋渡し
- `scripts/enemy_shooter.gd`：新規・射撃AI、発射予兆と弾生成
- `scripts/enemy_projectile.gd`：新規・弾の表示、移動、衝突判定、自然消去
- `project.godot`：アプリ表示名をv66に変更
- `README_v66_ja.md`、`DEVELOPMENT.md`、`tools/v66_enemy_ai_self_check.py`：開発履歴と静的検査

## 既存挙動の維持
- v65の下部グレーグラデーション、v63の距離別ステップ速度、v9のドラッグ移動・カメラ、単発近接攻撃、剣の軌跡、ターゲットHP・復帰は変更しません。
- 描画設定は元のCompatibilityを継承しています。

## 検証範囲
- 元プロジェクトとのファイル単位の差分とリソース参照、関数定義の重複とインデント、弾の発射位置の幾何条件を静的に検査します。
- 実際のGodotエディターでの読み込み・実機での表示や当たり判定は未検証です。Godot 4.7.2安定版での動作確認を推奨します。
