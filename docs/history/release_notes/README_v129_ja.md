# SERA v129 — カスタマイズ画面の浮遊モデル・ドラッグ回転

## 実装仕様
- 拠点背景、固定建造物、ゲート、ステージ台座、v128のカメラ位置・半透明青メニュー・不透明ラベルは変更しない。
- CUSTOMIZEへの0.18秒カメラ接近後、既存の展示用SERAモデルをカメラ座標基準の正面向きの浮遊プレビューとして表示する。モデルの複製、新しい3Dレンダリングパス、独立SubViewportは設けない。
- 元のSeraRigを親ノードから外すと既存の残像エフェクト管理を終了させてしまうため、親子関係を保ったまま、カメラ座標から求めたワールド変換でモデルだけを移動する。表示台・部屋・カメラには一切移動を加えない。
- 初期姿勢はカメラ画面に平行な正面向き（カメラ相対Y軸180°）。モデルの元のローカル変換を保存して、戻る操作時にステージ上へ復帰する。
- プレビューを右側（左メニューパネルの右端+18pxから画面右97%の範囲）へ配置する。モデルは少し大きく表示し、セラの全身・剣・盾を対象として、角度16分割の360°回転時の画面占有範囲を算出して配置とサイズを自動調整する。メニュー本体との余白を維持。
- CUSTOMIZE時は右側の3Dモデル展示領域を左右ドラッグして回転。指の移動量が横画面幅1本分なら360°に相当する速度で、モデルのY軸角度だけを変更。スマホの指ドラッグとPCの左ボタンドラッグに対応。
- 左のメニューと右下戻るUIをドラッグ判定領域から除外。ドラッグ中にカメラ位置・向き・背景・メニューの移動は行わず、選択シルエットの輪郭はモデルの向きに追従する。
- 右下の戻るボタンまたはAndroid戻る操作で展示モデルを元の台座へ戻して0.18秒で拠点全景に復帰。次回CUSTOMIZE開始時は正面向きへリセット。

## 既存機能との互換性
- TRAINING／SYSTEM／DATA ARCHIVE／DEPLOYMENTのカメラ・パネル・シーン遷移は変更なし。既存の枠の明滅、ゲート枠の遮蔽、v127コンソール左右入れ替えも維持。
- 変更：scripts/command_nexus.gd、project.godot、v125〜v128のソース検査、DEVELOPMENT.md。
- 新規：tools/v129_customize_floating_preview_self_check.py、README_v129_ja.md。
- セラのBlockbenchモデルとBash/Guard_REACTION、剣形状、戦闘入力、BGM/SE、その他全てのアセットは変更しない。
- 静的コード／モデル整合性検査のみ。Godot実行とAndroidでの表示サイズ・回転操作の実機検証は未実施。
