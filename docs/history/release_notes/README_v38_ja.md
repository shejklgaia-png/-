# SERA v38 — 近接距離ロックオン赤色化・ターゲット立体陰影

v37のプロジェクトを基準とした表示修正版です。

## 変更点

1. ロックオンレティクル（画面中央の弧・十字）は、ターゲット表面への水平距離が `MELEE_SURFACE_REACH = 0.75m` 以下になった場合のみ赤になります。距離の計算は既存の `_distance_to_cube_surface()` と共通です。範囲外またはターゲット撃破中は従来のシアンに戻ります。ドラッグ操作用のリングはシアンを維持します。
2. ターゲットのキューブのマテリアルを `SHADING_MODE_UNSHADED` から `SHADING_MODE_PER_PIXEL` に変更。既存の DirectionalLight3D を使い、各面の明暗で立体感を出します。発光成分を抑え、光による明暗が見えやすくしています。攻撃を受けた際のカラー変化は維持します。

## 変更していないもの

- `KeyLight.shadow_enabled = false`（床へのリアルタイム落ち影なし）
- ターゲット・プレイヤー双方のダークグレーの丸い影とサイズ
- v37の床グリッド色・線幅、正のダメージ表記
- 剣エフェクトと前方オフセット0.55m、攻撃判定、操作、アニメーション、カメラ

## 動作確認の目安

1. 初期位置ではレティクルがシアン。
2. プレイヤーをターゲットに近づけ、キューブ表面から0.75m以内になると赤。離れるとシアン。
3. 近接攻撃中に自動接近しても赤へ切り替わる。ターゲット撃破時はシアンに戻る。
4. キューブの上面と側面に光の当たり方による濃淡があり、丸い影はそのまま。
