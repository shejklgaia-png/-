# SERA v295 — 格闘後の歩行モーションとRUN進行方向の修正

## 不具合の原因
- RUNの腰骨格は進行方向から正しく方位を計算していましたが、±25°の制限と、RUNにも適用されたボス正面ロック補正によって最終表示が正面へ戻されていました。横方向へのRUNでは特に脚の向きと移動方向が一致しませんでした。
- 格闘中のRUN再生状態は次のレンダリングフレームで初期化される仕様だったため、格闘開始・終了が同じフレーム内で進む場合、直前の走行方向や後退モードが残る可能性がありました。

## 修正
- RUNの腰・脚は移動方向に適切に向けます。後退セクターでは後ずさりを維持し、胴体・胸・首・頭の追従でボスを確認します。CharacterBody3Dの物理向きとロック先は変えません。
- STEPとBOOSTのボス正面方向補正は維持。RUNだけ二重の方向補正を解除します。
- 格闘・ガード・STEP・ダメージなどでRUN以外のクリップへ移った時点で過去の方向・旋回状態を破棄します。RUNに戻る時は今の操作方向から再計算し、既存フェードを維持します。
