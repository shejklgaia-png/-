# SERA v486 — ビットタランの縦振動・攻撃別画面シェイク

## 振動の区別
- **踏みつけ**：接地時に、ヒット／空振りに関係なく大きな画面振動。急速に収束する減衰率13.5/s。
- **弾き**：命中または土埃の初期発生時に、非常に大きい一瞬の衝撃（強度0.38、減衰率20/s）。攻撃1回に追加ヒットは発生させない。
- **なぎ払い**：原本攻撃のstrikeフェーズ中に、強度0.16の中揺れを0.14秒間隔で継続。予備動作・復帰中は追加しない。命中後も攻撃中は継続する。
- **歩き**：足の着地のたびに、足先とプレイヤーの水平距離を基準として強度0.20（0m）〜0（10m）をsmoothstep補間。5mで半分、10m以上では振動ゼロ。カメラの高さには左右されない。
- **揺れ方向**：水平重み0.60、縦重み1.55。従来の縦0.70に対して上下振動を強調。振動終息後はカメラの水平・垂直オフセットを厳密にゼロへ戻す。

## 継続する仕様
- ビットタランの原本メッシュ、14関節・IK・攻撃タイムライン、足先接触・攻撃当たり判定、ダメージ・ノックバック、レールガンの追尾・音声と土埃VFXはそのままです。
- 既存のカメラ追従計算やズームを変更せず、カメラ投影オフセットだけで揺れを表現します。

## CIと実機確認
- 実装前に既存のCI登録・CI仕様・ゲームカメラ処理を調査。従来の攻撃判定テストは変更不要と判断しました。
- 新規 `tools/bittaran_camera_shake_runtime_check.gd` を実装前に作成し、`tools/sera_ci_manifest.txt`へ登録。4種の振動強度・減衰、上下優位、なぎ払いの繰り返し・終息、0/5/10/12m距離補間とゼロ復帰を検査します。
- マージ後main上で登録済みの全Python/Godot CIを実行。Android実機では大揺れの見え方、歩行中10m境界、連続なぎ払いの酔いにくさをご確認ください。
