# SERA v289 — 破壊部位のロック維持・正面ターゲット・部位被弾FX・バク宙後RUN復帰

## 1. 連続攻撃中は破壊済み部位のロックを維持
- 破壊時に`locked_target_part_id`を即座に空文字へ戻していた処理を撤廃。
- **通常格闘3連・バッシュ・左右蹴り・後方サマーソルト・着地中および派生受付0.65秒**の間は、破壊された部位も元のID・照準位置・攻撃判定のAABBを保持します。
- 破壊部位の耐久値は0のまま、以降の攻撃は従来同様にボス共通HPへダメージを与えます。新規の自動・手動選択では破壊済み部位を選びません。
- **連続攻撃が完全に終了した後**、使用可能な部位を再選択します。マニュアルロックで破壊された場合も、終了時だけ正面部位を再取得します。無傷のマニュアル選択は維持します。
- ボス共通HPが0になった場合の再生も、連続攻撃中なら終了後まで延期します。

## 2. 正面部位の優先選択
- セラから**敵全体の中心点（カメラ回転軸）**へ向かう水平ベクトルを前方基準にします。
- この軸と各部位への方向との角度差が小さい部位を優先し、セラより後方にある部位と、ボス本体・他の部位で遮られる部位は候補から外します。
- 角度の近い候補間では従来のヒステリシスを維持し、左右の細かい移動で照準が頻繁に切り替わるのを防ぎます。
- 入力フリックの方向や通常の360°ステップ操作は変更しません。

## 3. 破壊後も部位を表示
- 前脚を破壊すると従来`pivot.visible=false`にして消していましたが、**頭と4脚すべてを破壊後も表示**します。
- 破壊後は暗い損傷色に変え、破壊フレームや元の脚部造形を表示したままにします。移動用のコリジョンも維持し、見た目だけ残ってすり抜ける状態を防ぎます。

## 4. 部位ダメージの演出を本体と統一
- 各部位に、本体と同じ**0.145秒の暗赤色フラッシュ・発光と微細な揺れ**を追加。命中したパーツにのみ適用し、ほかの部位を同時に点滅させません。
- 通常格闘・左右蹴り・サマーソルト・バッシュの命中すべてに適用。破壊と同時に発生したFXも、その後の損傷色へ戻ります。
- 既存の本体HPフラッシュ、着弾位置の火花・ダメージ表示・SEは維持しています。

## 5. バク宙後にRUNが再生されない不具合
- バク宙前に`BACK_KICK_TRACK`が使用する`start_melee_approach()`によって、リグ内部`combat_playback`がtrueのまま残る経路を特定しました。
- **`start_back_somersault`と`finish_jump`の両側で戦闘再生フラグを解除**し、着地後に`set_moving()`を通常どおり受け付けられるようにしました。
- さらに、着地直後も指をホールドしている場合は、現在のスティック位置からRUN方向を再計算します。バク宙→着地0.2秒→RUNの連結を維持します。
