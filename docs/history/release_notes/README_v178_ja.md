# SERA v178 — 移動する訓練ターゲット・攻撃別HPダメージ

## 訓練用ターゲットの移動
- これまで静止していた赤いキューブが、地上で左右にストレイフし、セラとの距離に応じて接近・後退します。初期位置 (0, -8m) を中心とする半径10mの試験範囲内を最高1.55m/sで移動します。
- ボスの攻撃予告中は、発射位置と予告方向の整合を保つため、**移動停止**。既存のAIM/LEAD/SHOCK/ARCは予告開始時の狙いを維持します。
- 弱怯み・部位破壊大怯み・HP0・訓練KO中も停止します。
- 赤いキューブの見た目・判定・床影・敵AIの射撃発生位置は同じ移動基準に追従します。元のカメラやロックオン追従アルゴリズムは変更せず、動くターゲットの最新位置を使用します。
- 物理コライダーは `AnimatableBody3D` に切替え、すり抜け回避のためプレイヤーと新規に重なる移動を抑止します。
- 訓練用 **MOVE: ON/OFF** ボタン（初期値ON）で移動有無を比較できます。画面タッチは攻撃・移動に伝播しません。

## ターゲットの4攻撃に個別のHPダメージ
| 攻撃種別 | 基礎HPダメージ | ガード時の基礎SH消費 |
|---|---:|---:|
| AIM（直線射撃） | 18 | 23 |
| LEAD（偏差射撃） | 22 | 28 |
| SHOCK（衝撃波） | 28 | 36 |
| ARC（扇形攻撃） | 34 | 42 |

- 非ガード被弾時：`実ダメージ=基礎HPダメージ×(1-5部位の平均防御率)`。A/B装備の防御差が反映されます。
- ガード成立時：HPは減らず、SHが左手武器と両腕の補正を受けて減少。SHが0になればその攻撃で即ガードブレイクします。
- ガードブレイク中に追加被弾した場合も、攻撃種別に応じたHPダメージと脚のダウン耐性判定を適用します。ダウン中は無敵です。
- どの攻撃が当たったかは、発射/範囲展開時に確定し、途中でデバッグ選択を変更しても入れ替わりません。従来の射撃・エリア攻撃ごとの効果音も維持します。
- HUDに残HPと、短時間の赤い「-XX HP」数値を表示します。既存のTEST HIT / TEST BREAKも維持します。

## 訓練用KOと復帰
- セラのHPが0になると入力と敵攻撃を停止し、2.5秒後に訓練を自動再開。セラHP/EN/SHは満タン、セラ位置/ターゲット位置/コア耐久は初期状態に復元します。**これはTRAINING専用の仮動作で、正式な敗北条件・報酬処理ではありません。**
- 通常のシールドブレイク→ダウンは従来通り、ダウン中無敵・敵から4m離れる・起き上がり時EN/SH全回復です。

## 実機確認手順
1. GitSyncでmainを同期し、Godot `SERA v178` を起動します。
2. TRAININGに入り、MOVE: ONでターゲットの横移動・後退・接近を確認。MOVE: OFFで静止状態と比較します。
3. AIM/LEAD/SHOCK/ARCをそれぞれ選んでFIREし、HP表示と赤い被弾ダメージ数値を確認します。
4. A一式・B一式で同じ攻撃を受け、防御差、ガード時SH消費差を比較します。
5. TEST BREAKから追加被弾でダウンさせ、無敵と復帰時のEN/SH全快を確認。HPを0まで減らし、訓練自動再開を確認します。
