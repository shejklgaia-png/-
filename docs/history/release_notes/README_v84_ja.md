# セラ v84 — セラ式・剣エフェクト制作メソッド

## 実装概要
- v83の3段コンボ、移動、ステップ、追従カメラ、被弾、射撃AIを維持。
- 添付 `SERA_melee_combo_3.bbmodel` から **Swordeffectボーンのアニメーションのみ** を `melee1`、`Melee2`、`Melee3` に移植。ほかのアニメーション（Damageknock等）はv83を維持。
- Blockbenchの `Swordeffect` 四角形メッシュ（4頂点、2三角形）をそのまま表示メッシュとして共有。元の無地板はランタイムで非表示。
- 白／赤の透過PNGスプライトシート（4列×2行・8フレーム、モバイル用各1024×512px）を `StandardMaterial3D` のUV1スケール／オフセットで切り替え。新しいシェーダーやパーティクルは使用しない。
- メッシュは `Swordeffect` ボーンの子に配置。**回転・位置・拡大縮小の自動補正は一切しない**（過去の前方0.55mオフセットも撤去）。カメラ正対／ターゲット自動追従なし。
- エフェクトの位置・角度・大きさはBlockbenchで決定し、Godotではテクスチャフレームと表示・非表示のみ管理。
- 既存の白／赤シートを再利用（新規モバイル解像度1024×512へ縮小）。デスクトップ確認用の高解像度原本は `assets/slash_C_{white,red}_clean_4x2.png` に残している。
- スプライトシートの描画開始は通常0.075秒、終了0.485秒。3段目のみv83からの0.210秒オフセットを維持（0.285〜0.695秒）。
- 既存のCキーによる赤系カラーパレット切替を維持。

## Blockbench側の現状
- `melee1`：板のキーは0.0秒の位置・回転・拡縮。
- `Melee2`：位置・回転のキーは0.16667秒、拡縮は0.0秒と0.33333秒。
- `Melee3`：板のキーは0.0秒の位置・回転・拡縮。
- これらは**連続した板の移動モーションではない**。今回の実装は指定の配置を尊重し、テクスチャ側の時間変化で剣閃を再生する。今後Blockbenchで中間キーを追加すればエフェクト板の位置・角度も追従する。

## 変更ファイル
- `scripts/sword_trail.gd`：旧v35切り抜き/レンズ/粒子描画から、指定板上のUVアニメ再生へ変更。
- `scripts/sera_rig.gd`：旧0.55m配置補正を撤去。
- `scripts/main.gd`：コメント更新のみ。
- `assets/sera_source.json`、`assets/sera_data.gd`：更新モデル、埋め込みデータ。
- `blockbench/SERA_melee_combo_3_v84.bbmodel`：統合編集モデル。
- `assets/sword_fx_white_4x2_mobile.png`、`assets/sword_fx_red_4x2_mobile.png`：モバイル用8フレーム。
- `project.godot`、`DEVELOPMENT.md`、本書・静的検証ツール。

## 注意事項
- 元のv83切り抜き立体効果・粒子表現は今回の手法では表示しない。命中時の独立ヒットエフェクト (`hit_burst.gd`) は変更なし。
- Godot 4.7.2本体およびAndroid端末での実機動作・映像確認は未実施。静的チェックでは描画品質を保証できない。
