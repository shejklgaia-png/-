# SERA v360 — ビットタランのロック対象より奥でコントローラが180°上へ反転する問題

## 問題と修正

ビットタランのロック対象よりセラがカメラ奥側へ回ったとき、頭部などの高さがある部位では、カメラの俯角と遠近法によって**3Dの実際のロック点の画面位置**がセラより上へ投影されることがありました。そのため、地面で見ればロック対象が手前にあるのに、コントローラの前方向だけが180°近く上を向く場合がありました。また、カメラ背面などで座標投影が無効になった際、固定の上方向へ戻る問題もありました。

今回、ビットタラン専用の方向計算`scripts/bittaran_controller_axis.gd`を導入しています。

- **正しい3D画面方向と水平方向が一致するとき**：従来どおり、セラのカプセル中心→実際のロック部位の3D中心を投影します。
- **頭部などの高さによって向きが大きく食い違うとき**：セラと部位のXZ平面上の前後関係を基準として、連続的に補正します。頭部のロック位置やマーカー自体は移動させません。
- **カメラとの位置関係で投影できないとき**：上方向固定にせず、カメラの向きとロック対象のワールド水平位置から方向を求めます。
- **入力を押したままロック対象・カメラが動いたとき**：通常の自由操作中はコントローラ表示とフリック判定を追従させます。確定済みのコンボ・ガード入力の基準は途中で変えません。

ダウン中のHEAD AUTOロック、脚ロック、カメラ追従、STEPの移動方向は変更していません。

## 検証

`tools/v360_bittaran_controller_depth_runtime_check.gd`で、実際に**3D投影が反転するカメラ・頭部の高さ・セラの位置**を再現し、奥側でもロック方向が正しく向くこと、カメラ背面でも固定の上へ飛ばないこと、ガイドと入力方向が一致することを検証します。
