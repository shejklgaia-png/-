# SERA v522 — Androidで空白だったアイテム一覧を標準ボタンで再構築

## 実機の報告
v518からv521まで、画面上部のメニューは表示されるのに、装備製作・素材変換・倉庫のアイテム一覧だけが真っ白／暗い空白でした。v521のスクリーンショットで現象が継続していることを確認。バージョン未更新ではありません。

## 改修
- スロットの描画を、GDScript製PanelContainer＋GridContainerの構成から**Godot標準Button＋HBoxContainerによる3列配置**へ全面変更しました。
- 7つの試作装備、12種類の素材、倉庫の素材12種と装備7種は所持0個でも表示します。
- Buttonの標準テキスト・標準アイコン描画を利用。選択可能なカードは枠全体がタップ範囲です。
- 四隅を45度に欠いた枠は、新しい48×48のアルファ付き画像を9スライスするStyleBoxTextureで表示します。
- 受け取った素材、製作品のUID、NEXUS装備選択、素材変換計算と保存、戦闘系の仕様は変更していません。

## 表示検査
- 以前のheadless CIは見えていないUIノードの存在と座標を成功としていました。新規v522静的/実Godot検査を、実装前に作成・登録し、旧v511/v517/v518/v519/v521表示テストも新しい描画構造へ更新しました。
- 新たにGitHub Actions内のXvfb仮想ディスプレイ＋Godot OpenGL実描画でスクリーンショットを出し、カード内の青緑の枠ピクセルを検出する検査を追加しました。スクリーンショットはCI成果物として保存します。
- 実際のAndroid端末における最終画面はこの仮想ディスプレイとは異なるため、ユーザーの目視確認をもって完了判定します。
