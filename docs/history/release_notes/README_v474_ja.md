# SERA v474 — 10秒間は完全静止充填、球体開始から照射完了まで継続追尾

## 確定した1サイクル（初回／連続周回とも同じ）

| サイクル開始からの時間 | フェーズ | 照準・演出 |
|---|---|---|
| **0.0〜10.0秒** | 充填10秒 | **砲台は基本姿勢を維持。プレイヤーを追尾しない。** 左右3本の充填バーが時間に合わせて満充填へ進みます。 |
| **10.0〜12.0秒** | 青い球体チャージ2秒 | **追尾開始。** 最初の0.7秒で基本姿勢から追尾へ滑らかに移行します。球体は最初0.2秒で膨張、最後の1秒で収縮。青い外縁と稲妻は維持します。 |
| **12.0〜14.0秒** | レーザー照射2秒 | **追尾を一切止めず、速度も切り替えず、球体終了と同時に照射開始。** 追尾の瞬間補正・発射待機・照射開始後の無判定遅延はありません。 |
| **14.0〜14.7秒** | 基本姿勢へ復帰0.7秒 | **照射終了と同時に**追尾を停止し、最終角度から基本姿勢へsmoothstep補間で復帰。保持時間はありません。 |
| **14.7秒以降** | 次サイクル | 再び10秒間は基本姿勢で充填し、同じ順序を繰り返します。 |

**1サイクル14.7秒**で、ユーザー指定の**追尾禁止の充填時間10秒**を独立して確保します。従来の「10秒ごとの照射」ではなく、**10秒充填後に追尾付き球体チャージ→レーザー照射**です。

## 追尾速度：通常移動では避けられず、BOOSTでは振り切れる
- **通常RUN速度4.0625m/秒、BOOST速度6.09375m/秒**を採用し、その間の65%位置に相当する**移動換算5.3828125m/秒**を砲台追尾の上限とします。
- 砲台からプレイヤーまでの水平距離（最低1m）で割って角速度に変換するため、**近距離でも遠距離でも、RUNでは振り切りにくく、BOOSTなら振り切れる追尾速度**になります。
- 装備でRUNまたはBOOST速度が変わる場合は、`part_stats`の実際の装備速度を使って追尾角速度を再計算します。YawとPitchの合成回転も上限内に収め、ボス本体旋回で追尾速度を増やしません。
- 追尾の入り0.7秒はsmoothstepの重みで、追尾の抜け0.7秒は最終角度から基本姿勢までのsmoothstep補間です。
- 追尾は球体開始からレーザー終了まで連続しており、**球体→レーザーの境目で照準がワープしません。**

## ダメージと演出
- **発射待機0秒**、**レーザー開始後のダメージ判定猶予0秒**。照射が見えた最初のフレームから、実際に射線上にいる場合に当たり判定があります。
- 被弾しても、レーザー側の2秒照射は停止しません。SERAのHP/ガードへのダメージはあり、レーザー被弾によるノックバック・BOOST中断は発生させません。
- 球体の青縁明滅・分岐稲妻、レーザーの流動プラズマと電撃、45m射程、当たり判定半径、0.5秒ごとの被弾間隔は既存のままです。
