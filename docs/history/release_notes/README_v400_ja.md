# SERA v400 — ビットタラン攻撃モーションの3件の不具合を修正

ビットタランの攻撃モーションについて報告された3件（弾きの角度異常、なぎ払いの脚の埋没、踏みつけの足先の向き）を、実シーンで再現・計測して修正しました。原本キーフレーム、攻撃のタイミング、ダメージ等の数値は変更していません。

- **弾き（KICK）が左前脚以外で異常な角度**：伸び切った瞬間の足の傾きは左前脚9°に対し右前脚41°／左後脚87°／右後脚107°でした。原因は、左前脚の原本を他脚へ写す「Wait姿勢からの差分＋成分反転」変換が、親関節（屈んだ胴体や折れた脚）の回転した座標系では成り立たないことです。修正として、打撃の入りに合わせて肩と膝だけを「ワールド空間で鏡像化した原本姿勢」へブレンドします（脚が離地してから効かせるため、予備動作で足裏が接地する折り畳みは従来の差分方式のまま全脚で維持）。修正後は全脚9〜12°に揃いました。
- **なぎ払い（SWEEP）の前腕部分が地面に埋まる**：打撃中、下腿のメッシュが床下へ前脚−1.22m／後脚−1.57mまで入っていました（足先だけは従来補正で床上に維持）。修正として、既存の「足先を床下に沈ませない平行移動補正」を脚全体に広げ、脚の最下点が床を割った分だけ股関節ごと平行に持ち上げます。原本の関節角度は変更していません。
- **踏みつけ（STOMP）の足先**：着地の瞬間、足先の長軸が垂直から約63°傾いていました。原因は、着地姿勢の計算が「足の長軸はローカル−Y方向」という前提で組まれていたのに対し、実モデルでは長軸がローカル±X方向だったことです。実メッシュから長軸を実測して保持し、着地姿勢を「その長軸が真下を向く」形に組み直しました。あわせて、着地点の基準点（従来は足先の中ほど）も実際の先端面中心へ正し、復帰開始時に足裏が約0.94m瞬間移動する不具合も解消しています。修正後は長軸が正確に垂直となり、先端面が狙った位置に接地します。
- **検証**：新たに `tools/v400_bittaran_attack_motion_runtime_check.gd` を追加し、全脚について「弾きの伸展時の足の傾き20°以内・予備動作での足裏接地」「なぎ払い中の脚メッシュ最下点が床下に入らないこと」「踏みつけ着地で足先が垂直・接地すること」を検査します（修正前はなぎ払いの埋没−1.22mで失敗）。また、旧前提（+Yが上＝足先が垂直）で書かれていた既存チェック4件（v384／v385／v387／v392）は、実メッシュから測った足先軸で判定するよう更新しました。全件CIスイート（静的182件＋Godot 136件）が合格しています。Android実機での見た目は別途確認が必要です。
