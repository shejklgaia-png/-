# SERA v216 — スラスター加速バースト

STEPや格闘追尾など、短時間に大きな加速が生じる動作で、背面スラスターの噴射が一瞬大きく広がる演出を追加しました。

## 演出
- **加速開始から約0.035秒**：通常の四角い噴射筒が先端に向かって扇状に広がります。先端の幅は最大約2.8倍、長さは最大約1.28倍になります。
- **続く約0.18秒**：広がった噴射が自然に収まり、従来の細い四角筒へ戻ります。
- 合計約**0.215秒**。広がりの頂点では発光も一瞬強くなります。根元はノズル口の幅を維持し、既存の揺らぎアニメーションも残します。

## 発動する動作
| 動作 | 発動条件 |
|---|---|
| 360°のSTEP（前・後・左右・斜め） | 開始フレームに1回 |
| 格闘追尾（DASH / STRIKE_TRACK / STRIKE） | 実際の移動がある追尾開始・モード切替時に1回 |
| バッシュ追尾（BASH_TRACK / BASH） | 実際の移動がある追尾開始・モード切替時に1回 |
| 通常BOOST・方向転換 | 従来の通常噴射を維持し、連続フレアは発生させません |
| 重量脚部の通常SLIDE | 背面噴射・バーストなし |

アニメーションの同じ状態が継続している間、毎フレーム拡散し直すことはありません。別の追尾動作に移行した場合は新しい加速として再発動できます。

## 技術的な変更
- `scripts/main.gd`でSTEP・追尾の開始エッジを検出します。
- `scripts/sera_rig.gd`、`scripts/sera_equipment.gd`を通じて、選択中BOOSTERの左右ノズルに同一のバースト信号を送ります。
- `scripts/back_thruster_fx.gd`で0.035秒立ち上がり・0.18秒減衰の時間包絡を計算し、`shaders/back_thruster.gdshader`の`burst`パラメータで既存の四面メッシュを変形します。追加の粒子オブジェクト・テクスチャ・Blockbench元データは不要です。
- スラスターの向き（下向き既定、左側の画面下→右扇形、後退時下90°）とノズルPivotには変更がありません。

**移動速度・ステップ距離・EN消費・攻撃の当たり判定は変更していません。** Android実機描画は未検証です。
