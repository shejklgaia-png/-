# SERA v347 — ビットタラン2倍化と低重心IK

## 変更内容

- ボス全体を一様に2倍へ拡大（`target.scale = Vector3.ONE * 2.0`）。モデルだけでなく、関連するボスの当たり判定とロック位置も同じ倍率で拡大します。
- 頭・胴体・脚の元BlockbenchメッシュとWait初期姿勢は変更しません。
- IK側で親ノードの2倍スケールを考慮し、関節・足先のグローバル回転と実寸を両立させます。
- 胴体をワールド基準で0.34m下げ、脚の基準接地点を胴体側へ0.42m寄せて4脚すべての膝を深く曲げます。IKの最大到達距離を人工的に切り詰める処理は採用していません。
- 対角ペア歩行とワールド固定の足裏接地は維持し、拡大後の歩幅と足上げを調整します。
- 2倍の体格に合わせてAIの停止・再接近距離を拡張しました。視野角100°、接近速度0.72m/s、停止時旋回34°/s、歩行中旋回22°/sは変更していません。

## 検証

- `tools/v345_bittaran_runtime_check.gd`：出撃・戦闘シーン・AIの移動・視野角。
- `tools/v346_bittaran_ik_runtime_check.gd`：実サイズ2倍の4脚接地・対角歩行・足上げ・旋回・初期化。
- `tools/v347_bittaran_scale_crouch_runtime_check.gd`：モデルと当たり判定の2倍化、胴体が世界座標で0.34m低いこと、4脚の折り畳み比率が低下していること、床接地。
- Godot 4.7.2専用CIで上記に合格。脚の伸び比率は元姿勢の平均0.674から新姿勢0.557へ（全4脚で屈曲増加）。
- Android実機での見た目・接地感・重量感は別途目視確認が必要です。
