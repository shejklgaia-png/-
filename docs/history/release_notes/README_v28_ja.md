# セラ v28 — 剣軌跡の前方移動版

## v27からの変更
- 剣軌跡エフェクト `Swordeffect` **だけ**を、プレイヤーが向いている前方（プレイヤーのローカル **−Z**）に **0.55m** 移動しました。
- 既存のBlockbenchのメッシュ・キーフレーム・UVシート・斬撃デザイン・攻撃判定・カメラ・ドラッグ移動・音と火花は変更していません。
- 平面の回転や拡大率は変更せず、エフェクトルートの平行移動のみ行います。ターゲットの周りを移動しても、前方の定義は常にプレイヤー基準です。

## 距離を微調整する場合
`scripts/sera_rig.gd` の冒頭付近：

```gdscript
@export_range(0.0, 2.0, 0.05, "or_greater") var sword_effect_forward_offset: float = 0.55
```

数値を大きくするとさらに前に、小さくすると手前に表示されます。`0.0` でv27の元の位置に戻ります。数値はGodot空間でのメートルです（v27の `UNIT=0.065` を使用）。

## 起動
1. ZIPを展開し、Godot 4.7.2で `project.godot` を開きます。
2. ▶で実行します（Android縦画面対応）。
3. 短いタップで攻撃して剣軌跡の位置を確認してください。ドラッグで移動します。

## 検証について
`tools/v28_validate.py` で、エフェクトだけのオフセット適用、元モデル・テクスチャ・戦闘スクリプトの不変性、ローカル参照の整合性を静的に確認できます。
Godot本体・Android実機による画面上の実行検証は、この環境では実施していません。
