# SERA v218 — 短い距離で一気に15倍へ拡散するスラスター

## 変更した形状
加速バーストの噴射が、**ノズルの出口から噴射長の25%に到達するまでに、通常幅の15倍**まで広がります。従来は噴射の全長を使って徐々に5倍まで広がっていました。

| 項目 | v217 | v218 |
|---|---|---|
| 最大幅 | 通常の5倍 | **通常の15倍** |
| 最大幅に達する位置 | 噴射の先端（100%地点） | **噴射全長の25%地点** |
| 噴射口の幅 | 通常の1倍 | 通常の1倍（変更なし） |
| 拡散にかける時間 | 0.10秒 | 0.10秒（変更なし） |
| 収束時間 | 0.18秒 | 0.18秒（変更なし） |
| 総演出時間 | 0.28秒 | 0.28秒（変更なし） |

噴射口からすぐに広くなる形状ですが、入口そのものは拡大せず、ノズル本体から噴射がはみ出しません。拡散ピークが過ぎると、従来の細い四角筒に自然に戻ります。

## 実装上の変更
以前の噴射筒は根元と先端の2断面しか持たず、GPUで先端を拡大しても、中間地点で急激に広がる形状を表現できませんでした。

今回、既存の四角い噴射筒を長さ方向に**12分割**し、途中に変形可能な断面を設けました。頂点シェーダーの幅倍率を `1 + 14 × burst × smoothstep(0, 0.25, along)` に変更し、噴射全長の25%時点で最大15倍へ達するようにしています。

メッシュの細分化はエフェクト専用で、Blockbench原本やノズルPivotは変更していません。追加テクスチャ・パーティクルもありません。

**STEP・格闘追尾・バッシュ追尾の発動条件、スラスターの方向、EN、移動速度、モーション、0.28秒の演出時間は従来どおりです。**

検証は `tools/v218_thruster_short_15x_flare_self_check.py` と既存のCIで実施します。Android実機の描画確認は未実施です。
