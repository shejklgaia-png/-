# SERA v537 — カスタマイズ操作と部位選択表示

## 2026年11月22日の変更点
- NEXUSカスタマイズの全身3Dプレビューで上下ドラッグ方向を反転。ドラッグ中のモデル並進補正・倍率補正は削除し、回転だけにします。初回画面フィットは維持します。
- 選択中の部位は青白い発光を明確に点滅させます。1.0秒周期で0.60秒点灯、0.40秒消灯します。
- 右側の装備リストは現在閲覧中の部位の行を明るく表示します。名前で詳細を見る操作と右端のボタンで換装を開く操作は従来通りです。
- ビットタランの初期距離12mとHUD配置、および装備・戦闘の性能値に変更はありません。
