# SERA v164 — 6部位カスタマイズ（2026-11-09）

## 変更内容
- NEXUSのCUSTOMIZE右側メニューに6部位（頭・胴・下半身・腕・右手武器・左手武器）のセット選択を追加しました。
- **現状はA・Bの2セット**です。Aは従来のSERAモデル、Bは`models/SERA_BOOSTER_allテスト.bbmodel`内の`Waist2`ツリーです。Bの`Head2`には球体メッシュ`sphere`が入っています。Cセットは未制作のため、選択肢には表示しません。
- 同じ`.bbmodel`に全身セットを追加する制作方式に対応します。独立したモデルファイルは不要です。
- カスタマイズ画面の右メニューで各部位の行をタップします。**行の左45%で前のセット、右55%で次のセット**へ変更します。候補が1種類しかない部位は切り替わりません。
- 選択内容は`user://sera_equipment.cfg`に記録され、NEXUSとTRAININGの両方で同じ外見を使用します。
- アニメーションは既存のAリグのボーン・UUID・モーションを共有し、選択されたメッシュのみ表示します。元の攻撃・ガード・走行・ブースト等のロジックは変更していません。

## Blockbenchでのモデル制作
1. 現在の`models/SERA_BOOSTER_allテスト.bbmodel`を編集します。
2. Aセットは`Waist`、Bセットは`Waist2`として既に存在します。Cセットは`Waist3`以下にTポーズの全身構造を複製して制作します。代わりに`SET_A`/`SET_B`/`SET_C`で全身ルートを囲む形式にも対応します。
3. 首・肩・腰・肘・膝などの**ピボット位置と親子構造**を基準モデルに揃えてください。メッシュ名を`sphere`などに変えても、親グループと構造からパーツを抽出します。
4. スマホのGodotエディタでは、この`.bbmodel`がアクセス可能なら直接読み込みます。書き換え後はGodotプロジェクトを再読み込みして更新を反映してください。
5. Android APK等の単独エクスポート前は`python3 tools/rebuild_equipment_data.py`で`assets/sera_equipment_data.gd`を再生成し、GitHubへ反映してください。これにより`.bbmodel`の同梱がないビルドでも最新セットを使用できます。

## 実装上の注意
- セット検出はモデルの全身ルート（`Waist`, `Waist2`, `Waist3`など）の登場順です。現行A/Bに対し追加する場合はBの次にCを置きます。
- 部位の判定はメッシュ名に依存せず、追従先ボーンの階層と左右を使用します。改名されたボーンは同階層の名称とピボット位置で照合し、曖昧な候補は誤装着防止のためスキップします。
- ボーン座標が大幅に異なるセット、またはセット固有のアニメーション／装備固有ヒットボックスは本版の対象外です。
- Aの戦闘用正本は従来の`assets/sera_source.json`と`assets/sera_data.gd`です。B/Cの姿形を装着する際に既存アニメーションの正本を差し替えません。
