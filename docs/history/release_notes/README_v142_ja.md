# SERA v142 — カメラ後退時のセラ格納経路修正（2026-11-08）

### 修正内容
v141では、カメラが0.18秒で先に全景へ引く一方、セラの世界座標での直線移動は0.28秒続いていました。そのため、視点の変化とセラの位置が合わず、一度画面外へ出たあと展示台側から出現するように見えていました。

v142では、移動の両端を**カメラから見た相対位置・姿勢**に変換し、移動中も現在のカメラ姿勢へ掛け戻します。拡大位置から展示台へ、画面上で連続して縮小・移動する軌道を狙った修正です。入場・格納の両方向を同じ計算で処理します。

- CUSTOMIZE選択：展示セラの元の表示位置→左上拡大位置をカメラ相対補間します。
- 戻るボタン／Android戻る／Esc：回転済みセラの表示位置→展示台の位置をカメラ相対補間します。
- セラ0.28秒／カメラ0.18秒は変更せず、両方が同時に開始します。
- 3区画のメニュー、NEXUS_pose、固定背景グリッド、モデルとゲーム本編のデータは変更していません。

静的回帰検証：`tools/v142_camera_relative_transfer_self_check.py`。数式上の画面内位置移動の連続性と、ソース中の相対座標変換・開始終了の同期を確認します。Godotの実描画／Android実機での確認は未実施です。
