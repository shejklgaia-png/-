# セラ v43 — ロックオン円を1回転に変更

v42の円の回転数のみ、**2回転（720°）から1回転（360°）に変更**しました。アニメーション時間は**0.20秒**のままです。

- **近接距離に入る：** 時計回り1回転（360°）、半径62px→42pxへ縮小、0.20秒
- **離れる：** 反時計回り1回転（360°）、半径42px→62pxへ拡大、0.20秒
- **近接時：** 赤、線幅5px
- **通常時：** シアン、線幅2px
- **中央の十字：** 回転しない
- **途中反転：** 現在の角度・半径から逆方向に1回転

変更ファイルは `scripts/touch_overlay.gd`、プロジェクト名、READMEだけです。その他の動作はv42と同一です。

静的検証とZIP整合性検査を実施。Godot本体・Android実機での起動確認は未実施です。
