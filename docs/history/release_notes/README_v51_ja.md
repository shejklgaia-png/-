# セラ v51 — ターゲット2m以内でステップ6m/秒

## 変更点

- **ステップ開始時**のプレイヤー中心とターゲット中心の**水平（XZ）距離が2.00m以下**：移動速度を **6.0m/秒** に設定します。
- **2.00mを超える場合**：従来どおり **10.0m/秒** です。
- 一度始まったステップは、途中の距離変化によって速度が切り替わりません。
- 右上の速度ラベルは、通常時には「今フリックした場合の速度」、ステップ中には「そのステップの速度」を表示します。

## 維持する仕様

- 基本回り込み角度35°、希望移動距離1.5〜4.0m、最大所要時間0.40秒。
- 移動は敵を中心とする円弧。極端に敵中心へ重なった場合は直線フォールバック。
- 近距離の希望移動距離は1.5mとなるため、標準的には **1.5/6=0.25秒**（衝突のない場合）。
- ターゲットとの物理衝突判定（v50）、通常ドラッグ、左右フリック、攻撃、カメラ、モデル、エフェクトは変更なし。
- 障害物に当たったときは、物理貫通防止を優先します。実移動距離は1.5m未満となる可能性があります。

## 検証

`python tools/v51_close_step_self_check.py` を実行すると、速度境界条件・移動計算・モデル／スクリプトの維持を静的にチェックできます。Godotエンジンの実行、およびAndroid実機での入力確認は未実施です。
