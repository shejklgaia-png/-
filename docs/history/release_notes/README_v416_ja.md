# SERA v416 — ビットタラン後足弾きの接地軌道・右前足先の連続攻撃捻れ修正

## 実シーンで確認できた不具合

- v415の後足の弾きは、原本の**肩・膝・足先の回転**を維持していましたが、v414で独立して反転させた胴体ピッチによって**肩のワールド位置（股関節ソケット）**が大きく上昇していました。原本から反転・転写した足先軌道は、その上がった股関節を起点とするため地面を這いませんでした。
- 修正前に連続8回の実シーンで測定した、原本の弾きの伸長区間（source t=0.35〜0.60）のメッシュ最下点は、左後脚0.84〜2.51m、右後脚1.14〜2.81mでした。v415の原本回転テストとv408の「ある瞬間に地面に近い」テストでは、この問題を検出できませんでした。
- 同じ条件で弾きを連続再生すると、右前脚の足先の**ローカル回転**が初回から少しずつ変化しました（8回目で約0.26°）。足先のワールド回転はほぼ一定で、足先と脛の相対角度が履歴依存になっていました。

## 修正

1. **後足3攻撃共通**：独立した後傾25°→前傾25°の胴体姿勢は維持し、原本のBODYキーフレームを別の角度へ置き換えた際、攻撃脚の肩の**ワールド位置とワールド回転**を原本から変えないよう補正します。前バージョンは回転だけでした。胴体ルートの高さは変えず、頭の独立追従・支持脚IKも維持します。
2. **後足の弾き**：足先が地面に沿って伸びる区間に限り、原本の足先のワールド回転と水平方向を保持したまま、接地目標を脚が届く範囲へ移します。足元が床まで届かない場合は、原本の水平到達距離を**必要最小限だけ短縮**してから2リンクIKを解き、無理な伸長・足先のワープを防ぎます。脛などのメッシュが床を貫通する場合は足先のIK目標だけを少し持ち上げて解き直します。胴体の高さや股関節ソケットを追加で持ち上げません。接地補正は動作区間の前後で滑らかにゼロへ戻します。
3. **全脚の弾き、特に右前脚**：前回のIKで捻れた回転を次の弾きのキーフレーム補間の開始点に採用せず、Blockbench原本の不変の`Wait`キーフレームから開始します。通常姿勢へ戻った脚だけに適用し、踏みつけ・なぎ払いの既存の移行動作は変更しません。

## 実機検査と自動テスト

- 新規 `tools/v416_bittaran_rear_ground_right_toe_runtime_check.gd` を全件CIに登録。後足左右を各8回再生し、弾きの地面を這う区間の**80%以上のフレームで、足先メッシュ最下点が地上20cm以内**にあることを検査します。
- 右前脚は近距離のプレイヤー（モデル前方側面）を想定した条件で8回繰り返し、同じ原本時刻および実時間の予備動作〜復帰において、足先のローカル回転偏差が0.12°以下、ワールド回転偏差が0.20°以下であることを検査します。
- v415の原本姿勢検査に**3関節すべてのワールド位置の保持**も追加。v408の足先軌道検査は、後足の床接地を優先した場合だけの高さ方向の許容を変更し、前足の原本軌道検査を維持します。旧v410/v412では脛の床貫通も監視します。
- **Godot headlessの全件CIとビットタラン専用CIで確認済み。Android実機での見た目は未確認です。**

> 注意：後足の床への到達時は、現在の前傾胴体と解剖学的なリーチ制限に合わせて軌道の水平長を最小限補正するため、原本の絶対位置をすべてのフレームで完全再現するものではありません。関節回転・足先の向き・攻撃方向を優先して維持します。
