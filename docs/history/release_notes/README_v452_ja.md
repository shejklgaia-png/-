# SERA v452 — なぎ払い初回の接地ストロークと踏みつけ発動の修正

## なぎ払いの当たり判定

以前は足先を手前に戻す終盤に判定がありました。今回は、**振りかぶりが終わったあと、足先が地面を最初に這い、前から後ろへ払う攻撃部分**だけへ変更しました。

| 攻撃 | 判定可能な原本時間 | 実際の命中に必要な条件 |
|---|---:|---|
| 前左・前右のなぎ払い | 0.75〜1.25秒 | 実際の足先が床に接触＋下肢・足先メッシュとプレイヤーが重なる |
| 後左・後右のなぎ払い | 0.25〜0.75秒 | 同上 |
| 前左・前右の弾き | 0.35〜0.75秒 | 下肢・足先の実メッシュとプレイヤーが重なる |
| 踏みつけ | 下降後、初めて足先が地面に着いた瞬間 | 着地した足先の実幅×1.5の範囲にプレイヤーがいる |

前足は原本の1.25秒以降から明らかに減速し、1.5〜2.0秒は余韻になります。この区間と足戻しにはダメージを発生させません。後足も0.75秒以降の戻りはダメージが発生しません。減速中に足先に接触しても、検証用に1回限りの命中ラッチを解除した場合でさえ被弾しないことを実戦シーンで検査します。

## 踏みつけが発動しなかった原因と修正

ビットタランは攻撃前に最低3歩歩く仕様ですが、至近距離からでも後退していたため、最初の攻撃を選択するころには踏みつけ射程2.85mの外に出て、弾きが優先されていました。

- **至近距離の3歩は円弧を描いて歩く**ようにし、射程内に留まったまま歩行条件を満たすよう修正しました。
- 実戦AIで0.9m、1.65m、2.4m、2.75mに静止するプレイヤーに対して、すべて初回技に踏みつけを選択することを確認しています。
- 前足では原本約1.467秒、後足では約0.985秒の**実際の下降・接地時に1回だけ**着地衝撃とエフェクトが発動するようにしました。演出フラグに依存した後追い判定を削除しました。
- ダメージはショックウェーブ全体ではなく、従来どおり着地した足先の実寸の1.5倍を使います。足先から離れているプレイヤーが自動で被弾することはありません。

## その他

- 土埃は最初の地面を這う攻撃中だけ放出し、残りは自然に消えます。
- 同じ種類の攻撃を連続しない、次の攻撃まで最低3歩歩く、2対角脚の戻しを完成させる仕様は維持しています。
- Blockbench原本のキーフレーム・骨格・メッシュ・再生速度は変更していません。
- Godotの実戦回帰検査を増やしました。Android実機での見た目、当たり判定の体感、FPSは別途確認が必要です。
