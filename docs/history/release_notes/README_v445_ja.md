# SERA v445 — なぎ払い往路終了2.00秒＋各攻撃後の腕の戻りを滑らかに

## 今回の変更

1. **なぎ払い左右の往路折り返し：攻撃開始から3.00秒→2.00秒に短縮**しました。基本姿勢→攻撃開始姿勢への補間1.00秒は維持し、原本のなぎ払い往路0.00〜0.50秒を**均一な0.50倍速で1.00秒**かけて再生します。途中のみのスローモーションはありません。往路折り返し後、原本0.50〜1.50秒は通常1.00倍速です。
2. **すべての攻撃の腕（攻撃脚）復帰補間を滑らかに変更**しました。胴体を先に基本姿勢へ戻してから、攻撃脚を1.20秒で直接Waitの基本姿勢に戻す順序は維持しています。左右のなぎ払い・弾き・踏みつけ、合計6攻撃に適用しました。
3. 以前の3次式smoothstepの代わりに、**5次式smootherstep（6u⁵−15u⁴＋10u³）**を使います。開始と終了で速度と加速度が0へ滑らかに接続し、途中で急に速度が変わる感覚を抑えます。上肢・下肢・足先の3関節に同じ時間関数を使い、各関節の長さ・接続・メッシュの親子関係を維持します。
4. v444の**平面床Y=0に対する足先のめり込み防止IK**、攻撃中の3本の支持脚IK、踏みつけの振りかぶり姿勢を経由しない復帰、ゲーム起動時のビットタラン戦直行はすべて維持します。

## なぎ払いタイムライン

| 攻撃開始からの経過時間 | 動き |
|---|---|
| 0.00〜1.00秒 | 基本姿勢からなぎ払い開始姿勢へ |
| 1.00〜**2.00秒** | なぎ払い往路を均一0.50倍速で再生 |
| **2.00秒** | **往路終了・折り返し** |
| 2.00〜3.00秒 | 復路を通常速度で再生 |
| 3.00〜4.40秒 | 胴体を基本姿勢へ戻す |
| 4.40〜5.60秒 | 攻撃脚の上肢・下肢・足先を5次イージングで滑らかに基本姿勢へ戻す |

従来の1.50秒硬直がある弾き・踏みつけの攻撃終了後も、胴体先行＋攻撃脚1.20秒復帰のままです（総時間：弾き4.64秒、踏みつけ5.39秒）。
