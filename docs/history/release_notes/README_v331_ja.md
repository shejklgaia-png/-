# SERA v331 — リアルタイム回転フリック区画と立ち→歩き着地演出

- タッチ中の既存浮遊コントローラー内へ、フリック4区画（90°ずつ）を半透明の環状扇形で表示：前方は赤、左右は黄色、後方は控えめな青灰色。境界線と着色弧で区画角度を視認でき、指の位置・既存RUN/BOOST表示・全画面タッチは変更しない。
- 通常のRUN/BOOST操作では、セラの3D正面をその時のカメラで投影した角度に毎描画フレーム追従し、角度の揺れを避ける指数平滑化を使う。コンボ／GUARD派生フリック受付中は、実際の入力判定が保存した前方軸にガイドも固定して誤案内を防ぐ。既存の90°攻撃判定、360°STEP、攻撃優先順位は変更なし。
- 停止中 `WAIT_CLIP` から通常RUNへ移る場合のみ、`Jump`にある作者作成の着地キー（0.375～0.500秒）を**0.20秒**に伸長して先行表示。**入りの補間はゼロ**で直ちに着地ポーズへ移行し、最終着地キーをサンプルした後に**0.11秒クロスフェード**で歩行へ切り替える。
- 先行演出は視覚のみ：ジャンプ高度・着地状態や入力ロックを作らず、STEP・攻撃・停止・BOOSTなどが始まる場合は中断して通常の既存モーション制御へ戻す。立ちから歩きへの開始だけで再生し、連続歩行や向き変更では繰り返さない。
- Godot CIは実際の描画関数・リグクリップと切替ゲートを検査。Androidでの最終的な発色、サイズ、操作感は別途確認する。
