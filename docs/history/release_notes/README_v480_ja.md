# SERA v480 — プレイヤーの足音・ビットタラン砲台のチャージ／連続レーザー音

## 使用するユーザー提供音源
| 元の音源 | 実装したファイル | 再生イベント |
|---|---|---|
| `ロボットを殴る2.mp3` | `assets/sera_player_footstep_v480.ogg` | SERAの**左右の足裏メッシュの実接地イベント**。既存のモデル由来`foot_contact`シグナルを使い、接地していない空中では無音。歩行周期を音声から推定しません。 |
| `重力魔法2.mp3` | `assets/bittaran_charge_v480.ogg` | **10秒**の青い球体チャージ開始で1度だけ再生、球体縮小の11秒で再起動せず、発射の12秒で停止。約2秒に時間調整済み。充填0〜10秒間は無音。 |
| `sen_mi_b_saberu.mp3` | `assets/bittaran_laser_attack_v480.ogg`、`assets/bittaran_laser_sustain_loop_v480.ogg` | **12秒のレーザー発射**で短い開始音を1回、同時にクロスフェード編集済みの持続ループを開始。2秒間の照射中はループの再起動なし、14秒の照射終了時から0.14秒で滑らかに消します。 |

- Ogg VorbisはGodotのインポート後に読み込むほか、AndroidでGit同期直後にインポートキャッシュが未生成でも、`res://`内の生のOggデータから直接デコードできる構成です。
- 足音の従来の単純な金属打撃合成は、音声が未同期の場合のフォールバックとしてのみ残しています。SERAに元からある斬撃・被弾・スラスターの効果音、BGM、ビットタラン本体の脚音は変えません。
- 音量初期値：足音-8dB、チャージ-5dB、レーザー開始-7dB、持続-11dB。持続音は0.08秒で音量を立ち上げ、0.14秒で減衰します。

## 保護した仕様
- ビットタランの**充填10秒 → チャージ青球体2秒（11秒から縮小・追尾0.7倍） → レーザー2秒（1.5m超で追尾加速） → 基本姿勢へ0.7秒**。
- レーザーは0.20秒ごとの連続被弾と無制限ヒット回数、プレイヤーの通常のガード／ノックバックを維持。
- ビットタラン移動速度・旋回速度2倍、原本Blockbenchモデル、脚接地IK、FXと画面操作を維持。

## テスト
- `tools/sera_footstep_railgun_audio_runtime_check.gd`を全体CIに登録。実シーンの接地信号・非接地無音、音源のファイル存在・Oggデコード・Android生Ogg読込、青球体出現時の一度だけのチャージ音、照射開始の発射音とループ、照射中のループ維持、照射終了時の音量フェード・リセット時の停止を確認します。
- 音声と映像の実機シンク、音量バランス、イヤホン・スマホスピーカー上での音質はAndroid実機で確認が必要です。
