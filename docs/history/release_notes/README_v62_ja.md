# v62 ターゲット表面基準の近距離ステップ + 操作領域を濃いグレーへ

## ステップ速度の判定
- v61まではプレイヤーとターゲットの**中心間距離が2m以下**の場合のみ6m/sとなっていました。
- v62からは**ターゲットの箱型当たり判定の表面までの水平最短距離が2m以下**の場合に6m/sとします。箱の横、角付近などを含みます。
- 2mより離れている場合は10m/s。ステップを開始する瞬間の距離で速度を確定し、ステップ中は変更しません。
- 2.0〜4.0mの移動距離、0.4秒の最大所要時間、衝突判定、ドラッグ入力を維持します。
- スクリーンショットから正確なワールド座標を確定できないため、画像の近接状態を判別できるよう外周基準を採用しています。

## 操作用スペースのグラデーション
- 画面上75%まではグラデーションなし。
- 画面高さの75%〜85%を、完全透明から暗いグレーへフェード。
- **画面下15%（85%〜100%）はさらに濃いグレー**で一定にします。
- グレーは RGB(0.12, 0.125, 0.13)、下端の不透明度は90%（v61は72%）。黒塗りではありません。
- グラデーションはタッチ入力を受け取らないHUD上で描画されます。
