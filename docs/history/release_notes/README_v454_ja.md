# SERA v454 — ビットタランの攻撃エフェクトを足先から再構築

## 修正した問題

- 粉塵が足先から離れた変な位置で発生していたため、実際の足先メッシュの**最下部8.5cmの接地点**から発生させるよう変更しました。各脚の左右・前後ミラーとIK適用後のワールド座標を使用します。
- なぎ払いの粉塵が数個ずつ疎らに見えていたため、単独の連続発生器を廃止し、**10基の短い噴出を足先の移動軌跡へ並べる方式**へ変更しました。約0.045秒ごとに36粒を密集して放出します。
- 以前の高い初速による粉塵の飛散を抑え、発生場所は足先の周囲、残留粉塵は緩やかに広がって自然に消えるようにしました。

## 攻撃ごとの演出

| 攻撃 | 表現 |
|---|---|
| 踏みつけ | 実際の足先が床に着いた瞬間に、足幅に沿って濃い灰色の土・淡い粉塵・砂・小石がまとまって舞い上がる |
| 弾き | 接地面から弾いた方向へ濃淡のある土砂・粉塵・小石を直線的に噴出 |
| なぎ払い | 初回の地面を這うストロークに沿い、足先が通過した場所へ連続的な粉塵の軌跡を形成。余韻と足戻しでは新規放出なし |

小石は地面に落ちた時点で消え、煙は時間とともに自然にフェードします。足元にない場所からFXを発生させる演出用の架空の位置・衝撃波は使いません。

**攻撃モーション・原本Blockbench・当たり判定・攻撃AI・接地IK・攻撃速度は変更していません。** v453の近距離踏みつけ／中距離弾きの選択も維持しています。

Godot実戦シーンのエフェクト位置と発生密度、接地面と発生方向を新規テストで確認します。Android実機での視覚的な品質とFPSは未確認です。
