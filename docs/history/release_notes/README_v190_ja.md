# SERA v190 — 後退ランの回転、接地足音、脚の自動高さ補正

## 変更点
1. **右方向ラン → 右後方後退ラン**の腰回転を修正。後退への180°補正を右/左で反対にし、右後方へは右回り、左後方へは左回りに近い経路で移行。指の移動方向、速度、RUN/後退判定の閾値・ヒステリシスは変更していません。
2. **左右の足が接地した時に短いメカニカル足音**を鳴らすように変更。ランモーションの足裏メッシュの最低点を毎フレーム確認し、離地（5.5cm以上）から接地（2cm以下）へ移ったときに発音。音は起動時にPCMとして生成するオリジナル金属音です（音量 -11dB）。通常の静止、ブースト、ジャンプ中は鳴りません。モデルの足裏に応じる判定であり、指定の周期だけで鳴らす方法ではありません。
3. **大型の靴・脚パーツ**に対応。A脚の静止時の足裏最低点を基準として、選択脚の足裏最低点から機体全体のYオフセットを計算します。足が下に伸びたら機体と頭を持ち上げ、浮く方向なら下げます。必要に応じて衝突カプセルを上に伸ばします（半径や地面側端点は変更しません）。
4. v189の鳥足の足先に設定された**メッシュ固有の-22.5°回転**を読込側にも反映しました。標準A/Bのメッシュ向きは変更していません。

## 注意・限界
- セラの訓練室は物理床でなくXZ平面移動のため、足音の「接地」は**3Dメッシュから推定した接地イベント**です。物理エンジンの衝突シグナルではありません。
- 自動高さ補正は**静止モデルでの足裏基準の調整**です。走行中の両足接地を常時保証するIK、膝の伸長や靴底の変形、段差・斜面への適応は含みません。
- 既存カメラ/操作/攻撃、Aのアニメーション、鳥足専用ボーン、頭Cのピボットは維持しています。
- 視覚的な足音タイミング、PCM音の音色、機体の立ち位置、頭上の衝突判定はAndroid実機で未検証です。**Xperia 1 Vでの調整が必要**です。

## 確認方法
1. `main` を同期し、Godotで `SERA v190` を起動します。
2. 右RUNから右斜め後ろに方向転換して、腰が遠回りせず回ることを確認します。左側も確認します。
3. RUN中、左右の足が着くタイミングに合わせて短い足音が鳴ることを確認します。停止・ブースト中は鳴らないことも確認します。
4. NEXUSのCUSTOMIZATIONでLOWER BODYをA/B/Dに切り替え、足の浮き沈みと機体全体の高さを比較します。大きな新規脚を登録した場合は、足裏に合う高さが自動計算されます。
