# SERA v350 — ビットタラン脛ロック判定を2倍に拡大・高さ固定

## 仕様

- 四脛（左前・右前・左後・右後）のロック対象選定専用AABBを拡大。各LowerLegボーン直下の脛メッシュのみを測定し、縦・横・奥行をちょうど2倍にしたボックスを使用。Footは計測に含めません。
- ボス自体の2倍スケールは既に実寸に含まれるため、二重に掛けません。選定用の倍率2.0は表示される脛モデルに対する倍率です。
- 歩行・旋回・IK中、ロックボックスの中心X/Zは脛に追従します。中心Yと寸法は初期立位で固定し、歩行bobや脚の上げ下げで上下しません。
- ロックボックスは衝突レイヤー0・マスク0・監視OFFのArea3Dです。ロック線による候補選定にだけ使用します。
- 攻撃の命中判定、部位破壊、物理衝突は以前の実メッシュ基準のまま。ロック選択は拡大しても攻撃が自動的に届くわけではありません。
- 頭・胴体のロック候補は従来の1.15倍、通常時4脛・脚破壊ダウン中のみ頭/胴体を解放する前版仕様も維持します。

## 実装とテスト

- scripts/bittaran_parts.gd：脛メッシュ単独AABB、立位Yと寸法の保持、水平追従、Area3Dのみ2倍化。
- tools/v350_bittaran_shin_lock_self_check.py：仕様に関する静的チェック。
- tools/v350_bittaran_shin_lock_runtime_check.gd：Godot 4.7.2で4脛の2倍寸法、185フレームの歩行・旋回・IK、強制上下動でY固定、攻撃/物理判定不変を確認。
- 既存のv345〜v349専用回帰テストも継続実行。Android実機でのロック操作確認は未実施です。
