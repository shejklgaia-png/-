# SERA v482 — なぎ払いの前足・後足命中時刻を明示指定

## なぎ払いの命中判定（新しい確定値）

| 対象 | 開始（原本クリップ時刻） | 終了（原本クリップ時刻） | 判定部位 |
|---|---|---|---|
| 前足（左右） | **0.67秒** | **1.38秒** | 下肢・足先 |
| 後足（左右） | **0.17秒** | **0.63秒** | 下肢・足先 |

- 上記は**各Blockbenchなぎ払いアニメーションの原本クリップ上の時刻**です。2026-11-19のv481で採用した「停止0.5秒前から逆算」という旧ルールより、今回のユーザー指定値を優先します。
- 判定中は実際の**下肢メッシュと足先メッシュ**にプレイヤーが接触した場合に命中します。上肢・肩・胴体・広いロック用判定にはダメージ判定を設けません。
- **地面への接地は命中判定の必要条件にしません**。前足0.67秒・後足0.17秒の時点で足先が浮いていても、下肢／足先への実接触なら命中します。この変更により指定時刻から正確に判定が有効になります。
- 原本Blockbenchモーション、再生タイミング、4足の左右反転、IK、威力、1回の技での1ヒット制限、被弾演出は変更しません。
- **土埃エフェクトは独立**して、元の足先が地面をなぞる原本タイムライン（前足0.75〜1.25秒、後足0.25〜0.75秒）と実接地を使用します。判定開始を早めても空中に土埃は発生しません。

## 維持する他の仕様
- ビットタランのレーザーのHP／ガード威力は引き続きv481指定の60%、照射中の0.2秒ごとの無制限再ヒット、追尾距離1.5m超での加速・球体縮小からの減速を維持します。
- 他の踏みつけ・弾き・プレイヤー操作・音源・BGMは変更しません。

## 検査
- `tools/bittaran_keyframe_hit_sector_runtime_check.gd`で前後左右4本の指定時刻、境界前後の命中禁止、実下肢・足先メッシュでの被弾判定、独立した土埃の再生区間を検査します。
- Android実機の視覚的な命中感・回避しやすさはheadless Godot CIと別に確認が必要です。
