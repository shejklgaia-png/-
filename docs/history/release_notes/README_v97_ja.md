# セラ v97 — 上フリックジャンプ・慣性移動（2026-11-06）

**基準**：`sera_portrait_godot_melee_v96_player_bullet_hit_sound.zip`（v96）。

## 操作と運動

- 画面上方向へ速いフリックを行って**指を離す**とジャンプ。短いフリックに加え、走行・ブースト中の長いドラッグでも最後0.20秒の上向きフリックを認識します。左右フリック＝左右ステップ、下フリック＝4mバックステップは従来どおり。
- **固定跳躍高度：1.50m**、**滞空時間：0.80秒**（暫定、再調整可能）。放物線状に上昇・落下して0mに着地します。2段ジャンプはしません。
- 離地時の**水平速度を65％に減衰**したうえで、着地までその速度を維持します（空中での追加加速・方向変更なし）。立ち止まってからの短い上フリックでは、タッチ開始時の水平速度を引き継ぎます。
- 被弾中、攻撃モーション中、ステップ中、空中にいるときは新しいジャンプを開始しません。空中でのタップ攻撃、ステップも一時無効です。被弾中でも落下は継続します。
- デスクトップのデバッグでは `J` キーでもジャンプ可能。

## Blockbench モーション

- 提供ファイル `SERA_jumpmotion.bbmodel` に含まれていた**名前のない0.375秒のアニメーション**のみ、`Jump` に命名して追加（22骨のUUIDはv96と一致）。ジャンプ姿勢は0.375秒の全シーケンスを**0.80秒の飛行へ時間伸縮**して再生。実移動はGodotのCharacterBody3Dで処理し、モーションの位置キーフレームは外部のジャンプ高度に加算される視覚用のローカルオフセットとして使用します。
- 新たな `blockbench/SERA_v97_jump_integrated.bbmodel` に統合版、`blockbench/SERA_jump_user_input.bbmodel` に元データを保存。v96の既存モーション・ジオメトリ・テクスチャは維持。

## 実装範囲

- `scripts/main.gd`：上フリック判定、末尾フリック履歴、ジャンプ運動、水平慣性、入力・被弾状態遷移、床マークの位置固定。
- `scripts/sera_rig.gd`：`Jump` 再生と物理経過率に同期するクリップ再生、移動アニメーションとのブレンド。
- `assets/sera_source.json`／`assets/sera_data.gd`：追加クリップを反映（Androidエクスポート用埋め込みも更新）。
- `project.godot`：バージョン表記更新。`DEVELOPMENT.md`、本説明、検証スクリプトを追加更新。

**変更しない機能**：敵AI・敵攻撃4種・デバッグUI・弾/格闘/範囲被弾音・ダメージ数値12/12/26・通常移動／ブースト閾値・ステップの距離と速度・カメラ／残像・攻撃・エフェクト。

**現時点での制限**：床は従来どおり衝突用地面を持たないテスト空間で、着地はY=0へ復帰する方式です。高低差のある地形や台への着地、空中攻撃、空中ステップは未実装です。Godot本体／Android実機での動作検証は未実施です。
