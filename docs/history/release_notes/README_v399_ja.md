# SERA v399 — 攻撃のたびに胴体が下がっていく問題を修正

ビットタランが攻撃を繰り返すたびに、胴体が少しずつ下がっていく問題を修正しました。攻撃モーションや脚の動き自体は変更していません。

- **原因**：v398で入れた「攻撃前に脚をIKで基本姿勢へ戻す」準備動作中は攻撃ポーズが空のため、物理ティック末尾の接地補正（浮いている足裏に合わせて胴体を上下させる処理）が止まらずに動き続けていました。準備では対角ペアを意図的に持ち上げるうえ、もう一方のペアが歩行ステップの途中で止まった高さ（約24cm）に残ることがあり、4脚すべてが床より上にある瞬間が生まれます。その最低の足裏を「胴体が浮いている」と誤認して胴体を引き下げ、誤差が `ground_correction_world` に累積していました（実測で1回の準備あたり約1.34m分）。
- **修正**：スタンス準備中は、原本攻撃が脚を占有している間と同じく、接地補正を行いません。準備自体が4脚すべてを正確なWait接地点へ着地させるため、攻撃への引き継ぎ後は接地した状態から補正が再開します。準備の時間・着地目標・原本キーフレーム・IK・移動の数値は変更していません。
- **検証**：新たに `tools/v399_bittaran_body_height_stability_runtime_check.gd` を追加し、全12攻撃を2周連続で実行して、各攻撃の後に胴体高さ・累積補正・接地足裏が基準へ戻ることを検査します。修正前は累積補正-1.337mで失敗し、修正後は合格します。既存のビットタラン系ランタイムチェック全件も合格しています。Android実機での見た目は別途確認が必要です。
