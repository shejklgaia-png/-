# SERA v469 — 照準完全捕捉後に0.5秒待機してレーザー発射

## 発射までの流れ（10秒周期は維持）
- 側面の3本の充填バーが満点灯するまでは砲台は基本姿勢で静止します。
- **7.5～9.5秒：青白い球体が2秒間表示**され、プレイヤーへの追尾は同じ2秒を使ってsmoothstepで滑らかに立ち上がります。球体は最初0.2秒で膨らみ、最後の1秒で収縮します。
- **9.5～10.0秒：球体が消えてから0.5秒間、プレイヤーを捕捉した照準で発射を待機**します。待機開始時にはプレイヤーの現在位置へ正確に照準を合わせ、待機中も高速のYaw/Pitch追尾を維持してプレイヤーの移動を追い続けます。充填バーは3本とも点灯したままです。
- **10.0秒：レーザー発射**。最初のフレームでもプレイヤーの現在位置へ正確に照準を合わせ、発射後は水平24°/秒・上下18°/秒の低速追尾へ切り替えてブースト回避を可能にします。

## 維持する仕様
- レーザー2秒、発射周期10秒、発射後0.4秒保持＋0.8秒復帰、充填前の静止、2軸砲台のRoll防止、ビットタラン全身のカメラ内フレーミング、モデル原本と既存の脚IK／攻撃。
- 球体表示2秒、最後の1秒間での収縮、追尾の2秒間イーズインは変更しません。待機時間を新たに作る代わりに球体／追尾開始を0.5秒早めます。

## 検査
- `tools/bittaran_railgun_runtime_check.gd`で7.5～9.5秒の球体2秒、9.5～10秒の0.5秒完全捕捉待機、待機中の移動目標の再捕捉、3段目充填バー維持、10秒の発射境界、発射後のブースト回避を検査します。
- 既存の全身フレーミング・水平保持・14ボーン・モーション回帰を維持します。
