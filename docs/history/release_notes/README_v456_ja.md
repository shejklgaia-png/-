# SERA v456 — なぎ払いエフェクトを足先軌跡に沿って事前構築

## 方針

従来のv455は、なぎ払い中に毎フレーム足先メッシュの底面を測り、接地判定に従って粉塵の位置とタイミングを決めていました。ボーンのミラーやIKの誤差で、チラつき・突然移動・発生漏れが起きやすい構造でした。

v456では、実際の4脚それぞれのBlockbenchなぎ払いモーションを事前にサンプリングし、**「ソースアニメーション時刻→足先位置」**を用意してから粉塵を発生させます。ゲーム内の本物のモーションと接地IKを60fpsで一度再生して記録し、その結果をコードに保存します。Androidではこの保存データを読み込むだけで、骨格の再計算は行いません。

- 前脚：原本アニメーションの0.75〜1.25秒
- 後脚：原本アニメーションの0.25〜0.75秒
- 事前生成データ：`scripts/bittaran_sweep_fx_baked_data.gd`。実戦シーンで各脚を60fpsで再生し、約0.042秒間隔の13点ずつに圧縮しています。左右反転した偽物の脚位置ではなく、4脚の原本クリップと実IK補正済みの接地点から作成しています。
- 初回接地時に実際の足先へ軌跡を合わせます。以後の粉塵は保存した軌跡上にワールド座標で出し、**IKのわずかな位置ブレ／接地判定のオンオフで動かしません**。
- 攻撃の余韻／戻り動作中は新たな粉塵を発生させません。土砂は自然に消え、小石は地面に落ちると消えます。

**変更対象はなぎ払いVFXのみ**です。踏みつけ・弾き、被ダメージ、ボスAI、元のBlockbenchキーフレーム、関節接地IKは変更しません。

既存のシーンで予備動作・初回着地・FXが発生することを新規Godotテストで検証します。実機のレンダリング品質・FPSは後日APKで確認が必要です。
