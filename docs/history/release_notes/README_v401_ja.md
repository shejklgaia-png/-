# SERA v401 — ビットタランに重量感と技の個性を追加

指定された3観点（重量感があること／違和感が少ないこと／わざに明確な性質があること）でビットタランを実シーン計測つきで監査し、調整しました。移動速度・旋回・攻撃タイミング・ダメージ等の既存数値は変更していません。

- **重量感（歩行）**：計測すると、歩行中の胴体は高さが完全に一定（上下動0.0）でロ―ルも最大0.45°しかなく、足だけが動いて胴体が滑るように進んでいました。対角脚が浮いている間、接地している対角ペアの前脚側へ胴体を寄せる傾き（ロール最大約2°＋わずかな前傾）と、沈み込み（約4cm＋着地ごとの小さな脈動）を脚IKに追加しました。接地した足裏はその間も床に固定され（実測誤差ほぼ0）、停止すると全てゼロへ減衰します。
- **重量感（着地と音）**：踏みつけ着地に、距離で減衰する画面シェイクと、既存効果音と同じプログラム生成WAV方式の重低音を追加しました。弾き／なぎ払いが命中したときは小さめのシェイクと鋭めの音、歩行の着地にも控えめな足音が付きます。シェイクは他で未使用のカメラのフラスタムオフセットを使い、必ずゼロへ収束します（通常の追従カメラとは競合しません）。
- **技の性質（使い分け）**：技の選択を「順番に回すだけ」から状況判断に変えました。プレイヤーが脚のすぐ近くにいれば踏みつけ、脚の延長線上にいれば弾き、脚の横にいればなぎ払いを選びます。状況が合わない場合と、同種が連続する場合のフォールバックとして従来のローテーションを残してあるので、戦闘のリズムとばらつきは維持されます。
- **検証**：新規 `tools/v401_bittaran_weight_feel_runtime_check.gd` で、状況選択の4ケース（踏みつけ／弾き／なぎ払い／同種連続の回避）、歩行中の重心移動と足裏の接地・停止時の減衰、踏みつけシェイクの発生とゼロ収束を検査します（選択は修正前だと失敗）。既存チェックのうち2件は前提の変化に合わせて更新しました：v399 は歩行中の沈み込みと「攻撃による恒常的な高さ誤差」を分離するため計測前にIKを静定させてから測るよう変更（接地補正そのものの判定は不変）、v382 は実AIセレクタへの提示方法を「弾きの状況」に合わせて変更（壊れた脚でも弾きを出せることの確認は不変）。全件CIスイート（静的182件＋Godot 137件）が合格しています。Android実機での見た目と音は別途確認が必要です。
