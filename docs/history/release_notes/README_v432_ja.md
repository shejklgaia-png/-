# SERA v432 — ビットタランの全メッシュを原本の接地時間だけ床に合わせる

## 判定対象
- **全18メッシュ**：胴体、前後左右の上肢・下肢・足先、砲塔/頭部系を含むすべてのElement UUID。メッシュ名が重複していてもUUIDで個別に追跡します。
- **全10アニメーション**：17:21:58のBlockbench原本にある7種類（Wait、左右それぞれのなぎ払い・弾き・踏みつけ）に加え、ゲーム用原本にあるIdle、Turn、Approach。
- 各原本の全キーフレーム時刻とその間の120Hzサンプルで実頂点を変換し、最下点がBlockbench座標Y≤0.025の時刻のみ接地対象とします。空中判定の時刻は補正しません。

## 実装
1. `assets/bittaran_ground_contacts.gd` に、クリップ名・Element UUIDごとの**接地対象時間区間（秒）**を記録。
2. アニメーション開始・更新時に前フレームの視覚補正をクリアし、関節・キーフレームを正規の状態から再生。
3. 攻撃脚原本＋残り3脚の接地IK、独立した頭部追尾が終わった後、該当するメッシュだけ、**実頂点の現在の最低YがGodotの地面Y=0になるようメッシュのワールドY位置だけを補正**します。回転・骨格・関節Pivot・尺・時間は変えません。
4. 補正が不要な時間帯は対象メッシュの元のローカル位置を維持します。時間区間外の浮いたモーションを強制接地させません。
5. ダウン・ダウン移行など、Blockbench原本のクリップではない独自処理には誤ってIdleの接地区間を適用しません。

## 検証

- 回帰テスト：`tools/v432_bittaran_all_mesh_ground_runtime_check.gd`。全10クリップ×60Hzとすべてのキー時刻をサンプリングし、各メッシュの必要時だけ接地すること、空中では補正を加えないこと、ジョイントに変化がないことを検証する設計です。
