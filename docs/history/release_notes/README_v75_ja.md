# セラ v75 — ステップ・ブースト限定 軽量モーションブラー

## 動作
- **ステップ中**：プレイヤーに半透明の輪郭残像を1回重ね、距離7〜11mより遠い地面（格子を含む）だけに6pxの3サンプル方向性ブラーを適用します。
- **コントローラ円外のブースト走行中**：同じ処理を控えめに（3.6px）適用します。通常走行・停止中・攻撃・被弾ではエフェクトを描画しません。
- ブラーの方向は移動ベクトルを現在のカメラへ投影して決めます。ステップは衝突補正後の実際の移動方向を使います。
- 画面全体へのポストプロセスや高コストな過去フレーム蓄積・追加Viewportは使用しません。

## 対象範囲
- プレイヤーの本体メッシュ（剣・盾を含む既存パレット）。エフェクトメッシュは除外。
- 遠景：`ScrollingGround` の床・格子。プレイヤーからの水平距離**7mで開始、11mで最大**。
- 今後の背景MeshInstance3Dは `motion_blur_far_environment` グループに登録すると、同様の距離マスクを適用できます。非対象の敵、弾、画面UIには登録しないでください。
- オブジェクトを透過させず深度判定を維持します。ただし近景との境界には3サンプルによる微小なにじみが生じる場合があります。

## 軽量化と調整
- 停止中は地面の追加メッシュを非表示、プレイヤーの追加マテリアルパスも解除します。
- プレイヤー残像は既存メッシュの`material_overlay`による**1パスのみ**。フレーム履歴バッファ不要。
- 調整：main.gd の `MOTION_BLUR_FAR_START/FULL`・`MOTION_BLUR_PLAYER_TRAIL_SECONDS`、 `_update_motion_blur()`の `blur_px` と `blur_opacity`。
- プロジェクトは既存のGL Compatibilityを維持しています。

## 互換性・検証
- v74の速度、ステップ長、カメラ、UI、敵射撃、被弾、攻撃、既存のモーションデータは維持しています。
- コードとシーンの静的整合性は検査しています。Godot起動・Android実機の描画/性能は未検証です。
