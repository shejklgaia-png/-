# SERA v542 — ビットタラン前足「踏みつけ」の攻撃範囲拡大

## 2026年11月22日の更新

- 前足の踏みつけの**発動距離**を、足先から3.0m→**3.7m**に拡大しました。左前足・右前足共通です。距離基準は既存の足裏ワールドXZ座標を維持します。
- 前足踏みつけの**実際の3D攻撃判定**を、表示される足先メッシュの横幅・奥行きそれぞれ1.5倍→**1.8倍**に変更しました（平面面積は従来の1.44倍）。ヒットする箱はそのフレームの足先位置を追い、振り下ろし時のみ有効です。
- **後足踏みつけは変更なし**。発動距離3.0m、実際の判定1.5倍のままです。
- 前足踏みつけ・弾きの両方が発動可能な3.1～3.7mでは、従来の優先順位に従って踏みつけを選択します。弾きの発動可能距離3.10～6.30mと左右60°は変えていません。
- 原本の攻撃モーション、足先追従、最高点を過ぎてからのダメージ開始、攻撃1回につき1ヒット、着地した瞬間の土埃/揺れ、既存の威力、なぎ払い、武装、ダウンとSEを保持しています。
- テスト先行で踏みつけ発動距離と接触範囲の期待値を変更し、別途前足/後足それぞれの射程とメッシュ追従を確認する静的・Godot実行時テストを追加しました。
