# SERA v277 — 蹴りの接触判定・追尾・ブースト共通化

左右蹴り Kick_l / Kick_r は、原本モーションで両脚が伸びる 0.25秒および0.58333秒にそれぞれ1回、合計2回の当たり判定を行います。通常のSTEP所要時間へリタイムされても原本キーの比率で判定し、空振りしたイベントの再発火はありません。

Kick_b は原本0.79167秒の0.20833秒で1回のみ判定。従来の幅広い判定時間を廃止し、フレームをまたぐ判定で処理落ちに対応します。

左右蹴りは実ステップの最初の最大0.2秒、バッシュと共通の追尾関数を使用します。サマーソルトは射程外なら最大0.2秒のロックオン追尾を先に実施し、届かない場合はバッシュ同様に中止します。射程内では直接発動します。後方4m、高度1.5m、飛行0.8秒、着地0.2秒は変更していません。

蹴りの追尾中および飛行中は既存の背面スラスター関数を再利用します。逆方向への噴射、後退時の下向き補正、瞬間拡散、継続噴射、描画順と角度制限は同じシステムで管理します。

元のBlockbenchアニメーション、通常STEP、バッシュ、装備、タッチ操作やカメラを保持。GitHub CIで静的検査とGodot 4.7.2実行検査を行います。Android実機での見え方は未確認です。
