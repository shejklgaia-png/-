# SERA v517 — 装備製作・素材・倉庫の画面表示修正

## 拠点からすぐ使えるメニュー
- 拠点画面の下部に「装備製作」「素材変換」「倉庫」の3ボタンを常時表示。建物が見つからない場合も操作できます。
- 装備製作からLABOの7設計図と固有アイコンの一覧へ直接移動できます。倉庫には全12素材アイコンと製作済み個体のアイコン・名前・個体IDを表示します。
- 装備を製作するためのアクティブなセーブがない場合、LABO内に**空きスロットへの新規セーブ作成**を表示。既存のスロットは上書きしません。
- LABOから任意に「試作素材を受け取る」を選ぶと、12種類の各素材を6個ずつ**1回限り**受け取ります。無償の試作用であり、本番のドロップ/レシピは未確定です。セーブ済みの受領フラグにより再受け取りを禁止します。装備の試作は従来どおり素材消費なし。
- 項目名の「›」「▸」「‹」「< >」など装飾だけの記号を除去。変換の入力と出力を示す矢印のみ役割に応じて維持します。

## 保存・不変条件
- 製作品は `H01-0001` のような個体IDでセーブ/倉庫へ登録され、NEXUSのカスタマイズに反映。既存の試作7種アイコンアトラスと12種の素材アトラスを流用します。
- 既存の素材変換比率や装備モデルA仮表示、シールド・戦闘・Godot原本モデルは変更しません。

## CI・実機
- 既存の素材/アイコン/拠点/戻る/Godot検査を事前確認。実装前に`v517_base_accessibility_self_check.py`と`v517_base_accessibility_runtime_check.gd`を追加してCI登録。
- 実Godotで拠点のショートカット、製作一覧7個のアイコン、倉庫の12個のアイコン、セーブ新規作成、試作装備登録、素材補充と二重受領拒否を検証します。
- 実機では下部ボタンとアイコンの描画、縦画面スクロール、セーブ作成から製作までを確認してください。
