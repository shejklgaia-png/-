# SERA v405

## 概要
v404 の実機フィードバック対応です。動画で「攻撃時にビットタランが地面に倒れ込むようになる」と確認できました。v404 で入れた胴体のねじれ減衰が、想定外の経路で車高（胴体の高さ）を壊していたための回帰です。v404 の2つの修正（ねじれ減衰・弾きのリーチ調整）自体は維持し、壊れた経路だけを直しました。

## 何が起きていたか
- 攻撃の開始時に、IK が「脚の初期接地サンプル」（著者の元ポーズで測った足裏の高さ）から胴体の上下オフセットを一度だけ計算します。このサンプルは著者の元ポーズそのものであることが前提の基準値です。
- v404 の減衰は脚ポーズの計算関数側に入れたため、このサンプルまで減衰後のポーズで測られるようになり、基準値が最大 0.65m ずれました。結果、オフセットが胴体を余分に引き下げ、弾き／なぎ払いの構え〜打撃中に胴体がほぼ地面まで沈んでいました（実測: 胴体ボーン高さ 0.06m、本来の屈み込みは約 0.57m）。
- 脚の向き・足先の角度など、v404 で直した部分は計測上も維持されていました（だからチェックは通ってしまい、実機の見た目で初めて分かりました）。

## 修正（scripts/bittaran_rig.gd）
- 接地サンプル（initial_authored_sole_height）は、著者の元ポーズ（Body トラック減衰なし・脚の補正なし）で測るよう明示しました。サンプル値は v403 以前と完全一致に戻っています（全8通り: 4脚×弾き/なぎ払い）。
- 実測で、構え〜攻撃中の胴体の沈み込みが全ケース v403 と同じ値に戻りました（右前脚の弾き 0.60m、なぎ払い 0.61m、左前脚のなぎ払い 0.56m、左前脚の弾き 0m＝沈み込みなし）。ねじれ減衰とリーチ調整はそのまま有効です。

## チェック
