# セラ v44 — ロックオン外周弧の十字整列

v43をベースに、ロックオン外周の4つの弧の中心角を、**右0°／下90°／左180°／上270°**へ正確に揃えました（画面座標系）。

変更前は各弧の中心が `0.18 + 0.70 / 2 = 0.53rad`（約30.37°）ずれていました。変更後は `segment * PI/2 + lock_rotation` を弧の中心に使い、そこから弧長 `0.70rad` の半分を引いた位置を開始角としています。

- 弧の幅：0.70rad（約40.1°）、4つの弧の間隔：90°のまま
- 通常時：シアン、半径62px、線幅2px
- 近接時：赤、半径42px、線幅5px
- 近接移行：時計回り360°／0.20秒、円の縮小
- 離脱移行：反時計回り360°／0.20秒、円の拡大
- 中央の十字・距離条件・戦闘・移動・斬撃：変更なし

検証：弧の中心角、対向角、対称性、半径・線幅・回転設定、変更ファイルの差分、ZIPの整合性を静的確認済み。Godot本体・Android実機での描画確認は未実施です。
