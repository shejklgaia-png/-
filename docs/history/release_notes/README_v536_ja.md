# SERA v536 — NEXUS選択部位の発光とビットタラン開幕表示

## 2026年11月22日の更新

- NEXUSのカスタマイズ画面で現在選択している部位（頭部・胴体・下半身・腕・ブースター・左右武器）の装備メッシュを青白く発光表示します。部位の選択や装備交換に連動し、カスタマイズ画面を終了すると発光を解除します。
- ビットタラン戦の戦闘開始および再戦時、セラとボスの初期中心間距離を8mから12mへ変更します。通常トレーニングの8mは変更しません。
- ビットタランの名前を体力バー・部位HP表示より下へ移し、撃破時は通常名を隠して勝利表示の重複を防ぎます。
- 直前のv535で調整したビットタラン10分討伐目標、HP・部位耐久値・攻撃性能、各種モーションはそのまま維持します。
