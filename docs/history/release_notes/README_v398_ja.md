# SERA v398 — 攻撃前に脚をIKで基本姿勢へ向き直す

ビットタランは攻撃する前に、脚の**接地点と足先の向き**を基本姿勢（Wait）へ戻す動作を行います。戻し終わるまで、踏みつけ・弾き・なぎ払いの原本モーションは再生しません。

- **対角2脚ずつ**、0.32秒＋0.32秒（計0.64秒）で足先の位置と回転をIK補間します。移動中の対角2脚以外は接地したままで、歩行・旋回の途中からでも突然足を瞬間移動させずに準備できます。
- 脚を動かす距離と足先の回転量に応じて、最大12cmだけ足先を持ち上げます。真の基本姿勢の足先目標は`_home(leg, false)`、角度は`_rotation_home(leg)`を用い、既存の解析的2ボーンIKで実際の脚を動かします。
- 準備中はボスの移動・旋回を停止し、攻撃タイマーを0に保持します。攻撃判定・ダメージ・攻撃エフェクト・攻撃モーションを発生させません。
- 4脚すべてが基本姿勢に戻った次のフレームから、従来の攻撃準備・振りかぶり・攻撃・硬直・復帰を**元の時間とキーフレームで再生**します。以前設定した頭の左右30°制限、後脚なぎ払い時の胴体持ち上げ、20cmまでの頭部干渉、支持脚と地面の関係は維持します。
- 既存の直接的な攻撃モーション検証はそのまま維持し、新たに`tools/v398_bittaran_ik_neutral_stance_before_attack_runtime_check.gd`で全12攻撃について実戦場面で準備・接地IK・脚先角度・実モーションへの移行と中断を検査します。GitHub CIによるGodot実行テストで評価します。Android実機での見た目は別途確認が必要です。
