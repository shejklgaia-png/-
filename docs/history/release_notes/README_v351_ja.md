# SERA v351 — ビットタランのロック線を水平に固定

## 変更内容

- ビットタラン戦闘時のみ、2本の平行ロック線をセラのルート原点のY座標で水平に伸ばします。
- **始点**：セラのワールド位置（X/Y/Z）。
- **終点**：ビットタランのルート原点のX/Zを参照。ただし終点のYはセラのYと同一に固定します。
- 2本の間隔はこれまでどおり0.5m（中心線の左右±0.25m）。
- ボスの胴体が上下したり、足が歩行したり、脚破壊でダウンしたりしても、線の高さは変わりません。
- 自動ロック対象選定と任意のロック線デバッグ表示は同じ共通の座標計算を使用します。
- **訓練室のロック線計算は変更しません。** ビットタラン専用 scripts/bittaran_parts.gd にだけ関数を追加しました。

## 維持する仕様

- 脛メッシュの2倍の選定専用ボックスは初期姿勢のYを保持し、歩行中はX/Zに追従します。
- 通常時は4脛のみ、脚破壊によるダウン中は頭・胴体もロック可能です。
- ロック線の変更は攻撃命中判定・物理衝突判定には影響しません。

## 検証

- tools/v351_bittaran_horizontal_lock_runtime_check.gd：Godot 4.7.2でボスYを6段階変更したときの端点不変、セラY変更への追従、2本間隔0.5m、水平なデバッグ表示、訓練室の従来挙動を検査。
