# SERA v385 — ビットタランの3つの手制作モーションと土埃・土塊エフェクト

## 追加した原本モーション

`models/storage/ボステスト (2) (2).bbmodel` から、踏みつけ（1.75秒）、弾き（1.0秒）、なぎ払い（1.5秒）を正式な `models/bosses/Bittaran.bbmodel` に統合しました。全14ボーンのUUIDは互換です。アニメーションのキーの値は変えず、時刻順に整理しています。元のWait／Idle／Turn／Approach、既存の歩行とダウン動作を保持しています。

原本の主な攻撃動作は左前脚で制作されているため、右前・左後・右後の3脚へは左右・前後を反映した相対関節回転を適用します。攻撃しない3脚の足裏はワールド座標で接地固定し、胴体姿勢に合わせてIKで支えます。

## 攻撃仕様

| 攻撃 | 振りかぶり／予備動作 | 打撃 | 復帰 |
|---|---|---|---|
| **踏みつけ** | 原本の1.25秒の振りかぶり中、胴体のみ追尾旋回し、脚IKでプレイヤー頭上へ追尾。足先は垂直 | 0.25秒で地面へ振り下ろし、**足先が接地高さになったら水平化** | 0.25秒 |
| **弾き** | Turn/Approachから原本の低いBODYキーフレームへ**0.70秒**かけて滑らかに補間 | 原本「弾き」1.0秒を再生 | 0.45秒 |
| **なぎ払い** | Turn/Approachから原本の低いBODYキーフレームへ**0.70秒**かけて滑らかに補間 | 原本「なぎ払い」1.5秒を再生 | 0.65秒 |

いずれも振りかぶり終了時に胴体のプレイヤー追尾を停止し、攻撃中は通常旋回・接近を停止します。頭部の独立追尾、破壊済み脚の攻撃、死亡・ダウン中の攻撃停止は維持しています。

## 土と土埃の演出

- **踏みつけ**：脛の実際のXZ断面の**1.5倍幅**。中央から拡大する青いリングを廃止し、地面に欠けた部分がある灰色の円形衝撃波を全サイズで出現させ、徐々に消します。地面から上向きに土埃と茶灰色の土塊が跳ね上がります。
- **弾き**：攻撃脚が地表を弾いた位置から、移動方向へ土と土埃が弾け飛びます。
- **なぎ払い**：脚の動きに沿って土埃が帯状の軌跡を描き、小さな土塊が連続して跳ねます。

エフェクトの見た目は`scripts/bittaran_dirt_fx.gd`と`bittaran_battle.gd`で生成します。追加画像素材は不要です。演出には新しいダメージ判定を追加していません。
