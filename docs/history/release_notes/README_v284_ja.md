# SERA v284 — 画面4方向の格闘フリック、0.05秒キャンセル、命中後サマーソルト

## 3段コンボ後の方向入力
全て**画面の上・右・左・下**を基準とする90度セクターで判定し、セラの向き・ロック対象・カメラの回転には影響されません。

| 画面フリック | 派生 |
|---|---|
| 上 | バッシュ `Bash` |
| 右 | 右蹴り `Kick_r` |
| 左 | 左蹴り `Kick_l` |
| 下 | サマーソルト `Kick_b` |

通常STEPの移動はこれまでどおり画面方向に沿う**360度連続入力**です。ガード派生バッシュも画面上フリックへ統一しました。フリック受付の速度・距離・時間の閾値は据え置きです。

## 3段目キャンセル
- 振り切り：Melee3開始後 **0.625秒**
- **予約フリック専用キャンセル：0.675秒（振り切り＋0.05秒）**
- 予約がない場合：従来どおりMelee3終了の約0.83333秒まで完走
- Melee1/Melee2通常コンボのキャンセルと、通常攻撃1段目を再発動できる時間は変更しません。装備中の刀は元の0.5秒クリップ用タイミングを維持します。

## サマーソルトキック `Kick_b`
1. 従来の0.2秒上限の誘導加速（メレーブースト）で攻撃距離まで接近
2. 接地状態で**原本のKick_bモーションを開始**し、蹴りの伸びるキーフレームまで必要に応じて追尾
3. 蹴りのヒットフレームで命中判定を一度行う。**ヒットした場合だけ誘導を終了して、接触位置から後ろへ跳躍**
4. 命中後は固定した後退方向に沿ってベジェ曲線の弧を移動（後退4m・最高高度1.5m）。モーション終端まで再生した後に着地0.2秒
5. 外した場合は跳躍せず、原本モーションの完走後に通常状態へ復帰

`Kick_b`の全体アニメーション時計は従来の0.8秒を維持し、そのうち**約0.211秒が命中前、約0.589秒が命中後の跳躍**に相当します。命中後にターゲットが動いても再誘導しません。

## スラスターエフェクト
通常3連格闘と同じ**攻撃開始から追尾・接触・振り抜き完走まで連続噴射する規則**を、バッシュ・左右蹴り・サマーソルトにも適用します。追尾中は実移動方向の逆を向き、動きが小さい区間は安定した機体背面方向を採用します。命中後の後ろ跳躍はその進行方向に合わせ、加速開始時の一瞬の拡散と通常噴射の共通仕様を使用します。演出の見た目は実機未検証です。
