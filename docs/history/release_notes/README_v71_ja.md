# SERA v71 — コントローラのベクター描画への変更

## 基準
- v70 `sera_portrait_godot_melee_v70_damage_knockback_1_2m.zip` をそのままベースにしています。
- 提示された参考画像の意匠を、**画像アセットではなく Godot の `_draw()` で直接描画**します。

## 見た目
- 外周：二重の方向矢印（上下左右）、幅のある円環。
- 中央：単独の方向矢印（上下左右）、一体型の円盤。
- 外周と中央円の間：**完全に描かない透明な空白**。操作方向に応じて中央円が小さく動きますが、空白は維持します。
- 既存のシアン系のRGBA値を流用：外周下地 `Color(0.15, 0.60, 0.68, 0.08)`、弱線 `Color(0.21, 0.85, 0.93, 0.30)`、中心下地 `Color(0.13, 0.54, 0.61, 0.45)`、強線 `Color(0.21, 0.85, 0.93, 0.87)`。
- 発光、画像テクスチャ、斜め装飾なし。操作領域下部のグラデーションはv70と同じ。

## 挙動
- タッチで表示され、指を離すと非表示になる動作は維持。
- 入力解釈・スワイプ・フリック・タップの処理には一切変更なし。
- 中央円の視覚的な移動幅は操作半径の最大11.5%。操作判定半径112pxとは独立。
- ターゲットマーカー（ロックオン用レティクル）も変更なし。

## 変更ファイル
- `scripts/touch_overlay.gd`：描画部をベクター円環＋矢印へ置き換え。色・透明度・操作領域・ターゲットマーカーは保持。
- `project.godot`：プロジェクト表示名のみv71へ変更。
- `README_v71_ja.md`, `DEVELOPMENT.md`, `tools/v71_controller_self_check.py` を追加・更新。

## 検証
- スクリプトの入力処理・元のターゲット描画処理を維持する差分静的チェックを実施。
- `.gd`、シーン、モデル、敵AI、エフェクトなど未対象のファイルはv70からバイト単位で維持。
- Godotエディター／Android実機での表示・動作検証は未実施。
