# SERA v367 — 起き上がり中は胴体旋回、完全復帰後に脚の着地位置を追従

## 動作仕様

- **倒れている間：** 従来どおり静止し、脚の接地点は動かしません。
- **起き上がり開始：** 従来どおり`Turn`／`Approach`アニメーションと胴体旋回・接近を開始します。胴体はどちらのアニメーション中でも**最大34°/秒の旋回速度**でプレイヤーへ向きます。脚のIKは実世界の接地点を保持し、着地先へのステップは始めません。
- **起き上がり完了：** 胴体の向き・位置に対して、接地点が最もずれた脚の対角ペアから通常時間のステップを開始し、続いて残りの対角ペアを追従させます。
- **追従中：** 脚の**速度は上げず**、ステップ時間0.58秒のまま、目標着地点・足の向きを毎フレーム「現在の胴体の位置・Yaw」に合わせて再計算します。胴体が旋回・接近し続けても、着地時には最新の胴体姿勢に合った位置を目指します。
- **接地済みの脚：** 地面の同じ世界座標に固定し、必要になったときだけ次のステップで再配置します。

元の頭部追従70%、頭部と腕の干渉防止、横倒し脚の頭部支持、1脚2.5秒／全脚6.0秒のダウン時間を維持しています。

## 検証

`tools/v367_bittaran_body_turn_foot_catchup_runtime_check.gd`で、1脚／4脚ダウンと`Turn`／`Approach`の組合せを確認します。起き上がり中の脚IK停止、胴体34°/秒旋回、復帰完了後の脚追従、最新着地点への更新、従来どおりのステップ時間を検証します。
