# SERA v391 — ビットタランの攻撃照準と頭部先端

- 踏みつけ・弾き・なぎ払いは、予備動作中に移動するセラを追い、攻撃開始後は狙いを固定します。
- 弾き・なぎ払いは元のキーフレームを維持し、肩関節の水平旋回のみで打撃方向を補正します。硬直後の復帰時には補正角を滑らかに解放します。
- 弾きの予備動作で足の接地を優先して膝を過剰に折るIK処理を廃止しました。必要に応じて足先だけ軽微に高さ調整します。
- 頭部は長方形メッシュの先端、ローカル-Z側の短辺をセラに向けます。接触に対する旋回抑制は維持します。
- 元のBlockbenchの骨格・キーフレーム、攻撃時間、ダメージと支持脚の接地点は維持します。
- 12通りの攻撃を対象にGodot実行テストを追加しました。Android実機での最終視覚確認は未実施です。
