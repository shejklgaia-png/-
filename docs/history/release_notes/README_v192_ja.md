# SERA v192 — 足Cの独立選択とカスタマイズ表示崩れの修正

## 修正した問題
- v191では提供された靴Cを取り込み済みでしたが、誤ってLOWER BODY全体のCとして登録していました。足だけの独立した選択欄がなかったため、カスタマイズで分かりませんでした。
- v190の接地位置補正が、訓練室と無関係なNEXUS展示用セラの**ルート座標まで変更**していました。カスタマイズのカメラによる拡大配置に干渉し、モデルが画面下へずれる原因となっていました。

## 新仕様
- CUSTOMIZATIONの「LOWER BODY」の下に **FEET** を新設。**A STD**（選択中の人型脚の標準靴）と **C BOOT**（新規の足C・左右4メッシュ）を切り替えます。
- LOWER BODYは **A/B/D** の従来ボディ選択。A/Bに足Cを組み合わせても、腰・腿・膝下の形状と既存モーションを維持します。鳥足D装着中は鳥足に付属する足を優先します（FEETの設定は保存し、標準脚へ戻すと再び反映）。
- **展示用セラでは足裏由来の全身位置補正を完全に無効化**。撮影位置・拡大縮小は既存カメラのフィット処理だけで行います。
- **TRAININGではv190の足裏接地補正・足音・当たり判定の上下調整を維持**。選択した靴の足裏が基準になり、A/Bの標準足とCの新しい靴の高さを測ります。
- v191でLOWER BODY=Cにしていた既存プロフィールは、自動的にLOWER BODY=A＋FEET=Cへ移行します。頭C、武器、腕などの設定は変更しません。
- 元の`models/storage/足C.bbmodel`、標準A/Bの形状とアニメーション、鳥足D、頭Cのデータは変更していません。

## 端末での確認
1. `main`を同期してGodotで`SERA v192`を起動します。
2. NEXUS → CUSTOMIZATIONでセラの全身が画面内にあることを確認します。
3. LOWER BODY=A または Bにして、FEET=A/Cを切り替えます。**足先だけ**が変わることを確認します。
4. LOWER BODY=Dにして、鳥足が維持されることを確認します。Aに戻すと前のFEET選択が反映されます。
5. TRAININGで靴Cの接地と足音を確認してください。

GitHub CIではコード・モデルの静的検査を実施します。**Godot Android実機での描画確認は別途必要**です。
