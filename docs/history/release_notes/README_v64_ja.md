# v64：下部操作領域を白へ変更

- v63 をベースに、画面下部の操作領域の色をグレーから白 (RGB 255,255,255) に変更しました。
- 上端（画面高さ75%）は完全透明です。
- 75〜85% の範囲で透明から白・不透明度90%へ変化します。
- 下15%は白・不透明度90%の一定色です。
- カメラ、HUD、ステップ速度の5〜2m間の減速補間、ロックオン、移動・攻撃・衝突判定などは変更していません。
- 描画方式は Godot 公式 CanvasItem.draw_polygon / draw_rect に準拠しています。

※ Godot実行環境・Android実機での表示確認は未実施です。
