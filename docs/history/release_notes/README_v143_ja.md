# SERA v143 — 背景即時消去とセラの直線移動（2026-11-08）

## 戻るボタン
戻るボタン（またはAndroid戻る／Esc）を押した**その瞬間**、シアンの放射グラデーションと暗い青のグリッドを同時に非表示にします。セラが格納を完了するまで背景を残すことはありません。

## セラの経路
展示台の元の位置から左上の拡大位置へ、**画面上で直線を描くように**移動します。戻る時も拡大位置から展示台へ同じ直線経路を逆向きに移動します。移動中のカメラ変化や遠近法による曲がりを避けるため、画面上のモデル原点の位置を直接直線補間し、奥行きとモデルの向き・倍率は別に滑らかに補間します。

- セラの移動・拡大／格納：それぞれ0.28秒
- カメラの接近／後退：それぞれ0.18秒（タップと同時開始）
- 左上の最終位置、倍率、回転操作、3区画メニュー、NEXUS_pose、他設備、戦闘・音声は変更しません。

新たな回帰検査は `tools/v143_straight_motion_self_check.py` に記載しました。**実機のGodot描画確認は行っていません。** 直線性はモデルの中心（原点）の画面上の軌道であり、長い剣や盾が画面端からはみ出さないことは別の検証項目です。
