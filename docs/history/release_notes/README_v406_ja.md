# SERA v406

## 概要
v405 の実機フィードバック対応です。動画で「弾きモーションがおかしい」と確認できました。至近距離の弾きで、攻撃脚の付け根が大きく持ち上がり、脚が上から吊り下がるような姿勢になっていました。原因は v404 で入れた弾きの短縮方法そのものにあり、方式ごと差し替えました。

## 何が起きていたか
- v404 の短縮は「脚ポーズを Wait（立ち姿勢）へブレンド」していました。伸び切った脚を立ち姿勢へ回すと脚は下向きに回り、脚メッシュが床を最大 2.4m 突き抜ける姿勢になります（著者ポーズの実測、リーチ係数 0.5 時）。
- そこへ床めり込み防止の「脚全体リフト」（なぎ払いの下腿用）が 2.5m 分働き、付け根を持ち上げ続けていました。実測（前方のプレイヤーへ右前脚の弾き）: 付け根の高さ 2.66m → 4.35m、リフト 2.49m が打撃〜ホールドの間ずっと持続、足先は頭の高さ 1.84m を通過。
- v404 のチェックは水平方向の突き抜け量しか測っていなかったため、この壊れ方は検出できませんでした。

## 修正
- リグ側: ポーズのブレンドを廃止し、弾きは常に著者ポーズそのものを返すように戻しました（リーチ係数の計算は維持）。
- IK 側（scripts/bittaran_foot_ik.gd）: 打撃中、著者の伸びが目標リーチ（股関節→狙い点の距離＋余裕、係数から算出）を超えた分だけ、足先を股関節→足先の直線上で引き戻し、膝は著者の曲げ面のまま踏みつけと同じソルバで解きます。脚の向き・軌道・足先の角度は著者ポーズのまま、長さだけが変わります。目標リーチ以内では制約は一切かからないため、遠距離の弾きは従来と完全に同一です。
- 実測（同条件）: リフト 2.49m → 0.0m、付け根 4.35m → 1.86m（著者の屈み込み位置）、足先は低い位置でプレイヤーへ到達。関連チェック（v400 の足先角度・接地、v403 の方向、v404 のねじれ・突き抜け、v402 の復帰の滑らかさ）はすべて PASS のままです。

## チェック
