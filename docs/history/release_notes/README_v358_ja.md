# SERA v358 — ビットタランの重量感あるダウン予備動作と接地安定化

## ダウンモーションの変更
- 脚の部位破壊で、**0.6秒の予備動作**を挟んでから従来のダウンへ移行します。
- 予備動作では、頭を一度わずかに沈め、重たく振り上げ（最大26度）、ダウン直前にニュートラルへ戻します。両前脚も地面に足裏を残しつつ外側へ最大0.24m程度伸び、ダウン開始時に少しずつ戻ります。
- **ダウンの開始と同時に頭のプレイヤー追尾を解除し、Head関節を元の基準回転に戻します。** ダウン中は基準回転を保持し、起き上がると再びプレイヤーを追尾します。胴体自体の頭下がり姿勢は維持します。
- ダウンの持続時間は従来どおり**片脚破壊2.5秒／四脚破壊6.0秒**。それぞれ、これに0.6秒の予備動作が追加されます。すでにダウン中に別の脚が壊れても、胴体を起こして予備動作を繰り返すことはありません。

## 浮き上がり・接地の修正
- 胴体の高さが変わるフレームで脚IKが可動限界に達し、すべての接地足裏が一時的に浮いた場合、**地面Y=0に対して胴体の高さを補正してIKを再計算**します。
- 浮かせている歩行脚はこの補正の判定に含めず、接地している脚を参照します。
- 回避・押し出し・頭部追尾・部位の当たり判定などv357までの戦闘仕様は維持します。

## 検証
- `tools/v358_bittaran_windup_grounding_runtime_check.gd`：0.6秒演出、前脚伸長、倒れ始めから回復までの頭部初期化、単脚2.5秒/全脚6秒、足裏の高さを検証します。
- 旧バージョンのダウン終了テストは、予備動作の0.6秒を加えた時間で終了判定するよう更新しました。

Android実機の動きと重量感については、headless CIと別に視覚確認が必要です。
