# SERA v363 — 起き上がり中の旋回と頭部追従

## 動作仕様

ダウンからの起き上がりを進捗に応じた連続的な動作に変更しました。

- **旋回**：起き上がりが始まると同時に、胴体全体のYaw回転が極めて遅い速度から始まります。姿勢復帰のイージング進捗に合わせて角速度を滑らかに高め、立ち終えると通常の旋回速度（最大34°/秒）に移行します。
- **頭部**：起き上がりの**姿勢復帰率70%**までは通常のデフォルト回転を維持。70%を超えてから、残り30%の復帰に合わせて頭部のプレイヤー追従を滑らかに再開します。既存の脚干渉防止判定は引き続き有効です。
- **接近・脚の旋回モーション**：復帰中は`Idle`アニメーションを維持し、前進を禁止します。胴体全体の方向回転のみ先行して行うため、ダウンや横倒し脚の復帰姿勢を壊しません。
- **完全復帰後**：正常姿勢に戻ってから0.24秒の`Idle`安定時間を維持し、その後は通常の`Turn`／`Approach`アニメーションと接近が再開されます。

0.6秒の予備動作、1脚時2.5秒／4脚時6.0秒のダウン時間、頭部と下敷き脚の接触、ダウン中の頭部ロック仕様は変更していません。
