# SERA v321 — 歩行姿勢・カメラ・刀の鞘・テクスチャ表示修正

## 変更点
- **RUN姿勢の高さ**：通常RUN／後退RUNの骨盤Y座標を原本の待機ポーズより低く制限しました。これまでの前進RUN開始時にWaist Yが待機 -3 Blockbench unitsから +1.5 units相当に上がっていた動きが発生しないよう、ラン時の根元高さを-0.235m中心、歩容による上下動は0.25倍に調整しています。原本アニメーション、ジャンプ／STEP／攻撃のキーは編集していません。
- **カメラのガタつき**：フォーカス追従の0.65m距離ハード制限がSTEPや高速移動で一瞬の座標飛びを生む原因だったため、毎描画フレームの最大移動距離を設けて滑らかに回復する方式に変更しました。ボスと重なる近距離で向きが急反転しないよう、距離別の角度補間も追加しています。既存のSTEP回復時間、上下角度、通常の感度・ズーム条件を維持しています。
- **刀の鞘**：左前腕側のKatana_l／Katana_l2／Katana_l3は鞘本体3メッシュとして刀の装備中は常時表示。Katana_r_saya内の納刀刀身2メッシュだけを抜刀時に隠し、右手側Katana_r_nukimiの抜き身2メッシュと第4フレームで切り替えます。2段目でも鞘は表示し続けます。
- **テクスチャ／材質**：斬撃中に機体全体へ重ねていた深度テストなしのパレット専用半透明オーバーレイを無効化しました。全装備スロットの元マテリアル（A/BのUV、C/Dの固有カラー、背面ブースター等）は斬撃開始・終了に関係なく保持。KOとEN警告時の個別オーバーレイは維持します。
