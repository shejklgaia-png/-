# セラ v39 — 近接可能時の円を微調整・HP0でも攻撃可能

v38（近接マーカー赤色化・ターゲットの陰影あり）を基準とした最小修正版です。

## 変更点

1. 近接可能距離（ターゲット表面から水平0.75m以内）でマーカーが赤いとき、**外周の4本の弧だけ**線幅を `2.0` → `2.5` ピクセルに変更しました。範囲外のシアンの弧、および中央十字の線幅は `2.0` のままです。
2. ターゲットのHPが0でもタップで通常どおり自動接近→攻撃できます。HP0でも刃の命中判定・ダメージ数値・ヒットストップ・火花・音を再生します。HPは0を下回りません（ダメージ表記は20のまま）。1回の振りに対する命中は従来どおり最大1回です。
3. HP0でも近接範囲内ならロックオン円は赤のままです。離れるとシアンに戻ります。
4. **v38のHP自動復帰（最初にHP0になってから1.35秒後に100へ復帰）は維持**しています。HP0に追撃しても復帰タイマーをリセットしないようにしました。HUDの「DOWN / RESTARTING」は復帰まで表示されますが、攻撃は可能です。

## 変更しないもの

- v38のターゲット照明と両者のダークグレーの丸影、床グリッド
- v35以降の斬撃・粒子・残光と前方オフセット0.55m
- 攻撃距離0.75m、攻撃モーション、カメラ、操作、攻撃力20
- ターゲットがHP0になる前のHP減少挙動とHP回復までの時間

## 手動テスト

1. 離れている間、円は従来の太さのシアン。近づくと赤になり**外周の弧のみ**わずかに太くなります。
2. 5回攻撃してHPを0にします（20ダメージ×5回）。HP0時に素早く再度タップすると、攻撃モーション・剣エフェクト・ヒット演出が続くことを確認します。
3. HP0でも範囲内なら円は赤。離れるとシアン。HP自動復帰中に追撃しても復帰時刻が延長されないことを確認します。
