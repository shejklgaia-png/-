# SERA v539 — NEXUS全身プレビュー左右ドラッグの反転

## 2026年11月22日の更新

- NEXUSカスタマイズの**全身プレビュー左右ドラッグの回転方向**を反転しました。右へドラッグするとyawが正方向、左へドラッグすると負方向へ変化します。
- 上下ドラッグの反転、胴体中央を固定した回転軸、操作後の平行移動・自動倍率補正を行わない仕様は維持します。
- 選択部位の青白い点滅、右側の装備メニュー強調、装備性能・保存データ・ビットタランの戦闘仕様は変更していません。
- タッチとマウスの回転方向を回帰テストで確認し、角度の `-PI/PI` 跨ぎも `wrapf` で扱います。
