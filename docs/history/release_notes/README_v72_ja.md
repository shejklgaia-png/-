# SERA v72 — 走り / ブースト切り替えコントローラ

## ベースと方針
- **v71 を直接継承**：既存の片手タップ攻撃、ドラッグ、リリース時の横フリック・ステップ、カメラ、敵AI、ダメージノックバックは維持。
- 画像素材ではなく `scripts/touch_overlay.gd` の Godot `_draw()` によるベクター描画を継続。
- 既存のシアン系RGBA値と下部操作グラデーションを変更しない。

## 操作仕様
- コントローラ外半径は **112→168 virtual px（1.5倍）**。
- 指の開始地点を中心とする浮動コントローラ。指先の開始地点からの距離を `d`、外半径を `R=168` としたとき：
  - `d < 0.62R`（中心円＋透明空白帯）＝ **RUN / x1.0**。
  - `d >= 0.62R`（外周リング、あるいはさらに外側）＝ **BOOST / x1.5**。
- ブースト開始境界は **104.16 virtual px**、接触で即時切り替え、中央へ戻せば即時RUN。
- 元の `MOVE_SPEED=3.25m/s`、ブースト係数 `1.5` → 外周で `4.875m/s`。**中心〜透明空白はアナログ走行**とし、外周内端（半径62%）で通常速度が100%になるよう入力率を調整。外周リングではブースト倍率1.5倍で一定。
- 判定は走行中の通常ドラッグにのみ適用。横フリックやタップ攻撃、攻撃用の `meleeboost` は独立、ステップ速度は変更なし。
- RUN→BOOST時に新規のブーストモーションを挿入しない（v71の移動アニメーションを再利用）。

## UI
- 外周リングBOOST：既存パレットの濃いシアン色と強線で強調。
- 内側RUN：中央円の強線を優先。リングと中央円の間は**完全透明**。
- コントローラの上に `RUN  1.0x` / `BOOST  1.5x` のモード表示。
- 画面上部の行動ステータスにもモードを表示。
- ドラッグ終了時は従来どおりコントローラ非表示、モードをリセット。

## 変更ファイル
- `scripts/main.gd`：リング判定、倍率、状態テキスト。
- `scripts/touch_overlay.gd`：リング強調と文字表示。
- `project.godot`：表示名をv72へ。
- `README_v72_ja.md`、`DEVELOPMENT.md`、`tools/v72_run_boost_self_check.py`。
