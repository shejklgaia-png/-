# SERA v259 — 格闘3段・バッシュの入力受付中は自動ロック先を維持

- 格闘1〜3段目の接近・各攻撃・2/3段追尾・バッシュの追尾/モーション中は、従来どおりAUTOロックの部位切替を停止します。
- **格闘3段目の終了後0.65秒**は、バッシュの追加フリックを受け付けるため、`combat_state == IDLE` に戻っても同じロック対象を保持します（`bash_followup_window_remaining`）。
- **バッシュ終了後0.65秒**は、格闘1段目に戻るタップを受け付けるため、同様にロック対象を保持します（`bash_loop_window_remaining`）。
- 受付時間が自然終了すれば、通常のAUTOロック選択を再開します。
- **RUN/BOOSTの移動入力**が成立した時点で両方の追加受付時間をキャンセルし、次の物理フレームからAUTOロック選択を再開します。**STEP**が正常に開始した場合もキャンセルします。EN不足でSTEPが不成立なら受付時間は維持します。
- 攻撃中の移動キャンセルは既存の `_cancel_attack()` を継続使用します。MANUALモードは従来どおり部位固定で、ロックが壊れた部位／不正な対象になった場合の既存のクリア処理も維持します。
- AUTOの選択順・ロックマーカー表示、格闘／バッシュの入力時間・ダメージ・追尾・モーション、RUN/BOOST/STEPの速度・EN、カメラ・衝突は変更していません。

検証は `tools/v259_combo_lock_hold_self_check.py` と既存CIで実施します。Godot/Android実機での操作感は未検証です。
