# SERA v174 — CONFIRMボタン自体を点滅

## 修正内容
SYSTEMのセーブ管理で、上書きSAVE・上書きNEW DATA・DELETEを
選んだ後、確認を待つ間は、**対象の操作ボタン（表示名 `CONFIRM SAVE`・
`CONFIRM NEW`・`CONFIRM DELETE`）**のみを点滅させます。
v173で誤って点滅させていた保存スロットの選択枠は常時青色へ戻します。

- 点滅：明シアンの枠線と青のボタン背景を表示する状態、暗い状態を
  0.38秒ごとに切り替え。周期0.76秒。
- ボタンの文字は常時表示。対象外のボタンとスロット枠線は固定。
- CONFIRMで確定、戻るによるキャンセル、スロット変更、画面退出で点滅を停止。
  別操作の確認待ちに切り替える場合も新たなボタンの明状態から開始。

## 範囲
既存ボタンの`StyleBoxFlat`色を切り替えるだけです。
SYSTEMのセーブ処理、DATA ARCHIVE、トレーニング/バッシュ/ガード、
カスタマイズ、3Dシーン、入力・音声は変更しません。

静的ソースチェック用の`tools/v174_confirm_button_blink_self_check.py`を
追加。GodotパーサーとAndroid端末での表示・タップ操作は未検証です。
