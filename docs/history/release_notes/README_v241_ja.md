# SERA v241 — スラスターの下向き推力表現

## スラスター角度
- 左右背部スラスターの噴射に、**ワールド座標で下向き成分0.40**を加算しました。水平に噴射する状態では、従来の進行方向に対して**約21.8°下向き**になります。
- ノズル自体を回転させ、噴射火炎とワールド固定の帯状軌跡も最終的なノズルの向きに従わせます。機体の重さを支えているような演出です。
- BOOST・STEP・追尾・格闘中の通常噴射に適用。左移動時の画面右下向き専用操舵にもワールド下向き成分を追加し、画面右下の扇形を外れないようにします。

## 制限・既存仕様
- 上下操舵：上方向最大1°・下方向最大90°、左右最大80°を維持。後退時には既存の下向き90°を優先します。
- 格闘中はヨー±20°・下35°までの物理可動制限と、セラの胸部へ噴射がめり込まない安全補正を維持します。非噴射時は下向き90°へ戻ります。
- エフェクトの描画順・深度テスト・ノズルのモデル原本・セラの動作/移動速度・部位破壊システムは変更しません。
- **物理的な浮上動作は追加していません。** 下向き噴射によって浮力を視覚的に表現します。
