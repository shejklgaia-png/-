# セラ v32 — プレイヤーには隠れ、ターゲットでは薄く表示される剣エフェクト

## 内容

v31 の斬撃の位置・角度・形状・UV アニメ・色を維持したまま、画面の深度テクスチャを使って画素単位の遮蔽を制御します。

- **プレイヤーより奥:** プレイヤーの不透明モデルが手前にある部分は、斬撃のアルファ値を 0 に近づけます。
- **ターゲットに重なる部分:** エフェクトがターゲットの表面より後方にある場合はアルファを 28% に落とします。完全には消えません。
- **ターゲットより前にある部分:** 白い斬撃を従来の透明度のまま表示します。
- **元の前方オフセット 0.55 m:** 変更なし。Blockbench の Swordeffect モーションと連動。
- **立体メッシュ、元の平面残光、白いランダム粒子:** 同じ深度判定で統一。
- **命中時火花:** 深度テストを有効に戻し、プレイヤー自身の上に不自然に重ならないようにします。

## 切り替え可能な設定

`res://scripts/sword_trail.gd` 冒頭:

```gdscript
@export_range(0.0, 1.0, 0.05) var target_occluded_visibility: float = 0.28
@export_range(0.01, 0.3, 0.01) var depth_feather_m: float = 0.075
```

- `target_occluded_visibility = 1.0`：**プレイヤーには隠れる／ターゲットには完全に重なって表示**（第1案）
- `target_occluded_visibility = 0.28`：**プレイヤーには隠れる／ターゲットに埋まった部分だけ薄く見せる**（推奨・初期値）
- `target_occluded_visibility = 0.0`：プレイヤーにもターゲットにも隠れる通常の深度表示に近い状態。
- `depth_feather_m`：ターゲットの表面と交差する境界のフェード幅（メートル）。

## 技術メモ

- Godot 4.7.2 の公式ドキュメントに従って、`hint_depth_texture` と `INV_PROJECTION_MATRIX` でスクリーンの深度を線形化します。GL Compatibility（既存の設定）では NDC Z を `[-1, 1]` に変換します。
- 読み取った**手前の不透明面の3D座標**がターゲットの AABB（中心 ±1.0m）に入っている画素だけ、ターゲットとして透明度を調節します。それ以外に隠れている画素は非表示です。
- 現在のターゲットは回転していない 2m の立方体であることを前提としています。形状・回転を将来変えた場合は識別処理も更新してください。
- プレイヤーとターゲットの形状が重なる特殊な状況では、ターゲットとして誤判別する画素があり得ます。
- 深度テクスチャには不透明なオブジェクトしか含まれません。他の半透明オブジェクトの遮蔽は別途調整が必要です。
- Mobile/Compatibility のGPUと実機によって見え方に多少差が生じる可能性があります。

## テスト

1. Godot Android エディターで `project.godot` を開き、▶で起動。
2. 短くタップして攻撃。プレイヤーの上に斬撃が被らないか確認。
3. ターゲットに斬撃が重なると、ターゲットの輪郭が薄い斬撃越しに見えることを確認。
4. `target_occluded_visibility` を `1.0` と `0.28` に切り替えて比較。
