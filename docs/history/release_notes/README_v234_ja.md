# SERA v234 — 近距離のカメラ接近速度調整

## 変更内容
プレイヤーとターゲットの距離が近いとき、カメラがズームインする速度をプレイヤーの接近速度より少し遅くしました。

| 項目 | v234 |
|---|---|
| 距離5m以内 | プレイヤーとターゲットの距離短縮速度の約88％をカメラの目標接近速度に採用 |
| 距離5〜8m | 従来の追従速度から滑らかに切替 |
| 距離8m以上 | 従来の追従方式を維持 |
| 接近速度の急変 | 時間差フィルタ（10/s）・加減速上限（24m/s²） |
| カメラの接近停止 | 残り距離に応じた指数ブレーキ（6/s） |
| プレイヤー停止時 | 構図へ向けて緩やかに収束（最低0.70m/sの目標速度） |

カメラの半径は最接近8.8m・遠距離16mで変えません。ターゲットと自機が収まらないときは既存の安全フレーミングを優先します。

## カクつき対策
- 物理座標そのままではなく、表示用に補間したプレイヤーとターゲットの距離を使って速度を計算
- 実接近が終わってもカメラが急停止せず、加速度制限と残差ブレーキで滑らかに止まる
- 安全ズームの縮小上限を近距離の目標速度と連動させ、古い1.25m/s固定解除が追従を妨げないようにする
- KO後のワープによる誤った高速接近判定を防止

BOOST・SLIDE・STEP・武器攻撃・スラスター描画やカメラの角度制御は変更しません。

## 検証
GitHub Actionsによる静的検査と30〜120Hzの数値シミュレーションを実施します。Android実機の操作感は未確認です。
