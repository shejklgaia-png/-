# SERA v287 — 攻撃中のカメラ揺れと極端な横向きを抑制（俯瞰視点は撤回）

ユーザー提供の約11.6秒のv286実機動画では、攻撃・接敵のたびに画角とカメラ方向が変わり、セラが大きく左右に映り、敵を見ながら横向きになっていました。

## 修正

1. **v286の近距離俯瞰補正を完全に撤回しました。** カメラの垂直位置は以前の `CAMERA_ELEVATION_RATIO = 0.21`（約11.9°）に固定します。距離に応じて俯瞰へ変化しません。
2. **v286の毎フレーム9候補を試す視点探索を撤回しました。** 敵の向きやセラの左右判定でフレーム単位にカメラが振り回されないようにしています。
3. **通常時の近距離カメラ**はセラの背後から約12°だけずらした肩越し視点を基準とし、指数平滑化と上限32°/秒の角速度でゆっくり追従します。初期構図も大きな横向きではなく、約12°肩越しとします。
4. **通常攻撃3段・バッシュ・左右蹴り・サマーソルト・着地モーション中はカメラYawを固定**し、終了後も約0.45秒保持します。短い入力の隙間で視点の左右回転が反転しません。
5. 攻撃中は急なズームインを抑止し、既存の画面端保護による必要なズームアウトのみ許容します。狭い画角で両者が欠ける場合には、安全に必要な半径への拡大が発生することがあります。
6. 左右蹴りの敵中心旋回は維持しつつ、**セラの旋回後の位置がカメラから見て左右±30°以内**になるように、2段目の旋回角を制限しました。元の旋回距離が長すぎる状況では移動距離より視認性を優先します。攻撃判定・原本クリップ・1段目の停止・2段目振りかぶりキーとEN消費は変えません。
7. v286の大型敵の脚を考慮した最低旋回半径3.55m、衝突処理、画面下部のLOCK操作ボタン位置76%は維持します。360°通常ステップは変更しません。

## 回帰確認
v286以前の静的テストを現行仕様に合わせて更新。新たにv287の画角・攻撃中Yaw保持・ズーム保持・左右蹴りの最大角を検証する静的テストとGodot向けテストを追加。GitHubへの反映およびコード構造の確認は実施しましたが、Godot/Android実機での動作・映像は未検証です。
