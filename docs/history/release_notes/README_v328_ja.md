# SERA v328 — ロック操作とボス中心カメラ、着地STEPキャンセル

- NEXUSのSYSTEM画面に「LOCK MODE / AUTO・MANUAL」項目を追加。設定は端末上に保持し、ゲーム開始時に反映。
- 戦闘画面のロックUIを「◀・ロックサイト・▶」の3つの記号に簡略化。中央はモード切替ボタンではありません。右利きなら左側、左利きなら右側に3つ並べて配置。ロック線の診断は独立配置。
- 着地モーションの開始から終了まで通常の360°STEPでキャンセルできます。STEPのENが足りない／入力無効なら着地を中断しません。
- カメラ注視点をターゲット中心へ移し、斜めショルダー構図でセラがターゲット左右に映るようにします。大きく横位置を入れ替えた場合だけ表示側を切替。端の角度補正とズーム補正の競合をなくし、解析的な安全フレームフィットを優先。
- 端末での画角、着地途中からの連続回避、表示の最終確認は別途必要です。
