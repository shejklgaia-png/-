# SERA v415 — ビットタラン後足の原本モーション保持・弾きの捻れ累積防止

## 修正
- **後足（左右）の弾き・踏みつけ・なぎ払い**：v414で追加した「通常姿勢の後傾と同じ角度で前傾」では、回転済みのBODYが攻撃脚の原本関節回転にも掛かり、後足モーションまで余分に倒れていました。胴体に指定された角度を維持しつつ、攻撃脚の肩に逆補正を一度だけ適用し、原本キーから計算された肩・膝・足先の**ワールド回転**を保存します。補正は毎フレーム、原本キーフレームを起点に再計算し、過去フレームの変形と合成しません。
- **4脚の弾き**：前左脚を元にしたソース軌道をサンプリングする直前、IKで移動したソース関節のローカル位置を一時的に原本のバインド位置へ戻します。サンプリング後は元の姿勢・位置を完全復元します。これにより、支え脚として先にIKを解いた脚から不正確な脚長・軌道が原本読み出しへ流入する問題を抑えます。
- **4脚の弾き**：一時フィット中の足裏座標を、次の弾きの原本サンプルへ渡さないようにします。導入時に取得した不変の原本足裏座標を使い、終了・中断時は毎回それへ復元します。なぎ払いのサンプリングも同様に関節位置をバインド位置から取得します。
- 前足の通常攻撃の胴体姿勢、後足の胴体高さ固定、頭の独立追従、既存の攻撃後キャッシュ全初期化は維持します。

## 回帰確認
- `v415_bittaran_rear_author_motion_runtime_check.gd`：実際に読み込んだBlockbench原本の3攻撃×左右後足×4時点で、胴体補正後も攻撃脚の肩・膝・足先の原本に対するワールド回転と胴体Y座標が変化しないことを確認します。
- `v415_bittaran_repeat_kick_drift_runtime_check.gd`：4脚それぞれ6回の連続弾きで、同じ原本再生時点における関節と足先の回転が初回から大きくずれないこと、原本足裏やポールの補正が残らないことを検査します。
- 既存の全件Godot回帰検査も実行します。Android実機での最終的な外観・操作フィールは別途確認が必要です。
