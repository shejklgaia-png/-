# SERA v248 — コントローラー表示と操作半径を1.5倍

## 変更
- v247比で浮動コントローラーの**表示寸法と入力半径を150%**に変更。RUN半径70→105px、中央デッドゾーン11.25→16.875px、BOOST基準105→157.5px。

- RUNリング、BOOSTガイドと外装リングの線幅、方向矢印、センター部分、ラン/ブースト表示ラベルと文字を1.5倍（文字11→17pxは整数制約により約1.55倍）。ラベル位置の余白も同倍率。
- RUNの入力距離に対する出力の正規化曲線は維持（比例位置なら同じ速度）。

- 移動実速度、BOOST倍率、BOOST確定時間、フリックステップ（78px閾値）、ガード・攻撃、ロック切替、照準、背景とカメラは従来どおり。
