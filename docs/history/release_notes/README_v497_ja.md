# SERA v497 — 四脚砲台を下肢の外側装甲へ密着配置

## 修正
- 実機動画（2026-11-19）で砲台が脚から浮いて見えたため、前後左右4脚の**上肢骨**を基準とした取付位置を廃止し、`FrontLowerLeg_L/R`／`RearLowerLeg_L/R`の**下肢骨**へ変更。
- 実際に読み込んだBlockbench下肢メッシュの8頂点AABBを下肢骨ローカル座標へ変換し、四肢それぞれの装甲形状から砲台の埋込位置を計算。左右（X）＋前後（Z）方向の外側、かつ上寄り（Y）の装甲**内側**へ半球中心を置くことで、半球と砲身が下肢から生える形にした。
- IKはメッシュ子孫を接地測定に使うため、追加した砲台メッシュは骨階層へ混ぜない。独立ノードの砲台に対して最終IKの**実際の下肢のグローバル姿勢**を毎フレーム転写。
- 攻撃準備・踏みつけ・弾き・なぎ払い・ダウン中も位置の追従と姿勢同期を続ける。**射撃だけを停止**し、これまでの浮き・置き去りを防ぐ。

## 不変条件
- 原本`models/bosses/Bittaran.bbmodel`の頂点・骨・Pivot・キーフレームは変更しない。
- 4基、半球＋筒、1.2秒の共通インターバル、近距離順、17m/s光弾、攻撃/ダウン中射撃停止、背部レーザーのダウン中停止、IK・接地・ヒットボックスは維持。

## CI事前確認・修正
- `.github/workflows/sera-model-policy.yml`、`tools/sera_ci_manifest.txt`、`docs/SERA_ACTIVE_CI_POLICY_ja.md`、`tools/bittaran_leg_turrets_runtime_check.gd`およびBittaran原本骨格を調査。
- **本体修正前**に既存の登録済み実Godot検査を変更。各砲台の追従先を上肢→下肢へ更新し、下肢原本メッシュのローカルAABBの外側・上寄りで、かつ装甲内部の配置、射撃停止中でも下肢姿勢の移動へ追従することを追加検証。発射順・間隔・ダウン停止の既存検査は保持。
- mainマージ後に全Python/Godot CIを実行する構成。Android実機で下肢の接合、移動/攻撃/ダウン中の追従と装甲の食い込み量を別途目視確認する。
