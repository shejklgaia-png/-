# SERA v538 — NEXUS全身プレビューの回転軸を胴体中心へ

## 2026年11月22日の変更点

- NEXUSの全身プレビューは、原点（足元）ではなく、セラの**胸・胴体・腰の平均位置**を回転中心として使います。
- 胴体中心は表示開始前に既存の骨格から一度だけ求めます。回転中はその位置をカメラ相対座標で固定し、モデルの原点だけを必要な範囲で回転中心の周囲へ動かします。これは画面上の自動位置補正ではありません。
- **上下ドラッグの反転**、左右ドラッグ、±55°の上下回転制限、初期フィッティング、初期サイズ、選択部位点滅、右メニュー強調は前版のままです。
- 装備データ、戦闘性能、カスタマイズ終了後の拠点でのモデル配置は変更していません。
