# SERA v207 — 背面スラスター方向・ドラッグBOOST・EN切れ警告修正

## 背面スラスター
- 既存の左右ノズルの実ピボット、背面+Zの噴射起点、四角筒の揺らぎ、および左右±38°・上下±24°の機械的制限を維持。
- 旧方式は前方への逆向き要求（後退/後方STEP）で atan2 の符号が急転し、左右の制限角へ突然振れる場合がありました。進行方向の逆ベクトルをノズルのローカル座標へ変換したうえで、ノズルの後方中心へ連続的に射影してから制限角を適用します。
- 元モデル、Blockbenchピボット、移動ベクトル、エフェクト表示アクションは変更していません。

## BOOST操作とEN再開
- BOOST開始範囲は従来どおり168px基準の110%（184.8px）、0.10秒で確定。終了範囲を95%から90%（151.2px）へ変更し、指先の微小な揺れでRUNへ切り替わりにくくしました。
- ENが0になったらBOOSTを停止し、従来の**60%回復までEN消費行動禁止**を維持。
- EN切れによる「指を内側に戻さないと再開不可」のラッチは廃止。外周をホールドしたまま60%へ回復すると、入力し直さず自動でBOOSTが再開します。指を放した場合は通常どおり入力が終了します。
- 通常のガード、被弾、着地、バッシュ、フリックSTEP抑制と元の速度ブレンド・ブースト姿勢余韻は維持。

## EN切れの機体警告
- ENが0になった瞬間に0.60秒間、約7回/秒でセラの機体表面を赤く点滅。
- 別のオーバーレイシェーダーを既存の装備/機体メッシュに適用するため、Blockbenchのパレット、メッシュ、装備カラーを上書きしません。
- 点滅終了後は自動的に元の表示に復帰。KO用表示を優先し、剣撃時の既存の前面表示と共存します。
