# SERA v526 — Android Godotエディターの装備・素材一覧空白を追跡するUI診断

## 状況
同一コードをAndroidエディターから起動した場合は装備・素材一覧が空白となり、署名済みAPK版では正常表示されます。v525でETC2/ASTCインポート設定を統一しましたが、実機で改善しませんでした。Linux Godot上では描画できています。**Androidエディターでの失敗箇所はまだ特定できていません。**

## 検査と追加
- LABO・素材変換・倉庫などの施設画面の見出し右上に **「診断」** ボタンを追加しました。
- 「診断」を押すと、実際に使用中のGodotバージョン、Android/その他OS、セーブ選択状態、Atlas画像の存在、表示段階、生成済カード数、アイコン数、画面内ノード数・表示件数、初回カードの座標とサイズが確認できます。
- 製作7件・素材12件・倉庫素材12件を生成する途中に実行チェックポイントを記録します。Androidでスクリプトが停止した場合、最後に到達できた処理を表示します。
- カードは装飾用の四隅欠けStyleBoxTextureを生成するより前に、標準Buttonとしてノードツリーへ追加します。装飾処理だけがエラーになった場合、文字のある標準ボタンが残る可能性があり、原因を切り分けられます。
- 診断欄は通常は閉じています。ボタンを再度押すと閉じられます。セーブ、アイテム個体ID、素材の計算と保存、戦闘、NEXUSは変更していません。

## Androidでの確認方法
1. GitSyncで最新の`main`を同期し、Godot AndroidエディターからSERA v526を実行します。APKのインストールは不要です。
2. 拠点→LABO→上部の「装備製作」を開き、右上の**「診断」**を押します。
3. カードが空白でも診断欄が表示されるはずです。`Godot`、`stage:`、`created X/7`、`slots:`、`atlas:`、`first:`を含む画面のスクリーンショットを共有してください。
4. 続けて「素材変換」と「倉庫」のタブへ切り替えて診断画面を確認してください。
5. 必要であればGodot Androidエディターの**デバッガー→エラー**の最初のGDScriptエラーを確認します。

## 数値の見方
- `created 0/7`かつ`stage: craft H01 icon`：最初のアイコン画像を作る段階で処理が止まった可能性。
- `created 0/7`かつ`stage: craft H01 saved items`：保存済み装備の読み込み段階が疑わしいです。
- `created 1/7`かつ`stage: skin H01 normal`：四隅欠けStyleBoxTextureを作る段階が疑わしいです。
- `created 7/7`かつ`slots: 7 visible 7`なのに画面は空白：カード生成はできており、Androidの実描画・CanvasItem・クリッピング・実行エンジンの違いを優先して調査します。
