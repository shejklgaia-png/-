# SERA v121 — Command Nexus の遠近・設備表示位置調整（2026-11-08）

## 要求と基準
- 基準は `main` の v120（`5e0482ad6431eaed884ee8ad9e01fd7e93e6b5b0`）。
- 参考画像1枚目の、**近景＝TRAINING／SYSTEM端末、中景＝セラと整備台、遠景＝DATA ARCHIVE／DEPLOYMENT** という構図に寄せる。
- ユーザーのv120実機画像を参照。左上の `SERA SYSTEM / COMMAND NEXUS` 文字を削除し、奥の2設備の見出しを前景設備と重ならないよう上方へ移す。
- 設備内タップ処理は引き続き実装しない。起動時の2択は残す。

## 遠近感の実装
- 手前端末をカメラ側へ、奥の設備をさらに奥へ移し、投影倍率の差を拡大。
- 端末は視界内へ収まるよう内側へ少し寄せ、出撃ゲートも全体が画面内へ収まるようサイズを微調整。
- セラと整備プラットフォームは同じ量だけ後方へ移し、位置関係を維持。
- カメラは少し低く・近くし、視野角を広げて前景と遠景の差を強調。背景を画像に置き換える処理はしていない。
