# SERA v346 — ビットタラン4脚IK接地

## 新機能
- ビットタランの両前脚・両後脚の2ボーン解析IKを追加しました。各Footメッシュから接地点を取得し、接地した足をワールド空間に固定します。
- 前右＋後左、前左＋後右の対角ペアを交互に持ち上げます。最低2脚は常に接地し、旋回や胴体上下動でも脚で補正します。
- IKは移動・旋回・体の上下動を計算した後に毎物理フレーム更新します。初期姿勢は`Wait`、歩行中の補助モーションは`Idle/Turn/Approach`。
- Blockbench正本 `models/bosses/Bittaran.bbmodel`、ユーザーオリジナル `models/storage/ボステスト (2).bbmodel`、元アニメーションUUIDは無変更です。

## IK設定値
| 項目 | 値 |
|---|---|
| 脚の踏み替え開始偏差 | 0.38m |
| 踏み替え時間 | 0.52秒 |
| 足先リフト | 0.19m |
| 移動時の前方着地リード | 0.14m |
| 踏み替えクールダウン | 0.09秒 |
| テレポート再接地の判定距離 | 0.75m |
| ヨー瞬間変化の再接地判定 | 1.4rad |
| 接地面 | Y=0m |
