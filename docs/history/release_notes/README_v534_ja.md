# SERA v534 — ビットタランの可変速ダウン・4足接地・踏み替え復帰

## 2026年11月22日の更新
- 前脚ダウン_L/R・後足ダウン_L/Rの原本モーションを変更せず、再生速度のみ可変にする。
- 原本上の0.0秒で100%、0.5秒までに30%へ滑らかに減速。0.5〜0.6秒は30%を維持し、0.6〜1.75秒で滑らかに加速して基本55%へ到達。
- 脚の破壊でモーションを即開始し、1.75秒の作者接地キーフレームに到達するまでダウンタイマーを開始しない。前脚・後足ともそのポーズを保持し、着地時に胴体全域の灰色土埃を1回だけ発生。
- 落下中は四肢の実メッシュ足先の最低点を毎フレーム調べ、骨格IKで4足の床接地を保つ。浮き・床への埋没を防止し、元モデルの頂点・骨格を変更しない。
- 接地後の通常2.5秒／4脚破壊6秒のダウン保持が完了してから、対角ペアを2回、計1.16秒で踏み替え。胴体は1.75秒の作者ポーズを保ち、踏み替え完了後に5次補間で1.0秒／1.3秒かけて起き上がる。
- HEADの独立追尾、攻撃、通常移動、既存の土埃エミッター、Android埋込モデルは保持。
