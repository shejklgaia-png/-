# SERA v444 — なぎ払い中、足先メッシュを平面床Y=0に埋めない軽量IK

## 対象
左・右のなぎ払い（`なぎ払い`／`なぎ払い_R`）。踏みつけ・弾き、3本の支持脚IK、攻撃時間配分は変更しません。

## 修正
- v443までの攻撃脚IKは、上肢・下肢・足先の**3メッシュ全体**の最下点を一括評価していました。脚のほかのパーツの接地補正後、足先自身がまだ地面より下に残る問題があり得ます。
- v444は**なぎ払い限定で足先（FrontFoot_L / FrontFoot_R）の直方体メッシュの最下点を優先**します。起動時に足先のMeshInstance3DとローカルAABBをキャッシュし、各フレームは回転済み直方体の最下点を数式で計算します。
- 固定床は**ワールドY=0**。3mmの余裕を目標とし、2mm以内の微小誤差は許容します。足先が床を貫通したときだけ、関節に接続された上肢・下肢の2ボーンIKを実行します。
- IK実行後もまだ足先が床下であれば、**その場合だけ追加1回**再補正します。接地しているときや空中にあるときは、攻撃脚の床補正計算を最小限に留めます。
- **足先のメッシュ単体を移動・回転・床へスナップさせる処理はありません**。親子関節の接続・骨長・脚の原本再生時刻は維持します。
- 別のパーツ（脛など）が低くても、なぎ払いでは**実際の足先メッシュ**の高さを基準にします。これにより過剰な補正で足先が意図せず沈む原因を減らします。

### 最下点の解析式
`lowest_y = (transform * local_box_center).y - (abs(basis.x.y)*half.x + abs(basis.y.y)*half.y + abs(basis.z.y)*half.z)`

真の直方体に対して8頂点の最小値と数学的に同値です。**レイキャスト・物理コリジョン探索・24頂点の走査はありません**。

### 制約
脚の関節長は固定です。足先を持ち上げるのに必要な関節目標位置が物理的な到達範囲を超えている場合、足先の地下残差が生じる可能性があります。その場合も、メッシュを切り離す、足先だけ平行移動する、関節を引き伸ばすなどの処理は行いません。到達不能なケースは診断値として検出します。

## 維持するモーション
- **なぎ払い**：基本姿勢から開始姿勢へ1.00秒 → 往路全体2.00秒（往路終了は開始から3.00秒）→ 復路1.00秒。途中スローはありません。
- **攻撃後**：胴体が基本姿勢に戻った後に、攻撃脚の関節を1.20秒かけて直接Waitへ戻します。踏みつけの振りかぶりを挟みません。
- ゲーム起動時は従来どおりビットタラン戦へ直接入ります。
