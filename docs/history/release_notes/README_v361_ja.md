# SERA v361 — 頭の下にある脚を横倒しにし、頭部が脚の上に乗るダウン

## 新しいダウン仕様

ビットタランが旋回中などに脚を頭部の下へ回り込ませた状態で部位破壊によるダウンに入ると、**頭と足先の水平（XZ）位置**を判定し、近い脚を横へ倒します。

- 判定は**0.6秒の予備動作直後**。各脚の足裏のXZ位置と、頭部前半の実際の当たり判定位置を使います。
- 判定のしきい値は頭・脚のメッシュと当たり判定の大きさに基づいて計算し、0.65〜1.75mの範囲に制限します。高さの差によって下敷き判定は変わりません。
- 条件を満たした最も近い脚を、足首を傾けながら約0.17秒で横倒しにします。離れた脚は通常のIKと接地を維持します。
- 頭が下敷き脚の当たり判定に入る際は、その**頭部と脚の実際の衝突箱**を使用して胴体の前傾角を制限し、頭を脚の上で止めます。頭部関節のニュートラル回転は維持します。
- 下になった脚はAUTOロックの優先度を下げ、**ダウン中の頭部AUTOロックを優先**。MANUALでは引き続き脚を選択でき、ダメージも入ります。
- 起き上がると横倒しと低優先度は解除されます。2.5秒／6秒の既存ダウン時間は変えません。

## 自動検証

`tools/v361_bittaran_head_on_leg_runtime_check.gd`で、旋回後に脚が頭の下へ入った姿勢、横倒し、接触コリジョン、ロック優先度、起き上がりをGodotで検証します。
