# SERA v306 — カタナ1の構えを0.2秒で形成してから接近

## 変更
- カタナK装備時に初段のタップが成立すると、現在表示中の全身ポーズから `Melee_katana` の**時刻0（キーフレーム0）**へ、0.20秒で線形クロスフェードします。この準備中は機体をホーミング移動させません。
- 準備完了後に既存の `MELEE_APPROACH → DASH` を経て接近します。接近中はカタナ1のフレーム0を固定して表示し、命中距離に達したら同じクリップの時間進行を再開して1段目を発動します。
- すでに射程内にいる場合も0.20秒の構え移行を完了してから攻撃を開始します。
- 通常武器の `meleeboost`・キーフレーム終端待機、カタナ2段目、攻撃距離2m、接近速度・上限時間、ロック・入力・SE・カメラは変更しません。カタナの抜刀表示は既存の攻撃4フレーム目（3/24秒）で切替えます。

## 検証
- `tools/v306_katana_approach_self_check.py`：カタナ専用経路と通常武器互換を検査。
- `tools/v306_katana_approach_runtime_check.gd`：タップ→0.1秒→0.2秒、実リグのフレーム0ポーズ、ホーミング開始、打撃再生、通常武器の既存接近を検証。
- 両テストを `tools/sera_ci_manifest.txt` に登録。Android実機の表示と操作感は未検証。
