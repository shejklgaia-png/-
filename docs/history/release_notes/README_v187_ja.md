# SERA v187 — 頭Cのサイズと色を修正

## 原因
v186で統合した頭Cは、元メッシュの幅が標準A頭部の約3.33倍（20対6）あり、首も大きすぎました。元の単体.bbmodelにはテクスチャがなく、既存のパレットから白っぽい範囲を参照していました。

## 修正
- C頭部と首のみ、形状を保ったまま一律**32%**に縮小。頭部幅は6.4、首幅は約4.0 Blockbench単位になりました。
- 標準A骨格に合わせ、頭メッシュの中心を `[0,27.4,0]`、首の中心を `[0,24.4,0]` に配置。首上端と頭下端が重なるようにしています。
- Cのみ、灰青色のマテリアル補正 `(0.60,0.65,0.72)` を追加しました。既存A/B装備・Bの赤色は変更していません。
- 23アニメーション、骨格階層、UV・面情報、保存用の元ファイル `models/storage/頭C (2).bbmodel` は変更していません。
- 装備スナップショットを再生成し、`tools/v187_head_c_proportions_self_check.py` を追加。旧版専用v186テストは新しいバージョンでスキップします。

Godot/Androidの実機表示は未検証です。GitSyncで `main` を同期後、SERA v187のCUSTOMIZATIONでHEAD=Cを確認してください。
