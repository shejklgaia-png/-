# SERA v419 — ビットタランの胴体＋攻撃脚を原本から正確に4方向反転

## 変更方針

原本はBlockbenchに収録された**前左脚（leg_fl）用の「胴体＋太もも＋脛＋足先」**の攻撃アニメーションです。v419からは、踏みつけ（STOMP）・弾き（KICK）・なぎ払い（SWEEP）の3攻撃すべてについて、**同一の反転規則で4方向に展開**します。

| 使う脚 | 反転 |
|---|---|
| 前左脚 leg_fl | 原本をそのまま使用 |
| 前右脚 leg_fr | 左右反転（X） |
| 後左脚 leg_rl | 前後反転（Z） |
| 後右脚 leg_rr | 左右＋前後反転（X＋Z） |

原本の胴体の**Wait基準の回転差分**をモデルの解剖学的な反射平面で反転し、元のWait胴体姿勢へ再適用します。脚は、原本の胴体→3関節の**ワールド回転**を同じ平面で反転し、各脚の実際の親関節に対するローカル回転へ変換します。親関節の回転が異なっても、原本の足先の角度まで一致させるためです。

## 廃止・共通化

- 後足攻撃時だけ、胴体を通常後傾から同角度の前傾へ無理に変えるv414の追加姿勢補正を撤去しました。
- v418の接地から逆算する後足専用の**胴体後角の追加ピッチ**を撤去しました。原本モーションに含まれる胴体回転は反転して再生しますが、攻撃専用の人工的な前傾・後傾を追加しません。
- v404の攻撃別の胴体ピッチ／ロール**減衰**を撤去し、原本の胴体キーをそのまま使います。
- v400の弾きの途中で肩・膝だけ別ミラーへ補間する処理、弾き・なぎ払い・踏みつけで異なっていた関節反転方法を統合しました。
- **攻撃開始フレームから**原本の反転済み3関節を適用します。攻撃中の0.70秒の予備動作で、攻撃脚だけを原本から外してWaitへ固定する処理は行いません。攻撃前の基本姿勢への向き直りは、その前の独立した準備段階で引き続き行います。
- 弾きの足先が地面を這う補正と、毎フレームの原本基準の関節軸回転防止は**前後左右4脚共通**です。打撃開始の原本時刻0から接地処理を行い、再生後に脚全体の床貫通を検査します。脚の関節の原本回転とは接地位置の補正を分離しています。
- 弾きの伸長距離をプレイヤーとの距離に応じて変えないv418の仕様を維持します。照準方向・攻撃判定・頭部の独立追従は従来どおりです。
- 目標床高さへの補正は4脚共通の原本接地高さから算出します。原本の回転に加えて独立した前足／後足の傾斜は作成しません。

## 検証方針

- 新規`tools/v419_bittaran_exact_fourway_authored_mirror_runtime_check.gd`では、**4脚×3攻撃×8時点×3脚関節＝288関節ワールド回転**を、原本の実際のBlockbenchキーを反転した計算値と比較します。攻撃開始時刻0・1/60秒を含み、胴体の反転も検査します。
- 攻撃開始から着地、弾きの地面を這う軌道、床貫通、踏みつけの足先方向、復帰時の位置、繰り返しの軸回転と前右脚の足先回転をGodotの実際の戦闘シーンで検証します。
- 以前の「後足だけ25度前傾する」「攻撃脚を攻撃開始後までWait位置に固定する」「胴体キーを減衰する」というテスト条件は今回の原本ミラー仕様に置き換えました。

Blockbenchモデル原本`models/bosses/Bittaran.bbmodel`と生成データ`assets/bittaran_data.gd`は変更していません。**Android実機のモーションの見た目は別途確認が必要**です。
