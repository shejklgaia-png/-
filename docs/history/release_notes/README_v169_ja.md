# SERA v169 — タップ攻撃時の波紋フィードバック（2026-11-09）

## 仕様
- TRAINING画面で**短いタップによる攻撃が受け付けられたとき**、指を離した位置を中心にシアンの波紋を表示します。
- 直径が拡大しながら薄くなる円環を3本、0.075秒ずつずらして描画します。全体で**0.46秒**、半径約12→86px。発光・ぼかし・画像素材は使用しません。
- 波紋中に新たな指を画面へ置くと、**そのタッチ開始イベントで波紋を即時停止**します。ゲーム操作可能な場所なら既存の固定中心RUN/BOOSTコントローラーを表示します。HUDボタンは従来の操作を維持し、波紋はキャンセルします。
- 成功した短押しタップからの通常攻撃（新規攻撃／コンボ先行入力／Bash後のコンボ先行入力）を対象にします。入力が拒否された場合、ガード・ダメージ・着地・攻撃接近中、フリック・移動では波紋を発生させません。
- タップではないキーボードの攻撃入力は波紋の対象外です。波紋はターゲットのロックオン円・操作領域のグラデーションと独立しています。

## 維持する挙動
- タップ18px/0.32秒、ガード長押し、左右/下フリック、BOOSTの確定/解除、RUNコントローラーの円・装飾・角度入力、攻撃のダメージとモーション、コンボバッファ、シールドバッシュ、カメラ、BGMは変更しません。
- 波紋は`scripts/touch_overlay.gd`の既存CanvasItem描画に追加します。入力を奪う新しいControlは追加しません。
