# セラ v42 — ロックオン円の回転速度を1.5倍に変更

v41を基準に、**2回転（720°）の時間を0.30秒から0.20秒に短縮**しました。回転速度は1.5倍です。

- **近接可能になった瞬間：** 時計回り2回転＋半径62pxから42pxへ縮小（0.20秒）
- **近接範囲から離れた瞬間：** 反時計回り2回転＋半径42pxから62pxへ拡大（0.20秒）
- **色と線幅：** 近接時は赤・5px、距離外はシアン・2px（状態の切替時に即時反映）
- **中央の十字：** 回転させない
- **アニメーション途中で条件が反転した場合：** 現在の角度と半径から逆方向の2回転を開始

`scripts/touch_overlay.gd` の `LOCK_SPIN_DURATION = 0.20` を調整すれば、今後も速度変更できます。

変更範囲は `touch_overlay.gd` の時間定数と説明コメント、`project.godot` の名称、およびREADMEのみです。剣エフェクト、モーション、移動、カメラ、ダメージ、HP0時の攻撃には変更を加えていません。

ファイル差分および回転回数・時間・条件切替の静的確認を実施。Godot実行ファイルとAndroid実機による起動・描画検証は未実施です。
