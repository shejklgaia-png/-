# セラ v34 — プレイヤー最前面・ターゲット重複部のみ透過

基準: **v33**、斬撃の位置はv28由来の**プレイヤー前方0.55m**、色は白、Blockbenchの位置・角度・拡大アニメーションと8コマUVは**変更なし**です。

## 修正点

1. **斜め左から白い板が出る問題**: 立体シェーダーの不透明度に入っていた定数項（0.27）を廃止し、画像のアルファ値が低い領域は `discard`。立体レイヤーの初期表示率を0.42に設定。
2. **ターゲットの手前に斬撃が見えない問題**: 斬撃の深度テストを無効に維持し、ターゲットを隠すことなくエフェクトを上描き。
3. **ターゲット重複部だけの透過**: 深度テクスチャと不安定な「深度表面からの推定識別」を廃止。カメラからの視線と実物の2m立方体の交差を直接計算し、対象のシルエット部分だけ斬撃の不透明度を58%に。境界は8cm相当でなだらかに変化。
4. **プレイヤーを最前面に**: Seraの既存24前後のモデル部品の材質に、必要な攻撃の表示時間だけ二次描画パスを追加（`material_overlay`）。斬撃の優先度100〜110、通常の命中火花120、プレイヤー重ね描画126。元の3Dメッシュ・テクスチャ・アニメーションは変更しません。
5. **他の場所は変更しない**: 粒子生成ロジック、攻撃判定、カメラ、移動の基本処理は同じです。

## 設定箇所

`scripts/sword_trail.gd` の先頭:

```gdscript
@export_range(0.0, 1.0, 0.05) var flat_layer_opacity: float = 1.00
@export_range(0.0, 1.0, 0.05) var volume_opacity: float = 0.42
@export_range(0.0, 1.0, 0.05) var target_overlap_opacity: float = 0.58
@export_range(0.001, 0.5, 0.01) var silhouette_feather_m: float = 0.08
@export var debug_disable_target_mask: bool = false
```

`target_overlap_opacity`: 0.0でターゲットに重なる斬撃だけ消去、1.0で全面通常表示、0.58が初期値です。`debug_disable_target_mask = true`でターゲット重複部の透過だけ無効にできます。**プレイヤー優先表示はそのまま**です。

## 注意 / 検証

- この方法は**ターゲットの画面上のシルエット**に基づく透過です。物理的にメッシュが立方体へ侵入した深さを評価する方式ではありません。
- プレイヤーの重ね描画は、不透明物体も含めてプレイヤーを優先するため、他のオブジェクトが間に来る場面ではプレイヤーも手前に見えます（現状の単一ターゲット戦では仕様として妥当）。
- 実機画面での半透明合成や透明モデルの部品同士の重なりは、機種・描画方式により確認が必要です。

GodotのMobile/Compatibilityの深度テクスチャの差異に依存せず、元のGL Compatibility構成を維持しています。
