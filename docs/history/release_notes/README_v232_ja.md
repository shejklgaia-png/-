# SERA v232 — 左右画面端で外へBOOSTした際の微振動対策

## 確認した現象
9.35秒の参考動画`1000034531.mp4`では、機体が画面左端へ向けてBOOSTする間、カメラの背景格子やターゲット位置に細かな揺れが見られました。前回v230の角度補正バイパスはターゲットから6m以内に限定されており、遠ざかると画面端のYaw補正が復活する構造でした。

## 修正内容
1. **距離を問わずBOOST中の強制旋回を停止。** 通常の滑らかなターゲット追従だけで角度を変え、自機とターゲットの安全枠はズームで維持。離指直後のBOOST姿勢維持中も同じ制御を適用します。
2. **BOOST専用のカメラ距離計算を導入。** 従来は必要ズームを調べる際にカメラを繰り返し仮配置し、最大22回の拡大探索と16回の二分探索を行っていました。新方式では画面の縦横比、カメラFOV、現在の視線、機体の上端/下端/体幹とターゲット立方体の角を使い、必要な距離を直接求めます。
3. **ズーム保持の振動防止。** BOOSTのフィット半径は必要半径+0.12mを下回らず、余裕ができたときだけ最大1.25m/秒で小さくします。画面端の境界で拡大・縮小を毎フレーム繰り返さない構造です。

## 保持した仕様
- RUNとSTEPは従来の画面端・近距離カメラ制御
- BOOST入力の閾値、移動速度、ENと残像、スラスター
- SLIDE/BOOSTモーション補間、脚IK、モデル原本と攻撃操作
- v231の物理・描画補間とHUDターゲット位置の同期

## 検証
GitHub Actionsで既存回帰検査に加え、画面左右端・近距離・遠距離を含む350ケースの透視投影とズーム保持の数値検証を追加しました。Android実機での微振動解消は未検証です。
