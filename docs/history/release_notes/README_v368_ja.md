# SERA v368 — 2回目以降の部位破壊でも起き上がり・旋回・脚追従を再現／起き上がり1.25倍速

## 再発しなかった原因と修正

2脚目以降の部位破壊では、訓練用の共通`part_break_remaining`硬直が最大**3.5秒**になっていました。ビットタラン自身がダウンして起き上がり始めるタイミングより長いため、起き上がり中でも`Turn`／`Approach`を`Idle`に固定していました。

脚の破壊時はビットタラン専用のダウン・起き上がり状態で動作停止を管理し、重複する通常の部位破壊硬直を解除します。脚ごとの破壊後、胴体がプレイヤーへ旋回し、起立後は脚の着地点が胴体位置に追随する動作を、リスポーンしなくても毎回再現します。

## 起き上がりは1.25倍速

| 動作 | 従来 | v368 |
|---|---:|---:|
| 1〜3脚破壊時の起き上がり | 0.40秒 | **0.32秒** |
| 4脚破壊時の起き上がり | 0.60秒 | **0.48秒** |
| ダウン開始から起立まで（1〜3脚） | 2.50秒 | **2.42秒** |
| ダウン開始から起立まで（4脚） | 6.00秒 | **5.88秒** |

倒れた状態の待機時間は変更せず、**立ち上がる部分だけを短縮**しています。破壊直後の0.60秒の予備動作、頭部の追従70%開始、腕との干渉防止、胴体34°/秒の旋回、起立後の脚着地点の再計算とステップ時間0.58秒を維持します。

`tools/v368_bittaran_repeat_break_fast_rise_runtime_check.gd`で、**同じ戦闘中に4本の脚を順番に破壊**し、毎回の予備動作、物理ダウン、1.25倍速起き上がり、旋回・接近、足裏の接地、着地点追随を確認します。ビットタラン専用CIとSERA全体CIも実施します。
