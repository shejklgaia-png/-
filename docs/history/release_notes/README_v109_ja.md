# セラ v109 — RUN方向転換時の軽い左右バンク（2026-11-07）

- **基準**：GitHub `main` v108（`83eb19cec5dbc1e5b79e9bd04df1ea67927a86b0`）。
- **見た目**：RUN中に右へ旋回すると体を右へ、左へ旋回すると左へ、最大**5度**だけ傾けます。方向が定まると直立へ戻ります。
- **判定**：v108の4方向ブレンド済み方向（前・後・右・左の重みから復元したベクトル）を前フレームと比較し、符号付き旋回速度を計算。初回RUN入力では前フレームの方向を初期化するため、走り始めだけで傾きません。
- **応答**：旋回速度7rad/sを最大傾き5度へ対応させ、傾きの立ち上がり時定数は0.06秒、旋回終了後の復帰時定数は0.20秒。フレーム時間に対して安定する指数平滑化を使用します。180度の真逆への直線的な反転と停止付近では不自然な一方向へのバンクを抑えます。
- **描画範囲**：`Waist`ルートボーンを対象に、v108の4方向走行姿勢合成後、v107の−90度補正後に一度だけ局所Z回転を適用。カメラやプレイヤー本体のTransform、衝突判定は傾けません。非RUN状態に切り替わると残留バンクは停止し、既存の姿勢ブレンドで移行します。
- **維持**：4方向の同位相ブレンド、移動スピード、操作、攻撃・ガード・ブースト・ステップ・ジャンプ、カメラ、BGM、SE、Blockbench/モデルデータ。
- **検証**：`tools/v109_run_turn_bank_self_check.py` に左右の符号、傾き上限、静止時の復帰、30/60fpsの整合、バンク処理の適用箇所と従来機能の不変条件を収録。GitHub側での差分と数式を静的に確認。
