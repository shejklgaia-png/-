# SERA v161 — BOOST開始位置を中心へ近付ける

v160の固定式360°コントローラのBOOST開始距離を**210pxから184.8px**へ短縮しました。指を従来より25.2px短く動かしてBOOSTに入れます。

| 項目 | v160 | v161 |
|---|---:|---:|
| BOOST開始 | 210px（125%） | **184.8px（110%）** |
| BOOST解除 | 184.8px未満（110%） | **159.6px未満（95%）** |
| 判定間隔 | 25.2px | 25.2px |
| BOOST開始の維持時間 | 0.10秒 | 変更なし |
| BOOST速度補間 | 0.15秒 | 変更なし |
| BOOSTモーション保持 | 0.30秒 | 変更なし |
| RUN円の半径 | 112px | 変更なし |

BOOSTの外側に表示される8分割装甲リングと8方向の推進矢印も、新しいBOOST開始線に合わせて内側へ移しました。描画もタッチ開始地点に固定されたままです。

ガード・攻撃・ステップ、移動速度、セラ本体のモーションは変更していません。GodotとAndroid実機での動作は未検証です。
