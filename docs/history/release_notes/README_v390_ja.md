# SERA v390 — 頭部の水平維持・上下追尾、なぎ払いの振りかぶり減速

## 頭部
ビットタランの頭は常時プレイヤーを向きますが、**頭の面は地面に対して水平**に保ちます。胴体が前後や左右へ傾いた場合は、その傾きを頭部ジョイントで打ち消します。プレイヤーの左右への移動には従来どおり頭部が旋回し、**プレイヤーが上下に移動した場合は頭部自体が世界座標のY方向へ滑らかに移動**します。

- 頭部の上下移動範囲：基準位置から最大±0.65m
- 補間：毎秒8の指数平滑化、移動速度上限1.4m/s
- 頭部のアニメーションキー・ブレンドは再生しません
- ダウン中は従来どおり中立姿勢。起き上がり70％から段階的に追尾を再開
- ダウン前の頭を上げる予備動作は、頭を傾ける代わりに上方向への平行移動で表現
- 頭と脚の衝突判定および許容重なり10cm、接近時の追尾揺れ防止を維持

## なぎ払い
制作された`なぎ払い`原本クリップの**往路の終了は原本時刻0.50秒**です。この往路の最後を振りかぶりに見せるため、終了時刻から逆算した0.7秒間を0.2倍速にします。**復路は等倍**です。

| 攻撃モーション内の実経過時間 | 原本キーの進行 | 再生速度 |
|---|---|---|
| 0.00〜0.36秒 | 0.00〜0.36秒 | 1.0倍 |
| **0.36〜1.06秒（0.70秒間）** | **0.36〜0.50秒** | **0.2倍** |
| 1.06〜2.06秒 | 0.50〜1.50秒 | 1.0倍 |

この変更により、なぎ払いの原本1.50秒は**実時間2.06秒**で再生されます。往路の最後でゆっくり振りかぶり、折り返した瞬間に等倍へ戻ります。攻撃前の低姿勢0.70秒、攻撃後の硬直なし・1.40秒の緩やかな通常姿勢復帰、胴体のプレイヤー追尾なしは維持します。
