# SERA v543 — ビットタラン3被弾で次の攻撃を踏みつけに固定・攻撃SE強調

## 2026年11月22日の更新

- **ビットタランがセラの攻撃を3回受けたら、ビットタランの次の攻撃は確定で「踏みつけ」になります。** 1回は実際に敵HPを減らす1接触です。連撃の3段がそれぞれ命中すれば3回と数えます。入力回数・空振り・敵の被弾時のヒットストップは数えません。
- 3回目の被弾で踏みつけを予約し、次の攻撃選択時に通常の技選択・直前技の回避規則を上書きして踏みつけを最優先にします。すでに攻撃中なら、その攻撃は中断せず次の攻撃で踏みつけを選びます。
- 予約後にさらに攻撃を受けても予約は失われず、攻撃がキャンセルされても維持します。通常の戦闘へ戻る前に足裏位置に基づく前足3.7m／後足3.0mの踏みつけ射程へ接近するため、届かない距離から攻撃することはありません。実行を選択した時に予約・被弾カウントを消去。死亡・リスポーンでは初期化します。
- **攻撃開始SE「巨大ロボットが腕を動かす3」**の再生音量を-7→**+4dB**、戦闘BGMを-5→**-8dB**に調整しました。両音の相対差は従来より14dB大きくなります。踏みつけ着弾SEを-5→-3dB、弾きの着弾SEを-10→-4dB、なぎ払いの着弾SEを-9→-4dBへ増音しました。
- 4本の元SE音源、音声イベントの発生時刻と再生回数、踏みつけの原本モーション・攻撃メッシュ・威力、前脚3.7m／後脚3.0mの射程、弾き3.10～6.30m・左右60°、なぎ払いとダウン演出は変更していません。
- 仕様先行テスト `bittaran_three_hits_stomp_v543_self_check.py` と `bittaran_three_hits_stomp_v543_runtime_check.gd` をCIに登録。実際のボスダメージ処理、3回閾値、踏みつけ射程外で保留、脚の左右・前後、キャンセル・リスポーン時の状態、SE/BGMの音量を検査します。
