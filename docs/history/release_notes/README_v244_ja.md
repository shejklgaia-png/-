# SERA v244 — コントローラーとRUN／BOOSTの判定を50%に縮小

## 変更した寸法

| 項目 | 変更前 v243 | 変更後 v244 |
| --- | ---: | ---: |
| RUN操作円の半径 | 112px | **56px** |
| RUNデッドゾーン | 18px | **9px** |
| BOOST基準円の半径 | 168px | **84px** |
| BOOST開始距離（基準の110%） | 184.8px | **92.4px** |
| BOOST解除距離（基準の90%） | 151.2px | **75.6px** |

RUN・BOOST円、補助のエネルギー／推力リング、外装の矢印、現在のRUN／BOOST状態ラベルも半分の寸法へ調整しました。動的コントローラーの中心は**最初に指を置いた位置**から動かしません。

## 変更していない点
- 操作開始はv243の**右下4分の1の長方形枠内のみ**で、ドラッグ開始後は画面全域を操作可能です。
- ロック切替ボタンの位置・大きさとAUTO／MANUALモードは維持しています。
- RUN／BOOSTの最大移動速度・加減速補間、BOOST確定0.10秒、開始110%／解除90%の割合、モーション・EN・カメラは変更していません。
- フリックSTEPの最低78px、タップ/ガードの距離・時間しきい値も変更していません。デッドゾーンが半分になるため、ガードの静止判定範囲内でもRUN入力が発生し得ます。実機操作感は要確認です。
