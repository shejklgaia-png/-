# セラ v91 — 敵攻撃４種・デバッグ切替UI

**基準：v90** `sera_portrait_godot_melee_v90_boost_threshold.zip`。既存のプレイヤー操作、格闘3段、バックステップ4m、ブースト・ステップ分離、モデル、カメラ、残像、UIは維持。

## 上部の「ENEMY ATTACK / DEBUG」バー

- **AIM**：自機狙い弾（警告開始時の自機位置へ直進）。従来の敵射撃に相当します。
- **LEAD**：偏差射撃弾（警告開始時の移動速度から、発射までの警告時間と弾の飛行時間を考慮して着弾点を予測）。発射後は追尾しません。青系の発光で通常弾と区別します。
- **SHOCK**：全周衝撃波（敵を中心に360°へ地表リングが拡大）。
- **ARC**：円弧範囲（警告開始時の自機方向を中心とする145°の扇状・円弧帯）。
- **FIRE**：選んだ攻撃の警告をすぐ開始します。無警告の即時被弾にはしません。
- **AUTO ON/OFF**：約２秒ごとの自動攻撃を有効・無効にします。初期値はONです。OFFでもFIREは使用できます。切替前から進んでいた警告は最後まで実行します。

攻撃種を切り替えると、前の警告を取り消し、旧攻撃の残弾・残留範囲を消去します。AUTO ON中は新しい種類の警告がすぐ始まります。HPが0の敵は既存どおり射撃しません（復帰後に再開）。

バーは従来HUDの直下、仮想解像度720×1280でY=156〜233に表示します。バーで開始されたタッチ操作はドラッグ・タップ攻撃・フリックステップに流れません。

## 敵の攻撃パラメータ（暫定）

| 攻撃 | 警告 | 判定・速度 | 備考 |
|---|---:|---|---|
| 自機狙い弾 AIM | 0.65秒 | 弾速12m/s、半径0.23m | 既存の被弾・ノックバック連携 |
| 偏差弾 LEAD | 0.65秒 | 同じ弾速・半径、最大予測ずれ8m | 予測点への直線弾、発射後追尾なし |
| 全周衝撃波 SHOCK | 0.80秒 | 初期半径1.35m、拡大8m/s、最終半径12m | 波の厚さ0.64m。通過区間と自機の移動を考慮して判定 |
| 円弧 ARC | 0.95秒 | 前方145°、内半径1.0m／外半径5.5m | 予告位置のまま0.19秒だけ当たり判定 |

- 攻撃方向は**警告の開始時に確定**します。弾の発射後や円弧の発動直前に自機へ追従して向きを変えません。
- 偏差は自機の水平移動速度を使う簡易的な予測（上限あり）であり、将来の操作を知るものではありません。
- 衝撃波と円弧は床面の低ポリゴン描画と専用距離・角度判定です。パーティクルや追加のGPUブラーは使いません。
- 衝撃波・円弧で当たった場合にも、既存の被弾フラッシュと`Damageknock`反応を呼びます。シールド値・被ダメージ数値やステップ無敵時間など、**v90に存在しない戦闘システムは追加していません**。
- UIおよびパラメータはデバッグ用の暫定仕様です。実機での予告の読みやすさ、間隔、判定幅を評価してから調整してください。
