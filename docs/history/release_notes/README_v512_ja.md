# SERA v512 — 予測シールドの高彩度・鋭い命中表示

## v511からの改善
- シールドの防御光の**白っぽさ**を抑えるため、専用描画材質を加算合成から通常アルファ合成へ変更。
- 残量による色は鮮明な**青（#007AFF）／黄（#FFE100）／赤（#FF2140）**。中心部の白い閃光は一瞬だけ発生し、主役は鮮やかな色面と外周リング。
- 防御の接触光は発生直後から高い不透明度で強く表示し、すぐに減衰するシャープな表示へ。効果インスタンスの寿命0.44秒は維持（視覚的な減衰は前半に集中）。
- 破壊時の青白い稲妻を左右へ**0.13秒**で伸ばし、**0.32秒**程度で消す。放射状の青白い破裂にははっきりした発光輪郭を追加。
- **表示サイズはv511のまま**：通常の防御光は参考画面基準の半径100〜260px、亀裂は左右各最大470px、破裂は最大半径470px。

## 維持した仕様
- 対象：テストターゲットとビットタラン。HPバーへのシールド重畳なし。
- 本体と通常ヒット火花の間の描画優先度115、深度テストON、命中面からの描画専用オフセット0.14m。
- 青・黄・赤への切り替え閾値100〜60%、59〜30%、29%以下。シールド破壊時のSEと全武器の攻撃判定、敵のモーションは変更なし。
- シールド耐久100SP、近接最大25%・射撃最大95%軽減、最後の命中から4秒後に毎秒20SP回復。

## CI
既存`tools/v510_predictive_shield_self_check.py`と`tools/v510_predictive_shield_runtime_check.gd`の色・材質・時間曲線の期待値を**実装前に更新**しました。旧戦闘/部位破壊/描画/HUDテストは維持し、mainマージ後に全件を実行します。色の印象とキレはAndroid縦画面で実機検証が必要です。
