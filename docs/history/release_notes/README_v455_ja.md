# SERA v455 — ビットタラン攻撃エフェクトのチラつき・瞬間移動・発生漏れ修正

## Android実機動画に基づく原因と修正

| 症状 | 原因 | 修正 |
|---|---|---|
| 粉塵が一瞬で消える／急に別の位置に出る | 10基の粉塵発生器を0.045秒間隔で再起動し、1.12秒の寿命が終わる前に生存粒子を破棄していた | 28基へ増設。各発生器が完全に寿命を終えた場合のみ再利用 |
| 接地位置が跳ねる | 足先メッシュのうち最下部8.5cmの頂点だけを採用する不連続な座標計算 | 最低頂点への高さに比例する滑らかな指数加重平均へ置換。大きな軌道ジャンプでは新たな粉塵を描かない |
| 連続したエフェクトが途切れる | FX生成にもダメージ用の厳しい接地判定（足元6cm以内）を使用していた | **VFXに限って**床付近12cmまで許容。被ダメージ／当たり判定は一切変更しない |

なぎ払いは、足先が地面を最初に這う区間だけ高密度のワールド固定粒子を出し、戻り動作・余韻で新規発生しません。踏みつけと弾きは実際の足先の接地位置から発生し、石は地面に落ちたら消えます。

**Blockbench原本・アニメーション・当たり判定・AI・IKは変更していません。** 新しいGodotテストで粒子プールの寿命、急な足先移動、前後4脚なぎ払い／踏みつけ、左右前脚弾きのFX発生を検証します。

Android実機での見た目、半透明粉塵の描画、fpsはGodot headlessテストでは評価できないため、再ビルド後の目視確認が必要です。
