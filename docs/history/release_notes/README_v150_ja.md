# SERA v150 — 360°コントローラの滑らかな描画（2026-11-09）

v149で導入した方向矢印が、指の入力イベントごとに飛ぶようなカクカクした見た目になる点を修正しました。

- **矢印の位置：** 指の位置を毎フレーム追いかけるように滑らかに補間（時定数0.040秒）。
- **矢印の角度：** 360°全方向への変化を毎フレーム補間（0.052秒）。0°と360°の境界も最短方向に回転。
- **BOOSTチャージ円弧：** 蓄積ゲージを滑らかに変化（0.070秒）。
- **矢印の形状：** 鋭い三角形の塗りつぶしから、丸い端点を持つアンチエイリアスの線画に変更。RUN/BOOST表示、二重矢印とロックオンリングは維持。
- **表示の省電力：** ドラッグ中は毎フレーム更新し、指を離してロックオン回転も終了したら更新を停止。

**セラの実際の360°入力は補間せず即時反映**します。RUN/BOOSTの速度、同一方向140pxのブースト判定、方向転換時のBOOST解除、タップ攻撃、長押しガード、フリック回避は変えません。

プロジェクト名は`SERA v150`。静的検査と補間式の数値検査は`tools/v150_smooth_swipe_hud_self_check.py`を参照してください。GodotとAndroid実機での描画は未検証です。
