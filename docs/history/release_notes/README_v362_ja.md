# SERA v362 — ダウンから正常姿勢に戻るまで旋回・接近を停止

## 変更内容

ビットタランがダウン中に旋回（`Turn`）や接近（`Approach`）モーションを再生したり、起き上がる途中で移動を始めたりしないよう、ダウンの状態とAIの再生条件を連動させました。

- **ダウンの予備動作中（0.6秒）・ダウン中（通常2.5秒／全脚破壊6秒）**は`Idle`を維持し、敵本体の回転・接近を停止します。従来の頭上げ、脚のスライドや接触、起き上がりIKは引き続き再生します。
- ダウン時間が終了しても**即座には`Turn`／`Approach`へ切り替えません**。胴体の落下量がゼロになり、脚の支持状態が戻ってから、さらに**0.24秒の`Idle`姿勢安定時間**を設けます。
- 正常姿勢に戻り次第、敵AIを解除し、プレイヤーとの距離・向きに応じて旋回・接近を再開します。
- 途中で別の脚を破壊すると、従来どおりダウン期間を更新し、正常復帰まで停止を続けます。リスポーン時には待機状態をクリアします。
- ダウン中の頭部優先AUTOロック、下敷きになった脚の横倒し・頭部接触、2.5秒／6秒のダウン時間は変更しません。

## 検証

`tools/v362_bittaran_standup_motion_gate_runtime_check.gd`で、単脚ダウンからの`Turn`再開と、全脚ダウンからの`Approach`再開をGodot実環境で検証します。起き上がり完了前のモーション・本体位置・Yaw回転と、その後のIdle姿勢安定時間をチェックします。
