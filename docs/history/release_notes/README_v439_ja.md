# SERA v439 — なぎ払いの全体0.6倍速を取り消し、往路前の移行を1.00秒へ

## 今回の変更
- なぎ払いの**0.6倍速化（v438）を取り消し**ました。原本クリップ0.00〜1.50秒の再生時刻は、v437のHermite速度曲線／後半0.20倍速／復路1.00倍速に戻しています。
- **往路に入る前の基本姿勢→攻撃開始姿勢の補間を1.00秒**へ延長しました（変更前0.32秒）。攻撃原本0秒の姿勢に滑らかに到達してから、原本の往路再生を開始します。
- 左右の「なぎ払い」を同じ条件に変更しています。
- 弾き・踏みつけの攻撃前補間0.32秒／本体再生／硬直／復帰、および攻撃中の非攻撃脚3本のIKは変更しません。
- 起動時のビットタラン戦直行設定（`project.godot: run/main_scene="res://scenes/bittaran_battle.tscn"`）は維持します。
