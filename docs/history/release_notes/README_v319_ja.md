# SERA v319 — 立ち→RUNの着地ブレンドと追撃判定

## 立ち→通常RUNのモーション

- 停止（WAIT）から通常RUNへ移行する際、既存のJump着地アニメーションの途中姿勢を一瞬ブレンドします。
- 着地区間（0.375～0.500秒）の**45%地点**を参照。着地モーション全体は再生しません。
- 遷移時間は**0.11秒**。着地姿勢の混合率を0→最大62%→0と滑らかに変化させてから歩きモーションを開始します。
- プレイヤーの実移動は即時。BOOST、STEP、格闘、実際のジャンプ・バク宙着地には追加しません。

## 部位破壊後・敵撃破後の攻撃

- 頭・四脚は、破壊後もモデル・攻撃用当たり判定・移動衝突・ロック対象を保持します。
- 共通HPが0になっても、復活するまでの間、通常格闘・カタナ・Bash・左右蹴り・後方サマーソルトで命中できます。
- 被弾演出・ヒットストップ・ダメージポップアップは継続します。表示するダメージは、攻撃力と対象防御率から算出した**防御適用後のダメージ**です。残HPが3でダメージ20なら「20」、HP0への追撃でも「20」と表示します。
- 共通HP・破壊済み部位の耐久は0未満にしません。重複の破壊イベントや撃破カウントは発生させず、既存のリスポーン処理・敵の撃破時攻撃停止を保持します。
