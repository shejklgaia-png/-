- **8分割の外殻リング：** 元のBOOST距離を基準に半径約225pxに表示。
- **8方向の外向き推進矢印：** 半径約235〜252pxの範囲に表示。
- **BOOST中の明度：** 通常時は控えめ、BOOSTモード中は明るく強調。
- **モード表示：** 最外周の装飾に重ならない位置へ変更。

中央のRUN円（112px）とBOOST判定（開始210px、解除184.8px未満）、方向入力、速度、モーション、0.30秒のBOOST姿勢保持はそのままです。
