# SERA v250 — 本体500HPと各部位100HP

| ターゲット | 旧最大値 | 新最大値 |
| --- | ---: | ---: |
| 本体（共通HP） | 100 | 500 |
| 頭部（破壊耐久） | 38 | 100 |
| 左右前脚（破壊耐久） | 各30 | 各100 |
| 左右後脚（破壊耐久） | 各32 | 各100 |

**部位HPは本体HPと独立した破壊耐久です。** 通常攻撃力で本体の共通HPを減らし、部位破壊力でロック対象部位の耐久値を減らす仕組みを維持しています。部位HPの合計を本体HPから差し引く方式には変更していません。

本体の残りHPラベル・ゲージは500を表示し、残量の色変化は従来と同じ40%（200HP以下）です。LOCK/PARTS表示は各部位の100HPを表示します。復活・訓練リセットですべて最大まで回復します。

攻撃力・破壊力、部位防御率、頭部/脚破壊時の挙動、攻撃ロック、敵物理形状、操作・アニメーションは変更していません。Godot/Android実機動作は未検証です。
