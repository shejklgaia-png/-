# SERA v278 — 左右蹴りのモーション速度を半分に変更

Kick_l、Kick_rのゲーム内モーション再生時間を従来の2倍（再生速度50%）にしました。元のBlockbenchキーフレームとモデルは変更しません。

通常STEPの速度・移動距離は維持します。蹴りの移動は従来の所要時間で完了し、後半はその位置で蹴りモーションだけ最後まで再生します。

左右蹴りそれぞれ2回の判定は、原本0.25秒・0.58333秒の足の伸展キーで発生します。バッシュと共通の追尾時間は実時間で最大0.2秒のままです。

Kick_b（サマーソルト）、通常STEP、攻撃や装備、背面スラスターの仕様は維持しています。Godot 4.7.2のCIで実際の再生、判定、移動速度・距離を検証します。Android実機では未検証です。
