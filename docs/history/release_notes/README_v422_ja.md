# SERA v422 — 後足攻撃の胴体高さを原本の付け根の高さへ合わせる

## 変更方針

後足（leg_rl / leg_rr）の弾き（KICK）・なぎ払い（SWEEP）では、シャーシの上下補正を従来の「クリップ開始時点の足裏高さから決めた一定量を、攻撃中ずっと均等に引く」方式から、**攻撃脚の付け根の高さを、同じクリップ時刻における原本（前左脚）の付け根の高さに毎フレーム合わせる**方式へ変更します。前足の攻撃は従来どおりです。

## 理由と実測

- 従来の一定量の均等な下げ（後足で約−1.45m）は、前後反転した胴体ピッチで後ろの付け根が下がる分と二重に効き、胴体全体が沈んで床ガードが軌道を平らにしていました。
- 対称配置（各脚の付け根の角の方向へプレイヤーを配置）で実演モーションを左前脚の鏡像と比較した実測では、後足の弾きの足裏偏差が予備動作 2.84m → 1.90m、打撃 2.20m → 1.39m に改善し、打撃中の関節ジャンプも 104°/tick → 65°以下に収まりました。
- 弾き・なぎ払いの軌道は「付け根相対」で原本から移植されるため、付け根の高さそのものを原本に合わせるのが前提条件として直接的です。

## 残る既知の差異（今回は変更しない）

- 伸び切り時の**実メッシュの足裏**は、鏡像の到達点から約1.29mずれます（当たり判定などに使う足裏点は毎フレームfitされる側で正確です）。後足の足関節ローカルフレームは前足対の鏡像ではないため、足首位置・足の角度・メッシュ足裏を同時に厳密一致させることはできません。足の角度を曲げて足裏を合わせる方法は試算済みで、伸び切り時の足の傾きが原本の約9°に対して約33.7°になるため、どちらを優先するかは設計判断として残します。
- 予備動作の折り畳み形状は、前後反転した胴体ピッチから吊られるため原本の折り畳みと差が残ります（折り畳んだ足裏が約0.94m浮く件を含む）。胴体の前後反転そのものの見直しとあわせて別途判断します。

## 検証

- 新規 `tools/v422_bittaran_rear_hip_alignment_runtime_check.gd` で、対称配置の実演モーションを左前脚の鏡像と比較し、後足弾きの予備動作・打撃の偏差上限と関節ジャンプ上限、前足の厳密性（前右脚の弾き保持 0.10m以内・なぎ払い 0.20m以内）を検証します。
- 全件スイート（静的・Godot）で回帰がないことを確認します。Android実機での見た目の確認は未実施です。
