# SERA v477 — ビットタラン砲台の青球体チャージで高速追尾

## 時間と追尾
- **0〜10秒：充填。** 側面ランプを10秒間かけて充填。砲台は基本姿勢から動かさず、プレイヤーが動いても追尾しません。
- **10〜12秒：チャージ。** 青い球体が出現した瞬間に1回だけ追尾を開始。最初の0.7秒は滑らかに追尾が加速し、その後は角速度上限を設けずRUN／BOOSTの速度や急な方向転換にかかわらず照準を合わせます。青球体の縮小が終わるまで高速追尾を継続します。
- **12〜14秒：レーザー発射。** 球体が消えてレーザーが発射された瞬間から、従来どおりRUNより速くBOOSTより遅い装備連動の角速度上限へ切り替えます。射線の追尾は停止しません。
- **14〜14.7秒：復帰。** 砲台を0.7秒かけて基本姿勢に戻し、次の10秒間の充填中は静止します。

## 維持する仕様
- 球体の拡大0.2秒・縮小1.0秒、ビーム2秒、発射前後の停止遅延なし。
- 1照射最大1ヒット、Damageknock、ガード、距離・ビーム幅、青い球体・レーザーFX、Blockbenchモデルと脚の挙動。
- 砲台の回転はワールド水平回転と上下俯仰のみ。照射中は元の装備速度依存の旋回制限を使用し、BOOSTで振り切れます。

## テスト
- `tools/bittaran_railgun_runtime_check.gd` で10秒間の無追尾・基本姿勢、チャージ開始の0.7秒平滑導入、球体縮小までの速度無制限追尾、発射瞬間の速度制限切り替え、RUN/BOOST回避差、1照射1ヒット・ガード・基本姿勢復帰を確認します。
- Android実機の目視・回避操作は別途確認が必要です。
