# SERA v404

## 概要
v403 の実機フィードバック対応です。「まだおかしい」という報告を受けて動画と実シーン計測で分解したところ、至近距離の攻撃に2つの別々の問題が残っていました。どちらもビットタランの攻撃ポーズ側の修正で、移動・旋回・攻撃タイミング等の数値は不変です。

## 1. 攻撃中の胴体のねじれ（弾き／なぎ払い）
- 弾き・なぎ払い共通の Body トラック自体が、Wait から前傾 34.4°＋横傾き 19.7° まで回転し、クリップが最大点で終わるため、弾きの 1.5 秒ホールド中ずっと最大にねじれた姿勢で固まっていました。胸の追尾回転（45°）と重なり、実測で前傾 33.5°・横傾き 21.1°。
- 修正: Body トラックの前傾・横傾き成分だけを減衰（弾き: 前傾・横傾きとも 45% で約16°・約7°／なぎ払い: 前傾 60%・横傾き 45%。なぎ払いの前傾は脚の弧を腰より低く保つ役割があるため、45% では足首が腰より上がってしまうことを計測で確認し 60% にしました）。タイミング・向き・横回転は元のまま、重い屈み込みと重心移動のニュアンスは残ります。
- 脚側は、減衰前の Body 姿勢を基準に作られた脚ポーズのワールド向きを保つよう、攻撃脚の付け根に補正を入れてあります（減衰した分だけ脚の向きが傾く副作用を打ち消すもの）。そのため脚の軌道・足先の角度は従来のままです。

## 2. 至近距離の弾きの突き抜け（特に右前脚・正面付近）
- 弾きは常に脚の全長（腰から約 4.7m）まで伸び切るため、腰から 2m 弱の位置にいるプレイヤーを脚が 3.5m も通り過ぎ、つま先は 5.2m 先まで突き抜けて、そのままホールドしていました（方向自体は v403 で修正済みで、ずれ 0°）。
- 修正: 腰→狙い点の距離からリーチ係数を計算し、脚ポーズを Wait 側へブレンドして届く長さを調整。至近距離では脚がプレイヤー付近で止まる短い蹴りになり、中距離では従来どおり届きます。係数とリーチの関係は実シーンで較正済み（係数 0 で約 2.30m、0.7 で約 4.5m）。
- 肩の照準は短くなった脚そのものをサンプルするので、v403 の方向修正はそのまま有効です。
