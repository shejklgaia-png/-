# SERA v488 — なぎ払い振動を攻撃判定中だけに限定

## 変更点
- 画面振動の発生条件を、なぎ払いモーション全体ではなく、**実際に足先・下肢の攻撃判定が有効な原本キーフレーム区間**だけに変更しました。
- **前足左右**は原本アニメーション時刻 **0.67〜1.38秒**、**後足左右**は **0.17〜0.63秒** の間だけ中揺れを約0.14秒間隔で継続します。
- 命中後に1攻撃1ヒットの制限が発生しても、攻撃判定の時間内なら画面振動は継続します。予備動作、判定のない振り回し区間、終了後の余韻、復帰中には振動しません。
- なぎ払いだけ独立した振動チャンネルを使用し、攻撃判定の終了時には残留振動も**即座に停止**します。ほかの攻撃・歩行の指数減衰には影響しません。
- 土埃の発生タイミングと当たり判定は独立したまま維持し、判定外の土埃によって新しい揺れが始まらないようにしました。

## 維持する仕様
- 踏みつけの大揺れ＋高速収束、弾きの瞬間的な大揺れ、歩行の0〜10m水平距離減衰、縦方向優位の振動、全攻撃の既存ダメージとモーション。
- レールガン、モデル原本、IK、関節アニメーション、UI、拠点画面、サウンドに変更なし。

## CI
- `tools/bittaran_camera_shake_runtime_check.gd`の旧「strike中は振動」の期待値を実装**前**に更新。前後左右4脚それぞれの攻撃判定開始直前・開始・途中・終了・終了直後、命中済みでも判定中は継続すること、判定外のカメラオフセット即時ゼロ、土埃発生からの判定外バイパス防止を追加しました。
- 既存の`tools/bittaran_keyframe_hit_sector_runtime_check.gd`が攻撃判定の正式な原本時刻を継続検証します。既存の当たり判定・攻撃モーションの期待値は変更していません。
- マージ後にmainの全Python/Godot CIを実施します。Androidで前脚0.67〜1.38秒／後脚0.17〜0.63秒の揺れを実機確認してください。
