# SERA v251 — ターゲットへのめり込み防止（移動衝突判定）

## 対象と方式
- 既存の本体用 `TargetSolidBody`（`AnimatableBody3D`）に、頭部・前後左右4脚の **BoxMesh と同じサイズ・座標の `BoxShape3D`** を追加。外側フレームの空洞まで大きな1箱で埋めず、実際に見える構造を基準にします。
- 脚の本体側の付け根には、それぞれ **幅0.96×高さ1.85×奥行0.62m** の透明な接続判定を重ね、胴体と脚フレームの隙間への進入を遮断します。頭部は既存のNeckMountを直接コライダー化するため別の付け根判定はありません。
- 本体、部位、接続判定は**同一の移動する物理ボディ**に所属するため、ターゲットの移動・上下動にも追従します。実行中の部位メッシュは現時点では回転しません。
- プレイヤーの既存カプセルと `TARGET_COLLISION_LAYER` を使用し、RUN/BOOSTの`move_and_slide`、全方向STEPの`_move_player_swept`、ジャンプ（デバッグ）・ノックバックに共通適用します。格闘追尾の`_move_player_swept`も接触時の水平スライドを有効にします。
- 最初から見えるBoxMeshすべてに固定の物理判定を設置するため、通常プレイ中にメッシュから衝突形状を再計算しません。初期状態で非表示の頭部破損メッシュは、可視化後に衝突を有効にします。

## 部位破壊・リセット
- 前脚（`remove`）は部位破壊で見た目と移動用コライダーの両方を無効化。リセット・復活時にすべて復元します。
- 頭（`change`）と後脚（`remain`）は破壊後も残存するため、既存表示と一致するよう物理判定を維持します。頭部の破損メッシュも破壊後に衝突を持ちます。
- `CollisionShape3D.disabled` は物理処理中の書き換えを避けるため `set_deferred` で変更します。

## 変更しないもの
- **攻撃命中判定**（v249のロック部位限定AABB）、AUTO/MANUAL選択、各部位100HP・共通本体500HP、攻撃威力、破壊防御率、敵攻撃、セラ操作・モーション、カメラ、レンダリング、原本モデル。
- 接近角度のハード制限は付けていません。衝突判定によって進入を抑え、格闘追尾では接触面を滑ります。

## 検証と制約
- v251用静的回帰チェックを既存のGitHub Actionsに追加。実機の物理接触とAndroid描画・操作性は未検証です。
- 多数の小さな固定BoxShapeを持つ試験実装のため、端末で衝突時の引っかかり・カメラ挙動・負荷の確認が必要です。既存の移動・ジャンプ・KO機能に問題があれば次版で判定の統合や形状調整を行います。
