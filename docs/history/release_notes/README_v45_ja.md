# セラ v45 — 左右フリック・ステップ

v44を基準として、左右への高速短距離ステップを追加しました。カメラ、ロックオン、ドラッグ移動、タップ攻撃、斬撃エフェクトはそのまま保持します。

## 入力仕様

- **通常ドラッグ**：指を置いて動かし続ける間は、以前と同じ画面座標基準の移動です。フリック判定はドラッグ中に実行しません。
- **短い左右フリック**：指を離した瞬間に、変位が横78px以上・操作時間0.24秒以下・横方向の平均速度500px/s以上・縦変位が横変位の42%以内ならステップを発動します。途中で大きく逆戻りした軌跡は除外します。
- **タップ**：以前どおり、移動18px以内かつ0.32秒以内なら近接攻撃します。
- **方向**：フリックを離した瞬間のカメラの水平右ベクトル（左フリックは逆方向）。プレイヤーはその間もターゲットを向き続けます。
- **ステップ距離**：2.2m。所要時間0.26秒、前半で素早く移動し後半で減速。フレームレート非依存。
- **ステップ中に別のドラッグを開始**：新しいドラッグが18pxを超えたらステップを中断し、通常のドラッグ移動を即座に再開します。
- **ステップ中のタップ**：攻撃は開始しません。ステップ後の通常タップで攻撃できます。

## Blockbenchモデルについて

今回添付された `Step_R` と `Step_L` はどちらも**長さ0秒・キーフレームは時刻0のみ**でした。Godot側では各ポーズに0.055秒で補間して入り、0.11秒で通常待機・走行に戻します。複数キーフレームのステップモーションではありません。後日Blockbenchで時間付きキーを追加すれば、取り込み方式を変更せずに時間付き動作へ拡張できます。

取り込みソースは `assets/sera_source.json` に保存し、Android側での参照失敗を防ぐため `assets/sera_data.gd` を再生成しました。`blockbench/セラ･カラーエフェクト付き.bbmodel` に原本を収録しています。

## 操作確認

スマホでは短い水平方向のフリック→指を離すとステップし、指を置き続けて横へドラッグすると通常移動します。PC版ではマウス左ボタンで同等の操作を試せます。実機で誤検出があれば、`scripts/main.gd` の `STEP_FLICK_*` 定数を変更してください。
