# SERA v460 — ビットタランの攻撃距離を4脚ごとに判定

## 修正した問題

v459以前の攻撃種類の決定はボスの胴体位置からプレイヤーまでの距離を使用していました。そのため、プレイヤーのすぐ隣にある脚が踏みつけできる距離でも、胴体が離れていると弾きやなぎ払いになることがありました。

v460では、4脚すべての**現在の実際の足裏（IK適用後）のXZ座標**を取得し、脚とプレイヤーとの実際の距離で技を選択します。

| 技 | 脚からプレイヤーまでの水平距離 | 角度・脚制限 |
|---|---|---|
| 踏みつけ | **3.00m以内** | 前後左右4脚・全方向 |
| 弾き | **3.75〜5.15m** | 前脚のみ・足先からボス正面方向±38° |
| なぎ払い | **2.70〜7.10m** | 前脚±115°・後脚±165°、脚ごとの足先方向で判定 |

- まず脚ごとに技の射程と角度を照合し、適した技を踏みつけ→弾き→なぎ払いの順で検討します。技を決めたらその技が実際に届く脚から最も近い脚を選択します。
- 同じ種類の攻撃を続けることはありません。次の異なる攻撃が成立する距離まで通常歩行で移動します。
- 3歩歩いてから攻撃する仕様、元のアニメーションと接地判定、攻撃FXは変更していません。

**Android実機の操作感は新規Godot実戦テスト後に別途確認が必要です。**
