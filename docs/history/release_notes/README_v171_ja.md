# SERA v171 — データアーカイブと3スロットセーブ

## 操作
拠点で奥の「DATA ARCHIVE」を選択すると、既存の3D設備とカメラを維持したまま
3件のデータスロットを表示します。スロットを選んで SAVE / LOAD / NEW DATA /
DELETE をタップしてください。戻るボタンは従来どおり画面右下です。

- **SAVE**：選択したスロットへ現在の装備（頭・胴・下半身・腕・左右武器）、
  トレーニングの累積時間、最終利用エリア、将来のチュートリアル状態を書き込みます。
  既存スロットへの上書きは同じコマンドを再タップして確定します。
- **LOAD**：既存スロットをアクティブにし、装備を即座にセラへ反映します。
  装備はトレーニングに移動しても引き継がれます。
- **NEW DATA**：初期装備A、プレイ時間0、初期フラグで新規開始。
  既存スロットに作成する際は二度押し確認が必要です。
- **DELETE**：二度押しでスロットを削除。アクティブデータを削除した際は
  作業装備をAに戻します。別スロットは消しません。

セーブ先は端末内の `user://sera_archive/index.json` と
`user://sera_archive/slot_01.json` ～ `slot_03.json` です。
GitHubのGodotプロジェクトやGitSync対象フォルダには含まれません。
`user://sera_equipment.cfg` は従来との互換目的で保持していますが、
アクティブなデータがある間はスロットの作業装備が優先されます。
カスタマイズ変更はアプリ起動中・シーン間で保持され、
**SAVEを押すまでセーブスロットには確定されません**。

## 今回の範囲
現在のゲームには正式なチャプター進行・チュートリアル進行ロジックが
未実装のため、`tutorial_completed` は将来用の初期フラグです。
LOADでは装備・累積時間・メタデータを復元しますが、トレーニング中の
敵HPや立ち位置を再現するものではありません。ゲーム本体の入力・戦闘と
カメラはそのままにしています。アプリ削除や端末変更ではローカルセーブが
失われる場合があるため、必要なら端末側でバックアップしてください。

## 検証
`python3 tools/v171_data_archive_self_check.py` は静的検査です。
Godotの実行・Androidでのタッチ動作・実ファイルIO・端末再起動後の
復元は未検証です。
