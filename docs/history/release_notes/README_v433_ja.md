# SERA v433 — ビットタランの骨格接続を保つ接地方式に再設計

## 修正の理由
v432ではBlockbench上のY=0以下のメッシュを、Godotで実際のMeshInstance3D.global_positionを動かして接地させていました。この方式は親関節／子関節を移動しないため、上肢・下肢・足先・頭部・胴体のメッシュ接続が破綻します。さらに既存の支持3脚IKと二重に補正していました。

## v433の動作
- **18メッシュすべて**：MeshInstance3Dのローカル位置・回転を原本通り維持。床接地を理由としたメッシュ単独移動はしません。
- **攻撃脚1本**：17:21:58同期のBlockbench原本6攻撃クリップに合わせ、胴体と攻撃脚の関節角度・位置を無補正で再生します。
- **支持脚3本**：既存の2ボーンIKを使い、足裏の世界座標Y=0への接地を維持します。上肢・下肢・足先は各関節を回すことで追従し、メッシュ単独平行移動は行いません。
- **胴体**：通常移動時には従来の `_keep_chassis_above_ground` で胴体の床貫通を抑制。攻撃中は原本の胴体アニメーションを優先し、攻撃脚とともに胴体全体へ補正を加えません。
- **頭部・砲塔**：既存の骨格に接続したまま追尾し、メッシュ単独移動は行いません。
- **全メッシュの接地・貫通時刻情報**：`assets/bittaran_ground_contacts.gd` と `docs/BITTARAN_ALL_MESH_GROUND_CONTACT_V432_ja.md` は調査資料として保持。診断メソッド `inspect_blockbench_ground_contacts()` は18メッシュのワールド最下点とBlockbench接地区間を読み取るだけで、ポーズを変更しません。
- **攻撃脚の接地と原本忠実性が両立しない場面**：原本を優先し、攻撃脚を無理に床へ吸着させません。

## 検証

- `tools/v433_bittaran_skeleton_ground_runtime_check.gd`：全10クリップ、18メッシュの親子接続、診断時の無変形、攻撃脚・胴体の原本キーフレーム、支持脚3本の接地。
