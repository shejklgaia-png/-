# SERA v520 — 予測シールドの八角形を少し横長に

## 変更
- 通常被弾時の6層の厚い正八角形フレームと中心の色付き小八角形を、中心を固定して**横幅15%拡張（横1.15倍、縦1.00倍）**。
- 8辺、6層、層ごとの透明度、出現0.2秒・維持0.2秒・消失0.2秒、青/黄/赤のSP色分けは従来どおり。
- 破壊時のガラス状の破片14個、左右稲妻、SE、シールド耐久100SP・被ダメージ補正・回復、HPバーは変更しません。
- テストターゲット・ビットタランへ共通描画として適用。LABO/素材変換/倉庫UI・その他のゲーム機能は変更しません。

## CI
- **本体更新前**に既存v516の静的/実Godotテストへ1.15の横倍率と投影メッシュ幅:高さの検証を追加。旧の6層・8辺・時間・透明度・中心充填・破壊時空洞と全回帰テストを維持。
- mainへのマージ後にフルPython/Godot CI。Android実機の見た目は別途確認。
