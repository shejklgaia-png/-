# SERA v519 — 施設の空白一覧を修正し、四隅欠けスロットを実装

- Android実機のスクリーンショットを確認し、LABO・素材変換・倉庫のリストが空白に見える症状を修正。
- 施設内の一覧をScrollContainerに依存しない常時表示のGridContainerとPanelContainerに変更。3列のアイコン付き実スロットを配置。
- 拠点画面下部の重複「装備製作／素材変換／倉庫」ボタンを削除。3D施設をタップして開き、メニュー内上部の3タブを操作します。
- 試作装備7種、素材変換の12種、倉庫素材12種を未所持でも必ず表示。倉庫の「装備7種」タブに未所持0個の枠を表示。
- 全スロットに四隅が欠けたシアン枠を描画。製作済装備の個体ID一覧は装備の枠を選ぶと表示し、9件単位でページを切り替えられます。
- 既存の素材19アイコン、製作UID、試作素材・セーブ処理、NEXUS・戦闘・モデルは変更しません。

## CI
- v517・v518・v511の該当テストを新しい画面仕様に更新し、v519の実レイアウト検査を本体変更前に登録。
- スロットの画面内座標・3列グリッド・アイコン・未所持枠・欠けた四隅・下部ボタン除去をGodotで検査。
- 画面描画はAndroid実機での視認チェックが最終確認です。
