# SERA v158 — 360°連続RUN入力、短い固定RUN円、BOOST位置維持

v157の8方向デジタルスティックから、**全方向へ連続的に方向指定できる固定位置アナログ式**へ変更しました。スティック本体はタッチ開始位置から動かず、指を追尾しません。

| 項目 | v157 | v158 |
|---|---|---|
| 移動方向 | 8方向、45°刻み | **360°自由、段階なし** |
| RUN円の最大半径 | 168px | **112px** |
| RUNの入力強度 | 一定 | 18～112pxで0～100%に連続変化 |
| BOOST開始位置 | タッチ開始点から210px | **210pxのまま** |
| BOOST解除位置 | タッチ開始点から184.8px未満 | **184.8pxのまま** |
| BOOST確定／加減速 | 0.10秒／0.15秒 | 変更なし |

RUNの小さな円とBOOSTの大きな円は**同じタッチ開始点に固定**し、方向マーカーだけが360°滑らかに回ります。指に追従する動くスティック中心や、8方向の固定ボタン・自動反転はありません。

ガード・攻撃・リリースフリック回避、速度スケール、既存モーション、カメラは変更していません。GodotとAndroid実機での操作確認は未実施です。
