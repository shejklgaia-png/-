# SERA v518 — 拠点メニューの欠落・ボタンの見つけにくさを改善

## 表示と操作
- 拠点の固定メニュー3ボタンを明確な背景・枠線付きに変更。CanvasLayerのHUDを画面全体へのアンカーで自動伸縮し、縦画面サイズへの追従を維持。
- LABO、素材変換、倉庫を開いた状態でも、画面上部の「装備製作／素材変換／倉庫」タブを常時表示。どの詳細画面からも切り替え可能。
- 縦画面の施設モーダルを広く・高くして、素材/装備一覧のスクロール領域を確保。
- 試作装備の詳細では「製作して倉庫に登録」ボタンを最初に置き、画面内ですぐ押せるように変更。
- 素材変換の説明文を整理し、所持数とランクは変換元・変換先アイコンの隣に表示。
- 既存の素材12種・装備7種のアイコン、ID、セーブ、倉庫、戦闘・モデル仕様は維持。

## CI
- 作業開始時にv517・全登録済みCIとUIの実装を確認。
- UI本体変更前に `tools/v518_menu_visibility_self_check.py` と `tools/v518_menu_visibility_runtime_check.gd` を追加・CI登録。
- 拠点ショートカット、施設内の固定タブ、装備の選択・製作操作、素材変換、倉庫のアイコンが実際のビューポートに収まることを確認。
- Godotのテストでは実際の画面座標へ`InputEventScreenTouch`を送り、UIへのタップ経路を検査。Androidでの最終的なタッチ・表示確認は別途必要。
