# SERA v437 — なぎ払いの往路を基本姿勢から2.00秒に変更

## 変更内容
v436までのなぎ払いは基本姿勢から往路終了まで約1.38秒で、攻撃クリップの最初（原本0.00〜0.36秒）を1倍速で通過していたため、途中の0.2倍速区間までの動きが速すぎました。

v437では**基本姿勢（Wait）から往路の折り返し（Blockbench原本の時刻0.50秒）までを合計2.00秒**に調整しました。左右のなぎ払いへ共通適用します。

| 実時間（攻撃開始基準） | 動作 | 原本再生時刻 | 速度 |
|---|---|---|---|
| 0.00〜0.32秒 | Wait→なぎ払い0秒姿勢へ移行 | 0.00秒で停止 | smoothstep補間 |
| 0.32〜1.30秒 | なぎ払い往路前半 | 0.00〜0.36秒 | Hermite速度曲線で滑らかに加減速（開始0倍速→境界0.2倍速） |
| 1.30〜2.00秒 | 往路の最後0.70秒 | 0.36〜0.50秒 | **0.2倍速** |
| **2.00秒** | **なぎ払い往路終了（折り返し）** | **0.50秒** | 次のフレームから1倍速 |
| 2.00〜3.00秒 | 復路 | 0.50〜1.50秒 | 1倍速 |
| 3.00〜4.40秒 | 硬直なし、Waitへ滑らかに復帰 | 原本最終姿勢→Wait | 1.40秒で補間 |

次の攻撃までの既存クールダウン1.35秒は上記合計4.40秒に含まれません。

### 再生速度の連続性
原本0.00〜0.36秒を単純な一定倍速にせず、**三次Hermite補間で「実時間→原本時刻」の曲線**を設けています。開始速度が0で、0.2倍速区間との境界速度も0.2で一致します。元の0.36秒から0.50秒のスローと、往路後の1倍速の復路は維持します。速度値は`source_playback_speed()`で曲線の微分値から取得し、再生時刻`sweep_clip_time_at()`と整合させます。

## 保持した仕様
- Blockbench原本のキーフレーム、原本尺、姿勢、左右クリップを編集しません。
- 弾き（3.86秒）・踏みつけ（4.61秒）の攻撃時間と補間は変更しません。
- 攻撃脚のIKは無効のまま、その他3脚の接地IKを維持します。
- v432のメッシュ単独移動は復活させません。

## 検証
`tools/v436_bittaran_attack_timing_runtime_check.gd`の期待時刻をv437向けに更新し、原本再生の時刻、前半速度曲線の導関数、スロー開始・終了の境界、折り返し、全6攻撃の原本姿勢を検査するようにしました。既存のGitHub ActionsでGodotテストを実行する構成です。

数値による10万区間サンプリングで、原本再生時計の単調性・往路2.00秒・スロー入口での速度連続を確認しています。**Godot実行テストとAndroid実機映像での視覚確認は未完了です**。
