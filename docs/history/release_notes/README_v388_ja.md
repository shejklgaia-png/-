# SERA v388 — 頭部の常時追尾と、なぎ払い復路の一時減速

## 頭部の回転をモーションから完全に独立
- **ダウン中以外は常にプレイヤーを追尾**。待機／旋回／接近／3種類の攻撃／硬直／復帰中も同じ追尾制御を継続します。
- モーションリグは**HEADの回転を一切再生・上書きしません**。最初に正本のWait首ポーズを設定した後は、毎フレームの最終段階で、独立した追尾制御が頭の向きを決定します。
- モーション切替時の0.24秒のブレンドや攻撃のキーフレームは頭の向きに干渉しません。
- 部位破壊のダウン前の予備動作中も追尾を継続し、頭の前後傾は追尾回転へ合成します。物理的ダウン中は従来通り頭を中立姿勢に戻し、起き上がり後の段階的な追尾復帰・頭と膝の接触制御は保持します。

## なぎ払いの再生速度
正本の「なぎ払い」には1.50秒分のモーションが収録されており、往路終点を**クリップ時刻0.50秒**と判定しました。ユーザー作成キーは変更しません。

| 区間 | 実時間 | 再生速度 | 原本クリップの進行 |
|---|---:|---:|---:|
| 往路・折り返し前 | 0.50秒 | 1.00倍 | 0.00→0.50秒 |
| 復路の減速部分 | **0.70秒** | **0.60倍** | 0.50→0.92秒 |
| 残りのモーション | 0.58秒 | 1.00倍 | 0.92→1.50秒 |

この調整によって、なぎ払い攻撃部分の実時間は**1.50秒から1.78秒**へ延長されます。その後の緩慢な復帰1.40秒、硬直なし、胴体のプレイヤー追尾なし、独立した頭部追尾は変更しません。
