# SERA v217 — スラスターの加速拡散を5倍・0.1秒へ調整

v216で追加した加速バーストの拡散幅と立ち上がり時間だけを変更しました。

| パラメータ | v216 | v217 |
|---|---:|---:|
| 噴射先端の最大幅 | 通常の2.8倍 | **通常の5倍** |
| 拡散にかける時間 | 0.035秒 | **0.10秒** |
| 通常噴射に戻る時間 | 0.18秒 | 0.18秒（変更なし） |
| 一連の演出時間 | 0.215秒 | **0.28秒** |

加速開始後0〜0.1秒で四角い噴射筒の先端が徐々に5倍まで広がり、その後0.18秒かけて元の幅へ戻ります。噴射の根元はノズル口と同じ大きさを維持します。

前後左右・斜め方向へのSTEPと、実際に移動を伴う格闘・バッシュ追尾時の発動条件は従来どおりです。スラスターの方向・ノズルPivot・揺らぎ・明るさ・EN消費・移動速度・当たり判定は変更していません。

実装は`scripts/back_thruster_fx.gd`の拡散時間と、`shaders/back_thruster.gdshader`の幅倍率のみ変更。追加した`tools/v217_thruster_burst_size_time_self_check.py`で時間・幅・旧動作の維持を検証します。Android端末上での描画は未検証です。
