# SERA v152 — 指の動きに合わせたフリースワイプ感度調整（2026-11-09）

**変更前の問題**：約6pxごとの生の指移動をそのまま移動方向にしていたため、指先の小刻みな動きでセラとコントローラの方向が頻繁に切り替わっていました。

## 新しい感度
- **直近80msの指の移動を参照**し、単一タッチイベントの揺れに反応しないようにしました。
- 通常は**約12pxの移動**かつ**12°以上の方向変化**を検出してから方向指定を変更します。40°を超える急旋回では約20px以上の正味移動を求めます。
- セラの実移動方向は通常0.055秒の短い角度補間で追従。65°以上の大きな変更は0.020秒、140°以上の明確な反転は即時に反応します。RUN／BOOSTの速度は変わりません。
- **BOOSTは進行方向への140pxの正味移動**で発動します。指が小刻みに行き来しても140pxに達した扱いになりません。明確な急旋回でリセットされます。
- コントローラ矢印は実際に適用された移動方向を表示し、v150の滑らかな表示補間は維持します。

タップ攻撃、長押しガード、フリック回避、RUN／BOOSTの固定速度、v151のセラ本体の滑らかな方向転換は維持しました。

検証は`tools/v152_thumb_steering_self_check.py`の静的・独立数値計算です。Android実機での感度・フレームレート・操作感は未検証です。
