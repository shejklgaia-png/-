# セラ v52 — 操作スペースを確保するカメラ構図

## 変更点

- **画面下25%を操作スペースとして確保**：プレイヤーの足元、およびターゲットの8頂点が下から25%の領域へ入り込まないよう、従来の全体フレーム保護を強化しました（画面下端からの安全余白：旧8% → 25%）。
- **カメラを少し下げる**：高さの比率を0.1325 → 0.11に変更。注視点をターゲット中心から0.90m下げ、被写体を画面上側に寄せます。画面操作（タップ・左右ドラッグ・フリック）の座標系には変更を加えません。
- **近接時の最大ズームインを緩和**：カメラの最接近半径を6.5m → 7.8mに変更（約20%引き）。遠距離基準16mは従来どおりです。
- **見切れ防止**：カメラの角度・対象距離によって安全領域を守れない場合、既存のフレームフィット処理でカメラをさらに引きます。

## 維持する仕様

- v51：ターゲット中心から2.0m以内のステップ6m/s、2.0m超10m/s、最大0.4秒、角度35°、予定移動距離1.5〜4m
- v50：プレイヤー・ターゲット衝突判定
- タップ攻撃、通常左右ドラッグ移動、左右フリック、ロックオン／ターゲット回り込みカメラ
- 下部操作スペースは**非遮断**。画面下部へのドラッグ入力は従来どおり受け付けます。HUDや固定コントローラは増設しません。

## 注意点

- 25%の空き領域は、コード上で投影したプレイヤーの頭・足元とターゲットの箱を基準に保護します。剣の長さや特殊エフェクトの一時的な飛び出しは含みません。
- Godot 4.7.2の安定版APIを参照。Godot本体・Android実機の実行テストは未実施です。

## 検証

`python tools/v52_camera_self_check.py` でカメラ定数、焦点、ズーム、フレーム安全領域、v51の操作コードの維持をチェックできます。
