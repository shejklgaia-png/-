# SERA v213 — 左ブースト・左ステップ時のスラスター角度

## 指定可動範囲

左方向へのBOOSTとSTEPでは、ノズル本体の噴射方向を**画面の真下90°〜右90°の範囲**で制御します。

- 真左入力：右下45°を目標とします。
- 斜め左入力：左方向の成分に応じ、真下90°から右下方向へ滑らかに移動します。
- 右方向・前方の移動：従来どおり、スラスターの通常方向追従を使用します。
- 真後ろへの移動：下90°へ向ける従来の背泳ぎ動作を維持します。
- 無操作・待機：下90°をデフォルトとします。

ここでの「右」は、セラ本体のローカル右ではなく、**スマートフォンの画面上で見た右**です。

## 修正した問題

v212は「画面右下」のワールド空間方向を作った後、ノズルのローカルYaw±80°・Pitch制限へ変換していたため、胸部の向きによっては実際の3Dノズルが目標と異なる方向を向く可能性がありました。

v213では左移動時だけ、カメラの右方向とワールド下方向から作った目標ベクトルを、BlockbenchのThruster_L/Thruster_R**制作時の回転原点**へ直接変換します。GodotのQuaternionで実際の3Dノズルと子の噴射エフェクトを回し、出入りには0.075秒の滑らかな補間を行います。

左移動以外の通常スラスター可動制限（Yaw±80°、下90°、上1°）は変えません。また、重量脚部のSLIDEは待機50%・ブースト50%のままです。
