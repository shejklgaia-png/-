# SERA v479 — ビットタラン砲台：球体縮小開始で減速・レーザー逸脱1.5mで加速

## 砲台の追尾時間
- **0〜10秒：充填**。砲台は基本姿勢のまま静止し、プレイヤーを追尾しません。
- **10〜11秒：青い球体チャージ前半**。青い球体の出現と同時に追尾開始。最初の0.7秒は滑らかに追尾を加速し、その後はプレイヤーの速さに関係なく角速度制限なしで追い続けます。
- **11〜12秒：青い球体が縮小する間**。球体の縮小開始と**同時（t=11秒）**に追尾速度を発射中と同じ**従来比0.7倍**の角速度制限付きへ切り替えます。チャージ後半には、レーザーの照射地点からの距離による加速は発動しません。球体は従来どおり1秒かけて縮小します。
- **12〜14秒：レーザー発射**。基本追尾速度は従来の**0.7倍**。レーザー軸を地面に投影した位置からプレイヤー足元の水平距離が**1.5mを超えたときだけ**、プレイヤーの実移動速度を参照して追尾を加速します。**1.5m以内では基本速度へ戻ります。**
- **14〜14.7秒：復帰**。0.7秒で基本姿勢に戻り、次の充填中も静止します。

## 維持する仕様
- レーザーの照射は2秒、青球体はチャージ2秒（拡大0.2秒、後半縮小1秒）、発射までの待機なし。
- レーザーに実際に触れている間は、**1照射あたりの最大命中回数は無制限**。0.20秒間隔で再命中できます。通常のガード・シールド・HPダメージ・Damageknock処理を維持し、ノックバック中のアニメーションは再起動しません。
- ビットタランの歩行速度1.872m/s、加速度1.56m/s²、静止旋回68°/秒、移動旋回44°/秒、停止時の追尾旋回36°/秒（いずれもv478で2倍に更新済み）を維持します。
- 砲台のワールド水平回転＋上下俯仰、Blockbench原本モデル、脚IK、ビーム幅・最大射程・エフェクトとノックバックを変更しません。
