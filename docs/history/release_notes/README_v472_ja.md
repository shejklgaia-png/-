# SERA v472 — レールガン発射直後の避けられない被弾を修正

## 原因の検証
v471 の**照射中の角速度上限は水平15.12°/秒・上下11.34°/秒で正しく設定されていました**。一方、発射フレームでプレイヤーの現在位置へYaw/Pitchを完全一致させた**同じフレーム**にダメージ判定が有効になっており、射線内のSERAは発射開始直後から確実に被弾していました。

ヒットすると `scripts/main.gd` の既存ダメージリアクションが移動・BOOST/STEPを制限するため、照射中の追尾が遅くても、プレイヤー側は逃げられないように見えます。**数値の追尾速度だけを下げても解消しない問題**でした。

## 修正仕様
- `scripts/bittaran_railgun.gd` に `BEAM_DAMAGE_ARM_SECONDS = 0.40` を追加。**発射から0.4秒間はレーザーが見えていてもダメージ判定を発生させません。** それ以降は従来のビーム対SERAの幾何学的重なり判定を用います。
- **発射フレームの完全照準合わせは維持**。ただし当たり判定は0.4秒の猶予後に有効になるため、直後から横ブースト・ステップで回避するチャンスがあります。
- 静止したSERAや射線上に残ったSERAは、0.4秒後から従来どおり被弾します。照射中の当たり判定半径は従来のまま（ビーム0.70m＋プレイヤー0.48m）、被弾後の連続ヒット間隔0.5秒も変えません。
- BOOSTの実際の設定は基準速度6.09375m/秒、開始確認0.10秒＋速度ブレンド0.20秒です。近距離の身体衝突を伴う操作やBOOST入力のタイミングによっては、回避成立には横移動やSTEPを早めに開始する必要があります。

## 維持する仕様
- 発射前Yaw504°/秒・Pitch403.2°/秒、照射中Yaw15.12°/秒・Pitch11.34°/秒（v471から不変）。
- 10秒周期、2秒照射、2秒青い球体＋稲妻＋最後の1秒収縮、2秒追尾イーズイン、完全捕捉後0.5秒待機、発射後0.4秒保持・0.8秒復帰。
- 青いフレネル外縁と流動プラズマレーザー、砲台独立Yaw/Pitch、Blockbench原本18メッシュ／14ボーン、ビットタランの足・頭・IK・カメラは変更しません。

## 新しいGodot回帰テスト
- 発射瞬間は照準が現在のSERAへ正確に合い、**レーザーが見えるが当たり判定はない**こと。
- 0.4秒未満に当たらないこと、0.4秒後も射線内にいる静止プレイヤーには当たること。
- 8m地点から実際の基準BOOST速度6.09375m/秒でレーザーに対して真横に移動した場合、発射から1.92秒間、ダメージ判定が発生しないこと。
- 従来のLED充電・球体・追尾・照射中エフェクト・KOリセット回帰を維持します。Android実機では回避の触感と開始時の無敵猶予の視覚的分かりやすさを確認してください。
