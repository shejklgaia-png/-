# SERA v485 — レールガンの追尾加速を0〜2.5mで滑らかに補間

## レーザー追尾の変更
- 発射中、照射地点とプレイヤーの水平距離（地表に投影したレーザー射線からのずれ）0m〜2.5mで、追尾加速の適用率を滑らかに変化させます。
- ずれが0mなら従来の追尾角速度0.7倍を使用。0.625mで約15.6%、1.25mで50%、1.875mで約84.4%、2.5mで100%の加速補正を適用。端点で急激に速度が変化しないsmoothstep方式です。
- 2.5m以遠では加速補正率100%を維持し、実際のプレイヤーの移動速度と射線からのずれに応じて追尾できます。追尾角速度自体を固定上限で切り捨てません。
- 追尾速度の時間的な平滑化（16/s）は引き続き適用します。急な速度切替の抑制に加え、距離に応じた滑らかな増減を実現します。

## 変更しない仕様
- 10秒の充填中は砲台の追尾なし、10〜11秒の青球体追尾、11〜12秒の球体縮小中は0.7倍の速度上限、12〜14秒のレーザー照射、14〜14.7秒の復帰。
- 60%レーザー威力、0.2秒間隔の実接触再命中（最大ヒット回数なし）。
- ビットタラン本体と砲身の回転分離、縦接続軸の本体Yaw同期、原本モデル・攻撃モーション・音声・FX・足先の接地。

## CIと実機検査
- 既存の`tools/bittaran_railgun_runtime_check.gd`の旧1.5mしきい値テストを**実装前に**更新。滑らかな補間係数、各距離の回転速度、2.5m境界の連続性、実射撃中の部分／最大加速を確認します。
- マージ後は全Python/Godot CIを実施。Android実機では0〜2.5mの追尾加速と、BOOST回避の操作感をご確認ください。
