# SERA v357 — ビットタランの奥側コントローラ・ダウン時退避・頭部追尾

## 変更した挙動
- **ロック対象よりセラがカメラ奥側へ入った場合：** コントローラの前方向を固定画面上方向にせず、セラのカプセル中心からロック部位へ向かう線をカメラ投影した角度に回転します。表示とバッシュ/キック等のフリック判定で同一角度を使用。通常時の指を置いた位置→ロック対象の設定、攻撃入力中の軸保持は維持しています。
- **ビットタランのダウン中：** 胴体の下にいるセラは水平方向に押し出されます。拡大した脛の物理当たり判定にぶつかる経路は避け、足に接しているときは横側の退避経路へ変更します。上方向や床下へ押し込まない構造です。
- **頭部追尾：** 頭部の関節をプレイヤーに向けて滑らかに旋回させます。角度は最大左右48度ですが、頭のメッシュと脚・足の現在のメッシュが干渉する場合は、その直前に制限されます。ダウン時の頭下がりピッチも維持します。
- **地面への埋まり込み：** 敵との接触による物理補正でセラの本体Yが0未満になることを、ダウン時と攻撃中も含めて防ぎます。

## 変更しない仕様
- 立脚時の左右ロック安定化（v356）、前後脚の対称境界、2本の水平ロック線。
- 2.5秒/6秒ダウン、部位破壊・復活・HP、モデル/アニメーション原本。
- 訓練ルームにおける入力と衝突処理。

- v355の奥側向きテストを改訂し、v356以前のロック／IK／HP回帰テストも引き続き実行します。
