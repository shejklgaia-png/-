# SERA v503 — 腹部砲台を4秒間隔の細長い単発レーザー弾へ変更、十字を実際に発光させる

## 変更内容
- ビットタラン腹下中央の単砲台の射撃間隔を**1.2秒→4.0秒**に変更。最初は戦闘で発射可能になった時点で1発射撃し、その後は4秒ごとに1発だけ発射する。連続照射、追尾弾、拡散弾にはしない。
- 以前の直径0.24m球状弾を、**長さ1.50m・半径0.065m**の細い`CapsuleMesh`レーザー弾に変更。その外側に、長さ1.70m・半径0.16mの半透明加算発光を重ねる。**弾は1発**（コアと外光を同じ飛翔体ノードに保持）で、発射方向に長軸を揃えて17m/sで前進し、既存の被弾・ダメージ判定を維持する。発射時は後端が銃口へ接するよう、弾体中心を弾長の半分だけ前へ配置する。
- 十字が単に表示されて光らない問題に対応。従来の縦横3.10mの白い十字＋青いハローに、**半径方向に透明化するグラデーションの広い光輪（RadialRadiance）**を追加。色の中心が白く、周囲へ青く広がって自然に消えるようにする。
- 銃口には**実際の`OmniLight3D`（MuzzleBurstLight）**を配置。発射瞬間に光量10で点灯し、銃口から約4.5mまでの周辺の3D装甲・床を照明し、0.12秒以内に**光量を連続減衰**して消える（影の計算を行わずAndroidの描画負荷を抑制）。従来の十字・光輪も同時に縮小して消える。
- 新たな光輪だけが既存の十字と同じ一時的な前面加算描画。移動レーザー弾の外光は**深度テストON**とし、機体を透過させない。
- 攻撃モーション中とダウン中は射撃／追尾／フラッシュ／実照明／飛翔弾を停止。背部レールガンのダウン停止仕様もそのまま。原本の`models/bosses/Bittaran.bbmodel`、脚・IK、アニメーション、既存のダメージ・ガード仕様は変更しない。

- 同CIに追加した実照明の検査：`OmniLight3D`が発射前には消灯し、発射瞬間の光量が十分あり、時間経過で光量が下がり0.12秒後に消えること。`GradientTexture2D.FILL_RADIAL`を使用した半透明のグラデーション光輪があること。
