# SERA v412

## 概要
実機フィードバック4件への対応です。(1)「全脚で弾きの予備動作が異常な方向になっている」、(2)「脚のモデルがねじれる」、(3)「後足での攻撃時は、胴体の傾きを前足攻撃時と前後逆にするイメージで実装」、(4)「前足攻撃時は脚が頭を回避しないように変更」。 (1)と(2)は同根で、v410の「予備動作中は攻撃足を基本姿勢に植え付ける」変更に、植え付け以前の仕組みが作用していたことが原因でした。

## 何が起きていたか
- (1)(2) 予備動作と脚のねじれ: 植え付けた攻撃足には、予備動作の間ずっと2つの仕組みがかかっていました。
  - IKの弾き用「膝を体の内側へ巻く」ポール補正（70%まで混合）: 足裏が固定されたまま膝だけが動き、膝の移動速度は最大約7 m/s、左前脚では予備動作の途中でポールが股関節→足裏の軸を横切り、屈曲面が反転して膝が約1.6m跳んでいました。「異常な方向」の正体です。
  - 照準の肩回転: 予備動作中に肩へ回転がかかり続け、IK解法の最短弧補正がそのロール成分を引き継ぐため、メッシュのねじれとして蓄積していました。右後脚の脛は自軸まわりに **+105°** 回転し、左前脚の大腿は約43°溜めたねじれを1ティックで放出していました。
- (3) 後脚の胴体傾き: v411のなぎ払い胴体ミラーは左右反転のみで、後脚は前脚と同じ前後方向の傾きを再生していました。なお、前後反転は v411 で「打撃入りの膝ポールが軸を横切って膝が床を突き抜ける（-0.214m）」ため不採用にした経緯があり、今回はその軸横切り自体を根治してから導入しています。
- (4) 頭回避: 頭部の追尾に合わせて、前脚の膝が最大 0.70 rad（40°）まで折れて頭を避けていました（計測では後脚の攻撃時に左前脚で最大）。攻撃中に脚が頭をよける動きとして見えていたものです。

## 修正
- 弾きの内巻きポール補正は、打撃の開始時点から適用するよう変更（予備動作中は基本姿勢の膝のまま。復帰時の緩和＝v402のフェードは従来どおり）。
- 照準の肩回転の「適用」は予備動作中は行わず、打撃入り（弾き 0.25秒 / なぎ払い 0.36秒）でなめらかに効かせるよう変更。照準の値自体は予備動作中も追尾を続けるので、打撃開始時点の狙いは従来どおり合っています。
- 胴体ミラー（`scripts/bittaran_rig.gd`）を象限方式へ拡張: なぎ払いは右脚＝左右反転、後脚＝前後反転（右後脚は両方）。弾き・踏みつけは後脚のみ前後反転し、前脚は従来どおり無反転です。弾きについては、軌道サンプラと接地プローブは前脚形のままサンプルし、反転は再生される胴体だけに効かせました（反転した胴体の下でサンプルすると補正が肩で軌道を回してしまい、左後脚の足首プロファイルが 1.68m ずれることを計測で確認したため）。再配置される脚の軌道は調整済みのまま、胴体の傾きだけが前後逆になります。
- なぎ払いの打撃入りで、膝ポールのブレンドを「位置の直線補間」から「股関節まわりの方向の球面補間」へ変更。ポールが軸を横切らなくなり、前後反転した胴体の下でも膝が反転・沈下しません。
- 弾きの接地ガード（打撃中）を脚全体のメッシュで測るよう拡張。前後反転で後脚の付け根が下がり、右後脚の脛が打撃中に -0.054m 沈むケースを、腰と目標を一緒に持ち上げる既存方式で解消しました。
- 頭回避（`scripts/bittaran_foot_ik.gd`）: 攻撃中（スタンス準備を含む）は前脚の回避目標を 0 に固定しました。歩行・旋回時や脚折れダウン時の回避は従来どおりです。

## 計測結果
- 予備動作中の攻撃脚の膝: 移動速度 最大約7 m/s（+1.6mの跳躍）→ 約3 m/s（胸の追尾で股関節自体が動く速度と同水準）。脛の自軸ねじれ変化: 右後脚 +105° → 約19°。1ティックあたりのねじれステップは最大 35° → 2.2°（跳躍なし）。
- 後脚のなぎ払い: 胴体の総回転は全脚 70° 以内、脚メッシュの床めり込みなし（v411チェックで継続検査）。左後脚のなぎ払いを横カメラのスクリーンショットで確認し、低い弧と後方へ倒れる胴体の傾きになっています。
- 攻撃中の前脚の頭回避: 膝の折れ 0（攻撃開始前に歩行で付いた折れは、スタンス準備の間に緩やかに戻ります）。

## チェック
- 新規 `tools/v412_bittaran_windup_twist_rear_tilt_runtime_check.gd`: 予備動作中の膝ステップ（1ティック 0.09m以内）・脛のねじれ（ステップ8°以内・合計75°以内）、後脚の弾き/踏みつけの胴体が前脚の前後反転であること、攻撃中の前脚の膝折れが 0.05 rad 以内、後脚の弾きで脚メッシュが床を割らないことを検査。v411ツリーでは FAIL、本版で PASS。
- 既存チェックの変更（意図と理由は各ファイル冒頭と DEVELOPMENT.md に明記）:
  - v410 Part 2 / v411 Part 1: なぎ払い胴体ミラーの期待形を象限方式（後脚は前後反転を追加）へ変更。あわせて期待形の構成をリグ自身の座標系で行うよう変更しました（ワールド差分を反転して期待形を作ると、基本姿勢自体の傾きと反転が入れ替わらず約7°ずれます。左右面では偶然一致していたもの）。
  - v395: 「前脚の攻撃中に支持脚（前脚）の膝が頭を避けて折れる」という期待は、今回のご指示（前脚攻撃時は脚が頭を回避しない）により supersede されました。検査は「攻撃中は折れない」＋「攻撃が終われば従来どおり折れる」の2部構成に変更し、攻撃脚・頭・植え付けた足裏が回避で動かないという不変条件はそのまま残しています。
- 関連チェック（v383〜v412）はすべて PASS。ローカル全件スイートも PASS（静的 182/182、Godot 148/148。PR の CI でも確認）。

## 実機確認のお願い
- Android 実機で次の点をご確認ください: 全脚の弾きの予備動作（膝が変な方向へ巻かず、脚モデルがねじれないか）、後脚の攻撃で胴体が前足攻撃と前後逆に傾くか、前脚の攻撃時に前脚が頭をよけないか。
- なお頭回避の無効化は、ご指示の「前脚攻撃時」より広く、攻撃中は常に前脚が避けない形にしています（後脚の攻撃中も同様）。前脚攻撃時だけに戻したければお知らせください。
