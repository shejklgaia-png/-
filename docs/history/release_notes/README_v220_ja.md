# SERA v220 — 通常攻撃の振り抜き終了までスラスター噴射を維持

## 変更内容

通常攻撃の3段コンボは、追尾動作だけでなく**振り抜きまで空中で行う演出**です。そのため、移動や追尾が一時的に止まっても、攻撃アニメーションが続いている限り背面スラスターの**通常噴射**を表示します。

| 通常攻撃の状態 | 通常噴射 |
|---|---|
| 1段目の予備動作（MELEE_APPROACH） | 継続 |
| 初回追尾（DASH） | 継続 |
| 2・3段目の追尾準備（STRIKE_TRACK） | 継続 |
| 1〜3段目の振り抜き（STRIKE） | **最後まで継続** |
| 命中後・ヒットストップ・その場での振り抜き | **継続** |
| 攻撃終了・キャンセル・待機 | 停止 |

通常の青白い10角形スラスターエフェクトを継続します。**15倍に広がる加速バーストは従来どおり、追尾時など実際の移動を伴う加速の開始時に限ります。** 追尾後、単に振り抜いている間には追加バーストを起こしません。

変更対象は通常攻撃のみで、バッシュは追尾時の噴射仕様を維持します。被弾・ガード・ジャンプ・着地・EN枯渇時の停止条件も従来どおりです。

## 実装

`scripts/main.gd`に`normal_melee_exhaust`を設け、通常攻撃の4つの戦闘状態（MELEE_APPROACH、DASH、STRIKE_TRACK、STRIKE）を通常噴射の有効条件として扱います。`tracking_exhaust`による移動量判定は変更せず、加速バーストの判定と明確に分離しています。

スラスターの3Dノズル、向き、発光・拡散時間（0.05秒＋0.18秒）、15倍の拡散幅、ステップ・ブースト操作、格闘追尾速度、攻撃判定、EN消費、重量脚部の通常SLIDEは変更していません。
