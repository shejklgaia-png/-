# SERA v292 — 添付動画からのロック姿勢修正と刀2段目モーション検索

## 添付動画の所見（v291、約12.5秒）
- 動画のHUDには `LOCK HEAD`、`LOCK FRONT`、`LOCK REAR R` などが表示され、ロックリングも実際に頭・脚を追っていました。つまり**部位ロックのID取得そのものは動作**しています。
- しかし、横移動中のセラのモデルは敵の中心へ常に向いているようには見えません。前回のv290/v291で `player.look_at` は敵全体の中心へ向けていましたが、その**子モデルのWaist（腰）には別の原本モーション回転**が加算され、最終的な描画姿勢を逸らしていました。
- 原本の `Step_R` はWaistのY回転が約**−70°**です。`run_front_original`は約**+74.64°**で、ラン専用の−90°補正後も−15°程度のズレが残ります。これらは当たり判定用のプレイヤーの方向とは**別レイヤー**で適用されていました。
- AUTO部位選択もv291ではカメラ中央からの距離が少し変わるたびに次候補へ切り替わる可能性があり、ロック維持の操作感を損ねていました。

## 変更
1. **移動時だけ腰の余計なY回転を相殺**：`sera_rig.gd::_face_locked_boss_with_waist`を追加。RUN、BOOST/SLIDE、通常360°STEPのWaistのローカル前方から水平角を求め、親の `CharacterBody3D` が向いた敵中心と一致するよう補正します。元の上下傾き・横傾き・脚の歩法・水平移動方向は維持します。
2. **モーションの移行を保護**：この角度補正は既存のアニメーションブレンド終了後に適用し、ブレンド開始時は0から滑らかに補正します。通常3連撃・カタナ2段斬り・バッシュ・Kick_l/r/b・サマーソルト中の原本の回転には適用しません。
3. **AUTOロックの維持を安定化**：未選択・破壊後は即座にロック。無傷の現在の部位から別部位へ切り替える際だけ、カメラ基準で新候補が**0.22秒以上**優先候補であることを確認して切り替えます。別候補へ変われば確認時間をリセットします。3連撃・派生時間・破壊済みロック維持、MANUAL左右切替は従来どおりです。
4. **距離・遮蔽のハード除外は復活させません**。カメラ中央基準の部位選択、画面端橙色マーカー、左右手動の循環、左右両手武器制御はv291仕様を維持します。

## 刀2段目のモーション検索
2026-11-12時点のGitHub `main` にある、`models/motion/SERA_BOOSTER_allテスト.bbmodel` と `models/storage/SERA_BOOSTER_allテスト (...).bbmodel` の関連ファイルを調査。保存されている最も新しい原本 `SERA_BOOSTER_allテスト (9) (2) (2).bbmodel` には**`Melee_katana`（0.5秒）のみ**があり、`Melee_katana2`その他の刀2段目クリップはありませんでした（最新モデルの同期コミットは2026-11-12）。

そのため**存在しない原本モーションを適用したとは扱いません**。現在の2段目はv290で1段目のキーフレームを非破壊複製・捻り反転して生成する`Melee_katana2`を維持します。原本側に同名クリップが追加された場合は、`_build_katana_second_strike`の既存仕様により**原本を優先して自動生成をスキップ**します。
