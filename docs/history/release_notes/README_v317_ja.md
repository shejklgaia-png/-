# SERA v317 — 開発診断とCI監査

- **通常のゲーム仕様はv316のまま**です。入力、カメラ追従係数、3段格闘、ガード、キック、ロック、移動距離、モデル・モーションを変更していません。
- トレーニング画面上部のデバッグ列に `DIAG: OFF` を追加。タップで診断ON/OFF、ONの時だけCOPY LOGが表示されます。
- ONではFPS、カメラYaw・半径・追従誤差、再生モーション、ロック部位、操作ベクトル、STEP距離、ENなどを約0.12秒ごとに表示し、最大500件を保持。
- `COPY LOG` を押すと端末のクリップボードへ記録をコピーします。記録の送信、ログファイルの保存、常時バックグラウンド処理はしません。
- DIAGボタンとCOPYボタンのタッチは既存のデバッグ入力判定に統合し、戦闘や移動の入力に変換しません。
- 診断UIがOFFの時は通常プレイ画面とパフォーマンスへの影響を極小化しています。実機の操作/描画はユーザー確認待ちです。
