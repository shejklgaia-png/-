# SERA v430 — ビットタラン攻撃を原本再生のみに戻す

## 再生対象
- Blockbench原本 `models/storage/ビットタラン.bbmodel` の左右前脚、各3種類を使用。
- 左前脚：`なぎ払い`（1.50秒）、`弾き`（1.00秒）、`踏みつけ_L`（1.75秒）。
- 右前脚：`なぎ払い_R`（1.50秒）、`弾き_R`（1.00秒）、`踏みつけ_R`（1.75秒）。
- `models/bosses/Bittaran.bbmodel` には同じ6種類の原本キーが収録されています。モデル・キーは変更しません。

## 一時的に無効化する攻撃専用処理
- 攻撃開始前の専用IKでの立ち位置合わせ、独自の基本姿勢→キー0の補間、なぎ払いの減速、原本外の予備動作、独自のポーズ保持。
- 胴体降下、水平化、距離による脚伸長、肩／膝／足首の再解法、足先の床接地固定、脛の軸回転とメッシュ水平化。
- 攻撃後の持ち上げ復帰、脚→胴体の2段階復帰。
- この原本モーション確認段階では、追加の攻撃ヒット判定・衝撃波も無効にします。後続の段階で順番に再実装します。

## 変更しないもの
- 移動時の歩行・旋回AIとそのアニメーション・接地IK。
- 頭部のプレイヤー追尾、部位破壊・転倒など攻撃以外の既存の仕組み。
- 原本のボーン階層、Pivot、Blockbenchキーフレーム、Android用モデル埋込データ。

## 検証
- 実Godotで各攻撃クリップを2回、合計12回再生。全13ボーンの原本回転、各ボーンの元のPivot、クリップ時間が一致するか検査します。
- 本テストでは攻撃中の空中脚・床貫通を補正しません。**原本再生の忠実性を優先**します。Android実機の見た目は未確認です。
