# SERA v383 — ビットタラン攻撃の足先水平化・予備動作追尾（2026-11-15）

## 攻撃中の行動

- **攻撃前の移行**：通常の旋回（Turn）・接近（Approach）から、約0.24秒で滑らかに攻撃用のIdleベースの予備動作へ移行します。途中で歩行脚が持ち上がっているときも、その脚のワールドXZ位置を保ち、上下方向だけ滑らかに接地させます。
- **追尾タイミング**：予備動作の最後までプレイヤーの位置を更新し、攻撃の振り出し開始時に狙点を固定します。振り出し中はターゲットに追尾しません。
- **胴体と頭**：攻撃開始から終了まで本体ルートの旋回・接近移動は停止します。胴体のBODYボーンだけが毎秒最大100°、初期正面から±60°の範囲でプレイヤー方向へ滑らかに旋回します。振り始めに胴体の旋回を停止し、攻撃後は滑らかに戻します。頭部は従来の衝突制約を保ちながら独立してプレイヤーを追います。
- **支持脚**：攻撃に使わない3脚の足先のワールド接地点（XZ）は固定したままです。歩行ステップを発生させず、胴体の旋回や傾きは股関節と膝のIKで吸収します。
- **足先の水平**：踏みつけ・弾き・なぎ払いの攻撃脚は、振り出し時に足先のワールド上方向が真上となるよう回転を補正し、向きを保って接地と伸展を行います。振りかぶり中に元の姿勢から水平姿勢へ補間し、攻撃後に元の姿勢へ復帰します。

弾きの予備動作（接地しながら膝を内側へ折る1秒）、本打撃時の脚の伸び切り、なぎ払いの肩のロール、踏みつけ時の衝撃波、破壊済み脚の攻撃許可とダウン中の停止は継続します。Blockbench原本・既存のWait／Idle／Turn／Approachクリップは変更しません。
