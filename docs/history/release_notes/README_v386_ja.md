# SERA v386 — ビットタランの踏みつけ振りかぶりと低姿勢の接地修正

## 踏みつけ

添付動画で確認された振りかぶりの不自然な動作を修正しました。v385では`ボステスト (2) (2).bbmodel`から読み込んだ踏みつけの肩・膝モーションを、直後のIKが上書きしていました。v386では**振りかぶり1.25秒間は原本の肩・膝のキーフレームを優先**します。振りかぶりが終わった足先の実座標を引き継いで、着地IKに移行します。BODYによるプレイヤー追尾は振りかぶり終了まで継続します。足先は高所では垂直、接地高さでは水平とします。

## 弾き・なぎ払い

どちらも制作モーションの開始キーフレームが低い姿勢です。移行の開始時に原本の低いBODY・選択攻撃脚のポーズを一時的に再現し、**実際の足先が床に届く胴体Y補正量を1回だけ計算**します。その高さまで0.70秒の予備動作で滑らかに移行し、攻撃中はその補正値を固定して、終了時に戻します。予備動作の途中や攻撃中に高さを測り直しません。攻撃しない3脚のワールド接地位置は変わりません。

なぎ払いは予備動作・攻撃中ともに**プレイヤー追尾を全て無効化**します。BODY旋回、狙点更新、頭部のプレイヤー追尾も行いません。踏みつけ・弾きは従来の追尾を維持します。

## テスト

`tools/v386_bittaran_windup_ground_no_sweep_follow_runtime_check.gd`で4脚×3攻撃の実行経路を検査します。踏みつけでは実際の肩・膝キーフレームが振りかぶり中に上書きされないこと、弾き／なぎ払いでは予備動作終了時の床への足先接触と高さ補正の固定、なぎ払いではプレイヤー移動に対してBODY・HEAD・攻撃狙点が追尾しないことを確認します。全従来テストも継続します。
