# SERA v175 — CONFIRMのタップ外キャンセルとLOAD二段階確認

## SYSTEMでの挙動
SAVE上書き・NEW DATA上書き・DELETEに加え、**存在するスロットのLOADも
初回タップでは確認待ち**となり、LOADボタンが `CONFIRM LOAD` と表示されて
点滅します。確認ボタンをもう一度タップすると、対象のスロットをロードします。
空のLOADスロットでは従来どおりエラーを表示し、確認待ちには入りません。

**CONFIRM待機中に対象のCONFIRMボタン以外をタップすると、即座に
確認待ちをキャンセルします。** 対象外には、別のアクションボタン、
スロット行、背景の空白、パネルの外側も含みます。キャンセルするタップは
それ以上処理されないため、誤って別の操作が実行されることはありません。

既存の右下の戻るボタンとAndroid/PCの戻るキーでも同様にキャンセルし、
確認待ちではSYSTEM画面からは退出しません。キャンセル後は通常の操作を
改めてタップして開始できます。

## 点滅仕様
v174の **CONFIRMボタンのみが点滅する** 仕様を維持します。
0.38秒ごとに明暗切替。CONFIRM対象外のボタンと保存スロットの選択枠は
点滅せず、確定・キャンセル・画面退出で通常表示に戻ります。

## その他
SAVE / NEW DATAの空スロットへの作成は従来どおり即時です。
既存セーブデータの内容、保存先、DATA ARCHIVE統計、戦闘操作、
カメラ、音声、カスタマイズには変更しません。

`tools/v175_confirm_cancel_load_self_check.py`で静的仕様確認を用意しています。
GodotとAndroidでのタップ操作・描画・実際のLOAD動作は未検証です。
