# SERA v199 — トレーニングルームの足裏接地補正

## 問題
LOWER BODY Dなどの脚装備を使うと、特にアニメーションで骨格が回転した瞬間に靴が床から浮いて見える場合がありました。v198までは装備切替時のバインド姿勢だけで高さを合わせ、その後のポーズ変化は反映していませんでした。また、回転した靴の軸平行境界箱の角を靴底の最下点と誤判定することもありました。

## v199での変更
- **表示中の装備に属する左右の実際の足メッシュの三角形頂点**を使って最下点を測定。回転後のAABBの空白を接地候補から除外します。頂点リストはキャッシュし、位置変換だけ毎フレーム再計算します。
- `Wait_motion`、RUN、STEP、ガード・攻撃など、地上で実行する姿勢へアニメーションを適用した**直後**に、最も低い靴底を表示床の上面（Y=-0.0335）に合わせてセラの**見た目のリグだけ**を上下移動させます。
- 地面からジャンプ中（`jump_playback`またはPlayerのYが0.05超）には補正しません。着地後に自動復帰します。
- NEXUSは従来の展示用カメラが位置を決めるため、接地補正を完全に無効化したままです。
- 既存の装備A/B/C/D、足音の左右判定、移動速度、方向入力、カメラ、プレイヤーの論理Y=0、衝突判定カプセル、当たり判定、モデル/モーションの原本は変更しません。既存の静的装備高さ補正はカプセル用に保持します。

## 確認
1. Termuxで`main`を同期し、Godotで **SERA v199** を開きます。
2. NEXUSでLOWER BODY Dを選択してトレーニングルームへ移動します。
3. 待機・前後移動・左右移動・停止・ステップ時に、どちらかの靴底が床に接しているか確認します。
4. 標準脚A、B、鳥脚Cでも、床に埋まらず接地するか確認します。
5. ジャンプテストでは上昇中に足が無理に床へ引き戻されず、着地後に通常接地へ戻るか確認します。

`tools/v199_animated_sole_grounding_self_check.py`による静的・数式検査は可能ですが、Androidの実際の描画は未確認です。
