# SERA v108 — 4方向RUNモーションの滑らかな合成（2026-11-07）

- ベース：GitHub `main` v107（`65d8e874bf49f8d7c2192416d578564830956047`）。
- 変更前：斜め移動の優勢軸が切り替わるたびにRUNクリップを再選択し、前回ポーズから0.16秒の姿勢補間を行っていた。境界付近の往復操作で急な姿勢変化や足運びの再開始が発生し得た。
- 変更後：常に1つのRUN再生時計を継続し、前 `run_front_original`、後 `run_back`、右 `run_right`、左 `run_Left` の各1秒ループを**同じ再生時刻**で評価。移動方向の前後・左右成分（絶対値の和）で比率を計算し、例えば前右45度で前50%＋右50%の姿勢を合成。逆方向への転換も前と後の重みを直接変化させるため、一瞬0になった方向ベクトルで姿勢が飛ぶことはない。
- 4方向重みはフレーム間隔を考慮した指数平滑化（時定数 `0.12秒`）で追従。各ボーンの回転は正規化済みQuaternion SLERP、位置とスケールは線形補間する。v107の腰ルート-90度補正はそれぞれのRUNポーズへ先に適用。
- 待機・ブースト・ステップ・戦闘など異なる状態へ移る際は従来のスナップショット姿勢補間を継続。走行の足運び再生倍率は1.5のまま。
- HUDではRUN中に最も重みの高いクリップ名を表示（実際の表示姿勢は複数クリップの混合）。
- 非変更：`assets/sera_source.json`、`assets/sera_data.gd`、Blockbenchの全キーフレーム、当たり判定、攻撃/ガード/ジャンプ、ブースト/ステップ速度、操作、カメラ、BGM、効果音。
- 検証：4方向重みの合計、0°/45°/90°/180°/斜めケース、方向反転時の滑らかな推移、ルート補正の適用順、過去のモーション参照維持を `tools/v108_run_blend_self_check.py` に収録。旧 `v107_run_facing_self_check.py` のアサーションを新描画構成へ更新。
- **GodotランタイムおよびAndroid実機動作の検証は未実施**。GitSyncでmainへ同期後、前後/左右/斜め方向の連続ドラッグ、往復転換、ブースト・ステップ復帰時の姿勢を確認してください。
