# SERA v203 — トレーニングルームのターゲット初期設定

## NEXUS / TRAINING 選択画面
トレーニングコンソールを選ぶと、左側のメニューで以下の設定をタップして切り替えられます。

- **TARGET MOTION**：MOVE（移動）／HOLD（停止）
- **AUTO ATTACK**：ON（自動攻撃）／OFF（手動のFIREのみ）
- **ATTACK TYPE**：AIM → LEAD → SHOCK → ARC（順番に切替）

設定は変更時に端末内へ自動保存され、次回以降のトレーニング開始時にも読み込まれます。新規データや既存のセーブスロットの選択内容には依存しません。従来の初期値はMOVE / AUTO ON / AIMです。

## TRAINING START
既存の下部進入ボタンを「>> TRAINING START <<」とし、明るいシアンの太枠、白字、1.8秒周期の滑らかな明暗変化で識別しやすくしました。ボタン領域・訓練室への遷移・Androidのタップ入力方式は維持します。

## トレーニング中
入室時にターゲットの移動とAIの自動攻撃・攻撃タイプを反映します。既存の MOVE と COMBAT / DEBUG の選択表示も一致させます。トレーニング中の一時的な操作は、次回入室時の初期設定を変更しません。
