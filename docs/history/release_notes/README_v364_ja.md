# SERA v364 — 頭の追従をゆっくり開始、腕との干渉を軽減、旋回を前倒し

## 頭部追従
- 頭部追従の開始条件は**起き上がりの実姿勢復帰率70%**のままです。
- 最初の追従をさらに緩やかにし、復帰中と直後0.24秒のIdle安定時間は回転上限を **48°/秒** に引き下げます（通常時は140°/秒）。
- 頭部と四肢（上脚・脛・足）の実際のメッシュ当たり判定を回転途中の24段階でも検査し、腕に近づいて追加の貫通が増える角度への旋回を停止します。復帰中の重なり許容値は従来の0.035m³から0.008m³へ引き下げます。モデルの首元に元々ある接触分は保持します。

## 旋回
- **胴体が起き上がり始める0.30秒前**から、ビットタランのYaw旋回を緩やかに開始します。
- 旋回速度は起き上がり終了まで加速曲線で滑らかに高まります。
- 起き上がりとその後0.24秒のIdle安定時間が終わるまで、前進移動とTurn／Approachモーションは再生しません。頭部が脚に乗る既存ダウン・脚のIK接地も維持します。
