# SERA v359 — ビットタランのダウン中HEADロックとコントローラ方向の統一

## 修正内容

- **ダウン中のHEADロック：** 0.6秒の頭上げ予備動作が終わり、実際のダウンモーションへ入った際は、ビットタランのAUTOロックがHEADを優先します。水平に伸ばした胴体ロック線では頭の高さに届かず、脚・BODYに選択が吸われる問題を解消しています。
- **手動ロック：** ダウン中は従来どおりHEAD・BODY・4脚を手動で選べます。通常の立脚時は脚のみで、ダウンから起き上がれば再び脚へ戻ります。
- **コントローラ：** ビットタラン戦の方向ガイドとバッシュ・蹴りなどのフリック方向判定は、セラの**カプセル中心から現在のロック部位の中心まで**の線を、カメラで画面投影した方向に統一しました。指を置いた位置の違いや、ロック対象の手前・奥の違いで「前」が変わることを防ぎます。
- 立脚時・奥側・ダウン中を問わず同じ計算です。通常移動と360度STEPは従来どおり画面基準とし、入力開始時に捕捉したコンボのフリック軸も途中で意図せず切り替えません。

## 維持する仕様

- ダウン前0.6秒の頭上げ・前脚伸長、ダウン中の頭部ニュートラル角、2.5秒／6秒のダウン、脚IK接地補正。
- 立脚時の左右脚ロック安定化・前後の対称切り替え、訓練ルームへの非干渉、モデル編集原本。

## 回帰検証

Godot本体でのボスシーンから、ダウン中のHEAD AUTOロック、MANUALでの頭部選択、複数プレイヤー位置、異なるタッチ開始位置、表示とフリック判定の方向一致を検査します。
