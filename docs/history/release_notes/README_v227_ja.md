# SERA v227 — 重量脚部SLIDEの両足接地IK

## 対象
LOWER BODY BとDを装備した通常移動SLIDEのみです。A/CのRUNと通常BOOST・STEP・攻撃などは従来どおりです。

## 動作
- 既存の4方向Boost_*ポーズを50%利用したSLIDE姿勢を生成した後、両脚のThigh／LowerLeg／Footに二骨IKを適用します。
- B/Dそれぞれの実際の靴底頂点を計測し、左右両方の靴底を訓練室の床面に合わせます。足首のXZと靴の傾きは元モーションを維持し、スライド時は両足が胴体と一緒に移動します。
- 膝の曲がる方向を現在のモーション姿勢から取得し、関節がほぼ一直線のときは左右別の横方向ポールを使用します。
- 足が床に届かないときだけ機体の表示用リグを最大0.24m下げ、二骨の自然な届く範囲内で調整します。関節長と足メッシュは伸縮しません。極端な姿勢では完全な両足接地より関節の破綻防止を優先します。

## 変更しないもの
Blockbenchのモデルとキーフレーム、操作・移動速度、EN、HP、当たり判定、実BOOST、BOOST残像、背面スラスター、STEP、攻撃、ガード、ジャンプ、足音、NEXUS展示および装備保存は変更しません。

## 検証
静的回帰テストと数学的IKの到達範囲テストをGitHub Actionsへ追加しました。AndroidのGodot実機でのモーション・床接触・切替の検証は別途必要です。
