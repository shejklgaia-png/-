# SERA v495 — ビットタラン旋回中のレールガン追尾を完全ワールド基準に整理

## 修正する問題
- v494ではレールガン砲身の追尾Yawはワールド座標で管理していましたが、本体の旋回や原本BODY関節の回転で取り付け位置が動いた後も、追尾方向とレーザーの地表ずれ判定を**前フレームの取り付け位置**から計算する場合がありました。その位置誤差が本体旋回に伴う余計な照準補正につながり、回転速度が加算されたように見える原因になり得ます。
- 本体姿勢・IK処理後の**現在の取り付け位置を追尾計算前に同期**させ、砲身のターゲット方向をワールドYawから直接算出します。本体Yawとの差分を計算してから足し戻す経路を追尾モーターから取り除きます。
- ワールドYaw独立制御はそのまま使用し、メッシュの水平回転・上下旋回を現在の実姿勢に一致させます。取り付け位置は本体に追従し、上部接続軸は本体Yawへ同期します。

## 維持する追尾仕様
- レーザー照射中は0〜1.5mで0.85〜1.0倍にsmoothstep追尾速度補間、照準角度の時間補間14/s、速度命令の時間補間16/s、1.5m超は加速なし。
- 最大追尾速度は装備RUN/BOOSTの65%補間で、通常移動より速く、BOOSTより遅い。10秒充填→青球体2秒（11秒から縮小0.7倍）→照射2秒→復帰0.7秒を据え置きます。
- 威力60%、0.2秒の再ヒット、物理ノックバック、原本モデル/アニメーション/IK/FX/音声、カメラ、部位判定とNEXUSには変更なし。

## CI先行と検証事項
- 作業開始時に`tools/sera_ci_manifest.txt`、`.github/workflows/sera-model-policy.yml`、`docs/SERA_ACTIVE_CI_POLICY_ja.md`、既存`tools/bittaran_world_yaw_independence_runtime_check.gd`と`tools/bittaran_railgun_runtime_check.gd`を確認。
- **本体実装前**に登録済み実GodotのワールドYaw独立テストを拡張。本体ルートの±旋回とBODY骨のYaw変化を連続して与え、現在位置から伸ばした一定ワールド方位のターゲットに対し、砲身の制御Yaw・レンダリングYaw・原本レールメッシュの方位が変化しないことを確認します。古い位置を使う実装なら余計なYawで失敗する検証です。
- 新規テストファイル追加なし、マニフェスト変更なし。全Python/Godot CIはmainへマージ後に実施し、Androidでの射線の見え方とBOOST回避感は別途確認します。
