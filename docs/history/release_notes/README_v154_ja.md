# SERA v154 — 速い逆方向スワイプで即時方向転換

v153の円形アナログスティックを維持したまま、反対方向へ指を素早く戻した場合に限り、スティックの起点を逆方向ストローク開始位置へ移動して素早く方向転換できるようにしました。

判定は、スティック半径25%以上の位置から、現在の方向と約143°以上反対へ**120ミリ秒以内に32px以上、平均520px/秒以上**の連続動作です（ゲーム画面の仮想座標）。条件に達したタッチイベントで即座に反転します。ゆっくりした戻しや横方向への動きは従来どおりです。

反転に合わせて円形コントローラの中心も移るため、表示と実際の入力が一致します。BOOST時は新しい中心からの距離が解除境界以下なら通常どおり解除します。リリース操作・ガード・タップ・アニメーション・移動速度・BOOSTの判定は維持します。

GodotエンジンとAndroid実機での確認は未実施です。
