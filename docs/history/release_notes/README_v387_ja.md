# SERA v387 — ビットタランの踏みつけ・弾き・なぎ払いの硬直と接地、頭部追尾

## 攻撃と回復

| 攻撃 | 振りかぶり | 打撃 | 硬直 | 通常モーションへ復帰 |
|---|---:|---:|---:|---:|
| 踏みつけ | 1.25秒 | 0.25秒 | **1.50秒** | 0.55秒、なめらかに |
| 弾き | 0.70秒 | 1.00秒（制作モーション） | **1.50秒** | 0.60秒、なめらかに |
| なぎ払い | 0.70秒 | 1.50秒（制作モーション） | **なし** | **1.40秒**、ゆっくり |

踏みつけの足先の**長辺（モデルのローカル-Y軸）を地面に対して垂直**にします。振りかぶりから振り下ろし、接地、1.5秒間の硬直まで垂直を維持し、硬直が終わった後でだけ通常姿勢に戻します。原本の肩と膝の振りかぶりキーフレームは継続使用します。衝撃波と土塊エフェクトも維持します。

弾き・なぎ払いでは、足先の基準点だけでなく、足メッシュの全境界頂点の世界座標で最低高さを測り、地面への潜り込みを検出したフレームだけ二骨IKで脚を持ち上げます。足首の向きと関節長を守り、最後に接地した位置から滑らかに復帰します。攻撃開始時の胴体接地高さは従来どおり最初の一度だけ算出し、連続して再測定しません。

## 頭部

頭のアニメーションはIdle/Turn/Approach/攻撃中のいずれも再生しません。Waitの基準首角度から、衝突回避付きの独立したプレイヤー追尾を継続します。なぎ払い中も**胴体はプレイヤー追尾しない一方、頭だけは追尾**します。既存のダウン・起き上がりの安全動作は維持します。
