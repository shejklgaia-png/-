# セラ v33 — 白い斬撃の視認性修正（v32動画への対応）

## 動画から確認した問題と対処

1. **斬撃の主軌跡が細く、ほぼ消失**：v32の元テクスチャ不透明度0.35を1.00に戻しました。v29と同じ白い主軌跡を視覚的な主体にします。
2. **ターゲットに重なる斬撃が極端に薄い**：v32のターゲット遮蔽時表示率0.28を初期値1.00に変更。ターゲットより手前に見せる方式を初期状態にしました。
3. **立体効果の重なりが主軌跡を濁らせる**：立体面の強度0.75→0.66、主軌跡を優先します。
4. **独立粒子が小さすぎる**：発生率27→54個/秒、粒径0.009–0.024m→0.016–0.034m。
5. **画面内の前後関係が検証しづらい**：`debug_disable_occlusion`を追加。trueで深度処理を一時解除し、座標と深度のどちらに問題があるか比較できます。通常はfalseにしてください。
6. **前後関係のフェード帯が太い**：境界のソフト幅0.075→0.025m。
7. **ターゲット判定が立方体内部全域に適用されていた**：箱の内部ではなく、実際の表面付近の深度だけをターゲットとして分類します。

## 変更しないもの

- Blockbench由来の`Swordeffect`の親階層・モデル・アニメーションと0.55m前方移動
- UVの4×2／8フレーム・各フレームの立体メッシュの座標
- 通常攻撃、ターゲットHP、ドラッグ移動、カメラ

## 切り替え

`scripts/sword_trail.gd`先頭の値を変更。

```gdscript
@export_range(0.0, 1.0, 0.05) var flat_layer_opacity: float = 1.00
@export_range(0.0, 1.0, 0.05) var target_occluded_visibility: float = 1.0
@export var debug_disable_occlusion: bool = false
```

- `target_occluded_visibility = 1.00`：プレイヤーの後ろに隠れる／ターゲットより手前に見える（初期設定）
- `target_occluded_visibility = 0.75`：ターゲットの後ろに入った部分だけ、やや薄く表示
- `debug_disable_occlusion = true`：深度判定を解除し、斬撃が常に見えるか切り分けるテストモード（プレイヤーの前にも出ます）

## 検証上の注意

本パッケージではメッシュ・UV・親ノード・モーションを変更しておらず、v32の過剰な透明度と表示調整を優先的に修正しました。
Godot本体およびAndroid実機での描画確認はできていません。完全な描画保証はありません。

プロジェクトフォルダーの`project.godot`をGodot 4.7.2 Androidで開いて実行します。
