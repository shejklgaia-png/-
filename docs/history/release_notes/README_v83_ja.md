# セラ v83 — 格闘3段コンボ（Blockbench原本取り込み）

## 操作

- **1回目のタップ**：従来どおり `meleeboost` → 自動接近 → `melee1`。
- **2回目のタップ**：`melee1` の攻撃中に入力すると `Melee2` を予約。キャンセル開始時刻以降は待たずに移行します。
- **3回目のタップ**：`Melee2` の攻撃中に入力すると `Melee3` に移行。最大3段です。
- 先行入力は1段分だけ保持。タップしていなければ各モーションの残りを最後まで再生し、従来どおり待機へ戻ります。
- 3段目から4段目にはつながりません。3段目には振り抜き後の回復開始点が設定されていますが、追加の格闘段は発生しません。

## キャンセル開始点

Blockbenchの各モーションは24fpsです。「振り抜き後2フレーム」を **約0.08333秒** と解釈し、後半の振り抜きキーフレームを基準にしました。

| 段 | クリップ | 振り抜き時刻 | 連係・回復の開始 | クリップ全長 |
|---|---|---:|---:|---:|
| 1 | `melee1` | 0.2083秒 (5f) | **0.2917秒 (7f)** | 0.5000秒 |
| 2 | `Melee2` | 0.2083秒 (5f) | **0.2917秒 (7f)** | 0.5000秒 |
| 3 | `Melee3` | 0.5417秒 (13f) | **0.6250秒 (15f)** | 0.8333秒 |

3段目のキャンセル時刻は、格闘の次段がないため主に将来の派生行動の基準点です。従来のフリックによるステップキャンセル・ドラッグ入力による攻撃中断は **仕様を変更していません**（この格闘連係ゲートでは制限しません）。

## 実装・モデル

- 使用モデル：添付 `セラ･格闘連打.bbmodel` の `melee1` / `Melee2` / `Melee3`。
- **v82のモデル形状、通常移動、左右ステップ、被弾 `Damageknock` 0.22秒、`meleeboost` はそのまま保持**。添付モデルは左右ステップクリップを含まないため、それ以外の既存クリップを差し替えていません。
- `assets/sera_source.json` とAPK用 `assets/sera_data.gd` を同時更新。
- 編集用の統合モデルを `blockbench/SERA_melee_combo_3_v83.bbmodel` に同梱。
- 各段で斬撃の命中判定とヒットエフェクトを独立管理。ダメージ・ヒットストップ等の基本値はv82と同じ（従来1撃20、ヒットストップ0.06秒）。3段目の剣軌跡だけ開始時刻を遅らせ、長めの振り抜きに同期。
- 格闘コンボ中の敵の射撃、ステップ、ブースト、追従カメラの各処理・係数は未変更。
