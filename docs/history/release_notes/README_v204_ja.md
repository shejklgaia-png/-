# SERA v204 — 重量脚部のスライドモーション

## 対応する脚部
- **LOWER BODY B / D：重量級**。通常のRUN操作では脚を交互に動かすRUNモーションではなく、既存の4方向ブースト姿勢（Boost_front / Boost_back / Boost_Left / Boost_right）を使います。この移動表示を **SLIDE（スライドモーション）** と定義します。
- **LOWER BODY A / C：従来どおり**。通常RUNモーションを使用します。
- **Dの重量級性能**：暫定的にBと同じ HP+26、防御0.30、RUN速度3.35m/s、BOOST速度係数0.82、被弾時間1.1、ノックバック0.60、転倒耐性5回としました。今後D専用の性能調整が可能です。

## BOOSTとの違い
- スライド時はブースト入力判定が成立していません。元のBoost_*ポーズを表示するだけで、ブーストのEN消費、速度増加、残像を発生させません。
- BOOST入力が成立した場合は従来どおりの速度・EN消費・残像を使用し、入力終了後の0.50秒のブースト姿勢維持を保持します。
- ステップ中の残像は従来どおり継続します。SLIDEからBOOSTへ、またBOOSTからSLIDEへの姿勢切替では同じ4方向キーを共有するため不要なRUNへの切替を挟みません。

## 将来実装するスラスター
- SLIDE：**脚部スラスターのみON**。
- BOOST：**脚部スラスター＋背面ブースターON**。
- この区別はリグの移動状態とスラスター意図取得APIとして用意済みです。スラスターの3Dモデルや噴射エフェクト自体はまだ追加していません。
