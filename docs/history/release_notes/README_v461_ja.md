# SERA v461 — スラスター音の音量を半分に

スラスター継続音`01`と加速音`13-1`をどちらも**振幅50%（-6.0206dB）**に変更しました。

| 音源 | v460 | v461 |
|---|---:|---:|
| 01 継続音 | -12.5dB | **-18.5206dB** |
| 13-1 加速音 | -3.0dB | **-9.0206dB** |
| ビットタランBGM | -5.0dB | **-5.0dB（変更なし）** |

その他、ブースト・ステップ・追尾時の音声切り替え／同時再生、01のループ、スラスター終了時0.22秒フェードアウト、Android OGG読み込み対策は維持しています。元のOGGファイル、ゲームの当たり判定・原本モーションは変更していません。

GitHub側の更新だけでは旧APKへ反映されません。Android実機での聴感は未確認です。
