# SERA v521 — 装備・素材のカード全面タップに対応

## 操作変更
- 3列の四隅欠けスロットは維持したまま、**アイコン・装備名／素材名・所持数・余白のどの位置をタップしてもカードを選択**できるように変更しました。
- 対象はLABOの試作装備7種類、素材変換の12種類、倉庫の装備7種類の選択可能なカードです。
- 選択ボタンをカードの最上位に透明な1つのタッチ領域として配置。子のアイコンと文字は見た目専用にすることで二重発火を防止します。
- 倉庫の素材12種類と、所持個体UIDの一覧は引き続き参照用の表示です。閲覧以外の操作は追加しません。
- 上部タブと戻る操作、個体ID・製作/保存・素材数量・モデル・戦闘の仕様は変更していません。

## CI
- 着手時にv519のスロット／アイコンテスト、v518の実タップ検査、CIマニフェストと本体コードを確認。
- 本体変更前に`v521_full_card_touch_self_check.py`と`v521_full_card_touch_runtime_check.gd`を作成してCIに登録。
- Godot上でカードのタップ領域が枠全体に一致すること、アイコン・名前・余白への実際のタッチで正しい画面へ進むこと、二重ボタンがないことを検査。
- Android実機の最終的な視認性・タップ感は別途確認が必要です。
