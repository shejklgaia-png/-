# SERA v356 — ビットタラン正面・背面の左右脚ロック安定化

- ビットタラン正面から戦闘を開始すると、左右の脛の拡大ロック判定を同じ水平2本線が通過し、IKのわずかな動きでロック先が左右に頻繁に入れ替わる問題を修正しました。
- 前脚2本・後脚2本をそれぞれ独立した左右ペアとして扱い、**左右の実際の脛位置を結んだ線の中点**で左右判定します。中央付近では現在のロックを優先し、反対側へ0.65m以上移動すると同じ判定フレームで切り替えます。ロック待機時間は追加しません。
- 初回取得時は左右のどちらか1つを決定します。両方の判定に触れても交差距離の微細な差で取り合いません。
- 従来の前脚と後脚の切り替え境界、2本の水平ロック線、ロック判定の大きさ、手動選択、ダウン中のHEAD/BODY、破壊済み部位への命中は変更しません。
- 追加テスト：`tools/v356_bittaran_lateral_lock_runtime_check.gd`。正面・背面それぞれの中央付近で120回ずつの微細な揺れ、左右への相互切り替え、およびIKで姿勢が変化する90フレームを検証します。
