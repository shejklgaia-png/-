# SERA v500 — 腹下に重装甲の砲台1基＋発射瞬間の十字閃光

## 変更点
- 腹部前後左右の4砲台をすべて削除し、原本の`Body/body_mesh`下面の**中央に1基のみ**設置。半球の平坦な底面をボディ装甲へ約1.8cm埋め込んだ接合。装甲・アニメ・IK原本は無変更。
- 砲台外装を強化：半球半径0.24→**0.36m**、基部の金属製装甲カラー（直径0.86m）、砲身0.44→**0.68m**、太い装甲スリーブ、拡大した青い発光銃口。単砲台ながら重厚な見た目にする。取り付け座標と装甲外形からはみ出さない設計。
- **発射の瞬間、銃口を十字（横棒＋縦棒＋中心光球）に青白く発光**。実際の砲口ローカル座標に固定し、追尾に同期して移動・回転。点灯時間は**0.085秒**で、次弾まで消灯。再射撃のたびに再点灯、停止/ダウン/リセット時は即消灯。ビットタランの体や地面との前後関係は従来の深度テストを維持する。
- プレイヤーの継続追尾はこの1基のみ。発射方向は実際の砲身の向きに一致。
- **1.2秒間隔、弾速17m/s、既存の命中/ガード/ノックバック、通常攻撃中の発砲禁止、ダウン中の追尾・発砲停止、背部レールガンのダウン中停止**は維持。
