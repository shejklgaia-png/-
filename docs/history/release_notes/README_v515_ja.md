# SERA v515 — シールドの実体膜と破壊時の空洞演出

## 変更点
- 通常のシールド防御時は**中心から色のある膜で埋まる**表現に変更。中心0〜20%半径は一様な高彩度の色付き面で、接触時の白い閃光が消えた後も膜が残る。中間は薄い半透明のたわみ、外周73〜82%に細く強い輪郭を表示。
- シールドが剥がれた**破壊時だけ**中心に穴が開く。破裂リングの内径は半径14〜23%、横一線の青白い稲妻と、10方向の鋭い破片・放射状破裂・専用SEが発生。
- テストターゲット・ビットタランは共通の表示処理を使用。防御時は中心に穴を開けず、破壊後にのみ空洞化する。

## 変更しない要素
- 通常防御光・破壊演出の最大サイズ、青/黄/赤の色分け、描画優先度115と深度テストON、ヒット火花がシールドより手前に描画される順番、HPバーへのシールド重ね表示なし。
- シールド最大100SP、近接最大25%・射撃最大95%軽減、最後の被弾から4秒後に毎秒20SP回復。HP・部位破壊・判定・Bittaran脚IK・レールガン・LABOの製作装備やアイコンを変更しない。

## CI
- 作業開始時に既存シールドv510検査、描画順契約、CIマニフェストを確認。
- **描画本体より先**にtools/v515_shield_membrane_self_check.pyとtools/v515_shield_membrane_runtime_check.gdを追加・登録。実際のGodot ImmediateMeshの位置と頂点アルファで、通常膜の中心の充填と破壊後の空洞を検証する。
- mainへマージ後の全Python/Godot CIとAndroid実機で最終検証。実機では輪郭のキレ、破壊時の穴、青白い破片・SEを確認してください。
