# SERA v146 — セラの移動中の膨らみを抑える修正（2026-11-08）

添付動画`1000034285.mp4`の拡大・格納中、セラが途中で過剰に大きく見える問題に対応しました。

従来のv145は、セラ本体の表示中心を画面上で直線移動させていましたが、**途中の表示サイズは制限していませんでした**。カメラのFOVや奥行き、セラ自身の倍率が異なる速度で変化するため、画面中央付近で一時的に膨らんで見える可能性がありました。

v146では開始時と終了時のセラ本体の見かけの幅・高さを計測し、移動中の表示サイズがその2値の間を結ぶ補間サイズを超えないようモデルの倍率を調整します。位置は一定速度の直線移動のまま、向きの補間も維持します。v145の4回の位置補正は廃止し、サイズの抑制と中心位置の補正を2回に簡素化しました。

**維持する仕様：** セラ移動0.28秒／カメラ移動0.18秒、タップ直後の同時開始、拡大位置へ到着してから背景グリッドとグラデーションを表示、戻る操作では背景を即時非表示、既存3区画メニューとNEXUS_pose。

回帰テストは`tools/v146_bounded_body_motion_self_check.py`。GodotエディターやXperia実機での最終的な見え方は未検証です。
