# SERA v184 — 通常格闘の発動距離を1.0mに変更

通常格闘の追尾終了・攻撃モーション開始距離を、敵の当たり判定表面から **0.75m → 1.0m** に変更しました。距離はセラの中心座標から敵のコリジョン表面までの水平距離です。

## 対象
- 通常格闘1段目（`melee1`）の追尾終了と攻撃モーション開始
- 2・3段目（`Melee2` / `Melee3`）の追尾終了と攻撃モーション開始
- 格闘攻撃中、未命中の場合に追尾を停止する距離
- ターゲットの近接射程UI表示（同じ距離閾値を使用）

## 今回変更しない値
| 設定 | 値 |
|---|---:|
| Aの格闘1段目・攻撃前追尾上限 | 0.4秒 |
| Bの格闘1段目・攻撃前追尾上限 | 0.6秒 |
| 格闘2/3段目の攻撃前追尾上限 | 各0.2秒 |
| バッシュ攻撃前の追尾上限 | 0.2秒 |
| バッシュの発動射程 | 0.95m |
| 通常格闘の距離命中補助（A頭部） | 0.83m |
| 通常格闘の距離命中補助（B頭部） | 約0.82m |
| 剣の3D判定厚さ | 0.14m |

通常格闘の攻撃開始距離と命中補助距離は別設定です。1mから攻撃が始まっても、剣の3D軌道による接触か、従来の距離補助範囲に入らなければヒットは確定しません。これらの既存判定は変更していません。

## 確認
1. GitSyncでmainを同期して `SERA v184` を起動します。
2. 訓練ターゲットから少し離れた場所でタップ攻撃し、表面から1.0mで追尾を終えて攻撃に入ることを確認します。
3. 格闘2・3段目も1.0mで攻撃へ移り、振りかぶりが省略されないことを確認します。
4. バッシュの射程が0.95mのままであること、追尾時間と攻撃判定のタイミングが変わっていないことを確認します。

静的検査：`tools/v184_melee_start_range_self_check.py`。Godot/Android実機での動作検証は未実施です。
