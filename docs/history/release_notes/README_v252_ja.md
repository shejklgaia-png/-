# SERA v252 — 画面方向に沿った一貫した操作

## 操作方向
- **RUN/BOOST/空中ドラッグ**：従来どおりカメラの画面水平・垂直方向を地面へ投影した方向へ移動。カメラが回り込んでも、ドラッグの左右は画面の左右に対応。
- **360°フリックステップ**：旧仕様の「ターゲットの周囲を回る円弧」から、フリック開始時に確定したワールド方向へ**直線**で移動する方式に変更。
  - 右／左フリック → その瞬間の画面右／左（カメラ右ベクトル）。
  - 前（上）フリック → **セラの向いている前**（`-player.basis.z`。通常はロックしたターゲット方向）。
  - 後（下）フリック → セラの向いている後ろ。
  - 斜め → 画面左右とセラ前後の合成方向。移動方向はフリックを離した瞬間に確定し、ステップ中のカメラ回転で曲がらない。
- **前フリックのバッシュ**：既存のガード中・コンボ派生の上方向フリック認識と攻撃対象への追尾を維持。
- **左右ロック切替**：従来どおり画面に投影された部位を基準に左右へ選択。
- **タップ攻撃・ガード・AUTO/MANUAL・タッチ開始可能範囲**：変更なし。

## 距離・速度・衝突
- 前ステップ3m、後ろ4m、側方2〜4m、全方向2〜4mの既存上限、速度10m/s（接近時の前後のみ8m/sに低下）、装備倍率、アニメーション・ステップモーションの方向補間、EN消費15を維持。
- 旧ターゲット中心の円弧のための接近角度計算を、**指の向きに合う直線経路**へ変更。ターゲット付近ではv251の部位・本体衝突判定による水平スライドが適用され、物理的に通れない場所は無理に貫通しません。
- 斜め合成が極端なカメラ位置でほぼ相殺される場合は、画面方向のベクトルへ安全にフォールバックします。

## 検証
- v200の旧円弧期待値を更新し、v252用の方向/距離/スクリーンベース維持の静的・数値テストを既存CIへ追加。
- Android端末での方向感覚、カメラ回転中の入力、ステップ・ガード派生の操作感は未検証です。自機の前向きと「画面上方向」が大きく異なる場面では、前ステップは**ユーザー指定の自機前向き**を優先します。
