# SERA v334 — 敵の左右を越えるカメラ鏡像補正とロック前方コントローラー

- **カメラ**：セラの表示胴体と敵中心の横画面座標を比較し、左右2.5%幅のヒステリシスを越えたらショルダー補正を左右反転。旧判定はビューポート中央を基準にし、結果もYawに反映していなかった。新仕様は反転角度を指数補間（毎秒7）し、1フレームごとに旧角度へスナップしない。
- 判定はカメラYawを調整する前に1フレーム1回だけ行う。反転中は画面端の17段Yaw補正探索を停止し、既存の安全半径ズームを使うため補正どうしが競合しない。従来のSTEP後0.3秒復帰・格闘追尾・カメラ焦点・近距離ズーム・60Hz物理補間を維持。
- **コントローラー**：従来の「ロックへ向かう水平1m線」の投影は、実際に画面で表示される頭/脚ロックサイトの位置と角度が異なった。新仕様はセラの胸中心（高さ1.05m）から、**ロックマーカーと共通の3D照準点**（部位固有の高さを含む）を、それぞれ同一カメラで投影した2D線を前方として使う。プレイヤー/ターゲットの座標は描画時に一度補間取得したキャッシュを共有し、複数回の取得によるフレーム内の表示ずれを防ぐ。
- コンボフリック中はタッチ時に方向を固定して判定/表示を一致させるが、通常RUN/BOOSTではカメラ・ロック対象の移動に合わせて色区画をリアルタイム更新。コンボ指離し中も独立した遅れを入れず同期。重なり（前方線4px未満）や画面背後では水平方向に基づく安全な前方へフォールバック。
- 攻撃派生4方向、通常STEPのスクリーン連続方向、アイコン表示、モーション、カメラ距離・衝突条件はそのまま。
- **実機未確認**：Androidで左右を横切る連続移動のカメラ反転と指操作中の色ガイドがターゲット線に合うか確認してください。
