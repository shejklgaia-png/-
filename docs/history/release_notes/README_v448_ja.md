# SERA v448 — ビットタラン：原本による前後なぎ払いの全工程再生

## 攻撃モーションの刷新
ユーザーが新しく制作した `ビットタラン (1) (1) (1).bbmodel` を、元データを保護したまま統合しました。

| 攻撃 | 原本再生時間 | 元の編集データ |
|---|---:|---|
| 前左脚「なぎ払い」 | 2.625秒 | `なぎ払い_L` 73キー |
| 前右脚「なぎ払い_R」 | 2.625秒 | 左前脚を左右鏡映 |
| 後左脚「後足なぎ払い_L」 | 1.54167秒 | 同名36キー |
| 後右脚「後足なぎ払い_R」 | 1.54167秒 | 左後脚を左右鏡映 |

- **振りかぶり→往路→復路→足戻し**のすべてを新しいBlockbenchモーション内に収録。攻撃中は原本時刻を**1倍速**で再生し、以前の0.5倍速スロー・別IK足戻しを重ねません。
- 原本末端に基本姿勢への復帰があるため、攻撃クリップ終了後は待機姿勢への短い約0.2秒の移行のみ追加します。
- 右脚は実ボーンの左右を入れ替え、Euler回転のY/Z符号反転と位置のX符号反転で生成。骨格関節Pivot、メッシュ・テクスチャ、他の弾き／踏みつけ／歩行モーションには手を加えていません。
- `models/bosses/Bittaran.bbmodel` と `assets/bittaran_data.gd`（Androidフォールバック）を同期。提供された原本は `models/storage/ビットタラン_20261118_新なぎ払い.bbmodel` にそのまま保存しました。
- 新原本では元のキーUUIDの一部が旧モーションと重複していたため、ゲーム統合モデル内のみIDを整理しました。キーフレーム値は変更していません。

## 動作検証
- Godot: 前後左右4脚・218キーフレームの照合、原本時間・1倍速・Android埋込の一致が合格。
- Godot戦闘シーン: 4脚計310フレームを再生。3本の支え脚の最大接地位置誤差約1.21mm。攻撃脚の足先メッシュ最低点は床から最大約0.002mmの負値にとどまり、深いめり込みは検出されませんでした。
- Pythonの回帰テスト182件が合格。Godotの全体回帰テスト126件では20件が失敗しています。旧モーション／旧状態遷移の想定や他の攻撃の接地問題など、既存のテスト負債が残ります。
- **Android実機での動き・フレームレート・描画は未検証**です。Godotのheadless実行結果を実機の視覚品質保証と混同しないでください。

## 既存仕様
- 直前と同じ攻撃種別を連続して出さず、別種の攻撃条件を満たす位置へ歩くAIは保持。
- 踏みつけ・弾き・その他の骨格とゲームの進行条件は維持。
