# SERA v145 — 直線移動の再調整と背景エフェクト表示タイミング（2026-11-08）

添付動画`1000034283.mp4`に見られる曲がった移動感を改善するため、移動の基準を胸の1点から**頭・肩・胴体・脚を含むロボット全体の見た目の中心**へ変更しました。剣・盾は形状の長さが大きく異なるため、移動基準から除外しています。

- 拡大・格納中の画面上の中心位置は、始点から終点へ**一定速度の直線**で移動します。
- 回転と大きさは別の滑らかな補間にし、それらの変化が移動経路を押し曲げないよう再投影で補正します。
- モデルとカメラのTweenは従来どおり同時開始し、モデル0.28秒／カメラ0.18秒のままです。
- **背景エフェクトはセラが指定の拡大位置に到着してから表示します。** 拡大中にはグラデーション・グリッドとも出ません。戻るボタンでは従来どおり瞬時に消えます。
- 左上表示位置・回転操作・左下四角／右縦長メニュー、NEXUS_pose、戦闘や音声への変更はありません。

静的検査：`tools/v145_visual_center_glow_delay_self_check.py`。数値シミュレーションは代表的なモデル点から求めた投影中心の直線性検証であり、Godot・Android実機での映像検証は未実施です。
