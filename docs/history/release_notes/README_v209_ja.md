# SERA v209 — スラスターノズル本体回転とRUNのちらつき抑制

## 3Dノズルを実際に回転
- v208までは背面の噴射エフェクトのみを回転させ、ノズルのメッシュ自体は固定していました。
- 今回はBlockbenchの `Thruster_L` / `Thruster_R` **グループのPivotを直接回します**。各Pivotの子にあるOuter/Innerメッシュと噴射エフェクトが一体で動きます。本体 `BOOSTER` は固定です。
- ピボット位置と元のグループ回転を保存し、方向計算に**回転前のグループ基底**を使用します。現在の回転角を計算へ重複して戻さず、追従の振動を防ぎます。
- 角度は**左右±80°、下90°、上1°**。0.075秒の緩和と進行方向の逆への追従、移動時の表示条件は維持します。噴射が消えるとノズル本体も自然に元の向きへ戻ります。

## RUNのちらつき修正
- RUNと後退RUNを混合中、入力が真後ろの左右境界をまたぐと、腰の回転方向の符号が反転して不自然に瞬間回転する可能性がありました。後退へ入り始めたときの回転方向を保持し、前進RUNへ完全に戻るまで反転させません。
- RUN中の足音に同期した接地補正で、従来は1フレームだけ**セラ全身を上下移動**させ、次フレームに戻していました。これをやめ、接地した片足の装備メッシュだけをその1フレームで床に合わせます。次のフレームでメッシュの元位置へ戻すため、全身の高さがちらつきません。
- 待機中の全身接地処理、足音の判定と発音、走行速度、実際の移動方向、脚部ごとの元モデルとモーション、ステップ、ENとBOOSTの挙動は維持します。
