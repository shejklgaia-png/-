# SERA v402 — 実機フィードバック修正：弾き／なぎ払いの戻りの跳ね解消とシェイク再調整

v401の実機確認で寄せられた2点（カメラシェイクを感じない／左前脚以外の弾きがおかしい）を、実シーン計測で原因まで特定して修正しました。

- **弾きの戻りの跳ね（後脚）**：蹴った脚が戻る途中、右後・左後の脚だけ関節が1フレームで最大56°跳ねていました。戻り区間はIKが脚を解き直しますが、その際の「膝を内側に巻く」補正の重みが戻り全体に尾を引いていて、途中で膝の曲がる面が反転していたのが原因です。補正を戻りの最初の0.12秒で抜くよう変更し、跳ねは全脚で9°以下になりました。
- **なぎ払いの戻りの跳ね（全脚）**：脚全体を床から持ち上げる補正が、モーション再生からIKへの引き継ぎ境界で一括で切れていて、脚の付け根が0.74m瞬間移動し、肩が最大49°跳ねていました。持ち上げ量を記録しておき、戻りに合わせて徐々に抜くよう変更し、跳ねは全脚で18°以下（残りは技自体の速い戻り）になりました。
- **カメラシェイク**：発生はしていましたが、実測で画面の移動量が最大5.3ピクセルしかなく、実質見えていませんでした。振幅を再調整し、同じ条件で約22ピクセル（近距離ではさらに大きく）動くようになりました。必ずゼロへ収束する性質は維持しています。
- **検証**：新規 `tools/v402_bittaran_recovery_smoothness_runtime_check.gd` で、全脚の弾き／なぎ払いの戻りの滑らかさ（修正前は全脚で失敗）と、踏みつけシェイクの画面移動量・ゼロ収束を検査します。全件CIスイート（静的182件＋Godot 138件）が合格しています。Android実機での見た目とシェイクの体感は別途確認をお願いします（強すぎる／弱い場合は数値で調整できます）。
