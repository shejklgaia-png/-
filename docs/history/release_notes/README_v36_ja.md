# SERA v36 — 影の簡略化・プレイヤー足元の丸い影

v35の剣エフェクト・攻撃・カメラ・操作を維持した表示調整版です。

## 変更点
- DirectionalLight3D のリアルタイム影 (`shadow_enabled`) をオフ。地面に落ちる多角形の影を消去。
- プレイヤーのすべてのメッシュの `cast_shadow` をオフ。
- ターゲットの `cast_shadow` をオフ、`shading_mode=UNSHADED` で面ごとの照明による明暗を除去。
- プレイヤーのルートノード直下に `PlayerFloorMark` を追加。`TargetFloorMark` と **同じ円柱メッシュ、同じ色、同じサイズ** を共有。移動・回転に追従しますが、攻撃モーションの上下動には追従しません。
- 既存のターゲット床面マーカーは、デザイン・位置・大きさともに維持。

## 意図的に維持したもの
- プレイヤーのテクスチャに塗り分けてある上面/側面/下面の色。これらは光源による陰影ではなく絵柄としてのベイク済み配色です（形状・配色を不意に変えないため）。
- 斬撃の位置0.55m、白い弧、8フレーム、奥側メッシュ、白い粒子、v35の描画処理。
- 戦闘・移動・カメラ・ヒットストップ等のロジック。

## 実機確認ポイント
1. プレイヤーとターゲットの輪郭に沿った黒いリアルタイム影が床から消えること。
2. 両者の足元に同色・同サイズの青緑色の円が表示されること。
3. プレイヤーの円は移動中も足元に追従すること。
4. 剣のエフェクト、命中判定、HP表示に変更がないこと。

**Godot実行機はこの作業環境にないため、静的チェックのみ実施。**
