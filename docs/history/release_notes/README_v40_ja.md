# セラ v40 — 近接範囲だけロック円を太くする

v39を基準にした表示調整です。

## 変更内容

- 近接可能距離（ターゲット表面から水平0.75m以内）の赤い外周4本の弧の線幅を **2.5px → 5.0px** に変更しました。
- 距離が離れて近接範囲外になると、**シアン・2.0px** に自動で戻ります。
- 中央の十字は両状態とも従来の2.0pxのままです。弧の半径・色・長さも変更していません。
- ロックオンの近接判定は、従来の攻撃接近判定と同じ `_distance_to_cube_surface(player.position) <= MELEE_SURFACE_REACH` を使用します。
- `set_melee_in_range()` が距離状態の変化で `queue_redraw()` を呼び、`main.gd` の `_physics_process()` が移動直後に状態を更新するため、接近と離脱の両方を反映します。

## 維持事項

敵HP0での攻撃継続、HP自動復帰、剣エフェクト、プレイヤーとターゲットの陰影・丸い影・グリッド、カメラ・移動・攻撃判定はすべてv39から変更していません。

## 確認方法

1. 遠くでは細いシアンの円が表示される（2.0px）。
2. ターゲット表面から0.75m以内に入ると赤い太い円になる（5.0px）。
3. そこから離れると細いシアンに戻る。HP0の敵でも同じ。
