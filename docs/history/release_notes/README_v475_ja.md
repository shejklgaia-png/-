# SERA v475 — レーザー初回命中後はノックバックでフルヒット

## 被弾仕様
- ビットタランのレールガン照射中、**最初の命中は従来のレーザーとプレイヤーの実際の当たり判定**で判定します。射線から外れたBOOST中のSERAへは命中しません。
- **1回でも非ガードのレーザーが命中した時点で、通常のDamageknockリアクションを開始**し、ノックバック（基準1.2m／0.24秒・装備倍率を反映）を与えます。戦闘状態と移動操作は被弾リアクションによって中断されます。
- 初回命中後は**レーザー照射終了まで連続ヒットを確定**し、衝撃でプレイヤーがレーザーの当たり判定外に押し出されても、既存の**0.5秒ごとのダメージパルス**を受けます。
- **2秒照射の初期フレームで当たった場合は最大4回**（開始時・約0.5秒後・約1.0秒後・約1.5秒後）。途中で当たった場合は**残りの照射時間に対応する回数**だけ命中します。HPが0になってKOした場合は追加ダメージを加算せず、レーザーの表示は従来どおり2秒が終了するまで続きます。
- 最初の命中時に始まったDamageknockの**操作不能・怯み姿勢は照射終了まで継続**します。0.5秒ごとの追撃ではノックバックアニメーションを再起動しません。
- **レーザー終了時には連続ヒットフラグと操作不能の保持を解除**。次のレーザーに持ち越さず、次回は改めて実際にレーザーが当たったときのみ連続ヒットになります。
- **ガード時は従来どおりシールドが先に減少**し、シールドが残っている間はノックバックしません。シールドブレイク後は通常の被弾処理が適用されます。
- 他の攻撃のダメージ処理、連続ヒット・ノックバック挙動は変更しません。

## 維持する砲台仕様
- 0〜10秒充填中は追尾しません。10〜12秒の青い球体出現と同時に追尾開始、12〜14秒レーザーを照射しながら追尾、**14〜14.7秒で即座に基本姿勢へ補間**します。
- 球体出現時0.7秒の追尾への補間、RUNより速いがBOOSTより遅い追尾速度、発射直後からの当たり判定、青縁・電撃・流動プラズマ、45m照射、実モデル・ボーン・IKは維持します。
- **初回接触前はBOOSTで回避可能**です。

## 実装・検査
- `scripts/bittaran_railgun.gd`：実当たり判定で初回命中したビームだけ、照射終了まで0.5秒間隔の追撃を継続する連続ヒット状態を保持。次の発射でリセットします。
- `scripts/bittaran_battle.gd`：レーザー初回命中を既存の物理ノックバック・Damageknockへ接続。照射終了で長時間の被弾保持を解除します。
- `scripts/main.gd`：ビットタランのレーザーが確定命中中だけ、既存のDamageknockを照射終了まで維持する小さな制御フラグを追加。通常攻撃には影響しません。
- `tools/bittaran_railgun_runtime_check.gd`：最初の実接触・連続4パルス・射線外でも継続・ノックバック位置変化・ビーム終了後の解除・ガードの優先・次回への持ち越しなしを実際のGodotで検査。既存の8m／30mでのRUN／BOOST回避検査は保持します。
- Android実機での当たり方・怯み演出・ダメージ間隔の最終確認は別途必要です。
