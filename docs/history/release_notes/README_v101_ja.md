# セラ v101 — ホールドガード（2026-11-06）

**基準版：** `sera_portrait_godot_melee_v100_jump_debug_only.zip`。既存の戦闘・移動・カメラ・敵AI・音・ジャンプのデバッグ機能を保持します。

## 操作

- **静止ホールド（0.32秒以上）**：指を置いて押したまま、タップ判定距離の最大18px以内を保つと、ユーザー制作の `Guard` ポーズになります。ガードはホールド中持続し、指を離すと待機へ戻ります。
- **ガード中の入力制限**：移動・ブースト・左右ステップ・4mバックステップ・格闘・ジャンプ（デバッグ含む）は発動しません。ガード開始時の速度は0にし、指を途中で動かしてもガードを解除・移動・派生させません。解除には一度指を離します。
- **被弾判定**：ガード中に弾・範囲攻撃を受けても `Damageknock` アニメーションとノックバックを起動しません。赤い被弾フラッシュも表示せず、既存の金属ヒット音だけ再生します。ガード前や解除後の被弾処理は従来どおりです。
- **操作の互換性**：短いタップで格闘、スワイプで移動、リリース時フリックでステップ、長いドラッグでブーストする従来方式は保持します。**指を動かしてからホールド**した場合、最大移動量が18pxを超えていればガードには入りません。
- **PC検証用**：Gキー押下中もガードします（リリースで解除）。既存のSpace/Enter・J・Cのデバッグ操作を保持しています。

## ガード優先順位と対象範囲

- 立ち状態（`IDLE`）でのみガードを開始します。格闘・回避・空中・着地硬直・被弾リアクションの途中では開始しません。継続ホールドの場合、行動終了後に開始可能になります。
- v100には **プレイヤーHP・シールド値・ガード崩れを数値処理するコードが存在しません**。v101では新しいリソースやガード崩れを推測で実装せず、ダメージリアクションの抑止のみ実装しています。シールド値消費／シールド0でガード崩れ／シールドバッシュは後続工程です。
- ガードの正面／背面判定や専用ガード効果音、ガード中の方向転換制限も未導入です。
