# SERA v305 — セラの向きをロック対象へ・AUTOロック遅延を撤廃

## 変更
- SERAの物理ルート（CharacterBody3D）の**水平向きは、現在ロック中の部位の狙点**（HEAD・四脚）を向きます。BODYロック（空ID）時は敵本体中心を向きます。上下の高さには追従させず、ピッチ・ロールは変えません。
- RUNモーションの移動方向を機体の向きに対して解釈する基準も、BODY中心でなく**現在のロック対象**に統一しました。走行アニメの元の移動方向・反転・クロスフェード処理そのものは変更しません。
- **AUTOロックの0.22秒の切り替え確認を完全に撤廃**し、両平行線による交差候補を同じ物理フレームで採用します。前の部位が片線から外れた場合も待機せず次候補へ切り替えます。
- 互換用の`AUTO_LOCK_SWITCH_CONFIRM_SECONDS`は0.0に変更し、候補待機時間の積算・候補待ち分岐は削除しました。既存の`auto_lock_pending_*`変数は過去テスト・外部参照向けに毎回0へリセットしますが、**ロック遅延には使いません**。
- 攻撃中・コンボ追加入力待機中の部位ロック保持、手動左右切替、部位破壊時の再取得は維持します。破壊済み部位をコンボ中に保持する場合もその部位の狙点を向きます。

## 維持
- セラ起点左右0.5m間隔の**2本の平行判定線**、各部位115%の専用カメラ用ボックス、BODYを含む交点距離比較、LINES ON/OFF、攻撃・ダメージ・モーション・物理衝突、カメラ追従とステップ距離は維持します。

## 検証
- 新規v305 Python／Godot実行検査を登録し、即時BODY↔HEAD、全6部位の水平ロック向き、MANUAL、コンボ中固定、破壊部位、カメラ非依存を検証。
- 旧版の0.22秒確認を期待していた静的／実行検査は、既存の交差幾何の検証を残しつつ即時取得の期待値へ更新しました。
- Android端末での描画・操作感は未検証です。
