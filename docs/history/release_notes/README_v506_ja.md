# SERA v506 — レールガン追尾速度への胴体姿勢・俯仰角の不正な加算を防止

## 問題と原因
- ビットタランの胴体が前傾／起き上がり／縦向きになるとき、レールガンの砲身が意図しない速度でプレイヤーを追って見える。
- 従来は「WAITの胴体姿勢 → FLASH時の水平姿勢」の`charge_entry_pose_offset`を0.7秒で戻す際に、**胴体由来のピッチ・ヨーまで追尾モーターの回転へ加算**されていた。
- 角速度の基準となる距離は**アニメーションBodyに付随して動く砲台の根元**で測られ、ボスの起き上がりだけで`chase_speed / radius`の角速度が変化していた。
- レーザー照射中の追い付き加速（0～1.5m）は前のフレームの`elevation.global_basis`と砲身のピッチを用いて地表投影していた。砲身が上向き／垂直に近づくと水平投影が短くなり、プレイヤーが横移動していなくても偏差が増大して追尾速度を加算し得た。

## 修正
- **追尾が有効になった瞬間の実際の砲身の向き**をワールド座標のモーターyaw/pitchへ一度だけ転送。待機姿勢から補正してよいのは**砲身の向きを変えないロール成分のみ**にし、0.7秒の補間で解消。胴体が縦になることや本体yaw回転がモーターに二重加算されることを防止。
- `_tracking_speed_anchor_world()`を追加。BodyのモーションやIKでは動かず、ボスのリグの実際のルート移動／水平向きには付随する**ボディ初期姿勢の根元**で角速度を決定。実際の砲台表示と命中判定は引き続き現在のアニメーションBodyの位置を使用。
- `_ground_ray_gap`を現在の**ワールド照準yawだけ**を使う水平XZレイで計算。俯仰角・胴体前傾・前フレームの砲身行列に依存させない。プレイヤーの水平偏差が0～1.5mに達したときだけ従来の0.85～1.0倍の追い付き補正を適用。
- **意図した設定はそのまま**：10秒充填中の姿勢追従、球体出現後の追尾開始、0.7秒の追尾入り、球体縮小中の0.7倍制限、照射中の0.85倍→1.0倍（水平偏差0～1.5m）、RUNより速いがBOOSTなら振り切れる速度、2秒照射、0.7秒中立復帰、命中回数無制限と0.2秒再ヒット間隔、背部の元モデル・砲口・弾・音・エフェクト・下肢IK。
- 速度差がある**充填／縮小／照射の段階切替自体は既存の承認仕様**であり、本修正は姿勢変化による追加加速・見かけの速度増加のみを排除する。
