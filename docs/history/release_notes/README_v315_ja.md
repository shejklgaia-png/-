# SERA v315 — 通常STEP発動時の1mワープ・発動地点50ms残像/加速噴射

## 通常STEP
- 前後左右・斜めを含む全方向、フリックステップの**開始瞬間**に進行方向へ最大**1m**移動します。移動は `move_and_collide` の掃引により壁・敵をすり抜けません。
- **総ステップ距離は5mのまま**。開始時1m+残り4mを同じ画面基準の方向で移動し、従来の15m/s（装備補正あり）の時間軸をワープ分だけ進め、戻り移動・二重計上を防ぎます。障害物に妨げられたワープ分だけ開始時の経過時間も短くします。
- `reset_physics_interpolation()` により開始位置→移動先の補間表示を止め、瞬間移動として描画します。

## 発動地点の演出
- 移動前のセラの**全身ポーズ**を既存のワールド固定残像プールへ強制スナップショットし、0.05秒で消します。
- 現在装備中のバックノズルに対応した既存の十角形噴射メッシュ/発光シェーダーを複製し、**発動直前のノズル位置**へ世界固定して加速バースト（`burst=1`）を0.05秒残します。描画優先度と深度設定は既存素材を引き継ぎます。
- ステップ移動中の既存の残像・スラスター演出は維持します。新しい演出は通常RUN/BOOST、バッシュ、左右蹴り・サマーソルトには追加しません。

- v315の静的・Godot実行回帰検査を追加し、8方向の1m先行移動/合計5m/15m/s・残像0.05秒・世界固定ノズル・別アクションへの非干渉を確認します。
- Xperia 1 Vの実機表示と指操作の体感は未検証です。
