# SERA v410

## 概要
実機フィードバック2件への対応です。(1)「攻撃前に基本姿勢に戻る時、攻撃足も基本姿勢の位置に戻す」— 予備動作（ウインドアップ）の間、攻撃足が基本姿勢の位置に留まるようにしました。(2)「なぎ払い時の胴体の傾きを左前脚のモーションを正として全脚へ綺麗にミラーリングし直す」— なぎ払いの胴体回転を、左前脚の回転を基準面で反転した正確なミラーに変えました。

## 何が起きていたか
- (1) v398 のスタンス準備そのものは正常で、準備完了時点で攻撃足の足裏は全脚・全技とも基本位置に誤差 0 で戻っていました。問題はその後のウインドアップ 0.70 秒で、攻撃足だけがクリップの開始ポーズへ向けて基本位置を離れてしまい（足裏の移動量: 弾き 2.2〜3.5m、なぎ払い 2.9〜5.4m）、打撃開始時点で攻撃足だけが基本姿勢に収まっていませんでした。
- (2) なぎ払いの胴体回転は、Body ボーンのローカル回転の成分反転でミラーしていました。Body のバインド姿勢はリグの基準面に対して傾いているため、左前脚の傾きを幾何学的に反転したものと最大 34.0° ずれていました（右前脚・左後脚が最悪で、クリップ開始時点が最大）。

## 修正
- ウインドアップの植え付け（`scripts/bittaran_foot_ik.gd`）: ウインドアップ中、攻撃足を支持足と同様に基本姿勢の接地位置へ解法し続けます。植え付け目標は攻撃ごとに `_home` / `_rotation_home` から1回だけ取得します（アンカー回転は踏み替え途中の古い捕捉のことがあり、右後脚で足が約14°傾いて床ガードが 0.49m のリフトを毎ティック加える不具合があったため）。リグ側の脚ブレンドはウインドアップから打撃序盤へ移しました（弾き 0.25 秒＝クリップの折り畳み保持区間内、なぎ払い 0.36 秒＝往きのリードイン内）。
- 弾き: 軌道ブレンドの開始点を「植え付けられた基本姿勢」からに変更（開始膝・足首は前ティックの解法済み位置から取得。リグのエントリ姿勢を生で読むと膝が最大 2.4m 横にずれるため）。
- なぎ払い: 打撃序盤 0.36 秒を、サンプルした著者ポーズへの解法ブレンドにしました（新サンプラ `sample_authored_sweep_pose`）。著者ポーズ自身の床めり込み量は従来の全体リフトと同じ式で補い、ブレンド中は脚全体のメッシュを対象にした床ガードも併用します。ブレンド終了時点で著者ポーズへ継ぎ目なく接続します。
- なぎ払い胴体ミラー（`scripts/bittaran_rig.gd`）: Body 回転をワールド空間でリグの基準面（左右面・前後面）に対して反転する方式に変更しました（脚チェーンで v400 から使っているのと同じ反転）。脚チェーンの補正は新しい Body 回転に追随するため、攻撃脚のワールド軌道は従来と一致します。
- ついでに直した内部不具合: 攻撃が途中で打ち切られると、弾き用にフィットした足裏点が次の攻撃へ漏れ、接触プローブと軌道補正の基準を狂わせていました（連続した割り込みシーケンスで右後脚の膝折り角が 0.12 rad ずれる実測）。攻撃の再開始を検出して足裏点を復元するようにしました。

## 計測結果
- ウインドアップ中の攻撃足の足裏の基本位置からのずれ: 全8種（4脚×弾き/なぎ払い）とも 0.0m（従来 2.2〜5.4m）。打撃は従来どおりプレイヤーへ届き、脚メッシュの床めり込みもありません。
- なぎ払い胴体ミラーの誤差: 全脚・全サンプル時刻で 0.0°（従来最大 34.0°）。

## チェック
- 新規 `tools/v410_bittaran_windup_plant_sweep_mirror_runtime_check.gd`: 全8種でウインドアップ中は足裏が基本位置に留まること、打撃がプレイヤーへ届くこと、脚メッシュが床を割らないこと、なぎ払いの Body ワールド回転が左前脚の面反転と一致することを検査。v409 ツリーでは FAIL（ウインドアップのずれ 2.24m）、本版で PASS。
- 既存チェックの変更（意図と理由は各ファイル冒頭と DEVELOPMENT.md に明記）: v391（膝の折り角の比較時点を、ウインドアップ終了時から打撃序盤のブレンド完了直後へ移し、参照も同時刻の軌道サンプルに変更。主張と閾値 0.09 rad は不変）、v396（著者回転との一致検査の開始を、打撃序盤 0.36 秒のブレンド完了後に変更。床めり込みの検査はブレンド区間を含む全ティックが対象のまま）。
