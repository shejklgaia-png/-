# SERA v180 — プレイヤー最大HPを従来の1/5へ変更

## 適用範囲
- A/B全5ボディパーツのHP寄与値だけを0.2倍に変更しました。混合装備も各部位で同じ比率になります。
- 5部位合算・胴体が総HPの約半分という計算方式はそのままです。

| ボディ部位 | A（中量） | B（重量） |
|---|---:|---:|
| HEAD | 20 | 26 |
| TORSO | 80 | 104 |
| ARMS | 20 | 26 |
| LEGS | 20 | 26 |
| BOOSTER | 20 | 26 |
| **合計** | **160** | **208** |

- 防御率、移動速度、武器攻撃力、敵HP、EN/SH、敵攻撃の基礎ダメージは変更しません。
- TRAININGのSERA HPバー・HP0時の暗色化/最終ポーズ固定・2.5秒後の最大HP復元は装備合計HPを参照するため、今回の数値に連動します。

## 確認
1. GitSyncでmainを同期してGodotから `SERA v180` を起動。
2. A一式で最大HP160、B一式で最大HP208を確認。
3. A/Bを混ぜて各部位の差分が6HP、胴体のみ24HPずつ加算されることを確認。
4. 敵攻撃でHPが減り、0でKO演出、復帰後に新しい最大HPへ戻ることを確認。

静的テスト: `tools/v180_player_hp_self_check.py`。Godot実行/Android実機表示は未検証です。
