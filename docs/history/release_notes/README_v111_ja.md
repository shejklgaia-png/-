# セラ v111 — 前方走行・後方後ずさりの2モード＋段階的ターゲット追従（2026-11-07）

**基準**：v110、GitHub `main` コミット `48929713dc59a1454ae1199f7ce7d292c932770e`。

## RUN専用の構成
- モーション：前方 `run_front_original`、後方 `run_back` の2つだけを走行ベースとして使用。既存の `run_right`・`run_Left` はデータから削除せず保持します。
- 前後の判定：敵への相対移動方向を0°とし、名目上は前200°・後160°に分割します。ヒステリシスとして前方から後退へは105°超、後方から前進へは95°未満で切り替え、境界付近の連続反転を抑止します。
- **ルートの向き**：前進は進行方向を向け、後ずさりは進行方向から180°反転した向きへ回転。最大角速度450°/秒で追従し、一瞬で体を180°回しません。腰の位置アニメーションも同じ向きで回転させ、足運びとの相対位置を保持します。
- **歩行の遷移**：前後両モーションを同じ1秒の歩行位相で再生し、0.18秒の時定数でブレンド。前後異なる歩行アニメーションの接地位相までは保証できません。
- **上半身の向き**：最上位 `Waist` が移動基準で回転。子階層 `Torso`（腹部）20%、`Chest`（胸）累積50%、`Neck`累積75%、`Head`累積100%のターゲット方向補正を分配。各関節の最大相対ヨー補正は腹25°、胸30°、首25°、頭35°です。境界をまたいだときの追従角は0.10秒の時定数で滑らかに補間します。角度が大きい場合、完全な正面維持より関節可動域を優先します。
- **旋回傾斜**：v110の左右最大15度・立ち上がり0.06秒・戻り0.20秒を維持。腰へのバンク軸はルートの現在の向きに合わせて回転します。

## 対象外と検証

- 旧v108/109/110テストは新しい2モード・バンク軸に合わせて更新。`tools/v111_two_mode_run_self_check.py` に境界・角度変換・角速度制限・関節制限・旋回傾斜のモデル検査を追加。
