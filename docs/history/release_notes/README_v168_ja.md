# SERA v168 — カスタマイズ後の輪郭線を装備形状に追従（2026-11-09）

## 変更内容
- NEXUSでA/B（将来のC以降を含む）の頭・胴・下半身・腕・左右武器を切り替えると、その時点で**表示されているメッシュだけ**を取得し直します。非選択のメッシュを輪郭へ含めません。
- 以前は各ボーンに付くメッシュの**外接箱**をまとめて輪郭を生成していたため、球体の頭、輪郭の凹凸、離れた装甲の隙間などを適切に表現できませんでした。現在は**各メッシュの実頂点**を投影して凸包を取り、既存の2D輪郭結合処理で外周を作成します。
- 同一メッシュの頂点は一度だけ抽出・重複除去してキャッシュします。ポーズ・展示位置・プレビュー回転時には現在の3D姿勢で再投影し、毎回メッシュCPU配列を読み直しません。
- 形状取得は部位変更直後に行い、選択中の輪郭情報を更新します。拠点全体画面へ戻った際も再取得するので変更後の外観が選択枠に反映されます。
- 剣閃用の`Swordeffect`、非表示のA/Bパーツは輪郭から除外します。ArrayMesh以外は旧来の外接箱方式へフォールバックします。

## 維持する仕様
- カスタマイズ拡大表示中のシアン選択線は既存どおり非表示です。拠点全体画面の選択輪郭とタップ判定を正確にします。
- A/Bセット切替・保存・戦闘側の外観、展示モーション、拡大縮小、回転、背景グロー、他モジュールの選択線・ゲート遮蔽処理は変更していません。

## 確認方法
1. GitSyncで`main`を同期し、Godotの`SERA v168`を起動してください。
2. 拠点のセラをタップしてCUSTOMIZEを開き、頭をAからBへ変更してください。Bの頭部は`sphere`です。
3. BACKで全体画面へ戻り、セラ周囲のシアン輪郭が変更後の頭部・他の装備形状へ沿うことを確認してください。腕・武器など他の部位も切り替えて確認してください。
4. もう一度CUSTOMIZEへ入り回転させ、BACK後の選択線とタップ反応が変化後の外見に追従していることを確認してください。
