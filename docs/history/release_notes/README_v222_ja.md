# SERA v222 — 通常攻撃中にノズルが身体へめり込む向きになる問題の修正

## 添付動画での現象

実機録画 `1000034525.mp4` の攻撃・追尾・振り抜き中に、左右ノズルや青い噴射がセラの身体側を向くコマが見られます。

従来はワールド空間で指定した移動方向をノズルに追従させていましたが、Blockbenchのノズルは **Chest → BOOSTER → Thruster_L/R** の階層にあり、格闘モーションで胸部が傾くため、プレイヤーの固定向きに合わせただけでは身体へのめり込みを防げませんでした。

## 対策

通常攻撃でスラスターが噴射している毎フレーム、左右のノズルを個別にチェックします。

1. 現在アニメーションで回転している **Chestのワールド中心** と、各ノズルのワールドPivotから、身体の外側へ向く方向を算出します。
2. ノズルが実際に向いている噴射軸（ローカル+Zをワールド変換）と外向きベクトルの内積を確認します。
3. 外向き内積が **0.55未満** の場合は、軸を身体から離れる側へ補正します。補正は必要な最小角に近い位置へ行い、既存の接線方向の成分を優先して残します。
4. 胸部の角度が変化しても、噴射するフレームには補正後のノズル姿勢を使用します。前フレームからの一時的な身体向きも通しません。

外向き判定は、モデル原本の実際のChest/Thrusterピボット配置を根拠としています。左右別々に判定するため、片側だけ身体側へ向いてしまう場合にも対応します。

この保護は**通常攻撃中のみ**適用し、ステップ・ブースト・画面左移動・後退での従来のノズル角度指定は変更しません。

## 維持する仕様
- v221の振り抜きまで続く通常噴射と視認性の改善
- 正10角形の噴射断面、15倍の加速バースト（0.05秒拡散・0.18秒収束）
- ノズル本体のBlockbenchモデル、Pivot、元のモーション
- 移動・追尾速度、EN消費、当たり判定、戦闘状態

検証は`tools/v222_nozzle_torso_clearance_self_check.py`の静的・数値テストと既存のGitHub Actionsです。Android実機での3D表示・機体パーツとの干渉は未検証で、見た目の確認が引き続き必要です。
