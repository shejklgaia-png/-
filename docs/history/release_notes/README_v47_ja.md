# セラ v47 — 回り込みステップ拡張（35°／最大4.0m）

v46の円弧ステップを維持して、回り込み角度と最大移動距離を増やしたテスト版です。

## 変更内容

- **円弧角度**：25° → **35°**（ターゲット中心、左右とも同じ設定）。
- **移動距離上限（円弧長）**：3.0m → **4.0m**。遠距離では最大距離を優先し角度を小さくします。
- **時間固定モード**：引き続き起動時に選択し、1ステップの所要時間は **0.26秒** に固定。
- 比較用の右上モード切り替えボタンはそのまま残し、速度固定モード 8.5m/秒との再比較も可能です。
- 待機時HUDの説明値は `ARC 35deg / MAX 4m` に更新しました。

## 敵までの距離と円弧移動距離

| ターゲット中心までの距離 | v46（25°, 最大3m） | v47（35°, 最大4m） | v47時間固定 |
|---|---:|---:|---:|
| 2m | 0.87m | 1.22m | 0.26秒 |
| 5m | 2.18m | 3.05m | 0.26秒 |
| 8m | 3.00m | 4.00m | 0.26秒 |

円弧長は `min(距離 × 角度[rad], 上限)`。移動中は、開始時点の敵中心からの半径を維持します。

## 維持する仕様

- 左右フリックは指を離したときだけ判定。**左右ドラッグは従来通り継続**。
- ステップ中に新しいドラッグを始めた場合は即時中断して通常移動へ復帰。
- プレイヤーの向き、カメラの追従、タップ攻撃、Step_L/Step_Rの補間はv46から変更していません。
- モード切り替えボタンのタッチを攻撃やフリックとして誤認しない入力分離も保持。

## 検証

`python tools/v47_orbit_self_check.py` で、v45からの入力・戦闘・カメラ関数一致、UI操作配線、円弧半径保存、距離上限、画面左右の符号、FPS依存のなさ、両モードの所要時間と3Dモデル資産の一致を静的確認します。

Godot本体とAndroid実機による動作・操作感はこの環境では未確認です。
