# SERA v290 — カタナ透明切替・2段目とフリック派生・左右移動時の敵中心ロック

## カタナの鞘／抜き身表示
- Blockbenchのカタナは**鞘側5メッシュ・抜き身側2メッシュ**が別階層です。従来は`MeshInstance3D.visible`だけを切り替えていました。v290では**透明度(`GeometryInstance3D.transparency`)と表示フラグの両方**を明示的に切り替え、GPU描画および残像にも同期します。
- デフォルトは鞘表示／抜き身非表示。1段目`Melee_katana`の**4フレーム目(0.125秒)**から鞘透明／抜き身表示。2段目では再び鞘に戻さず、抜き身を維持。連撃終了・待機・他武器装備時は状態を戻します。

## カタナ2段コンボ
- 保存済みのモデルには**専用`Melee_katana2`の原本キーフレームが存在しません**。1段目`Melee_katana`の原本トラックを非破壊複製し、腰・胸・右腕・手首・カタナ保持グループの水平方向の捻りを反転させた**別の斬撃クリップ`Melee_katana2`を実行時生成**します。元のBlockbenchモデル・source JSON・embedded JSONには手を加えません。
- カタナ選択時は**1段目→2段目**、通常武器では従来どおり**1→2→3段目**。カタナの2段目は独立クリップなのでモーションが再生されず飛ばされる問題を防ぎます。攻撃判定は元のカタナ0.13～0.345秒で有効、2段目もその時間帯に1ヒット。
- カタナ2段目の振り抜き7/24秒の**0.05秒後(約0.342秒)**をフリック派生ポイントに設定。そこから**画面上=バッシュ、右=Kick_r、左=Kick_l、下=Kick_b**へ接続します。派生を予約していない場合は0.5秒のモーション完走後、0.65秒の派生入力受付が残ります。
- 通常武器の3連撃、モーション、ダメージ、フリック受付は維持しています。

## 左右移動でボスの本体から向きが外れる不具合
- 動画では`LOCK REAR R`など部位ロック中にセラが横移動し、視覚上の胴体が敵本体の中心から横を向く現象を確認しました。原因は、プレイヤー向きの計算が**ロック部位の座標に引っ張られていたこと**と、RUNのWaist根元に**移動方向へ最大90°回す処理**があったことです。
- v290では**セラの身体の正面を常に敵全体の中心（カメラ回転軸）へ向ける**ようにし、部位ロックの照準・攻撃部位判定のみは個別の位置を維持。さらに横RUN時のWaistの旋回角を**±25°**に制限し、脚の横方向移動・RUN方向・画面タッチ操作は維持します。
- 低いカメラ視点とSERA v288のカメラ追従仕様は変更していません。
