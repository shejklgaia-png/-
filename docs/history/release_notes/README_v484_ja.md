# SERA v484 — ビットタラン本体旋回とレールガン砲身回転を分離

## 修正内容
- ビットタランの本体が水平旋回しても、背部レールガン砲身の追尾回転にその角速度が加算・相殺されないよう変更しました。
- 砲身はワールド座標のYawで独立して回転し、本体Bodyの旋回を物理更新間に引き継ぎません。砲身の取付**位置**だけは、従来どおりBodyへ追従します。
- 発射前の青球体追尾、照射中、照射後0.7秒の復帰を独立ワールドYawで制御します。本体が復帰中に向きを変えた場合も、次の充填でスナップせずに基本姿勢へ再接続します。
- 上側の縦接続軸 `RailgunChassisAxis` は従来どおり本体の水平Yawだけに同期します。レールガンの照準Yawには追従しません。

## 維持する仕様
- 充填10秒、青球体2秒、レーザー2秒、復帰0.7秒。球体縮小時と射撃中の追尾速度基準0.7倍、レーザー射線とプレイヤーの距離1.5m超での追尾速度補正。
- レーザーの攻撃力60%、0.2秒ごとに実接触した場合の無制限再命中。
- 原本Blockbenchメッシュ／14関節／攻撃モーション、脚や接続軸の位置関係、FXと音響、通常攻撃の当たり判定。

## CIと実機確認
- `tools/bittaran_world_yaw_independence_runtime_check.gd` を現行CIマニフェストへ事前登録。追尾中・復帰中の本体Yaw非加算、取付位置の追従、復帰後の角速度上限を検証します。
- 既存の砲台追尾／ボス本体モーション／軸同期テストは維持。全テストをGitHub mainのPost-merge CIで実行します。
- Android実機では、ボスが旋回しながら照射した際の砲身速度と、復帰時に接続軸が外れて見えないかを目視で確認してください。
