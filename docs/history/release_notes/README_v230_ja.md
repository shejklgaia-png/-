# SERA v230 — 近距離BOOST時のカメラ振動対策

## 対象
カメラが近い状態で左後方へブーストすると、カメラがカクつく現象への修正です。

## 変更内容
- **近距離BOOSTでの角度補正を整理**：ターゲットから6m以内でBOOSTしているときは、画面端でカメラを強制旋回させず、これまでの滑らかなターゲット追従角度を維持します。画角は既存の安全ズームで確保します。
- **状態の切り替わりを安定化**：近距離カメラの解除判定は7.5mとし、境界で通常カメラと近距離カメラが頻繁に切り替わることを防ぎます。
- **ズームの往復を抑止**：一度安全枠のために広げたカメラ半径を保持し、実際に画面内へ収まることを確認してから、最大1.25m/秒で縮小します。強制拡大と通常追従による縮小がフレームごとに衝突する状況を防ぎます。

## 維持する仕様
- 通常RUN・遠距離BOOSTでのカメラ角度と画面端補正
- 近距離STEP固有のカメラ角度制限
- ターゲットと自機の画面内フレーミング
- BOOSTの移動方向・加減速・消費EN
- SLIDE/BOOSTのモーション補間と足IK、スラスター

## 検証
GitHub Actionsによる静的検証・数値テストを実施します。Android実機でのカクつき改善は未確認です。
