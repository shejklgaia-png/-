# SERA v467 — 2秒間の青い球体チャージと追尾イーズイン

## 充填完了から発射まで
- **発射の2秒前（10秒周期内の8.0秒）**に、砲台側面の3本の充填バーが満点灯します。未充填の間は砲台の基本姿勢を維持します。
- 満充填と同時に**銃口の青白い球体を表示**し、プレイヤーへの追尾を開始します。**追尾速度の立ち上がりは2秒**のsmoothstep（0→最大）で、追尾開始時のカクつきを防止します。
- 球体は**2秒間表示**します。最初の0.2秒で自然に膨らみ、中間は保持、最後の0.2秒で縮小します。従来の発射前の暗転0.2秒は廃止し、球体が消えるのと同じタイミングでレーザーが発射されます。
- 発射前の最大追尾速度は水平900°/秒・上下720°/秒、24Hz指数フィルタですが、開始後2秒の加速率に従います。**発射瞬間**は従来どおり現在のプレイヤー位置へ照準を正確に合わせます。

## レーザー照射中
- 発射後の追尾のみ水平24°/秒・上下18°/秒に落とし、ブースト横移動で回避できます。
- 10秒周期、2秒照射、終了後0.4秒保持＋0.8秒で基本姿勢へ復帰は不変。BodyのPitch・Rollを引き継がない2軸砲台、18メッシュ全身フレーミング、原本14ボーン、脚攻撃／頭追尾は保持します。

## 検査
- `tools/bittaran_railgun_runtime_check.gd`で球体の2秒間常時表示、開始・中間・終了のスケール変化、8秒～10秒の追尾smoothstep、正確なレーザー開始境界、ブースト移動中の発射時完全捕捉、発射後の追尾上限を検査します。
- 既存の `tools/bittaran_full_frame_level_gun_runtime_check.gd` などの回帰検査も全件維持します。
