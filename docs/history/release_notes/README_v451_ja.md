# SERA v451 — ビットタラン：キーフレーム同期の攻撃判定と位置別の攻撃選択

## 攻撃の当たり判定

**弾き**は、脚の伸長開始キー（原本0.25秒）から0.1秒後に判定が始まります。**なぎ払い**は足が着地して復路に入り始める原本キーフレームから0.1秒後に判定開始し、実メッシュが接地している場合に限り有効です。

| 使用する脚 | 判定開始（原本時間） | 判定終了（原本時間） |
|---|---:|---:|
| 前足なぎ払い（左／右） | 2.14167秒 | 2.50秒 |
| 後足なぎ払い（左／右） | 0.975秒 | 1.25秒 |
| 弾き（左／右） | 0.35秒 | 0.75秒 |

この値は**Blockbench内のクリップ時間**です。実際のゲームでは、原本再生前に0.32秒の導入遷移があるため、攻撃開始からの経過時間とは異なります。キーフレーム内容・再生倍率は変更していません。

実際にプレイヤーへダメージを与えるのは、既存どおり下肢・足先の描画メッシュとプレイヤーカプセルが接触した時だけです。なぎ払いはそのうえで足先の地面接地も必要です。判定開始時刻だけで自動命中したり、胴体・上肢に広い仮想判定を足すことはありません。踏みつけは従来どおり足先の着地時に1回発動します。

## プレイヤーの位置に応じた技選択

| 攻撃 | ボスからの水平距離 | ボス正面からの水平角度 |
|---|---:|---|
| 踏みつけ | 0〜2.85m | 全方位、最も近い脚 |
| 弾き | 2.65〜5.15m | 正面±38°、前脚のみ |
| なぎ払い | 2.70〜7.10m | 正面・側面は±115°、背面寄りは後脚で±165°まで |
| 追尾・旋回 | 射程外／真後ろ15° | 無理な攻撃は行わない |

至近距離は踏みつけが優先、正面の中距離では弾きが優先します。それ以外の側面・遠距離・背面寄りをなぎ払いが担当します。使用する脚は実際の足先とプレイヤーの距離を優先し、前後の位置も考慮して選択します。

これに合わせて、追尾AIの停止距離を**5.85m**、再追尾開始距離を**6.40m**に設定しました。従来の7.8m停止では、攻撃最大射程7.1mの外に留まる不具合が起きるためです。

## 維持する仕様

- 同じ攻撃種別を連続させません。
- 次の攻撃まで最低3歩歩きます。
- 攻撃後は2対角脚の足戻し・接地を完了してから再び攻撃します。
- 原本モーションの振りかぶり・伸長・足戻しの速度や姿勢を変更しません。

## Godot回帰検証

`tools/bittaran_keyframe_hit_sector_runtime_check.gd`で、前後左右のなぎ払いと左右の弾き6種について原本キーの時刻を照合します。実戦シーンで当たり判定開始前にメッシュへ接触してもヒットが消費されず、開始後に接触すればヒットが成立すること、なぎ払いの実メッシュが地面へ接地していることを確認します。加えて位置・方向と脚選択、実際の複数回連続戦闘を既存CIで検証します。

**Android実機での目視・タッチ操作・FPS・プレイフィールはまだ未確認**です。
