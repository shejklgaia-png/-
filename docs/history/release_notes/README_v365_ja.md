# SERA v365 — 起き上がり開始と同時に旋回（速度補間なし）

## 旋回の変更
- ビットタランの旋回は**胴体が起き上がる最初のフレーム**で開始します。
- それ以前のダウン予備動作・倒れた状態では旋回しません。
- 起き上がり開始時点から、最大**34°/秒の通常旋回速度**で回転します。起き上がり率による速度の補間や加速演出は行いません。
- AI更新より後に脚IKが更新される順序を考慮し、同じフレームで始まるよう次の物理フレームの復帰開始を予測します。

## 維持する仕様
- 起き上がり中は`Idle`モーションを維持。前進移動と歩行・接近の`Turn`/`Approach`クリップを禁止します。
- 起き上がった後0.24秒の姿勢安定時間も、胴体の通常速度旋回だけを許可します。
- **頭部追従は復帰率70%から**開始し、低速48°/秒と腕への干渉防止を維持します。
- ダウンは通常2.5秒／4脚破壊時6秒。脚のIKと頭部・脚の接触も変更しません。

## 検証
`tools/v365_bittaran_immediate_standup_yaw_runtime_check.gd`で、1脚・4脚ダウン時の復帰直前のYaw停止、復帰開始と同じフレームの34°/秒旋回、以後の補間なし、接近移動・歩行アニメーションの禁止をGodot上で確認します。v362〜v364の自動検査は新しい旋回開始時刻に合わせます。
