# SERA v438 — ビットタランなぎ払い全体0.6倍速・起動直後にビットタラン戦

## 変更点

1. **なぎ払いの原本モーション全体を0.60倍速に変更（左右共通）**。v437で作成したHermite速度曲線と往路末尾の0.2倍速スローを保ち、それらを含む攻撃クリップ全体に0.60倍の時間倍率を掛けています。キーフレームは変更していません。
2. **起動直後にビットタラン戦を開始**。`project.godot` の `run/main_scene` を `res://scenes/launch_menu.tscn` から `res://scenes/bittaran_battle.tscn` に変更しました。起動時にはメニューを表示せず、直接ビットタラン戦のシーンへ入ります。メニューのファイルは削除していません。

## なぎ払いの新しい時間配分

| 起動からではなく攻撃開始からの経過時間 | 段階 | 原本再生 |
|---|---|---|
| 0.00〜0.32秒 | 基本姿勢から攻撃クリップの0秒へ移行 | 従来通り0.32秒 |
| 0.32〜約1.953秒 | なぎ払い往路前半 | v437のHermite曲線を0.60倍速で再生 |
| 約1.953〜3.12秒 | 往路末尾 | v437の0.2倍速スロー×0.60＝**実効0.12倍速** |
| **3.12秒** | **往路終了・折り返し** | 原本0.50秒 |
| 3.12〜約4.787秒 | 復路 | **0.60倍速**で原本0.50〜1.50秒 |
| 約4.787〜約6.187秒 | 通常姿勢へ戻る | 従来通り1.40秒 |

全体所要時間は約6.19秒（次の攻撃までのクールダウン1.35秒は別途）。前回指定の「往路2秒」も、今回は**なぎ払い全体を0.6倍速にする新しい指定を優先したため、往路3.12秒へ変更**となります。前置姿勢補間0.32秒と攻撃後の復帰1.40秒はそのままです。
