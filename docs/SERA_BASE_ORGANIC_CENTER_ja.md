# BASE 中央の自然な余白・施設のまばらな配置（2026-11-21）

## 採用した視覚方針
中央を**広く空け切った正方形広場**として設計しません。NEXUSは画面上寄り、LABOは下寄りの中央に置き、6施設を左右に**少しずつ前後にずらした配置**にします。中央にはなんとなく通り道の余白があり、その周囲に少数の資材・スクラップが散る密度にします。

- 施設の**独立した専用鋼板1枚**を全8か所で維持し、床の区画は既存の `sera_base_deck_layout.gd` に再計算させます。施設サイズやモデル造形、カメラ、Yaw、タグ、描画MultiMeshは変更しません。
- 左右の同じ高さの列を避けるため、3段の施設中心Yの差は約1〜4%程度の画面幅でずらします。大幅な前後ズレや上下対称グリッドは禁止。
- CRATEの中央作業路を巡る九つの経路点は維持。移設後のLABOを横切らないように実物の歩行判定で検証します。SERAとジョイスティックは現在の仕様通り拠点画面には表示しません。
- **16基の既存スクラップ山**を維持し、LABOへ重なる2基だけ `(-1.6, 0.6)` と `(3.0, -0.8)` へ移設。中央の点 `(0,-2.2)` は塞がず、資材は周縁に分散します。追加ドローコールはありません。
- 床の `CautionStripes` は長大な輪郭線ではなく、不連続で微妙にズレた短線に再構成。中心の小さな床マークも実際の余白へ移設。大きな破線四角形や広場枠は作りません。
