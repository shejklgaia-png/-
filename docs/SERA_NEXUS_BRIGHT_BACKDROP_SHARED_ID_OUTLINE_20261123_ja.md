# NEXUS 背景統一と全身輪郭の可視ID方式（2026-11-23）

## 目的
シェーダーの法線・表裏・深度書込み設定が正しくても、NEXUS の背景・カメラ・Viewport・重ね順が原因で輪郭が不可視となる状況を防ぎます。背景を明るいブルーグレーへ統一し、NEXUS 建築と全身 SERA の輪郭を既存の同一深度IDパスへ集約します。

## 背景・画面設定（先に整備）
- NEXUS の WorldEnvironment 背景、CUSTOMIZE 画面固定バックドロップ、単体プレビューの環境色、実際に画面を覆う単体プレビューのグリッド生成画像、全画面単体プレビュー背面を **#AFC4D1** に統一します。
- CUSTOMIZE のグリッド色は **#7894A3**、強度は **0.32**、ベース不透明度は **1.0** とします。グリッドは本体と輪郭を視認できる程度に抑えます。
- 単体プレビューの背景テクスチャは既存のキャッシュを維持し、アイコン・LAB・STORAGE 用の通常背景には手を加えません。
- 現行の NEXUS カメラ（通常は透視投影、CUSTOMIZE の停止時は正投影）、アスペクト拡張設定、HUD CanvasLayer 2 を保持します。

## 輪郭方式の比較と採用
| 方式 | 長所 | 今回の判断 |
| --- | --- | --- |
| 法線膨張・反転ハル | ID用の追加Viewport不要、モデルと同フレームで追従 | 実際の表裏・法線・投影角度で欠落や面の黒塗りを生じたため通常描画から除外 |
| 既存の可視RGBメッシュID | 深度テストで手前の面を選び、画面画素で線幅指定。アイリス単体と考え方を共有 | **NEXUS通常描画に採用** |
| 旧GPUエッジ・ステンシル | 個別の凸角診断に便利 | 通常描画しない診断機能として維持 |

NEXUS の既存 `SeraIDOutlineLayer/SeraIDOutlineControl` が生成する **一つの共有 ID SubViewport** を建築と全身 SERA で使用します。セラだけの新しい SubViewport は増設しません。SERA 各メッシュには `sera_nexus_id_contact_only` で RGB 接合IDを付与し、建築の赤チャンネルIDと区別します。双方を同一ID深度バッファへ描画するため、建築輪郭がセラを透過して上書きされる問題を抑えます。

### 表示値
- SERA外周：**内側1px＋外側2px＝合計3px**
- 分離メッシュの可視境界：**3px**
- NEXUS建築：既存 **2px** を維持
- SERA/建築IDインク色：既存 **#17212F**
- エフェクトはID対象から除外し、原本SERAメッシュと素材は改変しません。
- キャラクター輪郭OFFでもセラを **ID=0の深度遮蔽物** として残し、建築線がセラ越しに見えないようにします。

## 描画・操作・負荷の注意
- 共有 ID は実際の表示Viewportの画素数に合わせます。通常時の輪郭用ハル複製が不要になる一方、装備メッシュのID描画は必要であり、性能向上を実測済みとみなさないでください。
- 旧深度ハルを診断モードでのみ生成し、通常モードでは有効化しません。診断パネルは本番IDコピー数・ID解像度・描画要求数・マテリアル接続状態を優先表示します。
- CUSTOMIZE 回転中は表示されない2D選択ポリゴンを毎ドラッグでCPU再計算しません。戻るとき・装備更新時は元の更新処理を維持します。
- NEXUS 可視IDは現行の CanvasLayer 合成です。3Dエフェクトとの重ね順は別途実機の画面から判断する必要があります。
