# SERA 全画面共通材質シェーダー（2026-11-22）

## 指定パラメータ（SERA_IRIS_MATERIAL_SHADING_V1）
| 材質 | 段階 | 陰影しきい値 |
|---|---:|---:|
| 装甲（armor） | 8 | 0.65 |
| 暗色機構（dark_mechanism） | 2 | 0.70 |
| レンズ（lens） | 3 | 0.10 |
| 発光（emission） | 0 | 0.00 |
`lens_lit=false`。アイリス単体編集画面の未保存初期値もこの値に変更。既存の端末側ユーザー保存値／5枠プリセットは上書きしない。

## 適用した3D描画経路
- NEXUS：施設・装備を含む画面、全身SERAおよび単体パーツプレビュー。
- 戦闘：SeraRigに適用して通常の戦闘・ボス戦のプレイヤー、交換候補装備も共通化。移動モーション・装備選択・ヒット判定は変更しない。
- BITTARAN：著者のポリゴン面単位で法線を統一したボスの装甲・内部機構に共通シェーダーを使用。背部レールガン・腹部砲塔の不透明な金属部も適用。被弾・部位破壊・死亡時の色と発光は材質パラメータで保持。
- BASE：屋外の施設・NEXUS外観・資源設備・クレート・装飾の不透明なメッシュ／MultiMesh。拠点レイアウト再生成後の新モデルにも再適用。
- LAB：製作／精製・分解／倉庫の個別3Dステージと稼働するクレート・設備。
- 装備プレビュー：NEXUS、LAB確認画面、倉庫、共通のEquipmentPreview／SeraRigを経由する回転3D表示。
- 従来の保存済みPNG装備アイコン・ドット絵素材・2D HUDは画像アセットのため変更しない。新シェーダーを反映したサムネイルが必要なら画像自体の再撮影が必要。

## 材質暫定分類
- アイリス16×16テクスチャ：ライトグレー＝装甲、2種類のダークグレー＝暗色機構、水色＝レンズ。水色の発光切り替えはアイリス個別編集UIで維持。
- それ以外：部品名・親階層・位置（関節、軸、ケーブル、サーボ、首、膝、駆動系）から暗色機構を暫定判定。通常の金属外装は装甲に分類。青系の非発光部分はレンズ候補。
- 元のUV、色・テクスチャ、頂点色、UV拡縮・オフセットを保持。静的な同設定はマテリアルを共有する。
- オリジナルの発光材質・透明VFX（レーザー／スモーク／火花など）は操作・点灯アニメーションを守るため改変せず、陰影なしで保持する。

## 輪郭・法線と共存
- SERA・BITTARANには既存の `SeraViewEdges`（3pxシルエット）、BASE施設は既存の外周／角線、NEXUS建物の2pxラインを引き続き使用。
- LABの立体設備・クレートおよび移動するBASEクレート、Bittaran腹部砲塔には既存輪郭処理を共用して追加。発光・射撃物・煙などのエフェクトは輪郭対象外。
- SERA／BITTARANのBlockbench原本ポリゴンの複数三角形は面ごとに共通法線として描く。原本のUV・位置・ポリゴンの接続・アニメーションは不変。変形面の法線集約が打ち消されても三角形を削除しない。
- 存在するStandardMaterial3Dの `next_pass` はShaderMaterialへ引き継ぎ、建築の縁取りを消さない。ShaderMaterial側の色と発光値でボスの破壊・被弾演出を継続する。
- すべての編集はコードと表示材質のみで、元の.bbmodel・モデルテクスチャ・セーブデータ・ゲームプレイ数値は変更しない。

## 設定UI
アイリス単体全画面プレビューにある材質名タップによる一回点灯、個別の段階／しきい値、コピー／貼り付け、5枠セーブロードは従来通り。全場面はここで指定された4材質値を固定して適用するが、現時点でほかのモデルへ自動的に個別編集UIを展開するものではない。
