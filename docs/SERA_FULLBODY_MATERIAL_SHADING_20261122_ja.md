# SERA 全画面共通材質シェーダー（2026-11-22）

## 指定パラメータ（SERA_IRIS_MATERIAL_SHADING_V1）
| 材質 | 段階 | 陰影しきい値 |
|---|---:|---:|
| 装甲（armor） | 8 | 0.65 |
| 暗色機構（dark_mechanism） | 2 | 0.70 |
| レンズ（lens） | 3 | 0.10 |
| 発光（emission） | 0 | 0.00 |
`lens_lit=false`。アイリス単体編集画面の未保存初期値もこの値に変更。既存の端末側ユーザー保存値／5枠プリセットは上書きしない。

## 適用した3D描画経路
- NEXUS：施設・装備を含む画面、全身SERAおよび単体パーツプレビュー。
- 戦闘：SeraRigに適用して通常の戦闘・ボス戦のプレイヤー、交換候補装備も共通化。移動モーション・装備選択・ヒット判定は変更しない。
- BITTARAN：著者のポリゴン面単位で法線を統一したボスの装甲・内部機構に共通シェーダーを使用。背部レールガン・腹部砲塔の不透明な金属部も適用。被弾・部位破壊・死亡時の色と発光は材質パラメータで保持。
- BASE：屋外の施設・NEXUS外観・資源設備・クレート・装飾の不透明なメッシュ／MultiMesh。拠点レイアウト再生成後の新モデルにも再適用。
- LAB：製作／精製・分解／倉庫の個別3Dステージと稼働するクレート・設備。
- 装備プレビュー：NEXUS、LAB確認画面、倉庫、共通のEquipmentPreview／SeraRigを経由する回転3D表示。
- 従来の保存済みPNG装備アイコン・ドット絵素材・2D HUDは画像アセットのため変更しない。新シェーダーを反映したサムネイルが必要なら画像自体の再撮影が必要。

## 材質暫定分類
- アイリス16×16テクスチャ：ライトグレー＝装甲、2種類のダークグレー＝暗色機構、水色＝レンズ。水色の発光切り替えはアイリス個別編集UIで維持。
- **単色パーツは全て装甲**：材質にテクスチャがない、または小さなテクスチャの全画素が同色なら、元の色・パーツ名・配置を問わず `armor` 固定。暗色でも暗色機構にはせず、青色でもレンズにはしない。頂点色で描き分けるメッシュや大きなアトラスは単色と断定しない。
- 複数色パーツのみ暫定分類：アイリス16×16は従来のピクセル色識別を維持。ほかは明示的なレンズ名称（eye/lens/optics等）、関節・機構名称/階層を参照。単純に「黒っぽい」「青っぽい」だけでは暗色機構・レンズへ変更しない。
- 例：HEAD Cは元の色しか指定されていないため、借用していた96×32テクスチャを外して装甲単色で描画。ビットタランの単色装甲・クレートの単色装飾も原色を保ちながら装甲8段/0.65を適用。
- 元のUV、色・テクスチャ、頂点色、UV拡縮・オフセットを保持。静的な同設定はマテリアルを共有する。96×32のSERAパレットに描き込まれた上/側面の明暗へ二重に強い影が乗らないよう、追加した陰影差を半分に抑える（しきい値・段階数は変更しない）。
- オリジナルの発光材質・透明VFX（レーザー／スモーク／火花など）は操作・点灯アニメーションを守るため改変せず、陰影なしで保持する。

## 輪郭・法線と共存
- SERA・BITTARANには既存の `SeraViewEdges`（3pxシルエット）、BASE施設は既存の外周／角線、NEXUS建物の2pxラインを引き続き使用。
- LABの立体設備・クレートおよび移動するBASEクレート、Bittaran腹部砲塔には既存輪郭処理を共用して追加。発光・射撃物・煙などのエフェクトは輪郭対象外。
- SERA／BITTARANのBlockbench原本ポリゴンの複数三角形は面ごとに共通法線として描く。原本のUV・位置・ポリゴンの接続・アニメーションは不変。変形面の法線集約が打ち消されても三角形を削除しない。
- 陰影はカメラ向きで変わらないよう、フラグメントのビュー空間法線を `INV_VIEW_MATRIX` でワールド空間へ戻してから、固定のワールド方向光と内積を取る。これは実ライトの位置追従ではなく、全場面で一致する擬似ライト方向として使用する。アイリス単体専用シェーダーも同じ計算へ修正。
- 輪郭の3pxは **描画先Viewportのピクセル** であり、テクスチャの3画素やAndroid端末の物理画面3画素を無条件に指すものではない。アイリス単体のID輪郭は表示領域に合う解像度で3pxを直接描画するため、変更しない。
- **2026-11-22追加修正：** 3D装備・SERAプレイヤー・ボス・クレート等の `SeraViewEdges` 輪郭を描画Viewportの3px固定へ戻す。単体アイリスのID輪郭は引き続き3px（別方式）で、輪郭色 `#17212f` は不変。720×1280で前回の5.625pxではなく3pxになる。
- 急角度の面が帯状に黒くなる問題の抑止：閉じたメッシュ用の `sera_view_edges_fast.gdshader` も、元の表面深度と接するピクセルだけを残すよう深度バッファの中心＋隣接サンプルで判定する。元の `cull_back` は保持し、裏面を無条件にインクで描かない。開いたメッシュ用 `sera_view_edges.gdshader` も同じ3px基準の輪郭を描画する。
- この修正は既存 `SeraViewEdges` だけの対象で、NEXUS施設／BASE施設固有の2px・4px線、アイリスID輪郭の専用処理、3Dモデル・材質の陰影数値には変更なし。高速版にも深度取得が入るため、従来より輪郭描画のGPU負荷が高くなる可能性がある。CI・実機の性能確認は実施しない。

- `project.godot` のアスペクト設定を `expand` にして9:16固定による上下のレターボックスを解消する（端末システムバーはアプリ設定外）。縦長画面では追加の表示領域が増えるため、画面内のHUD配置は実機で別途確認が必要。
- 存在するStandardMaterial3Dの `next_pass` はShaderMaterialへ引き継ぎ、建築の縁取りを消さない。ShaderMaterial側の色と発光値でボスの破壊・被弾演出を継続する。
- すべての編集はコードと表示材質のみで、元の.bbmodel・モデルテクスチャ・セーブデータ・ゲームプレイ数値は変更しない。

## 設定UI
アイリス単体全画面プレビューにある材質名タップによる一回点灯、個別の段階／しきい値、コピー／貼り付け、5枠セーブロードは従来通り。全場面はここで指定された4材質値を固定して適用するが、現時点でほかのモデルへ自動的に個別編集UIを展開するものではない。
