# BASE 小物配置プレビュー・テキスト引継ぎ（仮配置）

## 操作
- 拠点画面右上の「小物を再配置」を押すたびに、8施設の床パネル上の小物と、独立するスクラップ山16か所が再配置されます。施設建物の位置、入口向き、床パネル、ゲームUI、セーブデータは変化しません。
- 施設入口と建物本体の保護領域、小物相互の占有領域、各施設の専用床パネル端、クレートの巡回通路、スクラップの重複を避けます。条件を満たさない候補は採用しません。
- 好みの配置で「配置データコピー」を押すと、完成時点の正確な配置全体をAndroidのクリップボードにJSON形式でコピーします。ChatGPTにそのまま貼り付けて「この配置を確定して」と指示すると、このデータをモデル配置の新しい正本として実装できます。
- プレビューは**その場限り**です。拠点に戻ると従来の正本配置に戻ります。確定前に現行の見た目を保存したい場合も、データコピーを行ってください。ゲームのセーブデータは変更しません。

## JSON契約
- `format = SERA_BASE_PROP_LAYOUT_V1`、`version = 1`、`status = PREVIEW_NOT_COMMITTED`
- `sites[]` は NEXUS / LABO / SCRAP_COLLECTOR / SMELTER / RECYCLER / GENERATOR / STORAGE / BUILD_TERMINAL の8件を含みます。
- `items[]` は全68件で、`index`、`kind`、`x`、`z`（**施設ローカル座標、メートル**）、`yaw_deg`、`scale`、`stack`（板・スクラップは1〜8の主要部材数）、`pattern`（板・スクラップは0〜3の4種類の積み方）、`accent` を保存します。コンテナの積載細部は施設・種類・インデックスからの従来の決定論的規則を使用します。
- `scrap[]` は16件で、`index`、`x`、`z`（**ワールド座標、メートル**）、`yaw_deg`、`scale`、`profile`、`stack`（1〜8）、`pattern`（0〜3）を保存します。
- `seed` と `reroll` は作業履歴の参考値です。確定時は**乱数から再生成せず、コピーされた全座標と倍率**を採用します。
- 採用時は `scripts/sera_base_clutter.gd` の正本位置と `scripts/base_exploration.gd` の16スクラップ位置へ正確に反映し、CIおよび実機で施設の視認性を確認してください。

## 2026-11-21：板・スクラップの1〜8個重ね対応
- 小物の板材・装甲片・ラック材・パイプ束・廃機械部品は、1〜8個の主要部材を持つ生成モデルに変更しました。下層を横に広げ、上層は少数とする4種類の `pattern` を用意しています。
- 独立スクラップ山16か所にも同じ重ね数・パターンを適用します。複数の装甲片、筐体、ベアリング、軸、補強材などを組み合わせ、材質別の一括描画を維持します。
- ランダム再配置時、種類と施設パネル内での安全な座標に加え、`stack=1〜8` と `pattern=0〜3` を抽選します。コピーされたJSONはこの選択結果をすべて含むため、後から完全固定できます。
- コンテナ類の1〜4個積みと、機械・端末など重ねられない装置の挙動は変えていません。
