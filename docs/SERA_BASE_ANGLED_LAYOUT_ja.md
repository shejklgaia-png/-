# SERA BASE：施設・置物の向きの分散（2026-11-21）

## 目的
俯瞰BASEの施設・周辺置物がすべて同じ方向を向く人工的な印象を解消する。ユーザーの添付BASE画像を方向調整の参考とし、現在の3D配置を保持したまま**向きだけ**を自然に散らす。

## 実装箇所
- `scripts/sera_base_architecture.gd` の `BODY_YAW_DEGREES` を8施設の角度正本とする。NEXUS −11°／LABO +14°／精製装置 −18°／分解装置 +17°／資材保管庫 −21°／発電機 +19°／回収機 +10°／建設端末 −14°。
- `Batch._put` で、実ジオメトリの**中心回転**をMultiMeshのTransform3Dへ直接反映する。全施設の形状と小物は同じ既存のマテリアル別MultiMeshバッチに入る。ノード・マテリアル種類・GPU描画パスは増えない。
- `scripts/sera_base_clutter.gd`: 小物は各グループの位置を固定し、単一の支点を中心に9〜21°程度（干渉時は縮小または0°）の安定角を決定。種は施設名/種類/並び順から再現でき、毎フレーム再抽選しない。支え合う2+1の箱や複数段積みはグループ全体を回すため、接触関係を保つ。
- `BaseArchitecture.build_nexus/build_facility` は建物本体を施設ごとに回すが、`BaseClutter.decorate` で原点基準から**小物ごとの支点**に切り替え、終了時に元へ戻す。施設床のFoundationも本体に同期して回し、専用大型鋼板の角度は変えない。
- `base_exploration.gd` の画面端Blockbench置物と独立スクラップ置物群も固定した別々のYawで配置。建物投影のタップAABBは見た目の回転に応じて計算。発電機ローター、局所ライトも設備の向きに合わせる。

## 保持する条件と検査
- 拠点カメラ正投影・FOV0相当、8施設の位置、HUD、クレート歩行ルート、ゲーム経済・セーブ・Lab/倉庫/戦闘は不変更。
- 各施設は従来どおり**1枚だけの専用鋼板**に設置。施設内の小物は支点を変えずに回すため、周囲の搬送動線を維持する。候補角度は他の小物と玄関・設備の立入領域を評価し、重なりが発生する場合は回転量を下げる。
- テストを先行追加: `tools/base_natural_yaw_self_check.py`、`tools/base_natural_yaw_runtime_check.gd` を既存CIへ登録。実建物Yaw、コンテナ群メッシュ姿勢、施設の触れる範囲、回転後小物の1枚鋼板内収まり・非重複を検証。既存床配置・カメラの静的/実行時/画素チェックは保持。
- Android上での角度の自然さ・画面端の見切れ・ラベルの重なりは自動CIと別に確認する。
