# NEXUS全身枠線：PR #807の全消失を回復し、小さな輪郭欠けを補助（2026-11-23）

## 実機の状態

- PR #806の実機画像では、胴体・腕・武器の黒い輪郭が表示された一方、頭部・肩・脚先に線の欠けや部分的な内部線があった。
- PR #807で深度テクスチャ（`hint_depth_texture`）・`INV_PROJECTION_MATRIX`・深度差による補助判定を追加した直後、ユーザーの実機画像では黒い輪郭がほぼ全消失した。
- 原因がシェーダーコンパイル、GL Compatibilityでの深度復元、描画パスの扱い、深度比較のどれにあるかは実機ログなしで確定できない。安全策として、その新規の深度テクスチャ処理は通常描画から完全に外す。

## 今回の修正

`shaders/sera_nexus_stencil_edge_outline.gdshader` のみ修正。

1. **PR #806のGPU標準深度テスト＋2面表裏判定へ復帰**。透明パス内での追加深度テクスチャ読み出しは使用しない。`depth_test_disabled` は設定しない。
2. 通常の隣接面前後判定はそのまま残す。両面の向きがわずかに近い場合に限り、片面がほぼ横向き（カメラとの角度差のdot絶対値が0.05未満）かつもう片面が十分前を向いている（dotが0.10超）場合のみ、欠けたエッジの追加候補にする。これ以外の内部線は追加しない。
3. 角の線の端部延長を`min(exterior_px * 0.45, 1.35)`から`min(exterior_px * 0.55, 1.65)`へ少し広げ、端の微小な切れ目を減らす。横幅は3px設定を維持。
4. 本体の黒 `#0B1118`、装備の自動登録、全身同一フレーム追従、GPUエッジリボン、19種類の診断、単体装備プレビューなどは変更しない。

## 実機でお願いしたい確認

- **確認A：通常表示（必須）**：頭部・肩・腕・胴体・脚・武器に黒い線が表示されるか。PR #806の状態へ戻ったか。
- **確認B：カメラ角度（必須）**：正面、左右斜め、背面で、輪郭が消えたり奥側の不要な線が出たりしないか。左右どちらかの肩・脚だけ欠けないか。
- **確認C：回転時（必須）**：ドラッグ回転で1秒程度視点を動かし、線の遅延・点滅・線幅急変がないか。
- **確認D：条件付き**：通常表示で再び線が消えた場合のみ、同じ角度の「外周候補」（青緑）と「深度なし全エッジ」（青緑）の2枚、および可能ならGodotのシェーダーエラー文を確認する。

写真は確認Aの正面1枚＋確認Bの斜め1枚を基本とする。回転追従は「遅延あり／なし」を文章で教えていただくだけでもよい。新たなCIや実行確認を開発側で行わない。

## 制約

深度テクスチャ補完は撤去したため、PR #806で残っていた頭部・肩・脚先の外周欠けが完全に埋まる保証はない。今回の小さな許容幅で補助できるのは、隣接面がカメラに対してほぼ横向きの境界だけ。最終的な品質判定はAndroid実機画像で行う。

ユーザーの開発ルールに従い、CI項目の確認・修正・適用およびテスト実行は行わない。
