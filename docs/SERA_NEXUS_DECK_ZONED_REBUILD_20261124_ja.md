# NEXUS床の機械的再構成（2026-11-24）

## 目的
装甲板と灯具が同じ配置規則で繰り返され、奥行き方向が単調に見える問題を改善する。単純な小物の増殖ではなく、構造スケール・切り欠き・大きな暗明差を使い、Android縦画面で読み取りやすい工業床を構築する。

## 床のゾーニング
- **遠景搬送床（Z < -11m）**：大型の暗いグラファイト装甲と広いパネルピッチ。ゲート方向のスケール感を表現。
- **整備展示域（-11〜-2.6m）**：SERA展示台周囲に48分割の曲面式機械レールを配置。前面8セグメント分を開口にして導線を確保。レールは曲線のテクスチャではなく、上下段差と内外側壁を持つ共有ArrayMesh。
- **端末前庭（-2.6〜7.25m）**：中央の比較的明るい金属と暗い周辺設備で視線誘導。排水設備と実装済み端末の選択領域は変更しない。
- **前景重量床（7.25m以遠）**：左右の装甲板の角を大きく斜めに切り、分割寸法を広くする。中央パネルを二分して実際に開口するサービス溝を追加。

## 立体機構
- 床専用の非対称シアーカット装甲メッシュ：多角形上面、面取り斜面、深い側壁。
- 分割整備レール：2分割弧×48の共有メッシュ。立体リム、内側壁、上面金属仕上げ。
- 前景の埋設配線溝：パネルを横に分離し、下面暗色、縁金具、間隔を空けた梁と小型表示窓を配置。
- 左右の開放ルーバー：傾斜した7枚のフィンと両端の鋳造枠を単一ArrayMesh化。
- 横断整備ポケット：2箇所だけに低い収まりを設け、全域を横線で区切る反復を回避。

## 描画・互換
- `scripts/sera_nexus_floor_panels.gd` のみで床メッシュを再構成。NEXUSの原本モデル、設定・操作、SERAリグ、モニター、共有シルエット描画は変更しない。
- 既存の床全体の範囲 `DECK_BACK..DECK_FRONT`、既存のメンテナンス排水設備・警告溝・床基礎を保持。
- 追加した複合メッシュは再利用し、材質・メッシュごとにMultiMeshバッチ化。発光窓は既存の不透明材質のemissionのみ。新規ライト、透明描画、パーティクル、Viewport、シェーダーは追加しない。
- 全床部品を `FX_NO_OUTLINE` および `sera_outline_occluder_only` として保持し、施設・キャラクターの描画ルールに干渉させない。
- **CI項目の調査・変更、テスト実行、画像生成なし**。実機での見え方、重なり、FPSは未確認。
