- **詳細正本:** `docs/SERA_WAREHOUSE_UI_AND_CRAFT_AFFIXES_ja.md`。実装前に競合する旧CIの期待値を更新し、テストを削除・無条件スキップしない。
- 倉庫は装備カテゴリ別ハンガー各999個。1個体1枚、装備2列縦スクロール、素材は同系統3ランク横3枚。暗い欠け角枠・正方形アイコン・白いデジタル書体・空枠を維持し、「所持×N」の装備集約表示は廃止。
- 製作成功時に個体UIDへ追加性能5個を抽選・永続保存。NEXUSの追加効果モジュールと別管理し、ロード再抽選・旧装備破壊は禁止。

## HTMLツールの配布方法（必須・2026-11-21）
**`docs/SERA_HTML_ARTIFACT_DELIVERY_POLICY_ja.md` を参照。** GitHub Rawを「HTMLを開く直リンク」にしない。検証済みHTTPSホストがあれば直接起動リンク、未公開なら完成HTMLそのものを添付する。Godot Web版はWASM/PCK付きの同一オリジン配信が必須。ChatGPT Page埋め込みはWebGL等が未検証ならその旨を明示する。

## 制作用モデル識別子とゲーム内装備の区別（2026-11-21・必須）
- **「A/B/C/D/Kセット」という装備システムは存在しない。** A/B/C/D/Kは各部位をモデリング・検証する際の識別子にすぎない。頭部Aと脚部Aを選ぶことは「Aセットを装備する」ことではなく、それぞれ別の部品を選んだだけである。
- **ゲーム内の単位は個別装備品（設計図ID、装備品UID、対象スロット、固有の性能、追加効果、3Dモデル参照）**。製作・所持・換装・セーブは部位/個体ごとに行い、同文字の部品を一括適用する「セット装備」「セットボーナス」「セット専用ステータス」を導入しない。
- 既存コードの`rig_set`/`set_id`/英字キーは旧来の**制作モデル参照キー**で、ゲームプレイ上のセット属性ではない。セーブ・既存テストとの互換性のため内部キーを維持してよいが、ユーザー向けには装備名を優先する。
- 装備設定フォームに独立した「装備セット」入力欄を設けない。モデル参照はFULL BODYの部位ごとの選択から自動取得する。既存出力の`rig_set`は互換用に残してもよいが、新しいセット概念を示すものとして扱わない。

## 全身モデルプレビューの立ち姿勢（2026-11-21）
- FULL BODYはユーザー制作の`NEXUS_pose`を正本とする。Godot実`SeraRig`のアニメーショントラックをそのまま0秒サンプリングする。戦闘用`Wait_motion`を全身の立ちポーズに流用しない。
- ICON/ステータスの単体表示は元のアイコン用姿勢に戻し、BODYへの復帰時には再びNEXUSポーズを適用。装備品ごとの独立性・モデル制作識別子・既存セーブ/UIDは維持。

## 新規チャットへの装備設定引継ぎと共通アイコン背景（2026-11-21）
- **新規チャットでも実装可能な正本:** `docs/SERA_EQUIPMENT_CROSS_CHAT_HANDOFF_ja.md`。フォームのEXPORTにはGitHub原本・SHA・製作設計図ID・UID実装要件・性能・素材・特殊効果・原本カメラ設定と実装先を含める。エージェントは受け取った`SERA_EQUIPMENT_INTAKE_V1`をGitHub mainへ照合し、過去チャットやモデル手動再アップロードを必須としない。
- **共通アイコン背景:** `scripts/sera_icon_background.gd`の#111e28単色＋#55798Aの8分割グリッド（重み36%）。装備アイコン・Godot装備単体プレビュー・LABO製作確認に共通使用。完成PNG原本は透明でもよく、ゲームの表示時に2D合成する。材料アイコンには勝手に適用しない。各装備のアイコンは一度だけ2D合成しキャッシュして倉庫999件で3Dを生成しない。
- **製作確認:** `scripts/base_facility_system.gd`の`LaboConfirmRotatablePart`に実際のSeraRig装備単体を表示し、ドラッグ回転・2本指の平行移動とピンチ。確認時のみ1個生成し閉じたら描画停止。装備セット概念は作らない。
- **安定ジェスチャー:** 1本指は回転、2本指は重心と距離の差分による移動/ズーム。指を足す/外す瞬間は再アンカーしジャンプさせない。
- **分布図:** `ANALYSIS`の横軸Xは右ほど高く、縦軸Yは上ほど高く表示し、選択欄と正方形グラフ内の双方に名称と方向を明示する。
