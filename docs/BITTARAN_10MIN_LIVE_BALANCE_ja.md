# SERA v535 — ビットタラン戦闘バランス（実装値・2026-11-22）

## 目的と検証境界
- **全身A装備、A標準3段コンボ、GRID補正なし、部位破壊主体で順調に戦うと約10分で討伐。**
- 10分固定タイマーやHPの時間自動減少は導入しない。実際の攻撃成功間隔により所要時間は変化する。
- 合格モデルは「8秒に1回の3段コンボ成功」「4脚を各12コンボで1回だけ破壊」「ダウン中の頭部攻撃は順に1/1/1/2コンボ」「その後は胴体を攻撃」。
- これは**プレイヤーの実機操作を再現した測定値ではなく、実際のGodot命中・防御処理を使うシナリオ試験**。実戦の命中率・回避成功率・位置取り・KO率は別途Android実機で検証する。

## 実装と計算式
- 数値の正本：`scripts/bittaran_balance.gd`。ボス本体と部位制御はこの定数を使用。
- 共通HP：`main.gd`の命中処理 → 予測シールド軽減 → `target_parts.gd`の部位防御・整数丸め → `bittaran_parts.gd`で対象部位に応じ0.75／2.5／1.0を乗算して整数丸め。**部位破壊量にはHP倍率を掛けない**。
- A標準の3段攻撃は基礎12／12／26、破壊量14／14／32。部位破壊防御は前脚0%、後脚12%、頭部10%を維持。
- 破壊済みの脚は耐久0のまま攻撃可能で、**同一脚を再破壊して新たなダウンを起こすことはない**。
- 頭部はダウン中のみロック・攻撃可能。頭部破壊後もダウン中は同じ2.5倍の弱点として残る。
- 4脚すべてを破壊すると、起き上がった後も胴体（BODY）をAUTO/MANUALでロックし、通常の本体HPダメージを与えられる。**第6の部位破壊ゲージは作らない**。
- セラ装備部位HPをA/B/C/Dで一律2倍。防御、攻撃、重量階級、EN、ガード性能・回復は変更しない。
- ボス踏みつけ・弾き・なぎ払いは従来の攻撃IDに個別倍率を掛け、既存のガードSHコストとHP被ダメージの比率を一致させる。トレーニング敵の攻撃力に変更はない。

## 約10分モデル
- 3段コンボ成功間隔：平均8秒（実機未測定）。
- 各脚：3段コンボ12回 × 4脚＝48コンボ、合計384秒。単発3段は満SP開始なら脚への本体HPダメージ**26**。
- 通常ダウン中頭部へ1コンボを3回、最終ダウンで2コンボ。頭部1コンボは既に脚を攻撃して削れたSPを引き継ぐ。頭部の計5コンボに計9.7秒を割り当てる。
- 残HPを胴体へ26コンボ（計208秒）与えて撃破。
- **384＋9.7＋208＝601.7秒（10分01.7秒）**。これはプレイの成功間隔を外生的に与えた近似値であり、ゲーム内では固定タイマーを使わない。撃破までの時間を人為的に補正するコードも実装しない。
- カタナK・全B装備・混合装備は速度とコンボ構成が異なるため、この10分の基準値とは別に実戦測定する。Aの標準コンボとダウン硬直を優先する。
