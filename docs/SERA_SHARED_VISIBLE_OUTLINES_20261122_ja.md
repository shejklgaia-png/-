# SERA 全3Dシーン共通の可視ID輪郭（2026-11-22）

## 描画対象

- SERA・Bittaran・NEXUS・LABO等の一般3Dモデル：全身可視外周の内1px＋外3px、別メッシュの可視接合境界3px。
- BASEの8設備：同じ内1px＋外3px／接合境界3pxに加え、80°以上の手前向きポリゴン角（物理リボン）を1px。古い設備用外周リボンは表示しない。
- BASEの小物（Blockbench置物、スクラップ、施設バッチの小部品）：内1px＋外1px、接合境界2px。
- 3D GRID／電力制御盤：内1px＋外3px／可視接合境界3px。UI自体は既存の2Dデザインを維持。
- 不透明な重なりは1回のID用深度描画で解決し、隠れたメッシュの輪郭を透かさない。

## エフェクトと描画順

- VFX系のFX_NO_OUTLINE、煙、炎、レーザー、発光、軌跡、パーティクル、透明なQuadMesh、およびグリッド床一面はID輪郭の対象外。
- 輪郭はCanvasLayer最前面ではなく、3D透明描画の優先度-30のスクリーンクアッドとして合成する。
- BASEの手前角リボンは-29で合成し、エフェクトの標準・正の優先度（0以降）より先に描く。
- 透明エフェクトの実際のブレンドが輪郭の後から行われるため、前面エフェクトが線を覆う。通常の深度テスト付きエフェクトは不透明物体に隠れる。深度テストを無効にした前景エフェクトは従来どおり線より前面となる。
- 不透明な発光パーツは深度マスクに参加する一方、ID色をゼロとして自身には輪郭を出さない。

## 軽量化

- 各3D Viewportにつき共有のID用SubViewport1個を維持。ID画像のCPU readbackは一切しない。
- 12bitメッシュID（R/B）とカテゴリーコード（G）を使う。MultiMeshは同じ元メッシュ資源を共有し、INSTANCE_IDで識別する。BASEの施設／小物の混在はINSTANCE_CUSTOMで区別するため、バッチは分裂させない。
- 可視ID・カメラ・装備・施設の動作更新時だけIDパスを再描画する。施設のMultiMeshアニメーションは既存30Hzサンプル時に更新カウンタを進める。
- 外周の外側サンプリングは投影された対象AABBの合成範囲に限定する。設備・小物・GRID以外の床のID0では塗りを行わない。
- ID用メッシュが4095識別子の範囲を超えるバッチは、一括IDへのフォールバックがあり、同バッチ内接合線を省略し得る。
- 描画優先度による透明エフェクト遮蔽は、深度バッファを持たない半透明レイヤーと深度テスト無し前景エフェクトの表現差を残す。複数透明面の完全な物理前後関係の再構成を保証しない。

## 適用

`scripts/sera_view_edges.gd`が各3Dシーンで共通モードを有効化。従来のIRIS特別な単体パーツビューでは専用ID描画への切替を維持。BASE施設の90°相当の凸角だけは1px物理メッシュ線を加える。

CI項目の確認・更新・CI/動作テストは実施せず、ユーザーの「マージ」に従ってコードをmainへ反映する。実機での見え方・負荷改善は未確認。
