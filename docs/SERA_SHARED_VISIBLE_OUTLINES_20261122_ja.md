# SERA 可視メッシュID輪郭 — 全画面の共通描画規則（2026-11-23）

## 方式
NEXUSで成立した「深度解決済みメッシュID → 画面上のユークリッド距離円盤 → 内側／外側／接合線を独立描画」を、既存の単一ID SubViewportへ展開する。**半透明のグレー境界は付けない**。輪郭はNEXUS・戦闘・プレビューでは #17212F、BASEでは純黒 #000000 の不透明線。別メッシュとの境界はIDの片側だけが所有して二重描画を防ぐ。

NEXUS全身は既存のRGB接合IDをSpatialで透明VFXより先に合成し、それ以外はRGB12+役割ID Spatial合成を使用する。シェーダーの役割と合成順は変えず、可視画素の距離判定法則を同一にする。

## 可視性・軽量化
- 既存のViewportごとにIDパス1つ。HEAD D専用プレビューは二重登録せず、既存の6パーツIDのみ使用。
- 役割6は単体プレビュー。役割7（G=7/8）は不透明な発光面専用の保護ID。役割1〜6は不変。
- 各画素の隣接探索は必要な円形半径に制限。すべての内側／接合線／外側が最大3px。指定幅に満たないサンプルを除外し、輪郭発見後は走査終了。
- 半透明を使用しないためアンチエイリアスの灰色フリンジを発生させない。斜め線はピクセル階段状となりうる。
- スモーク、炎、レーザー、残像、透明面、床面の全面アウトラインを除外。床などはID=0の奥行き遮蔽物として維持。BASEの不透明発光面（建築エミッター・作業灯の発光ガラス）はID=7で奥行きを保持しつつ輪郭を破棄し、施設外周3pxが光源の上に被さる現象を防ぐ。枠線設定OFF時もその不透明ジオメトリは遮蔽物として扱う。
- BASE角線は80°以上の手前角のみの物理リボンを継続。NEXUS室内の旧3D角線設定は変更しない。
- 距離サンプルを表示Viewportの画素寸法で解釈する。Viewport縦横比変更時もカメラ・ID画像・表示を一致させる。

## 背景と描画の安全性
- NEXUS全身／CUSTOMIZEは #AFC4D1、NEXUS単体は同色のグリッド。LAB／倉庫のライブプレビューは従来 #A9BBC7 を維持し、どちらも環境背景とグリッド用テクスチャの基準色が一致している。
- BASEの旧 #070B10 と戦闘の旧 #131B29 は輪郭色 #17212F に近く、空背景で線の判別が難しい。立体モデル・照明を変えず、BASE空背景 #607D8F、戦闘／トレーニング空背景 #70899A に変更。
- 全画面Shaderが透明画素を描画せず discard する既存の防御を維持。ID画像の黒を実際の表示背景として合成しない。
- 画面上の色変化は実機未確認。輪郭の細部、深度境界、タップ操作、GPU負荷の実測済みとは表現しない。

ユーザーの指示に従ってCI項目・CI設定に触れず、CI／Godot／Android／手動テストの実行は行わない。

## 2026-11-23：BASEの発光面保護・単純描画構成
- BASEの施設本体は従来のStandardMaterial3D、実際のSpotLight3Dと1種類の低コストな光テクスチャを維持。発光面だけをUNSHADED+EMISSIONとし、初回フレームで付近のライト数や時間的な照明変化に依存しない強い発光コアを描画する。
- 共有ID SubViewportに**保護役割7**を追加。発光する不透明MultiMeshと実体のある発光ガラスは同じ深度付きIDパスへ収め、役割7の画素を直接描画せず、周囲からの施設外周膨張によって黒く塗られないようにする。床や既存の遮蔽ID0は変更しない。
- 追加のSubViewport、全画面Blur、シーンロード時の恣意的な描画待機フレームは不要。起動時／ロード演出後とも同じ描画パスを継続して使用する。
- 元の施設配置・動く部品・材質色・実ライト・モールス点滅・煙・VFX・輪郭幅（施設内1外4接合1）は変更しない。実機での完全な一致や描画負荷は未確認。
