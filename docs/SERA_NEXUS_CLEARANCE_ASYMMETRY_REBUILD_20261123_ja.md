# NEXUS 室内第三次全面構築（2026-11-23）

## 再構築の理由

ユーザー提供の実機画面では中央ブランド柱と右奥ゲート、トレーニング端末が重なって見え、両手前端末が左右反転した同型設備に見える。2026-11-23の旧造形を残さず、7系統の施設＋新設2系統の端末を原本から作り直した。

## 新配置

- 中央柱は幅1.64m、奥行1.20m、背面Z=-13.3m。既存の幅約3.6mの巨大柱とは異なる小型背景設備。
- ゲート中心を**(5.35,0.02,-17.00)m**に移す（旧(4.00,0.02,-10.48)m）。中央柱からX軸で5.35m離れ、正面開口は展示セラを向くよう角度追従。後壁をZ=-23.9mに引き下げて門が壁に埋まらない設計。
- SYSTEM端末は**(-2.65,0,2.18)m**。低い横長パノラマモニター、左の電源棚、低い鍵盤、アナログ制御基板。
- TRAINING端末は**(2.64,0,0.72)m**。高い縦画面、右の独立センサー、左の油圧試験部、モジュール式キーパッド。両方のBlockbench原本を別々に作成。
- 室内カメラの奥行きを10.20→11.75mへ後退させ、左右端末と奥の施設をフレームに収める。操作時は各固有モデルを注視する焦点座標へ更新。
- NEXUS展示SERA、リング（世界Z=-4.75m）、出撃用光漏れ制御、セーブ、NEXUSのタッチ操作／UI構造は維持。

## 形状と線

ブロックの単純な増量ではなく、斜めの補強材、複層のアーチ、機構フレーム、ケーブル、縦横の凹凸、冷却ベント、2面キーボード、非対称センサーブーム、階段の蹴上げと警告ラインを設ける。Blockbenchの7施設系統と2つの新端末の計8モデルを現行の形に新規定義。

元の `SERA_kiosk.bbmodel` は旧形式の履歴モデルとして残すが、本番では参照しない。ゲームに使う定義は `SERA_system_console.bbmodel` と `SERA_training_console.bbmodel`、および再構築した6施設。全要素は `assets/base_command_modules.gd` に同期。

CI項目・テストコードに触れず、Godot／Android／Pythonを実行しない。3D上の視認性、ゲートの映り込み、FPSは実機未確認。
