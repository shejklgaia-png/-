# SERA 視点依存の外周・段差輪郭線 (SERA_VIEW_EDGES_V2)

## 描画仕様
- SERAの装備済み機体、訓練ターゲット、ビットタランに常時適用。
- 同一メッシュ内で隣接する面の法線角度が**80°以上**ならハードエッジ情報として登録。ただし**角度差だけでは線を表示しません**。
- 2面ともカメラを向くエッジは**90°以上でも非表示**。一方の面がカメラを向き、隣接面が裏向きになる輪郭のみ表示。80°未満でも実際に外周になるなら表示します。
- 開放境界（面が1つしか接していないエッジ）は、その面がカメラを向く場合のみ表示。手前の独立部品の外周が奥の別部品を隠す部分は、深度テストを経て段差線になります。
- 遮蔽されたエッジは通常の深度テストで非表示。地面や前面装甲を透過しない。
- 頂点法線の前後判定はカメラ位置に連動し、モデル/関節/装備の移動と回転に自動追従。
- 現在のスタイル：線幅3.0画面px（2026-11-21、旧1.6pxから調整）、暗いブルーグレー `#17212f`、不透明。
- ライティングや装甲色に影響しない独立したMeshInstance3D/ShaderMaterial。衝突・ロック・IK・モーションには変更なし。

## Android GL Compatibilityでの負荷対策
1. `scripts/sera_view_edges.gd` が元メッシュの三角形頂点を一度解析し、量子化位置（0.1mm単位）で面の隣接関係を復元。同一平面内の三角化境界は削除。
2. 面のペアと80°分類情報を保存した、単純な6頂点/エッジの固定リボン・メッシュを生成。80°の分類情報自体は描画を強制しません。変更なしのMeshリソースはインスタンスID別にキャッシュ。
3. `shaders/sera_view_edges.gdshader` が**GPU上で毎フレーム**カメラ方向と面法線を比較し、視点依存のシルエットと手前の部品による遮蔽輪郭だけを表示。両面が手前向きの四角形の角は表示しません。スクリーン空間で線幅を一定に補正。
4. CPUは0.75秒おきに新しいMeshInstance3Dや装備交換を検知するだけ。毎フレームの全頂点投影・線メッシュ再生成は行わない。
5. 元メッシュの表示/非表示を継承し、独立したマテリアルを破壊・書換しない。
6. GL Compatibilityでの透明パスを用いて不透明な装甲描画より後に出す。通常深度テストON。発光色や不透明度は元材質へ伝播しない。

## 既知の制約・実機確認
- この版の80°分類は**同一メッシュ内の隣接面**が対象です。頭と首など**別MeshInstance3D間の接合部**は、形状が一体化したかどうかの幾何学的な証明を行っていません。部品の重なりによっては余計な接合輪郭が残るため、顎を上げて首とつながる表現の完全な再現には別メッシュ間の結合・深度輪郭判定が必要です。
- UVシームの座標一致は約0.1mmの許容範囲です。外周が独立ポリゴンで滑らかに繋がっているモデルは原本の面法線に従います。
- Android GL Compatibilityでの太さ、GPU費用、透明FX/火花とのソート、極端な近接や遠景、ビットタランの脚・首・砲台の遮蔽、装備交換を実機で確認してください。Headless CI合格は実機視覚保証ではありません。
- 閾値を変更する際は `CREASE_DEGREES` と `tools/sera_view_edges_{self_check.py,runtime_check.gd}` の契約を**先に**更新してください。
