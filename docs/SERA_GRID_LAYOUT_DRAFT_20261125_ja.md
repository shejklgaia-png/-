## 操作改訂（2026-11-25）
- 移動・回転専用モードを廃止。配置モードで既設設備をタップして選択、ドラッグで移動（掴んだセル相対位置を維持）。有効なセルのみ表示更新、指を離した位置が盤外・重複・UIなら開始時の座標へ戻す。二本指・キャンセル・画面退出でもロールバック。マウス入力にも対応。
- 選択設備の画面上の左上・右上に、背景なしの反時計回り・時計回り矢印を表示。タップで各90°回転、衝突・盤外は拒否。ドラッグ中・撤去モード・遷移中は非表示。従来通り左上占有セルが回転の基準。撤去モードとパレットからの空きセル配置は維持。
- ノード選択時はパレット上部に名称・面積・役割・生産量/消費EP等を表示。設計値と明記し、戦闘支援は暫定。操作結果は別ラベルで表示して説明を消さない。経済・所有・保存・実給電なし。
- 技術参照: Godot公式 InputEventScreenTouch / InputEventScreenDrag / Camera3D.unproject_position と Androidの複数指キャンセル事例 godotengine/godot#99647。タッチIDとエミュレーション入力を分離、絶対座標から盤面セルへ変換。CI・実機・テストは未実施、ソース差分確認のみ。

## 構成概要と設備分類（2026-11-25）
- 生産12・電力3・補助3・戦闘6の4カテゴリ。カテゴリ切替は配置選択を解除し、撤去から配置へ戻す。既存のドラッグ・回転・撤去を維持。
- 定格概要：占有面積、総設備数、変換上限（140EP×GEN）、基本500EP＋蓄電池、原料処理上限、満量加工費＋配線維持費、戦闘支援基数／種類数。戦闘3基超・重複種類は注意色。配置自体は禁止しない。数値は未接続・OFF・増幅・原料不足を考慮しない設計定格で、帰還実績・蓄電残量とは別。操作時のみ集計。
- 次段階案：固定端子のセル座標と回転規則を確定し、上下左右の接続判定→有効給電網→未接続表示→実稼働ON/OFF→プリセットと所有権→帰還精算の順。戦闘支援の暫定数値は変更しない。専用3Dモデルは別途着手指示まで保留、俯瞰シルエットが占有セル内という規則を維持。
