# LABO 装備制作3D：右向きプリンターと右側操作モニター（2026-11-24）

## ユーザー指定
装備制作画面では、左側に**右向き**3Dプリンター、右側に操作モニターを配置し、クレートが両者を往復する。機能機器の具体性と室内デザインを改善する。画像生成は行わずGodotの既存3Dルートを更新する。

## 構図と設備
- 左：`AtlasOpenFramePrinter` を位置(-2.42,0,-1.34)に配置し、Y角を +π/2（ローカル前面+Zがワールド+Xを向く右向き）へ変更。スケール(1.30,1.20,1.06)。従来のノズル、造形途中の部品、回転給材スプール、前回追加した鋳造・駆動部メッシュはすべて機械ローカルに属し、向きに追従する。
- 造形機の右向き排出口へ、面取り搬送トレーと5本の送りローラー、左右の搬送ガイドを追加。トレーもプリンターに従って右向きになる。
- 右：`TechnicalConsole` を(2.58,0,-1.35)、Y角-0.34へ。大型八角フレーム付きの作業モニター（幅1.78・高さ1.06）、背面支持台、面取り制御デスク、22mmの実立体キー14個、操作インジケータ、放熱スリット、工程表示銘板を追加。
- 既存の `PrintProgressMonitor` の名前と動的モード0（PRINT、画像テクスチャ方式24fps）を維持し、モニターを二重生成しない。
- 室内はプリンターと操作端末の上方を結ぶ吊り配管、床の青色作業灯、両側の誘導ラインと六角形の停止デッキを追加。新たなライト・テクスチャ・SubViewportは追加しない。左の工具収納と既存の天井骨格は保持する。

## クレートとカメラ
- プリンター前出発(-0.62,0,-0.48)→右のモニター前(1.70,0,0.40)で約3.2秒の操作→左のプリンター排出台前(-0.52,0,-0.62)で約2.8秒の点検→右へ戻る。既存の`_move_to`で距離ベース移動し、機械・画面に向くよう旋回角を調整。印刷ノズル、完成部品、動的スクリーンの従来アニメーションを変更しない。
- LABO専用カメラ(2.10,2.35,5.35)、FOV56°、注視(0.10,1.66,-1.22)。左プリンターの右向き加工面、中央クレート、右モニターが同じプレビューに入る狙い。SMELTER/RECYCLER/STORAGEカメラは変更しない。

## 運用・確認範囲
編集対象は`scripts/labo_rebuilt_scenes.gd`と`scripts/labo_hero_stage.gd`および記録のみ。LABO装備制作の保存/所持素材/特性/制作UIのロジックは変更しない。
GitHubソース/差分の人手による確認だけを行い、ユーザー指定のテスト禁止（CIの項目確認・修正・実施を含む）と画像生成禁止を守る。Android実機での表示・クリッピング・動線・パフォーマンスは未確認。
