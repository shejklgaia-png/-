# SERA v317 — Xperia実機診断の手順

## トレーニングでの操作
1. 画面上部のデバッグボタン列にある **DIAG: OFF** をタップしてONにします。診断パネルが表示されます。
2. カメラのカクつき、ステップ方向、モーションの誤り、ロック切替などを再現します。約0.12秒ごとの短い記録を最大500件保持します。
3. **COPY LOG** をタップします。端末のクリップボードへタブ区切りログをコピーします。ChatGPTに貼り付けて原因調査を依頼できます。必要に応じて再現動画やスクリーンショットも添付してください。
4. **DIAG: ON** をもう一度タップするとOFFになり、サンプリングとパネル描画が止まります。

収集項目: 時刻、FPS、現在のアニメーション名、戦闘状態番号、ロック部位ID、カメラYaw・追従半径・位置追従遅延m、STEP実走行距離m、方向入力X/Y、BOOST状態、EN量。

**プライバシーと安全:** 記録は端末内メモリのみ。COPY操作を行わなければクリップボードへ渡しません。ログファイル、外部送信、自動アップロードは行いません。診断ONはトレーニング画面を開き直すとOFFに戻ります。普段のプレイはOFFを推奨します。

## 開発者用CI棚卸し
`python3 tools/sera_ci_inventory.py --json`: 登録数、完全一致するテストソース、未登録候補、過去計測データを表示。重複候補の**推測による削除はしません**。ランタイム実機テストはCIと別です。
