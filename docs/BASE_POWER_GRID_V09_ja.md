# SERA / 電力制御施設 → 電力パズル（Ver.0.9）

## 位置・導線（2026-11-21）
- 拠点の既存内部ID `GENERATOR` はセーブ・UI参照の互換性のため維持し、表示名称だけ「電力制御施設」に変更します。
- 施設から画面右方向（カメラの右ベクトルに沿ったワールド +X/-Z 側）へ、2回以上うねる一本の太い電力ケーブルと青い通電ラインを伸ばします。セグメントを別MeshInstanceにせず、インデックス付きメッシュ2個で静的描画します。
- ケーブル先端はパズル用独立空間 `PowerPuzzleZone/PowerGrid8x8` の入力端子につながります。基板の中心はワールド座標 `(35.5,0,-20.0)`、設備自体の当たり判定・位置・床パネルは固定です。
- 施設をタップすると従来の「発電機」情報モーダルではなく、現在と同じ平行投影カメラがケーブルの途中を経由して基板へ移動します。上部の「拠点へ戻る」ボタンまたはAndroid戻る操作で逆方向に復帰します。施設名ラベル・拠点小物再配置操作は移動中および基板ビューで非表示にします。
- 基板の床は8×8=64マス。64個の別ノードではなく2つのMultiMesh（各32マス）で描画します。外枠と接続プラグが見え、今後の設備ノード配置に使える枠を優先します。

## 記録から引き継ぐパズル仕様（現時点の境界）
- 2026-11-21、空間配置型（B）を基本に、回路設計型（A）の要素を採用。バージョン0.9の基盤は**8×8、接触辺搬送、局所冷却、方向付きの電力・素材・熱接続**です。
- 検討した設備記号は `G/H/K/P/C/D/R/X/Y/T/O`。標準配置の試算は**素材4個/分、52EP、余剰22.25EP、熱0HU**、改善配置は**素材6個/分、余剰8EP、熱0HU**。D/X/Pの移動・追加を含む試算で、Godot全配置探索や実機検査ではありません。
- 各設備の最終的なマス形状・係数・操作UI・生産計算・正当性の判定は、まだ確定仕様ではありません。今回の実装は**3D空間・ケーブル・基板フレーム・画面遷移のみ**です。試算値を実際の資源増加や電力残量として表示・加算しません。
- 将来ノードを実装する際は当ファイルのルールを最低条件として、ユーザー確認後の確定数値で電力/素材/熱を計算してください。

## 2026-11-21：BASE / GRID シェルUI・配置モード（未実装の計算と分離）

- BASE（拠点）およびGRID（電力パズル）の左上画面見出しは、斜め欠け四角の大きなプレート。UDEV Gothic/Moralerspaceの共通フォント、マットなブルーグレー `#55798A` の細線を使う。切り替え時には**現在のプレートが左へ、次のプレートが右から左へ約0.24秒でスライド**する。GRIDから戻ると逆方向。
- GRIDの8×8盤面をタップすると、実際のタップ位置にある1マスを選択表示し、カメラが約0.58秒で**真上の平行投影**に移動し、画面比率に応じて盤面全体が収まるよう拡縮する。隙間、盤外タップでは何もしない。
- 真上視点へ移ると、画面下から「NODE PALETTE」が、画面右から背景なしの**配置・移動・回転**アイコンが滑り込む。パレットは11候補 `G/H/K/P/C/D/R/X/Y/T/O` を横スクロール。候補をタップすると枠の選択表示と現在の操作アイコンが切り替わる。
- **ガワのみ**。G等の具体的な設備形状・実際の設置・移動・回転処理、接続判定、電力/熱/素材の数値計算、セーブへの書き込みは実装しない。右側アイコンの切替えは現在の操作表示の切替えに限定する。
- GRID内では戻る操作1回で「真上配置モード→斜め俯瞰GRID」、さらに1回で「GRID→BASE」へ復帰する。もとの拠点カメラ・施設UIに戻る。
- 低負荷：タイトルやアイコンはUI CanvasItemの線画、11候補は簡素なControl、マスの選択は既存3D基板に単一のマーカーを重ねるだけ。機械の生成やマスごとのUIノード生成は行わず、既存の64マスMultiMeshを維持する。
- 検証：`tools/base_grid_presentation_runtime_check.gd` の画面遷移・操作と、`sera_base_grid_edit_shell.png` の実Godot GLスクリーンショット。

## 2026-11-21：画面遷移の高速・直線化

- BASE⇔GRID のカメラ移動は**0.48秒・1区間**。ケーブルはそのまま表示するが、カメラはケーブル途中で減速／停止せず終点へ直進する。復路も同様の1区間とする。
- GRIDのマスをタップして配置モードへ切り替える際、および配置モードを閉じる際は**0.46秒・1区間**。カメラの位置、回転（クォータニオン球面補間）、正投影サイズを共通進捗率で同時補間し、直線的な移動経路と滑らかな角度変化・拡縮を維持する。
- 時間的な減速加速は SINE IN_OUT を1回だけ適用する。複数Tweenの区間つなぎ、回転だけ遅れる演出、ズーム後に位置を動かす演出は行わない。
- BASE/GRIDの左上見出しも0.20秒で横スライドし、3D移動のテンポに合わせる。UI構成およびノード実配置・計算の未実装方針は変更しない。
