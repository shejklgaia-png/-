# NEXUS全身：不採用の2D境界箱輪郭を通常表示から撤去（2026-11-23）

## 実機判断

PR #812の同一Viewport 2D-AABB投影輪郭はAndroid実機では描画自体はできたが、頭・腕・武器・胴体の外側に**実際の形状と一致しない太い外周や内部線**が多発した。異なる角度の画像2枚でも同じ問題があり、ユーザーは「これは使えないね」と判断した。

メッシュごとのAABBを投影した凸包は、そもそも装備本来の凹み・薄さ・複雑な形を表現しない。多角形結合の小変更や線幅の調整だけでは改善を保証できないため、**今回の変更では通常描画を無効化し、未検証の代替方式を自動採用しない**。

## 実装

- `scripts/sera_nexus_canvas_silhouette.gd` の `_enabled()` を診断中の **mode 1 / 9のみtrue** へ変更。NEXUS全身通常モード0や診断を閉じた状態では線を描かない。
- 普段の `_ready()` での初期メッシュ走査を廃止。`_process()` のAABB取得・2D投影・ポリゴン結合・毎フレーム再描画を**診断表示中だけ**実行する。閉じた際には登録ソースと描画件数をクリアする。
- 診断UIの「通常」を「通常 (枠線OFF)」、「外周候補」を「旧2D近似」、「合成確認」を「旧2D合成」に変更。2D境界箱が正式な本番方式であるかのような説明を撤回する。
- 従来のGPUエッジ・ステンシル・反転ハルは元から診断専用であり、その運用を変更しない。
- ほかの設定（装備単体プレビュー、BASE、戦闘、クレート、敵、キャラクター枠線設定値）には手を加えない。

## 次の設計に必要な条件（今回未実装）

候補は**各装備の実形状から簡略化した輪郭専用プロキシ**。ただし、現行のAABBを置き換えるだけで多メッシュの可視全身シルエットを求められるとは限らない。

- 実メッシュの頂点・三角形を基準に簡略化する。AABBの8角のみを用いて代用しない。
- 前後で隠れる境界や装甲同士の重なりを考慮し、**全身の外側だけ**を出す。独立した装備ごとに輪郭を描くと、また内部線が増える。
- 同一カメラ・同一Viewport、追加SubViewportなし、GPU/CPUの1フレーム遅延を増やさない。
- 装備交換・関節・回転・ズーム・全身表示／非表示に追従。プレビュー専用に限定する。
- Android負荷、シルエットの連続性、内部線ゼロを実機で評価してから本番モードに切替える。候補が十分に成立しない場合は通常の枠線OFFを維持する。

今回のPRは**旧方式の通常表示停止と次方式の要件整理まで**で、新しい外周専用簡略メッシュの描画実装・本番採用は含まない。未検証の方式をいきなり有効化して、繰り返し全消失や誤輪郭を起こすことを避ける。

## 運用

ユーザー指定によりCI項目の確認・修正・適用およびCI／動作テストを実施しない。Androidでの今回の修正後表示も未確認。
