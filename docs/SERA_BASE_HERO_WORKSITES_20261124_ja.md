# 2026-11-24 BASE準拠の施設3D背景再構築

- LABO・精製（炉/分解機）・倉庫の旧背景を新規の開放型作業ヤードに置換。現行BASEの `sera_base_fresh_design.gd` と `sera_base_architecture.gd` のBatch・生成ポリゴン・色材を直接利用。旧室内の独自機械、3反応塔、左右の独自大型棚は描画しない。各設備は局所+Zが作業正面。各施設の内部寸法・位置関係・可動軸を維持し、描画用親ノードで一律2.0/2.1/2.2倍に拡大。屋外の施設ワールド配置や資源・UIには変更なし。 close-up専用の広い床、低い背面設備柵、CRATEが操作できる高さの補助端末を加える。
- LABOは原料ラック・ホッパー・造形機・SCARA・完成品収納、精製炉は側面投入・炉口・双煙突・鋳造、分解機は二軸刃・後部投入・前部排出、倉庫は左手リフト・背面棚・貨物。実際のBASEの機械30Hzモーションと4種造形物、炉の24fps炎を利用。資源を消費しないプレビュー演出。機械はCRATEの端末操作→点検→復帰の循環に連動。共通CRATEモデルは等倍。作業点は施設の実変換から取得し、機械前方の通路に置く。
- 既存480×240 SubViewport、アングル正規配置と通常UIを維持。旧背景の座標の誤復元防止に施設別 `*_BASE_V2` を採用。炉と分解機は個別アングル。モデル正規配置は機械全体とCRATE経路を対象とし、内部可動軸や機材配置を分離しない。モニター6モードは既存実装を利用、現在の背景のみ更新。非表示の機械は処理を停止、背景自体が非稼働の時もステージの手動更新を止める。
- ソース差分と既存エディターAPI、生成メッシュID、作業点の局所座標、モーションの継続・完了処理を確認。Android実機での見え方、クレートの手の接触、フレームレートは未確認。CI・画像生成なし。旧背景の保存済みカメラは旧キーのまま保持し、新しいカメラを改めて正規配置すること。
