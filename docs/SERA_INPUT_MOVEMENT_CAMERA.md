# SERA — 操作・移動・カメラ・UI
基準 v102。細かい数値は `scripts/main.gd`, `scripts/touch_overlay.gd`, `README_vNN_ja.md` を優先。

## [実装] 1本指操作
- 縦画面のタッチ開始位置に動的コントローラを表示。短いタップは格闘、画面基準ドラッグはRUN、外周を越える大きなドラッグはBOOST、左右・下フリックのリリースはSTEP/後退。
- 止まったまま0.32秒以上ホールド（指移動18px以内）でGUARD。ガード中は移動、攻撃、BOOST、STEP、ジャンプ不可。離指で解除。v102はGUARDのポーズ修正。
- タップ攻撃時の自動接近「MELEE APPROACH」は、BOOST移動とは別。旧モーション名 `meleeboost` による誤解を避ける。
- 上フリックによるジャンプは **`JUMP_TOUCH_INPUT_ENABLED=false`** で既定OFF。左右と下フリックは維持。

## [実装/履歴] 移動の数値
- RUN最高速度 **3.25 m/s**、BOOST倍率1.5（履歴上 **4.875 m/s**）。
- v90では操作円半径の125%超過を0.10秒維持してBOOST開始、110%未満で解除。加速・減速補間0.15秒。旧v73の「168pxを1px超えると即BOOST」は履歴上の旧挙動。
- 下フリックBACKSTEPはv88で **4m**、速度8〜10m/s程度、最大0.40〜0.50秒。左右STEPと後退は同じ衝突処理を使う設計。
- [要確認] ユーザーは接敵時のSTEP/BOOST速度調整として「距離5m以下から減速、2mで6m/s」を要求。旧RUN/BOOST速度値と異なるため、**どの状態にどう適用されたか**現行コードを確認し、記憶だけで上書きしない。
- v92で被弾後に同じ指でBOOSTへ再移行できるようにし、離指時の誤STEP/誤タップ抑止は維持。

## [実装] カメラの基本
- v9をドラッグ/カメラの設計ベースとした。画面基準移動、敵を中心に捉えるターゲット追従、遅延追従、停止時の見やすい構図を重視。
- 敵へ近づけば敵全体が収まる範囲で寄る。自機は左右へ大きく動いてよく、前腕程度の画面外は許容。描画順を強制的に敵優先にせず自然な奥行き関係とする。
- v82では敵キューブ表面から1m以内で始めた左右STEPのカメラ保護を導入。ターゲット中心の方位でプレイヤーとカメラの角度差を原則 **±65°** に抑え、最大角速度 **300°/秒**。STEP終了後0.18秒の移行期間、新タッチで解除。画面端の強制回転を抑止しズーム保護は維持。
- 旧v80〜81の開始カメラ角±18°固定は撤廃。**通常BOOST・通常格闘カメラの既存追従には問題がない**ため、至近距離STEPの修正を他のカメラへ波及させない。

## [実装] ジャンプはデバッグのみ
- v98〜99で高さ1.5m、通常空中0.80秒、水平速度80%継承、空中ドラッグ制御はRUN速度の30%、空中の左右/後退STEP・3段格闘後の落下・0.6秒着地硬直を試作。
- v100以降通常上フリックでは起動しない。`JUMP TEST` ボタンとPC Jキーでテスト。**コードと元アセットは削除禁止**。

## [実装/履歴] 残像とロックオン意匠
- STEP/BOOSTの残像は各瞬間の姿勢と位置を保存し、時間差で発生して透明化。背景ブラーなし。v78履歴値: STEP寿命0.22秒/不透明度34%、BOOST寿命0.14秒/不透明度28%、間隔0.055秒、最大3。現在値はコードで確認。
- v44のロックオン円は4弧（0/90/180/270度）、距離変化で回転・拡縮、0.20秒、直径相当62→42px、赤/シアン、線幅5/2px、十字は非回転。現行描画に優先。

## [設計決定/コード統合未確認] 新しい操作UIの画像案
- コントローラは**シンプル、グロー無し**。中心の円に上下左右の波矢印、外周円に二重矢印。中心と外周は灰色で塗り、**2つの円の間は完全透明**。余計な十字線・斜め装飾や画像の指示用点/線は使用しない。
- 画面下部の操作領域のグラデーションは、下を控えめに濃いグレー、上端で透明にする方向性。真っ白な下端は避ける。画像の最終案と現在の実装を取り違えない。

## [実装] v112 利き手別・RUN判定範囲
- 走行ベースは前方 `run_front_original` / 後方 `run_back` を維持。
- 右利き既定で左後方の前方走行判定を20度拡大（中心120°、ヒステリシス115°/125°）。右側は従来中心100°（95°/105°）。左利きへ切り替えると左右の拡張が反転する。入力方向・速度・STEP判定・カメラに変更なし。
- ゲーム上部の `HAND: RIGHT` / `HAND: LEFT` ボタンで即時切替。`user://sera_settings.cfg` に保存し、次回起動時に復元。実機での操作感とボタンタップは未検証。

## [実装・実機未検証] v113 RUN中の頭部回転スタビライズ
- 腰から上の4関節（Torso/Chest/Neck/Head）の合成姿勢を4走行位相で平均し、RUN周期由来の頭部回転揺れを65%抑制（35%残す）。前後RUNブレンドとターゲット追従の補正は維持。
- 既存Waistの15°旋回バンクは残し、頭部の位置・モデルキー・非RUNの姿勢は不変。実機の見た目は未確認。

## [実装・実機未検証] v114 BOOST 4方向
- `Boost_front`、`Boost_back`、`Boost_Left`、`Boost_right` をユーザー作成の `SERA_BOOSTER_all.bbmodel` から統合。全て時刻0の静止ポーズで、斜め方向は隣接する2姿勢のQuaternion／位置／スケール補間で合成します。
- BOOST中の向き変化は最短角・時定数0.12秒で追従。RUNモーションや走行ベクトルの処理を変更せず、0.16秒の既存の状態間ブレンド、1.5倍速、既存の入力判定を維持します。
