# LABO・精製・倉庫：床・天井の構造化と倉庫拡張（2026-11-24）

## 意図
3施設の床の平板感、天井の反復的な梁だけの見た目、倉庫の狭さ・貨物不足を解消する。建築構造を実際に拡張する。画像生成・外部テクスチャは用いない。

## 新しい建築・床・天井
- scripts/sera_labo_deck_architecture.gd：3室を独立して1部屋1静的ArrayMeshに描画。角を切り落とした実際の8角押出し床パネル、検査スロット、アンカープレート、搬送レーン、グレーチング、天井トラス、斜め支柱、設備カセットを造形。
- LABO：青い作業レーンと精密造形機の給材排気ダクト。
- 精製：別色の資源取り回し線、反応塔に対応した天井の圧力・冷却マニホールド。
- 倉庫：幅広の中央走行路と危険表示、奥まで届く天井主桁、荷役用斜材。視界を塞がない側部設備カセット。
- 床デッキの厚みは約3.5cm、追加点検プレートは数cm。既存の物理床・CRATE移動・衝突判定は変更しない。

## 描画コストの方針
すべての床・天井を施設ごとに1つの不透明ArrayMeshへまとめる。既存の静的貨物はMultiMesh再利用。新規画像・ライト・テクスチャ・SubViewport・影・物理体・パーティクルを増やさず、床・天井を毎フレーム作り直さない。増加した頂点数・実機FPSは未計測。
