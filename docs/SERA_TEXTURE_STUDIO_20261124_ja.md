# SERA Texture Studio（テクスタ）仕様 2026-11-24

## 目的
Android縦画面のゲーム内開発者ツール。実寸に揃った粗いピクセルを3D表面へ直接描く。通常プレイ中は動作させない。LABO装備制作画面に独立ランチャー、終了時は元のページへ戻る。ゲームの資源・装備性能を変更しない。

## UV
三角形の同一平面を法線・平面距離でまとめ、面内の直交基底に実寸投影。台形を矩形に引き延ばさない。曲面は平面単位に分離。8/16/32/64 texel/m、既定32。各島の外接矩形を余白付きで非重複配置。64～1024の正方形アトラス、入りきらない場合は密度変更を要求（自動的に歪ませない）。三角形を重心座標でラスタ化してベース色を焼く。UVシームの余白を確保。元のモデルを破壊しない。

## 操作
対象を選択、UV生成、独立3Dビューで回転・拡縮、描画モード切替。ペン、消しゴム（初期色へ復帰）、スポイト、面塗り、直線・矩形、明暗、ノイズ、摩耗・傷、色選択、Undo/Redo。直接描画はカメラレイと三角形の交差からUVを計算。ドラッグ補間、2指操作時は描画を中断。Androidでタッチを優先しPCマウスにも対応。ピクセルはnearest、ゲーム用はミップマップ考慮。解像度選択、UVプレビュー、保存先表示。

## データ・範囲
ゲームの通常MeshInstance3D（LABOおよびBASE等の候補）と外部GLBモデルの選択を段階的に対応。編集単位はメッシュ。元のマテリアル色/テクスチャ、形状、法線の維持を優先。動的MultiMesh、スキン、特殊シェーダー、アニメーション、複数素材、既存デカールの完全保持は個別対応が必要であり、非対応データを破壊しない。保存はuser://texture_studio配下のPNG＋UV付きMesh Resource、編集用データと原本を分離。ゲームへの永続反映は識別子・原本との互換確認・GitHubへの取り込みを別工程とする。端末の保存をGitHub反映と偽らない。

## 段階・受入
1. 独立編集画面、平面UV、密度、ペン／回転／拡縮、Undo、PNGとメッシュ保存、LABOランチャー。
2. 外部モデル、複数メッシュ／スキン対応、素材保持強化、UV島境界のパディング・シーム補完、レイヤー・デカール・左右対称・高度ブラシ、安定した永続反映。
3. Android実機で台形・隣接面・タッチ・保存復元・戻る・負荷を確認。実機未確認の機能を完成と断定しない。
既存LABOの正規配置・カメラ・スクロール操作を侵害しない。編集処理は遅延ロード、失敗時もLABOを維持。CI項目変更・実行と画像生成は現運用では行わない。

## 第2段階 追補
- ベース画像は不変、透明な描画レイヤー最大4枚。上から重ね、選択・追加・表示切替・削除。消しゴムは選択レイヤーのみ透明に戻す。明暗は合成結果を参照し、選択レイヤーへ記録。Undo/Redoは選択レイヤー内、切替時に履歴をクリア。ブラシ径1/3/5px。UV島外への描画を禁止。
- 摩耗はUV島の外周近傍に限定した明色ドット、傷は暗い刻みと明るい縁。左右対称はモデル中心のX面を基準とし、鏡像レイの交点が鏡像位置に近い場合だけ描画（非対称部には投影しない）。ペン・消しゴム・明暗・ノイズ・摩耗・傷対応。面塗り・形状・スポイトは対称対象外。
- デカールは番号や警告用の固定ピクセルスタンプ。UV島外は切る。画面上に文字を重ねる方式ではない。
- 保存は合成PNGとUV付きメッシュに加え、元画像・レイヤーPNG・表示状態・密度・三角形ごとの島IDをJSONに保存。編集プロジェクトを読み込む際はUVを再展開せず、保存済みメッシュのUV・元画像・レイヤーを復元。保存は端末内。元ゲームシーンへの永続適用は別段階。
- 編集画面のUV/レイヤー表示は省スペース。テクスチャGPU更新は一つの入力イベント内でまとめる。MultiMesh・スキン・特殊シェーダーとモデル全体一括UVは未対応。

## パーツ選択（実機試用）
- 起動直後に既存装備カタログを2列のサムネイル一覧で表示。頭部・胴体・腕部・脚部・ブースター・右手武器・左手武器の7カテゴリ、カタログに登録済みの全19種を対象とする。画像は既存の装備アイコンを再利用し、毎回3D撮影しない。
- 選択時のみ非表示の独立SeraRigをロードし、正本の装備ID→セット・スロット→実メッシュ群を参照する。現装備・所持数・製造状況・装備セーブは変更しない。パーツに属する静的メッシュを姿勢込みで一時結合し、1つのUVアトラスで同時に編集する。カタナは抜身と鞘を対象とし収納刃の重複を除外する。
- 共通装備シェーダーのソース色・テクスチャ・UV変換・頂点色をペイント用に復元する。照明等のシェーダー効果そのものは焼かない。外部GLBや従来の個別メッシュ選択も残す。編集結果は端末に保存し、原本装備へ自動上書きしない。
