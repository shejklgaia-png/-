# SERA 敵用予測シールド — v510実装契約

世界観：高度に普及した弾道予測防御で直線射撃が95%軽減されるため、予測が困難な近接攻撃に戦術的な価値がある。ただし近接も100%貫通ではなく、SPに比例して最大25%軽減される。

## 状態遷移
- 最大SP100。近接1ヒットで 8 + raw_attack×0.16 SP消費。射撃1ヒットで 2 + raw_attack×0.05 SP消費（負数は0扱い）。
- 軽減はSP比率比例。攻撃力に倍率を適用後、既存の部位ごとの防御率でHP計算。部位破壊量は未変更。
- SPが0になったヒットだけ破壊エフェクトとSE。すでにSP0なら亀裂を繰り返さない。
- ヒットごとに4秒回復待機、待機終了後は20SP/秒。継続的な攻撃は回復を遅らせる。
- 敵死亡中はSP回復を止める。リスポーン時にSPを完全回復し、進行中エフェクトを消す。
- プレイヤーのガードSHとは独立した敵用機構であり、既存のEN・ガード・怯み制御を変えない。

## 表示
- **HPバーの青オーバーレイ案は廃止**。HP残量は従来のバーのみで示す。
- 命中した表面の座標にカメラ正対の半透明放射状グラデーション。中心強め、縁透明。青 >=60%、黄 >=30%、赤 <30%。
- 防御光は装甲不透明描画の後、`HIT_SPARKS`の前：`SHIELD_IMPACT=115`、深度テストON、衝突面からカメラへ0.032m。
- 破壊時は中心から左右へ青白い横の稲妻を約0.2秒で伸ばし、放射状の青白い光を約0.44秒で拡散・減衰。破壊SEは短い電撃クラッキングと広がる破裂音を混合。
- 複数ヒットは最大5個の独立した短命インパクトを保持。動作中にノードや音源を繰り返し生成しない（ImmediateMesh更新のみ）。

## 改修箇所
- `scripts/enemy_predictive_shield.gd`：数値。
- `scripts/enemy_shield_hit_fx.gd`：エフェクト・SE。
- `scripts/main.gd`：共通命中処理、描画・SE呼び出し、リセット。
- `scripts/bittaran_battle.gd`：mainを継承しているため追加分岐不要。頭・脛の実際の命中面をそのまま利用。
- `scripts/render_order_policy.gd` / `docs/RENDER_PIPELINE_POLICY_ja.md`：描画順契約。

## 実機目視確認
1. テストターゲットのBODY、各脚、頭で防御光が装甲面に接し火花より奥か。
2. SPを連撃で減らして青→黄→赤、0で横方向に亀裂→放射状破裂+SE。
3. 4秒無被弾で回復、ヒットで停止し、回復後の防御光の色が戻るか。
4. ビットタランの動く脚・頭、ダウン・復帰の極端な姿勢でも背面透過と浮きがないか。
5. Android縦画面・GL Compatibilityでの光の強さ、自然な破裂音、元の赤色HPバーの明瞭さ。

## v511：視認性の改善（v510からの変更のみ）

Android実機で初期エフェクトがほぼ見えなかったため、接触点の通常防御光を半径100〜260px（参考720px幅）へ拡大し、最低表示倍率0.85、0.44秒表示へ延長。中心を白寄りに発光させ、外周は引き続き透明。破壊時の青白い横亀裂は左右各最大470px、放射状拡散は最大半径470pxへ拡大し、0.65秒で消灯。深度上のオフセットはカメラ側0.14m。防御計算/軽減/回復、HPバー非重畳、描画優先度115と既存の火花120の順番は維持。
