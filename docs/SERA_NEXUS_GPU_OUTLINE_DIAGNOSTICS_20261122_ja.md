# NEXUS 全身GPU枠線 診断ツール

2026-11-22 / 対象：NEXUSカスタマイズ画面の全身SERA

## 目的

シルエット欠落の原因を、(1)元のメッシュ／エッジ生成、(2)GPU視点判定、(3)GPU深度遮蔽、(4)接合線生成のどこにあるか切り分ける。旧別ViewportのID画像の確認ではなく、新しい `SeraLiveMeshEdges` と `sera_live_mesh_edges.gdshader` を直接制御する。現在のシルエット精度を自動で修正するツールではない。

## 操作

NEXUS → カスタマイズ → 左上の「輪郭診断」をタップ。診断パネルは右側の装備メニューに重ねて表示するので、左側の全身SERAを回転させながら比較できる。モード選択はパネル内の6ボタン。診断ボタンをもう一度押すか、カスタマイズを離れると表示を通常に戻す。素材・装備・ユーザー設定を変更しない。

| モード | 表示 | 判断 |
| --- | --- | --- |
| 通常 | 通常色（外周3px、開放・接合線1px） | 変更前の実際の見え方 |
| 外周候補 | 青緑 | 隣接面の表裏が変化する候補だけ。閉じたメッシュの正面／背面判定を見る |
| 全エッジ | 黄 | 生成済みトポロジエッジをすべて表示。ここで欠落する場合はGPUの視点判定以前の問題 |
| 開放境界 | 橙 | 開いたメッシュの自由端のみ。閉じた六面体は通常ここには出ない |
| 接合線 | 紫 | 重なりメッシュの交差から生成された線のみ。接触・共面や交差数上限で不足する場合がある |
| 深度無視 | 青緑・橙・紫 | 同一GPUエッジの深度テストを外した透視診断。ここでだけ現れる線は遮蔽／深度競合が候補 |

パネルの「描画元」「輪郭生成」「欠落」「候補エッジ」「交差線」はGPUメッシュの事前生成数であり、画面に描画されたピクセル数ではない。GPU描画成功、期待する全身最外周の画素精度、端末FPSを保証する数値ではない。

## 原因の切り分け

- 通常に線がないが「全エッジ」にある → 視点依存の表裏判定を疑う。
- 「全エッジ」でもないが「欠落」が1以上 → エッジメッシュ生成・非対応トポロジ等を疑う。
- 「全エッジ」では消えて「深度無視」で見える → 深度テスト、遮蔽、線オフセットを疑う。
- 「接合線」がない → 交差判定が生成できないか、その装備の重なりは表面の接触や共面である可能性。
- 各メッシュの線は合っていても全身最外周が繋がらない → メッシュごとの表裏シルエットを合成しただけであり、複数メッシュを合わせた外周を保証していない。

**制約：** 深度無視モードは意図的に見えない線を露出させ、キャラクターの外から内部が透ける。常時使用する描画方式ではない。表示が異なる角度でスクリーンショットを保存すれば原因調査に利用できる。実機確認は未実施。

## 運用

診断はユーザーが画面から手動で起動するだけのGPU可視化機能。CIの設定・項目・テストは変更せず、テスト実行を伴わない。通常の枠線描画のロジック、初期線幅・色は維持する。
