# NEXUS 全身輪郭：同一Viewport GPUエッジ方式（2026-11-22）

## 適用範囲

NEXUS の SERA 全身プレビューのみを切り替える。BASE 施設、GRID、戦闘中の SERA/ボス、パーツ単体プレビューに現行方式が残る。既存のGRAPHICS SETTINGS「キャラクター枠線」ON/OFFに連動する。

## 描画

- 本体と同じメッシュ階層に線ジオメトリを配置する。別のカメラ・ID用Viewport・CPUの画面投影を介さないため、全身回転と各ボーンへの追従に時間差を設けない。
- トポロジから隣接面を解析し、同じ平面の三角分割線を除外する。GPUで二つの面の向きが視点を挟む場合だけシルエット線を表示する。
- 元メッシュの開放境界を3pxで描画する。
- 閉じた分離メッシュ同士の交差線は、NEXUSで組み立てた姿勢の三角形交差を事前抽出し、補助線として同一Viewportに描画する。モデルの相対姿勢／構成が変わった場合にのみ更新し、全身回転のたびには再計算しない。
- 線幅はスクリーンピクセル基準。通常輪郭4px・境界／接合線3px、色 #17212f。通常の深度テストで完全遮蔽部を隠す。
- 原本の.bbmodelや材質には手を加えず、描画用ArrayMeshを追加する。

## 限界と注意点

- 事前交差線生成には1メッシュ500三角形、全体75,000三角形ペアの上限があり、超過部分は省略する。
- 平面同士が完全に重なる場合、貫通ではなく接触するだけの場合、複雑な非多様体、スキンメッシュは自動接合線が欠ける場合がある。
- 動的に相対姿勢が変化する戦闘用の接合線処理には未対応。NEXUS上の全身姿勢を対象にした実装であり、戦闘へ直接流用しない。
- GPU負荷・見た目・Android Compatibility実機挙動は現時点では未評価。旧方式の更新遅延の構造的要因を除去することを目的とする。
