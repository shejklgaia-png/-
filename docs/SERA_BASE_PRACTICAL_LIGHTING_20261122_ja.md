# SERA BASE 設備シルエットと局所照明（2026-11-22）

## 枠線
- BASEの設備カテゴリ（facility role 2）の可視シルエット：**内側1px＋外側3px**。可視メッシュ接合部2px、手前向き凸角2pxは従来どおり。
- BASE小物（clutter role 3）は内側1px＋外側1px、境界1px、手前凸角1pxに変更。GRIDやSERA単独の設定は変えない。
- 外側線を3pxへ縮小したため、第4リングと施設専用の投影AABB判定を廃止。1px境界と既存の深度解決IDパスを維持し、追加の画面全体IDパス・CPU読取りは設けない。

## NEXUSアンテナ
- アーカイブNEXUSモデルのアンテナ竿は位置・向きを固定し、旧MultiMesh回転・垂直往復・スケール拡縮のサンプル更新を廃止。
- 旧発光バッチ内Beaconキューブを削除し、同じ屋根座標に固定の防護ケース＋独立発光レンズ＋ごく弱いOmniLightを配置。
- Timerによる短点灯（約0.075〜0.14秒）、長点灯（約0.26〜0.40秒）、短休止（約0.07〜0.16秒）、組間休止（約0.45〜0.83秒）をランダム構成。毎フレームのBeaconスケール・位置変更は行わない。

## 共通側面光の整理
- 既存 `BaseFacilityVFX._add_entrance` の全面的な大きなDoorLightLeak/DoorLightFloorは**精製機SMELTERだけ**で維持。非SMELTERでは呼ばない。
- 共通のDoorLamp、NEXUS上部光帯・旧下端光帯、RECYCLER光帯、STORAGE光帯など旧側面光は廃止。小型の機能的な状態表示灯は残す。
- 局所照明のモデルは遮光ハウジング、取り付けブラケット、光るディフューザーをBoxMeshベースで生成。FX_NO_OUTLINEを付け輪郭対象から除外。スポットの影は生成しない。

## 施設別
- **NEXUS**：シャッター下に細い青白色の物理照明＋ローカルスポット＋シャッター前床への低い漏れ光。上部の門灯で側面を照らさない。
- **RECYCLER（分解装置）**：粉砕口の左右に保護フレーム付き作業灯を設置。スポットはカッター／噛み込み部に集光。
- **GENERATOR（電力制御）**：壁のメーター隙間に細い埋め込み照明を複数配置。回転ファンの**背面**に青白い放射状発光板を置き、前面の羽根を遮蔽物とする。ファン周辺には1基の局所スポット。
- **STORAGE（資材保管庫）**：入口に工業用ダウンライト2基、保護シェードと取付ブラケット、入口付近に独立した円形の暖色照射範囲2箇所。
- **SCRAP_COLLECTOR（回収機）**：回収対象エリアと回収箱にそれぞれ作業灯＋スポットを配置。
- **LABO／BUILD_TERMINAL**：従来の共通入口ビームを除去し、既存の作業用局所ライトに物理ハウジングを付加。
- **SMELTER**：従来の煙、炉内炎、炉口光、床反射を維持。

## パフォーマンス・描画
- 新規照明は影なし、定位置配置でアニメーション用ジオメトリ更新なし。精製機の既存炎・煙以外、時間変化はアンテナのTimerイベントのみ。
- スリットやファン背面光、円形床照明は透明パスで既存輪郭より後に合成し、光源自身への枠線や不透明なX-ray線は付けない。
- 実機での見え方、透過の重なり、GPU時間は未測定。

- ランプの実体はFX_NO_OUTLINE配下にあっても、**不透明発光ガラスだけ**既存の同一ID SubViewportに役割7で登録する。透明煙・ビームは輪郭対象に入れない。
- 新規Viewport、フルスクリーンBlur、影ありライト、大量の個別Spriteは追加しない。発光ラインの位置は生成時に確定し、通常の毎フレーム処理は増やさない。発電設備の回転ルーバーは元のモデルを動かし、光の隙間は元の固定座標に維持。
- CI項目に触れずテストは実行しない。Android/GL Compatibilityでの明るさ・遮蔽・描画負荷は実機確認前であり、全面的な改善を断定しない。

## 2026-11-23：全8施設の投光器をサーチライト構造へ更新

### 共通の照明構造
- 既存のFX専用子ツリーを維持。実体のある回転式灯具（ハウジング／遮光上縁／青白・暖色の発光レンズ／取り付けブラケット）を**発光レンズのローカル-Z方向が照射点を向くよう**配置する。
- そのレンズ直前を始点として、**影なしSpotLight3D、三平面の柔らかいテーパービーム、光源ハロー、作業地点の着地ハロー**をすべて同じ「始点→照射先」ベクトルで構築する。従来の「光っている灯具とSpotLightの位置・向きが違う」実装を廃止。
- 見えるビームは、横断面を60度ずつ回した低ポリゴン3枚の交差面、長手方向5分割。UVを使って輪郭と両端をフェード。**現実のボリュームライトではなく、深度テスト付きの疑似体積光**。遮蔽物の奥にある光線は描画しないが、影なしSpotLight自体は遮蔽物の影を計算しない。
- 全ての可視ビームは**施設ごとにMultiMesh描画1回**、共通ArrayMeshとShaderMaterialを利用。煙・炎・ラインの軽量ハローとは別バッチだが、追加のViewport・全画面ブラー・シャドウ計算・毎フレームジオメトリ更新は行わない。
- ビームの終了位置を作業点に合わせ、床に向かう投光と機械上部へ向かう投光で着地ハローの向きを変える。従来の強すぎる一部床プールは控えめにして、作業点と光線の整合を重視。
- SpotLight3Dの向きはGodot標準の **-Z**。光源レンズと実スポットを同じ向きにする。複数灯具に対し名前を分け、編集中の識別性を確保。

### 配置の可視性・重なり防止
- 位置の疑似乱数は各施設ID固定シードで発生し、上表の候補近辺だけを探索。毎回遠くへ飛ぶ全面ランダム配置から変更。回転はカメラ方向を中心に±45度ランダムとして、状態灯と二つのソケットが画面に向くようにする。

### コードの貫通防止
- 従来は始点・終点をCatmull-Romで直接つなぎ、曲線が建物内側や小物を貫通する可能性があったため廃止。
- **ワールドXZ床面に1辺0.82mのAStarGrid2D障害物地図を一度だけ構築**。施設の回転済みフットプリントに約0.48mの安全余白、既存小物の包囲半径、新設装置の包囲半径を使用。障害物がない経路だけ通過し、斜め移動でも角を横切らないモードを使用する。
- 経路を直線化する場合は細かく障害物を確認し、**通れる場合だけ**補間。コードは床面約0.115mの高さで障害物を回避し、端子付近でのみ立ち上げる。既存の6角チューブ＋信号帯を共通メッシュの2表面に統合。
- GRID→配電端末の新接続1経路、配電端末→各装置7経路、各装置→施設7経路で**計15経路**。複数コードが同じ床面経路に重ならないよう、使用済みセルへ軽い通行コストを加える。
- 経路が見つからない場合、機械を貫通する直線コードにフォールバックせず警告を出して該当コードを省略する。ゲームプレイの電力計算は従前どおり非連動。

## 2026-11-23：障害物回避を維持した電源コードの曲線化

- ユーザー実機画像では、AStarGrid2Dによる回避経路が長い直線や急角度の折れ線になっていた。**障害物を回避した経路そのものは維持し、床上部分だけを滑らかに補間**する。端子の始点・終点と垂直方向の接続位置は変更しない。
- A*による経路探索→直線化可能な部分の経路圧縮→**安全判定付きの二次ベジェ角丸化**→**長距離区間の緩い弓形湾曲**の順。以前に貫通を起こした制約なしCatmull-Romへは戻さない。
- 角の半径は最大1.8m、隣接する直線のそれぞれ43%以下。候補の半径を1.0／0.62／0.32倍と縮めながら、曲線の全サンプルが障害物を避けるか確認する。許容できない角では従来の角の点を残す。
- 2.4m以上の長い床配線には、始点・終点で接線方向が変わらない**4次の釣鐘型側方変位**を使用。最大たわみは1.10mまたは長さの10%の小さい方。左右それぞれ、たわみ量1.0／0.62／0.32倍を確認し、通れない場合は安全な直線に戻す。曲げ方向はケーブル名・区間番号の固定シードで変化する。
- **貫通防止の優先条件**：曲線を0.43m程度の間隔で分割し、各隣接サンプルの中心線と左右0.14mのオフセットについて、既存AStarGrid2Dの通行判定を行う。ケーブルの半径0.087mと信号帯の半径を考慮し、中心線だけが通れても外周が障害物に寄りすぎる場合はその曲線候補を採用しない。
- 既存の7施設向け給電・施設接続と電力制御からの入力コードの全15経路へ一括適用。6角チューブ／青灰色の信号帯／小物と共通の内1外1接合1凸角1pxは変更しない。メッシュの分割数は滑らかさの分だけ増えるが、**1つのArrayMesh（2材質表面）と1度限りの経路生成**を維持し、新たなノード・毎フレーム更新・Viewport・Lightを追加しない。
- セル障害物マップは簡易占有近似のため、**実機での全ての接触・オーバードローが検証済みという意味ではない**。CI項目や設定の確認・変更、CI／Godot／Android／その他のテスト実行、画像生成は行わない。


## 2026-11-23：電源コードの不自然なうねりを除去（最新）

- 前節のPR #848で追加した「長い区間への左右交互の4次ベル型側方変位」は**廃止**。直線が通れる場所まで強制的に蛇行させるため、電源配線が不自然な波状になっていた。施設への分岐や障害物経路は変更せず、直線の通行可能区間は直線のまま使用する。
