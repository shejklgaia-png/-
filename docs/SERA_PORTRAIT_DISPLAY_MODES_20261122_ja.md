# SERA 縦長画面の表示範囲と従来表示（2026-11-22）

## 表示仕様
- 基準レイアウト：**720×1280（9:16）**。Xperia 1 V対応後も基準となるUI/カメラ設計は変更しない。
- 初期設定：**上下拡張**。Godot の Window.CONTENT_SCALE_ASPECT_EXPAND と、基準9:16の水平3D画角を維持する補正を併用。縦長画面では左右を切り詰めたり3Dモデルを拡大したりせず、上下の表示範囲を追加する。
- もう一つの設定：**従来 9:16**。Window.CONTENT_SCALE_ASPECT_KEEP に切り替え、720×1280基準の表示範囲とカメラを復元する。縦長画面ではレターボックスの余白が表示される。
- BASE（平行投影）：設計上のカメラ上下サイズに「実際の表示の高さ/幅 ÷ 1280/720」を乗算する。幅を9:16と同じに保つ。
- NEXUS・戦闘（透視投影）：設計上の縦FOVから、tan(実縦FOV/2)=tan(設計縦FOV/2)×実縦横比/設計縦横比 として実際の縦FOVを求める。
- NEXUSのSYSTEMで設定変更した場合は、その場でカメラの縦FOVとHUDの配置を補正する。NEXUSの各焦点移動とカスタマイズ画面にも同じ画角補正を適用する。シーン入場ごとに設定を読み直す。

## 操作・保存
- 設定画面：**NEXUS → SYSTEM → GRAPHICS SETTINGS → 画面表示**
- 項目：**上下拡張 / 従来 9:16**。FPSの3項目は既存値・挙動を維持する。
- 保存場所：`user://sera_settings.cfg` の `[display] portrait_mode`。
- FPS・操作設定・セーブスロットとは独立した端末共通の設定で、アプリ再起動後も保持する。

## 備考
- デザイン解像度は変更せず、物理解像度・3Dレンダースケールも変更しない。
- 戦闘カメラの周辺物体・UI要素・画角の視認性は、選択した両モードで実機確認する必要がある。
