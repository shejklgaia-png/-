# CRATE — 添付設定画準拠の3D全面再構築 (2026-11-24)

## 描画方針
- 原案はユーザー添付『SERA Companion Robot』の多視点設定画。画像生成は実施しない。
- 正本は scripts/sera_crate_model.gd の create_model()。BASEとLABO全3背景で同じ共通モデルを使用する。
- 前方はローカル -Z。白い面取り頭部、両耳アンテナ、側面の同心円サーボ、黒い横長バイザーとシアンの一本ラインを再現。
- 白系トラペゾイド胸部、アンバーのパネル境界、鋼色の関節、左右各3本の湾曲したC字クロー。
- 左右独立の小型クローラーは連続したベルト、独立トレッド、三連車輪、ホイールハブと整備パネルから構成。
- 背面に箱型収納／整備ユニット、アンバーの枠とシアン保守スロットを設ける。
- 顔文字・絵文字・テクスチャ貼り付け・画像生成を禁止。形状はすべて実体3Dポリゴン。

## 技術的契約
- 八角面取りプリズム、法線付き回転体、Y-Z断面履帯、節付きクローを生成する。
- 可動部を材質別ArrayMeshに結合し、メッシュとStandardMaterial3Dを静的キャッシュする。
- 全マテリアルはOpaque、シアンはEmission。追加の3Dライト・CSG・描画中のジオメトリ更新は使用しない。
- CRATE、HeadPivot、LeftArmPivot、RightArmPivot、LeftTrack、RightTrackの既存ノード名を維持。
- BASEの巡回とLABOのピボットアニメーション、シーンの配置、セーブ、ゲームバージョンを変更しない。
- キャラクター枠線のロール（外4px・内0px・境界2px・凸線なし）を継承する。
