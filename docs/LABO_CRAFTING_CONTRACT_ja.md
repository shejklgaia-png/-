# SERA LABO 試作製作・アイコン・倉庫の契約

## 対象
- 基本素材は `sera_base_materials.gd` の4系統×3ランク＝12種類。IDと日本語名は固定し、品質の自動代替はしません。
- 試作装備は `sera_prototype_catalog.gd` の H01 / T01 / A01 / L01 / B01 / WR01 / WL01 の7種類です。
- 素材12種類は `assets/ui/sera_pixel_material_atlas.webp`（3列×4行、各72×72、背景透過）のドット絵へ差し替えます。並びは上からスクラップ・合金・電子部品・有機素材、各行左から低・中・高。文字・枠は画像に含めません。
- 装備7種類は既存の `assets/ui/sera_matte_icon_atlas.webp`（4列×5行）を引き続き参照し、装備画像は変更しません。`sera_item_icons.gd` は素材と装備のアトラスを別キャッシュで保持し、アイコン領域の重複判定はテクスチャの出自と矩形の組で行います。
- 倉庫の素材カード、LABOの素材選択・素材変換プレビューには nearest-neighbor 描画を使用し、ドットの輪郭を保ちます。GitSync直後にGodotのimportキャッシュがない場合はWebPの元バイト列から読み込みます。
- アイコンは回収した資材の保管庫、精製・分解の投入/生成プレビュー、LABOの試作リストと詳細、製作後の倉庫、NEXUSのカスタマイズ（選択中）に表示します。

## 製作操作・保存
1. 拠点の LABO → Shell開発 → 試作装備（7種類）から製作対象を選択します。
2. 現段階では**操作検証専用の無償試作**です。実際の素材消費・性能・希少度・追加効果の設計が確定するまでは、仮の必要素材を設定して消費させません。
3. 製作が成功したときだけ、アクティブなセーブスロットの `crafted_items` に装備個体を追加し、`craft_serials` を更新して原子的に保存します。セーブがない場合や保存に失敗した場合は新しい個体を発行しません。
4. 倉庫には素材12種と製作済個体を分けて表示します。NEXUS→CUSTOMIZEの各パーツ欄で既存のセットと製作個体を切り替え、スロットの適合を検証して `equipped_crafted` に保存します。
5. **試作装備の3D表示は既存Aモデルを一時的に利用します。** アイコンと個体IDをモデルデータと取り違えず、独自の3Dメッシュや性能を作成済みとは扱いません。

## 一意な製作個体名
- 安定した内部ID：`<設計図ID>-<4桁以上の十進連番>`。例：`H01-0001`、`H01-0002`、`T01-0001`。
- 表示名：`スカウトバイザー  H01-0002` のように日本語名と**省略しない内部ID**を併記します。翻訳名・レアリティ変更とは独立しています。
- 連番は**各セーブスロット、設計図IDごと**に管理し、製作済個体の最大番号と保存済カウンタを比較して次番号を割り当てます。装備切替で番号を変更せず、将来の分解・削除でも番号を再利用しません。
- 保存データ読込時は、正規フォーマット・有効な設計図・重複しないUID・スロット適合を検査します。旧版の正規UIDはそのまま維持します。

## 確認
- 変更前に既存の `tools/sera_ci_manifest.txt`、`v511_matte_icons_self_check.py`、`v511_matte_icons_runtime_check.gd`、`base_material_conversion_runtime_check.gd` と `.github/workflows/sera-model-policy.yml` を確認します。
- 新仕様に合わせて本体編集**前**にv511のPython/Godotテストを拡張しました。素材・装備19枠の一意性、正規UID生成、同一設計図の連番、別設計図の連番、保存再読込、カタログ個数表示を検証します。
- マージ後 `main` の全登録Python/Godot CIを実施します。Android縦画面の行高さ・指操作と、実際の読みやすさは実機で検証します。

## v517：試作機能へのアクセスと素材
- 拠点の常設ショートカット「装備製作」「素材変換」「倉庫」から直接開きます。従来の3D建物タップも使えます。
- アクティブなセーブがなければ、製作カタログ上の「セーブを新規作成して製作を始める」から**空きスロットのみ**を作成します。既存のデータは上書きしません。
- LABOの「試作素材を受け取る」は**操作検証のための任意の1回限りの付与**です。12種類それぞれ6個を各セーブスロットへ記録します。受領フラグは再ロード後も維持し、重複獲得できません。
- 項目名から装飾だけの矢印/括弧を除き、実在する素材・装備IDとアイコンを対応させて表示します。

## v529：個体別追加性能と倉庫UI
- 最新UI仕様は [SERA_WAREHOUSE_UI_AND_CRAFT_AFFIXES_ja.md](SERA_WAREHOUSE_UI_AND_CRAFT_AFFIXES_ja.md) を優先します。
- 製作成功時に装備個体へ重複しない5件の暫定追加性能データを抽選し、UIDごとに保存します。旧装備は後付け再抽選しません。戦闘ステータスへの加算は未実装です。
- ハンガー容量は装備カテゴリ別に999個。いっぱいの場合は製作・新個体保存が拒否され、UID連番は消費しません。
- 倉庫の装備一覧は2列・縦スクロール・個体カード、素材は各系統3枚を横に配置します。装備の集約「所持×N」は表示しません。
- v528以前の倉庫7設計図カードや9件単位の個体ページの説明は履歴であり、現行表示を定義しません。
