# SERA — コンセプト、作品・開発方針
2026-11-06時点のゲーム関連決定。区分は `SERA_MEMORY_INDEX.md` を参照。

## [設計決定] 基本コンセプト
- **Android縦画面、片手・指1本完結**の3D近接アクション。大型単一敵との戦闘を中核にする。
- タップ格闘、フリックSTEP、ホールドGUARD、ドラッグRUN、長いドラッグBOOST。原則、プレイヤーはターゲットの方を向いて移動。
- モンハンNOW系の大型単一敵と、EXVS系の接近・回避・近距離での読み合いを参考にした操作感。ただし具体的な他社作品の複製はしない。
- スマートフォン上で60Hz/60fpsを理想とする。**ローポリで軽量、GPU負荷を増やし過ぎない、基本無料制作**。
- 長い隙には3段格闘コンボを入れられ、短いまとまった隙には別の攻撃択を活かせるようにしたい。

## [設計決定] 主人公「セラ」
- ロボットと近未来の騎士を組み合わせた、機械的・無個性寄りの装甲。
- 全体の色はグレーに寄せたモノトーン、**約5頭身、やや太め、スカート無し**。
- 頭は左右対称、角は簡素、顎先に目立つ尖った意匠は付けない。
- 剣は大きく、首から足先くらいの長さを一つのデザイン目安とする。盾も装備予定。
- 後に剣、盾、体の装甲を組み替える可能性があるため、アタッチメントやパーツ階層を考慮。ただし既存モデルを無断で分割しない。

## [設計決定／未実装] 敵とゲームシステム
- 敵は大型の機械。近距離・遠距離・振り向き・尾・範囲・波状の攻撃を使い分ける構想。
- 部位破壊候補は**頭・脚・尾**。怯みは一定回数の攻撃で発生する構想。耐久値、ダメージ倍率、部位ごとの報酬などは未確定。
- 距離によって攻防が変わるようにする。たとえば「後退して敵の攻撃範囲外へ逃げる」か「多くのシールド値を消費してシールドバッシュで突破・反撃」かの選択を迫る技。
- チャージ攻撃は、フルコンボほど大きくないがまとまった隙に入れる技として構想。**長い隙の最適解はフルコンボ**にしたい。溜め時間や威力などは未確定。
- 自動接近格闘は、接近処理終了時に攻撃射程へ届いていなければ攻撃モーションを出さず、接近だけで終了する方針。接近最大距離は未確定／コードで確認。

## [実装] 直近の大枠
- v102では3段格闘（ダメージ12/12/26）、左右STEP、4mバックステップ、BOOST、Guardポーズ、ダメージノックバック、4種の敵デバッグ攻撃等が実装履歴にある。
- **ジャンプ・空中戦は当面の標準操作から外し、地上戦優先**。コード・アニメーションは削除せず、JUMP TEST（およびPCのJキー）用に保持。
- シールド値、ガード崩れ、シールドバッシュ、エネルギー、部位破壊等は**v102の実装済み機能ではない**。詳細は戦闘文書を参照。

## [設計決定] 開発優先度
1. 既存の地上操作とカメラ・攻撃・ガードの安定化。
2. エネルギー・シールド・ガード崩れ・シールドバッシュ。
3. 敵攻撃の選択肢、被弾蓄積・ダウン、チャージ攻撃、怯み・部位破壊。
4. 装備交換、画面UI、剣閃・ブースト炎、効果音/BGMの品質向上。

**注:** 優先度は開発の方向性でありCodexへの自動実装指示ではありません。
