# SERA GRAPHICS SETTINGS：輪郭・モーション残像設定（2026-11-22）

## UI
NEXUS → SYSTEM → GRAPHICS SETTINGS の既存「BASE/NEXUS」「GRID操作」「戦闘中」FPS 3項目と「画面表示」に、4項目を追加します。

| 項目 | 保存キー | 初期値 | 影響範囲 |
| --- | --- | --- | --- |
| 拠点の枠線 | `base_outline` | ON | BASE施設・建築・装飾・NEXUS施設のメッシュID輪郭、BASE施設用の角線材質 |
| 全身キャラ枠線 | `character_outline` | ON | 戦闘中のSERA全身・武装・敵（ビットタラン含む）、NEXUS全身プレビュー、拠点のクレート |
| 単体パーツ枠線 | `part_outline` | ON | LAB/倉庫/NEXUS共通の単体パーツプレビュー（通常共有輪郭およびアイリス専用輪郭） |
| ステップ/ブースト残像 | `motion_blur` | ON | 戦闘でのSTEP開始位置スナップショットとSTEP/BOOST中の時間残像 |

- 各項目は独立し、ON/OFFをタップで巡回させます。未設定・不正値では従来の描画ONに戻します。
- `user://sera_settings.cfg` の `[graphics]` セクションに保存し、セーブスロット・FPS・画面表示・操作設定と共存します。
- NEXUSの枠線変更は描画コンポジタへ即時再読込を要求します。その他の画面は新規シーン入場時に設定を読み込みます。
- メッシュIDコンポジタの分類タグ `sera_graphics_outline_category` に `base`, `character`, `part` を使い、元の物理モデル・マテリアル・武装・アニメーションには触れません。
- オフ対象はIDパスの対象から除外されます。床・エフェクト等の背景マスク、照明・粉塵・ヒットエフェクト、選択可能位置を示すUI、アウトラインとは別のステップ発光は維持します。
- モーション残像はブースト姿勢や速度、当たり判定などの戦闘挙動を変更せず、残像エミッションだけを抑制します。
