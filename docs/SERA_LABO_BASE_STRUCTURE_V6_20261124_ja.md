# BASE構造準拠の屋外実寸施設 V6

2026-11-24。BASEスクリーンショットと sera_base_fresh_design.gd の LABO / SMELTER / RECYCLER / STORAGE の現行造形を参照。BASEの完成モデルをそのまま拡大せず、近景専用の生成メッシュで独立再設計。屋外、BASE空色・床・遠景方位、等倍CRATE、既存資源・UIを維持。

- LABO: 四柱の閉じたような機械を撤去。二柱式オープン造形機、左原料棚・受入ホッパー、後方抽気塔・冷却槽、左完成品受け、二リンクSCARAと昇降グリッパー。基台幅15.4m×奥行12.2m（描画1.30倍で約20.0×15.9m）。造形物4種、造形後にSCARAの搬送を追加。
- 精製: 圧力ジャケット上部の発光磁気リング、シール、両側冷却槽・戻り配管、炉口耐火材と格子、側面受入と昇降トレイ、鋳造・冷却設備、双煙突（最上部約18.8m）。前回の燃焼シェーダーは変更せず、局所照明追加。
- 分解: 露出した二軸の互い違いの切削ディスク、フレア型ホッパー、後方傾斜供給・前方排出シュート、モーター冷却・軸受、スクラップの部品形状と破砕後の回収部品。
- 倉庫: 中央リフトを廃止し、左側リフトと背面の4層6列ラック、前方荷受け床、左搬入ローラー、局所庇・灯具。背面ラック幅約21.8m、高さ約15.4m。荷物の昇降・移載は同一モデルで補間。伸縮フォーク支持部。
- 近景メッシュ材質と既存バッチを利用。黒潰れ対策の実寸投影、火炎、設備モデル編集を維持。アングル・モデル正規配置キー OUTDOOR_V6 に変更し旧構造の座標混入を防止。
- ソース上のメッシュ種、モーション辞書、UI接続、差分を確認。実機描画、接触、アニメーション見栄え、FPS、コンパイルは未確認。CI・画像生成なし。
- 再発防止: BASE施設の用途だけでなく構造・位置関係を正本のソースで先に照合。接続不可の即断を避け、再探索してGitHub操作を確認。コード置換時はJSのテンプレート文字列を使用。
