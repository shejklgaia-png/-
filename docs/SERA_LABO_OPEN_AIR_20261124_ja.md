# 2026-11-24 LABO・精製・倉庫の屋外作業場

- #1158の大規模な専用近景モデル、1.30倍の機械寸法、CRATE等倍、既存作業演出、実寸テクスチャと炉内の炎を保持。屋内ホール・背面壁・側壁・共通天井・架空の室内照明/ギャラリーを撤去。LABOの原料棚と倉庫棚に限定した防候庇のみ。炉・分解機は開放。BASEの青灰色の空 #607d8f と太陽方向を使用、近景で黒潰れを防ぐため照度は別調整。
- BASEの鋼板分割アルゴリズム・ポリゴン・6色・デッキウェアテクスチャ・床用材質を共通利用。全近景で共有する詳細147m床＋低密度外周鋼板、320m下地。BASE全体の床と同一の個別パネル座標ではない。近景用の安全線を維持。追加の影・Viewport・物理なし。

- 既存のモデル・アングル編集を維持、屋外用キー OUTDOOR_V5。屋内向け旧キーを保持するが読み込まない。UIや資源データに変更なし。
