# SERA 全モニターの24fpsアニメーション（2026-11-24）

## 対象と表示仕様

NEXUSとBASEの3D表示面11台と、LABO・素材精製・倉庫の独立3D背景で使われる
6種類のモニター表示、合計17演出を **24fps** に統一します。

フレーム番号は `floor((TIME + phase) * 24.0)`、描画時刻はその値を24で除算して算出します。
つまり、各演出の表示状態は約41.67msごとに更新されます。
実際の画面出力は端末の描画フレームレートに制約されます。

各フレームはGPUシェーダーで手続き的に構築するため、**画像枚数や再生時間に上限はありません**。
大量の連番PNG、画像の逐次デコード、CPUからのテクスチャ更新は行いません。
シーン切り替えや一時停止後もGPU時刻から状態を再計算できます。

### NEXUS（6画面）

| ID | 24fpsの動き |
|---|---|
| N01 | システム波形が連続更新し、8レーン稼働率の表示が変動 |
| N02 | OSの診断ログがスクロールし、選択・状態表示が更新 |
| N03 | ターゲットの追尾照準、リング、クロスヘアが移動 |
| N04 | レーダーが回転、索敵ブリップが明滅 |
| N05 | データアーカイブの行がスクロール |
| N06 | データ解析バーとスキャンカーソルが変動 |

### BASE（5画面）

| ID | 24fpsの動き |
|---|---|
| B01 | 回収データの内容と強調行が更新 |
| B02 | 保管資源のリストと量・選択行が切り替わる |
| B03 | 3Dプリント断面、ノズル、進捗レールが進行 |
| B04 | 電力計の針と出力メーターが変動 |
| B05 | 設計図が3パターンに切り替わり、走査線が移動 |

### LABO・精製・倉庫（6種類）

| mode | 24fpsの動き |
|---|---|
| PRINT | 積層ヘッド移動・パーツの積層・進捗 |
| FLOW | 3つの素材流路で信号が流れる |
| PURITY | 純度解析バー・走査線 |
| RECYCLE | リサイクル機構の回転・周辺粒子・進捗 |
| INVENTORY | 倉庫リストのスクロール・保有量の変化 |
| SCANNER | 照射スイープ・追尾照準・センサー信号 |

## 実装

- `assets/monitors/world_monitor.gdshader`:
  N01〜B05の11種類をそれぞれの`mode`で描き分ける24Hz GPU演出。
- `scripts/sera_world_monitor_textures.gd`:
  11台のIDとmodeを対応付け、fps=24.0、画面固有の位相を設定。
- `assets/monitors/labo_display.gdshader`:
  LABO系6種類を24Hz GPU演出へ再構築。
- `scripts/labo_hero_stage.gd`: LABO用materialにfps=24.0を明示。

従前の11台分の8コマPNGアトラスは**静的なタイポグラフィ・画面意匠の下地**として保持し、
メインの動きは時間制限のないGPU演出が担います。アトラス側の緩やかな画面変更周期は
`atlas_fps`として独立し、24fpsの演出更新速度には影響しません。

元のモニター筐体・座標・表示面サイズ・クリック操作・枠線除外メタデータは変更しません。

## 描画負荷・運用

各パネルは既存のQuadMesh・ShaderMaterialを使用します。フレームごとのテクスチャ再生成や
ネットワーク転送はありません。固定長の算術演算のみをGPUで実行します。
追加パスや複数Viewportを設けず、既存表示面のGPUシェーダーを差し替えます。

SERA運用ポリシーに従い、CI項目の確認・更新・適用およびテスト実施は行っていません。
端末実機上での見た目・24fps体感・発熱・GPU負荷は別途観察が必要です。
