# 装備制作3D：主役設備を引き立てる工場内構図（2026-11-24）

## 課題と方針
現行の装備制作画面では、プリンターが四本柱の開放フレームに見え、右のモニターは小さな端末に埋もれる。CRATEが画面手前の中央を塞ぎ、前方の天井梁・強い床ラインが主役より目立つ。3D表示そのものは直前の安定化PR #970で復帰しているため、3Dサブビューの描画経路・ノード構成原則を保ち、**同じ既存のプリンター・画面・CRATEを再構図する**。

## 具体的な変更
- \`scripts/labo_hero_stage.gd\`：装備制作専用カメラを(2.18,1.92,4.85)、縦FOV52°、注視(0.10,1.69,-1.42)に変更。ほかの施設カメラは不変。CRATEを(-0.68,0,-1.12)で開始し、プリンター出口側(-0.70,0,-1.12)と右モニター前(1.87,0,-0.68)を往復する。作業中の向きもそれぞれ更新し、中央手前を占有させない。
- \`scripts/labo_rebuilt_scenes.gd\`：装備制作室だけ手前の天井梁を減らし、奥に２列の荷重梁を集約。天井灯を奥側の左右２列とし、強い発光面が画面上部を支配しないよう配置。プリンターは引き続き左から右(+X)を向いた既存モデルを使う。機械の右向き開口に冷却グリル、加工門の２軸ガイド・送りねじ、給材ケーブル、排出台の軸受・支持材と細い動作灯を付加。
- 右操作盤は従来の同一\`PrintProgressMonitor\`を使用し、動画モード0のまま画面2.08m×1.27mへ拡大。厚い背骨プレート、左右支柱、斜め支持材、14キー、微調整つまみ、スロット、表示インジケータで機能を明確化。２個目の動的画面は生成しない。
- 奥壁に3基の整備用パネルと隅のユーティリティ配管を配置。プリンター・モニターをつなぐ配管は背面寄りへ移し、クレートの動線と中央の視認性を確保。床の大きな明色の線は暗色に変更する。
- \`scripts/sera_labo_deck_architecture.gd\`：装備制作室のみ梁を5→3段へ減らし、厚み・前方斜材も削減。精製施設・倉庫の床、天井は変えない。

## 実装上の注意点
前回の灰色一色の表示障害を再発させないため、設備への追加形状は既存の\`_b\`、\`_line\`、\`_cylinder\`、\`_box\`を通して作成する。\`_screen\`も既存を再利用する。新しいSurfaceToolメッシュ・テクスチャ・描画Viewport・ライトは追加しない。機械ノズル、スプール、画面の24fpsアニメと装備製作UI・所持データ・セーブ形式は変えない。
