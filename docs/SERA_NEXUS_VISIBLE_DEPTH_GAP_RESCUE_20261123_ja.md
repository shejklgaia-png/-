# NEXUS全身枠線：深度境界による外周欠落補完（2026-11-23）

## 実機で確認した状況

PR #806（GPU標準深度テストと隣接面表裏判定を採用）後の2枚の実機画像では、以前のような背面・遠景エッジの大量表示は概ね抑制され、胴体、腕、関節、装備境界の線が表示された。一方で **頭部の上辺・側面、肩の外側、腕・足先の外周に大きな欠落**があり、装甲の内側には比較的太い線が残った。単純に線幅を増やすことは、内部の線も太くするため採用しない。

## 変更内容

NEXUS全身プレビューの `shaders/sera_nexus_stencil_edge_outline.gdshader` だけを変更。

1. **第一判定は維持**：隣り合う2面の前後切り替わり、または開いた境界を輪郭候補として採用する。GPU標準深度テストを有効にしたまま、奥の線は遮蔽される。元の装備データ・実際の3D材質・頂点配置・カリングを変更しない。
2. **第二判定を追加**：第一判定で除外された非接合エッジについてのみ、リボン左右で約 `exterior_px+1.25px` 離れた不透明深度をサンプリングする。片側が現在のエッジ深度と近く、もう片側が十分奥（装甲に対する深度段差）なら、外周候補として救済する。
3. 深度サンプルを `INV_PROJECTION_MATRIX` で視点空間の距離に復元し、透視投影の距離に依存しにくい `max(depth_gap_floor, eye_depth * depth_gap_ratio)` を閾値とする。初期設定は **固定3.5cm相当**または視点からの距離の**1.5%**のうち大きい方。Godot CompatibilityのGL深度NDCを `CLIP_SPACE_FAR` で判別する。
4. **輪郭シェーダーだけの小さな変更**：従来の自己深度オフセットを少し弱め、内部面上の不必要な太線を抑える。端点キャップを最大2pxに広げて隣接する角の切れ目を減らす。通常色 `#0B1118` と画面幅3pxは維持する。
5. 画面深度テクスチャはフォールバック判定の必要な画素でのみ2回参照する。法線表裏で確定した輪郭では追加サンプルを行わない。処理はすべてNEXUSの同じGPUフレーム内で行い、別カメラ・別Viewport・CPU毎フレーム再抽出は不要。

## 制限

これは画面上の**深度不連続を利用した輪郭候補の補完**であり、モデル全身の厳密な2Dシルエットを計算する処理ではない。モデルの各装甲面と近接した別の装甲では、境界の一部が追加・欠落する可能性がある。深度テクスチャの実機挙動により補完が効かない場合もある。また、素材が半透明の場合は不透明深度に含まれない。画面上の最終3pxやFPSを未検証のまま保証しない。

- 新たなエッジメッシュ生成や重いCPU処理を追加しない。
- 既存19モードの輪郭診断、通常の枠線ON/OFF、装備交換時のメッシュ自動登録を維持する。
- NEXUS全身以外（単体装備プレビュー、戦闘、BASE施設、敵、クレート）は変更しない。
- Android実機での効果・パフォーマンスは未確認。
- ユーザーの指定に従い、CIの項目確認・修正・適用、およびCI／動作テストの実行は行わない。

## 技術根拠

Godot 4.7 Spatial shadersの `hint_depth_texture`, `INV_PROJECTION_MATRIX`, `SCREEN_UV`, `CLIP_SPACE_FAR` と通常のGPU depth testの仕様。Godot 4.7ではCompatibilityレンダラーのNDC奥行きが[-1, 1]、Forward+/Mobileが[0, 1]であるため復元時に分ける。
