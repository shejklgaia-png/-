# NEXUS / BASE モニター灰色表示・アニメーション不再生対策（2026-11-24）

## 報告された現象

PR #945 の24fps再構築後、実機 NEXUS（SERA v545）で前景左右・奥のアーカイブモニターが
灰色の無表示面になっている。添付スクリーンショットで確認。静止画であるため、
再生周期や実時間の動作そのものは確認できない。

## 旧経路の問題

旧 `scripts/sera_world_monitor_textures.gd` は
`numbered_frames.gd` に埋め込んだ PNG の復号が成功した場合のみ
`ShaderMaterial` を持つ QuadMesh を生成していた。GL Compatibilityで専用
`world_monitor.gdshader` が表示されない場合、画像表示を保障する別経路がない。
本事象の実機ログは未取得のため、シェーダーコンパイル失敗と断定はできない。

## 対応

1. 11面の下地を `StandardMaterial3D` の非ライティング・
   `ImageTexture` 表示に置換。GLSL空間シェーダーへの依存を排除。
2. PNGを復号できない場合にも、ブルーグレーの診断アトラスを1回だけ生成し、
   灰色のままにしない。
3. `sera_monitor_24fps_driver.gd` は毎フレーム経過時間から
   `floor(time * 24)` を算出し、**コマが変わった場合だけ**
   StandardMaterial3D の UV と4個の小さな QuadMesh の位置を更新する。
   0.041666...秒間隔で24枚の画面状態を合成し、移動するライン・照準・
   進捗インジケーターを見える形で追加する。
4. 永久ループ／時間非制限のGPUベーステクスチャ+3Dオーバーレイ方式。
   連番PNGの無限展開や毎フレームの画像転送は不要。
5. 画面の筐体、当たり判定、NEXUSレイアウト、表示面の姿勢、ID枠線除外は保持。
6. LABO / 精製 / 倉庫の独立シェーダー6種類は現状維持。

### 注意

旧8コマのアトラスは下地用です。下地そのものは 0.85〜6fps の周期で切り替わり、
最前面のアニメーションマーカーは24fpsで異なる位置に更新されます。
これは24fpsに更新される画像合成であり、24枚の独立PNGを毎秒読み込む方式ではありません。

NEXUSとBASEはユーザーの設定により描画上限20/30/40/60fpsになります。
**20fps上限時は、物理的に24枚すべてを表示できずフレームの間引きが起こります。**
画面の24fps視認確認には30fps以上を設定してください。
