# NEXUS 完全再構築設計（SERA_NEXUS_REBUILD_V2）

## 制作方針

ユーザー提供の SERA COMMAND NEXUS 参照画像を立体構図の基準とし、2026-11-23 の「追加装飾型」改修は使わない。旧7モデルの要素は一つも流用せず、同じ機能・配置座標に接続する7個のBlockbenchモデルを新規構築した。単一の背景写真ではなく、カメラ移動できる実3D空間。

## 構図と層

1. 近景：金属製の長い床導線と左右の大型コンソール。
2. 中景：実際にSERAが立つ低い16分割の青白い発光展示リング。
3. 展示台の真上：センター座標を補正した12分割のサスペンド・メンテナンスリング（世界Z=-4.75m）。
4. 左奥：段差があるアーカイブ階段、上部デッキ、二連端末と左壁の資料ディスプレイ。
5. 右奥：圧縮した前面の厚い出撃ゲート、青白い光の漏れる奥行きある通路。
6. 最奥：中央SERAのロゴ面を持つタワー、背面配管、壁パネル。
7. 最上層：コファー付き天井、重梁、青白い照明。室内は暗い青黒／スレート装甲、強調色はシアンと少量のアンバー。

## 実装構造

- 室内構造を `blockbench/base/SERA_*.bbmodel` 7原本に新規定義し、同じ座標と順序で `assets/base_command_modules.gd` に埋め込む。
- 各プリミティブの後ろに `edge`・`hit` フラグを付ける。大型装甲だけ2pxの既存表面輪郭シェーダーを使用し、細かな床継目・蛍光管・配線・警戒帯は輪郭なしでバッチ化する。
- クリック対象は端末の本体・画面、アーカイブの制御デスク、ゲートの骨格のみ。細部装飾はタップ外形に含めない。
- `_render_batches` は従来と同じ箱1メッシュを同一色／輪郭フラグで一括描画する。追加のビューポート／透明パス／新規シェーダー／ライト／テクスチャの読み込みは行わない。
- NEXUSの既存カメラ、固定配置基準、メニュー、装備、SERAモデルと姿勢、ゲートの発光エフェクト、既存UI、シルエット判定処理を変更しない。

## 作業制限

ユーザー方針に従ってCI項目・テストコード・CI設定は確認・変更しない。Godot、Android、Pythonなどのテストも実行しない。したがって最終的な画面上の遠近・形状干渉・FPSは未確認。
