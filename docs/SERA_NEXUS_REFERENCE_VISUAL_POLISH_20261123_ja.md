# NEXUS 室内モデル・参照ビジュアルの立体化（2026-11-23）

参照：ユーザーから提供された縦長の SERA COMMAND NEXUS 室内画像。静止画像そのものを背景にせず、既存のBlockbench室内7モジュールを改修して実際の3Dモデルとして表示する。

## 改修対象

- hangar_shell: 工業天井の繰り返しコファーと梁、青白い埋込照明、側壁装甲・ケーブルトレイ、中央タワーの補強、床金属パネル・排水溝・警戒帯。
- maintenance_pad: 展示台の放射状リム・サービススタッド・整備軌道。
- maintenance_canopy: 分割装甲と照明を持つ上部整備リング、吊り下げホイスト。
- deployment_gate: 張り出した装甲フレーム、発光サイドレール、警告マーキング、奥行きのある坑道内装。
- kiosk: 上部バイザー・立体的な筐体・スリット換気・キーボードとモニター内の細い表示ライン。
- data_bank: 二連モニター下のキャビネット、配線・表示・キーを強化。
- archive_mezzanine: 段差を持つ階段踏み面、サイドガード、発光表示。

## 統合ルール

ゲームで使用する正本は `blockbench/base/SERA_*.bbmodel` の7ファイル。実行用 `assets/base_command_modules.gd` を同じプリミティブ配列で同期。
配置、カメラ、選択判定、実機の表示領域、SERA展示用輪郭描画、ゲート光漏れの既存経路を保持する。床の追加インセットは既存の床専用判定に従い、ポリゴン枠線生成対象から除外。発光パーツは既存カラーインデックスを流用する。

描画は既存の単色MultiMeshバッチを使用し、新しいViewport、ライト、シェーダーパス、透明オブジェクト、パーティクルは追加しない。キャラクターや装備モデル、アニメーションは変更しない。

CI・Godot・Androidを含めテストは実施せず、実機での視認性、ポリゴン線の密度、FPSは未確認。
