# NEXUS アイリス：ポリゴン陰影とプレビュー全画面モード（2026-11-22）

## 適用範囲
- **陰影**：NEXUS内のHEAD D「アイリス」（H02）の単体プレビューのみ。SERA全身、BASE、LABO、倉庫、戦闘へは適用しない。
- **全画面**：NEXUSの単体パーツプレビュー。ダブルタップで展開／復帰。Android Backと左上「縮小」でも復帰。
- **右上縦配置**：OFF（元の表示）／2段／3段／4段／5段／6段／7段／8段。初期選択は4段。全画面中も切替可能。プレビューが小さいときはボタンを縦方向に圧縮して表示する。
- 閉鎖メッシュは元のGodot時計回り巻き方向に合わせ `cull_front`、開放メッシュは `cull_disabled` を維持。

## 5〜8段階の陰影
- 2〜4段階は以前のしきい値と明るさを維持する。
- 5〜8段階は光の角度に応じた明度 55%〜105% の範囲を各段階数で均等量子化する。画面全体のポストプロセスではなく、既存のIRIS専用装甲シェーダー内で処理する。
- 閉面用／開放面用で量子化式を統一。光源の見え方以外のモデル形状・色・3px輪郭線は変更しない。

## 描画
- 元モデルとテクスチャを非破壊で使用する。現在の青いレンズ色を維持し、装甲面のみBlockbenchの**元の面単位**の共通法線から段階陰影を生成。
- 2026-11-22 三角分割陰影の対策：HEAD D原本の四角面28箇所で内部2三角形の法線差（最大約13.3度）を確認。元のH02を改変せず、NEXUSプレビュー内で元メッシュ配列から**同一Blockbench面に含まれる三角形の面積重み付き平均法線**を一度だけ構成し、全頂点へ共通法線を与えたプレビュー専用ArrayMeshを使用する。元の形状・UV・6メッシュ境界・カリングは変更しない。
- シェーダーでは `normalize(NORMAL)` を使用し、三角形ごとの `dFdx(VERTEX)/dFdy(VERTEX)` は廃止。隣接する**別の元面**の法線までは統合しないため、装甲角の立体感は維持する。
- 元面と頂点配列が一致しない場合は推測で統合せず、対象メッシュの再構成を中止する。陰影OFF、別パーツへの切替、プレビュー終了時に**元Meshリソースと元Material**を復元する。
- 各装甲ごとに±3.5%の控えめな明度差を付与（元色・モデルデータは変更しない）。
- 既存3px可視メッシュID輪郭、画面上の近接輪郭合成、元の独立6メッシュのポリゴン配置は変更しない。
- OFFやプレビュー終了時は、MeshInstance3D.material_overrideを元の参照へ戻す。
- 再利用する1本の3DプレビューSubViewportの表示領域だけ拡大。新規の3D全画面ビューは作成しない。
- ID輪郭用SubViewportは既存の実表示解像度追従を利用する。全画面時のGPU負荷増加に注意。

## 操作境界
- 1本指ドラッグで従来通り回転、2本指操作と端末Backは保持。
- 330ms以内・30px以内のダブルタップで切替。18px以上動いたドラッグはタップとみなさない。
- ボタン開始タッチを専用キャプチャし、装甲回転・ダブルタップと混同しない。
- 全画面表示中は背後のステータス・装備選択にタッチが届かない。
