# NEXUS アイリス：ポリゴン陰影とプレビュー全画面モード（2026-11-22）

## 適用範囲
- **陰影**：NEXUS内のHEAD D「アイリス」（H02）の単体プレビューのみ。SERA全身、BASE、LABO、倉庫、戦闘へは適用しない。
- **全画面**：NEXUSの単体パーツプレビュー。ダブルタップで展開／復帰。Android Backと左上「縮小」でも復帰。
- **右上縦配置**：OFF（元の表示）／2段／3段／4段。初期選択は4段。全画面中も切替可能。
- 閉鎖メッシュは元のGodot時計回り巻き方向に合わせ `cull_front`、開放メッシュは `cull_disabled` を維持。

## 描画
- 元モデルとテクスチャを非破壊で使用する。現在の青いレンズ色を極力維持し、装甲面のみ幾何面法線（画面微分）から段階陰影を生成。
- 各装甲ごとに±3.5%の控えめな明度差を付与（元色・モデルデータは変更しない）。
- 既存3px可視メッシュID輪郭、画面上の近接輪郭合成、元の独立6メッシュのポリゴン配置は変更しない。
- OFFやプレビュー終了時は、MeshInstance3D.material_overrideを元の参照へ戻す。
- 再利用する1本の3DプレビューSubViewportの表示領域だけ拡大。新規の3D全画面ビューは作成しない。
- ID輪郭用SubViewportは既存の実表示解像度追従を利用する。全画面時のGPU負荷増加に注意。

## 操作境界
- 1本指ドラッグで従来通り回転、2本指操作と端末Backは保持。
- 330ms以内・30px以内のダブルタップで切替。18px以上動いたドラッグはタップとみなさない。
- ボタン開始タッチを専用キャプチャし、装甲回転・ダブルタップと混同しない。
- 全画面表示中は背後のステータス・装備選択にタッチが届かない。

## 検証
- 既存CI manifestに静的契約テストを先行登録。
- ソース契約の照合済み。Godot 4.7 GL Compatibilityでのシェーダーコンパイル・Android実画面・操作遅延・GPU時間は**未検証**。CI / Actionsは起動していない。
- 実機ではレンズの青色、6メッシュ裏面の遮蔽、2〜4段階の見た目、3px輪郭、全画面からの復帰を確認する。
