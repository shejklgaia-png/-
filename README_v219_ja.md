# SERA v219 — 加速バーストを0.05秒・10角形に変更

ステップや格闘・バッシュ追尾で発生するスラスターの加速噴射を調整しました。

| 項目 | v218 | v219 |
|---|---|---|
| 噴射エフェクトの断面 | 四角形 | **正10角形** |
| 最大拡散に達する時間 | 0.10秒 | **0.05秒** |
| 最大拡散幅 | 通常の15倍 | 15倍（維持） |
| 幅が15倍になる位置 | 噴射長の25%地点 | 25%地点（維持） |
| 収束時間 | 0.18秒 | 0.18秒（維持） |
| 演出全体 | 0.28秒 | **0.23秒** |

## 形状・処理

エフェクト用の中空噴射筒を四角形から**10角形断面**へ変更し、輪郭の角張りを抑えました。外側の青い噴射と内側の明るい噴射の両方を同じ10角形で生成します。

既存の長さ方向12分割は保持します。外側・内側それぞれが10面×12区間の低ポリゴンメッシュになり、短い距離で急拡散する形状を保持します。追加のテクスチャ・パーティクルや描画オブジェクトはありません。

**Blockbenchの金属ノズル本体は変更していません。** 変更は生成エフェクトの形状だけです。噴射の根元の位置・スラスターの可動方向・既存の揺らぎ・EN消費・STEPや攻撃の挙動にも変更はありません。

## 検証

`tools/v219_decagonal_thruster_50ms_self_check.py` で10角形の頂点・周方向の連続性・0.05秒の立ち上がり・0.18秒の復帰・15倍拡散を検査し、v206/v216/v217/v218の既存テストを新仕様と整合させます。Android実機での描画は未確認です。
