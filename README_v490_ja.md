# SERA v490 — 拠点メニューの床を画面全体へ連続表示

## 変更点
- 屋外俯瞰拠点の床面を1枚の不透明な256m×256mの金属床で覆いました。画面の上下左右に床の終端や背景の空白が現れないようにします。
- 継ぎ接ぎの金属プレートは地面の上に重ねて残します。既存のNEXUS建物・クレート自律巡回・SERA移動、カメラ追従、Android縦画面、描画方式は変更しません。
- 遠景床を大量のタイルインスタンスにせず1枚のBoxMeshで構成し、Androidの描画負荷を抑えます。床の見える範囲の拡大でSERAの移動可能領域を広げる変更はしていません。

## テスト
- `tools/base_exploration_runtime_check.gd` に、実Godotでカメラ追従範囲の左端・中央・右端と手前・中央・奥の9地点それぞれの**画面四隅**が連続床面上に投影される検査を実装前に追加しました。
- 既存の拠点↔NEXUS往復、クレート移動、戦闘、全CIテストは保持します。
- マージ後`main`のCIを実施します。実機では上下端・左右端の床欠け、金属プレートの隙間、FPSをご確認ください。
