# SERA v237 — 頭部＋四脚の部位破壊、自動ターゲット切替

## 敵モデルと部位
- 既存の赤い2m胴体に、頭部（HEAD）と4本の脚（FRONT L/R、REAR L/R）を追加。
- 破壊可能な5部位に独立の耐久値／被ダメージ防御率／破壊力防御率／破壊済みフラグ。
- 頭：耐久38、通常防御20%、破壊防御10%、破壊後は暗色の損傷モデルへ変化。
- 前脚：各耐久30、通常防御12%、破壊防御0%、破壊後は消失。
- 後脚：各耐久32、通常防御16%、破壊防御12%、破壊後は灰色の残存モデル。
- 胴体防御は各部位の中央値。HP配分基準は胴体50%、頭・四脚各10%（試作用データ定数）。全体HPの既存100を引き続きボス共有HPとして減らし、破壊耐久は個別。
- 破壊済み部位のロック・耐久追加減少なし。復活／トレーニング再開始時は全て初期化。

## 攻撃判定・怯み・破壊
- 一度の命中で、装備の`attack_damage`をボス共通HPへ、`break_damage`をロック先の部位耐久へ**独立して適用**。
- 弱怯みは全体共通蓄積50で0.55秒、短時間内連撃で延長（既存仕様）。
- 部位破壊時は1.0秒の大怯み。**2本目以降の脚破壊時には3.5秒ダウン**。
- 頭部破壊でSHOCK/ARCは使用できず、選択中は予告つきAIMへ代替。
- ステップ、RUN、BOOST、EN、元のメレーモーション、実体コライダー、カメラの追従中心は維持。

## ターゲット変更
- 未破壊で視認可能な部位を機体前方に近い順で自動選択。0.13radの切替抑制。
- 通常移動では自動更新、格闘の追尾／3段／バッシュではロックを固定。
- ロック円は部位の位置へ移動し、格闘追尾の方向もその部位へ調整。敵全体を映すカメラは胴体のまま。
- 破壊直後はロックを一時解除し、攻撃状態終了後に別の有効部位へ再選択。
- 操作ジェスチャーの新設はなく片手操作のまま。
