# セラ v87 — バックステップ実装／ブーストとステップの明確化

## 追加・変更

- 添付 `SERA_backstep.bbmodel` の `Backstep` クリップを、**v86の既存モデル／既存10クリップを維持して**統合しました。統合済みの編集用モデルは `blockbench/SERA_v87_backstep_integrated.bbmodel` です。原本は `blockbench/SERA_backstep_user_input.bbmodel` に保存しています。
- **画面下方向へのフリック**で、現在ロックオンしている敵から真後ろへ**2.0m**移動し、専用 `Backstep` ポーズを再生します。操作上は「指を離した瞬間」に判定されます。
- 判定条件：タッチから **0.24秒以内**、下方向 **78仮想px以上**、平均速度 **500仮想px/秒以上**、横ぶれ **縦距離の42%以内**、折り返しが少ないこと。上方向のフリックは今回、ステップにはしません。
- 速度は左右ステップと同じ **8～10m/s**（敵の箱表面から2～5mの間で滑らかに変化）。2m後退に必要な時間は約 **0.20～0.25秒** です。
- 胴体の移動はGodot側の **CharacterBody3D衝突判定付き**で行い、Blockbenchのポーズにワールド座標の移動を加算しません。画面の左右位置やカメラの向きではなく、敵とプレイヤーの水平位置関係から後方を決定します。
- 左右ステップの円弧軌道・接敵カメラの角度保護はそのまま維持。後退は円弧を描かないため、左右用の近接カメラ角度保護を起動しません。
- Backstepは添付原本で**時刻0の18キーフレームからなる1ポーズ**です。開始時0.055秒、終了時0.11秒の既存ステップのブレンド処理を使用し、実際の後退時間中はこのポーズを維持します。複数ポーズの時間変化は追加していません。

## 操作の名称（今後の基準）

| 名称 | 入力 | 処理 |
|---|---|---|
| 通常移動（RUN） | ドラッグ距離168仮想px以内 | 最大3.25m/sの移動 |
| **ブースト（BOOST）** | 円の外までロングドラッグ | 移動速度1.5倍（最大4.875m/s）。移動中継続 |
| **ステップ（STEP）** | 左右／下方向に短時間でフリックし、指を離す | 8～10m/sの高速回避。左右は従来の円弧軌道、下方向は後退 |
| 格闘接近（MELEE APPROACH） | タップ攻撃の射程外からの接近 | 既存 `meleeboost` の格闘専用モーションを使用。ロングドラッグのブーストとは別処理（内部状態 `MELEE_APPROACH` として区別） |

※「ロングドラッグ」は、従来のコントローラ円外まで**長い距離をドラッグすること**です。時間のしきい値は追加していません。ステップ判定は引き続きリリース時に行います。
