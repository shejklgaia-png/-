# SERA v182 — 追尾時間短縮・振りかぶりループ・命中まで追尾

## 新しい追尾時間
| 攻撃・ブースター | 攻撃開始前の最大追尾時間 |
|---|---:|
| 通常格闘1段目 + Aブースター | **0.4秒** |
| 通常格闘1段目 + Bブースター | **0.6秒** |
| シールドバッシュ（A/B共通） | **0.2秒** |
| 格闘2段目 | **0.2秒** |
| 格闘3段目 | **0.2秒** |

- 装備別の追尾速度はA=11.5m/s、B=9.5m/sのままです。追尾EN消費もv181の16EN/秒×ブースター消費補正を維持します。
- 表の制限時間は**攻撃を開始できる距離に入るまでの追尾期間**です。**攻撃を開始した後は、命中するか既存の攻撃モーションが終了するまで敵位置を追い続けます**。無限時間の追尾にはせず、攻撃モーション終了で空振り扱いとします。

## バッシュ（0.2秒）
- ガードからの前フリックと3段コンボからの前フリックの両方に適用します。
- 対象が射程外であれば、実際の `Bash` モーションの**0秒〜0.20833秒の振りかぶりキーフレーム区間**を往復ループしながら、毎フレーム更新される移動ターゲットの位置を追います。
- **射程内に入った瞬間**にループを解除し、実際の `Bash` モーションを0.20833秒のキーから再生して打撃へ移ります。すでに射程内なら追尾0.2秒を待ちません。
- 発動後も未命中で敵が動けば追尾を継続し、打撃時刻0.25秒以降、モーション終了まで毎フレーム命中判定します。命中した時点で追尾停止。射程外のまま0.2秒経過した場合は中断し、**空振り用の遠距離攻撃を発動しません**。

## 格闘
- **1段目：** 既存 `meleeboost` 準備モーションの後、A/Bブースターの追尾時間で移動。射程到達で `melee1` 開始。打撃中も未命中なら追尾を続け、接触したら即終了。攻撃判定は従来の刃スイープと距離補助を維持します。
- **2段目：** `Melee2` の0〜0.08333秒の振りかぶりキーを往復ループして最大0.2秒追尾。射程到達後、0.08333秒のキーから攻撃部分へ移り、当たるまで（またはモーション終了まで）追尾します。
- **3段目：** `Melee3` の0〜0.20833秒の振りかぶりキーを往復ループして最大0.2秒追尾。射程到達後、0.20833秒のキーから攻撃部分へ移り、当たるまで（またはモーション終了まで）追尾します。
- 2・3段目は追尾中に射程内へ入れなければコンボ終了。ヒットストップ・キャンセルキーフレーム・3段目からのバッシュ派生は維持します。

## キーフレーム検証
- `assets/sera_source.json`（Blockbench原本）の `Bash`, `Melee2`, `Melee3` の実際の時間キーを調べ、上記3つの追尾ループ終点を採用しました。モデルのキーフレームそのものは変更しません。
- `scripts/sera_rig.gd` の追尾中は0→終点→0の**折り返しループ**を再生し、射程内に入ると0.025秒の姿勢補間を挟んで攻撃部分へ移ります。ループ中に攻撃判定は発生しません。

## 実機確認
1. GitSyncでmainを同期して `SERA v182` を起動。
2. TRAINING `MOVE: ON` でA/Bブースターの通常格闘1段目の追尾時間差を確認。
3. ガード前フリックで、敵が遠いときはバッシュの振りかぶりループ、近いときは即発動することを確認。
4. 3段コンボをつなげ、2・3段目も敵が離れた場合は最大0.2秒追いながら固有の振りかぶりキーをループすることを確認。
5. 打撃モーション中に敵が離れたとき、命中までは追尾、命中後は追尾停止、モーション終了で空振り終了することを確認。
6. EN不足、時間切れ、ステップによるキャンセル、シールドブレイクでも追尾状態が残留しないことを確認。
