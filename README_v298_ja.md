# SERA v298 — 本体も頭・四脚と同じ交差判定でAUTO選択

## 自動ロックの変更
- カメラから敵本体中心までの**有限線分**が交差する可視メッシュを対象とします。
- **BODY**も実際の赤い`FloatingBox`（2m×2m×3.4m）の`BoxMesh`を判定します。未破壊の頭・脚のメッシュと同じく、ローカル空間で`AABB.intersects_segment()`を実行します。
- BODYと頭・四脚の交点をすべて**カメラからの距離**で比較し、最も近い交点を持つ対象を選びます。BODYは候補に交差した場合だけ選ばれ、他部位がなかった場合の強制デフォルトにはしません。
- BODYは内部ID`""`を維持し、HUD・既存攻撃の本体判定を変更しません。
- BODY⇄部位間も、両者が線分と交差している限り、既存の**0.22秒の切替確定**を利用します。現在の対象が線分から外れた場合や破壊された場合は直ちに再取得します。
- カメラ→本体中心の線分は通常BODYを貫きますが、**前にある頭・脚が先に交差すれば、その部位が選ばれます**。

## 維持する仕様
- v297の頭部専用上方1.0mロック判定、脚の実メッシュ交差、破壊部位の除外。
- 攻撃中および派生受付中のロック保持・追尾補正、攻撃用AABB、MANUAL左右切替、カメラ追従、HUD・表示。
- 物理衝突、敵モデル・モーション、装備・スラスターには変更なし。

## 検証
- BODY実メッシュの交差、HEAD/BODYの近い交点の優先、同時交差での安定化、BODYからHEADへの移行と離脱をGodot実行テストで確認。
- 旧v296のBODY→HEAD即時切替テストは新しい「両方交差なら0.22秒」の仕様へ更新。その他の既存回帰テストは維持。
- Android実機でのロック遷移・表示は未検証です。
