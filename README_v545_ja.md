# SERA v545 — ビットタラン「なぎ払い」に添付音源のループSEを追加

## 2026年11月22日の更新

- ユーザーが添付した約20秒のうなり系SEから、周期約4秒のループ1周期を抽出して継ぎ目を補正し、Android向けにOgg Vorbisで同梱しました（モノラル16kHz、約4秒、Godot埋め込み形式で初回アセットインポート待ち不要）。
- **なぎ払いの実際の部位当たり判定が有効になった瞬間**に、専用SEを再生開始。前足は元モーションの**0.67〜1.38秒**、後足は**0.17〜0.63秒**が当たり判定有効区間です。左右とも同一仕様です。
- 当たり判定中は**等速1.0倍・音量+2.0dB一定・ソースループ有効**。セラへの攻撃ヒットが1回確定しても、実際の脚部当たり判定が継続する限り鳴り続けます。単発SEを毎フレーム繰り返す方式ではありません。
- **判定が終了したフレームから3.0秒で線形音量フェード**。音量0になると専用音声プレイヤーを停止し、フレームごとに再生位置をリセットしません。フェード中に再びなぎ払い判定が始まれば、同じプレイヤーを再利用し等倍・+2.0dBへ直ちに戻します。新しいバトルでは停止・初期化します。
- なぎ払いの既存ダメージ（1ヒット）、実脚のメッシュ判定、カメラ揺れ、土埃、武器・AIと物理攻撃原本には変更を加えていません。踏みつけ/弾き/ダウン・元の4種SEも保持しています。
- 並行BASE更新で戻っていた歩行音は、前回承認された**-13dB・同時2音**の値に再調整し、攻撃SE+4dBとBGM-8dBは保持しました。
- テスト先行：`tools/bittaran_sweep_audio_v545_self_check.py`で音源形式、4脚のソース時刻、音声ループ機構、3秒フェードを固定。 `tools/bittaran_sweep_audio_v545_runtime_check.gd`で、実Godotの当たり判定開始/終了、ヒット済みでも継続、3秒で停止、再開、リスポーン初期化、音量を検証。従来のカメラ・SE/ダウン回帰検査は保持しています。
