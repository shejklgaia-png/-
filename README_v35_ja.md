# セラ v35 — 板の描画を除去した切り抜き斬撃

## 修正内容
- **元のSwordeffect平面は常に非表示**。アニメーション用の骨のみ再利用します。
- 元の2Dテクスチャの透明領域を含む全面クワッドを廃止。アルファのある8x8pxタイルだけを描画するメッシュに変更しました。
- **Godot標準のStandardMaterial3D**で白色のアルファ透過を行い、斬撃用のカスタムシェーダーを使用しません。
- ターゲットの立方体と画面上で重なった部分のみ、CPUで頂点ごとの透明度を算出。初期値は58%で、フレーム切り替え時に更新します。
- 立体レンズは元の8フレーム立体メッシュを使用。裏側半透明、白色、個別粒子も残しています。
- プレイヤーの前景描画パスはv34から変更していません。
- 前方0.55m、BlockbenchのSwordeffectアニメーション、攻撃、当たり判定、カメラは維持。

## 画面表示の確認
1. ターゲットの左右どちらにいても、斬撃が**灰色の長方形として表示されない**こと。
2. ターゲットと重なる部分も、白い弧が58%の強さで見えること。
3. プレイヤーの上に斬撃が重なっていないこと。

## 位置調整・見た目
- `scripts/sera_rig.gd`：前方オフセット0.55mを維持。
- `scripts/sword_trail.gd`：`target_overlap_opacity = 0.58`（重なり部分の表示率）、`volume_opacity = 0.38`。
- `enable_target_fade = false`にすると重なり部分の透過を無効にして原因を切り分けられます。
- `show_lens = false`で立体部分のみを一時非表示にして比較できます。

## 検証と制約
- ZIP・8画像の寸法/アルファ・メッシュタイル・Godotの参照・既存スクリプトとの差分を静的検査。
- **GodotアプリとAndroid実機でのゲーム起動・描画検証は未実施**。
- 透明度の切り替えはUVアニメーションのフレーム更新時です。フレーム内でカメラが動いても次の切り替えまでマスクは固定されます。
- v34の3D効果は引き継ぎますが、完全な画素単位の正確なマスクではなく、頂点単位の近似です。
