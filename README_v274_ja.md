# SERA v274 — 3段目後の後ろフリックでサマーソルトキック（Kick_b）

## 操作
- 通常格闘3段目（`Melee3`）の再生中、または**3段目完全終了後0.65秒以内にタッチ開始**した場合、画面下方向を中心とする90°セクターへの短いフリックで`Kick_b`を派生します。
- 判定の入力軸は**画面基準**です。セラがどちらを向いていても、画面下方向のフリックは後方サマーソルトになります。**着地・移動方向**はロックオン中のセラ自身の後方（敵から離れる方向）です。通常の後方STEPや前方Bashとは別の技で、同じ入力を二重に発動しません。
- 3段目の振り抜き中のフリックは**予約**し、`Melee3`を最後まで再生してから発動します。従来の左右蹴り、バッシュ、3連撃、通常STEPは保持します。
- フリックの入力長・速度は既存のコンボ蹴り判定（最大0.42秒、30px、200px/s）を使い、ガード・被弾・EN不足などの禁止状態では開始しません。

## 動き・攻撃
- **後方移動：4.0m**。ロックオン中のセラから敵へ向かう水平ベクトルを反転し、`_move_player_swept`による衝突付きの後方移動を行います。遮蔽物は通り抜けません。
- **飛行時間：0.80秒／最高到達点：1.50m**。飛行進捗`p=0..1`に従い、後方距離`4p`、高さ`1.5 sin(πp)`の滑らかな弧を描きます。地面への帰還後は着地動作へ移ります。
- **着地：0.20秒**。`Jump`のユーザー制作済み着地区間（元タイムラインの0.375～0.500秒）を0.20秒へリタイムし、直後に立ち姿勢へブレンド。従来の普通の`Jump`は0.125秒着地＋0.60秒ホールドを維持します。
- キックは飛行の前半に敵の判定範囲に接触すると**1回だけダメージ**を与えます。初期実装は左右蹴りと同じダメージ・EN15・部位破壊・怯み値を暫定流用します。ダメージ・ガード破壊等の受付では通常のダメージモーションを優先し、宙に浮いた状態が残らないようにします。

## 原本の状態と暫定表示（重要）
2026-11-12時点のGitHub `main`では、標準の`assets/sera_source.json`、`models/storage/SERA_BOOSTER_allテスト (9).bbmodel`および他の統合候補に**`Kick_b`というアニメーションが存在しません**。`Kick_l`・`Kick_r`は存在しています。

したがって、現状の**モデルの回転／姿勢は暫定動作**です。既存の制作済み`Jump`の飛行部分を使い、セラの表示モデルを1回転させてサマーソルトを表現します。原本データを捏造して`Kick_b`として登録せず、HUDには`KICK BACK | Jump FALLBACK`と区別して表示します。

今後、ユーザー制作の`Kick_b`が原本へ追加されて`sera_source.json`へ統合されるか、Godotが読み込める著者用`.bbmodel`として反映された場合は、`SeraRig.has_back_somersault_clip()`が実際のキーフレームを検査してから**正規の`Kick_b`を優先再生**します。原本のモーションでは余計な1回転回転補正を加えません。移動弧と0.2秒着地は共通です。

## 再発防止・検証
- `tools/v274_back_somersault_self_check.py`で、後方フリックが通常STEP／前方Bashより先に拾われること、3段目中の予約、4m後退、1.5m弧、0.8秒飛行、0.2秒の着地、回転のリセットと被弾時の解除を静的に検証。
- `tools/v274_back_somersault_runtime_check.gd`でGodot 4.7.2の**実際のメインシーン**をロードし、フリック方向の判定・飛行中の物理位置・最高点・着地の0.2秒区間・立ち姿勢への復帰を確認。
- 既存の`tools/sera_animation_runtime_smoke.gd`（全統合モーション）および`tools/v273_kick_lookup_runtime_check.gd`（左右蹴り）も同時に維持。

Godot headlessの実行検査はAndroid実機での操作感・描画を確認するものではありません。実機上の`Kick_b`元モーションの再生は、原本がGitHubへ反映されてから別途確認が必要です。
