# SERA v149 — 360°フリースワイプ移動とロングドラッグBOOST（2026-11-09）

## 操作
- **タップ**：従来どおり近接攻撃。
- **ドラッグ**：指を動かした直近の方向へ、360°どの角度でも**一定RUN速度**で移動。反対側へ少し動かせば即座に逆走できます。指を止めても進行方向を維持し、離すと停止。
- **進行方向へ長くドラッグ**：同じ方向へ約140pxを積算すると**BOOST**に切り替わります。押し続ける時間ではなく、指の実移動距離で判定します。
- **大きな方向転換**：約50°以上の向き変更でBOOSTを解除してRUNへ戻します。新しい方向に140pxドラッグすると再BOOSTできます。
- **ガード・フリック回避**：従来の0.32秒静止ホールドによるガード、および指を離した時のフリック回避を維持します。BOOSTしたジェスチャーからの回避誤発動は抑制します。

## 新しいコントローラ
固定の168px円盤とアナログノブを廃止し、指の上に追従する小さな方向矢印とブースト蓄積を示す円弧へ変更。BOOST中はシアンの枠・二重山形マーク・`BOOST x1.5`で明示します。ロックオンリングと操作領域背景は変更しません。

RUNは4.0625m/s、BOOSTは6.09375m/sで固定。速度調整スティックはありません。方向表示を速くするため、RUN・BOOSTのモーション方向補間時間も短縮しています。

変更点：`scripts/main.gd`、`scripts/touch_overlay.gd`、`scripts/sera_rig.gd`。検査：`tools/v149_free_swipe_control_self_check.py`。GodotエディターとAndroid実機での入力感・描画は未検証です。
