# SERA v155 — 高速反転の速度判定を厳しく

v154で追加した「反対方向へ素早く指を動かすと即座に方向転換する」操作の**速度しきい値のみ**を変更しました。

| 項目 | v154 | v155 |
|---|---|---|
| 必要な平均移動速度 | 520px/秒 | **800px/秒** |
| 反転角度 | 約143°以上 | 変更なし |
| 判定時間 | 120ms以内 | 変更なし |
| 指の移動距離 | 32px以上 | 変更なし |
| 判定開始時の半径 | 25%以上 | 変更なし |

ゆっくりした戻し操作では固定起点のアナログスティックとして動作します。円形コントローラ、RUN速度のアナログ入力、BOOSTの125%開始・110%解除、攻撃・ガード・回避、セラのモーションは維持しています。

数値・静的回帰検証のみ行いました。GodotやAndroidでの実機操作感は未検証です。
