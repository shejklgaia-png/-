# セラ v50 — ターゲットに物理的な当たり判定を追加

## 変更点

- プレイヤー本体を `CharacterBody3D` に変更。半径 **0.40m**、高さ **1.85m** の立ち姿のカプセル型 `CollisionShape3D` を付与。
- ターゲットの視覚的な **2.0×2.0×2.0m** の箱と同じ形状の `BoxShape3D` を持つ `StaticBody3D` を追加。
- プレイヤーの `collision_mask=2`、ターゲットの `collision_layer=2` で物理判定。床はビジュアルのみで、従来通り無限に移動可能。
- **通常のドラッグ**： `velocity` + `move_and_slide()` に変更。ターゲットの面に当たった場合でも、面に沿って左右移動可能。
- **左右フリックの円弧ステップ**：予定座標へテレポートせず、フレームごとの変位を `move_and_collide()` でスイープ。衝突したら残りの運動を壁面に沿ってスライド（最大3回）。衝突で元の予定軌道から外れる場合があります。
- **攻撃中の自動接近**：既存の「箱の表面から0.75m」の停止判定を維持し、実際の移動も `move_and_collide()` 経由に統一。
- **非移動時**：`move_and_slide()` を呼び、すでに重なった位置での押し戻しを試みます。
- 右上の `LAST` 表示は**実際に移動した距離**を集計するよう変更。衝突で短くなった場合は計画距離と異なります。

## 維持した仕様

- ステップの希望移動速度 **10.0m/秒**、希望円弧長 **1.5～4.0m**、基本角度 **35°**、所要時間の上限 **0.40秒**。
- ステップの距離は障害物がない場合に保証されます。物理衝突がある場合は実際の移動距離・速度が小さくなることがあります。衝突を無視して1.5m移動させることは**しません**。
- 左右ドラッグ、フリック判定、プレイヤー向き、ロックオン、カメラ、攻撃モーション、剣エフェクト、モデルを維持。
- 当たり判定はプレイヤーの**胴体中心を囲うカプセル**に設定。アニメーション中の剣・手先・腕まで各パーツ単位でブロックするものではありません。

## 確認について

`python tools/v50_collision_self_check.py` で静的構造、物理レイヤー、移動経路のスイープ処理、既存の入力・カメラ・アセットの同一性をチェックします。Godot本体とAndroid実機での実行は本環境では未確認です。
