# SERA v529 — 倉庫2列/素材3列・個体ごとのランダム追加性能

## 今回の実装
- 装備倉庫はカテゴリ（頭部・胴体・腕部・脚部・ブースター・右手・左手）別に切り替えます。各ハンガー上限999個で、同一設計図でも製作個体を別カードとして扱います。
- 装備個体カードは縦スクロールの2列。左に正方形アイコン、右に装備名・UID・5件の追加性能を縦表示します。装備がなくても空の枠を表示します。
- 素材は系統ごとに低・中・高を横3枚にして4系統を縦方向に並べます。個数表示は維持します。
- 倉庫の素材・装備カードは共通の暗いブルーグレー色、四隅を斜めに切り欠いた9-slice枠、白文字、日本語を優先するデジタル系システムフォントを採用。その他LABOの角丸操作ボタンは維持します。
- 製作に成功した装備個体には、8種類の候補から重複しない追加性能5個（各+1〜5%の暫定値）を抽選して個体データへ保存します。新しい5個はリロード・装備切替では再抽選されず、モジュール装着スロットとは独立します。旧装備の値は勝手に再抽選しません。
- 倉庫・製作カタログから集約の「所持×N」を削除します。素材個数、ハンガー容量は引き続き表示します。
- 新たな追加性能の**戦闘パラメーターへの適用は別段階**です。未承認の戦闘バランス値を自動変更していません。

## 軽量化
- scripts/sera_warehouse_grid.gd はScrollContainer内で標準Buttonの有限プール（最大32）を使い回します。999個のデータに比例してUIノードを生成しません。描画対象を変更するのはスクロール行が切り替わった時とカテゴリ変更時です。
- 32×32の切り欠き枠テクスチャは描画状態ごとに一度だけ生成し、全カードで共有します。アイコンは既存の共通アトラスを参照します。
- Android Godotエディター固有の不可視カード問題が過去に発生しているため、実機確認はGitHub CIと別です。

## CI・互換
- tools/sera_ci_manifest.txt に新しいv529静的・実Godot検査を登録。旧CIの倉庫カード数・所持数・丸角前提を新仕様に更新し、既存の製作・素材変換・3D研究室・クレート演出の検査を維持します。
- UID連番・原子的保存・既存のスキーマ2形式と旧装備データは維持します。
