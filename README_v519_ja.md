# SERA v519 — シールドの八角形を少し横長に

## 変更点
- テストターゲット・ビットタラン共通の**正八角形のシールドフレーム6層と中央の埋まった八角形**について、横方向だけ**1.15倍**に調整。縦方向は維持します。
- 同じ中心を基準に左右へ均等に拡張し、厚みのある八角形の輪郭も横長になります。
- シールドの6層・8辺・外側ほど薄い透明度、展開0.2秒→維持0.2秒→消滅0.2秒、破壊時の大きなガラス片14個、素早く消える左右稲妻、破壊SEは変更しません。
- 攻撃判定・100SP・近接/射撃軽減・回復、HPバー非重畳、他の拠点/LABO/製作UIは変更しません。

## CI
実装前に既存のv516八角形CIへ**横:縦=1.15±0.015**の形状検証を追加し、実GodotのImmediateMeshの画面投影頂点から横長比率を計測する仕様としました。従来の全回帰テストを残したまま、mainへマージ後のフルCIで確認します。Android実機での見え方・体感は別途確認してください。
