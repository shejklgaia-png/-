# SERA v424 — ビットタラン新モデルと左右前脚攻撃テスト

## 今回の実装
- 新しいビットタランの胴体・四脚・砲台・眼球のメッシュを採用します。砲台は胴体固定、眼球はHeadに追従します。
- 元の歩行・旋回アニメーションとAI・接地IKは維持します。
- 左右前脚だけが「なぎ払い」「弾き」「踏みつけ」を実行します。Blockbench原本の左右それぞれのキーフレームを再生し、従来の前後反転・方向追尾・伸縮処理を攻撃中の脚へ重ねません。
- 後脚からの攻撃はテスト中は停止し、移動時の後脚の歩行と旋回は維持します。
- 頭部（眼球）はプレイヤーに向かい、左右・上下それぞれ最大90°まで追従します。頭部と脚の干渉回避補正は行いません。

## 検証
- 新モデルの14関節と左右6攻撃クリップを構造検査します。
- Godotの攻撃キー読込・再生と歩行・旋回・頭追尾を自動検査します。
- Android実機での映像とプレイフィールは未検証です。
