# SERA v176 — CONFIRM点滅の両色を通常ボタンより明るくする

## 色変更
SYSTEMの確認ボタン（CONFIRM SAVE / LOAD / NEW / DELETE）の点滅について、
従来は暗い方の位相が通常ボタンとほぼ同じ色になっていました。
今回は**点滅中の明暗どちらの背景色も通常ボタンより明るく**しています。
これにより、確認待ちの途中でキャンセルすると、ボタンが暗い通常色へ
即座に戻り、解除されたことが見分けられます。

- 通常時（キャンセル後）：`_menu_style()`の暗紺色、RGB(0.018, 0.035, 0.060)
- CONFIRM・明：RGB(0.14, 0.39, 0.50)、枠線 `#e5fbff`
- CONFIRM・暗：RGB(0.075, 0.21, 0.30)、枠線 `#7cd6f0`
- 0.38秒ごとに2色を切り替え（1周期0.76秒）。文字は常時表示。

## 操作・範囲
CONFIRMボタン以外の空白や他ボタンを押すとキャンセル、
対象CONFIRMボタンを再タップした場合のみ実行するv175の仕様は維持。
**確認対象のボタンだけ**色変更し、他のアクションボタンやスロット選択枠、
保存ファイル、LOAD動作、DATA ARCHIVE、トレーニングなどには影響させません。

`tools/v176_confirm_colors_self_check.py`は静的ソース/色比較テストです。
Godot構文解析およびAndroid実機での視認性は未検証です。
