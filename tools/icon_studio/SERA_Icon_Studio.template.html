撮影設定の保存先はこのブラウザの端末内ストレージです。別の端末へ移す場合は「設定JSONを保存」を使ってください。

使い方
  1. HTMLを開くと原本モデルが自動表示されます（読み込み操作不要）
  2. ドラッグ・ピンチで好きな角度・大きさにする
  3. 「設定をコピー」→ ChatGPTのこの会話へ貼り付ける
  4. 「透過PNGを保存」で装備情報入りPNGを保存する。別チャットではこのPNGだけを送信できます

※ブラウザからChatGPTへメッセージを勝手に送信することはできません。コピーしたテキストをこの会話に貼り付けて送信してください。
