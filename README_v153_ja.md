# SERA v153 — 固定式アナログスティック操作へ復元（2026-11-09）

v149〜v152の「直近の指の動きで進行方向を決めるフリースワイプ方式」を取り消し、**v148の操作方式に戻しました**。

- タッチ開始位置を中心にした半径168pxの仮想スティックで方向・アナログ入力強度を指定します。方向変更はタッチ開始位置を起点に判断します。
- 半径100%でRUN速度が最大になり、それより外側でもRUNの入力強度は上昇しません。
- 半径125%以上へ押し出して0.10秒維持するとBOOSTが始まり、110%未満へ戻すと解除されます。BOOST速度の切替は0.15秒の補間です。
- 従来の円形コントローラと、BOOST中148%位置に表示されるノブを復元します。
- v148の移動速度1.25倍設定は維持します（RUN最大4.0625m/s、BOOST最大6.09375m/s）。
- v151で改善したセラ本体のRUN/BOOST方向モーション・滑らかな旋回は維持します。
- タップ攻撃、長押しガード、指を離した時のフリック回避、メニューなどは変更しません。

対象コード: `scripts/main.gd`、`scripts/touch_overlay.gd`（v148から内容を復元）、`project.godot`（名称）、`DEVELOPMENT.md`（履歴）。フリースワイプ用v149〜v152の検査スクリプトは履歴保存用です。GodotやAndroid実機での動作は未検証です。
