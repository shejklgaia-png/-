# SERA v430 — ビットタランの骨格接続を保った胴体降下によるなぎ払い

## 設計変更
- **足先・下肢を水平にするための後付け回転は削除しました。** 下肢メッシュだけの回転、軸周りの旋回探索、足先の強制ワールド水平回転を行いません。
- 胴体、上肢、下肢、足先のNode3D親子関係・Pivot・メッシュの初期角度は不変です。
- なぎ払いアニメーションの各フレームの原本ローカル姿勢から開始し、胴体を下げた場合の足先角度を「上肢＋下肢の2リンクIK」で試算します。足首の相対回転を固定するため、足先の方向は胴体降下と自然な関節屈曲の結果としてのみ変化します。
- 胴体の複数の高さを床との距離と足先の傾斜で評価し、無理な関節やねじれを使わずに水平に近づく姿勢を求めます。完全な水平が物理的に不可能なら近似を選びます。
- 2リンクの各IK再試行では原本の関節回転・上肢と下肢の軸を毎回復元し、基準軸から目標軸への最短回転のみを適用します。前フレームの角度を足し込まず、軸回転の蓄積を防ぎます。
- 胴体の下面が床へ埋まらないように制限し、脚→胴体の順序で復帰する仕様と踏みつけを参考にした足先の持ち上げ復帰を維持します。

## 技術的な区別
- 胴体を平行移動させるだけでは、固定された足首のワールド角は変わりません。**接地目標に対して股関節・膝を屈曲させ、原本の足首ローカル回転を保持する**連動IKが必要です。
- 足先を水平に回す命令、下肢メッシュを独立して水平に置く命令はありません。実モデルの長軸と床の角度を計測するのは評価とテストのみです。

## 検証
- v430は左右のなぎ払いを各2回再生し、足先の傾斜・床接近、関節Pivot・メッシュローカル回転の不変性、同時再生の軸方向と次回攻撃の一致、胴体高さリセットを確認します。
- Android実機の見た目や滑らかさは別途確認が必要です。
