# SERA v530 — 視点依存の80°エッジ・外周輪郭線

## 今回の実装
- キャラクターSERA、訓練ターゲット、ビットタランの実体メッシュに外周線とハードエッジ線を追加。
- 視点依存の外周シルエットと、手前の部品が奥の部品を隠す段差輪郭だけに線を表示します。**両面がカメラを向く四角形の手前角は、面同士が80°以上でも非表示**です。80°の角度情報は保持していますが、角度だけで線を強制しません。
- 線は暗いブルーグレー（#17212f）、画面上の幅3px（初期1.6pxから調整）。前面の装甲や地面に隠れた線を透過させず、SERAの装備変更とビットタランの関節/IKに追従します。
- 原本のBlockbenchモデル、シェーダーマテリアル、攻撃・衝突・ロックオン・操作・セーブデータを変更しません。

## 軽量化と検証
- 面の接続関係と80°判定は初回だけCPUで解析し、GPUシェーダーが各フレームの視点から描画/非描画を決めます。
- 同一Meshはキャッシュを使用し、装備の追加/交換は0.75秒ごとにスキャン。毎フレームのCPUによる全ポリゴン検査はしません。
- [仕様と既知の制約](docs/SERA_VIEW_DEPENDENT_EDGES_ja.md) に、別メッシュ接合部の視点依存線除去の限界とAndroid検証項目を記載しています。
- 新CI：`tools/sera_view_edges_self_check.py` および `tools/sera_view_edges_runtime_check.gd` を先行追加しました。79°/81°、専用Mesh/Shader、深度契約を検査します。

## v529から引き継ぐ機能
- 倉庫は装備カテゴリ別に各999個まで保存、2列の個体カードを縦スクロール。素材は同系統の低/中/高を横3枚に表示します。
- 製作した装備個体ごとにランダム追加性能5件を保持し、個体UIDに保存。装備の追加効果モジュールとは別です。
- 装備・倉庫・ラボのUI最適化や各種既存ゲームプレイは維持します。
