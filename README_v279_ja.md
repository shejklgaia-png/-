# SERA v279 — サマーソルトキックのモーション完走

**原因**：従来の処理では、0.8秒の飛行の最終tickで `Kick_b` の最終キーフレーム時刻へ更新した直後、同じtickのうちに `Jump` の着地モーションへ切り替えていました。このため最後の姿勢が描画されない場合がありました。

**修正内容**
- `Kick_b`は原本0.79167秒の**終端時刻ちょうど**まで再生（従来は終端-0.0001秒）。
- Godotが最後の姿勢を全身の骨格へ適用し、フェードが完了したことを確認してから着地へ移行します。最後のフレームを未描画のまま上書きすることはありません。
- 低フレームレートで物理tickだけ進んでも、移動は0.8秒・後方4m・最高1.5mで終了し、その位置で最後の姿勢を保持します。追加移動や当たり判定の再発火はありません。
- 最後の姿勢から着地への0.055秒クロスフェードを付与します。着地モーション自体の0.2秒は維持します。
- 通常ジャンプ、左右蹴り、バッシュ、スラスター、入力操作やモーション原本は変更しません。被弾／KOによる中断時には完走待ちを解除します。

GitHub CIで実際のGodotリグ・物理処理・描画姿勢・着地と中断動作をテストします。Android実機の画面での確認は未実施です。
