# SERA v194 — 下半身Dが標準足に見える問題の修正

## 原因
v193で`足C.bbmodel`の12メッシュは登録済みでしたが、腰・腿・膝下をすべて標準Aの外接寸法の約110%へ個別に縮めていました。特に装甲が広がる腿の幅までAの幅とほぼ同じになり、**元モデルのシルエットが失われていました**。

加えて、原本の各面には0～16のUVが付いていましたが、ゲームの読込器は96×32のセラ共通パレットへUVを割り当てる仕様です。元のUV値をそのまま使うと、面によって必要な濃淡が失われます。

## 修正内容
- 新しいLOWER BODY **D**に限定し、原本の相対的な装甲配置・張り出しをより残すスケーリングに変更しました。腿はAの約2.1倍の幅（原本の大型二重装甲を再現）、ただし全体の左右外縁はAの標準足幅に近い位置に収めます。腰と膝下は自然な接続を優先し、足先は指定どおり幅116%・高さ114%・前後112%を維持しています。
- Dの12メッシュの全6面について、向きに合わせてセラの96×32パレット用UV（4～92、縦4～28）へ変換しました。元の顔色・材質データには手を加えていません。
- CUSTOMIZATIONで**LOWER BODY=D**を選ぶ際、Dの登録が12メッシュ揃っていなければDを選択肢に出さず、エラーを記録します。正常に12メッシュが表示され、A/B/C脚が隠れていれば、Godotの出力に`SERA Lower Body D active: 12/12 authored meshes; A/B/bird hidden`と記録します。
- **LOWER BODY C=鳥足**、**LOWER BODY D=新しい人型下半身**、**HEAD C=頭C**という割り当て、およびセーブデータの移行、NEXUSの高さ補正無効、TRAININGの接地補正・足音は保持しています。
- 制作用原本`models/storage/足C.bbmodel`とA/B/鳥足Cのモデル、通常モーション、操作・戦闘コードは変更しません。

## 確認
1. GitSyncで`main`を同期し、Godotで`SERA v194`を開きます。
2. CUSTOMIZATIONのLOWER BODYをA→Dへ切り替え、腿の装甲幅と濃淡が変わることを確認します。
3. 足先もAより一回り大きく、腰・腿・膝下と同時に交換されることを確認します。
4. 必要に応じてGodotの出力で上記`12/12`のメッセージを確認してください。

**検査範囲**：GitHubの静的検査で、Dの新シルエット寸法・UVの範囲・元モデルの保持・データ埋込一致を検証します。Godot/Androidの実際のレンダリングは別途確認が必要です。
