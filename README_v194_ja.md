# SERA v194 — LOWER BODY Dの実装経路を専用化

## 変更内容
- 最新の制作原本「足C (1).bbmodel」を元に前段で整理した標準人型下半身を、カスタマイズの **LOWER BODY D** に専用登録しました。
- ゲームが使うモデル: models/storage/SERA_LOWER_BODY_D_STANDARD_READY.bbmodel
- 専用の実装時埋め込みデータ: assets/sera_lower_body_d_data.gd
- Godot側の scripts/sera_equipment.gd が、統合モデルのRoot順番を間接的に使う方式から、専用D下半身を明示的に読み込む方式に変更。モデルが読めないときは埋め込みを使用します。
- 同じDメッシュが旧統合モデルのWaist3と専用モデルから二重登録されることを防止。腰2・腿4・膝下2・足4の **12メッシュの登録件数**を検査し、不足した場合はD選択肢を無効にします。
- 標準Aの腰・腿・膝下・足首の既存Pivotとモーションに追従します。NEXUSのカスタマイズ画面・TRAININGで同じ装備セットDを使います。
- A・B、鳥脚C、頭C、既存セーブデータ（schema v2）、操作/戦闘/カメラ/音声は変更しません。

## 選択方法
1. Termuxの同期フローで最新mainを取得し、Godotを開き直します。
2. **SERA v194** のNEXUS → CUSTOMIZE → LOWER BODYで「D NEW」を選択します。
3. 下半身がA/B/Cとは別のメッシュで描画されることと、TRAINING/再起動後の保存内容を確認します。

## 注意
- 今回は実際のデータロード先を専用のDモデルへ変更しましたが、前段のv193で生成したA骨格用Dメッシュと同じ幾何データです。**元の更新は主にPivot調整であり、外見を変える編集ではありません**。そのため、以前指摘された「標準足と見分けにくい」という見た目自体が変わるとは限りません。
- Python/モデル構造の静的検査とGitHub CIは可能ですが、Android版Godotの画面・足のアニメーション・接地は実機での確認が必要です。
