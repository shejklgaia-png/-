# SERA v163 — BOOST⇄RUNの速度を滑らかに変更

RUNからBOOST、BOOSTからRUNへの**速度の変化を両方向とも0.20秒のイーズイン・アウト**に変更しました。従来の一定割合で変化する0.15秒の加減速よりも、切り替わり始めと終わりが滑らかになります。

| 切り替え | v162 | v163 |
|---|---|---|
| RUN→BOOST速度 | 0.15秒・直線補間 | **0.20秒・滑らかな曲線補間** |
| BOOST→RUN速度 | 0.15秒・直線補間 | **0.20秒・滑らかな曲線補間** |
| RUN速度倍率 | 1.0倍 | 維持 |
| BOOST速度倍率 | 1.5倍 | 維持 |
| BOOST解除後のモーション保持 | 0.50秒 | 維持 |
| BOOSTモーション→RUNモーション | 0.20秒クロスフェード | 維持 |

加速・減速の途中でBOOST判定が切り替わっても、その瞬間の倍率から反対方向への補間を開始するため、突然1.0倍／1.5倍に跳ねることはありません。

操作終了・ガード・ジャンプ時は従来どおり通常移動の速度状態をリセットします。BOOST入力の境界・360°操作・HUD・攻撃・カメラなどは変更していません。

静的コード検査と数値シミュレーションは実施。GodotエンジンとAndroid実機では未検証です。
