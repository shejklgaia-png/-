# SERA v403 — 弾きの発動方向の修正（伸びる最中の回転ずれを打ち消し）

v402の実機確認で「弾きがまだ変な方向へ発動する。回転？」との報告を受け、実シーンで計測して修正しました。ご指摘どおり回転が原因でした。

- **症状**：蹴り始めの瞬間は全脚とも狙いが合っているのに、脚が伸びていく最中に向きが回転し、伸び切った時点では左前−9°／右前−48°／左後−91°／右後+38°もプレイヤーからずれていました。足の進む方向で測ると最大約102°のずれでした。
- **原因**：肩の照準は予備動作中に「伸び切った姿勢」だけを見て角度を決め、打撃中は固定されていました。しかし左前脚の原本を他脚へ変換したモーションは、伸びながら脚の向き自体が50〜100°回転します（原本の左前脚は回転しません）。固定された照準では、この回転に付いていけませんでした。
- **修正**：打撃中とホールド中も、現在の姿勢の向きを毎フレーム測って照準を更新し続け、変換モーションの回転を肩の回転で打ち消すようにしました。狙う先は予備動作の終わりに固定された位置のままなので、プレイヤーを追尾するホーミングにはなりません。あわせて、予備動作中の照準サンプルを打撃時と同じ変換方式で測るよう揃えました（最大18°あった脚ごとのずれを解消）。
- **結果**：実際にゲームが選ぶ配置（前脚は正面の相手、後脚は背後の相手）で、足の進む方向のずれは全脚・全配置で **1.3°以下** になりました。
- **検証**：新規 `tools/v403_bittaran_kick_direction_runtime_check.gd` で、全脚の弾きの進行方向と伸び切った向きを検査します（修正前は左後91°などで失敗）。全件CIスイート（静的182件＋Godot 139件）が合格しています。Android実機での見た目は別途確認をお願いします。
