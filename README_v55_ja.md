# セラ v55 — コンパクトな上部HUD／視点角度を保ったカメラ位置の調整

## UI 再設計

- 画面上部の情報を横長の透過ダークパネルへ集約（初期720×1280ビューでは x=18〜702、y=26〜150）。旧HUDは最下部が約200pxでした。
- 左：SERA/LOCK、現在モーション、ターゲットHPと細いHPゲージ。
- 右：次のステップ速度（6/10m/s）、予定／前回のステップ実績、操作ヒント。
- 画面下の英語操作説明は廃止し、操作用の25%の余白に表示が乗らないように変更。
- トップパネルを起点とするタッチは戦闘入力として扱わず、その他の領域のタップ／ドラッグ／フリックはv54と同じです。
- 画面の左右幅の違いに対してHUD全体は上部全幅固定（左右18pxの余白）、右欄は右側アンカーを使用します。

## カメラ

- CAMERA_ELEVATION_RATIO=0.1325（v53／v54と完全に同じ）で俯瞰角度は変えません。
- CAMERA_FOCUS_DROP=0.90→1.35m（カメラと注視点をともに0.45m下げ、戦闘対象を画面内で上へ移動）。
- HUDとキャラクターが重ならないよう、上部安全域を14.5%へ変更。プレイヤー頭部／ターゲット8頂点の投影を使う既存の自動ズームアウトがこの範囲も保護します。
- 画面下25%の操作域、最短ズーム7.8m、通常のカメラ追従／マーカー追従／ステップ／衝突判定／攻撃は維持。
