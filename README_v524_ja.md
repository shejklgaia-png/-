# SERA v524 — 拠点施設のカード空白とタブ二重選択を修正

## Android実機で確認された現象
- SERA v523でも装備製作・素材変換・倉庫のカード欄が空白。
- 上部「装備製作」と「素材変換」が、順に押すと両方選択色になる。
- Linux上のGodotスクリーンショットではカードが描画できるがAndroid実機では表示できていない。Linux検査結果はAndroid動作を保証しない。

## 修正
- 施設メニュー上部の3タブ、倉庫の2タブにそれぞれ共有ButtonGroupを設定し、選択状態を相互排他に変更。
- 施設内カードを、手動座標計算する全画面オーバーレイから、上部タブと同じ**FacilityContentの直属**へ変更。
- 各アイテムは引き続きGodot標準Button＋HBoxContainerの3列構成。四隅欠け枠、アイコン、名前、所持数、全面タップを維持。
- 「製作」「素材変換」「倉庫」の内容は常に描画対象（装備7種・素材12種・倉庫素材12種と装備7種）とし、空きがあっても枠を表示。
- LABOのセーブ作成ボタンと素材受け取り、倉庫内切替の表示順は維持。セーブ・素材・UID・シールド・戦闘処理は変更していません。

## テスト
- 本体変更前に新しいv524排他タブ／縦レイアウト検査をCI登録。
- 旧v519/v523テストを新しい配置階層に合わせ更新。既存v511〜v523の機能検査も維持。
- 実画面撮影のOpenGLピクセル検査を保持し、表示位置・カード数・ボタン選択の単一性も検査。
- Android実機で空白が解消したかは、最新v524の実機画面で最終判定します。
