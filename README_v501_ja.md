# SERA v501 — 砲台発射時の十字閃光を5倍の長さにして前面表示

## 変更点
- ビットタランの腹部中央**1基の砲台**に付く銃口十字閃光の横・縦を、従来の **0.62m → 3.10m（5倍）** へ拡大。
- 十字の芯の太さを **0.047m → 0.135m** に変更し、さらに幅0.42mの半透明な青い発光ハロー（横・縦）を重ねる。中心発光球も拡大。白い芯と青い外周の二重十字にする。
- 十字を**実銃口の20cm手前（砲身前方）**に配置。発射の瞬間、**3Dの装甲や障害物に隠れない前面描画**で強調する。発光マテリアルを加算合成・透明描画・深度テストOFFにし、既存の描画規約`CHARACTER_FOREGROUND`(126)を使用。カメラ向きビルボードなので斜めからも十字が読み取りやすい。
- 視認性のため発光時間を **0.085秒 → 0.12秒**へ延長。発射フレームに点灯して縮みながら消灯する。攻撃中／ダウン中の停止時には即座に非表示にする。
- **十字の発光だけが前面描画の例外**。砲身、光弾、当たり判定、背部レーザー、セラ、床、他のエフェクトは従来の遮蔽や描画方法を維持。
- **不変**：1基の腹下固定、プレイヤー追尾、弾速17m/s、1.2秒間隔、攻撃中/ダウン中の射撃停止、ダウン中の追尾停止、既存のIK・攻撃/モーション・機体原本。
