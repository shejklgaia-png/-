# SERA v501 — 俯瞰拠点にLABOと資源・生産・発展設備を配置

## 実装
- メニュー型の既存NEXUSを右上側へ移し、左隣に**LABO**の独立した3D建物を建設。NEXUSの既存出撃・装備変更・トレーニング・データ・設定は移動/重複させない。
- フィールド上に**スクラップ回収機／精製炉／リサイクラー／発電機／資材保管庫／建設端末**を直接配置。専用のポリゴンモデル、施設名ラベル、カメラ投影によるタップ範囲を追加。
- 施設をタップすると拠点画面内に専用パネルを表示。LABOはShell（性能向上）・OS（機能拡充）・追加効果スロット研究の役割を分離し、関連情報にアクセス可能。タップ外側または「閉じる」で戻る。
- CRATEの巡回路と装飾品の配置を見直し、工場の中央通路を空ける。広域グリッド床、NEXUS画面遷移、非表示のセラ/コントローラ設定は維持。
- 発電機ローターは稼働アニメーション付き。透明描画を使わない不透明な立体を採用。

## まだ接続していないシステム
- 素材獲得量・精製比・消費量、電力容量、建築コスト、装備製作とOS研究の実際の進行は**未確定**。今回これらの仮数値・ダミー報酬は設定せず、施設の外観とタップUIのみを先に実装。
- 後から報酬・資源経済システムを確定させ、設備パネルの操作へ接続する。

## CI
- 変更前に`AGENTS.md`、`tools/sera_ci_manifest.txt`、`docs/SERA_ACTIVE_CI_POLICY_ja.md`、既存`tools/base_exploration_self_check.py`および`tools/base_exploration_runtime_check.gd`、描画規約、mainのGodotワークフローを確認。
- 本体実装**前**に独立した`tools/base_facilities_self_check.py`と`tools/base_facilities_runtime_check.gd`を作成、CIマニフェストへ登録。
- 新規検査は7設備の実ノード、射影タップ、モーダル開閉、NEXUSの現存を検証。既存の拠点/NEXUS/CRATE/床/非表示設定を検査するテストは改変せず保持。
- この変更は装備/戦闘値/STEP/ボス/モデル原本を変更しない。全Python/Godotテストはmainマージ後に既存Actionsで実行。Androidの視認性とタップ誤爆は実機で確認する。
