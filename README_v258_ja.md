# SERA v258 — セラ正面に戻す／90°×4方向フリック

**前方0°は画面に映るセラ本体の向きです。** v257のコントローラ発生位置からロックマーカーへのベクトルは使いません。

- 360°を90°×4方向：前0°、右90°、後180°、左270°。各方向は中心±45°、斜め操作は最も近い前後左右へ分類します。
- STEP、GuardからのBash、3段コンボ後のBashは同じ前方軸を共有します。Bashの有効範囲も**前方±45°**へ拡張します（旧±22.5°より広い）。
- 操作開始時に前方を保存。長押しGUARDの最後のフリック開始時は前方を取り直し、途中のカメラ旋回による不一致を防止します。
- 前ステップ3m、後4m、横2–4m、ステップEN/速度/モーション・衝突、v256のBash入力緩和（0.42秒、正面30px、200px/s、初動38px猶予）、追尾、RUN/BOOSTの連続操作、ロック表示、デバッグJumpは維持します。
- 共通方向クラス `scripts/flick_direction_policy.gd` の4セクター分類へ集約。過去バージョンの回帰検査も現行4方向仕様と矛盾しないよう更新しました。
- GitHub Actionsの静的・数値テストはAndroidでの入力感やGodotランタイム動作の代替にはなりません。
