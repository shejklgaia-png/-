# SERA v449 — ビットタランの20件の回帰不具合と検証条件を修正

## 実際のゲーム側で修正した問題

- **脚破壊から起き上がれない問題**：現行のsource-ground IK経路で転倒・起き上がりの時間更新が欠落していたため復旧しました。転倒中の歩行を抑え、起き上がり中の旋回を維持します。
- **起き上がった脚が追従しない問題**：立ち上がり直後に対角の脚を2組順に踏み直し、0.52秒の足運び中も胴体の位置・角度に応じて着地点を更新します。
- **初期姿勢で足先が浮く問題**：4脚それぞれの実メッシュの下面を調べ、二ボーンIKによる関節回転で床へ接地させます。骨長、関節Pivot、メッシュのローカル位置は変えません。
- **支え脚が攻撃後に沈み込む問題**：なぎ払い・弾き・踏みつけで、基本姿勢への補間により接地点が失われた支え脚を、関節IKで再拘束します。
- **視野外でも無理に歩く問題**：攻撃前3歩の制約があっても、視野の外なら先にその場旋回します。同じ種類の攻撃を連続しないための回り込みは維持します。
- **頭部の追従停止**：現在のsource-ground IK戦闘経路でも、衝突制限つきの頭部追従を実行します。

## 現行仕様に合わせた回帰検査

ゲームに存在しない後脚の弾き攻撃、廃止済みの固定0.34mしゃがみ、なぎ払い旧0.5倍速再生、逐次的な胴体→脚の復帰、旧IKの状態変数を要求するテストを見直しました。正常な動作を見逃さないため、骨格長・接地・実攻撃の終了・頭部追従・脚破壊・起き上がり・関節接続の検証は継続しています。

- **全10種類の合法な攻撃**と916回の原本関節姿勢サンプルをGodotで検査します。
- 新しい前後左右なぎ払いは、原本どおり1倍速で再生し、足戻しまでの動作と3本の支持脚の接地を検査します。
- プロジェクトの静的検証は、設定に記載された実際の起動シーンが存在するかを確認し、メニュー画面と現在のビットタラン戦画面の両方を正しい起動候補として扱います。
- CIの全Godot回帰テスト126件およびPython回帰テスト182件を確認対象としています。実行結果とマージ判断はGitHub Actionsのログを基準にします。
