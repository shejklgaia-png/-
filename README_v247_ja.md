# SERA v247 — 右下操作枠の明るい背景を完全削除

## 変更
- 右下に残っていた明るい灰色の四角形を廃止しました。v246で残したグラデーション多角形および下部の単色塗りつぶしを削除しました。
- その描画だけに使用していた定数を削除しました。操作用の背景は全画面で透明になります。

## 維持
- v246で復帰した「UIボタン部分を除く全画面から操作を開始可能」な仕様。タッチ開始位置を基準とする浮動コントローラー、ロック照準、波紋・フリックエフェクト。
- RUN半径70px、デッドゾーン11.25px、BOOST基準105px、開始/終了倍率110%/90%、確定0.10秒。
- 左右LOCK・AUTO/MANUAL・他ボタンの優先入力、ガード・攻撃・ステップ、既存の戦闘/カメラ動作。

## 検証
- 旧v243〜v246の検査を最新仕様に合わせて更新し、v247専用の背景非描画チェックをCIに追加しました。
- Android実機の表示・操作とGodot実行時の確認は別途必要です。
