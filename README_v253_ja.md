# SERA v253 — バッシュの画面上のセラ正面方向への統一

- 3段コンボ後のバッシュ、およびガードからのバッシュを固定の「上フリック」から **画面に投影されたセラの正面方向へのフリック**へ変更。
- セラの前方 `-player.global_transform.basis.z` をカメラで画面座標に投影。セラが画面右・左・斜め・下側を向いていれば、その方向へのフリックがバッシュ入力となります。
- タッチ開始時の画面上方向を保存。候補維持／最終確定／ガード最後の短いフリックが同じ軸を使用し、カメラ旋回中でも判定軸が途中で変化しません。
- バッシュの元の最大0.24秒・前方50px・前方500px/s・横ずれ比率0.42を保持します。コンボ入力優先順位、Bash追尾、ロック対象、モーション・当たり判定は変更しません。
- 今後の新しいフリック操作も `scripts/flick_direction_policy.gd` の `projected_forward` / `within_sector` / `is_flick` を使い、キャラクター前後・斜めを画面上のキャラ向きに合わせます。固定Y方向だけで前後を判定する実装は禁止します。画面左右の移動は画面左右のまま、連続RUN/BOOST操作は現行仕様を維持します。
- v252のSTEP移動方向・距離・EN・衝突、通常攻撃・ガード・AUTO/MANUAL、デバッグ専用ジャンプは変更していません。
- CIに静的／数値検査を追加。Godot/Android実機未検証。
