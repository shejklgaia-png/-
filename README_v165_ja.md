# SERA v165 — Bセット全身の赤色化（2026-11-09）

## 仕様
- Aセットは従来の色のままです。
- Bセットは頭・胴・下半身・腕・右手武器・左手武器、すべて赤系に統一します。
- Bメッシュの描画色を `Color(1.0, 0.18, 0.18, 1.0)` にし、既存のテクスチャ・UVを残して明暗差を維持します。平面的なベタ塗りではありません。
- Bセットの剣閃前面描画とステップ／ブースト残像も同じ赤色補正を適用します。
- A・C以降のメッシュとエフェクトは既存色（白色補正）を維持します。現行A/Bの切替、保存、アニメーション、戦闘／移動ロジックは変更しません。

## 実装
- `scripts/sera_equipment.gd`: Bセットのメッシュに限ってマテリアルを複製し赤色を乗算。マテリアルの共有によるAへの色漏れを防止します。Bを表すメタデータを追加します。
- `scripts/sera_rig.gd`: 剣閃前面表示と残像のB専用マテリアルを作成。残像の透明化速度・モーションは変更せず、赤い色だけ同期します。
- `shaders/sera_foreground.gdshader`, `shaders/sera_motion_ghost.gdshader`: 既定値を白にした `set_tint` を追加し、Aの従来色を維持します。
- Blockbenchの`.bbmodel`および`assets/sera_source.json`、埋め込みモデルの元データは編集しません。**赤色化はGodot側の表示のみ**に適用されます。
- `project.godot`: `SERA v165`。

## 検証
- `tools/v165_b_set_red_self_check.py`にセット限定、色調、描画パス、既存切替APIに関する静的チェックを追加。
- Godotのパーサー、Androidの実機表示と操作感は未検証です。

## スマートフォンでの確認
1. GitSyncで`main`を取り込み、Godotで`SERA v165`を再読み込みしてください。
2. NEXUSのCUSTOMIZEで頭から左右武器までBを選び、赤系の色で統一されるかご確認ください。
3. TRAININGで移動・ブースト・攻撃中も同じ赤系の外見で表示されるかご確認ください。
