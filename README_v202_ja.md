# SERA v202 — 左上HP・ENバーとEN切れ60%回復ロック

## 戦闘画面
- 既存の上部コンパクトHUD内の**左上**に小さなHP／ENバーを**縦2段（HPが上、ENが下）**で配置します。HPは現在値と最大値、ENは残量%を表示します。ENが回復ロック中は `RECOVER`、空になったら `EMPTY` を表示します。
- 既存の右側のターゲットHPバーは維持し、DEF／SH情報を中央へ配置します。従来右側にあったSERA HP表示とEN重複数値を整理し、戦闘視界の上に別の大型パネルを増やしません。両バーはタッチ入力を遮りません。
- HP：通常はシアン、残り**25%以下**（0より大）で橙色の枠線が約1.25Hzで滑らかに明滅します。**0**では枠線・バーを暗色に固定し、点滅はしません。
- EN：通常は緑系、残り**25%以下**（0より大・使用可能中）で枠線が約1.25Hzで滑らかに明滅します。**0**では赤色の枠線が約4Hzで速く点滅し、**回復開始後（0超〜60%未満）は暗色に固定**します。60%へ回復して再使用可能になると、通常色へ戻ります。

## EN切れの処理
- ENが0になったら `energy_exhausted` をロックし、最大ENの**60%以上**に回復するまで、ENが必要なアクションの消費をすべて拒否します。EN不要の操作は妨げません。
- ブースト消費の最後の1フレームを残量不足で支払えなかった場合も、残りの微量ENを0にして回復ロックへ移行します。ENが不足しただけの別行動を強制的にEN0にする変更はありません。
- ENの回復速度・回復待機、ステップ・攻撃の消費コスト、既存v201の「指を戻してから再BOOST」判定、RUN／BOOST速度補間、ガード・カメラ・各モーションは変更しません。訓練KOからの復帰時は従来どおり全回復してロック解除します。
