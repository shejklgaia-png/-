# SERA v496 — ビットタランの四脚砲台とダウン中の武装停止

## 四脚砲台
- 前左・前右・後左・後右の**実際の上肢関節**に、半球装甲＋筒状銃身の砲台をそれぞれ設置。
- 四基で**共通の1.2秒射撃間隔**を持つ。一斉射撃はせず、プレイヤーまでの距離が短い脚から順に発射し、4脚を一巡するたびに距離順を再計算。
- 発射時点のプレイヤー位置に向かう光弾（17m/s・寿命3秒、命中半径0.62m）。既存の盾・HP・ダメージ反応・ノックバック経路へ28%威力で渡す。
- 脚砲台は各脚のBlockbench原本骨の子として配置し、モーション／IKに追従。原本メッシュ、関節、足先当たり判定、アニメーションを変更しない。

## 射撃停止条件
- **四脚砲台：** 踏みつけ／弾き／なぎ払いの攻撃モーション中、攻撃準備中、ダウン予備動作（0.6秒）、ダウン本体、起き上がりまで停止。停止に入った時点で未着弾の光弾も消去する。再開時は一番近い脚から新たな射撃サイクルを開始。
- **背部レールガン：** ダウン予備動作開始から起き上がり終了まで、充填・青球・照射・音声を停止し、サイクルをリセット。攻撃モーション中は従来どおり動作する。
- ボス死亡時はすべての武装を停止。復活／戦闘リセット時も弾とタイマーを初期化する。

## CI事前確認・検証
- `.github/workflows/sera-model-policy.yml`、`tools/sera_ci_manifest.txt`、`docs/SERA_ACTIVE_CI_POLICY_ja.md`と既存のレールガン、Bittaran実シーン検査を確認。
- **実装前**に`tools/bittaran_leg_turrets_runtime_check.gd`を追加しCIマニフェストに登録。四基の取り付け先、半球＋筒の形状、1.2秒間隔、距離順、攻撃中停止、ダウン予備動作／ダウン中の両武装停止を実シーンで検査。
- 既存のレールガンの10秒充填・2秒チャージ・2秒照射・0.7秒復帰・速度補間・原本模型・IKなどの期待値は変更しない。
- mainへのマージ後にGitHub Actionsの全件Python/Godot CIを実行。Android上では半球と筒の見え方、射撃順、モーション中／ダウン中の停止を別途目視確認。
