# SERA v156 — 反転後も元のBOOST範囲を維持

高速反転による方向変更はそのままに、BOOST判定用の基準位置を最初のタッチ地点へ固定しました。

- 移動方向用スティックは反転時に新しい中心へ移ります。
- BOOST判定は反転前の円の125%（210px）で0.10秒維持したときだけ開始します。110%（184.8px）未満で解除します。
- 反転したらBOOSTを解除し、元の110%圏内へ戻るまで再BOOSTを禁止します。戻った後に125%圏外へ移動すると、通常の確定時間でBOOSTできます。
- BOOSTのガイド弧も元の中心の判定境界を指すよう変更しました。

反転の速度800px/秒・角度約143°・32px/120ms、通常アナログ移動、BOOSTの0.15秒加減速、ガード・攻撃・回避とセラ本体モーションは変更しません。

静的・数値テストによる検査です。Godot/Android実機での操作確認は未実施です。
