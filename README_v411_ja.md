# SERA v411

## 概要
実機フィードバック2件への対応です。「後足の攻撃時、胴体が異常にねじれる」と「攻撃の予備動作が正常でない」。計測の結果、どちらも同じ原因（なぎ払いの胴体ミラーの方式）でした。ミラーする対象を「絶対姿勢」から「基本姿勢からの動き（差分）」に改め、反転は左右方向だけにしました。

## 何が起きていたか
- v410のなぎ払い胴体ミラーは、Bodyボーンの絶対姿勢をそのまま面反転していました。ビットタランの基本姿勢は前後非対称（前脚の付け根が後脚より高い）なため、反転した姿勢が基本姿勢からどれだけ動くかは脚ごとに変わり、左後脚では胴体の傾きの動きが左前脚より大きく膨らんでいました（クリップ開始時点のワールド差分で 30.2° vs 左前脚 22.5°）。
- これが胸の追尾回転（最大51°）と重なり、左後脚のなぎ払いでは胴体が基本姿勢から最大 **94°** 回転していました。ねじれは予備動作（ウインドアップ）の間に形成されており（予備動作の終了時点で既に約90°）、「予備動作が正常でない」という指摘も同じ現象です。
- なお v409 時点でも左後脚のなぎ払いは 63° まで回っており、v410 のミラー変更がそれを 94° まで悪化させていました。

## 修正
- なぎ払い胴体ミラー（`scripts/bittaran_rig.gd`）: 基本姿勢（Wait）からの回転差分を取り、ワールド空間で左右面に対してだけ反転し、基本姿勢へ戻す方式に変更しました（`_mirror_body_delta_for_attack`）。反転は回転角の大きさを保存するので、全脚が左前脚とまったく同じ大きさの傾きを再生します。左後脚は左前脚の傾きをそのまま共有し、右後脚は右前脚と同じ左右反転です。脚チェーン側の補正は従来どおり再生側に追随するため、攻撃脚の軌道は変わりません。
- 試して不採用にした案:
  - 差分を前後方向にも反転する（幾何学的に完全なミラー）: 後脚では屈み込みのピッチが反転して後脚の付け根が約0.6m沈み、サンプルされる著者ポーズが床下約2.2mまで潜りました。さらに打撃入り（0.36秒のブレンド）で膝のポールが股関節→足裏の軸を横切り、左後脚の膝が1ティックだけ床を -0.214m 突き抜けたため不採用。
  - 弾きにも同じ差分ミラーを適用: 左前脚基準で調整済みの軌道サンプラ・到達解法・照準が右前脚で崩れました（v400/v406/v408/v409 が FAIL）。弾きの胴体回転は全脚 30〜70° で異常値がないため、弾きは従来の無反転のままにしています。弾きのミラーは専用の再調整として別途行うべきものです。

## 計測結果
- 実景でのなぎ払いの胴体回転（基本姿勢からの総回転の最大値）: 左前 56° / 右前 60° / 左後 **52°**（v410では94°）/ 右後 33°。予備動作中の最大値も打撃中と同じ水準で、予備動作の間にねじれが溜まることはなくなりました。
- 後脚のなぎ払いで脚メッシュの最下点は -0.000m（床めり込みなし）。左後脚・右後脚のなぎ払いを横カメラのスクリーンショットで確認し、地面を這う低い弧と水平な胴体になっています。
- ウインドアップ中の攻撃足の植え付け（v410）はそのまま維持されています。

## チェック
- 新規 `tools/v411_bittaran_sweep_body_delta_mirror_runtime_check.gd`: クリップ各時点での差分の大きさが全脚で左前脚と一致すること、左右反転の形が正しいこと、実景のなぎ払いで胴体回転が70°以内・脚メッシュが床を割らないことを検査。v410ツリーでは FAIL（左後脚の差分 30.2° vs 左前脚 22.5°）、本版で PASS。
- 既存チェックの変更（意図と理由は各ファイル冒頭と DEVELOPMENT.md に明記）: v410 Part 2（なぎ払い Body ミラーの意味を絶対姿勢の反転から差分の左右反転へ変更。Part 1 の植え付け検査は不変）、v385（Body 予備ポーズの参照を、生クリップ回転からリグの再生目標 `_authored_body_rotation_for_attack` へ変更。生キーは左前脚の無反転ソースであり、正しくミラーされた後脚は許容 1.15 rad を超えて離れるため。「予備ポーズへ 0.12 rad 以上動く」という不変条件は不変）。
- 関連チェック（v383/v385/v386/v389/v391/v392/v396〜v411）はすべて PASS。ローカル全件スイートも PASS（静的 182/182、Godot 147/147。PR の CI でも確認）。
