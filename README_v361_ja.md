# SERA v361 — ダウン時に頭を支える脚の接触判定と頭部ロックの優先

## 新しい挙動

ビットタランが旋回中に脚を大きく曲げて、頭の下へ前腕や脚が入り込んだ状態でダウンした場合、**頭がその脚を突き抜けず、脚の上に乗る**ように修正しました。

- 頭の先端側と各脚の実際の各メッシュから接触を判定します。ロック判定を大きくしている箱や、脚全体を一つに包む空の多い境界箱を物理的な支持には流用しません。
- ダウンで下がる胴体を接触地点で止め、脚の地面接地をその物理フレーム内で再計算します。頭の関節を回すのではなく、元のダウン用頭部姿勢を維持します。
- 頭の下から脚が抜けた場合、支持を解除して自然にダウン姿勢へ近づけます。ダウン終了時と復活時には補正を消去します。

## ロック対象の選択

- **ダウン中のAUTO**：引き続き頭部を優先します。
- **ダウン中のMANUAL**：実際に頭を下支えしている脚は、頭と画面上で重なったときだけロック優先度を下げます。頭から手動で切り替えれば支持脚も引き続き選択できます。
- **通常時・その他の脚**：優先度は変わりません。

## 維持する仕様

0.6秒の重たい頭上げ予備動作、元のダウン時間、頭部の初期回転、脚のワールド固定接地、ダウン中のHEADロック、奥側のコントローラ方向補正、通常STEP操作。

## 回帰テスト

`tools/v361_bittaran_head_leg_contact_runtime_check.gd`は、ダウン中の頭への脚の食い込みを再現し、脚上での停止、足裏の接地、頭部回転、支持脚の優先度、復活時のリセットを検査します。
