# SERA v256 — Bashフリックの入力負荷軽減

## 変更対象
**GUARD→Bashと3段目→Bashのみ**。セラの画面投影正面を基準とする45°×8区画（Bashは前方の±22.5°）は変更しません。

| Bash条件 | v255 | v256 |
| --- | ---: | ---: |
| 最大フリック時間 | 0.24秒 | **0.42秒** |
| セラの正面方向の最低移動量 | 50px | **30px** |
| セラの正面方向の最低移動速度 | 500px/秒 | **200px/秒** |
| 候補の角度が外れた際に取り消す距離 | 18px超 | **38px超** |
| 指の軌道が往復した場合の許容倍率 | 1.20 | **1.35** |
| ガード中の末尾サンプル時間 | 0.20秒 | **0.42秒** |

- 指を短く・ゆっくり動かしてもBashが成立しやすくします。初期の指の揺れだけでは即キャンセルしません。
- **発動方向はセラの画面上正面±22.5°のまま**です。上下左右・斜め45°刻みの8区画ルールは維持します。
- 変更範囲はBash判定とガード中のフリック記録だけです。STEPは引き続き78px/500px/s/0.24秒、RUN/BOOST・攻撃追尾・EN・カメラ・UI・破壊は変更しません。
- JUMPは実験用・タッチOFFのままで、0.20秒の末尾サンプルを保持します。
