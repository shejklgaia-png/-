# SERA v285 — 左右蹴りを敵中心の旋回移動に変更、カメラ角度を縮小

## 左右蹴りの移動
- 従来は画面左／右へ**直線ステップ**していましたが、`Kick_l`・`Kick_r` のみ**敵の中心（軸）を基準とする円弧移動**へ変更しました。
- 1発目はその場で蹴り、原本モーションの**2発目の振りかぶり**で円弧移動を始めます（右: 0.33333、左: 0.41667、クリップ進行比）。
- 1発目のBash式追尾でプレイヤー位置が変わることを考慮し、**2発目の振りかぶり直前の敵→プレイヤー距離**を実際の旋回半径として採用します。
- 画面右フリックは画面右方向の円弧、左は画面左方向の円弧を選択。敵が移動した場合は旋回軸も追従します。キャラクターの実移動は既存の衝突検出付きで行います。
- 元のステップから引き継ぐ移動距離（2〜4m）、速度、EN、原本左右蹴り2倍再生、2回の蹴り当たり判定は維持します。極端な中心重複の場合のみ、従来どおり安全な接線直線移動へフォールバックします。
- **通常の360°ステップとバックステップは従来どおり直線移動**し、変更しません。

## カメラ・ターゲット軸・セラの角度制限
- 敵（ターゲット）を頂点とするカメラ方向とプレイヤー方向の水平角差を、従来の**最大65°から45°**へ縮小しました。
- 以前は旋回中もカメラYawを固定し、ステップ終了後のみ制限しましたが、**左右蹴りでの旋回中からターゲット中心の角度制限を適用**します。
- カメラの旋回速度上限（300°/秒）を維持しているため、初期の角度差が大きい場面では制限角への追従に短時間の遅れが生じる場合があります。
- 通常ステップの画面方向維持、フレーミング用ズーム、既存のターゲットロック、通常攻撃受付時間等は変更しません。
