# SERA v426 — ビットタラン攻撃時の胴体水平化・降下と段階復帰

## 攻撃中
- 原本Bodyキーの傾きをWaitの水平寄り姿勢へ最大68%補間します。完全水平には固定せず、残り32%の原本姿勢を保持します。
- 足先メッシュの着地点を基準に、胴体を接地に必要な高さへ徐々に降下します。胴体自身の床とのクリアランス20mmと最大降下1.10mを制約にし、前フレームのIK補正を高さ算出に使用しません。
- なぎ払いの足先は攻撃中に接地しますが、脛は「接地を強制」せず、原本軌道が床へめり込む場合だけ膝IKで回避します。
- 踏みつけは振り上げ中の浮遊を保持し、着地後に足先接地。弾きも足先だけを接地させます。

## 攻撃が終わった後
1. 足先の攻撃用強制接地を終了し、0.42秒で攻撃脚をWait基本姿勢の足位置へ戻します。胴体の低い高さは維持します。
2. 脚が戻った後、0.62秒で胴体を通常の基準高さに戻します。その間は歩行・旋回と次の攻撃を停止して他脚の世界足先アンカーを維持します。
3. 復帰完了時に高さ・膝ポール・接地・旋回補正の一時的な値をクリアします。部位破壊・KO・強制再開でもリセットします。

## テスト
- v425：左右3攻撃の足先接地およびなぎ払い脛の床貫通防止。
- v426：左右3攻撃を2巡連続再生し、胴体水平化、脚先行の復帰と高さ補正リセット、回数によるずれを検証。
- 実機でのモーション滑らかさと各攻撃のプレイフィールは未検証です。
