# SERA v114 — BOOST 4方向姿勢補間（2026-11-07）

## 対象と適用
- GitHub main v113を基準に、ユーザー作成の `models/SERA_BOOSTER_all.bbmodel` から `Boost_front`、`Boost_back`、`Boost_Left`、`Boost_right` の4クリップだけを統合しました。
- 4クリップはいずれも時刻0の21キーフレームからなる静止ポーズです。元のキーフレームは補作・変更せず、Godot上で各ボーンのQuaternion（最短弧SLERP）、位置、スケールを補間します。
- BOOST中の入力は既存のターゲット相対方向（X右、Y前）を利用。隣接する前／後と左／右の2姿勢を入力角度に応じて0〜1の重みで混ぜ、斜め方向も連続して表現します。
- BOOST内の旋回は最短角の指数補間（時定数0.12秒）。前から後ろへ180度反転しても入力ベクトルがゼロになる不安定さを避けます。各純方向では作成されたポーズをそのまま表示します。
- BOOSTの開始／終了は既存の0.16秒ポーズ遷移を維持します。BOOSTモーションの再生は姿勢のみで、実際の移動や当たり判定にはルートモーションを加えません。

## 変更と保護
- `assets/sera_source.json`／`assets/sera_data.gd`、`scripts/sera_rig.gd`、BOOST表示部分のみの `scripts/main.gd`、`project.godot` を更新。統合編集用は `blockbench/SERA_v114_boost_four_way_integrated.bbmodel`、既存のユーザー原本は変更しません。
- 既存のRUN前／後モード・左右RUNソース・利き手判定・頭部揺れ抑制・15度旋回バンクは変更しません。ガード、3段格闘、ステップ、ジャンプデバッグ、残像、BGM、カメラ、移動速度も維持します。
- モデルのジオメトリ、ボーングループ、UV、既存の他16クリップは変更せず、入力モデルから4 BOOSTクリップだけ採用しました。
- `tools/v114_boost_four_way_self_check.py` を追加し、過去の一部テストに含まれる旧クリップ数・旧バージョン名の前提を更新します。
