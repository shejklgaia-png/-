# SERA v172 — SYSTEMのセーブ管理、DATA ARCHIVEのプレイ記録

## 拠点メニューの役割
- SYSTEM: 既存の3スロット、SAVE / LOAD / NEW DATA / DELETEを移動。
  空スロットからの作成・上書き二度押し・ロード後の装備反映を維持。
- DATA ARCHIVE: 保存操作は行わず、開いているプレイデータの統計だけを表示。
  SUMMARY / COMBAT / PROGRESS / PROFILEの4つのタブをタップして切替。
  カメラ・3D設備・タップ判定・右下の戻る操作は維持。

## DATA ARCHIVEの表示
- SUMMARY: 累積プレイ時間、トレーニング時間、撃破した訓練ターゲットの数、最後にいたエリア。
- COMBAT: 訓練ターゲット撃破、格闘命中、バッシュ命中、実際に減らしたHP（与ダメージ）、
  ガード成功回数、ガード外の被弾回数。
- PROGRESS: トレーニング訪問の有無。未実装のストーリー・ミッション・チュートリアルは
  `NOT IMPLEMENTED` と明示し、架空の達成率は表示しない。
- PROFILE: スロット番号、データ作成日時、最終保存日時、現在の6部位の装備セット。

## 集計仕様
数値は選択中の有効なセーブスロットのプレイ中に計上します。
ゲーム時間はNEXUSとTRAININGの稼働時間、トレーニング時間はTRAININGのみです。
命中は剣またはバッシュがターゲットに接触した確定時だけ計上し、与ダメージは
ターゲットHPの実減少量を採用。ターゲットHPが正から0になった瞬間だけ1撃破とします。
**これは訓練用ダミーの破壊記録であり、正式な敵撃破数ではありません。**
被弾とガードは敵射撃/範囲攻撃の接触通知で計上します。

集計はアクティブデータの作業コピーに記録され、SYSTEMのSAVE操作で
従来の `user://sera_archive/slot_XX.json` へ保存されます。
v171のデータもそのまま読み取れ、追加統計は0から、プレイ時間は保存済み
トレーニング時間を下限として補完します。データのリセットやスロットの
自動変更は行いません。
