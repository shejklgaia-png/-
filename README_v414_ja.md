# SERA v414 — ビットタラン後足攻撃の等角度・逆方向の前傾と高さ固定

## 変更
- **後足の踏みつけ・弾き・なぎ払い**：基本の後傾（Blockbench「Wait」胴体姿勢のローカルX角度）から開始し、予備動作の間に**絶対値が同じ前傾角度**へ移ります。打撃・硬直中は前傾を維持し、復帰時間内に元の後傾へ滑らかに戻ります。v413の「後ろ側をさらに8°持ち上げる相対補正」は廃止しました。
- **胴体の高さを固定**：後足攻撃では、初期接地位置から算出した高度オフセット、踏みつけ用の胴体降下、胴体メッシュの床接触による胴体全体の持ち上げを適用しません。回転の支点・位置は変えず、頭・支持脚のIKや攻撃脚の個別床処理は従来どおりです。
- 前足の全攻撃は従来のキーフレームと姿勢・接地補正を維持します。攻撃終了時のキャッシュ完全初期化も維持します。

## 検証
- 新規`tools/v414_bittaran_rear_mirrored_pitch_fixed_height_runtime_check.gd`：左右の後足×3攻撃を実シーンで再生し、通常の後傾→同角度の前傾→後傾の遷移、攻撃中の胴体Y位置固定を各フレームで検査します。
- v397・v413の旧「8°の後側持ち上げ」検査は、変更した仕様に合わせて同角度反転・高さ固定を確認する検査に更新します。他のv381〜v413の回帰検査は継続します。
- Godot headlessの結果とAndroid端末上の見た目は別に確認が必要です。
