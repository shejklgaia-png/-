# SERA v492 — 拠点メニューのSERAとコントローラーを一時非表示

## 仕様変更
- **俯瞰拠点メニューだけ**SERAのキャラクターと画面右下の移動スティックを非表示にします。動かせない不可視キャラクターが残らないよう、拠点内のSERA移動入力（タッチ・マウス・方向キー）も停止します。
- 拠点ではSERAの重い3Dリグの生成を省きます。既存の不可視アンカーはカメラ用に残し、以前の移動コードは削除しません。
- 一時設定は`scripts/base_exploration.gd`の`HUB_SERA_CONTROLS_ENABLED = false`に集約。再表示する際は`true`へ戻せます。
- CRATEの自律巡回、拠点の広いグリッド床、NEXUS建物のタップ入室、NEXUS内部メニュー、出撃・戦闘時のSERAは変更しません。

## CI
- 更新前に共通manifestと既存の拠点実行・静的テストを確認。**本体変更前**にSERA非表示・リグ不生成・2コントロール非表示・移動無効の期待値を追加しました。
- 旧「拠点でもSERAを動かせる」というテスト条件を、建物と拠点境界が残る検査に変更しました。グリッド・CRATE巡回・拠点↔NEXUS検査は維持します。
- 既存327テストは全て登録状態を保持。main統合後にフルCIを実施します。Android実機の表示は別確認です。
