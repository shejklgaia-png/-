# セラ v90 — 通常走行／ブースト操作の分離

基準版：v89 `sera_portrait_godot_melee_v89_boost_front_motion.zip`。

## 操作仕様

- 通常ドラッグ：中心から半径168pxまでアナログ走行（最大3.25m/s）。半径100%に達したスティックは外周にスナップし、それ以上は通常走行入力を増やしません。
- ブースト開始：実際の指が半径の**125%（210px）以上**にあり、その状態が連続**0.10秒**継続するとブーストを確定します。毎物理フレーム判定するため、指を静止しても確定します。
- ブースト解除：実際の指が半径の**110%（184.8px）未満**に戻った瞬間に解除します。125%より少し内側に戻っただけでは解除しません（ヒステリシス）。
- ブースト速度：通常移動倍率1.0から最大1.5へ**0.15秒**かけてリニア加速（解除時も同時間で通常速度へ戻る）。モーション `Boost_front` ／ `run_front_original` の0.16秒ブレンドは維持します。
- 視覚案内：スティック円周でノブを固定。指が外周を越えた場合、ブースト未確定の間だけ指の向きに半径125%の短い薄色ガイド弧を表示します。ブースト確定後は従来の縁と矢印の強調を維持します。
- ステップ：フリックは**指を離した瞬間**に判定します。確定ブーストを経験していない短いフリックは従来の左右・下方向ステップとして動作します。一度ブーストを確定したジェスチャーは離すときにステップへ再分類しません。

## 既存機能の維持

- バックステップ4m、左右ステップの軌道・速度、フリックしきい値は変更なし。
- Blockbenchモーション、3段格闘12/12/26、格闘接近、残像、カメラ追従、敵AI、被弾、衝突処理は変更なし。
- 変更ファイル：`scripts/main.gd`、`scripts/touch_overlay.gd`、`project.godot`、`DEVELOPMENT.md`。追加：`README_v90_ja.md`、`tools/v90_boost_threshold_self_check.py`。
- Godot 4.7.2の公式リリースとInputEventScreenTouch/Dragの仕様を参照。既存プロジェクトのCompatibilityレンダラーは変更しません。
