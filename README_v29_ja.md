# セラ v29 — 剣軌跡の白色化版

## v28からの変更
- 剣エフェクトのデフォルト色を、青紫がかったグレー系から**純白（RGB 255,255,255）**へ変更しました。
- 元の8コマの輪郭と透明度（アルファ値）は完全に維持しています。
- `Swordeffect`の前方オフセット**0.55m**、Blockbenchの位置・角度・拡大率・攻撃キーフレームはそのままです。
- カメラ・移動・当たり判定・再生タイミング・火花などの戦闘処理は変更していません。

## 変更ファイル
- `assets/slash_C_white_4x2.png`（追加、白色の8フレーム素材）
- `scripts/sword_trail.gd`（デフォルト読み込み素材を白色版に切り替え）
- `assets/slash_C_white_preview.gif`（追加、動作の参考画像）
- 元の青紫版 `assets/slash_C_ice_4x2.png` と赤版は保存しています。

## 確認
Godot 4.7.2で `project.godot` を開き、▶で起動、短くタップして攻撃します。
位置やアニメーションがv28と同じで、斬撃だけ白いことを確認してください。
キーボードの `C` で従来どおり赤／白の切替ができます（Androidではデフォルト白）。

## 検証範囲
画素値・透明度・ZIP内の参照・v28とのコード差分は静的検証済みです。GodotエディターおよびAndroid実機での起動確認は未実施です。
