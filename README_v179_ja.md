# SERA v179 — プレイヤーHPバーと訓練KO演出

## 変更点
- TRAININGの固定HUDに、敵HPバー（左）を残したまま**SERAのHPバー（右）**を追加しました。A/B装備の最大HP合計（A一式800 / B一式1040）を分母に使用し、被弾・復帰時に即更新します。
- プレイヤーHPバー：HP 50%以下で橙、25%以下で赤、HP0で残量0かつ `SERA DOWN 0 / 最大値 HP` と表示します。従来のEN/SH/防御率表示は維持します。
- HP0の瞬間、装備A/Bを含む**プレイヤー全身の材質だけを一時的に暗色化**します。元のパレットテクスチャ・B赤色補正・モデルは編集せず、`shaders/sera_ko_dark.gdshader` をマテリアルオーバーレイとして使用します。
- HP0になる際は残存するブースト・ステップの残像を消去し、KO中は新しい残像を発生させません。
- HP0では `Damageknock` の「**最後のキーフレーム時刻**」を読み取り、全身をそのポーズに固定します。ダメージモーションがループ設定であっても先頭へ巻き戻しません。KO中はリグの再生・ブレンド処理を停止します。
- **2.5秒の訓練KOタイマー**が終わると、暗色材質を解除、ポーズ固定を解除して通常の `Wait_motion` に復帰し、HP/EN/SHを満タン・位置を初期位置に戻します。元々存在する装備別のカラーや剣閃用描画の処理を復元します。
- 通常のシールドブレイク・ダウン（HPが残っている場合）は今回のKO演出の対象外です。モーション・モデル・攻撃・保存形式を変更していません。

## 動作確認
1. GitSyncでmainを同期して、プロジェクト `SERA v179` をGodotで起動します。
2. TRAININGのHUDで「TARGET」と「SERA」の2つのHPバーを確認します。
3. `TEST HIT` を繰り返すか、攻撃4種（AIM/LEAD/SHOCK/ARC）の命中によりSERA HPを0にします。HP残量・色の推移を確認します。
4. KO中はセラ全身が暗くなり `Damageknock` 最終キーフレームで動きを停止していることを確認します。
5. 約2.5秒後、元の明るさ・待機姿勢へ戻り、SERA HPバーが最大HPまで回復することを確認します。
6. CUSTOMIZEでBパーツを混ぜても、KO暗色化と復帰後のB赤色が正常に戻ることを確認します。
