# SERA v189 — 鳥足Dセットと頭Cピボット修正

## 変更内容
- カスタマイズの **LOWER BODY** に **D**（逆関節脚・鳥足）を追加。A/B脚は変更せず、表示を切り替えます。上半身の選択、既存の戦闘モーション、頭の選択などは独立です。
- 最新の `models/storage/SERA_BIRD_LEGS_MIRROR_EDIT.bbmodel` から、鳥足左右6ボーン・10メッシュと、その専用キーフレームを読み込みます。鳥足は標準Aの `Waist` に接続され、元の上半身モーションと同じタイムラインで動きます。
- NEXUS展示用 `NEXUS_pose` では鳥足左右6ボーンの最新版キーフレームを使用します。RUN、格闘、ガードなど既にある鳥足トラックは再利用します。
- 鳥足作者のキーフレームがない `run_back` は前走、`run_right` は左走、`Jump` は静止姿勢の一時代用です。**これらは新しい専用モーションを作成したことを意味しません。** 全動作の足接地・回転の微調整が残ります。
- 頭Cは `models/storage/頭C (2) (1).bbmodel` の新しい首・頭のピボットとメッシュ角度を適用。元の1.5倍サイズを維持するため、原本を0.48倍に正規化して接続しています。頭Cのみ専用のピボットを持ち、標準Aの頭のモーションに追従します。
- 鳥足DのHP・防御・移動速度などは、暫定的にAセットと同じ既存ステータスです。Bセットの赤い色や装備の保存処理は維持します。
- Godotプロジェクト名を `SERA v189` に変更。実際のランタイムモデルはスマホGodotで表示・モーションを確認してください。

## 検証
- 静的検査: 6鳥足ボーンの左右/階層、10メッシュ、NEXUSの6トラック、Cピボットと頂点、Aモデル・23既存モーション、埋込データ整合性。
- 自動CI: PRで `tools/v189_bird_headc_self_check.py`、`tools/self_check.py`、`tools/codex_project_check.py` を実行する設定です。
- **未実施**: Godot Editorでの起動、Xperia 1 Vの実機確認、モデルの干渉・着地・ジャンプ中の見た目。実機結果までは保証できません。

## 実機確認手順
1. GitSyncで `main` を同期し、Godotで `SERA v189` を開きます。
2. NEXUSのCUSTOMIZATIONを開き、LOWER BODYを **D** に切り替え、脚が表示されること、A/Bに戻せることを確認します。
3. HEADを **C** に切り替え、首が埋まらないこと、頭を回転させても接続が破綻しないことを確認します。
4. TRAININGに移動し、走行・ブースト・ステップ・格闘・ガードで鳥足が動くことを確認します。接地と左右回転は今後の調整対象です。
