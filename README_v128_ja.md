# SERA v128 — 片側フォーカス構図と仮メニューパネル

## 設計
- 全景の選択枠、ワンタップ、0.18秒のカメラ接近／復帰、右下戻るボタンは継続。選択直後の新たなフラッシュや残像、粒子は追加しない。
- 選択後の専用アングルを更新。SYSTEM／DATA ARCHIVEは3Dオブジェクトを画面左側、TRAININGは画面右側、DEPLOYMENTは画面右側に配置して、斜めの遠景から開口部を圧縮して見せる。CUSTOMIZEはセラ本体と台座を画面右側に収め、全身・剣・足元を含める。
- 各画面の空白側に四角い仮のメニューを追加。メニュー本体は枠線・角丸・装飾のない、単色半透明サイバー青（RGBA 0.025/0.155/0.260/0.52）。上部のみ不透明な青（0.035/0.190/0.315/1.00）の見出し帯として、対象名を表示。
- メニューは通常画面には表示せず、0.18秒のカメラ移動が完了したときだけ表示。仮画面なのでメニュー項目は作らず、TRAININGだけは従来の「ENTER TRAINING」遷移ボタンをパネル内に残す。
- パネル位置は対象ごとに指定：左寄せのSYSTEM／DATA ARCHIVEは右側パネル、右寄せのTRAINING／DEPLOYMENT／CUSTOMIZEは左側パネル。端末・アーカイブ・ゲートは輪郭とパネルを水平方向に2〜6%程度重ねる。
- CUSTOMIZEだけは全く重ねない。実際のセラモデル（武器含む）の投影輪郭の左端を計測し、パネル幅をそこから16px以上離すよう制限。背景の台座も右側に入れる。
- 新たな3Dモデル複製なし。既存のシーン／モデルの移動・拡大縮小・旋回なし。カメラ位置／注視点／FOVとUIのみ変更。
