# SERA v427 — ビットタランなぎ払いの導入補間と接地タイミング

## なぎ払いの攻撃開始
- 左右それぞれの前脚3関節とBodyを、Wait基本姿勢からなぎ払いのキーフレーム0へ0.32秒でsmoothstep+slerp補間します。原本アニメーションのキーは変更しません。
- この補間が完了した後、キーフレーム0から原本のなぎ払いの時間軸を再生します。攻撃開始時に一気に原本キーフレーム0へ飛ばないようにします。

## 地面への切り替え
- なぎ払いでは、まだ足先が宙にある間は床へ強制的に引き下げません。実際の足先メッシュが床から3.5cm以内に到達し、かつ上記の導入補間が完了した時点で接地IKを有効化します。
- 切り替えた後はなぎ払いの足先を床に合わせます。脛は従来どおり、地面に入る場合に限り回避します。攻撃が終了したら接地ラッチをクリアします。

## 胴体と脚の連動
- 胴体を下げるとき、開始時はゆっくり、0.4秒で最大2.0m/sへ速度を上げる方式に変更。1フレームで胴体だけが突然数十cm下がることを防ぎます。
- すべての腕／脚の付け根は胴体の親子階層に従って動き、支持する3脚はそのフレームの胴体位置から既存の2関節IKで再計算し、足先の接地を維持します。攻撃側は着地前に原本姿勢、接触後にIKと原本姿勢を併用します。
- v426の足→胴体の復帰順序と補正値の全リセットも維持します。

## 検証
- v427 Godotランタイムテストは左右の基本姿勢→キー0の補間、導入中に強制接地しないこと、接触後の足先・胴体速度・ラッチ解除を確認します。
- Android実機での自然さは未確認です。
