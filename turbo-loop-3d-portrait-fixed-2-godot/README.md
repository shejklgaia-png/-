# TURBO LOOP 3D — 縦画面・片手操作版 🏎️

Godot 4.3以降で開く、オリジナルの3Dカートレース試作です。既存の横画面版とは独立したフォルダーにしています。任天堂のキャラクター・素材は使っていません。

## 今回の変更

- **道路を見やすく**：濃色アスファルト、車線区分、路肩、交互色の縁石、方向矢印、両脇のガードレールを描画します。道路外への移動は減速し、遠くに外れた場合は復帰処理が働きます。
- **車体の進行方向を修正**：Godotのローカル前方向 `-Z` とワールド移動方向が揃うよう、カートのYaw符号を修正しました。ステアリングとカメラの基準も一致しています。
- **縦画面**：仮想解像度は540×960、Androidの画面向きは縦固定です。カメラは道路の先を見通す追従式に調整しました。
- **片手操作**：アクセルを押す必要はありません。画面下側で1本指を左右ドラッグするとステアリング、曲げた状態で0.34秒以上保持するとドリフト、指を離すと一定以上のチャージがある場合にミニターボ。下にドラッグするとブレーキです。
- **道路追従補助**：ハンドルから指を離したとき、コースの曲線に合わせて緩やかに向きを補正します。

## 遊び方

1. ZIPを解凍します。
2. Godot 4.3以降のプロジェクトマネージャーで「インポート」→ `project.godot` を選択します。
3. ▶でゲームを実行し、**RACE START** を押します。
4. カウントダウン後に自動発進します。画面下部をドラッグして走行してください。

### 画面下側の操作

| 動作 | 1本指の操作 |
| --- | --- |
| 進む | 自動（指を離しても進みます） |
| 左右へ旋回 | 下半分をタッチし、指を左右に移動 |
| ドリフト | 左右に動かしたまま0.34秒以上保持 |
| ミニターボ | ドリフトでチャージして指を離す |
| ブレーキ | 触れた位置から下向きにドラッグ |

スマートフォンでは加速・ハンドル・ドリフトの別々のボタンを同時に押す必要はありません。スタートとリトライのみボタンを使います。

### PCでのテスト

PCでは自動加速のほか、A/Dまたは←/→でステアリング、Sまたは↓でブレーキ、Shift/Spaceでドリフト、Rで再起動です。ウィンドウ下半分のマウスドラッグ操作も利用できます。

## ゲーム要素

- 3周レース、ライバルCPU3台、順位・速度・タイム・ミニマップ
- ドリフトチャージによるミニターボ、コース上の加速パネルとアイテム
- 外部3Dモデルなしで自動生成する立体カート、コース、樹木や看板
- 既存のSERA・GitHubリポジトリへの変更はありません

## 技術情報

- Godotプロジェクト一式で、**APKではありません**。Androidに直接インストールするためにはGodotからAndroid向けAPKへのエクスポートが必要です。
- この環境にはGodotの実行バイナリがないため、Godot本体での描画／タッチ操作の実機動作は未検証です。
- 車体の回転符号・移動方向の一致は計算でチェックしました。自動走行の近似シミュレーションでは、指を離した状態で3周完走し道路内を走れました（実機テストとは別です）。

## 主なファイル

- `project.godot` : 540×960 / Android縦固定
- `scripts/track.gd` : 道路、方向矢印、ガードレール、道路外の判定用座標
- `scripts/kart.gd` : 車体モデル、進行方向、道路追従、自動加速、ドリフト
- `scripts/hud.gd` : 縦画面レイアウト、片手用ジェスチャー
- `scripts/main.gd` : レース進行、カメラ、入力連携
- `scripts/minimap.gd`, `scripts/pickup.gd`, `assets/*.wav` : 補助機能・効果音
