# SERA v425 — ビットタランの左右前脚攻撃に地面接地IKを追加

## 接地対象
| 攻撃 | 接地を調整する実メッシュ |
|---|---|
| なぎ払い（左右） | 下肢（脛）と足先の両方 |
| 踏みつけ（左右） | 足先 |
| 弾き（左右） | 足先 |

- v424からの6個のBlockbench原本攻撃クリップは無変更。
- 各フレームで攻撃側の原本姿勢を再生してから、攻撃側のみ2関節IKで接地を再計算します。元の足先回転と水平位置を維持し、必要な上下方向・膝の曲げ方向だけを補正します。
- なぎ払いの脛は、足先接地位置を固定して膝の曲げ方向（ポールベクトル）を探索し、両メッシュの床との接触を優先します。
- 踏みつけは振り上げ中に足先を無理に床へ引き下げず、衝突予防と着地・硬直中の接地を行います。弾き／なぎ払いは打撃中の接地を行います。
- 攻撃脚以外の3脚は既存の世界接地IKを維持します。歩行・旋回・頭部90°追尾、後脚攻撃停止はv424と同じです。
- v424の6攻撃原本読込テストと、新しいv425接地・貫通防止のGodotランタイムテストを実行します。
- 実機画面でのモーションの自然さ・急激な姿勢変化は別途確認が必要です。

## 履歴テストの整理
- v391（弾き予備動作の膝角度無補正）とv422（後脚を含む旧4脚のミラー軌道）は、新しい床接地・前脚限定仕様と両立しないため、現行CIから除外して原本の履歴ファイルは維持します。
- v425の全6攻撃接地テストと、その他の維持対象テストを継続します。
