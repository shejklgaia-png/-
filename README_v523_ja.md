# SERA v523 — Android実機で空白の一覧を直接オーバーレイへ

v522実機画面でも製作・倉庫のカードが見えず、Linuxのピクセル検査だけではAndroidの表示を保証できないことが確認されました。

- 既存のネストした施設コンテナから全カードグリッドを分離し、表示できている施設パネルと同じ階層の FacilityItemLayer に直接配置します。
- 実画面の説明文・プロファイル操作・倉庫切り替えタブの下に各3列カードを配置し、戻るボタンより上に収めます。
- 装備7種、素材12種、倉庫装備7種の未所持枠、四隅欠け、実アイコン、カード全面タップ、個体UIDを維持します。
- データ保存・素材変換・戦闘・モデルは変更しません。

## 検査

v523新規レイアウトCIを本体変更前に登録し、v511〜v522の既存テストを新レイヤーに対応させました。仮想ディスプレイで実描画とピクセルを検査します。Android実機の最終的な表示は別途確認が必要です。
