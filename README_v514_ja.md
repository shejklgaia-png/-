# SERA v514 — 予測シールドの膜とシャープな破壊表現

## 変更点
- **通常命中時は中心に穴が空かない**：接触点から半径20%を均一に埋めた高彩度の防御膜にし、中央の白い閃光が消えた後も色のある膜が外周と一緒に減衰。外側には薄い膜面と細く硬い輪郭を表示し「張った膜を叩く」印象へ修正。
- **破壊時だけ中央が空洞化**：シールドSPが0になったとき、破裂リング中心に14〜23%の穴が開く。横一線に走る青白い亀裂、放射状の青白い破裂に10方向の鋭い破片を追加。
- 既存の鮮やかな青・黄・赤、表示サイズ、深度テスト付き描画順、破壊SEは維持。HPバーへの重ね表示はしない。

## ゲーム上の不変条件
- テストターゲットとビットタランの両方に共通コンポーネントで適用。
- 予測シールド100SP、近接最大25%・射撃最大95%軽減、攻撃が止まって4秒後から毎秒20SP回復。部位破壊、被弾判定、Bittaran脚IK・射撃・頭追従の挙動は変更しない。
- 通常防御光0.44秒、破壊演出0.65秒。最大サイズはv511、彩度・通常アルファ合成はv512の設定を維持。

## CI
- 作業前にAGENTS、既存CIマニフェスト、v510のシールド/描画順テストを確認。
- **本体修正前**に新規tools/v514_shield_membrane_self_check.py、tools/v514_shield_membrane_runtime_check.gdを追加し、CIマニフェストに登録。通常の膜が中心を埋め、破壊後のみ中心が空になることをGodotで生成した実メッシュの位置と頂点アルファから検査する。
- 本体修正後、mainマージ後のフルPython/Godot CIで既存のシールド軽減、ターゲット、Bittaran挙動も回帰検査する。Android実機の色・見え方・音は別途確認する。
