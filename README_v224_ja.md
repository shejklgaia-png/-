# SERA v224 — 格闘2段目のノズル姿勢修正

## 症状
1段目から2段目への切り替えで、バックパックの物理ノズルと噴射が不自然な位置・向きへ回転し、一瞬見えなくなるように見える。動画の約3.0秒付近。

## 原因
2段目のBlockbenchアニメーションでは開始直後から Torso Y 約41°、Chest Y 約23° の回転がある。従来は正常な上半身の回転に対して、噴射軸をプレイヤールート基準の後方へ維持するため、ノズルの機械的ヒンジが最大80°まで逆回転した。ノズルのリムはヒンジから距離があるため、その回転に巻き込まれて表示位置も大きく動く。

## 対応
- 通常格闘中（接近・追尾・1〜3段目）に限り、物理ノズルの左右可動域を±20°、下方向を35°へ制限。上方向1°は維持。
- 既存の追尾方向の計算は継続して使い、上記の可動域でのみ制限する。噴射メッシュは常に実際のノズルに追従する。
- v222の胴体貫通防止（外向き dot ≥0.55）は引き続き適用。
- 通常BOOST、STEP、左画面方向制御の80°/90°限界は変更しない。
- 元のBlockbenchアニメーション、胸部・ノズルピボット位置、10角形噴射、15倍加速拡散、0.34秒の帯状軌跡は変更しない。

## 検証
`tools/v224_melee_nozzle_articulation_self_check.py` で通常格闘限定の角度制限、元のノズル左右ピボットとv222の外向き安全範囲、Melee2の元モーション姿勢を検証する。Android端末での実機描画・動作は未検証。
