# SERA v293 — 刀2段目の原本適用・カメラを40%近づける

## 刀モーション
- 新しい原本: `models/storage/SERA_BOOSTER_allテスト.bbmodel`
- クリップ: `Melee_katana2`、長さ **0.58333秒**、**70キーフレーム**（空トラックを除き19ボーン）。原本の19ボーンUUIDは現在のAリグに一致します。
- `sera_rig.gd`の初期化時、既存の原本アニメーションを読み込んだ後、**2段目だけ**追加インポートします。元の1段目・キック・標準3連撃・モデルは一切入れ替えません。原本がなければv290の反転生成2段目を使用します。
- カタナの2段コンボ、攻撃判定、刀身/鞘透明度、バッシュ/キックへのフリック派生、ヒットストップは従来どおりです。2段目をフリックせず再生すれば原本の0.58333秒まで進みます。

## 戦闘カメラ
- 設定 `CAMERA_DISTANCE_SCALE = 0.60` により、通常/接近半径と攻撃中最小半径、起動時半径の**希望距離**を40%短縮します。
- 基準数値: 通常16.0→9.6、最接近8.8→5.28、攻撃中最低11.3→6.78。これらは追従系の半径値で、実際のプレイヤーまでの直線距離とは完全には一致しません。
- 画面外へのはみ出しを防ぐ`_fit_full_frame`・`_minimum_boost_camera_radius`は維持します。安全フィットが必要ならカメラは指定位置より遠くへ後退します。追従速度・カメラ傾斜・ボス中心と部位ロック・操作入力を変更しません。
