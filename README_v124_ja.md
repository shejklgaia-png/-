# SERA v124 — ゲートのセラ方向への回転と青白い漏光

日付：2026-11-08

## 変更内容

### DEPLOYMENTゲートの方向

- 基準：v123（`main`）。
- 出撃ゲートは元のBlockbench資産・寸法を維持し、Godotで開口を中央のセラへ向けるようY軸回転させます。
- ワールド座標：ゲート `(4.00, 0.02, -10.48)`、セラ台 `(0.00, 0.00, -4.75)`。
- 向きは`atan2(セラX−ゲートX, セラZ−ゲートZ)`で計算し、約 **−34.9°**。元のゲートはローカル`+Z`が開口の向きです。ゲートの座標変更時にも開口がセラ側を向くようにしています。

### ゲート奥からの漏光

`scripts/command_nexus.gd`に`_deployment_gate_lightspill()`を追加。ゲート本体と同じ座標・回転を使用する、読み取り専用の軽量VFXです。

- ゲート内部に深さの異なる青白い**発光QuadMesh 2枚**
- ゲートの敷居と外部床面に淡い光が落ちる**水平QuadMesh 2枚**
- ゲート枠を照らす**影なしOmniLight3D 1基**

標準マテリアルのUnshaded＋透過＋Emissionを使用します。ボリュームライト・Bloom・フォグ・パーティクルは追加していません。Android用GL Compatibilityを維持します。これらは簡易的な光の演出であり、実際の体積光や物理的な照射の完全再現ではありません。

### 手前コンソール2台

- TRAINING（左）：`(-1.95, 0.0, 1.30)`、Y軸 **+36°**
- SYSTEM（右）：`( 1.95, 0.0, 1.30)`、Y軸 **−36°**
- v123の`x=±1.82, z=0.75, yaw=±34°`から手前へ0.55m移動。視界から切れないよう左右のみ微調整しています。
- 両端末のBlockbench原本は変更していません。

## 検証・非変更範囲

- `tools/v124_gate_lightspill_self_check.py`：ゲートの向き、エフェクト数、軽量化条件、720×1280画面想定のゲートと2コンソールの矩形・HUD重なりを静的検査。
- 既存の`v121`、`v122`、`v123`の回帰検査は新しい端末とゲート配置に合わせて更新。
- 対象変更ファイル：`scripts/command_nexus.gd`、`project.godot`、上記テスト、`DEVELOPMENT.md`、本README。
- 訓練ステージ、コントローラー、カメラ・格闘・ガード・ブースト、SERAモデル・アニメーション原本、音声、Blockbench拠点原本、他の4設備および起動時2択は不変更。基地メニューのタップ機能は追加していません。
- **GodotエディタとAndroid実機の描画・FPS・発光の見え方は未検証**です。静的検査で照度や透明素材の描画品質は保証できません。

## Android実機で確認するポイント

GitSyncで`main`を取り込み、Godotでプロジェクトを再読み込みします。ゲートの開口がセラの方向へ向き、奥から青白い光が見えること、手前のコンソールが大きくなりつつ画面端・HUDに重ならないことを確認してください。
