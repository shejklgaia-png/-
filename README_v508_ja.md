# SERA v508 — 基本素材12種類・品質指定レシピ・精製/分解設備

## 新しい素材体系
基本素材4系統をそれぞれ低/中/高に分けて**12品目**としました。素材名は同じ系統の品質差を一目で識別できるよう統一しています。

| 系統 | 低ランク | 中ランク | 高ランク |
| --- | --- | --- | --- |
| スクラップ | 雑スクラップ | 選別スクラップ | 高純度スクラップ |
| 合金 | 粗製合金 | 精製合金 | 高強度合金 |
| 電子部品 | 再生電子部品 | 汎用電子部品 | 高精度電子部品 |
| 有機素材 | 低活性有機素材 | 安定有機素材 | 高活性有機素材 |

- 製作レシピが要求するのは**固定素材ID・固定品質**です。同じ系統の低/中/高を代用品として直接渡すことは禁止。製作のために不足ランクへの交換が必要なら専用設備を通してください。
- 素材間の変換は**同系統の隣接ランク同士のみ**。精製装置で低→中→高へ、分解装置で高→中→低へ移動可能。
- **暫定比率**：精製は同じ素材を2個消費して1個の一段上の品質に変換。分解は上位素材1個を一段下2個に変換。往復しても素材が増えない単純な初期値です。経済バランスの承認前なので`scripts/sera_base_materials.gd`の定数で変更できます。
- 必要素材が足りない場合、無効な系統/方向/ランク/回数の場合、セーブが失敗した場合は**変換処理を実行せず所持数を維持**します。

## 拠点施設（新築ではなく既存2設備の用途確定）
- **精製装置（旧精製炉）**：素材の系統を選択し、低→中・中→高の2段階から変換先を指定。
- **分解装置（旧リサイクラー）**：高→中・中→低の2段階から変換先を指定。
- 両施設は3Dモデルとタップ領域をそのまま利用。所持数・必要個数・実行回数のUIを表示し、残高が足りない変換ボタンは無効化。
- **資材保管庫**：12素材の現行所持数を一覧表示。
- NEXUS上部中央、LABO中央、残りの周囲設備、クレート巡回・床・出撃など前バージョンの配置と挙動は変更しません。

## 保存と現時点の制約
- 所持素材は既存の3セーブスロットごとに保存。古いセーブには素材欄がないため初期値0で補完。セーブバージョンと装備の互換性は保持します。
- 素材入手量のバランスやボス撃破報酬との接続は未確定です。**素材を無料配布する機能や自動生成する機能は追加していません**。新規データは素材0から始まります。
- **LABOでの装備レシピそのもの・高レアリティ専用素材・電力/製作時間の消費は未実装**。装備レシピを追加する際は`meets_requirements()`で正確な素材IDとランクを照合してください。
