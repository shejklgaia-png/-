# SERA v366 — 起き上がり開始から旋回・接近モーションを再生

## 変更内容

ビットタランが起き上がるまで脚のモーションと接近が停止したままになる問題を修正しました。原因は、旧仕様でAIの`Turn`／`Approach`アニメーションと脚のIKステップの双方が、起き上がり完了まで`Idle`に固定されていたことです。

- **ダウンの予備動作・倒れたままの時間**：従来どおり静止し、頭と脚が地面で支持された姿勢を維持します。
- **起き上がり開始の最初の物理フレーム**：プレイヤーの位置に応じて通常の`Turn`または`Approach`クリップをすぐ再生します。同時に胴体のYaw旋回／接近移動と脚のIKステップを開始します。
- **起き上がり中**：胴体の持ち上がり、横倒し脚の復帰と通常の脚ステップを重ねます。頭を支えている脚は持ち上げず、ほかの対角脚からステップを始めます。
- **完全復帰後**：AIとIKを途切れさせず通常動作へ継続します。元の0.24秒の姿勢安定タイマーは残しますが、`Turn`／`Approach`を停止する条件にはしません。

頭部の追従は引き続き**姿勢復帰率70%から**で、低速48°/秒の開始と、腕の実メッシュとの干渉防止を維持します。0.6秒の予備動作、単脚2.5秒／4脚6秒のダウン時間にも変更はありません。
