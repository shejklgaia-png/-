# SERA v348 — ビットタラン6部位ロック・脚破壊リアクション

## ロック対象（6か所）

- **BODY**：実Blockbenchモデルの胴体メッシュ。空文字列の既存BODYロックIDを維持。
- **HEAD**：独立した頭部メッシュ。
- **FRONT LEFT SHIN**：左前脚の脛（`FrontLowerLeg_L`）。
- **FRONT RIGHT SHIN**：右前脚の脛（`FrontLowerLeg_R`）。
- **REAR LEFT SHIN**：左後脚の脛（`RearLowerLeg_L`）。
- **REAR RIGHT SHIN**：右後脚の脛（`RearLowerLeg_R`）。

既存の部位破壊耐久値・手動切替・自動ロックを再利用し、ビットタランのみ実際のモデルメッシュのAABBと関節追従の専用ロック・当たり判定に変更しました。頭と胴体、脛をそれぞれ独立して照準・攻撃できます。破壊済みの部位も攻撃を受けられます。

## ヒットエフェクト

- **脛の被弾**：該当する脚の付け根・脛・足先のメッシュ全体を閃光。
- **頭の被弾**：頭部メッシュだけを閃光。
- **胴体の被弾**：胴体メッシュだけを閃光。
- 各メッシュは独立したマテリアルを持つため、隣接部位へ被弾エフェクトを漏らしません。
- 共通のSERAダメージ数値・ヒットストップ・火花・部位破壊ゲージは維持。

## 脚破壊と姿勢崩し

いずれかの脛の部位耐久値がゼロになると、その脚の接地点を床Y=0mに沿って外側へ約1.05m滑らせます。同時に胴体を沈め、実測した頭部メッシュ中心が約1.35mになるよう前傾角度を毎フレーム自動計算します。動作は下降0.17秒→低姿勢保持→0.67秒から復帰し、**全体約1.15秒**で元の低重心IKへ戻ります。

破壊された脚のロック・当たり判定・被弾可能性は維持し、再破壊では同じダウンを繰り返しません。後続の別の脚を破壊した場合は、その脚で独立してリアクションが発生します。

## 開発構成・検証

- `scripts/bittaran_parts.gd`：6つの実モデルロック、専用物理/カメラ判定、部位別発光エフェクト。
- `scripts/bittaran_battle.gd`：共通ダメージパイプラインと新部位管理の接続。
- `scripts/bittaran_foot_ik.gd`：滑走と頭部高さ1.35mへの自動前傾、1.15秒で復帰。
- `tools/v348_bittaran_parts_runtime_check.gd`：Godot 4.7.2で6ロック、頭/胴体/脚のエフェクト独立性、全4脛の破壊・滑走・頭部下降・復帰、足裏IKを検証。
- 既存のv345/v346/v347ビットタラン回帰テストもそのまま実行。
- Android端末での画面表示、演出の質感・頭の打ちやすさは実機での確認が必要。

前版の2倍サイズとIK設定値は[前バージョンの記録](docs/history/release_notes/README_v347_ja.md)を参照してください。
