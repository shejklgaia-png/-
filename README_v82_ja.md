# セラ v82：接敵時ステップ・ターゲット基準のカメラ角度制御

- ベース: v81（先のGodot構文エラー修正を保持）
- 対象: 敵キューブ表面から1.0m以内で開始した左右ステップと、終了後0.18秒の短い移行期間
- 敵から見たプレイヤー方位とカメラ方位の差（target-centered polar yaw）を基準として、原則±65度の範囲へ収束させます。
- カメラが1フレームで急旋回しないよう最大300度/秒の回転速度を設けています。回転速度制限が優先される瞬間は角度差が一時的に65度を超えることがあります。
- ステップ開始時の絶対カメラ角を固定する従来の±18度制限は廃止しました。
- 至近距離の保護中は、画面端補正による強制回転を避け、ズームによるフレーム保護を維持します。
- 通常移動・円外ブースト・格闘・遠距離ステップに対するカメラ係数はv78/v81と同じです。
- 新たなドラッグ／タップで移行保護を解除し、通常操作に戻します。
