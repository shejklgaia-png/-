# SERA v286 — 近距離で敵とセラが重なって見える問題の対策

添付のv285スクリーンショットでは、待機中のセラが大きな敵の脚部と重なり、カメラが低く近い位置から捉えているため、両者の位置関係が分かりにくくなっていました。

## 原因
- v285の近距離カメラは、敵中心を基準にセラの方向へYawを寄せるため、**セラが敵の真正面に重なる画角**になり得ました。
- 元の「待機中は両者のシルエットを分離する角度を探す」処理が、左右蹴り後の近距離でも十分な画面上の間隔を確保できていませんでした。
- v285の旋回半径はボスの**中心からセラまでの距離をそのまま固定**し、幅広い外側の脚部のボリュームを十分に考慮していませんでした。

## 修正
1. **近距離での左右蹴りと蹴り後の待機状態**では、カメラが候補の水平角を検索し、敵とセラの**画面上のシルエット間隔が広くなる画角**を選択します。45°の制限は維持します。十分な間隔が作れない場合は、指定角度内で最大の間隔が得られる向きを使います。
2. 敵との距離が6m以下では、画角を徐々に俯瞰寄りへ移行。3.7m以下ではカメラの上下角を約39°にし、足元・距離関係を見えるようにします。通常の遠距離カメラは変更しません。
3. 左右蹴りの2段目の旋回時、敵の大きな脚に入ることを防ぐために、**最終旋回半径を最低3.55m**にします。近い位置から蹴り始めた場合、旋回中に滑らかに半径を拡大し、プレイヤーを瞬間移動させません。障害物との物理衝突判定は維持します。
4. 1段目と2段目のモーションキー、蹴りの2回の命中判定、通常STEPの360°連続入力、スラスター仕様、EN消費は変更しません。
5. 画面上の分離にはボス自体のサイズ・衝突物・現在のカメラ方位による限界があります。常に完全な非重複を数学的に保証するものではありません。
