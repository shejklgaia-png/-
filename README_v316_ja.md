# SERA v316 — モデル・モーションの正本統合

- Standard：通常骨格、標準メッシュ、基本モーション、NEXUSpose。
- BirdLeg：鳥脚6関節・10メッシュ・鳥脚専用モーションのトラック。通常上半身を共有。
- Katana：刀の基礎モデル、初段・二段目のキーフレーム。二段目は専用ファイルからロード。
- Equipment：A/B装備、ブースターのみ。アニメーション・頭C・下半身Dの重複を除外。
- storage：頭Cと下半身Dは各1つの正本を管理。
- すべての正本は models/manifest.json に登録。assets側のJSON/GDScriptはAndroidエクスポート用の生成データです。
- 旧モデルは回帰テスト/再現用に保持。通常操作、カメラ、戦闘、ステップ距離と速度はv315から変更しません。
- Godot実行CIでモデル/装備/モーションを検証。Android実機表示は別途確認が必要です。
