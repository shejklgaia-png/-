# SERA v486 — 俯瞰視点で探索できる拠点（第1段階）

## 新しい探索シーン
- `scenes/base_exploration.tscn`：既存のBlockbench格納庫モジュールを再利用した、縦画面向けの見下ろし視点の拠点です。ステージ中央には整備台、左右には端末、後方に出撃ゲートがあり、周囲に金属廃材を置いています。
- `scripts/base_exploration.gd`：画面右下のドラッグスティックでSERAを歩かせます。PCでは方向キーも使えます。俯瞰カメラがゆっくり追従し、壁と整備台中央を通り抜けません。
- SERAの外見は保存済みの現在の装備選択を使用します。移動時は既存のRUNモーションを使用し、戦闘用の操作や数値は変更しません。
- CRATEは履帯・横長バイザー・整備用マニピュレーターを備えた仮ローポリモデルです。表情や飲食描写はありません。

## NEXUSとの往復
- COMMAND NEXUSの全体画面左下に「EXPLORE BASE」を設置。ここから探索へ移れます。
- 探索中は右上の「NEXUS」でいつでも既存のメニューへ戻れます。
- 整備・訓練・システム・データアーカイブ・出撃の5地点に近づくと「開く」が表示されます。対応メニューを直接開くため、既存機能を二重に作りません。
- メニューの一時的な遷移先指定だけをSeraSaveに持たせ、セーブファイル形式や装備情報には変更を加えません。
- 起動時のビットタランテストシーンはそのまま保持します。拠点へは従来のNEXUSから入ります。

## 検証
- 新規静的検査 `tools/base_exploration_self_check.py` と実Godot検査 `tools/base_exploration_runtime_check.gd` を、実装に先行して共通CIのmanifestへ登録しました。
- 壁外への移動、設備の接近判定、初期SERA/CRATE/カメラの生成とNEXUSルーティングを確認します。
- 他の322件の既存検査の仕様値や範囲は変更していません。マージ後のmainで全件のPython/Godot CIを実施します。
- Android実機では片手移動、カメラの見下ろし角、機体の向き、UIタップ領域、格納庫の遮蔽や負荷をご確認ください。
