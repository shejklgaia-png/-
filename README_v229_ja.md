# SERA v229 — SLIDE/BOOSTモーション遷移とカメラ補正

## SLIDE・BOOST
重量脚部B/DのSLIDEは4方向Boost_*ポーズの50%、実BOOSTは100%を使用します。従来は同一クリップ内でこの比率が即時切り替わっていたため、0.18秒smoothstepで連続補間するように変更しました。途中で状態が反転しても現在の姿勢から続け、両足の水平化・二骨IK・腰の沈み込みも同じ重みで補間します。

既存のBOOST解除後0.50秒姿勢維持、加減速、スラスター、装備保存、戦闘・ステップ・ジャンプは変更しません。

## 左移動のカメラ
画面端でカメラ角度を瞬間補正していた経路に対し、横幅の0.8%手前から補正を開始し、強制的な方向補正を最大240度/秒に制限しました。画面全体のフィットズームには0.12mの余裕を設けます。左右共通に適用します。

## 検証
GitHub Actionsの静的・数式チェックを追加しました。Xperia実機でのカメラの滑らかさ、画面端の安全枠とモーション中の脚の接地表示は未検証です。
