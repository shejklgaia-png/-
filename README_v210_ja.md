# SERA v210 — 後方ブースト・後方ステップ時のスラスター下向き制御

## 演出意図
背泳ぎで後ろへ進むように、セラがターゲットと反対方向へブースト・ステップする際、背中の左右スラスターノズルを下へ向けます。3Dモデル本体と噴射エフェクトが一体で動きます。

| 操作 | スラスター姿勢 |
|---|---|
| 真後ろへのBOOST | 左右のノズルを下90°、左右振り0°へ |
| 真後ろへのSTEP（後方フリック） | 同様に下90°へ |
| 斜め後方へのBOOST・STEP | 後方成分に合わせて0〜90°まで滑らかに補間 |
| 前方・真横へのBOOST・STEP | 従来の移動反対方向への追従を維持 |
| 通常RUN、攻撃追尾、バッシュ追尾 | 変更なし（後方への特別な補正なし） |

## 実装詳細
- STEPは発動時に保存したターゲット基準のフリック方向（+Yが後方）から後方重みを求めます。従来の専用Backstepにも対応します。
- BOOSTはタッチで指定した地上移動方向とセラのローカル後方(+Z)の内積を使います。壁で実移動がゼロになっても、ノズルが一瞬元の向きへ跳ねることを防ぎます。
- main → sera_rig → sera_equipment → back_thruster_fx に0〜1の後方重みを渡します。FXスクリプトはYawを0°へ、Pitchを下90°へ重みに応じて補間します。
- ピボットはv209の制作モデルThruster_L/Thruster_R、角度制限は左右80°・下90°・上1°、回転追従時定数は0.075秒のままです。
- 走行・ステップ速度、モーション、EN・HP、ガード、攻撃、ターゲット追尾、重脚SLIDE、既存メッシュや噴射タイミングは変更していません。
