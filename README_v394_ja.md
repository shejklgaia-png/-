# SERA v394 — ビットタランの螺旋IK・頭部の腕復帰範囲・攻撃中ダウンの振りかぶり

- 胴体の旋回に接地中の脚が追いつかない場合、胴体に対する足先の角度差を測定し、**股関節→足先の軸まわりに膝の曲げ面を最大70°ねじる**螺旋状の脚動作を追加しました。旋回差が8°以下では通常IKへ戻り、75°で最大になります。ねじりは毎秒220°の速度制限で補間し、脚の骨長・足先の接地座標は維持します。攻撃中の元モーション再生脚とダウン中の特殊脚姿勢はねじり対象外です。
- 頭は腕と接触していなくても、**通常姿勢に戻る前腕の付け根位置**から算出した左右の機械的な可動範囲を超えて旋回しないようにしました。前足の肩Pivotと頭のPivotから腕復帰側の境界角を求め、安全余裕45°を確保します。現行の10cm干渉制限も維持します。
- **攻撃中に脚破壊によるダウンが始まる場合のみ**、現在の攻撃から胴体と攻撃脚をBlockbenchの「踏みつけ」振りかぶりキーフレームへ**0.60秒**のsmoothstepで移行してから通常の物理ダウンへ進みます。頭部の独立した対プレイヤーYaw/Pitch追尾はそのまま維持し、通常のダウン予備動作に付随する頭部の反り返りは適用しません。攻撃していない時の従来のダウン予備動作・硬直・起き上がりは変更しません。
- 対象の脚の他の3本はワールド固定の支持脚IKを維持します。元のモデル原本・アニメーションキーフレーム・部位破壊タイマー・ダウン時間・頭の上下追尾方式は変更していません。
- 専用Godotランタイムテストと既存の全CIを実施します。Android端末上の見え方は別途確認が必要です。
