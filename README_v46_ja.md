# セラ v46 — 円弧ステップ「時間固定／速度固定」画面切り替え

v45をベースに、左右フリックでのステップを「ターゲット中心の円弧移動」に変更し、画面右上に比較用ボタンを追加しました。

## 操作

- **左／右フリック**：敵との距離を保つよう、敵を中心とした円弧を左／右へ移動します。
- **右上の `STEP TIME 0.26s` ボタン**：押すたびに `STEP SPEED 8.5m/s` と交互に切り替えます。初期設定は時間固定です。
- **右上の小さな表示**：直前に発動したステップの円弧長（m）／所要時間（秒）を表示します。切り替え中のステップには即時適用せず、次のステップから反映します。
- **通常ドラッグ**：v45と同じ判定。フリックを離すまでは従来の左右移動が有効。右上のボタン操作は移動／攻撃として扱わないようタッチIDを分離しています。
- **タップ攻撃**：v45のまま維持します。

## 両モード共通の軌道

- 円弧角度：**25°**。ターゲット中心からの半径が長い場合は、弧長**3.0m**を上限として角度を縮小します。
- ステップ開始時点の敵中心・半径・カメラ右方向から軌道を決め、ステップ中は敵との半径を維持します。
- **時間固定**：距離に関係なく0.26秒。距離が長いほど横移動速度が上がります。
- **速度固定**：弧に沿って8.5m/s。距離が短いと早く完了し、長いと時間が長くなります。
- **両モードとも円弧上は等速移動**：比較条件を揃えるため、v45の減速補間は使いません。
- 例：敵まで5mの場合、弧長約2.18m。時間固定は0.26秒、速度固定は約0.257秒。敵まで2mの場合、弧長約0.87m、速度固定は約0.103秒です。
- 敵中心まで10cm未満で円弧が定義できない場合のみステップは発動しません。
- 敵とプレイヤーに物理衝突判定を追加した変更ではありません（v45のまま）。

## ファイル変更

- `scripts/main.gd`：ステップ軌道、時間の算出、モード切り替えUI、GUI入力の除外処理。
- `project.godot`：プロジェクト表示名のみ変更。
- 3Dモデル、剣エフェクト、アニメーション、カメラ追従関数、通常ドラッグ判定条件は変更していません。
