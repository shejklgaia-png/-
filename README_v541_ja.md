# SERA v541 — ビットタラン「弾き」の発動範囲拡大

## 2026年11月22日の更新

- 前脚の「弾き」（KICK）のAI発動判定を、**実際の前脚足裏から3.10～6.30m、ボス正面左右60°以内**へ拡大しました。旧仕様は3.75～5.15m、左右38°でした。
- 距離の計測基準はこれまでどおり最新の前脚の足裏ワールドXZ位置です。胴体中心からの推定距離ではありません。
- 踏みつけの3.0m以内優先、なぎ払いの発動範囲、後足に弾きモーションがない制約、直前と同じ技を避ける選択は維持します。
- 攻撃モーション、ダメージ、接触メッシュ、ヒット発生時刻（原本0.35～0.75秒）、ダウン・効果音・カメラは変更しません。広げたのは攻撃の**発動判定**であり、実際のダメージ当たり判定ではありません。
- 既存の距離・角度CI期待値を先行更新し、前脚左右対称、距離・角度の境界、後足制限、別技優先、従来のヒット発生時刻を確認する静的/Godot実行時テストを登録しました。
