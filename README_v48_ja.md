# セラ v48 — 最低1.5mの左右ステップ

v47をベースに、左右フリックの移動距離に**1.5mの下限**を追加しました。

## 変更

- ステップ移動距離（円弧上の道のり）：**1.5〜4.0m**。
- 基本回り込み角度：**35°**。近距離では1.5mを確保するため自動的に角度を拡大します。
- 敵との距離が約**2.46m未満**のとき最小距離制御が効きます。
- 円弧中心への距離が約**0.716m未満**の極端な重なり時には、異常な多周回を防ぐため、円弧ではなく接線方向へ1.5m平行移動します。この例外のみ敵中心からの半径は保持しません。
- 所要時間は引き続き**0.26秒固定（起動時の初期モード）**。比較用の速度固定切り替えボタンは保持します。
- UI待機表示は `MIN 1.5m / MAX 4m` に変更。

| 敵までの距離 | v47移動距離 | v48移動距離 | v48回り込み角度 |
|---|---:|---:|---:|
| 1m | 0.61m | **1.50m** | 約85.9° |
| 2m | 1.22m | **1.50m** | 約43.0° |
| 3m | 1.83m | 1.83m | 35° |
| 5m | 3.05m | 3.05m | 35° |
| 8m | 4.00m | 4.00m | 約28.6° |

数値は直線距離ではなく、移動経路に沿った距離です。円弧時は敵との半径を保ちます。

## 変更していない操作

- 左右ドラッグで通常移動、左右の短い水平フリックは指を離したときに発動
- ドラッグを再開するとステップを中断
- タップ攻撃、ロックオン、カメラ、左右ステップポーズ、当たり判定は継承
- 右上の時間固定／速度固定ボタンは維持。ボタンへのタッチは攻撃やフリックと分離

## 検証

`python tools/v48_orbit_self_check.py`：ジェスチャー・戦闘・カメラ関数のベース照合、UI配線、最小・最大移動距離、FPS非依存性、左右、両モードおよび元のアセットの整合性を静的検証。

Godotエディターでの実行とAndroid実機での操作感はこの環境では未確認です。
