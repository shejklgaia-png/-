# SERA v148 — RUN・BOOSTの実移動速度を1.25倍（2026-11-08）

## 変更点
地上でドラッグ操作したときの**通常移動（RUN）**と**ブースト移動（BOOST）**を、それぞれ従来比 **125%** にしました。

| 操作 | v147 | v148 |
| --- | ---: | ---: |
| RUN最大移動速度 | 3.25 m/s | **4.0625 m/s** |
| BOOST最大移動速度 | 4.875 m/s | **6.09375 m/s** |

`MOVE_SPEED=3.25`と`MOVEMENT_BOOST_MULTIPLIER=1.5`をそのまま残し、**地上移動式にのみ**`GROUND_MOVE_SPEED_SCALE=1.25`を適用しています。操作円内のアナログ入力の強弱も従来比1.25倍になります。

## 維持する挙動
BOOST開始125%、解除110%、0.10秒保持、加減速0.15秒、コントローラー表示、RUN/BOOSTアニメーションの再生倍率、STEP・BACKSTEP、格闘時の自動接近、ガード、カメラ、CUSTOMIZE、BGM、モデルおよびジャンプのデバッグ用空中ステアリングは変更しません。画面の「RUN x1.0」「BOOST x1.5」は相対倍率のため変更不要です。

Godotのプロジェクト名は`SERA v148`です。

`tools/v148_ground_movement_speed_self_check.py`で定数・速度式・速度数値・変更対象範囲を検査できます。ソース構造上の検査であり、Godot起動・Android実機のプレイ感・実移動計測は未検証です。
