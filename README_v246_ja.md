# SERA v246 — コントローラー枠線削除と全画面操作

## 変更
- 旧v243〜v245の「画面右下4分の1からしかタッチ操作を始められない」制限を解除しました。画面の上下左右どこでタッチしても、その位置を中心に動的コントローラーを表示します。
- UIボタンが表示されている位置はコントローラー起動の対象外です。左右LOCK、AUTO/MANUAL、HAND設定、NEXUSへの戻り、トレーニングテスト、および敵攻撃デバッグの各ボタンを優先します。読取専用HUDの余白は操作できます。
- 右下の操作枠を囲っていた青緑の長方形の枠線と下の角マーカーを削除しました。背景グレーのグラデーションは変更していません。

## 維持する挙動
- コントローラーのRUN表示円半径70px、デッドゾーン11.25px、BOOST基準半径105px、BOOST開始115.5px/解除94.5px、0.10秒のBOOST確定。
- 通常攻撃タップ、全方向のドラッグ、フリックステップ、ガード、ガードバッシュとAUTO/MANUAL切替、左右ロック切替。
- コントローラーはタッチした位置を固定中心にし、ドラッグ・離指は画面内の位置による制限をしません。UIボタンとゲーム操作用の指は従来どおり分離します。

## 検証
- v243、v244、v245回帰検査を新版で整合させ、`tools/v246_fullscreen_controller_self_check.py`を追加しました。既存CIへ登録しています。
- 静的検査は入力の可否や描画コードを確認するもので、Godot構文解析・Android実機の表示／複数指操作確認ではありません。
