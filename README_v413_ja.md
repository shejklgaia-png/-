# SERA v413 — ビットタランの前後傾と攻撃後補正の完全初期化

## 変更
- 前足の踏みつけ・弾き・なぎ払いは、従来の前傾寄りのキーフレームとIKを維持します。
- 後足の3攻撃すべてで、胴体後側を持ち上げる局所X軸の後傾補正（弾き4°、踏みつけ・なぎ払い8°）を加えます。既存の後足なぎ払いの8°を共通化し、予備動作で滑らかに入り、攻撃終了時の回復区間で完全にゼロに戻します。攻撃脚の元キーフレームや足裏の接地点は改変しません。
- 通常終了・中断・直後の別攻撃への切り替えを同一の`clear_attack_pose()`で統一し、脚の接地位置フィット、接地点キャッシュ、持ち上げ、ポール、ねじれ、姿勢スウェイを初期化します。頭追尾・歩行時の接地補正など攻撃以外の責務は維持します。
- リグ側の弾きミラー混合率と射程係数も攻撃終了時に既定値へ戻します。

## 背景と調査
従来の`set_attack_pose({})`は接地高さをゼロにするだけで、攻撃中に蓄積した`attack_exit_lift_world`、軌道補正、ポールなどを通常終了時に消していませんでした。中断用の別経路のみ完全初期化していたため、次の弾きの予備動作に前回の残留値が混入する余地がありました。攻撃終了時の通常経路にも同じ初期化を適用することを根本修正とします。

## 確認
- `tools/v413_bittaran_rear_attack_reset_runtime_check.gd`：4本の脚×3攻撃の後傾補正、前足の無補正、通常終了・直後の別攻撃への切り替えで前回の補正が残らないことをGodotで検査。
- 既存のv397（後足なぎ払いの8°）、v410〜v412（予備動作の接地・鏡映・弾きの膝位置／ねじれ）はCIで引き続き検査します。
- Android実機での最終的な弾きの予備動作・外観はCIとは別に確認が必要です。
