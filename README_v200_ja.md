# SERA v200 — RUN接地制限と360°フリックステップ

## 接地タイミング
- WAIT（立ち）では、実際の足裏を表示床に接地させます。
- RUN（前・後・方向転換）では、既存の足音イベント foot_contact が発火する**そのフレームだけ**接地し、それ以外は従来の装備別固定Y位置へ戻します。
- 通常攻撃3段、追尾、バッシュ、ガード、被弾、前・後・左・右・斜めステップ、ブーストは、アニメーションへの追加接地を行わず以前の高さに戻します。
- ジャンプ中とNEXUS展示中も地面へ引き戻しません。モデルとモーション原本、足音発生の判定ロジックは変更しません。

## ステップ
- 0.24秒以内に78px以上・500px/s以上の距離と速度を満たすリリースフリックを、**360°全方向**で認識します。斜め・前方向も無効にしません。戻しフリックの除外、BOOST済み操作の除外、ガードバッシュ優先、通常ジャンプ無効は維持します。
- 左右は従来のターゲット周回を維持、後ろは4m、前は暫定2m、斜めは横周回と前後移動を連続して合成します。衝突検知には従来のスイープ移動を使います。
- 見た目は Step_L / Step_R / Backstep と、前方向のみ暫定 Boost_front を方向に応じてブレンドします。モーションは開始0.12秒・終了0.16秒でつなぎます。
