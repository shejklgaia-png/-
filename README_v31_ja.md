# セラ v31 — 斬撃をターゲットより前面に表示

v30をベースに、白い立体剣軌跡・薄いテクスチャ残光・独立粒子、および既存の命中時火花を、ターゲットの手前に**描画上**表示するテスト版です。

## 変更箇所
- `shaders/slash_C_volume.gdshader`：`depth_test_disabled` を追加（奥側のみの `cull_front` や半透明は維持）。
- `shaders/slash_C_sprite.gdshader`：`depth_test_disabled` を追加。薄い白色残光を維持。
- `shaders/slash_C_particle.gdshader`：`depth_test_disabled` を追加。弧に沿うランダム粒子を維持。
- `scripts/sword_trail.gd`：透明パス内の描画優先度を立体弧 `100`、残光 `105`、粒子 `110` に変更。
- `scripts/hit_burst.gd`：命中時の火花も透明描画パスへ移し、深度テストを無効化。優先度は `120`。

## 変更していないもの
- `Swordeffect` の元の位置・回転・スケールと Blockbench キーフレーム
- 前方オフセット **0.55m**、8コマUVアニメーションと再生タイミング
- 白色のエフェクト、立体メッシュ形状、残光・粒子生成方法
- カメラ、ドラッグ移動、攻撃判定、ターゲットのHP処理

## 注意事項
- **ターゲットだけでなくプレイヤー本体や他の3Dオブジェクトよりも前に見える**ことがあります。これは「常に見える」指定の仕様です。狙った箇所だけに深度判定する方法ではありません。
- `render_priority` だけでは不透明ターゲットによる遮蔽は解消しないため、**深度テストを無効化**しています。
- カメラに対して斜めになって細く見えることや、裏面カリングで消えることなど、**深度以外の原因**による見え方は今回変更していません。
- 初期色は白。前バージョンと同じ起動・操作方法です。

## 検証
- `python tools/v31_validate.py`：静的差分・設定・素材・モーション座標を検証。
- **Godotエディターでの起動とXperia 1 V実機での描画確認は未実施**です。
- ゲームとしては `project.godot` を開いて短くタップし、ターゲットに重なった斬撃が消えないかを確認してください。
