# SERA v458 — スラスターが聞こえない問題の対策

## 変更点

AndroidのGit同期でOGGが届いた直後、Godotのインポートキャッシュに音源が登録されていないことがあります。v457のスラスター音は静的preloadに依存していたため、音声の読み込みに失敗する可能性がありました。v458ではインポート済みリソースを優先し、存在しない場合は実際のOGGバイト列を直接読み込む方式に修正しました。同期が遅れた場合の再試行にも対応しています。

- **ブースト中**：01の4.90秒ループを保持、出始め0.075秒フェードイン
- **ステップ開始時**：13-1を一度だけ鳴らし、01はステップ終了まで連続
- **追尾加速時**：13-1を重ね、01は継続
- **スラスター停止**：01は0.22秒かけて消え、炎も既存の0.22秒フェードを維持
- **音量**：01は-12.5dBから-3.0dB、13-1は-3.0dBから+6.0dBへ調整（原音のピークとの合算でクリップを回避）
- **ビットタランBGM**：スラスターと加速音の発生時だけ最大7dB下げ、音声終了後に自然に元へ戻す

## 検証

Godot実行テストでOGG直接デコード、音声プレイヤーの読み込み／ループと重ね再生、ボスBGMダッキングを検査します。Androidの実際の端末スピーカーで聞こえることは実機確認が必要です。

**重要：** GitHubのコードをマージしてもインストール済みのAPKは自動的に更新されません。Godotで実行している場合はGitを同期してからGodot側でプロジェクトを再読み込みしてください。APK版の場合はv458を含む新しいAPKのインストールが必要です。
