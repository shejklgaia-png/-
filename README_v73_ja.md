# セラ v73 — 単一円コントローラ / 円外でブースト

## 変更概要
- ベース：`sera_portrait_godot_melee_v72_run_boost_ring.zip`。
- 前版の外周円の**外縁**（半径168仮想px）をそのまま採用し、内部を一体の半透明円で表示。
- 指の操作方向を**中心から指先までの線＋先端の丸**として表示（旧v70の方式）。先端は円内にクランプされるため、指が画面外へ大きく動いても線は暴れません。
- 二重の山形矢印を上下左右の**円の外側**へ移動。中央円、内周リング、透明な分離帯、内側矢印は廃止。
- カラーと透明度は従来のシアン系RGBA（円0.08、輪郭/線0.30、指先0.45、強調0.87）を再利用。

## 移動判定
- タッチ開始地点が円の中心になります。
- **指の距離 `d <= 168px`**：RUN。アナログ入力は `d / 168`（最大1.0）、最高速度3.25m/s。
- **指の距離 `d > 168px`**：BOOST。フル入力で最高速度4.875m/s（通常の1.5倍）。
- 境界の**ちょうど168pxはRUN**。1pxでも円外へ出るとBOOST、内側へ戻すとRUN。
- BOOST中は円周・外側矢印が強く発色し、既存の `RUN 1.0x` / `BOOST 1.5x` と上部HUDも連動。
- 既存のタップ攻撃、リリース時のフリックステップ、敵AI、ノックバック、カメラ・モデル等の挙動を変更しません。
- ブースト専用モーションは追加せず、従来の走行モーションを使用。

## 変更対象
- `scripts/main.gd`：入力強度と速度切り替え境界を円の外へ変更。
- `scripts/touch_overlay.gd`：円と中心からの線、外部二重矢印の直接描画。
- `project.godot`：版名。
- `DEVELOPMENT.md` と `README_v73_ja.md`、`tools/v73_outside_circle_self_check.py` を追加・更新。
