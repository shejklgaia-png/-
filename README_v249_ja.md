# SERA v249 — ロック中の攻撃対象を厳密化

## 原因
ロック部位への剣接触が無い場合に胴体の接触へ代替され、近距離命中補助やシールドバッシュの射程が胴体基準になっていました。攻撃の接近完了条件も胴体基準で、外側に張り出した頭・脚への追尾を途中で終了していました。

## 変更
- ロック中は剣がその部位AABBに接触したときだけ命中。外した攻撃が別部位・胴体に吸われることを防止。
- 通常攻撃1〜3段の追尾、バッシュ、近距離ヒット補助はすべてロック部位の水平AABBまでの距離で判定。
- ヒット補助で表示する命中位置もロック部位のAABB上へ合わせる。
- 有効な部位ロックがないときは従来の胴体命中・接近を維持。

## 維持と未検証
AUTO/MANUALロック、部位HP・破壊、敵物理コライダー、カメラ、攻撃モーション・タイミング、STEP/BOOST等は変更なし。Godot/Android実機の動作は未検証。
