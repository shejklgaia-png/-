# SERA v468 — 青い球体の収縮を1秒間に延長

## レールガンの発射前演出
- 青白い球体の表示時間は引き続き**2秒間**（10秒周期の8.0～10.0秒）です。
- 出現後**0.2秒かけて膨張**し、9.0秒までサイズを保持します。
- 発射の**1秒前（9.0秒）から1秒間かけて滑らかに収縮**します。収縮はsmoothstepで、9.5秒時点の球体スケールは約半分になります。
- 球体は10.0秒の発射開始と同時に消灯し、直ちに2秒間のレーザー照射へ切り替わります。暗転はありません。

## 維持する挙動
- 充填完了の8.0秒から追尾を滑らかに立ち上げる**2秒間のイーズイン**、発射瞬間のプレイヤー完全捕捉。
- 発射後の低速追尾（Yaw24°/秒・Pitch18°/秒）、ブースト回避性能、10秒周期、2秒照射、0.4秒保持、0.8秒復帰。
- 3本の充填バー、2軸・Roll禁止の砲台、全身フレーミングカメラ、既存モデル・脚IK／攻撃。

## 検査
- `tools/bittaran_railgun_runtime_check.gd` に、収縮開始時9.0秒のフルサイズ、9.5秒の約半分、9.9秒のさらなる縮小、10.0秒のレーザーへの切り替えを検査する条件を追加しました。
- 全件CIのPython・Godotテストを保持します。
