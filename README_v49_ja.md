# セラ v49 — 速度固定ステップを採用（最大0.4秒）

v48を基準に、時間固定／速度固定の比較モードを廃止し、**速度固定方式**に一本化しました。

## ステップ仕様

- 移動速度：**10.0m/秒（経路に沿った一定速度）**。
- ステップ最大時間：**0.40秒**。
- ステップ時間：1.5m時 **0.15秒** ～ 4.0m時 **0.40秒**。
- 移動距離：**1.5～4.0m**（直線距離ではなく円弧上の移動経路）。
- 回り込み基本角度：**35°**。近距離では最低1.5m確保のため角度を拡大、遠距離では最大4.0mに収めるため角度を縮小。
- 敵中心との距離は原則維持。極近接（半径約0.716m未満）でのみ接線への1.5m直線移動に切り替え。
- 画面右上の比較ボタンは削除し、固定速度の表示ラベルに変更。前回ステップ距離・所要時間は従来どおり表示。

旧版速度固定モードの **8.5m/s** では4.0mを進むのに約0.471秒かかります。
最高移動距離4.0mと0.40秒上限を両立しつつ、速度を途中で変えないため、速度を **10.0m/s** に上げました。

| 敵中心との距離 | ステップ経路長 | 所要時間 |
|---|---:|---:|
| 1m | 1.50m | 0.15秒 |
| 2m | 1.50m | 0.15秒 |
| 3m | 約1.83m | 約0.18秒 |
| 5m | 約3.05m | 約0.31秒 |
| 8m | 4.00m | 0.40秒 |

## 継承する操作

- 左右ドラッグ：通常移動を継続。短い水平フリックを離したときにのみステップ。
- ステップ中に再ドラッグすればステップを中断して通常移動へ復帰。
- タップ攻撃、ロックオン、カメラ、Step_L / Step_Rポーズ、その他エフェクトはv48を維持。
- 右上の情報表示領域に触れても攻撃／ステップが誤発動しないよう入力を除外。

## 検証

`python tools/v49_speed_step_self_check.py`：既存入力・カメラ・攻撃処理との関数一致、式とUI配線、移動距離・所要時間・フレームレート非依存性、左右方向・敵中心重なり時の例外、その他アセットの整合性をチェック。

Godot実行環境とAndroid実機がないため、実機でのタッチ操作感・実際の描画は未検証です。
