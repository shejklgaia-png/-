# SERA v166 — トレーニングルームから拠点へ戻る（2026-11-09）

## 操作
- トレーニングルーム上部HUDの中央寄りに「BACK TO NEXUS」を追加。タップすると拠点メニュー（SERA COMMAND NEXUS）へ直接移動します。
- PCでは同ボタンのクリック、Esc（ui_cancel）でも戻れます。
- Androidのシステム戻る要求もトレーニングルーム内では拠点への移動として処理し、アプリの自動終了を防ぎます。トレーニングを離れたら元の終了設定へ戻します。
- NEXUS側の「TRAINING」端末→トレーニングルームへの遷移は従来のままです。

## 実装
- `scripts/main.gd` にNEXUSシーンパス、戻る用ボタン、二重遷移防止と遅延シーン切替を追加しました。切替失敗時はエラー出力し再試行可能にします。
- タッチ→マウス変換を有効化せず、生のタッチ開始座標でボタンの矩形を判定します。既存HUD／敵攻撃デバッグ領域をタッチした際の格闘・ガード・移動の誤発動防止を維持します。
- ボタンは既存の左側戦闘情報と右側STEPテレメトリーの間に配置し、ステージの中央や下部の指操作領域を塞ぎません。
- `project.godot` の表示名は `SERA v166`。Bセット装備・カラー、ブースト/RUNの入力と補間、カメラ、3段格闘、ガード、ジャンプデバッグ、BGMには変更なし。

## Androidでの確認手順
1. GitSyncで `main` を取り込み、Godotで `SERA v166` を開きます。
2. 拠点メニューからTRAININGを選びます。

4. 再びTRAININGへ入り、移動・BOOST・格闘・ガードが従来どおり動くか確認します。
5. 必要に応じてAndroidの戻る操作でも同じ遷移になることを確認します。
