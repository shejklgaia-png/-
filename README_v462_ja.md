# SERA v462 — ビットタランの通常歩行の歩幅を2倍に

ビットタランが通常歩行で次の対角脚ペアを踏み出すまでの移動距離基準を **0.62mから1.24m（2倍）** に変更しました。

- 通常歩行の接地IKによる踏み替えの間隔が大きくなり、一歩を大きく見せます。
- 既存の接地位置計算、対角2脚ずつの歩行、脚上げ高さ0.22m、踏み出し時間0.52秒、胴体の移動速度・加速度は変更しません。
- 攻撃後の4脚復帰用の強制2ペア踏み替えと、次の攻撃前に通常歩行を3歩完了する条件も変更しません。
- 歩行IKの実接地・攻撃前の歩数・反復攻撃はGitHub ActionsのGodot CIで検証する対象です。Android実機の見た目と足の届き方は別途確認が必要です。

※2倍にしたのは通常歩行の踏み替えを開始する距離基準です。実際の着地点は移動中の胴体位置に合わせて毎フレーム再計算されるため、各歩の足先移動距離は移動方向や旋回の影響を受けます。
