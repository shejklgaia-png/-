# SERA v261 — 斜め後退BOOSTの背部ノズル方向を修正

## 動画と現行コードの調査
- 左方向の入力が少しでも含まれると、左移動用の `left_sector_world` による独立ノズル方向の処理が通常の後退用 `backstroke_weight` のピッチ補正を上書きしていた。
- 左斜め後退では、移動が後方を含むにもかかわらず、ノズルが横へ向きすぎ、後方入力を強めても下向きに十分移らない非対称があった。

## 修正
- 左用の「画面下から右下へ45°まで」の方向を計算した後、後退成分 `backstroke_weight` の割合に応じて **世界下方向 `Vector3.DOWN`** へ球面線形補間する。
- 後退成分0%なら従来の左移動用方向をそのまま使用し、50%なら下方向へ半分、100%なら世界下向きへ移る。斜め後退で急にノズル方向が切り替わらず、左斜め後退と右斜め後退の下向き優先度を合わせる。
- モデル実ノズルのピボット回転・`TURN_TIME=0.075` の追従補間・世界下向き浮力補正・スラスター帯状軌跡・描画順・格闘時の胴体侵入防止は変更しない。
- 既存 `held_boost_left_sector_world` に補正後の方向を保存するため、入力が一瞬ニュートラルになっても角度を保持し、再入力時に滑らかに追従する。

## 不変更
- 前後左右・斜めへの移動速度、RUN/BOOST/STEP・EN、入力ジェスチャー、四方向STEP、Guard/バッシュ/3段コンボ、ロック固定、カメラ。
- 純粋な左移動時の45°下右方向、純粋な後退時の真下ノズル、後退以外の右方向ノズル制限も維持。

新しい `tools/v261_rear_diagonal_thruster_self_check.py` をActionsに追加し、数値検査とコード構造検査を行います。Godot/Android実機での動きは別途確認が必要です。
