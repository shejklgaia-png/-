# SERA v477 — ビットタラン砲台のチャージ中高速追尾

## 追尾の動作
- **0〜10秒：チャージ。** 追尾はチャージ開始時に1度だけ起動し、0.7秒の滑らかな加速で照準を取得します。加速完了後は通常の角速度制限を適用せず、プレイヤーのRUN／BOOST速度や方向転換に関係なく目標位置へ追尾します。
- **10〜12秒：青い球体が生成・拡大・縮小。** 追尾モードを再起動せず、チャージからの高速追尾をそのまま維持します。縮小中もプレイヤーを狙います。
- **12〜14秒：レーザーを直ちに照射。** この瞬間から従来の装備速度依存の追尾制限へ切り替えます。RUNより速く、BOOSTより遅い角速度を維持し、持続ブーストでビームを振り切れる仕様です。
- **14〜14.7秒：** 照射終了の最初のフレームから基本姿勢へ0.7秒で滑らかに戻し、次のチャージで再度1回だけ高速追尾を開始します。

## 変更しない要素
- チャージ10秒／球体2秒／照射2秒／復帰0.7秒の時間軸。球体の拡大0.2秒・縮小1秒。発射時の停止・遅延・当たり判定猶予は追加しません。
- 照射中の旋回上限、プレイヤー装備速度反映、ワールド水平回転／上下俯仰のみという砲台軸制約。
- 1照射最大1回の命中、Damageknock、ガード、距離・ビーム幅、各エフェクト、Blockbench原本と脚の動作。

## 検証
