# SERA v311 — ロック中のターゲットをセラの正面としてSTEPモーションを選定

## 仕様
- **ロック中の前方**は、現在セラがロックしている部位（本体の場合は本体中心）へ向かう水平ベクトルです。これは物理的にセラが向く方向と一致します。
- ステップ姿勢はその前方を基準に**前 `Frontstep`／後 `Backstep`／右 `Step_R`／左 `Step_L`**から選び、斜めは既存の360°補間でつなぎます。画面右へのフリックが、敵に対する現在位置によって前進ポーズになることも正しい仕様です。
- **ロックしていない場合**は画面方向をポーズ基準に使用します。
- **移動方向と距離はこれまでどおり画面フリック基準**です。前・左右3m、後5m、斜めは中間距離。姿勢の向きが変わっても実移動の進行方向や距離は変えません。
- ステップ中にロック先が変わった場合、現行の0.08秒補間で姿勢方向だけを追従します。9.2.2の`Step_R`、腰回転の保持、その他の4方向原本、蹴り派生、EN、ロック/衝突/カメラ/攻撃は維持しています。

## 検査
- 新規静的検査：ロック優先方向の判定、スクリーン基準移動、9.2.2原本の維持。
- 新規Godot実行検査：正面/側面/後方にセラを配置し、画面右へのフリックが実際のロック前方に応じて別のポーズになることを検査。無ロック時の画面方向フォールバック、ロック部位変更時の姿勢追従と実移動ベクトルの維持も確認。
- Android実機の映像・タッチ体感は未検証です。
