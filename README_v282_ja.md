# SERA v282 — サマーソルトキックの二重回転を修正

## 添付動画で確認した問題
`Kick_b` 発動中、機体が空中で回るというよりも、地面付近で不自然に振り回される挙動が発生していました。

## 原因
- Blockbench原本の `Kick_b` では、腰（Waist）のX回転キーフレームが約 -12° から 369° まで進み、**既にバク転が定義されていました**。
- v280で描画リグ（原点は足元）全体にも360°回転を足したため、**バク転が二重に加算**されていました。
- 腰の原本回転では、125° → 335° の区間があるにもかかわらず、通常のクォータニオン短経路補間（SLERP）が逆方向の回転を選んでいました。

## 修正
1. **原本 `Kick_b` がある場合**は、描画リグ全体の追加回転と原点補正を行いません。Blockbenchの腰ピボット（地上約1.105m）を基準に回転します。
2. `Kick_b` のWaistだけ、原本Eulerキーを連続補間してからクォータニオンへ変換します。125° → 335° を正しい正方向に回します。他の関節／モーションの補間は従来どおりです。
3. `Kick_b` が欠落した場合だけ、従来の仮回転を使用します。
4. v281の**単一ベジェ曲線による跳躍軌道**を維持します（後方4m・頂点1.5m・飛行0.8秒・着地0.2秒）。
5. 2回蹴り・バッシュ・操作受付・スラスター・当たり判定の仕様は変更しません。

## 検証
- 既存のv280 Godot実行テストを、二重回転を検出し原本腰回転の連続性を確認する内容へ更新しました。
- v282の静的回帰テストを追加し、CIに登録しました。
- Android実機での修正後動画確認は未実施です。
