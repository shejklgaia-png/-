# SERA v141 — タップ直後から動くセラとカメラの同時アニメーション（2026-11-08）

CUSTOMIZEをタップした**その入力処理内**で、元の展示セラの拡大・移動（0.28秒）と、カメラ接近（0.18秒）の両方を開始するよう変更しました。これまでの0.18秒待機をなくしています。

### 変更後の挙動
- CUSTOMIZE選択：セラは展示台から左上のプレビューへ移動・拡大しながら、カメラも同時に接近します。
- 戻るUI／Android戻る／Esc：セラはその時の回転姿勢から展示台へ0.28秒で戻り、同時にカメラも0.18秒で全景へ引きます。両方が完了するまでは操作をロックします。
- モデル到着後は左上で定位置回転。暗い青のグリッドと放射背景はセラの回転に追従しません。
- 3区画のメニュー、モデルサイズ、NEXUS_poseやその他4設備とゲームプレイは維持します。

最終カメラにおけるモデルの位置・倍率は入力時に一時的に計算し、描画に使う元のカメラを戻してから2つのTweenを同時に開始します。モデルやゲームシーンの複製はありません。

コード検査：`tools/v141_concurrent_nexus_motion_self_check.py`。GodotエディターとAndroid実機でのフレームごとの動きや入力応答は未検証です。
