# SERA v170 — フリック操作をボート型の波跡へ変更（2026-11-09）

## 動作
TRAINING画面でフリック操作が受け付けられると、指を離した位置から指の移動方向とは反対側へ、ボートの後方にできる航跡のような**左右対称のV字の曲線波**を表示します。3組の波面が0.06秒差で現れ、広がりながら薄くなって消えます。演出時間は**0.43秒**です。円形の波紋や直線矢印ではありません。

対象は左右フリック（サイドステップ）、下フリック（バックステップ）、上フリック（3段目／3段目終了直後のバッシュ、ガードからのバッシュ）です。デバッグ用の上フリックジャンプが将来有効化されたときも、成立した場合にのみ同じエフェクトを表示するようにしました。

フリック不成立時・通常のRUN/BOOSTドラッグには発生しません。新しい指で触れた瞬間に波跡を消し、従来どおりのRUN/BOOSTコントローラーを表示します。HUD上のタッチでも波跡を消しますが、ボタン入力は妨げません。

## 維持した仕様
- **タップ攻撃後の円形波紋（v169）はそのまま維持**します。フリックの波跡とは同時に重ねません。
- フリック判定距離／速度／持続時間、ステップ移動量、既存モーション、バッシュ連携、ダメージ、ロックオン、コントローラーの位置・形状は変更していません。
- 追加したのは既存HUD内の2D描画です。新しい画像素材・シェーダー・Controlのタッチ捕捉はありません。

## Android実機での確認
1. GitSyncで`main`を同期して`SERA v170`を起動し、トレーニングルームで左右と下に短くフリックします。
2. 指の移動方向の後ろにV字の曲線が伸び、約0.43秒で消えるか確認してください。
3. 3段コンボ後の上フリックBashと、ガードからの上フリックBashでも同様に確認してください。
4. 波跡の再生中に画面へ触れ、波跡が即座に消えて通常のコントローラーが現れることを確認してください。
5. 短いタップ攻撃は従来の円形波紋が出て、RUN/BOOSTのドラッグでは波跡が出ないことを確認してください。
