# SERA v516 — 6層八角形シールドとガラス破片の破壊演出

## 通常のシールド命中
- **中心から厚みのある正八角形のフレームが6個、内側から順番に出現**。1層ごとに8辺の直線で輪郭を作り、面や輪郭をぼかさない。
- 6層は内側から外側へ大きくなり、透過率も段階的に高くする（アルファ0.95→0.35）。中心の小八角形は色のある膜で埋めたまま。
- 6層の展開 **0.20秒** → 全層表示 **0.20秒** → 消えるまで **0.20秒**。合計 **0.60秒**。

## シールド破壊
- 旧円形・放射グラデーションは廃止。大きな青白い**ガラス状の破片14個**を各ヒット時にランダム生成し、回転しながら外へ飛散させる。破片の輪郭は硬い多角形のまま。
- 横一線の青白い稲妻は0.065秒で左右へ伸び、0.16秒で消える。**左右の先端は透明度0へ減衰**。空間ぼかしは使わず短い2層の実線とする。
- 破壊SEと中心が空洞になるルールは保持。

## 維持した仕様
- シールドがある間は中心を欠損させない。テストターゲット・ビットタランに共通適用。
- 青/黄/赤への色分け、HPバー非重畳、3D描画優先度115・深度テストON、既存ヒット火花より奥の描画位置は維持。
- シールド100SP、近接最大25%・射撃最大95%軽減、4秒後から20SP/秒回復、部位破壊とモーション・レールガン・LABO/装備カスタマイズに変更なし。
