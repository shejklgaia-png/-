# SERA v288 — セラ密着追尾カメラ（小遅延＋距離・角度上限）

## 変更した追従方式
- カメラの基準点を**敵の中心**から**セラの位置**へ変更。敵が画面に残るよう、基準点はセラから敵方向へ最大2.0mだけ先行させます。遠距離ではセラとほぼ1対1で並進します。
- 通常は約0.07秒（追従率15/秒）の軽い平滑化を適用します。ただしセラと基準点の差が**0.65m**を超える場合は、そのフレームで**差を最大0.65mに制限**します。その後はセラの動きと並走し、置いていかれる距離が増えません。
- カメラの水平角も10/秒の軽い平滑化でセラへ追従。追従目標はセラの背後12°の肩越し位置で、**角度差が12°を超えない**よう強制補正します。高速の左右ステップや追尾攻撃でも、セラが極端に横向きになりにくくします。
- **攻撃中もカメラの位置・水平角の追従を継続**します。v287の「攻撃中は完全にYaw固定」は撤回し、角度・距離の上限で過剰な遅れを防ぎます。通常の画面方向360°ステップ中はその入力のワールド方向を保つため、短いステップのYaw固定だけ維持します。
- 攻撃中のズームイン抑止、必要な画面端保護のズームアウト、低いカメラ角度0.21（約12°）は維持します。**俯瞰視点にはしません**。
- 敵の上下アイドルボブ（上下約7cm）をカメラへ伝搬させないよう、カメラの注視高さは安定した基準高さとします。これにより短周期の上下揺れも軽減します。
- 左右蹴りの敵中心の弧、終点の左右±30°制限、安全半径3.55m、モーション・EN・スラスター・当たり判定はそのままです。
