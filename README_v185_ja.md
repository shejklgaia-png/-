# SERA v185 — 通常格闘の発動距離を2.0mへ変更

- `MELEE_SURFACE_REACH` を **1.0m → 2.0m** に変更しました。距離はセラ中心から敵の当たり判定表面までの水平距離です。
- 通常格闘1～3段目の追尾終了と攻撃モーション開始、攻撃中の追尾停止距離、近接射程表示に共通で反映します。
- バッシュの発動距離は **0.95m** のまま、通常格闘の距離命中補助もA頭部 **0.83m** / B頭部 **約0.82m** のままです。
- A/Bの攻撃前追尾上限 **0.4/0.6秒**、格闘2/3段目とバッシュの **0.2秒**、近接ブースト速度、モーション・攻撃判定のタイミング、EN消費は維持します。

**注意**：2.0mは攻撃モーションが始まる距離であり、命中確定距離ではありません。剣の3D当たり判定か既存の命中補助範囲に入らなければ空振りする場合があります。

## 確認手順

GitSyncで `main` を同期し `SERA v185` を起動、TRAININGでターゲットの表面から2.0mに近づいたときに通常格闘が始まることを確認してください。バッシュの射程、A/B追尾時間、剣の命中範囲は変更していません。
