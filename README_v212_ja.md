# SERA v212 — 重量脚部SLIDE姿勢とスラスターの方向

## 重量脚部のSLIDE

重量級のLOWER BODY B/D装備で通常移動する際は、4方向のBoost_*姿勢をそのまま100%適用せず、待機姿勢 `Wait_motion` と半分ずつ混合します。

| 状態 | 姿勢 |
|---|---|
| 重量脚部の通常移動（SLIDE） | 待機50% ＋ 対応するブースト姿勢50% |
| 本当にBOOST中 | 従来のブースト姿勢100% |
| 他の脚部でのRUN | 従来どおりの走行アニメーション |
| STEP、攻撃、ガード、待機 | 既存アニメーションを維持 |

単に腰の傾きだけでなく、全ボーンの回転Quaternion・位置オフセット・スケールを50%でブレンドします。ブースト速度、EN、タイミングは変えません。従来の重脚SLIDEは背面スラスター噴射を発生させません。

## ノズルの既定方向

- 待機時を含め、左右ノズル本体の初期姿勢を**下90°**に変更しました。
- 噴射終了後も従来の水平角0°ではなく下90°へ自然に戻ります。
- 本体のPivotは引き続きBlockbenchのThruster_L/Thruster_Rを使用し、金属ノズルと噴射筒が同時に回ります。

## 左ブースト・左ステップ

**画面左へ移動するとき、スラスターは画面右下へ噴射**するようにします。

- 左STEPはフリック方向Xから、左BOOSTはデジタルスティックの方向Xから判定します。従来の左ステップ操作にも対応します。
- カメラの画面右方向と世界下方向を1:1で合成した噴射方向を使用します。画面右下へ斜めに進むイメージです。
- 左斜め方向への操作では左向き成分に応じて段階的に補間します。
- 右移動・前移動・既存の後方ステップの下向き制御は維持します。後ろ左への斜め操作は後退用の下向き重みも引き続き適用します。

既存の左右80°・下90°・上1°の機械的回転制限、0.075秒の回転追従、アニメーション原本、ENコスト、操作とステップ距離は変更しません。
