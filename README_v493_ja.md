# SERA v493 — レールガン追尾をRUNとBOOSTの間の速度に制限

## 変更した挙動
- 12〜14秒のレーザー照射時、射線とプレイヤーの水平距離0〜2.5mに応じて、従来の0.7倍の追尾角速度から最大1.0倍へsmoothstep補間します。
- **2.5m以遠では追尾角速度を一切増やしません。** 目標速度だけでなく、補間途中の実速度も上限を超えないよう制限します。
- 最大追尾速度は現在の装備のRUN速度とBOOST速度を65%で補間した値です。標準装備なら**RUN 4.0625m/s、最大追尾相当5.3828125m/s、BOOST 6.09375m/s**です。実距離に応じて角速度へ変換するため、通常移動ではレーザーが追いつき、BOOSTで横方向に動き続ければ振り切れます。
- 移動距離／入力フレーム間隔からプレイヤー速度を逆算して追尾を無制限に加速する処理を廃止。急な位置変更やノックバックでも速度が暴走しません。
- 追尾速度の時間平滑化(16/s)と照準の時間平滑化(10/s)は維持します。

## 維持する仕様
- 0〜10秒充填中は追尾なし。10〜10.7秒は青球体の追尾開始を補間し、10.7〜11秒は従来どおり高速の事前照準。11〜12秒の球体縮小時は追尾速度0.7倍。12〜14秒照射、14〜14.7秒復帰。
- レーザー威力60%、重なったときの0.2秒ごとの無制限再ヒット、ノックバック、青球体とレーザーの表示、音、元のモデル、IK、足攻撃とその判定は変更しません。
- 砲台の世界Yaw独立制御、本体旋回と接続軸の同期、0.7秒の復帰補間も変更しません。

## CI更新と実機確認
- 変更前に`tools/sera_ci_manifest.txt`、`docs/SERA_ACTIVE_CI_POLICY_ja.md`、既存の`tools/bittaran_railgun_runtime_check.gd`、`tools/bittaran_world_yaw_independence_runtime_check.gd`、共通CIワークフローを確認。
- **本体変更前に**追尾の既存CIへ2.5m以降の速度上限と5/8/30mでのRUN＜追尾＜BOOSTを追加。さらに実シーンでRUNとBOOSTの円周横移動を各1.5秒実行し、前者はレーザーの判定幅に入り後者は外へ逃げられることを検査します。
- マージ後`main`で全Python/Godot CIを実行。Android実機では横BOOSTの回避しやすさ、通常移動での追いつき方、近距離の照準を別途確認します。
