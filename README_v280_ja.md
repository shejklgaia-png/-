# SERA v280 — 左右蹴りの移動タイミングとサマーソルトの全身回転

- `Kick_r`: 原本モーションの2段目振りかぶり（0.33333／全長1.0秒）から横移動を開始。
- `Kick_l`: 原本モーションの2段目振りかぶり（0.41667／全長1.0秒）から横移動を開始。
- 横移動の方向・距離・衝突判定は従来のSTEP計算を使い、移動に要する時間は通常STEPと同じです。横移動が始まるまでは1段目の蹴りを行い、2段目の途中から移動します。2発の当たり判定時刻（0.25／0.58333）は変更しません。
- `Kick_b`: 原本の骨格モーションに加え、描画リグ全体を飛行中に後方へ360度回転させます。従来は原本モーションが存在すると全身回転が無効になっていました。回転中は中心軸の高さを補正し、キャラクターの衝突形状は回しません。
- 後方4m、最高1.5m、飛行0.8秒、着地0.2秒、原本最終フレームの描画完了待ち、入力・EN・バッシュの扱いは維持します。
- 旧v278テストは、新しい横移動開始タイミングに合わせて期待値を修正。v280でGodot実行時の全身回転とキャンセル復元を追加して検証します。

Android端末上での視覚・操作確認は自動テストの対象外です。
