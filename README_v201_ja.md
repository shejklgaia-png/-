# SERA v201 — ブースト中ホールド時のRUN判定ちらつき修正

指をブースト位置でホールドしている間、ENが不足するとブーストが解除され、その後のEN回復で同じ指位置から再発動する問題を修正しました。

- **ENが十分な間**：指を動かさずにホールドすればBOOST判定を維持します。
- **EN不足後**：RUNへ戻った後、ENが回復しても同じ指位置からBOOSTが自動再発動することはありません。
- **再度BOOSTへ移行**：指を一度解除円（半径159.6px）より内側へ戻し、再び開始円（半径184.8px）より外側で0.10秒ホールドします。指を離して新しい操作を開始した場合も従来どおりです。
- **変更しないもの**：360°のRUN方向判定、ステップ、攻撃、ガード、EN消費と回復、ブースト速度補間0.20秒、ブーストポーズ維持0.50秒、UI意匠と判定円のサイズ。

検査：`python3 tools/v201_boost_hold_rearm_self_check.py`。静的検査と状態遷移の数値モデルです。Android実機での操作確認は未実施です。
