# SERA v167 — Guard Reaction + Bash Loop（2026-11-09）

## 操作
- ガード中に敵攻撃が当たると`Guard_REACTION`を1回再生して、ガード継続中は`Guard`に戻ります。ノックバックと通常被弾モーションは発生しません。
- 通常3段コンボ `melee1 → Melee2 → Melee3` の3段目中、または3段目終了後0.65秒以内に**画面上へ素早くフリックして離す**と`Bash`が発動します。
- `Melee3`の0.625秒より前にフリックしても入力を記憶し、キャンセル可能になった時点でBashを始めます。
- Bash中にタップすると入力を記憶して、Bash終了時に1段目を再開します。Bash終了後0.65秒以内のタップでも1段目を再開できます。
- ガード成立後に画面上へ素早くフリックして離す操作でもBashに移行します。

## 判定と暫定仕様
- Bashは最新Blockbenchの`Bash`モーション（0.5秒）。発動後は移動ロック、専用の1ヒット判定です。
- 仮のダメージ12、接触キーフレーム0.25秒、対象キューブ表面から0.95m以内で命中。既存のヒットストップ、ヒットエフェクト、SE、ダメージ表示を流用します。
- 盾値、シールド消費、攻撃相殺や強攻撃の突破判定は未設定です。値を推測して追加していません。
- 他のRUN/BOOST操作、横フリックSTEP、下フリックBACKSTEP、3段のダメージ12/12/26、3段モーション、ジャンプデバッグ、NEXUS画面、カスタマイズは変更していません。

## アセット
- `models/SERA_BOOSTER_allテスト.bbmodel` の`Guard_REACTION`と`Bash`だけを`assets/sera_source.json`のアニメ配列に追加し、`assets/sera_data.gd`の組込データを同期。モデル本体のA/B形状、元のBlockbenchファイルは変更しません。
- `scripts/sera_rig.gd`: 読込確認、反応モーションの1回再生と戻り、Bashワンショット再生。
- `scripts/main.gd`: ガード成立の反応呼び出し、前フリックの優先判定、Bashの1回命中、追撃バッファ／受付時間。
