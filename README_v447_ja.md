# SERA v447 — 胴体上昇中の足先先端を床につけ、届かなくなったら手前へ引きずる

## 仕様
なぎ払い・弾き・踏みつけ（左右6攻撃）で、攻撃終了後の復帰動作を次のようにします。

1. **胴体の基本姿勢への復帰**：実際の足先メッシュの**先端側の下面角**を、ワールド床Y=0（接触余裕3mm）に置き続けます。端面を先に特定し、そこから一番低い角を選ぶため、根元や足首ではなく先端下面が接地します。先端角の選択に必要な8頂点の確認は、胴体復帰開始の1回だけです。
2. **関節が伸びきりそうなときは床上で引きずる**：原本の脚を伸ばしきると床に接触できなくなるため、上肢・下肢の現時点の正確な長さから最大到達半径を毎フレーム計算し、距離不足分だけ**足先の接地点XZを胴体の付け根（肩）側に引き込みます**。引き込む間も**接地点のYを変えず**、浮き上がりを防ぎます。
3. **関節ごとに異なる役割**：上肢と下肢のつなぎ目（膝／肘側）の曲がる方向には、前フレームのIK解を**82％**引き継ぎます。一方、下肢と足先のつなぎ目（足首／手首側）の角度は、届きにくくなったときに限って**最大18％**の補助回転に制限します。主な短縮は上肢・下肢の折れ曲がりと床上の引きずりで表現します。
4. **胴体が基本姿勢に戻りきったら**接地点の拘束を解除し、その直前のIK補正済み3関節姿勢から、従来どおり**1.20秒かけて5次イージング**でゆっくり基本姿勢へ戻します。別途足を振り上げるモーションは挟みません。

## 軽量化の仕組み
固定床の高さは常に **Y=0** です。世界座標のヒップ `H`、足先 `P`、足先から足首までのオフセット `D`、上肢＋下肢の安全な最大到達距離 `L` から、

`r = sqrt(max(L² - ((P-D).y - H.y)², 0))`

を算出します。足首の目標位置 `P-D` の水平距離が `r` を超えた場合だけ、ヒップを中心とする水平到達円の境界までXZを内側へ動かします。この計算は平方根1回・ベクトル演算数回です。接地する脚の**2ボーンIKは1回／フレーム**です。レイキャスト、形状キャスト、毎フレームの頂点走査、メッシュ単体の位置変更は使用しません。

膝が伸びきる直前に不自然な角度に飛ばないよう、到達長に8cmの安全余裕を持たせています。足先の角度補助は最大18％で、変化速度も制限します。

## 維持したもの
- **なぎ払いの往路終了は開始から2.00秒**、復路は通常速度、途中スローなし。
- 復帰順序は**攻撃終了→胴体復帰（なぎ払い1.40秒／弾き・踏みつけ0.62秒）→腕1.20秒で基本姿勢へ**。
- 元のBlockbench原本、関節の親子接続、脚の固定長、ゲームの起動シーン、蹴り・踏みつけの時間は変更しません。

## 実行確認の限界
実装はGitHubのmainブランチに反映済みで、数式の独立した数値検証とソースの静的整合性確認を実施しています。**Godotの実行・Android実機による見た目確認はまだ完了していません。** 特に胴体の高さが上下2本の骨の長さと足首補助角で到達可能な範囲を超えた場合、XZを胴体側へ引き込むだけでは物理的に接地できず、残差が生じ得ます。この限界は`source_ik_body_toe_pin_drift_max`で検出します。
