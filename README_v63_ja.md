# v63 ステップ速度の連続減速／下部グレーの明度調整

## ステップ速度
- 距離基準はv62と同じ「プレイヤー中心から、ターゲット箱型当たり判定の**表面**までの水平最短距離」です。中心間距離ではありません。
- 5m以上：10.0m/秒。
- 5m未満〜2m超：smoothstep補間により、10.0m/秒から6.0m/秒へ滑らかに減速。
- 2m以下：6.0m/秒。
- 減速はステップ開始時点の距離で計算し、ステップ中の速度は固定します。
- HUD表示を小数第1位に変更し、途中の速度変化を確認できます。
- 最小予定移動距離2.0m、最大予定移動距離4.0m、最大時間0.4秒、接触判定・円弧移動・ドラッグ入力は維持します。距離上限と最大時間の制限が競合する場合は0.4秒以内で移動できる長さを優先し、接触時は予定距離未満になる場合があります。

| ターゲット表面までの距離 | 設定速度 |
|---|---:|
| 5.0m以上 | 10.0m/s |
| 4.5m | 約9.7m/s |
| 4.0m | 約9.0m/s |
| 3.5m | 8.0m/s |
| 3.0m | 約7.0m/s |
| 2.5m | 約6.3m/s |
| 2.0m以下 | 6.0m/s |

## 操作用グレー領域
- v62の上端(75%)→85%のフェードおよび下部15%のベタ表示を維持します。
- 色はニュートラルグレー RGB(0.22,0.22,0.22)に明るく調整。
- 下端の不透明度90%は変更しません。グラデーションの上端は完全透明です。

## 変更していないもの
- v56以来のカメラ俯瞰角度と位置、上部HUD構成、ロックオンマーカー追従、攻撃、衝突判定、ステップの方向・モーション。

Godot 4.7.2 stableの公式ドキュメントにあるCanvasItem.draw_polygon/CanvasItem.draw_rectを引き続き使用しています。実機での描画・操作確認は未実施です。
