# SERA v313 — 手動BOOSTの移動距離を全方向5mに統一

## 移動操作
- 長押しドラッグで発動する**通常BOOST**は、前後左右・斜めを含む360°のどの方向でも**1回の発動につき移動距離5m**を上限とします。
- BOOST確定後に実際に移動した水平距離を積算し、方向転換してもリセットしません。壁などに阻まれた距離は加算しません。5mを超える最終物理フレームの速度を残距離に合わせて制限します。
- 5mに達したらBOOSTを終了してRUNへ移行します。外周で指を保持し続けても自動再発動せず、指を内側の解除範囲へ戻してから外周へ出すか、新しくタッチすると再発動できます。
- 既存の**RUN⇄BOOST速度補間0.20秒**、BOOST解除後の姿勢保持0.50秒、入力方向・スラスター、EN消費および解除条件は維持します。終了後の速度補間中はRUNとして動き、追加BOOST距離には算入しません。

## 変更しない項目
- **通常フリック回避（STEP）は全方向7m・15m/sのまま**です。回避の低姿勢リーン、カメラ・ロック、キック派生（左右蹴り合計3m／サマーソルト5m）、近接攻撃追尾は変更しません。
- 画面内アナログRUN、BOOST入力の閾値／確定時間、装備による走行・BOOST速度補正とアニメーション原本は変更しません。
