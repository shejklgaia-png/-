# SERA v140 — 高速な拡大と、戻る時の滑らかな格納（2026-11-08）

CUSTOMIZEに入る際の展示モデル移動アニメーションを**0.46秒→0.28秒**に短縮しました。速度を上げつつ、Cubic Ease In Outの滑らかさを維持しています。

戻る操作も対称的にし、右下の「<」ボタン（Android戻る・Escを含む）を押すと、**回転済みの現在位置・姿勢から0.28秒で展示台の元の姿勢・位置・倍率まで滑らかに格納**します。その後、カメラが従来の0.18秒で全景へ戻ります。カメラ移動を待たずに枠線の選択状態を解除し、両メニュー／戻るUIは即時に非表示です。

モデルのTween中はタッチ回転操作を無効にします。グラデーションとグリッドは動かず、モデル格納の完了時に消えます。左上モデル表示、左下正方形・右縦長のメニュー、NEXUS_pose、ほか4施設、戦闘と音声は維持します。
