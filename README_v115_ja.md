# SERA v115 — BOOST中のコントローラ操作点を境界線の外側に配置（2026-11-07）

## 変更
- 従来はBOOST確定後も操作点をRUNの半径100%で描画していたため、125%のBOOST境界線より内側に見えていました。
- RUN中は従来の半径100%以内の表示を保持します。BOOST確定中は操作点の中心を方向に沿って半径148%へ切り替え、半径29pxの操作点全体が125%のBOOSTガイド円弧の外側に配置されるようにします。
- BOOST開始前は実際の指がRUN円周を超えた場合に薄いガイド円弧を表示。BOOST確定中も同じ円弧を明るく太く表示することで、操作点がBOOST領域にあると明示します。
- 半径168pxのRUN円、BOOST開始125%（210px）、BOOST表示中心148%（248.64px）、操作点半径29px。操作点内側219.64pxはガイド210px＋線幅を超えています。
- 指の実位置と入力方向を変更せず、操作点の描画位置のみを切り替えます。BOOST解除時はRUN描画に即時復帰します。

## 維持
- BOOST有効条件：125%超で0.10秒保持。解除条件：110%未満。倍率1.5倍、加減速0.15秒、BOOST4方向アニメーション・全RUN操作・カメラ・残像・他のゲーム機能に変更なし。
- 変更ファイル：`scripts/touch_overlay.gd`、`project.godot`、`DEVELOPMENT.md`、`docs/SERA_INPUT_MOVEMENT_CAMERA.md`。新規：`README_v115_ja.md`、`tools/v115_boost_controller_visual_self_check.py`。
