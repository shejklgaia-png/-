# SERA v511 — シールド防御光・亀裂・破裂の視認性を大幅拡大

## 実機報告への対応
v510で接触シールドが「ほぼ見えない」という報告に対応。テストターゲット・ビットタランの両方に適用される共通描画コンポーネントだけを調整しました。

- **通常の接触防御光**：半径を旧27〜74px相当から **100〜260px相当**へ拡大。最低表示倍率0.85を適用し、遠いカメラでも小さくなりすぎないよう調整。
- **明るさ・持続**：中心を白寄りの強い光、青/黄/赤の色帯も高い不透明度に。外周のアルファは0のままで自然に透ける。0.28→**0.44秒**。
- **シールド破壊の横亀裂**：中心から左右へ各最大**470px相当**に伸びる、太く明るい青白い稲妻（旧最大180px相当）。
- **シールド破壊の拡散**：最大半径 **470px相当**（旧約186px）の青白い放射状グラデーション。0.44→**0.65秒**。
- **描画奥行き**：斜めの命中時に本体装甲へ埋もれないよう、描画専用カメラ側オフセット0.032→**0.14m**に。判定やロック位置は変更しない。

## 維持する仕様
- HPバーへの重ね表示は引き続き**廃止**。シールドの表示は命中部位の3Dエフェクトのみ。
- 残量100〜60%青、59〜30%黄、29%以下赤。破壊時のみ横亀裂＋青白い放射状破裂と専用SE。
- 防御計算（100SP、近接最大25%、射撃最大95%、4秒後から20SP/秒回復）、部位破壊計算、既存の命中火花、ビットタランのモーション・当たり判定は変更なし。
- 描画は`SHIELD_IMPACT=115`、深度テストON。既存の命中火花`HIT_SPARKS=120`の下に合成。

## 検査
`tools/v510_predictive_shield_self_check.py`と`tools/v510_predictive_shield_runtime_check.gd`の大きさ・表示時間・装甲前面距離を**本体より先に**新しい仕様へ更新しました。既存の戦闘/モデル/HPバー回帰テストは保持します。CIはマージ後mainで全件を確認し、Android実機で最終的な発光・サイズ・遮蔽を確認してください。
