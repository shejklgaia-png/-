# セラ v80｜至近距離ステップ時のカメラ回転を修正

## 修正
- v79で導入された「格闘・ブースト時だけカメラ追従を強める」変更を、v78の標準設定へ戻しました。
  - 通常追従レート `1.65`、移動中の方位追従係数 `0.55`（従来通り）。
  - 格闘・ブースト向けの追従レート `6.0`、方位追従係数 `0.85` は削除。
- **敵キューブの表面から1.0m以内で開始した左右ステップ**に限り、ステップ開始時のカメラ方位からの変化を左右18°以内に抑えます。
- この条件のステップ中は、`_enforce_screen_edge()` によるカメラ方位の強制補正を回避します。
- プレイヤーと敵が画面外へ出ないための `_fit_full_frame()`（ズーム補正）は従来通り使います。
- ステップ最終フレームでも同じ制限を使います。終了後は自然な標準追従に戻ります。

## 維持
- v78のブースト移動／通常走行／通常格闘の追従設定。
- ステップの移動軌道・速度8〜10m/s・距離2〜4m・当たり判定。
- 時間差残像（ステップ0.22秒、ブースト0.14秒）、敵AI・弾・被弾・ノックバックなど。

## 動作検証
- コード差分と静的チェックを実施。Godot本体およびAndroid実機の動作は未検証。
- 確認操作：敵キューブの至近距離まで近づく→左右に連続フリックして、カメラが急回転しないことを確認。
