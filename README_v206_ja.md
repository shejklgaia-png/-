## スラスターエフェクト
- **形状**：左右それぞれ四角形断面の中空筒。外側の青い半透明筒と、細い水色の内側筒の2層。
- **揺らぎ**：長さ方向に増える波形ゆらぎと、輝度・透明度の周期変化。GL Compatibility向けのメッシュ＋軽量シェーダー。新規パーティクルやテクスチャは使いません。
- **起点**：Blockbenchの`Thruster_L/R_Outer`の実際の頂点・メッシュ原点から先端を計算するため、編集済ピボットに追従します。
- **方向**：衝突後の実移動ベクトルの逆方向を狙い、ノズルのローカル後方(+Z)から左右最大38°・上下最大24°で制限します。0.075秒の指数補間で機敏に向きを変えます。正面方向への180°折り返しは許しません。
